## الهوية

- **الاسم الرسمي:** القاهرة (Cairo) | **الاسم المحلي:** القاهرة عموم (مصر) | **الأسماء التاريخية:** القاهرة المعزية + المنصورية + مدينة السلام | **الأسماء الشعبية:** مدينة الألف مأذنة + القاهرة الفاطمية + مصر.
- **الموقع:** شمال شرق مصر — على الضفة الشرقية لنهر النيل + طرف دلتا النيل 🟢 | **الإحداثيات:** 30.04°N, 31.24°E 🟢 | **الارتفاع:** ~60 م (تتفاوت) | **المساحة:** ~3,085 كم² (محافظة القاهرة) 🟡 | **السكان:** ~10 مليون (المدينة) + ~21 مليون (القاهرة الكبرى — تقديرات 2024–2025) 🟡.
- **اللقب:** مدينة الألف مأذنة + القاهرة المعزية + مدينة السلام 🟢 | **تاريخ التأسيس:** 969 م (358 هـ — القائد الفاطمي جوهر الصقلي بأمر الخليفة المعز لدين الله) 🟢 | **عاصمة لـ:** مصر + محافظة القاهرة.
- **أكبر مدينة في أفريقيا + العالم العربي** + **ثاني أكبر مدينة عربية** (بعد القاهرة؟ لا — بعد بغداد) + **عاصمة مصر منذ 969** (الفاطميون → الأيوبيون → المماليك → العثمانيون → محمد علي باشا → الجمهورية).

## سبب اختيارها عاصمة + تاريخها

### سبب الإختيار 🟢
- **الموقع الإستراتيجي:** طرف دلتا النيل + على النيل — حلقة وصل بين الشمال (الشام) والجنوب (السودان/الحبشة) + بين الشرق (الحجاز) والغرب (الليبيا).
- **وفرة المياه:** نهر النيل + أراضي زراعية خصبة + مركز زراعي وتجاري.
- **البُعد عن مناطق الصراع:** بعيدة عن الفسطاط (العاصمة القبلية) + عن العسكر/القطائع (عواصم قبلية) + عن دمشق/بغداد (عواصم الخلافات).
- **موقع وسطي:** بين المغرب (تونس/القيروان) والمشرق (الحجاز/الشام) — يسهل الحكم + التجارة + الحج + الاتصالات.
- **الدفاع:** قلعة صلاح الدين (الجبل) + أسوار + أبواب (باقية) + مركز عسكري.

### التاريخ 🟢🟠
- **ما قبل 969 (العصور القديمة):** من نِفِر (عاصمة قديمة ~3000 ق.م) → الفسطاط (641 م — عمرو بن العاص) → العسكر (750 — العباسيون) → القطائع (870 — أحمد بن طولون) → القاهرة الفاطمية (قبل 969).
- **969 (358 هـ — 16 يوليو):** تأسست على يد **جوهر الصقلي** (القائد الفاطمي) بأمر الخليفة **المعز لدين الله** → سماها «المنصورية» ثم «القاهرة المعزية» (القاهرة) + بناء قصر + أسوار + أبواب + مساكن الجيش.
- **970–972:** تأسيس **جامع الأزهر** (أقدم جامعة إسلامية) + بناء المدينة.
- **973:** المعز يصل القاهرة + يتخذها عاصمة + يغير الاسم → «القاهرة».
- **973–1171 (الفاطميون):** عاصمة الخلافة الفاطمية + ازدهار + العلوم (دار الحكمة) + القصور + الجوهرات + المدينة الألف مأذنة.
- **1171–1250 (الأيوبيون — صلاح الدين):** صلاح الدين ينهي الحكم الفاطمي + يبني القلعة + القاهرة عاصمة الأيوبيين + الفاطميون يتراجعون.
- **1250–1517 (المماليك):** القاهرة عاصمة إمبراطورية المماليك + ازدهار + العمارة الإسلامية + المساجد + المدارس + القلاع + الأسواق.
- **1168:** حريق الفسطاط (الصليبيون + السترات الصليبية) + نزح الأهالي إلى القاهرة.
- **1517–1798 (العثمانيون):** ولاية عثمانية + القاهرة عاصمة + تدهور + تراجع.
- **1798:** الحملة الفرنسية (نابليون) + القاهرة تحت الحكم الفرنسي قصيرًا.
- **1801:** العثمانيون يعودون + محمد علي باشا (والٍ) + القاهرة عاصمة مصر المستقلة فعليًّا.
- **1820–1952 (محمد علي + إسماعيل + توفيق):** تحديث + قناوات + عمارة حديثة + سكة حديد + تمدن + توسع.
- **1882:** الإحتلال البريطاني (السترة البريطانية).
- **1922:** استقلال مصر (مملكة — سعد زغلول) + القاهرة عاصمة المملكة.
- **1953:** الجمهورية (الضباط الأحرار) + القاهرة عاصمة الجمهورية.
- **1956:** الوحدة مع سوريا (الجمهورية العربية المتحدة — قصيرة 1958–1961).
- **1970ات–1981:** الإصلاحات + الإنفاق + السلام مع إسرائيل (القاهرة + دمسر) + التأميم + التحديث.
- **2011:** ثورة 25 يناير (ميدان التحرير) + الإخوان + حكم مرسي + 2013: عزل مرسي + حكم السيسي.
- 🟠 **الوضع الحالي:** القاهرة = مركز إداري + إقتصادي + ثقافي + إعادة بناء (العاصمة الإدارية الجديدة + التجمع الخامس + مدينة نصر) + تحديات (السكان + المرور + الإقتصاد).

## الجغرافيا والتضاريس

### الموقع 🟢
- **على نهر النيل:** شمال شرق مصر + طرف دلتا النيل + الضفة الشرقية (القاهرة تضم 2 جزر: الزمالك + الروضة).
- **الصورة الطوبوغرافية:** سهل فياضي + تلال (المقطم) + جبل (الجيزة) + النيل يجري شمالًا نحو المتوسط.
- **التضاريس:** سهل + تلال + جزر (الزمالك + الروضة) + جبل المقطم (شرق) + جبل الجيزة (غرب).

### المناخ 🟢
- **حار صحراوي** (BWh) — صيف >35°م (مايو–أكتوبر) + شتاء معتدل (10–20°م — نوفمبر–مارس) + أمطار نادرة (<25 مم/سنة) + رطب نسبي.
- **رياح:** شمالية + جافة + غبار أحيانًا.

## خاتمة

القاهرة = **مدينة الألف مأذنة + القاهرة المعزية + مدينة السلام** — تأسست 969 م (جوهر الصقلي — الفاطميون) + عاصمة الخلافة الفاطمية + الأزهر (أقدم جامعة إسلامية) + قلعة صلاح الدين (الأيوبيون) + عاصمة المماليك + عاصمة مصر منذ العثمانيين + محمد علي. **القاهرة الكبرى** (~21 مليون) = أكبر مدينة في أفريقيا + العالم العربي. **النهر يخترق المدينة** إلى شرق (الأثرية) + غرب (الحديثة). معالمها: ميدان التحرير + الأزهر + خان الخليلي + قلعة صلاح الدين + المتحف المصري + متحف القاهرة + جامعة القاهرة + كوبري القاهرة. أحياءها: مصر الجديدة + مدينة نصر + المعادي + مصر القديمة + الزمالك + شبرا + حلوان. اللهجة: القاهرية (عربية مصرية). الطعام + الملابس + العادات: (انظر ملفات مصر). القرى التابعة: >20 مدينة + قرى (15 مايو + العاشر + العبور + الرحاب + الشروق + بدر + القاهرة الجديدة... — تُفصَّل في المرحلة السادسة).
