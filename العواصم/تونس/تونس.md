## الهوية

- **الاسم الرسمي:** مدينة تونس (Tunis / Tūnis) | **الاسم المحلي:** تونس | **الأسماء التاريخية:** تونس العتيقة + المدينة العربي + تونس القديمة | **الأسماء الأمازيغية:** ⵜⵓⵏⴻⵙ | **الأسماء الشعبية:** تونس الخضراء (لوفرة أشجارها وغطائها النباتي).
- **سبب التسمية:** «تونس» نسبة إلى صومعة راهب كانت تسمع منها تلاوات دينية 🟢؛ أو «تونس الخضراء» لوفرة أشجارها 🟢 — روايات متعددة.
- **الموقع:** شمال شرق تونس — على خليج تونس في البحر المتوسط، خلف بحيرة تونس، مقابل ميناء اللكlette (حالق الوادي) 🟢 | **الإحداثيات:** 36.8065°N, 10.1815°E 🟢🟡 | **الارتفاع:** 0–41 م (ساحل منخفض يرتفع نحو التلال) 🟡 | **المساحة:** ~212–346 كم² (أصغر ولايات تونس مساحة) 🟡.
- **السكان (تعداد2024):** المدينة ~693,210 (الكيان الإداري لبلدية تونس) 🟢 | **«تونس الكبرى» (المترو):** ~2.7 مليون (تقديرات — ثالث أكبر مدن المغرب العربي بعد الدار البيضاء/الجزائر + حادية عشر عربيًّا) 🟡.
- **اللقب:** العاصمة السياسية والإدارية والاقتصادية والثقافية 🟢 | **من أعرق المدن التونسية** + **عاصمة ولاية تونس** (أصغر ولايات تونس مساحة + أعلاها سكانًّا) + مركز لجهة إعلامي/جامعي/ثقافي.
- **تاريخ التأسيس:** 698 م (جامع الزيتونة) 🟢؛ والجذور أقدم (قرطاج الفينيقية) + تأثير أندلسي/عثماني/فرنسي.

## سبب اختيارها عاصمة + تاريخها

### سبب الإختيار 🟢
- **الموقع الساحلي الإستراتيجي:** على خليج تونس في البحر المتوسط — مركز تجاري/دفاعي + ميناء اللكlette (ميناء تونس) + ربط بين الشرق (إيطاليا/صفاقس) والغرب (الجزائر/المغرب).
- **التاريخ العريق (تراث يونسكو 1979):** قرطاج الفينيقية (814 ق.م) ← الرومان (146 ق.م) ← الفتح الإسلامي (698 م) ← الأغالبية (القيروان) ← الحفصيون ← الحسينيون ← العثمانيون.
- **التنوع الثقافي:** ملتقى حضارات (أمازيغي/عربي/إسلامي/أندلسي/عثماني/متوسطي/فرنسي) — فسيفساء ثقافية.
- **المركزية الإقتصادية:** تونس قلب الإقتصاد التونسي (أكبر مدن البلاد + عاصمة + أكبر تجمع حضري).

### التاريخ 🟢🟡
- **الفترة الفينيقية (القرن 9 ق.م – 146 ق.م):** قرطاج (814 ق.م) ← نهب الوندال (146 ق.م) ← استرجاع قرطاج رومانية.
- **الفترة الرومانية (146 ق.م – 439 م):** مركز روماني كبير + معابد + مدرجات + قنوات مياه (دقة/الجم/سبيطلة) + المسيحية (القرن 5).
- **الفتح الإسلامي (647–698 م):** 698 م — بناء جامع الزيتونة (أقدم مسجد في أفريقيا) ← عاصمة إسلامية.
- **الدولة الأغلبية (800–909 م):** إبراهيم بن الأغلب القيروان عاصمة ← رقادة (876 م).
- **الدولة الفاطمية (909–1158 م):** المهدية + القيروان + القصرين.
- **الدولة الموحدية (1159–1269 م):** حسان بن النعمان يتحول تونس إلى قاعدة عسكرية ← يعقوب المنصور (1195) يوسع + يبني الأسوار + جامع/صومعة حسان + قصبة الأوداية.
- **الحفصيون (1229–1574 م):** عاصمة الحفصيين + ازدهار + مدارس/أسواق/قصور.
- **العثمانيون (1574–1881 م):** جامع سيدي محرز + الجامع الجديد + حمودة باشا + قصبات/أسوار.
- **الحسينيون (1705–1881 م):** عاصمة الحسينيين + قصور/أسواق.
- **الإحتلال الفرنسي (1881–1956 م):** تونس عاصمة المقيم العام الفرنسي ← عمارة كولونيالية (مبان/قصر) + بنية تحتية.
- **1956 (20 مارس):** استقلال تونس ← تونس عاصمة ← إعادة بناء جامع الزيتونة + المعهد الرشيدي + الفرقة الوطنية + المكتبة الوطنية.
- **1957 (25 جويلية):** إلغاء الملكية + إعلان الجمهورية التونسية.
- **القرن 21:** عاصمة حديثة + مركز إقتصادي/إعلامي/جامعي + رؤية.
- 🟡 **الوضع الحالي:** عاصمة + تراث يونسكو + مركز إقتصادي + ديمقراطية (بوع 2011/2014) + تقلبات سياسية.

## الجغرافيا والتضاريس

### الموقع 🟢
- **شمال شرق تونس** على خليج تونس في البحر المتوسط — خلف **بحيرة تونس**، مقابل ميناء اللكlette 🟢.
- **الشكل:** سهل ساحلي منخفض يرتفع نحو التلال المحيطة (ارتفاع 0–41م) + بحيرة تونس تفصله عن البحر.
- **الموقع الإستراتيجي:** على مفترق الطرق بين شرق وغرب المتوسط (إيطاليا/صفاقس × الجزائر/المغرب) — مركز تجاري/دفاعي/بحري.

### المناخ 🟢🟡
- **متوسطي (Csa — كوب):** صيف حار جاف + شتاء معتدل رطب + نسيم قادم من البحر.
- **الصيف (يوليو/أغسطس):** ~30–33 °م + جاف.
- **الشتاء (يناير):** ~7–11 °م + ماطر + أحيانًا ثلوج (نادرة لكنها تحدث) + رياح/هبوب.
- **الأمطار:** ~400–700 مم سنويًّا (تباين بين المصادر) 🟡 — أكتوبر–أبريل.

### الأحياء البارزة (ضمن تونس العاصمة) 🟢🟡

> 🟡 **تنبيه:** تونس لا تجري تعدادًا رسميًّا منتشرًا كاملًا بعد 2014؛ الأرقام تباينة (المدينة ~693,210؛ المترو ~2.7 مليون) وتُذكر بحصر. الأرقام المتاحة (تعداد 2004) مذكورة في تقرير الفجوات، والأرقام اللاحقة موصونة بـ🟠. الأمازيغية أقلية (~1% — تقديرات غير رسمية تصل إلى ~5%) تُصنَّف 🟠.

## خاتمة

تونس = **عاصمة الجمهورية التونسية** + **تونس الخضراء** (لوفرة أشجارها وغطائها النباتي) + **من أعرق المدن التونسية** + **أكبر مدن تونس والمغرب العربي** (ثالثة في المغرب العربي بعد الدار البيضاء/الجزائر + حادية عشر عربيًّا) + **عاصمة ولاية تونس** + **مركز إقتصادي/إعلامي/جامعي/ثقافي**. على خليج تونس في البحر المتوسط خلف بحيرة تونس، صاغت **المدينة العتيقة** (تراث يونسكو 1979 — نحو 700 معلم أثري) **التنوع الثقافي** (ملتقى حضارات: أمازيغي/عربي/إسلامي/أندلسي/عثماني/متوسطي/فرنسي). تاريخها الممتد: قرطاج الفينيقية (814 ق.م) ← الرومان (146 ق.م — مركز روماني/معابد/مدرجات) ← **الفتح الإسلامي 698** (جامع الزيتونة — أقدم مسجد في أفريقيا) ← الأغالبية (القيروان) ← الحفصيون ← الحسينيون ← العثمانيون (جامع سيدي محرز + الجامع الجديد) ← **الإحتلال الفرنسي** (1881 — عاصمة المقيم العام) ← **استقلال 1956** (تونس عاصمة — إعادة بناء جامع الزيتونة + المعهد الرشيدي + الفرقة الوطنية). معالمها: **المدينة العتيقة** (40 سوقًا + قصور + جامع الزيتونة + المساجد + المتاحف + جامعة تونس 1960) + **بحيرة تونس + ميدان باب البحر + المطار**. أحياؤها: المدينة العتيقة (التراث) + لبطون + حي الرياض + حي المطار + حي السردينة + حي الفيتنام + حي المنار + حي الأنفال + حي لرسيان + ضواحي (لبطون + قرطاج + سيدي بوزيد + لمرس + حومة + المنيان + برج العامر). اللهجة: التونسية (قاف همزة + مفردات فرنسية/إيطالية + 6 لهجات جهوية + أدوات استفهام مميزة + جدل لغوي). الطعام + اللباس + العادات: (انظر ملفات تونس — الكسكسي/البريك/اللبلابي/الشكشوكة/الحريرة/السلمة/الكفتاجي/العصبان + الجبة/السفساري/الطريون — تراث يونسكو). محاطة بـ21 ولاية (سوسة + نابل + الكاف + بنزرت + أريانة + صفاقس + قفصة + قابس + مدنين + تطاوين + قبلي...). لا تعداد رسمي منتشر بعد 2014 — الأرقام تباينة (المدينة ~693,210؛ المترو ~2.7 مليون) تُذكر بحصر 🟡، والأمازيغية أقلية (~1%) موصونة بـ🟠.
