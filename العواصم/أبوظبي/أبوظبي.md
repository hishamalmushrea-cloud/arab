## سبب اختيارها عاصمة + تاريخها

### سبب الإختيار 🟢
- **الموقع الإستراتيجي:** على جزيرة مثلثة الخليج العربي — مركز تجاري/دفاعي + ميناء + ربط بين الداخل (العين/الظفرة) والخارج (دبي).
- **التاريخ العريق:** الظبيان (قبل الإسلام) + بني ياس + الدولة العتبية (1761) + الإحتلال البريطاني + الإستقلال (1971).
- **النفط:** اكتشاف النفط (1939) → الثروة النفطية (نفط + رؤية حكومية).
- **المركزية الحديثة:** العاصمة + مركز النفط + المال/الأعمال/الإعلام + التنويع.

### التاريخ 🟢🟡🟠
- **قبل الإسلام (الظبيان):** استيطان قديم على الجزيرة.
- **بني ياس (القرن 18):** استوطنوا + زراعة + صيد + غوص.
- **الدولة العتبية (1761–1818 م):** أبوظبي عاصمة + مركز تجاري/دفاعي.
- **الإحتلال البريطاني (1820–1971 م):** معاهد + حلفاء (حفظ الملاحة).
- **الإستقلال (2 ديسمبر 1971):** أبوظبي عاصمة دولة الإمارات (6 إمارات + 7 إمارة — «أبوظبي + دبي + الشارقة + عجمان + أم القيوين + رأس الخيمة + الفجيرة»).
- **النفط (1939):** اكتشاف → الإستثمار الأجنبي + الثروة النفطية.
- 🟠 **الوضع الحالي:** عاصمة + مركز نفط/مال + رؤية 2030 + تنويع/سياحة + تقلبات إقليمية.

## الجغرافيا والتضاريس

### الموقع 🟢
- **شمال شرق الإمارات** على جزيرة مثلثة المثلث على الخليج العربي — بين أبوظبي والدبي، على ساحل الخليج 🟢.
- **الشكل:** جزيرة/ساحل منخفض يرتفع نحو الياب (ارتفاع 0–15م؛ أعلى قمة الجبل علي ~1,300م).
- **الموقع الإستراتيجي:** مركز تجاري/دفاعي + ميناء — حلقة وصل بين الداخل (الشرق) والخارج (الغرب).

### المناخ 🟢🟡
- **صحراوي حار (BWh):** صيف طويل جاف حار جدًّا (يونيو–أغسطس ~40+ °م) + رياح رطبة + رطوبة عالية.
- **الشتاء (ديسمبر–فبراير):** معتدل (~18 °م) + أحيانًا ضباب/برد.
