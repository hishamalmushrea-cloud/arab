- **سبب التسمية:** «كوت» = الحصن/القلعة 🟢؛ أو «كاظمة» = الميناء 🟢؛ أو «قرين» = التل/الأرض العالية 🟠؛ أو نسبة إلى «إيكاروس» اليونانية 🟠 — روايات متعددة.

## سبب اختيارها عاصمة + تاريخها

### سبب الإختيار 🟢
- **الموقع الساحلي الإستراتيجي:** على ساحل الخليج العربي — مركز تجاري/دفاعي/ميناء + ربط بين الهند (شرق) والشام/العراق (غرب) + ميناء هام (صيد/لؤلؤ/تجارة).
- **التاريخ العريق:** >4,000 سنة (إيكاروس اليونانية) + إيكاروس الحضارية الدلمونية + الكاظمة الميناء + الرقرن الوسيط التجاري.
- **النفط:** اكتشاف 1937 + تصدير 1946 → تكنيت الكويت الحديثة (دولة نفطية حديثة).
- **المركزية الحديثة:** العاصمة + مقر الحكم + الإعلام + الثقافي/الإقتصادي.

### التاريخ 🟢🟡🟠
- **التاريخ القديم:** إيكاروس اليونانية (القرن 3 ق.م) ← الدلمون (600 ق.م) ← اليونان (400 ق.م — القرن 2 ق.م) ← البرتغاليون (القرن 5 ق.م — القرن 16 م) ← المسلمون.
- **التاريخ الإسلامي (القرن 9–11 م):** خلافة العباسية ← القرامطة ← المرابطون → الدولة العتبية (1613) ← العثمانيون (1871).
- **التاريخ الحديث (القرن 18):** آل صباح (1756) ← الأسوار (1812/1815) ← الطاعون (1831) ← مبارك الكبير (1892/1896) ← أحمد الجابر (1915/1920) ← عبد الله السالم (1950 — أبو الدستور).
- **التاريخ المعاصر:** معركة الجهراء (1920) ← هدم السور (1920/1957) ← إعلان الاستقلال (19 يونيو 1961).
- **التاريخ النفطي:** اكتشاف النفط (1937) ← تصدير أول شحنة (1946) ← تأسيس الأحمدي (1948) ← دولة نفطية حديثة + الإعلام/الثقافي/الإقتصادي.
- 🟠 **الوضع الحالي:** عاصمة + دولة نفطية حديثة + ديمقراطية برلمانية + التحوّلات السياسية (البرلمان 2011/2014).

## الجغرافيا والتضاريس

### الموقع 🟢
- **شرق جزيرة الكويت** على ساحل الخليج العربي — على رأس خليج الكويت (خليج ضحل) 🟢.
- **الشكل:** سهل ساحلي منخفض (ارتفاع 0–16م) + ميناء الكويت (ميناء طبيعي على خليج الكويت).
- **الموقع الإستراتيجي:** بين الهند (شرق) والشام/العراق (غرب) — حلقة وصل تجاري/ميناء/دفاعي.
- **المغيرات البيئية:** رأس خليج الكويت (خليج ضحل) + الأحمدي (صحراوي) + الجهراء/الأطراف (بادية) + فيلكا (جزيرة).

### المناخ 🟢🟡
- **صحراوي حار (BWh):** صيف طويل جاف حار جدًّا (يوليو–سبتمبر ~45–50 °م) + رياح شمالية غربية جافة.
- **الشتاء (ديسمبر–فبراير):** معتدل (~10–15 °م) + ماطر قليلة (~125 مم — نوفمبر–أبريل + أحيانًا ثلوج/برد.
- 🟢 **ربط الجغرافيا بالثقافة:** الساحل الصحراوي صاغ **اللباس الكويتي** (الدشداشة/الغترة/العقال — حماية من الشمس + البهارات الخليجية) + **المطبخ البهاراتي** (المجبوس — الطبق الوطني) + **الميافة** (القهوة العربية + التمر).

### المحافظات الستة 🟢

### الأحياء البارزة 🟢🟡
- **مدينة الكويت العتيقة** (شرق — دشداشة + الصرح + السوق + الأسواق) + **جبلة** (شرق — جبلة الكويت) + **المرقاب** (شرق — جبلة المرقاب) + **الفنطاس** (شرق — الفنطاس) + **دسمان** (جنوب شرق — دسمان الكويت) + **الشامية** (جنوب غرب — الشامية/قصر السيف).
- **ضواحي مدينة الكويت:** سالمية/الجابرية/سلوى (الفروانية) + قرين (الأحمدي) + ظهران (الجهراء) + ميداء (الأحمدي) + بوبيان/ربة (الأحمدي/مبارك الكبير) + أم النوار (مبارك الكبير) + الربدة (مبارك الكبير) + عبد الله/الأحمدي/برقاط (محافظات نفطية).

## خاتمة

مدينة الكويت = **عاصمة دولة الكويت** + **أكبر موانئ الكويت** + **مركز الإعلام والثقافي والإقتصادي** + **مقر الحكم + مجالس الأمة**. على ساحل الخليج العربي، صاغت **اللباس الكويتي** (الدشداشة/الغترة/العقال — حماية من الشمس) و**المطبخ البهاراتي** (المجبوس — الطبق الوطني) و**الميافة** (القهوة العربية + التمر). تاريخها الممتد: إيكاروس اليونانية (القرن 3 ق.م) ← الدلمون ← اليونان ← البرتغاليون ← المسلمون ← خلافة العباسية ← القرامطة ← المرابطون ← الدولة العتبية (1613 — العتوب/الصباح) ← العثمانيون (1871) ← مبارك الكبير (1892) ← أحمد الجابر (1915) ← عبد الله السالم (1950) ← إعلان الاستقلال (1961). معالمها: **المدينة العتيقة** (السوق + الأسوار + القصور) + **المسجد الكبير** + **الأبراج** (1979) + **قصر السيف + دسمان** + **بيوت تاريخية** + **المتاحف** (الوطني + طارق الشمالي + صدام + بيت العثمين/العروة) + **المراكز الثقافية** (JACC + ASCC) + **الجامعات** (الكويت 1966 + الخليجية + الأهلية +...) + **المطار الدولي**. أحياؤها: مدينة الكويت العتيقة (شرق) + المحافظات الست + ضواحي (بوبيان/ربة/فيلكا/قاروة/أم النوار/الربدة). اللهجة: الكويتية (خليط نجدي/بدوي + تحوّلات حروف + لهجتين حضرية/بدوية + مفردات فارسية/هندية + مفردات حديثة). الطعام + اللباس + العادات: (انظر ملفات الكويت — المجبوس/الهريس/الجريش/المرقوق/القبوط/المضروبة/المموش/الزربيان + الدشداشة/الغترة + العباءة/الدراعة + الثوب/البرقع + الزبون/الدقلة + المشلح/القاط + القميص + العرضة + السامري + الخماري + فن الصوت + الديوانية + الكرم/الضيافة + النخوة + التكافل + العائلة). محافظة العاصمة + 5 محافظات + الجزر. لا تعداد رسمي منتشر بعد 2011 — الأرقام تباينة (المدينة ~2.38 مليون؛ المترو ~3 مليون) تُذكر بحصر 🟠، والأرقام اللاحقة موصونة بـ🟠.
