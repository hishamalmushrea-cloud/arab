# العواصم والمدن الكبرى

هذا المجلد سيحتوي (في المرحلة الثالثة) على ملف موسوعي مستقل لكل عاصمة من عواصم الدول الـ22،
يدرسها ككيان مستقل: تاريخها، سبب اختيارها عاصمة، جغرافيتها، أحياءها، حاراتها، أسواقها،
معالمها، سكانها، لهجتها، طعامها، ملابسها، عاداتها، اقتصادها، جامعاتها، متاحفها، مساجدها،
قصورها، أحيائها التاريخية والحديثة والشعبية، والقرى التابعة لها إن وجدت.

لا تُكرَّر فيه معلومات الدولة آليًا؛ العاصمة تُدرَس بذاتها.
