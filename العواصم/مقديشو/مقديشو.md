# مقديشو — عاصمة الجمهورية الفيدرالية الصومالية

> 🟢🟡🟠 (مصادر: ويكيبيديا العربية + ويكيبيديا الإنجليزية (Mogadishu) + المعرفة + a-frica-press + aljazeera + tipyan + alfan + mwadee3 + m.marefa + elfagr + ajnet). علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر (الحرب الأهلية + الإحتلالات + تقلبات سياسية). كل رقم مقرون بسنة.
>
> 🟠 **تنبيه (الحياد):** مقديشو متأثرة بالحرب الأهلية (1991–) + الإحتلالات (الإيطالي/البريطاني) + تقلبات سياسية/أمنية/إنسانية + نزاع داخلي/خارجي + الجفاف/الصحراء. يلتزم الملف بالحياد التام في تناول مقديشو بذاتها (هوية/تاريخية/معالم/أحياء) دون تبني موقف في النزاع، مع تصريح صريح بالحياد في المقدمة. الأرقام السكانية تباينة (تعداد 2005/2011) وتُذكر بحصر، والأرقام اللاحقة موصونة بـ🟠.

## الهوية

- **الاسم الرسمي:** مدينة مقديشو (Mogadishu / Muqdisho) | **الاسم المحلي:** مقديشو (حمر) | **الأسماء التاريخية:** مقديشو (القرن 10) + بنادر (Xamar) + مقديشو القديمة | **الأسماء الشعبية:** حمر (مدينة) + مقديشو (مدينة) + عاصمة الصومال.
- **سبب التسمية:** «مقديشو» = مقعد/مركز (نسبة لموقع مقديشو القديم على الساحل) 🟢 — روايات متعددة.
- **الموقع:** جنوب شرق الصومال — على ساحل المحيط الهندي (خليج عدن)، مقابل الساحل الزنجباري الشرقي 🟢 | **الإحداثيات:** 2.0469°N, 45.3182°E 🟢🟡 | **الارتفاع:** 12 م (ساحل منخفض) 🟡 | **المساحة:** ~1,657 كم² (مدينة مقديشو) / 1,817 كم² (منطقة بنادر) 🟡.
- **السكان (تعداد):** المدينة ~2–2.5 مليون (تعداد 2005/2011) 🟡 | الكثافة عالية (نحو 9,38/كم²) | **مقديشو الكبرى (المترو):** ~3.5 مليون (تقديرات متفاوتة — أكبر مدن الصومال) 🟠.
- **اللقب:** العاصمة السياسية والإدارية 🟢 | **أكبر مدن الصومال بالسكان** + **مركز التجارة + الميناء + مقر حكم**.
- **تاريخ التأسيس:** القرن 10 م (مقديشو القديمة/بنادر) 🟢؛ والجذور أقدم + تأثير عربي/هندي/فارسي/إيطالي/بريطاني.

## سبب اختيارها عاصمة + تاريخها

### سبب الإختيار 🟢
- **الموقع الساحلي الإستراتيجي:** على ساحل المحيط الهندي — مركز تجاري/ميناء (ميناء مقديشو) + ربط بين الساحل الشرقي (الهندي/الجزيرة العربية) والغربي (الإفريقي).
- **التاريخ العريق:** مقديشو من أعرق المدن الإسلامية (مركز حكم إسلامي) + سارابيون (قبل القرن 7) + التجارة الحضرية + الإحتلال الفرنسي/البريطاني + الإستقلال (1960).
- **الإسلام:** مقديشو مركز إسلامي + تبادل تجاري مع الملاحة البحرية + الصوفية + الطرق الصومالية.

### التاريخ 🟢🟡🟠
- **قبل القرن 10:** سكان قديم (تجارة بحرية) + آثار (مقابر/أضرحة).
- **القرن 10 (مقديشو القديمة/بنادر):** مقديشو القديمة ← مركز تجاري/إسلامي.
- **الإمبراطورية المرابطية (القرن 10–15 م):** مركز تجاري/إسلامي + دولة.
- **الإمبراطورية العثمانية (القرن 16–19 م):** مركز إداري عثماني.
- **الإحتلال الإيطالي (1889–1960 م):** عاصمة الإقليم + عمارة كولونيالية + بنية تحتية.
- **الإحتلال البريطاني (1941–1949 م):** إدارة بريطانية (شمال) + حلفاء.
- **الإستقلال (1 يوليو 1960):** مقديشو عاصمة الجمهورية الصومالية المستقلة.
- **الإنقلاب (1969):** سياد بري → إنهاء الحكم الديني + الجمهورية.
- 🟠 **الوضع الحالي:** حرب أهلية (1991–) + الإحتلالات الأجنبية + نزاع داخلي/خارجي + الصحراء + تقلبات سياسية/أمنية.

## الجغرافيا والتضاريس

### الموقع 🟢
- **جنوب شرق الصومال** على ساحل المحيط الهندي — مركز تجاري/ميناء + ربط بين الساحل الشرقي والغربي.
- **الشكل:** ساحل منخفض (ارتفاع 0–12م) + رأس شبه جزيرة على خليج عدن + ميناء طبيعي.
- **الموقع الإستراتيجي:** مركز تجاري/ميناء + حلقة وصل بين الساحل الشرقي والغربي.

### المناخ 🟢🟡
- **صحراوي حار رطب (BSh — كوب):** صيف حار رطب جدًّا (يونيو–سبتمبر ~27–32 °م) + رياح موسمية رطبة.
- **الشتاء (ديسمبر–فبراير):** معتدل (~24 °م) + أحيانًا برد/جفاف + أمطار قليلة (نوفمبر–أبريل).

## خاتمة

مقديشو = **عاصمة الجمهورية الفيدرالية الصومالية** + **أكبر مدن الصومال بالسكان** + **مركز التجارة + الميناء + مقر حكم**. على ساحل المحيط الهندي، صاغت **المطبخ الصومالي** (الكنترة — الطبق الوطني) و**اللباس الصومالي** (المكاوييس — ثوب أبيض، فريد عن باقي الخليج) و**الشاي** (الضيافة — مع القهوة) و**المشوي** (لحم الضأن). تاريخها: مقديشو القديمة (القرن 10) ← إمبراطورية المرابطية ← إمبراطورية العثمانية ← الإحتلال الإيطالي/البريطاني ← الإستقلال (1960). معالمها: الجامع القديم + القصور + المتاحف + المطار + الجامعات. أحياؤها: مقديشو + بنادر + هوردي + جوبا + دالون + هيران + مدج + صان + بول + جحر + عقيل + قدظ + بحر + جللق + غس + طوس + حوف + غس + قمرس + حمد بنو. اللهجة: الصومالية (لهجة كوشية — 30% من السكان) + المحاتري (لهجة المعيارية) + الماي (لهجة مستقلة) + بنيادر/بنيادر + بكية. الطعام + اللباس + العادات: (انظر ملفات الصومال — الكنترة/البرياني + السوقار/المشوي + المهراس/العصيدة + الحرف التقليدية). منطقة بنادر (17 مديرية) + 5 مناطق. لا تعداد رسمي منتشر بعد 2005 — الأرقام تباينة وتُذكر بحصر 🟠، والأرقام اللاحقة موصونة بـ🟠.
