## خاتمة

موروني = **عاصمة اتحاد جزر القمر** + **مقر حكومة الاتحاد** + **أكبر مرفأ أفريقي**. على ساحل جزر القمر الكبرى (نجازيجيا)، صاغت **المطبخ القمري** (اللوكي — الطبق الوطني) و**القهوة** (الضيافة — مع القهوة) و**الشاي** (الضيافة). تاريخها: سكان قديم + آثار + تجارة سواحلية ← موروني القديمة (القرن 10) ← إمبراطورية المرابطية ← إمبراطورية العثمانية ← الإستعمار الفرنسي ← الإستقلال (1975). معالمها: المسجد القديم + المطار + الميناء + المرفأ + جبل كارتالا + المتاحف. أحياؤها: موروني + دمبني + بامباو + مرهوي. اللهجة: القمرية (لهجة وطنية) + الشيقمري (لهجة سواحلية). الطعام + اللباس + العادات: (انظر ملفات جزر القمر — اللوكي/اللوغو + الكاري/البيلا + السومبوكو + القهوة/الشاي + الجوز الهند/الموز + الحرف التقليدية). جزر القمر الكبرى (4 بلديات) + 3 جزر. لا إحصاء رسمي حديث — الأرقام تقديرات، والأرقام اللاحقة موصونة بـ🟠.
