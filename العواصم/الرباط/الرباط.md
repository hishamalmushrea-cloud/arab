> 🟠 **تنبيه حيادي (الصحراء):** المغرب يعتبر **الصحراء الغربية** إقليمًّا مغاربيًّا محتلًّا وفق القانون الدولي (قرارات الأم المتحدة 1495، 1754، 1975)؛ يُعد المشرق العربي (الأردن/مصر) والصحراء الجنوبية (موريتانيا) من الأراضي المحتلَّة. الصحراء قضية محورية (حدود الصحراء الغربية مع موريتانيا + الجزر الممتعة + قضية إصلاح الحساسية) تُتناول بحياد في الملف دون تبني موقف — مع تصريح صريح بالحياد في المقدمة. تُوثَّق الحقائق الجغرافية والتاريخية والمعالم (المساجد/المتاحف/القصبات) كما هي، مع الإشارة إلى الوضع القانوني/الدولي دون حسم.

## الهوية

- **الاسم الرسمي:** مدينة الرباط (ar-Ribāṭ) | **الاسم المحلي:** الرباط | **الأسماء التاريخية:** صلا كولونيا (رومانية) + رباط الفتح (موحدية) | **الأسماء الأمازيغية:** ⵕⵕⴱⴰⵟ (تاشلحيت/تاريفيت/تمازيغت) | **الأسماء الشعبية:** رباط الفتح + مدينة الأنوار (رؤية 2030).
- **سبب التسمية:** «الرباط» العربية = الرباط/القاعدة العسكرية 🟢؛ أو «رباط الفتح» = معقل النصر 🟢؛ أو نسبة إلى قبيلة بني حسان التي استوطنت الإقليم 🟠 (روايات متعددة).
- **الموقع:** شمال غرب المغرب — على مصب نهر أبي رقراق (Bou Regreg) في المحيط الأطلسي، مقابل مدينة سلا 🟢 | **الإحداثيات:** 34.0209°N, -6.8416°W 🟢 | **الارتفاع:** ~79–87 م فوق سطح البحر 🟡 | **المساحة:** ~117–118 كم² 🟡.
- **السكان (إحصاء 2024):** 515,619 نسمة (المدينة) 🟢 | الكثافة ~4,400/كم² | **الرباط–سلا–تمارة (المترو):** ~1.2–2.1 مليون (تقديرات) 🟡. (سابعة في المغرب بعد الدار البيضاء/مراكش/فاس/مكناس).
- **اللقب:** العاصمة السياسية والإدارية للمملكة 🟢 | **من أعرق المدن المغربية** (الرباط/فاس/مراكش/مكناس) + **رابعة عاصمة الأمبراطوريات** + **موقع تراث يونسكو العالمي 2012** 🟢 | **عاصمة جهة الرباط–سلا–زمور الإدارية** + مركز لجهة الرباط.
- **تاريخ التأسيس:** القرن 12 الميلادي (يعقوب المنصور الموحدي) 🟢؛ والجذور أقدم (صلا كولونيا الرومانية/شالة) + الفينيقيون.

## سبب اختيارها عاصمة + تاريخها

### سبب الإختيار 🟢
- **الموقع الإستراتيجي:** على مصب نهر أبي رقراق في المحيط الأطلسي — مركز بحري/تجاري/عسكري + مقابل مدينة سلا (المترو المكتظ).
- **الجذور الموحدية:** القرن 12 — يعقوب المنصور يبني رباط الفتح + الأسوار + صومعة حسان + قصبة الأوداية — رمز الهوية الموحدية.
- **النقل الحديث:** مركز لجهة الإدارية/الملكية + مطار/مطار + الخط السريع (البراق 2018) — ربط مع طنجة/الدار البيضاء.
- **التراث يونسكو 2012:** إدراج «الرباط الحديثة والمدينة العتيقة — تراث مشترك» قاد الملك محمد السادس لإدارجها.

### التاريخ 🟢🟠
- **قبل التاريخ (صلا كولونيا):** موقع روماني/فينيقي على نهر أبي رقراق — أقدم استيطان.
- **المرابطون (القرن 12):** أسسوا رباطً محصنا لرد الهجومات البرغواطية.
- **الموحدين (1121–1269):** عبد المومن الموحدي يبني حصن + نواة المدينة ← يعقوب المنصور (1195) يبني الأسوار + صومعة حسان + قصبة الأوداية + يودعها عاصمة.
- **المرينيون (1269–1516):** تراجع + مهجور شالة الأثر.
- **السعديون (1554–1667):** استقرار + توسع تجاري + قوراصنة سلا (قراصنة بحرية) + موريسكيون من الأندلس.
- **العلويون (1666–1912):** قفطان/البلغة + القصبات + قصور.
- **الإنتداب الفرنسي (1912–1956):** الرباط مركز المقيم العام ← عمارة كولونيالية الفرنسية.
- **1956 (استقلال):** الملك محمد الخامس يُبقي الرباط عاصمة (بدل فاس).
- **2012:** إدراج «الرباط، المدينة الحديثة والعتيقة: تراث مشترك» في قائمة يونسكو للتراث العالمي.
- 🟠 **الوضع الحالي:** الرباط عاصمة + تراث يونسكو + رؤية 2030 (مشاريع) + عاصمة جهة إدارية + الصحراء قضية محورية (موريتانيا/الجزر) — تُتناول بحياد.

## الجغرافيا والتضاريس

### الموقع 🟢
- **شمال غرب المغرب** على المحيط الأطلسي — على مصب **نهر أبي رقراق** (Bou Regreg) مقابل مدينة سلا (المترو المكتظ عبر النهر).
- **الشكل:** شبه جزيرة/سهل ساحلي على المحيط الأطلسي + نهر أبي رقراق يخترقها.
- **الموقع الإستراتيجي:** مركز بحري/تجاري بين الدار البيضاء (شمال) + مراكش/أكادير (جنوب) + فاس (شرق) + سوس (جنوب).

### المناخ 🟢🟡
- **متوسطي (Csa — كوب):** صيف دافئ إلى حار جاف + شتاء معتدل رطب.
- **الصيف (أغسطس):** ~22 °م (أحر الشهور) + نسيب قادم من المحيط الأطلسي.
- **الشتاء (يناير):** ~12 °م (أبرد الشهور) + أمطار غزيرة (~560 مم سنويًّا — أكتوبر–أبريل) + أحيانًا رياح/هبوب.
- 🟢 **ربط الجغرافيا بالثقافة:** الساحل الأطلسي صاغ **المطبخ المتوسطي** (زيت الزيتون/زيت الأركان/الكسكس/الطاجين/السمن + الحلويات) + **اللباس الجلابة/القفطان/التكشيتة/الطربوش/البلغة** (هوية مغربية مميزة) + **العمارة الموحدية/الأندلسية** (صومعة حسان/قصبة الأوداية/شالة) + **أتاي** (شاي النعناع — تراث يونسكو 2024).

## الأحياء (قائمة كاملة)

> **عمالة الرباط** (جهة الرباط سلا زمور) تنقسم إداريًّا إلى **6 ملامات** (التقسيم الإداري 2015) 🟢، كل ملامة تتكون من أحياء.

### الملامات الستة 🟢
1. **حسان** (شمال غرب — قصبة الأوداية + صومعة حسان + حي حسان) + 2. **أكدال–الرياض** (وسط — حي أكدال + حي الرياض + القصر الملكي + الوزارات + المطار) + 3. **يعقوب المنصور** (وسط شرق — حي يعقوب المنصور + حي العكاري) + 4. **اليوسفية** (شرق — التقدم + اليوسفية + سيدي خليفة + مابيلا + الطيران + العسكري + حي النهضة) + 5. **السويسي** (شمال غرب) + 6. **التواركة** (جنوب شرق — الجزء الجنوبي من القلب).

### الأحياء البارزة 🟢🟡
- **حي حسان** (صومعة حسان + ضريح محمد الخامس + المدينة العتيقة + حي الأطلسي + حي الليمون) + **حي أكدال** (مركز الإدارة + الوزارات + المطار) + **حي الرياض** (راقٍ + تجاري + أكبر أحياء الرباط) + **حي يعقوب المنصور** (وسط — كثافة سكانية) + **حي اليوسفية** (شرق) + **حي التواركة** (جنوب شرق).
- **أحياء فرعية:** حي التقدم + حي سيدي خليفة + حي مابيلا + حي الطيران + حي العسكري + حي النهضة (ضمن اليوسفية) + حي الأطلسي + حي الليمون (ضمن حسان).

### مناطق/أحياء أخرى 🟢🟡
- **المدينة العتيقة** (القصبة/الأسواق العتيقة/المسجده/الحدائق) + **باب الوداية** (1195 — باب تاريخي لقصبة الأوداية) + **المسرح الكبير** (مسرح على نهر أبي رقراق ~7000 شخص) + **شالة** (آثار رومانية/فينيقية/مرابطية/موحدية) + **شاطئ الرباط/شاطئ سلا** (شواطئ) + **حي العرفان/حي المستشفي** (ضمن أكدال-الرياض) + **حي الصارة** + **حي السويسي** + **حي المحيط**.

- **المدينة العتيقة:** نسيج تاريخي (قصبة + أسواق + منازل + مسجده).
- 🟠 **الحارات الفرعية:** تسميات/أزقة/محلات تاريخية — يتطلب ميدانيًّا (المرحلة السادسة).

## الأسواق والمعالم والمساجد والقصور والمتاحف والجامعات

### الأسواق 🟢

- **الأسواق الحديثة (المولات):** مول الرباط + ميجا مول + مارجا مول + أكدال ستري + ساحة الحسين.

### المساجد والقصور والقلاع 🟢

- **مسجد الحسن الثاني** (الدار البيضاء — 1930+؛ طراز علوي/مراكشي؛ مدرسة قرآنية + مكتبة + متحف) 🟢.
- **مسجد السنة** (ضمن حسان — جامع/مسجد السنة).
- **مسجد الجمعة** (المدينة العتيقة).
- **القصبات:** قصبة الأوداية (القرن 12 — قلعة حصينة) + قصبة الأشراف (فاس) + قصبة تامكوشت/أيت بن حدو (أمازيغية — تراث يونسكو) 🟢.
- **قصر الوداية/قصر الملكي:** قصر الوداية (القرن 12) + القصر الملكي (الملكية) + قصر البديع (مراكش) + قصر مولاي إسماعيل (مكناس).
- **قلاع:** قلعة الرباط/ضريح محمد الخامس (ضريح الملك محمد الخامس وولديه — 1909–1961) + قلعة الشوافة.

### المتاحف 🟢

### معالم أخرى 🟢🟠

## القرى والمدن التابعة إن وجدت 🟡

> الرباط عاصمة **عمالة الرباط سلا زمور** (جهة واحدة) 🟢، محاطة بعمالة جبل لبنان (بعبدا) + عمالة طنجة (شمال). من مدن/بلدات الجهة المتاخمة:

- **تمارة** (شمال — ضاحية) + **هرهورة** (شمال شرق) + **أقدال** (شرق) + **الصال** (جنوب شرق) + **مولاي إدريس** (جنوب شرق) + **الخامسات** (جنوب) + **حد كورت** (جنوب غرب — واحات).
- **التجمع الحضري:** الرباط–سلا–تمارة (المترو) + الرباط–الدار البيضاء (البراق 2018) — ربط مع المغرب.

## خاتمة

الرباط = **عاصمة المملكة المغربية** + **رباط الفتح** (يعقوب المنصور الموحدي 1198) + **من أعرق المدن المغربية** (الرباط/فاس/مراكش/مكناس) + **موقع تراث يونسكو العالمي 2012** + عاصمة جهة الرباط–سلا–زمور الإدارية. على مصب **نهر أبي رقراق** في المحيط الأطلسي مقابل **سلا**، صاغت **مطبخها المتوسطي** (الكسكس/الطاجين + زيت الأركان + البهارات) و**لباسها المغربي المميز** (الجلابة/القفطان/التكشيتة/الطربوش) و**عمارتها** (صومعة حسان/قصبة الأوداية/شالة — تراث يونسكو) و**أتايها** (تراث يونسكو 2024). تاريخها الممتد: صلا كولونيا الرومانية ← المرابطون (القرن 12 — حصن) ← الموحدون (1195 — يعقوب المنصور يبني الأسوار + صومعة حسان + قصبة الأوداية + يودعها عاصمة) ← المرينيون ← السعديون (قوراصنة سلا) ← العلويون (قفطان/البلغة/القصبات) ← الإنتداب الفرنسي (1912 — مركز المقيم) ← استقلال 1956 (الرباط عاصمة) ← تراث يونسكو 2012. معالمها: **صومعة حسان** (44م؛ غير مكتملة — رمز الرباط) + **مسجد الحسن الثاني** (الدار البيضاء) + **قصبة الأوداية** + **باب الوداية** + **موقع شالة** + **المدينة العتيقة** + **ضريح محمد الخامس** + **حدائق الأندلسية** + **المتحف الوطني/الوداية/الفن الإسلامي** + **جامعة محمد الخامس 1957** + **المطار/الترامواي/الخط السريع**. أحياؤها: 6 ملامات (حسان/أكدال–الرياض/يعقوب المنصور/اليوسفية/السويسي/التواركة) + أحياء فرعية. اللهجة: الرباطية (قاف همزة + إيقاع غنائي + مفردات فرنسية + ثنائية لغوية). الطعام + اللباس + العادات: (انظر ملفات المغرب — الكسكس/الطاجين/الجلابة/القفطان/أتاي/رأس الحانوت). محافظة الرباط سلا زمور: تمارة + هرهورة + أكدال + الصال + مولاي إدريس + الخامسات + حد كورت. الرباط عاصمة تُوثَّق قضية الصحراء بحياد تامًّا دون تبني موقف — والتراث العالمي (يونسكو 2012) مرصود.
