## الهوية

- **الاسم الرسمي:** مدينة طرابلس (Tripoli / Ṭarābulus) | **الاسم المحلي:** طرابلس | **الأسماء التاريخية:** أويا (Oea — الفينيقيون) + إيكوسيم (الرومان) + طرابلس الشام (لتمييز عن طرابلس لبنان) | **الأسماء الأمازيغية:** ⵟⵔⴰⴱⵍⴻⵙ | **الأسماء الشعبية:** عروس البحر المتوسط + المدينة البيضاء + المحروسة.
- **سبب التسمية:** «أويا» الفينيقية 🟢؛ أو «طرابلس الغرب» للتمييز عن «طرابلس الشام» (لبنان) 🟢؛ أو نسبة إلى ثلاث مدن فينيقية (تريبوليتانيا) 🟠 — روايات متعددة.
- **الموقع:** شمال غرب ليبيا — على رأس صخري مطل على البحر المتوسط، يصوّر خليجا 🟢 | **الإحداثيات:** 32.8752°N, 13.1875°E 🟢🟡 | **الارتفاع:** ~81 م (ساحل منخفض) 🟡 | **المساحة:** ~400–1,507 كم² 🟡.
- **السكان (إحصاء2021):** المدينة ~1,183,000 🟡 | الكثافة عالية | **«طرابلس الكبرى» (المترو):** ~1.3 مليون (تقديرات — أكبر مدن ليبيا) 🟠.
- **اللقب:** العاصمة السياسية والإدارية والاقتصادية والثقافية 🟢 | **أكبر موانئ ليبيا** + **مركز الإعلام والتجاري/الصناعي** + **مقر الحكم**.
- **تاريخ التأسيس:** القرن 7 ق.م (أويا — الفينيقيون) 🟢؛ والجذور أقدم + تأثير روماني/عثماني/إيطالي/بريطاني.

## سبب اختيارها عاصمة + تاريخها

### سبب الإختيار 🟢
- **الموقع الساحلي الإستراتيجي:** على رأس صخري مطل على البحر المتوسط — مركز تجاري/دفاعي + ميناء (ميناء طرابلس) + ربط بين الشام (شرق) والداخل الأفريقي (جنوب).
- **التاريخ العريق:** >2,500 سنة (أويا الفينيقية) + طرابلس الشام (تمييز عن لبنان) + الإحتلال الإيطالي/البريطاني + الإستقلال (1951).
- **المركزية الحديثة:** مركز نفطي/تجاري/صناعي/إعلامي + مركز حكم + جامعة.

### التاريخ 🟢🟡🟠
- **التاريخ القديم (أويا — القرن 7 ق.م):** الفينيقيون ← الرومان (146 ق.م — ترايبوليتانيا) ← البيزنطيون ← الوندال ← البرتغاليون.
- **الفترة الإسلامية (643–1510 م):** الفتح الإسلامي (643 — عمرو بن العاص) ← الأمويون ← العباسيون.
- **العثمانيون (1551–1911 م):** «ولاية طرابلس» ← قصبات/أسوار/مساجد + مركز إداري + تجاري.
- **الإحتلال الإيطالي (1911–1943 م):** طرابلس عاصمة الإقليم الإستعماري + عمارة كولونيالية + بنية تحتية.
- **الإحتلال البريطاني/الحلفاء (1943–1951 م):** إدارة بريطانية + قتال ضد الإيطاليين.
- **الإستقلال (24 ديسمبر 1951):** الملك إدريس السنوسي + طرابلس عاصمة المملكة الليبية المتحدة.
- **الإنقلاب (1 سبتمبر 1969):** القذافي → إنهاء الحكم الملكي + الجمهورية.
- **الإنقلاب (1 سبتمبر 1969):** القذافي يتولى الحكم → إنهاء الملكية + الجمهورية.
- 🟠 **الوضع الحالي:** طرابلس عاصمة + الإستقرار السياسي (إنقسام/حكومات متعددة + تقلبات) + الحرب (2011–) + الإحتلالات الأجنبية — تُتناول بحياد.

## الجغرافيا والتضاريس

### الموقع 🟢
- **شمال غرب ليبيا** على رأس صخري مطل على البحر المتوسط — يصوّر **خليجا** (خليج طرابلس) 🟢.
- **الشكل:** رأس صخري + خليج طبيعي (ميناء).
- **الموقع الإستراتيجي:** على مفترق الطرق بين الشام (شرق) والداخل الأفريقي (جنوب) + ميناء/تجاري/دفاعي.

### المناخ 🟢🟡
- **متوسطي (Csa — كوب):** صيف حار جاف + شتاء معتدل ممطر (~125 مم — نوفمبر–مارس) + رياح صحراوية.
- **الصيف (يوليو–أغسطس):** ~30 °م + جاف.
- **الشتاء (يناير):** ~10–15 °م + أحيانًا ثلوج/برد.

## خاتمة

طرابلس = **عاصمة دولة ليبيا** + **أكبر مدن ليبيا** + **عروس البحر المتوسط** + **المدينة البيضاء** (للعمارة الحجرية البيضاء) + **مركز الإعلام والتجاري/الصناعي** + **مقر الحكم**. على رأس صخري مطل على البحر المتوسط، صاغت **المطبخ الليبي** (البازين/الكسكسي/العصيدة/المبطن — الجنوب/الغرب) و**اللباس الليبي** (الجرد — أعرق أزياء العالم) و**المالوف** (موسيقى أندلسية-صوفية). تاريخها الممتد: أويا الفينيقية (القرن 7 ق.م) ← الرومان (146 ق.م — ترايبوليتانيا/قوس ماركوس أوريليوس) ← الفتح الإسلامي (643) ← الأمويون/العباسيون ← العثمانيون (قصبات/أسوار) ← الإحتلال الإيطالي (1911) ← الإحتلال البريطاني (1943) ← الإستقلال (1951) ← الإنقلاب (1969) ← الحرب (2011–). معالمها: **المدينة القديمة** (الساحة الشهداء + الأسواق) + **القصر الأحمر** (سرايا الحمراء — القرن 7 + متحف ليبيا الوطني 1919) + **قوس ماركوس أوريليوس** (163م — روماني) + **جامع الناقة** (أقدم مسجد — القرن 4هـ/10م) + **الجامعات** (طرابلس 1957 + المرقب + المفتوحة +...) + **المطار الدولي** + **ميناء طرابلس** + **الشوارع** (ميزران/24 ديسمبر/17 فبراير/الاستقلال/الرشيد/عمر المختار). أحياؤها: المدينة القديمة + ميزران + الظهرة + سوق التلاث + زايوية الدهماني + السواني + شارع 17 فبراير + شارع الاستقلال + العمارة (القصر الأحمر + صبراتة + قورية + غدامس + لبدة). اللهجة: الطرابلسية (حلقة وصل بين المشرق والمغرب + 4 لهجات جهوية + مفردات إيطالية). الطعام + اللباس + العادات: (انظر ملفات ليبيا — البازين/الكسكسي/العصيدة + الجرد/الفرملة/الشاشية + المالوف/الزوايا الصوفية + الأعراس/المناسبات + العمارة/الحرف). شعبية طرابلس (10 شعبيات) + 22 شعبية. لا تعداد رسمي منتشر — الأرقام تباينة وتُذكر بحصر 🟠، والأرقام اللاحقة موصونة بـ🟠.
