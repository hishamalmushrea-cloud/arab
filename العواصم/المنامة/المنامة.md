- **الموقع:** شمال شرق البحرين — على ساحل خليج البحرين (خليج البحرين) في الجزء الشمالي الشرقي من الجزيرة، مقابل الساحل الإيراني 🟢 | **الإحداثيات:** 26.2235°N, 50.5876°E 🟢🟡 | **الارتفاع:** ~7 م (ساحل منخفض) 🟡 | **المساحة:** ~78.6 كم² (محافظة المنامة) 🟡.

- **تاريخ التأسيس:** القرن 18 م (المنامة/أوال) 🟢؛ والجذور أقدم + تأثير خليجي/هندي/فارسي/عراقي.

## سبب اختيارها عاصمة + تاريخها

### سبب الإختيار 🟢
- **الموقع الساحلي الإستراتيجي:** على ساحل خليج البحرين — مركز تجاري/دفاعي + ربط بين الأحياء (المنامة/سترة) والضواحي (المحرق + الجفير + النعيم + السلمانية).
- **التاريخ العريق:** المنامة/أوال (تجارة بحرية قديمة) + الؤلؤ/الفجري (يونسكو 2012) + استثمار بريطاني + الإستقلال (1971).
- **النفط:** الإكتشاف (1932) + إعادة البل + البحرين الحديثة (تنويع/تقنية/سياحة).
- **المركزية الحديثة:** عاصمة + مركز مال + مطار + المطار.

### التاريخ 🟢🟡🟠
- **قبل القرن 18:** سكان قديم (تجارة بحرية) + آثار (اللؤلؤ/الفجري — قبل النفط.
- **القرن 18 (المنامة/أوال):** المنامة القديمة ← مركز تجاري/دفاعي.
- **الإحتلال البريطاني (1820–1971 م):** معاهد + حلفاء (إدارة بريطانية).
- **الإستقلال (15 أغسطس 1971):** المنامة عاصمة مملكة البحرين (الإمارات السبع — البحرين + السعودية + قطر + الإمارات + عُمان + الكويت).
- **النفط (1932):** الإكتشاف → الإستثمار + مركز نفط.
- 🟠 **الوضع الحالي:** عاصمة + إعادة البل + البحرين الحديثة (تنويع/تقنية/سياحة) + تقلبات (2011: احتجات بـ«ربيع فبراير» + 2011: احتجات بـ«دوار اللؤلؤ»).

## الجغرافيا والتضاريس

### الموقع 🟢
- **شمال شرق البحرين** على ساحل خليج البحرين في الجزء الشمالي الشرقي من الجزيرة، مقابل الساحل الإيراني.
- **الشكل:** جزيرة/ساحل منخفض (ارتفاع 0–7م) + جزر مجتمعة (أمواج/الصخير).
- **الموقع الإستراتيجي:** مركز تجاري/دفاعي + ربط بين الأحياء والضواحي.

### المناخ 🟢🟡
- **صحراوي حار رطب (Cfa — كوب):** صيف طويل حار رطب جدًّا (يونيو–أغسطس ~40+ °م) + رياح شمالية/شمالية غربية رطبة + ماطر قليلة (نوفمبر–مارس).
- **الشتاء (ديسمبر–فبراير):** معتدل (~14 °م) + أحيانًا برد.

## الأحياء (قائمة كاملة)

> **محافظة المنامة** تنقسم إداريًّا إلى **4 محافظات** (التقسيم الإداري 2014) 🟢، كل محافظة تتكون من دوائر/أحياء.

### المحافظات الأربع 🟢
1. **العاصمة** (المنامة + سترة + البلاد القديم) + 2. **المحرق** (شمال) + 3. **الشمالية** (الدراز + باربار + بني جمرة) + 4. **الجنوبية** (الرفاع + عوالي + الزلاق + صدد + مقابة + جزر حوار).

### الأحياء البارزة 🟢🟡
- **المنامة القديمة:** المنامة العتيقة (أسواق + بيوت تاريخية + المدينة القديمة + المسجد الجامع) + **الساحة** (ساحة المركز) + **الدبلوماسية** (ساحة المنامة الدبلوماسية).
- **المحرق:** المحرق القديمة + ساحة المحرق + الحد + السماهيج.
- **الشمالية:** الشمالية القديمة + ساحة الشمالية + بني جمرة + الدراز.
- **الجنوبية:** الرفاع القديم + عوالي + الزلاق + صدد + مقابة + جزر حوار.

## خاتمة

المنامة = **عاصمة مملكة البحرين** + **أكبر مدن البحرين بالسكان** + **مركز المال والأعمال** + **مقر حكم آل خليفة**. على ساحل خليج البحرين في الجزء الشمالي الشرقي من الجزيرة، صاغت **المطبخ البحريني** (المجبوس — الطبق الوطني) و**اللباس البحريني** (الثوب — الدشداشة، فريد عن باقي الخليج) و**الفجري** (اللؤلؤ/الفجري — روح التراث الغوص) و**العيالة** (الرقصة الوطنية) و**القهوة العربية** (الضيافة). تاريخها: المنامة/أوال (القرن 18 — مركز تجاري/دفاعي) ← الإحتلال البريطاني ← الإستقلال (1971) ← النفط (1932) ← إعادة البل. معالمها: القلعة البراحة (يونسكو 2019 — تراث عالمي) + المساجد + القصور + المتاحف + المطار + الجامعات. أحياؤها: محافظة المنامة (4 محافظ: العاصمة + المحرق + الشمالية + الجنوبية) + جزر + ضواحي. اللهجة: البحرينية (تباينات داخلية بارزة + 5 لهجات جهوية) + مفردات فارسي/هندي/عراقي + مفردات إنجليزية حديثة. الطعام + اللباس + العادات: (انظر ملفات البحرين — المجبوس/الهريس/الثريد/اللقيمات + الثوب/الغترة/العقال/الدقلة/المشلح/البرقع + الفجري/العيالة/الأعراس + القهوة/شاي الكرك + المحشي/السالونة/البرياني/الصالونة + العوال/القاشع). محافظة المنامة (4 محافظات) + 3 محافظات + جزر. لا تعداد رسمي بعد 2024 — الأرقام تباينة وتُذكر بحصر 🟠، والأرقام اللاحقة موصونة بـ🟠.
