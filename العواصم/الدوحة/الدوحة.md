# الدوحة — عاصمة دولة قطر

> 🟢🟡🟠 (مصادر: ويكيبيديا العربية + ويكيبيديا الإنجليزية (Doha) + المعرفة + qatarshares + doha24 + lahajat + alsom3a + الجزيرة + almintaqa + mawdoo3 + 2thar + claudeabouchacra). علامات الثقة: 🟢 موثَّق / 🟡 اختلاف بين المصادر / 🟠 حصر (الإقليم البريطاني + التوسعات الإقليمية + قضية الحساسة). كل رقم مقرون بسنة.
>
> 🟠 **تنبيه (الحياد):** قطر متأثرة بالإقليم البريطاني (1868–1916) + التوسعات الإقليمية على الجزر + دولة محمية (1971–1971) + إعلان الاستقلال (3 سبتمبر 1971) + النفط (1939) + رؤية 2030 (كأس العالم 2022) + المركزية الحديثة (التلوي + السياحة + الإعلام + التنويع). يلتزم الملف بالحياد التام في تناول الدوحة بذاتها (هوية/تاريخية/معالم/أحياء) دون تبني موقف في النزاع. الأرقام السكانية تباينة وتُذكر بحصر، والأرقام اللاحقة موصونة بـ🟠.

## الهوية

- **الاسم الرسمي:** مدينة الدوحة (Doha / Ad-Dawḥa) | **الاسم المحلي:** الدوحة | **الأسماء التاريخية:** الدوحة/البدع (نسبة إلى «الدوحة البدع» للتمييز عن «الدوحة العتيقة») | **الأسماء الشعبية:** عاصمة قطر + نصف سكان قطر.
- **سبب التسمية:** «الدوحة» = الخليج/الخليج الصغير (نسبة لموقعها على خليج صغير) 🟢 — روايات متعددة.
- **الموقع:** شرق قطر — على ساحل خليج قطر (الخليج العربي) في منتصف شبه الجزيرة، مقابل جزيرة البحرين 🟢 | **الإحداثيات:** 25.2854°N, 51.5310°E 🟢🟡 | **الارتفاع:** ~11 م (ساحل منخفض) 🟡 | **المساحة:** ~132 كم² (المدينة) / 234 كم² (البلدية) 🟡.
- **السكان (إحصاء2015):** المدينة ~956,457 🟡 | الكثافة عالية | **الدوحة الكبرى (المترو):** ~2.4 مليون (تقديرات — ثاني أكبر مدن قطر + نصف سكان قطر) 🟠.
- **اللقب:** العاصمة السياسية والإدارية 🟢 | **أكبر بلدية قطر بالسكان** + **مركز النفط + المال/الأعمال** + **مركز الإعلام/التعليم/السياحة** + **مقر حكم آل ثاني**.
- **تاريخ التأسيس:** القرن 19 م (البدع/الدوحة) 🟢؛ والجذور أقدم (تجارة بحرية) + تأثير بريطاني/هندي/فارسي.

## سبب اختيارها عاصمة + تاريخها

### سبب الإختيار 🟢
- **الموقع الساحلي الإستراتيجي:** على ساحل خليج قطر في منتصف شبه الجزيرة — مركز تجاري/دفاعي + ميناء (ميناء الدوحة) + ربط بين الداخل (الريان/الشحانية) والخارج (الخور).
- **التاريخ العريق:** السكان القدماء (تجارة بحرية) + الدولة العثمانية + الإقليم البريطاني + الإستقلال (1971).
- **النفط:** اكتشاف النفط (1939) + الإستثمار الأجنبي + الثروة النفطية (نفط + رؤية حكومية).
- **المركزية الحديثة:** عاصمة + مركز النفط + المال/الأعمال + الإعلام/التعليم + التنويع/السياحة + المركزية الإقليمية.

### التاريخ 🟢🟡🟠
- **قبل الإسلام:** سكان القدماء (تجارة بحرية) + دولة العثمانية.
- **القرن 19 (البدع):** الدوحة العتيقة ← مركز تجاري/دفاعي.
- **الإقليم البريطاني (1868–1916):** عاصمة المقيم + القواعد البريطانية + توطين.
- **الدولة القطرية (1916–1971):** حماية بريطانية.
- **الإستقلال (3 سبتمبر 1971):** الدوحة عاصمة دولة قطر (الإمارات السبع — قطر + أبوظبي + الشارقة + عجمان + أم القيوين + رأس الخيمة + الفجيرة).
- **النفط (1939):** اكتشاف النفط → الإستثمار الأجنبي + الثروة النفطية.
- 🟠 **الوضع الحالي:** عاصمة + مركز نفط/مال + رؤية 2030 + المركزية الإقليمية + تنويع/سياحة + تقلبات إقليمية.

## الجغرافيا والتضاريس

### الموقع 🟢
- **شرق قطر** على ساحل خليج قطر في منتصف شبه الجزيرة، مقابل جزيرة البحرين.
- **الشكل:** ساحل منخفض يرتفع نحو الداخل (ارتفاع 0–11م).
- **الموقع الإستراتيجي:** مركز تجاري/دفاعي + ميناء — حلقة وصل بين الداخل (شرق) والخارج (غرب).

### المناخ 🟢🟡
- **صحراوي حار (BWh):** صيف طويل جاف حار جدًّا (يونيو–أغسطس ~45+ °م) + رياح رطبة.
- **الشتاء (ديسمبر–فبراير):** معتدل (~18 °م) + أحيانًا برد/ضباب.

## الأحياء (قائمة كاملة)

> **بلدية الدوحة** تنقسم إداريًّا إلى **7 مناطق** (التقسيم الإداري 2014) 🟢، كل منطقة تتكون من أحياء.

### المناطق السبع 🟢
1. **الدوحة** (المركز الإداري) + 2. **الريان** (غرب) + 3. **الوكرة** (جنوب) + 4. **الشحانية** (شمال غرب) + 5. **الخور** (شمال) + 6. **الأشحانية** (شمال غرب) + 7. **الوعب** (جنوب شرق).

### الأحياء البارزة 🟢🟡
- **الدوحة العتيقة:** الدوحة القديمة + الكورنيش + ساحة الجامعة + السوق القديم + حي الوكرة.
- **الريان:** الريان القديمة + الريان الجديدة + ضواحي (أبوظبي/الشحانية).
- **الوكرة:** الوكرة القديمة + سوق الوكرة + الخور.
- **الشحانية:** الشحانية القديمة + ساحة الشحانية.
- **الخور:** الخور القديم + الخور الغربي + الخور الشرقي.
- **الأشحانية:** الأشحانية + الأشحانية الجنوبية + الوعب.
- **الوعب:** الوعب القديم + حي الوعب الجديد + الوعب الصناعي + الوعب الشرقي + سوق الوعب.

## خاتمة

الدوحة = **عاصمة دولة قطر** + **أكبر بلدية قطر بالسكان** + **مركز النفط** + **المال/الأعمال** + **مركز الإعلام/التعليم/السياحة** + **مقر حكم آل ثاني**. على ساحل خليج قطر في منتصف شبه الجزيرة، صاغت **المطبخ القطري** (المجبوس — الطبق الوطني) و**اللباس القطري** (الثوب — النجدي-البدوي) و**العيالة** (الرقصة الوطنية) و**القهوة القطرية** (الضيافة). تاريخها: السكان القدماء (تجارة بحرية) ← الدولة العثمانية ← الإقليم البريطاني ← الإستقلال (1971) ← النفط (1939) ← رؤية 2030. معالمها: الزبارة (يونسكو 2013 — تراث عالمي) + قلعة الزبارة + برج الزبارة + سوق واقف + المطار + المدينة التعليمية + حي كتارا + لوسيل + اللؤلؤة + أبراج الدوحة. أحياؤها: 7 مناطق (الدوحة + الريان + الوكرة + الشحانية + الخور + الأشحانية + الوعب) + ضواحي. اللهجة: الحضرية (قاف همزة) + البدوية (أقرب للفصحى) + الخدمونية (نبرة خاصة). الطعام + اللباس + العادات: (انظر ملفات قطر — المجبوس/الهريس/الثريد + الثوب/الغترة/العقال/البشت/الدقلة/المشلح + المضروبة/المموش/الجشيد + العيالة/المجالس/الأعراس + القهوة/شاي الكرك). بلدية الدوحة (7 مناطق) + 6 إمارات. الأرقام تباينة وتُذكر بحصر 🟠، والأرقام اللاحقة موصونة بـ🟠.
