## الهوية

- **الاسم الرسمي:** بغداد (Baghdad) | **الاسم المحلي:** بغداد عموم | **الأسماء التاريخية:** مدينة السلام + مدينة المنصور + الزوراء + المدورة | **الأسماء الشعبية:** دار السلام + عاصمة الرشيد.
- **الموقع:** وسط العراق — على ضفتي نهر دجلة 🟢 | **الإحداثيات:** 33.31°N, 44.36°E 🟢 | **الارتفاع:** 34 م 🟢 | **المساحة (الولاية):** ~4,555 كم² (مدينة بغداد: ~204 كم² — النطاق الحضري) 🟡 | **السكان:** ~7–8.8 مليون نسمة (تقديرات 2024–2025 متباينة بسبب الحروب) 🟡🟠.
- **اللقب:** دار السلام + الزوراء + عاصمة العالم الإسلامي 🟢 | **تاريخ التأسيس:** 762 م (145 هـ — الخليفة العباسي أبو جعفر المنصور) 🟢 | **عاصمة لـ:** العراق + محافظة بغداد.
- **ثاني أكبر مدينة عربية** (بعد القاهرة) + ثاني أكبر مدينة في غرب آسيا (بعد طهران).

## سبب اختيارها عاصمة + تاريخها

### سبب الإختيار 🟢
- **الموقع الإستراتيجي:** وسط العراق + على نهر دجلة — حلقة وصل بين الشرق (فارس) والغرب (الشام) + بين الشمال (خراسان) والجنوب (الحجاز/عُمان).
- **وفرة المياه:** نهر دجلة + قنوات للري + أراضي صالحة للزراعة + سهل فياضي خصب.
- **أهمية عسكرية + تجارية:** موقع دفاع طبيعي (النهر) + مركز تجاري (طرق الحرير) + معبر للجيوش + سهولة الملاحة.
- **البُعد عن مناطق الصراع:** بعيدة عن الكوفة (الصراعات القبلية) + عن دمشق (الأموية) + عن الحجاز (قليلة الموارد).
- **موقع وسطي:** بين أقاليم الإمبراطورية الشرقية والغربية — يسهل الحكم + التجارة + الاتصالات.

### التاريخ 🟢🟠
- **ما قبل 762:** قرى بابلية + سونيا الآرامية + الخطابية + شرفانية + بناورا (قرى مأهولة) + موقع استيطان بشري منذ العصر الحجري.
- **762 (145 هـ):** تأسست على يد **أبي جعفر المنصور** (الخليفة العباسي الثاني) → سماها «مدينة السلام» + بناها **مدينة مدورة** (أسوار مركزية + 4 أبواب + قصر الخلافة + المسجد الجامع في المركز).
- **763–766:** إكمال البناء + إستقرار العباسيين + إتساع سريع.
- **786–809 (هارون الرشيد):** قمة الازدهار + **دار الحكمة** (الترجمة + العلوم) + أكبر مدينة في العالم (~1 مليون) + توسع شرقًا (الرصافة) + غربًا (الكرخ).
- **809–814 (الأمين):** وفاة الرشيد + البيعة للأمين في طوس ثم بغداد.
- **814–833 (المأمون):** قتل الأمين + البيعة للمأمون + إزدهار العلوم (بيت الحكمة).
- **836–892:** انتقال العاصمة إلى **سامراء** (أيام المعتصم + المتوكل).
- **892–1258:** عودة العاصمة إلى بغداد (المعتضد) + تراجع + غزوات البويهيين + السلاجقة + تراجع.
- **1258 (656 هـ):** **سقوط بغداد** على يد **هولاكو المغولي** + مذبحة (~800,000–1 مليون) + تدمير + فرار السكان (~100,000–200,000) → تدهور قرون.
- **1258–1534:** الإيلخانيون + تدهور + تراجع ديموغرافي.
- **1534:** العثمانيون يسيطرون على بغداد.
- **1638+:** سيطرة المتلك (المناطق الكردية) + الحكم المحلي.
- **1917:** الإحتلال البريطاني (الحرب العالمية الأولى).
- **1920:** عاصمة الانتداب البريطاني (العراق).
- **1921:** المملكة العراقية (فيصل الأول).
- **1932:** استقلال + بغداد عاصمة المملكة.
- **1958:** الجمهورية العراقية (انقلاب) + بغداد عاصمة الجمهورية.
- **1979–2003:** حكم البعث (صدام حسين) + حروب (إيران + الكويت) + الحصار + التدمير.
- **2003 (9 أبريل):** الغزو الأميركي + سقوط صدام + الإحتلال + الفوضى + التدمير + المليشيات + الطائفية.
- **2003–2011:** العنف الطائفي + التدمير + التهجير + إعادة بناء بطيئة.
- **2011–2014:** الإنسحاب الأميركي + إعادة بناء.
- **2014–2017:** داعش + التدمير + تحرير المدن.
- **2017–الآن:** إعادة بناء + تحسن أمني + تقلبات.
- 🟠 **الوضع الحالي:** إعادة بناء + تقلبات سياسية + أمنية + إقتصادية.

## الجغرافيا والتضاريس

### الموقع 🟢
- **على نهر دجلة:** وسط العراق + سهل فياضي خصب (ترسبات النهر) + النهر يخترق المدينة إلى شطرين: **الكرخ** (غرب) + **الرصافة** (شرق).
- **نهر ديالى:** رافد لنهر دجلة جنوب شرق المدينة + يحد الأحياء الشرقية.
- **الصورة الطوبوغرافية:** سهل مسطح منخفض (34 م) + أراضي فياضية + قنوات.

### المناخ 🟢
- **حار جدًّا صيفًا** (>45°م — مايو–سبتمبر) + **معتدل شتاءً** (5–15°م — نوفمبر–مارس) + أمطار قليلة (<150 مم) + رطب نسبي.
- **رياح:** شمالية غربية + شمالية شرقية + غبار + عواصف رملية أحيانًا.

### التضاريس 🟢
- **سهل فياضي مسطح** + **نهر دجلة** = العصب + **لا جبال** (أنخفض نقطة 34 م) + **قنوات**.
- **الجسور:** جسر الأعظمية + جسر الصرافية + جسر باب المعظم + جسر الشهداء + جسر الجمهورية + جسر الأحرار + جسر السنك + جسر الجادرية + جسر 14 تموز + جسر الأئمة + جسر ديالى + جسر ذو الطابقين (13 جسر رئيسي + أخرى).

## خاتمة

بغداد = **دار السلام + الزوراء + عاصمة العالم الإسلامي** — تأسست 762 م (أبو جعفر المنصور — العباسيون) + شهدت قمة الازدهار في عهد الرشيد + دار الحكمة (مركز العلوم) + صارت أكبر مدينة في العالم (~1 مليون) + **سقوطها 1258** (هولاكو المغولي) → تدهور قرون → العثمانيون → البريطانيون → استقلال 1932 → حكم البعث → الغزو 2003 → داعش 2014 → إعادة بناء. **النهر يخترق المدينة** إلى **الكرخ** (غرب) + **الرصافة** (شرق) — تاريخي + إجتماعي + إقتصادي. معالمها: شارع الرشيد + ساحة التحرير + جامع الإمام الأعظم + قصر العباسي + المدرسة المستنصرية + متحف العراقي + جامعة بغداد + القصر الجمهوري. أحياءها: الأعظمية + الكاظمية + الحرية + المنصور + الكرادة + الشعب + مدينة الصدر + العطيفية + الوزيرية + كمب سارة + الحسينية + زيونة + حي الغدير. اللهجة: البغدادية (عربية عراقية). الطعام + الملابس + العادات: (انظر ملفات العراق). القرى التابعة: >50 قرية + مدن (أبو غريب + المحمدية + المدائن... — تُفصَّل في المرحلة السادسة).
