## الهوية

- **الاسم الرسمي:** مدينة بيروت (Beirut) | **الاسم المحلي:** بيروت | **الأسماء التاريخية:** بيروتا (تل العمارنة) + بيريت + بيروتوس (Berytus) + بيريتيس + بيرووه + لاذقية كنعان + جوليا أغسطس بيروتوس السعيدة + رديدون + باروت + دربي | **الأسماء الشعبية:** زهرة الشرق + باريس الشرق الأوسط + الدرة الغالية + المدينة الإلهة + بيروت الأبية المجيدة.
- **سبب التسمية:** «بيروتا» الفينيقية = «الآبار» (لمياه الجوفية) 🟢؛ أو «بيريت» نسبة إلى آلهة بيروت (صاحبة أدونيس إله جبيل) 🟢؛ أو «الصنوبر» بالسامية (لقربها من غابات الصنوبر — حرش بيروت) 🟢؛ أو نسبة إلى «بيرو» ابنة أدونيس وأفروديت 🟠 (روايات متعددة).
- **الموقع:** ساحل شرق البحر المتوسط — على رأس شبه جزيرة في وسط الساحل اللبناني 🟢 | **الإحداثيات:** 33.8938°N, 35.5018°E 🟢 | **الارتفاع:** ~0–200 م (ساحل منخفض يرتفع سريعًا نحو جبل لبنان) 🟡 | **المساحة:** ~19.8–21.4 كم² (المحافظة — من أصغر المحافظات مساحة) 🟡.
- **السكان (تقديرات متباينة):** المحافظة ~532,246 (تقدير) 🟡؛ الكثافة ~24,890/كم² (من أعلى الكثافات في المنطقة) 🟢؛ **بيروت الكبرى (المترو):** ~2.2–2.4 مليون (تقديرات 2020–2025 — نحو نصف سكان لبنان) 🟡🟠. (لا يوجد تعداد رسمي منذ 1932 — كل الأرقام تقديرات متباينة).
- **اللقب:** العاصمة السياسية والاقتصادية والثقافية 🟢 | **من أقدم مدن العالم مأهولةً باستمرار** (>5,000 سنة — آثار تعود للعصر الحجري النطي) 🟢 | **عاصمة الجمهورية اللبنانية** + مركز تجاري/مالي/إعلامي.
- **تاريخ التأسيس:** >5,000 سنة (الفينيقيون) 🟢؛ أول ذكر موثَّق في ألواح تل العمارنة (القرن 15 ق.م — الملك عمونيرا) 🟢.

## سبب اختيارها عاصمة + تاريخها

### سبب الإختيار 🟢
- **الموقع الساحلي الاستراتيجي:** ميناء طبيعي على وسط الساحل اللبناني — حلقة وصل تجارية بين الشرق والغرب (الفينيقيون → المتوسط).
- **التنوع الطائفي:** بيروت المدينة الأكثر تنوعًا دينيًّا في الشرق الأوسط (18 طائفة) — رمز الهوية اللبنانية المشتركة.
- **المركزية الجغرافية:** في وسط الساحل اللبناني بين الشمال (طرابلس) والجنوب (صيدا/صور) وجبل لبنان والبقاع.
- **التاريخ العريق:** >5,000 سنة من الإستمرار الحضري + «أم الشرائع» الرومانية (مدرسة الحقوق).
- **التطور الحديث:** مركز تجاري/مالي/إعلامي/سياحي — «باريس الشرق الأوسط».

### التاريخ 🟢🟠
- **العصر الحجري النطي (>5,000 سنة):** أقدم استيطان — صيد/تقاط.
- **الفينيقيون (القرن 15 ق.م — تل العمارنة):** أول ذكر موثَّق باسم «بيروتا» (= الآبار) + الملك عمونيرا + عبادة «بعل بيريت» + سك عملة 🟢.
- **الهلينستية/السلوقيةون:** تدمير ديودوتوس تريفون (140 ق.م) → إعادة بناء هلينستية → «لاذقية كنعان/في فينيقيا» 🟢.
- **الرومانية (64 ق.م):** بومبي يفتحها → ماركوس أغريبا → «جوليا أغسطس بيروتوس السعيدة» (نسبة إلى جوليا بنت أغسطس) → مستوطنة رومانية + مدرسة الحقوق («أم الشرائع») + مسارح/هياكل/حمامات 🟢.
- **551 م:** زلزال مدمر → تراجع أهميتها → صور عاصمة مقاطعة فينيقيا 🟢.
- **635 م (الفتح الإسلامي):** معاوية بن أبي سفيان يفتح بيروت في عهد عمر بن الخطاب → إعادة ترميم + بناء حصون 🟢.
- **الأمويون/العباسيون:** ازدهار + تحصين.
- **الصليبيون (1099):** احتلال + قلاع.
- **المماليك:** تحرير + عمارة.
- **العثمانيون (1516–1918):** «الدرة الغالية» + عمارة عثمانية (خانات/أسواق/مساجد/كنائس) + تطور المرفأ 🟢.
- **1860+:** توسع خارج الأسوار + قنصاليات + إرساليات (الجامعة الأمريكية 1866 + Jesuit 1875) → نهضة ثقافية.
- **1920–1943 (الإنتداب الفرنسي):** قنصالية + «باريس الشرق الأوسط» + بنية تحتية حديثة + توسع.
- **1943:** استقلال لبنان + بيروت عاصمة الجمهورية.
- **1975–1990 (الحرب الأهلية):** تقسيم بيروت (شرق مسيحي/غرب مسلم) + تدمير + نزوح + هجرة مسيحية 🟢.
- **1990–2005:** إعادة إعمار وسط بيروت (Solidere) + إغتيال الحريري 2005 🟠.
- **2006 (حرب يوليو):** تدمير في الجنوب + تأثير على بيروت.
- **2020 (4 أغسطس):** انفجار المرفأ — تدمير ضخم + ضحايا + أزمة 🟠.
- **2019–2022:** أزمة اقتصادية طاحنة + تضخم + إنهيار النظام المصرفي + هجرة 🟠.
- **2024 (سبتمبر–أكتوبر + إعادة 2025):** التصعيد العسكري + تكررت + ضربات + نزوح 🟠.
- 🟠 **الوضع الحالي:** أزمة اقتصادية مستمرة + هجرة + إعادة إعمار + تقلبات سياسية/أمنية.

## الجغرافيا والتضاريس

### الموقع 🟢
- **رأس شبه جزيرة** على وسط الساحل اللبناني الشرقي للبحر المتوسط — يحدّها البحر غربًّا ونهر بيروت شرقًّا وجبل لبنان غربًّا (ترتفع سريعًا).
- **نهر بيروت:** يخترق المدينة + يصب في البحر (مرفأ بيروت).
- **الشكل:** ساحلي منخفض → يرتفع نحو جبل لبنان (من 0 إلى ~200م سريعًا).

### المناخ 🟢🟡
- **متوسطي (Csa — كوبن):** صيف حار رطب + شتاء معتدل ماطر.
- **الصيف (يوليو/أغسطس):** ~28–32 °م + رطب (ساحلي).
- **الشتاء (يناير):** ~11–14 °م + ماطر + أحيانًا ثلوج (2015, 1992).
- **الأمطار:** ~600–800 مم سنويًّا (تباين بين المصادر) 🟡 — نوفمبر–أبريل.
- 🟢 **ربط الجغرافيا بالثقافة:** الساحل المتوسطي صاغ **الإيقاع الغنائي** للهوية اللبنانية + **المطبخ المتوسطي** (زيت زيتون/ثوم/ليمون/خضر) + **العمارة المتوسطية** (شرفات/قناطر) + **اللباس المنفتح** (تأثير فرنسي/متوسطي) + النبيذ/العرق (تأثير فينيقي/روماني للكرمة).

## الهوية والكلمات المحلية والطعام والملابس والعادات

### اللهجة 🟢
- **اللهجة البيروتية:** شامية جنوبية — **قاف تُنطق همزة مفخمة** («قال» → «ئال/أل») + إيقاع «غنائي» مميز (إرتفاع في نهايات الجمل + تمدد المقاطع) + جذور آرامية (قلب الذال زايًا + الثاء تاء + حذف «أن») 🟢.
- **«البسطاوية» (بيروت القديمة):** تكسر الفتحات («أنا» → «أني»، «باب» → «بيب») 🟡.
- **الكلمات:** (انظر `الدول/لبنان/الهجات.md`): «شو/إيه» (ماذا) + «وين» (أين) + «ليش/كيف» (لماذا) + «تعا/تعي» (تعال) + «هلّق/هلّأ» (الآن) + «بكرا» (غدًا) + «كتير» (كثير) + «شوي» (قليل) + «حلو كتير/magnifique» (جميل) + «ميرسي/مرسي» (شكرًا — فرنسية) + «أوتو» (سيارة — فرنسية) + «تقبرني» (تتطلع على قبري — محبة) + «بهداوة» (بهدوء) + «حايص» (محتار) + «زنخ» (دمه ثقيل) + «عجئة سير» (زحمة) + «برندا» (شرفة — إيطالية/فرنسية) + «كرمالك» (من أجلك) 🟢.

## خاتمة

بيروت = **عاصمة الجمهورية اللبنانية** + **زهرة الشرق + باريس الشرق الأوسط + الدرة الغالية** (تسميات عبر العصور) + **من أقدم مدن العالم مأهولةً باستمرار** (>5,000 سنة — «بيروتا» في تل العمارنة القرن 15 ق.م). **رأس شبه الجزيرة** الساحلية على البحر المتوسط صاغت **إيقاعها الغنائي** المميز + **مطبخها المتوسطي** (مازة + حمص + تبولة + فتوش + كبة + زيت زيتون + نبيذ/عرق) + **عمارتها المتوسطية** (شرفات/قناطر) + **لباسها المنفتح** (تأثير فرنسي). تاريخها الممتد: الفينيقيون (بيروتا/بعل بيريت) ← الهلينستية (لاذقية كنعان) ← الرومان (جوليا أغسطس بيروتوس السعيدة — «أم الشرائع»/مدرسة الحقوق) ← زلزال 551 ← الفتح الإسلامي 635 (معاوية) ← الأمويون/العباسيون ← الصليبيون ← المماليك ← العثمانيون («الدرة الغالية» — خانات/أسواق/مساجد الكبير 1580) ← الإنتداب الفرنسي (1920 — «باريس الشرق الأوسط») ← استقلال 1943 + بيروت عاصمة ← الحرب الأهلية 1975–1990 (تقسيم) ← إعادة إعمار (Solidere 1990) ← اغتيال الحريري 2005 ← انفجار المرفأ 2020 ← أزمة 2019 + حرب 2024. معالمها: **وسط بيروت** (ساحة الشهداء + المسجد الكبير + الأسواق + المتحف الوطني) + **كورنيش بيروت** (الروشة) + **شارع الحمراء** («شانزليزيه بيروت») + **ساحة ساسين** + **المزارعة + الرميل + المصيطبة + زقاق البلاط + الأشرفية + دار المريسة + الباشورة + رأس بيروت** (الأحياء الـ12-13) + **الجامعة الأمريكية 1866 + القديس يوسف 1875 + اللبنانية 1951** + **المتحف الوطني + المتاحف** + **المطار رفيق الحريري** + **المرفأ**. أحياؤها: 12-13 رسمية (الأشرفية/المريسة/الباشورة/المزارعة/المدوّر/ميناء الحصن/المصيطبة/مرفأ بيروت/رأس بيروت/الرميل/الصيفي/زقاق البلاط) + ضواحي (برج حمود/الضاحية الجنوبية/شياح/حارة حريك/مخيم شاتيلا). اللهجة: البيروتية (قاف همزة + إيقاع غنائي + مفردات فرنسية). الطعام + اللباس + العادات: (انظر ملفات لبنان — المازة/الدبكة/القمباز/الطربوش/فيروز/النبيذ). محاطة بمحافظة جبل لبنان (جونية/بعبدا/عاليه/الشوف). **لا تعداد رسمي منذ 1932** — كل الأرقام تقديرات متباينة (🟡🟠)، والمدينة تعيش أزمات متتالية (الحرب + اغتيال + انفجار + أزمة + حرب 2024) — الوضع متغيّر.
