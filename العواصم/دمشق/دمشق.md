## سبب اختيارها عاصمة + تاريخها

### سبب الإختيار 🟢
- **الموقع الإستراتيجي:** ملتقى طرق تجارية (آسيا ↔ أفريقيا ↔ أوروبا) + بين الساحل (المتوسط) والداخل + حلقة وصل بين الشام + العراق + الجزيرة العربية.
- **وفرة المياه:** نهر بردى + غوطة دمشق (واحة خصبة) + مركز زراعي وتجاري.
- **البُعد عن مناطق الصراع:** بعيدة عن أنطاكية (عاصمة بيزنطية قبلية) + عن المدينة المنورة + عن الكوفة.
- **موقع وسطي:** بين الشام + العراق + الجزيرة — يسهل الحكم + التجارة + الاتصالات.
- **الدفاع:** قلعة دمشق + أسوار + أبواب + جبل قاسيون.

### التاريخ 🟢🟠
- **ما قبل 635 (العصور القديمة):** ~9000 ق.م (أقدم استيطان مستمر) → الآراميون → الآشوريون (732 ق.م) → الكلدانيون → البابليون → الفرس → الرومان (64 ق.م) → البيزنطيون.
- **635 (الفتح الإسلامي):** خالد بن الوليد يفتح دمشق + تنقل عاصمة الشام من أنطاكية إلى دمشق.
- **640:** معاوية بن أبي سفيان واليًا على الشام.
- **661–750 (الأمويون):** معاوية يتخذ دمشق **عاصمة الخلافة الأموية** + بناء جامع بني أمية + القصور + الأسواق + ازدهار + المدينة أكبر مركز للعلم (بعد المدينة المنورة + الكوفة).
- **750 (العباسيون):** تنقل العاصمة إلى بغداد + دمشق عاصمة إقليمية (العباسيون + الفاطميون + السلاجقة).
- **1154 (نور الدين):** نور الدين يوحد سوريا + تنقل العاصمة إلى دمشق.
- **1174–1250 (الأيوبيون — صلاح الدين):** صلاح الدين ينطلق من دمشق + يبني القلعة.
- **1260–1516 (المماليك):** دمشق عاصمة إمبراطورية المماليك + العمارة الإسلامية + المساجد + المدارس + القلاع + الأسواق.
- **1516–1918 (العثمانيون):** ولاية عثمانية + دمشق عاصمة + التكية + ترميم.
- **1831:** والي ضربية جديد + ثورة الميدان ضد الإحتلال الفرنسي (الفرنسيسون).
- **1918:** الإعلان عن دولة دمشق (الإنتداب الفرنسي) + دمشق عاصمة إقليمية.
- **1920:** الإحتلال الفرنسي (معركة ميسلون) + دمشق عاصمة مصغرة.
- **1922:** تنقل العاصمة إلى حمص (الإتحاد السوري) + عادت 1925.
- **1946:** استقلال سوريا + دمشق عاصمة الجمهورية السورية.
- **1958–1961:** الوحدة مع مصر (الجمهورية العربية المتحدة — قصيرة).
- **1970–1979:** الأسد (حافظ الأسد) + الإصلاحات + حرب أكتوبر.
- **2011 (15 مارس):** ثورة + الحرب الأهلية + التدمير + النزوح + الأسد (2011–2024).
- **2024 (8 ديسمبر):** سقوط نظام الأسد + إعادة بناء + عودة اللاجئين (~1 مليون عادوا 2025) + الوضع متغير.
- 🟠 **الوضع الحالي:** إعادة بناء + تقلبات سياسية + أمنية + إقتصادية + عودة اللاجئين.

## خاتمة

دمشق = **الشام + الفيحاء + مدينة الياسمين + باب الكعبة** — أقدم عاصمة مأهولة في العالم (~9000 ق.م) + أقدم عاصمة للخلافة الإسلامية (الأمويون 661–750) + العاصمة الثالثة في الإسلام (بعد المدينة المنورة + الكوفة). **نهر بردى** + **غوطة دمشق** + **جبل قاسيون** — الموقع الإستراتيجي + التاريخ المستمر. معالمها: جامع بني أمية + قلعة دمشق + قصر العظم + ساحة الأمويين + ساحة المرجة + سوق الحميدية + المتاحف + جامعة دمشق. أحياؤها: دمشق القديمة (الشاغور + باب توما + الصالحية + الميدان + القيمرية + القنوات + ساروجة + البرامكة + المزرعة + المهاجرين) + خارجها (المزة + كفر سوسة + برزة + المالكي + ركن الدين + القابون). اللهجة: الدمشقية (عربية سورية). الطعام + الملابس + العادات: (انظر ملفات سوريا). القرى التابعة: >10 مدن + قرى (دوما + حرستا + التل + النبك + الزبداني + قدسيا + القطيفة + الكسوة + يبرود... — تُفصَّل في المرحلة السادسة).
