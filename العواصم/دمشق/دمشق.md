## سبب اختيارها عاصمة + تاريخها

### سبب الإختيار 🟢
- **الموقع الإستراتيجي:** سفوح جبل الشيخ + 80 كم من المتوسط — حلقة وصل بين البحر المتوسط (غرب) + بادي الشام/العراق (شرق) + الحجاز/فارس (جنوب) + الأناضول (شمال).
- **وفرة المياه:** نهر بردى + ينابيع + الغوطة (واحة خصبة) + أراضي زراعية + نخيل + قمري.
- **أهمية تجارية:** معبر طرق التجارة (الحرير + القوافل) + مركز تجاري إقليمي + واجة بين الشرق والغرب.
- **الدفاع:** أسوار + قلعة (صلاح الدين) + جبل (قاسيون/الشيخ) — مركز دفاع طبيعي.

### التاريخ 🟢🟠
- **~9000 ق.م (العصر الآرامي):** تأسست (ريزون الآرامي) + معبد هدد + قنوات ماء (نهر بردى).
- **القرن 1 ق.م (السلوقيون):** تحصين المدينة + شوارع على طراز هندسي (الشارع المستقيم) + معبد جوبيتر.
- **القرن 1 ق.م (الرومان):** معبد جوبيتر (دمشقي) + ساحة الفوروم + قلعة.
- **العصر البيزنطي (القرن 4 م):** كنائس (يوحنا المعمدان) + المسيحية غالبية.
- **635–636 م (الفتح الإسلامي):** خالد بن الوليد يفتح دمشق (بعد حصار 6 أشهر) + الأمان + المسلمون + المسيحيون (تعايش).
- **661–750 (الأمويون):** دمشق **عاصم الدولة الأموية** + معاوية بن أبي سفيان (والٍ) + الوليد بن عبد الملك يبني **الجامع الأموي** (705–715) + ازدهار + قصور + قنوات + الفسيفساء.
- **750–1250 (العباسيون):** إنتقال العاصم إلى بغداد + دمشق تدهور + الصليبيون (حريق الفسطاط 1168).
- **1171–1250 (الأيوبيون — صلاح الدين):** صلاح الدين ينهي الحكم الفاطمي + يبني القلعة + القاهرة عاصم الأيوبيين + القاهرة عاصم إمبراطورية الأيوبيين.
- **1250–1517 (المماليك):** دمشق عاصم ولاية + العمارة الإسلامية + المساجد + المدارس + القلاع.
- **1400:** تيمورلنك ينهب دمشق + حريق الجامع الأموي + فرار الصكان + نقل الصناع إلى سمرقند.
- **1516–1918 (العثمانيون):** دمشق عاصم ولاية + التكية السليمانية + إعادة ترميم الجامع الأموي + السلاجقة.
- **1918–1946 (الإنتداب الفرنسي):** الإحتلال الفرنسي + التحديث + المظاهرات.
- **1925:** الثورة السورية الكبرى → إستقلال 1946 + دمشق عاصم سوريا المستقلة.
- **1958–1961:** الوحدة مع مصر (الجمهورية العربية المتحدة — قصيرة).
- **1963:** حكم البعث + حرب 1967 + حرب أكتوبر 1973.
- **2011 (15 مارس):** الثورة السورية + الحرب الأهلية + تدمير + النزوح + الأزمة.
- 🟠 **الوضع الحالي:** الحرب الأهلية + تدمير + تقلبات + إعادة بناء بطيئة + الأزمة الإقتصادية + السكان + المرور.

## الجغرافيا والتضاريس

### الموقع 🟢
- **سفوح جبل الشيخ:** شرق منحدرات سلسلة جبال لبنان الغربي + 80 كم من ساحل المتوسط + هضبة 680 م.
- **نهر بردى:** يجري في دمشق + الغوطة (واحة) + ينابيع (عيون) + قنوات ماء تاريخية (الآراميون + الرومان + الأمويون).
- **الغوطة:** واحة خصبة حول دمشق (نخيل + قمري + أراضي زراعية) — تدهور.

### المناخ 🟢
- **شبه جاف** (BSh) — صيف حار >35°م (مايو–سبتمبر) + شتاء معتدل/بارد (5–10°م — نوفمبر–مارس) + أمطار قليلة (<200 مم) + جاف.
- **رياح:** غربية + جبل الشيخ يمنع الرطب (ظل المطر) → شبه جاف.

### التضاريس 🟢
- **هضبة 680 م** + **سهل** (الغوطة) + **جبل قاسيون** (شمال — نصب الجندي المجهول) + **جبل الشيخ** (غرب).
- **نهر بردى** + ينابيع + قنوات + ساحة المرجة (وسط المدينة — تقاطع طرق).

## خاتمة

دمشق = **الشام + فيحاء + مدينة الياسمين** — أقدم عاصم مأهولة في العالم (~9000 ق.م) + أقدم عاصم إسلامية (661 م — الأمويون) + رابع أقدم مسجد إسلامي (الجامع الأموي) + **عاصم الدولة الأموية** (661–750) + يونسكو تراث عالمي (1979). **الغوطة** (واحة خصبة) + نهر بردى. معالمها: الجامع الأموي + قلعة دمشق + سوق الحميدية + الشارع المستقيم + ساحة المرجة + قصر العظم + المتحف الوطني + جامعة دمشق + كنيسة حنانيا + البيمارستان النوري. أحياءها: القنوات + العمارة + باب توما + الميدان + الشاغور + الصالحية + المزة + كفر سوسة. اللهجة: الدمشقية (عربية شامية). الطعام + الملابس + العادات: (انظر ملفات سوريا). القرى التابعة: >20 بلدة + مدن (دوما + حرستا + داريا + جرمانا + التل... — تُفصَّل في المرحلة السادسة).
