- **تاريخ التأسيس:** القرن 16 م (احتلال بريطاني) 🟢؛ والجذور أقدم (مسقط الخليجية + تجارة بحرية) + تأثير بريطاني/هندي/فارسي.

## سبب اختيارها عاصمة + تاريخها

### سبب الإختيار 🟢
- **الموقع الساحلي الإستراتيجي:** على خليج عُمان — مركز تجاري/دفاعي + ميناء (ميناء السلطان قابوس) + ربط بين الداخل (الجبال/الفلج) والخارج (الباطنة/ظفار).
- **التاريخ العريق:** مسقط الخليجية (تجارة بحرية) + الدولة العثمانية (القرن 16) + الإحتلال البريطاني (القرن 18) + الإستقلال (1970).
- **النفط:** الإستثمار + التنويع.
- **المركزية الحديثة:** عاصمة + مركز البل + الإعلام + التعليم + السياحة + النقل.

### التاريخ 🟢🟡🟠
- **قبل الإسلام:** سكان قديم (تجارة بحرية) + تأثير بريطاني/فارسي/هندي.
- **الإحتلال البريطاني (القرن 16):** احتلال + قاعدة + دور هام.
- **الدولة العثمانية (القرن 16–1741 م):** مسقط عاصمة إقليمية (إقليم البريطاني).
- **الدولة البوسعيدية (1741–1970 م):** تراجع + غارات بريطانية.
- **الإستقلال (23 يوليو 1970):** مسقط عاصمة سلطنة عُمان.
- 🟠 **الوضع الحالي:** عاصمة + سلطنة (السلطان هيثم بن طارق آل سعيد) + إعادة البل + عُمان الحديثة (تنويع/سياحة + تقلبات).

## الجغرافيا والتضاريس

### الموقع 🟢
- **شمال شرق عُمان** على خليج عُمان — مركز تجاري/دفاعي على ساحل 🟢.
- **الشكل:** ساحل منخفض + جبال/خورود (ظفار) + خليج (ميناء).
- **الموقع الإستراتيجي:** مركز تجاري/دفاعي + ربط بين الداخل (شرق) والخارج (غرب).

### المناخ 🟢🟡
- **صحراوي حار (BWh):** صيف طويل حار جدًّا (يونيو–سبتمبر ~40+ °م) + رياح رطبة.
- **الشتاء (ديسمبر–فبراير):** معتدل (~18 °م) + أحيانًا برد.

## الأحياء (قائمة كاملة)

> **محافظة مسقط** تنقسم إداريًّا إلى **6 ولايات** (التقسيم الإداري) 🟢، كل ولاية تتكون من أحياء.

### الولايات الستة 🟢
1. **مسقط** (المركز الإداري + العاصمة) + 2. **ظفار** (جنوب) + 3. **الداخلية** (نزوى + سمائل + بهلا + إزكي) + 4. **شمال الباطنة** (صحار) + 5. **جنوب الباطنة** (الرستاق) + 6. **مسندم** (شمال غرب).

### الأحياء البارزة 🟢🟡
- **مسقط القديمة:** أزقة تاريخية (السوق القديم + القلعة + المدينة القديمة + الأسواق + بيوت تاريخية).
- **المطرح:** مطرح مسقط + القرم + دار البلدية + دار الأوبرة + المطار + رويش.
- **الرويش** (شرق مسقط) + **المسرح** (شمال مسقط) + **الخوض** (شمال غرب مسقط) + **بحيرة** (شمال غرب).
- **الضواحي:** صلالة + العامرات + بوشر + السيب + قريات.

## خاتمة

مسقط = **عاصمة سلطنة عُمان** + **مركز البل والمال** + **ميناء + مطار** + **مقر حكم**. على خليج عُمان، صاغت **المطبخ العُماني** (الشوا — الطبق الوطني) و**اللباس العُماني** (الدشداشة — رداء فضفاض، فريد عن باقي الخليج) و**القهوة العُمانية** (الضيافة — تراث يونسكو). تاريخها: سكان قديم (تجارة بحرية) ← الدولة العثمانية (القرن 16) ← الإحتلال البريطاني ← الإستقلال (1970). معالمها: المسجد السلطاني (السلطان قابوس الأكبر — 2001) + القلعة الجالي (يونسكو 2013) + القصور (قلعة الميراني + حصن نزوى/الرستاق/صحار/مطرح) + بيوت تاريخية + المطار الدولي. أحياؤها: مسقط القديمة + ظفار + الداخلية + شمال الباطنة + جنوب الباطنة + مسندم. اللهجة: الحضرية (قاف همزة) + الداخلية (أقرب للفصحى) + الظفارية + البادية. الطعام + اللباس + العادات: (انظر ملفات عُمان — الشوا/القبولي/الهريس + الدشداشة/الكمة/الخنجر + العرسية/العيالة + الرزحة/العازي + المضروبة/البرياني + القهوة/شاي + العوال/القاشع + المعجون + الفلج/الخزف/صناعة السفن). محافظة مسقط (6 ولايات) + 5 محافظات. لا تعداد رسمي بعد 2020 — الأرقام تباينة وتُذكر بحصر 🟠، والأرقام اللاحقة موصونة بـ🟠.
