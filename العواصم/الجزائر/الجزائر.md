# الجزائر — عاصمة الجمهورية الجزائرية

> 🟢🟡🟠 (مصادر: ويكيبيديا العربية + ويكيبيديا الإنجليزية (Algiers) + المعرفة + هيئة الإعلام (sfari/marefa) + aljarida + alkhaleej + almosaferoon + batna05 + areq + mawdoo3 + sotor + edarabia + citiesabc + geographyworlds + worldpopulationreview + worldometer + Britannica + inaturalist + kids.kiddle + mappr + ultrasawt + ultrasawt + ahnami + daralhikma). علامات الثقة: 🟢 موثَّق / 🟡 اختلاف بين المصادر / 🟠 حصر (الواقع الميداني + أرقام متباينة). كل رقم مقرون بسنة.
>
> 🟠 **تنبيه:** الجزائر عاصمة أكبر مدن البلاد + تُعد ثالث أكبر مدن المتوسط + سادسة عربيًّا + تاسعة إفريقيًّا. لا توجد إحصاءات رسمية حديثة موثوقة بعد 2008، والأرقام تقديرات متباينة جدًّا (المدينة ~2.4 مليون؛ المترو ~3.3–4.5 مليون) — تُذكر بحصر. كل رقم مقرون بسنة.

## الهوية

- **الاسم الرسمي:** مدينة الجزائر (Algiers / El Djazaïr) | **الاسم المحلي:** الجزائر | **الأسماء التاريخية:** إيكوسيوم (Icosium) + إيكوسيم/يكسم + جزائر بني مزغنة | **الأسماء الشعبية:** الجزائر البيضاء + المحروسة + البهجة (لبياض ولمعان عماراتها ومبانيها).
- **سبب التسمية:** «جزائر بني مزغنة» = الجزر الأربع 🟢؛ أو «إيكوسيوم» = جزيرة النورس (رومانية) 🟢؛ أو نسبة إلى الجزر الأربع الأربع أو الإيكوسيم الفينيقي 🟠 — روايات متعددة.
- **الموقع:** شمال وسط الجزائر — على خليج الجزائر في البحر المتوسط، على سفوح جبال ساحل الجزائر (جبل بوزريعة) 🟢 | **الإحداثيات:** 36.4635°N, 3.0331°E 🟢🟡 | **الارتفاع:** ~0–122 م (القصبة ~122م؛ سفوح التلال) 🟡 | **المساحة:** ~363–1,190 كم² 🟡.
- **السكان:** المدينة ~2,4230,000–2,988,145 (تعداد 1998–2008) 🟡 | الكثافة ~9,400/كم² (من أعلى الكثافات في العالم) | **المترو (التجمع الحضري):** ~3.3–4.5 مليون (تقديرات متباينة) 🟠. (أكبر مدن الجزائر + عاصمة ولاية الجزائر).
- **اللقب:** العاصمة السياسية والاقتصادية والثقافية 🟢 | **من أعرق المدن المتوسطية** + **الجزائر البيضاء** (للعمارة الحجرية البيضاء) | **عاصمة الجمهورية الجزائرية** + مركز إعلامي/جامعي.
- **تاريخ التأسيس:** 960 م (بلكين بن زيري) 🟢؛ والجذور أقدم (إيكوسيوم الفينيقية/الرومانية) + تأثير أندلسي/عثماني/فرنسي.

## سبب اختيارها عاصمة + تاريخها

### سبب الإختيار 🟢
- **الموقع الساحلي الإستراتيجي:** على خليج الجزائر في البحر المتوسط — مركز تجاري/دفاعي + ميناء + ربط بين الشرق (تونس/قسنطينة) والغرب (المغرب/الأندلس).
- **التاريخ العريق:** >2,000 سنة (إيكوسيوم) + عاصمة الولايات المتعاقبة (الزيانيون/المرابطون/العثمانيون).
- **النقل الحديث:** مركز لجهة الإدارية/الملكية + ميناء/مطار + الجامعي/الثقافي — أكبر مركز إقتصادي في البلاد (~20% من الناتج المحلي الإجمالي).
- **التراث يونسكو 1992:** القصبة (المدينة العتيقة) — تراث عالمي.

### التاريخ 🟢🟠
- **قبل التاريخ (إيكوسيوم):** موقع فينيقي على خليج الجزائر — أقدم استيطان (بقايا أواني تعود للقرن 3 ق.م).
- **الرومان (202 ق.م):** خضعت المدينة للهيمنة الرومانية بعد حلف سكيبيو–ماسينيسا ضد قرطاج ← «إيكوسيوم» (جزيرة النورس) ← الوندال (429) ← المسيحية (القرن 5) ← استرجاع إيكوسيوم (429).
- **العصر الوسيط (960 م):** بلكين بن زيري مؤسس الدولة الزيرية يبني إيكوسيوم على أنقاض المدينة الرومانية ← «جزائر بني مزغنة» (4 جزر).
- **العثمانيون (1516–1830):** عروج بربروس + سالم التومي يطلب النجدة + معركة الجزائر (1516) ← عاصمة إيالة الجزائر ← قصبات/أسوار/قلاع/المسرح/دار البلدية/دار المحكمة/دار البريد/قصر الحاكم.
- **الاحتلال الفرنسي (1830–1962):** الجزائر عاصمة المستعمرة ← عمارة كولونيالية فرنسية (بيار أوغست جيوشان 1845 — مخططات/مباني) ← بنية تحتية + جامعات/مطار/صناعة.
- **1962 (5 يوليو):** استقلال الجزائر ← الجزائر عاصمة (الدي بورمونت) ← توسع سكاني هائل.
- **القرن 21:** مركز مهم إقتصادي/إعلامي/جامعي/سياسي + رؤية (المتشريات).
- 🟠 **الوضع الحالي:** عاصمة + تراث يونسكو (القصبة) + مركز إقتصادي + تقلبات سياسية/أمنية.

## الجغرافيا والتضاريس

### الموقع 🟢
- **شمال وسط الجزائر** على خليج الجزائر في البحر المتوسط — على سفوح جبال ساحل الجزائر (جبل بوزريعة ~400م) 🟢.
- **الشكل:** شبه جزيرة/تل ساحلي (القصبة) + حي حديث على سفوح التلال + وادي الحراش (شرق) + خليج الجزائر (غرب).
- **الموقع الإستراتيجي:** بين الشرق (تونس/قسنطينة) والغرب (المغرب/الأندلس) — مركز تجاري/دفاعي/ميناء.

### المناخ 🟢🟡
- **متوسطي (Csa — كوب):** صيف حار رطب + شتاء معتدل بارد.
- **الصيف (أغسطس):** ~25–30 °م + رطب (ساحلي).
- **الشتاء (يناير):** ~11 °م + ماطر + أحيانًا ثلوج (1955، 2013) + رياح/هبوب.
- **الأمطار:** ~600–800 مم سنويًّا (تبيان بين المصادر) 🟡 — أكتوبر–أبريل.
- 🟢 **ربط الجغرافيا بالثقافة:** الساحل المتوسطي صاغ **العمارة الكولونيالية الفرنسية** (مبان حجرية بيضاء + شرفات/قناطر) + **اللباس الجزائري** (الجلابة/القفطان/البرنوس — فسيفساء مغربية) + **المطبخ المغاربي** (الكسكس/الطاجين/الشخشوخة — تراث يونسكو) + **الزي الأندلسي** (الشدة التلمسانية — تراث يونسكو).

## الأحياء (قائمة كاملة)

> **ولاية الجزائر** (عاصمة + ولاية) تنقسم إداريًّا إلى **13 دائرة** (التقسيم الإداري 1984/1997) 🟢، كل دائرة تتكون من بلديات/أحياء.

### الدوائر الـ13 🟢
1. **الجزائر-الوسط** (القصبة + المركز الإداري) + 2. **الجزائر-الشرق** (بلكور/الحراش) + 3. **الجزائر-الغرب** (بوزريعة/العقنة) + 4. **بئر مراد رايس** (الحراش) + 5. **حسين داي** (وسط) + 6. **الحراش** (شرق) + 7. **بلكور** (شمال) + 8. **بوزريعة** (غرب) + 9. **بني مراد** (جنوب شرق) + 10. **الرئيسة** (العيوبة) + 11. **دار البيضاء** (شرق) + 12. **برطال** (غرب) + 13. **الزرقونة** (شمال غرب).

### الأحياء البارزة 🟢🟡
- **القصبة** (المدينة العتيقة — أقدم نسيج حضري، تلة شديدة الانحدار ~122م؛ القصبة العليا + القصبة السفلى + الحراش + الحراش البحري) + **بلكور** (شمال غرب — عدة أحياء: لعقيبة/الحامة/سارفونتاز) + **حسين داي** (وسط — حي حسين داي + القبة + باب الواد + المحروسة) + **الحراش** (شرق — حي محي الدين) + **العقنة** (غرب) + **بئر مراد رايس** (شمال) + **حسيبة** (غرب).
- **مناطق/أحياء أخرى:** باب الواد + باب عزون + باب الجزار + الساحة الكبرى (ساحة أول ماي) + كرمة الساحة (شارع ديدوش مراد) + حي الجزار.

## القرى والمدن التابعة إن وجدت 🟡

> الجزائر العاصمة عاصمة **ولاية الجزائر** (دائرة واحدة عاصمية) 🟢، محاطة بـ13 ولاية متاخمة (بلكور/بجاية/قسنطينة/تلمسان/عنابة/الأوراس/بسكرة/غرداية/وهران). من مدن ولاية الجزائر المتاخمة:

## خاتمة

الجزائر = **عاصمة الجمهورية الجزائرية** + **الجزائر البيضاء** (للعمارة الحجرية البيضاء) + **من أعرق المدن المتوسطية** + **أكبر مدن الجزائر** (ثالثة على المتوسط + سادسة إفريقيًّا + عاشرة عربيًّا) + **عاصمة ولاية الجزائر** + **مركز إقتصادي/إعلامي/جامعي/سياسي** (~20% من الناتج المحلي). على خليج الجزائر في البحر المتوسط، على سفوح جبال ساحل الجزائر، صاغت **القصبة** (المدينة العتيقة — تراث يونسكو 1992) **العمارة الكولونيالية الفرنسية** (مبان حجرية بيضاء + شرفات/قناطر) و**اللباس الجزائري** (الجلابة/القفطان/البرنوس/الشدة التلمسانية — تراث يونسكو) و**المطبخ المغاربي** (الكسكس/الطاجين — تراث يونسكو). تاريخها الممتد: إيكوسيوم الفينيقية ← الرومان (202 ق.م — إيكوسيوم/جزيرة النورس) ← الوندال (429) ← المسيحية ← استرجاع إيكوسيوم ← العصر الوسيط (960 م — بلكين بن زيري يبني «جزائر بني مزغنة») ← العثمانيون (1516 — عروج بربروس/سالم التومي — معركة الجزائر) ← الإحتلال الفرنسي (1830 — بيار أوغست جيوشان يخطط 1845) ← استقلال (1962 — دي بورمونت) ← توسع سكاني/قرن 21. معالمها: **القصبة** (تراث يونسكو 1992) + **الجامع الكبير** (أقدم مسجد) + **جامع كتشاوة/الجامع الجديد/مسجد علي بتشين/مسجد الشهيد/مسجد السبتي/مسجد سيدي عبد الرحن** + **قلاع** (قلعة بئر مراد رايس/بني مقني) + **قصر الحاكم/دار البلدية/المسرح/دار المحكمة/قصر باسطة** + **شارع ديدوش مراد/شارع الأمير عبد القادر** + **متحف** (الوطني للفنون/بار دو/باردو/المجاهدين/الجزائر للآثار/الأباضي/الأمازيغ/المعركة/النور/الشفعة/كرمة) + **جامعات** (الجزائر 1879 أعرق جامعة + أولى إفريقيا + هواري بومدين + الشهيد بن عودة + الشهيد طاهر لوطار + عبد الرحن ميرة + جيلالي يب محمد + مرسية + أم تبة + سعيدة + الشهيد حبي بن يحي + مولود معمري) + **مطار هواري بومدين الدولي**. أحياؤها: 13 دائرة (الجزائر-الوسط/الجزائر-الشرق/الجزائر-الغرب/بئر مراد رايس/حسين داي/الحراش/بلكور/بوزريعة/بني مراد/الرئيسة/دار البيضاء/برطال/الزرقونة) + حارات (القصبة/بلكور/بلوزداد/الحراش/العقنة). اللهجة: العاصمية (قاف همزة + مفردات فرنسية + اختزال حروف العلة). الطعام + اللباس + العادات: (انظر ملفات الجزائر — الكسكس/الطاجين/القفطان/الشدة التلمسانية/الشعبي/الراي). محاطة بـ13 ولاية (بجاية/تيزي وزو/عنابة/بسكرة/غرداية/وهران/الأوراس/بني صاف). لا إحصاء رسمي حديث بعد 2008 — الأرقام تقديرات متباينة (المدينة ~2.4 مليون؛ المترو ~3.3–4.5 مليون) تُذكر بحصر 🟠.
