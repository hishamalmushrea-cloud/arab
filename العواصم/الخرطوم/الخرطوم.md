## سبب اختيارها عاصمة + تاريخها

### سبب الإختيار 🟢
- **الموقع الإستراتيجي:** ملتقى النيلين الأبيض والأزرق (المقرن) — وسط السودان + مركز تجاري تاريخي (قوافل الماشية + العاج + الرقيق) + مركز حكم.
- **سهولة الوصول:** وسط السودان + على النيل (ملاحة قوارب + جزيرة توتي) + معبر بين الشمال والجنوب.
- **أهمية عسكرية:** معسكر للجيش المصري (1821) + دفاع طبيعي (النيلان + الصحراء) + مركز لانطلاق الحملات.
- **موقع ثقافي:** مركز العلوم + الجامعات + المتاحف + الأحياء التاريخية (حلة حمد + حلة خوجلي).

### التاريخ 🟢🟠
- **ما قبل 1821:** سوق + نقطة قوافل + مملكة علوة القديمة (~4000 ق.م) + استيطان بشري منذ العصر الحجري (خور أبي عنجة + الشهيناب).
- **1821:** تأسست كمدينة على يد إبراهيم باشا (الجيش العثماني المصري) + اتُّخذت عاصمة للبلاد.
- **1824:** عثمان جركس باشا البرنجي يُعينها عاصمة + بناء الثكنات.
- **1859:** ~30,000 نسمة + مركز تجاري (العاج + الرقيق).
- **1882:** الإحتلال البريطاني (الحكم الثنائي).
- **1884–1885:** حصار المهدية للخرطوم + سقوطها + قتل غوردون باشا.
- **1885:** المهدي يُحوّل العاصمة إلى أم درمان (عاصمة المهدية).
- **1898:** كتشنر يسترجع الخرطوم + تُصبح عاصمة الحكم الثنائي (البريطاني–المصري).
- **1899–1956:** الحكم الثنائي + إعادة بناء (العمارة الإنجليزية + شوارع على شكل «اليونيون جاك»).
- **1956:** استقلال السودان + تُصبح الخرطوم عاصمة الدولة المستقلة.
- **1903:** افتتاح كلية غوردون (→ جامعة الخرطوم).
- **1971:** افتتاح متحف السودان القومي.
- **1976:** افتتاح قاعة الصداقة (الصين).
- **2002–2023:** إعصار المهدية + تقديرات الناتج + دمار.
- **2023 (15 أبريل):** حرب السودان (الجيش × الدعم السريع) + تدمير المدينة + نزوح ~4–5 مليون (2025).
- 🟠 **الوضع الحالي:** الحرب + تدمير + الصراع + تقلبات.

## الجغرافيا والتضاريس

### الموقع 🟢
- **المقرن (al-Mogran):** ملتقى النيلين الأبيض (من بحيرة فيكتوريا/أوغندا — شمالًا) + الأزرق (من بحيرة تانا/إثيوبيا — غربًا) → نهر النيل (نحو الشمال إلى مصر).
- **الصورة الطوبوغرافية:** سهل مسطح منخفض (382 م) + النيل يجري شمالًا شرقًا نحو شندي.
- **العاصمة المثلثة:** الخرطوم (جنوب غرب النيل الأزرق + شرق النيل الأبيض) + أم درمان (غرب النيل الأبيض) + الخرطوم بحري (شمال النيل الأزرق) — مرتبطة بجسور.

### المناخ 🟢
- **معتدل شتاءً** (15–25°م — ديسمبر–فبراير) + **حار صيفًا** (>40°م — أبريل–يونيو) + **موسم الخريف** (أمطار غزيرة يونيو–سبتمبر).
- أمطار موسمية + مناخ شبه صحراوي.

### التضاريس 🟢
- **سهل مسطح** + **النيل** = العصب + **لا جبال** (أنخفض نقطة 382 م).
- **النيلان:** ملتقى المقرن + جزر (توتي + المقابر) + أودية.
- **الجسور:** جسر النيل الأبيض (الخرطوم ↔ أم درمان) + جسر النيل الأزرق (الخرطوم ↔ بحري) + جسر شمبات (بحري ↔ أم درمان — 2023) + جسر الفردوس.

## خاتمة

الخرطوم = **عاصمة ملتقى النيلين** (الأبيض + الأزرق → النيل) — مركز سياسي + إقتصادي + ثقافي + تجاري تاريخي. تأسست 1821 (الجيش العثماني المصري) + شهدت المهدية (1885) + الحكم الثنائي (1898) + استقلال 1956. **العاصمة المثلثة** (الخرطوم + أم درمان + بحري) — أكبر تجمع حضري في السودان (~6 مليون قبل الحرب). تأثرت بشدة بحرب 2023 (دمار + نزوح + الصراع). معالمها: شارع النيل + القصر الجمهوري + قاعة الصداقة (الصين) + متحف السودان القومي + جامعة الخرطوم + جزيرة توتي + مقابر الأتراك + قبة المهدي. أحياءها: المقرن + أركويت + الجريف + الحلة الجديدة + حلة حمد (صوفية) + شمبات + إلخ. اللهجة: الخرطومية (عربية سودانية). الطعام + الملابس + العادات: (انظر ملفات السودان). القرى التابعة: >50 قرية في الولاية (تُفصَّل في المرحلة السادسة).
