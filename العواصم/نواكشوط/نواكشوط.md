# نواكشوط — عاصمة الجمهورية الإسلامية الموريتانية

> 🟢🟡🟠 (مصادر: ويكيبيديا العربية + ويكيبيديا الإنجليزية (Nouakchott) + المعرفة + rimnow + البوابة الرسمية rimnow). علامات الثقة: 🟢 موثَّق / 🟡 اختلاف. كل رقم مقرون بسنة.
>
> 🟠 **تنبيه (الحياد):** نواكشوط متأثرة بالعبودية (قانون 1981) + التركية الاجتماعية (1980/2007) + نزاع مع المغرب (الصحراء الغربية). يلتزم الملف بالحياد التام في تناول نواكشوط بذاتها (هوية/تاريخية/معالم/أحياء) دون تبني موقف في النزاع، مع تصريح صريح بالحياد في المقدمة. الأرقام السكانية تباينة (إحصاء2013) وتُذكر بحصر، والأرقام اللاحقة موصونة بـ🟠.

## الهوية

- **الاسم الرسمي:** مدينة نواكشوط (Nouakchott) | **الاسم المحلي:** نواكشوط | **الأسماء التاريخية:** نواكشوط الشمالية + بلاد شنقيط | **الأسماء الشعبية:** عاصمة موريتانيا.
- **سبب التسمية:** «نواكشوط» = ربط البلد بمنطقة شنقيط (نسبة لموقعها في أقصى الشمال، بمنطقة شبيهة بجزيرة) 🟢 — روايات متعددة.
- **الموقع:** جنوب غرب موريتانيا — على الساحل الأطلسي للبحر المتوسط، مقابل الساحل السنغالي، على رأس شبه جزيرة منخفض، عند مصب نهر السنغال 🟢 | **الإحداثيات:** 18.0860°N, -15.9780°W 🟢🟡 | **الارتفاع:** ~10 م (ساحل منخفض) 🟡 | **المساحة:** ~25,000 كم² 🟡.
- **السكان (إحصاء2013):** المدينة ~1 مليون 🟡 | الكثافة عالية (نحو 50/كم²) | **نواكشوط الكبرى (المترو):** ~1.2 مليون (تقديرات — ثاني أكبر مدن موريتانيا) 🟠.
- **اللقب:** العاصمة السياسية والإدارية 🟢 | **أكبر مدن موريتانيا بالسكان** + **مركز البحر والصناعة** + **مقر حكم** + **مركز التجارة**.
- **تاريخ التأسيس:** القرن 17 م (أطار/شنقيط) 🟢؛ والجذور أقدم + تأثير بربري/إفريقي/بدوي.

## سبب اختيارها عاصمة + تاريخها

### سبب الإختيار 🟢
- **الموقع الساحلي الإستراتيجي:** على الساحل الأطلسي للبحر المتوسط — مركز تجاري/ميناء (ميناء نواكشوط) + ربط بين الأحياء والصحراء (الداخلية + الجنوبية).
- **التاريخ العريق:** سكان قديم (تجارة بحرية) + بربر صنهاجي (الإمبراطورية الموريتانية) + الإحتلال الفرنسي (1904) + الإستقلال (1960).
- **المركزية الحديثة:** عاصمة + مركز صناعة/تجاري + إعلام/تقليم + سياحة.

### التاريخ 🟢🟡🟠
- **قبل القرن 17:** سكان قديم (تجارة بحرية).
- **القرن 17 (أطار):** نواكشوط القديمة ← مركز تجاري.
- **الإحتلال الفرنسي (1904–1960 م):** عاصمة الإقليم + معاهد فرنسية + بنية تحتية.
- **الإستقلال (28 نوفمبر 1960):** نواكشوط عاصمة مملكة موريتانيا.
- 🟠 **الوضع الحالي:** عاصمة + تقلبات (عبودية + تركية اجتماعية + نزاع مع المغرب).

## الجغرافيا والتضاريس

### الموقع 🟢
- **جنوب غرب موريتانيا** على الساحل الأطلسي للبحر المتوسط، مقابل الساحل السنغالي، على رأس شبه جزيرة منخفض — عند مصب نهر السنغال 🟢.
- **الشكل:** ساحل منخفض (ارتفاع 0–10م) + رأس شبه جزيرة.
- **الموقع الإستراتيجي:** مركز تجاري/ميناء + ربط بين الداخل والصحراء + صحراء (غربية + جنوبية).

### المناخ 🟢🟡
- **صحراوي حار (BWh):** صيف طويل حار جدًّا (يونيو–أكتوبر ~40+ °م) + رياح جافة شديدة.
- **الشتاء (ديسمبر–فبراير):** معتدل (~18 °م) + أحيانًا برد/ضباب.
- **الخريف (مارس–مايو):** رياح جافة شديدة + عواصف رملية.

## خاتمة

نواكشوط = **عاصمة الجمهورية الإسلامية الموريتانية** + **أكبر مدن موريتانيا بالسكان** + **مركز البحر والصناعة** + **مقر حكم** + **مركز التجارة**. على الساحل الأطلسي للبحر المتوسط، مقابل الساحل السنغالي، صاغت **المطبخ الموريتاني** (مارو الحوت — الطبق الوطني) و**اللباس الموريتاني** (الدراعة — فريد عن باقي الخليج) و**المشوي** (لحم الضأن) و**الشاي** (الضيافة — مع القهوة). تاريخها: سكان قديم (تجارة بحرية) ← القرن 17 (أطار/شنقيط) ← الإحتلال الفرنسي ← الإستقلال (1960). معالمها: المساجد الطينية + المدن التاريخية الأربع + القصور + المطار الدولي + الميناء + المتاحف. أحياؤها: نواكشوط الشمالية + نواكشوط الغربية + نواكشوط الجنوبية + 3 ولايات + 12 مديرية. اللهجة: الحسانية (لهجة بدوية + 30% من السكان) + البدوية + الصحراوية. الطعام + اللباس + العادات: (انظر ملفات موريتانيا — مارو/المشوي + الكسكس/القمح + الدراعة/الثوب + العقال/الغترة + الحرف التقليدية). ولاية نواكشوط (3 ولايات) + 12 مديرية. لا تعداد رسمي بعد 2013 — الأرقام تباينة وتُذكر بحصر 🟠، والأرقام اللاحقة موصونة بـ🟠.
