## 2. القطاعات الاقتصادية

### (أ) النفط والغاز 🟢
- **الإنتاج:** ~600–800 ألف برميل/يوم (نفط) + غاز.
- **حقول:** حقل صنعاء + حقل غرب Bukha + حقل خابور + غاز (الحيول/الغمر).
- **PDO (تنمية نفط عُمان):** شركة الإنتاج الرئيسية.
- **مساهمة:** ~30–40% من الناتج (تراجعت من 90%+ في السبعينات).

### (ب) القطاعات غير النفطية 🟢 — محرك التنويع
- **السياحة:** سياحة ثقافية (مسقط/نزوى) + سياحة طبيعية (الجبل الأخضر/خور العديد) + **خريف صلالة** + سياحة بحرية (مسيرة) — هدف 13.8 مليار ريال بحلول 2040 + 300 ألف وظيفة.
- **اللوجستيات:** **ميناء الدقم** (الوسطى — استراتيجي + منطقة صناعية) + ميناء صلالة + مطار مسقط + طرق.
- **الصناعة:** صحار (ألمنيوم QALCO + صلب) + البتروكيماويات + الأسمدة + الدقم.
- **التعدين:** نحاس + رخام + جبس + كروم.
- **الصيد البحري:** ثروة سمكية ضخمة (ساحل 3,165 كم) + الدقم.
- **الزراعة:** تمر (أخصب في الباطنة) + لُبان (ظفار) + فواكه (الجبل الأخضر) + الأمن الغذائي.
- **الطاقة المتجددة:** الهيدروجين الأخضر + طاقة شمسية.

### (c) الاستثمار الأجنبي 🟢
- نحو 30 مليار ريال (2025) — نمو 12.79% — 78% في النفط/غاز + 8.5% صناعة.

## 3. الصادرات والواردات 🟢

- **الصادرات:** النفط + الغاز + البتروكيماويات + الألمنيوم + التمور + اللُبان + الأسماك.
- **الواردات:** machinery + غذاء + سيارات + سلع استهلاكية.

---

## 4. رؤية عُمان 2040 🟢

- **الهدف:** مضاعفة الناتج المحلي للفرد + رفع مساهمة القطاعات غير النفطية إلى **93%** + نمو 6%.
- **5 قطاعات محورية:** **السياحة + اللوجستيات + التصنيع + صيد الأسماك + التعدين**.
- **«تنفيذ» (البرنامج الوطني للتنويع):** تنويع حقيقي + التخارج من النفط بحلول 2050.
- **5 تجمعات اقتصادية:** النجد الزراعي (ظفار) + الدقم اللوجستي + صحار (ألمنيوم) + شليم (معادن) + الداخلية السياحي.
- **الهيدروجين الأخضر:** طاقة نظيفة.

## خلاصة الاقتصاد

الاقتصاد العُماني = **اقتصاد ريعي نفطي-غازي متنوِّع** (~110 مليار $) + **رؤية 2040** (تنويع: سياحة + لوجستيات + صناعة + صيد + تعدين — القطاع غير النفطي ~65%) + **الدقم** (ميناء استراتيجي) + الهيدروجين الأخضر. النفط = ~30–40% من الناتج (تراجع). النمو ~2.6% + استثمار أجنبي متنامي. التحديات: الاعتماد على النفط + نضوب الاحتياطيات + الدين + البطالة. المستقبل: التخارج من النفط بحلول 2050 + اقتصاد معرفي + سياحة. 🟢/🟡
