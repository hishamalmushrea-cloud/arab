# سلطنة عُمان — اللهجات

> منهجية: اللهجة العمانية + لهجاتها الجهوية + لغات غير عربية + قاموس.
> المصادر: ويكيبيديا (اللهجات العمانية)، alkhalil.unizwa.edu.om، jaalan.net، qassimy، buraimi.net، om77.net.

## 1. نظرة عامة 🟢

| الحقل | المحتوى | الثقة |
|---|---|---|
| الاسم المحلي | **اللهجة العُمانية** (مجموعة لهجات) | 🟢 |
| العائلة | عربية وسطى → (متنوعة: خليجية + نجدية + يمنية + ظفارية) | 🟢 |
| الانتشار | عُمان + أجزاء من الإمارات/اليمن | 🟢 |
| القرابة | تتباين: الباطنة/مسقط (خليجية) + الداخلية (خالصة) + ظفار (يمنية) + مسندم (خليجية) | 🟢 |
| اللغة الرسمية | العربية الفصحى (دستوريًّا) | 🟢 |
| مكانة الإنجليزية | لغة عمل/تجارة واسعة | 🟢 |

> 🟢 **لا توجد «لهجة عُمانية موحدة»** — كل محافظة لها لهجتها الخاصة (مسقط ≠ الداخلية ≠ ظفار ≠ الباطنة ≠ مسندم). هذا التنوع يعكس التباين الجغرافي-الثقافي.

## 2. اللهجات الجهوية 🟢

### (1) لهجة مسقط والباطنة 🟢
- **المنطقة:** مسقط + شمال/جنوب الباطنة.
- **الميزة:** قريبة من اللهجات الخليجية (الإمارات/قطر) + نطق القاف لهوي/مهموس + بعض المفردات الإنجليزية (إرث بريطاني).

### (2) لهجة الداخلية 🟢
- **المنطقة:** نزوى + سمائل + بهلا + إزكي.
- **الميزة:** **«عُمانية قح»** (أصلية) — قريبة من الفصحى + نطق القاف جيمًا في بعض المناطق + مفردات بدوية/فلاحية. «أصعب لهجة عُمانية على غير العُمانيين فهمها».
- **أمثلة:** دوك/يود (خذ) + روح/سير (اذهب) + احترني (انتظرني) + غاوي (جميل) + باغي (يريد).

### (3) لهجة ظفار (الظفارية) 🟢
- **المنطقة:** صلالة + ظفار.
- **الميزة:** **تميل للهجة اليمنية** (قرب جغرافي) + مفردات ظفارية فريدة + تأثير سواحيلي/إفريقي.
- **أمثلة:** فعور (ثور) + بحيصة (بئر) + فعور (تنطق هكذا في ظفار).

### (4) لهجة مسندم 🟢
- **المنطقة:** خصب + دبا + بخا + مدحاء.
- **الميزة:** خليجية + «الكمزارية» (لغة فريدة في قرية كمزار).

### (5) لهجة البادية 🟢
- **المنطقة:** الداخل + الظاهرة + الوسطى + رمال الشرقية.
- **الميزة:** بدوية + أقرب للفصحى + نطق القاف جيمًا + قلب الجيم ياء.

## 3. لغات غير عربية في عُمان 🟢

> عُمان تتميز بوجود **لغات محلية** (وليست مجرد لهجات) — بسبب التنوع الإثني والتاريخ البحري:

| اللغة | المنطقة | المتحدثون | الثقة |
|---|---|---|---|
| **الشحرية (الجبالية)** | ظفار (جبال) | الشحوح + القبائل الجبلية | 🟢 |
| **المهرية** | ظفار (جنوب) | المهرة | 🟢 |
| **البلوشية** | شمال الباطنة/الظاهرة | البلوش (أصول بلوشستان) | 🟢 |
| **السواحيلية** | مسقط/زنجباريون | العُمانيون من شرق أفريقيا | 🟢 |
| **الكمزارية** | مسندم (كمزار) | سكان قرية كمزار | 🟡 |
| **البتحرية** | ظفار | أقلية | 🟡 |

## 5. ربط اللهجة بالجغرافيا والتاريخ 🟢

- **مسقط/الباطنة:** ساحل + تجارة بحرية + إرث بريطاني → خليجية + مفردات إنجليزية.
- **الداخلية:** جبال + فلج + عزلة → «عُمانية قح» قريبة من الفصحى.
- **ظفار:** جنوب + جوار اليمن + إرث إفريقي (زنجبار) → يمنية + سواحيلية.
- **مسندم:** جيب معزول → خليجية + كمزارية.
- **البادية:** صحراء + رعي → بدوية قريبة من الفصحى.

---

## خلاصة اللهجوية

اللهجة العُمانية = **مجموعة لهجات متباينة** (مسقط/الباطنة خليجية + الداخلية «قح» + ظفار يمنية + مسندم + البادية) + **لغات محلية فريدة** (شحرية/مهرية/بلوشية/سواحيلية/كمزارية). هذا التنوع يعكس **الجغرافيا المتنوعة** (جبال + صحارى + سواحل + جيب معزول) + **التاريخ البحري** (إمبراطورية عُمانية → زنجبار/شرق أفريقيا → سواحيلية). عُمان = **أكثر دول الخليج تنوعًا لهجيًّا-لغويًّا**. 🟢
