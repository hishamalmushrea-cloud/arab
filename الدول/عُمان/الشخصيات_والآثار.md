## خلاصة الشخصيات والآثار

عُمان = **أقدم دولة عربية مستقلة** + **أقدم أسرة حاكمة عربية مستمرة** (البوسعيدية منذ 1749). أعلام: **أحمد بن سعيد** (المؤسس) + **سعيد بن سلطان** (العصر الذهبي) + **ناصر بن مرشد** (اليعاربة) + **قابوس** («باني النهضة» — 50 سنة) + **هيثم بن طارق** (الحالي). المواقع: **5 مواقع تراث يونسكو** (بهلاء 1987 + الفلج 2006 + أرض اللبان 2000) + حصون (نزوى/الرستاق/جبرين) + المسجد السلطاني + المتحف الوطني. **13 عنصرًا تراثًا غير مادي** (أكثر دولة عربية). عُمان = **دولة عريقة بحضارة بحرية + إمامة إباضية + استمرارية بوسعيدية + نموذج تعايش**. 🟢
