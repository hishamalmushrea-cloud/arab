# سلطنة عُمان — اللباس التقليدي

> منهجية: لكل قطعة يُذكَر اسمها المحلي + المناسبة + المنطقة + الأصل.
> المصادر: ويكيبيديا، وكالة الأنباء العمانية (omaninfo.om)، omannews.gov.om، omsta.net، omandaily.

---

## 1. ملاحظة أولى 🟢

> اللباس العُماني = **مميز وفريد عن باقي الخليج** — الدشداشة + الكمة + الخنجر + العمامة. محافَظ عليه بقوة — **اللباس الرسمي** في العمل والمناسبات.
> **سمة:** البساطة + الأناقة + التكيف مع البيئة + **الخنجر العُماني** (رمز وطني) + **الكمة** (طاقية مطرَّزة فريدة).

---

## 2. اللباس الرجالي 🟢

### القطع الأساسية

| القطعة | الوصف | الأصل/الاستخدام |
|---|---|---|
| **الدشداشة (الثوب/الكندورة)** | ثوب طويل أبيض — **عنق مستدير** + شريط رفيع (يختلف لونه) + **«الفراخة/الكركوشة»** (خيوط متدلية على الصدر + معطَّرة بالبخور) + تطريز على الأطراف | عُماني — اللباس اليومي + الرسمي |
| **الكمة (الطاقية/القحفية)** | طاقية أسطوانية مطرَّزة يدويًّا بأشكال وزخارف — **ميزة عُمانية فريدة** (نصف نجم/نجم كامل) — ألوان متعددة | عُماني — يومي + رسمي |
| **العمامة (المصر)** | عمامة قماشية ملوَّنة تُلف على الرأس فوق الكمة | عُماني — مناسبات |
| **الخنجر العُماني** | **خنجر معقوف فضي/ذهبي** — رمز الهوية العُمانية — مقبض (قرن/عظم/فضة) + نصلة + غمد (جلد + فضة/ذهب) + حزام — **يُصنع يدويًّا (شهر+)** | **عُماني فريد** — المناسبات + الوجهاء + رمز وطني |
| **البشت (المشلح)** | عباءة صوفية بلا أكمام + مطرَّز بالذهب على الأطراف — أسود/بني/أبيض | خليجي — المناسبات |
| **الشال** | يُلف حول الوسط فوق حزام الخنجر — من نفس نوع العمامة | — |
| **الصندل** | حذاء جلدي مفتوح | — |

### **ميزة الدشداشة العُمانية** 🟢
- **عنق مستدير** + شريط رفيع (عكس الإماراتي بدون ياقة).
- **الفراخة/الكركوشة:** خيوط متدلية على الصدر + معطَّرة بالبخور.
- **الدشداشة الصورية:** تطرز في الجزء العلوي من الأمام والخلف (نوع فريد من صور).

### **أنواع الخنجر العُماني** 🟢
- **الخنجر السعيدي:** مزيج من التصميمات التقليدية + مقبض مغطى بفضة منقوش عليها آيات قرآنية.
- **الخنجر الصوري:** صغير + خفيف + مقبض مذهَّب (صنع في صور).
- **الخنجر النزوى:** من نزوى — تصميم تقليدي.

---

## 3. اللباس النسائي 🟢

### القطع الأساسية

| القطعة | الوصف | الأصل/الاستخدام |
|---|---|---|
| **الكندورة (الدشداشة)** | رداء طويل ملوَّن + مزركش برسومات + تطريز بخيوط ذهبية/فضية (بريسم/زري) على الأكمام | — يومي + مناسبات |
| **الثوب** | ثوب طويل بأكمام طويلة — يُطرَّز (الردون = الأكمام المطرَّزة بالسيم/الغولي + الخرز + الترتر) + شق الصدر (السفة/السنجاف) | — مناسبات |
| **الثوب الظفاري (أبو ذيل)** | ثوب طويل من الخلف + يطرَّز بأحجار وفصوص لامعة — **ظفار** | — ظفار |
| **السروال** | بنطلون فضفاض + تطريز يدوي بخيوط فضية/ذهبية («النقشة» — أكثر جزء تطريزًا) | — |
| **الشيلة (الوقاية/اللحاف/الليسو/الفتقة)** | غطاء رأس + تزيين بالترتر/الخرز الملون + «الحضية/الشلاشل» (خيوط ملوَّنة متدلية) | — |
| **البرقع/النقاب** | غطاء وجه — بعض النساء | — |
| **الحلي الفضية/الذهبية** | العقام + المرصعات + قلائد الخرز («المنثورة») + الأساور + الأحراز | — |

### **تنوع نسائي جهوي** 🟢
- **الداخلية/جنوب الباطنة:** ثوب قصير (إلى الركبة) + تطريز (السيم/الغولي/الخوصة/البريسم/السنجاف/الزري).
- **الباطنة/مسندم/الظاهرة:** كندورة طويلة ملوَّنة + تطريز بخيوط ذهبية/فضية.
- **صور:** ثوب بثلاث فتحات واسعة + تطريز أمامي وخلفي.
- **ظفار:** الثوب الظفاري (أبو ذيل) — طويل من الخلف + فصوص لامعة.

---

## 4. الأعراس 🟢

- العريس: الدشداشة + البشت + الكمة + العمامة + **الخنجر**.
- العروس: الثوب المطرَّز + السروال («النقشة») + حلي + الحناء.

---

## 5. التطور الحديث 🟢

- **الدشداشة + الكمة + الخنجر:** اللباس الرسمي اليومي + العمل — **محافَظ عليه بقوة**.
- **البشت:** في المناسبات الرسمية + الوجهاء.
- **اللباس الغربي (البدلة/الجينز):** رائج بين الوافدين + بعض الشباب.
- **النساء:** الكندورة + الشيلة — شائع + الثوب المطرَّز في المناسبات.

---

## خلاصة اللباس

اللباس العُماني = **فريد عن باقي الخليج** — الدشداشة (عنق مستدير + الفراخة) + **الكمة** (طاقية مطرَّزة فريدة) + **الخنجر العُماني** (رمز الهوية الوطنية — فضة/ذهب) + العمامة + البشت. اللباس النسائي متنوع جهويًّا (الكندورة + الثوب المطرَّز + السروال «النقشة» + الثوب الظفاري «أبو ذيل»). اللباس التقليدي محافَظ عليه بقوة + مُلزَم في العمل. الخنجر العُماني = **رمز وطني فريد**. 🟢
