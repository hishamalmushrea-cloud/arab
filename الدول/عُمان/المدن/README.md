# مدن عُمان — المرحلة الخامسة

> **المرحلة الخامسة:** ملف لكل **مدينة** موثَّقة داخل **محافظة → ولاية**. ليست إمارة إماراتية ولا منطقة سعودية. 🟢
>
> **مسقط المدينة** في `العواصم/مسقط/` — لا تكرار هنا. ولايات المحافظة الحضرية (السيب/بوشر/مطرح/قريات) هنا لأنها ليست ملف العاصمة.
>
> **السكان:** نشرة المركز الوطني للإحصاء والمعلومات **2022** (سكان **الولاية**) عبر جداول ويكيبيديا المطابقة لنشرة 2023 🟢. حيث وُجد رقم **نواة المدينة** في تعداد **12 ديسمبر 2020** (citypopulation) يُذكر منفصلًا. لا يُخلط سكان **المحافظة** بسكان **الولاية/المدينة** (ظفار 416,458 في 2020 ≠ صلالة المدينة 293,962).
>
> لا تُهمَّش الجيوب والجزر والداخل: مدحاء، دبا مسندم، مصيرة، هيماء، الدقم، قريات.
