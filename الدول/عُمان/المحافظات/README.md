> **المرجع الإداري:** المستوى الأعلى = **محافظة** — **11 محافظة** (مرسوم 114/2011 ثم نظام المحافظات **مرسوم 36/2022**). المستوى الثاني = **ولاية** — **63 ولاية**. المستوى الثالث = **نيابة/مركز** بقرار وزاري. 🟢

## ملاحظة منهجية — لا تخلط الجيوب والولايات

| المكان | المحافظة الصحيحة | ليس |
|---|---|---|
| مدحاء | **مسندم** (جيب داخل الإمارات) | إمارة إماراتية |
| دبا (البيعة) | **مسندم** | دبا الفجيرة / دبا الحصن |
| كلباء / خورفكان | **الشارقة (الإمارات)** | مسندم |
| حتا | **دبي** | البريمي / الظاهرة |
| العين | **أبوظبي** | البريمي (مجاورة فقط) |
| بهلاء / نزوى / جبل شمس / الجبل الأخضر | **الداخلية** | الظاهرة / الباطنة |
| بات والختم والعين الأثرية | **الظاهرة** (عبري) | العين الإماراتية |
| قلهات | **جنوب الشرقية** (صور) | مسقط |
| أرض اللبان / صلالة / الحلانيات | **ظفار** | الوسطى |
| مصيرة | **جنوب الشرقية** | ظفار / الوسطى |
| الدقم | **الوسطى** | ظفار |
| بركاء / المصنعة / نخل | **جنوب الباطنة** | شمال الباطنة |
| الخابورة / السويق / شناص | **شمال الباطنة** | جنوب الباطنة |
| قريات | **مسقط** | جنوب الشرقية |
| سمائل | **الداخلية** | الباطنة |
| سناو | **شمال الشرقية** | الداخلية |

- المسمى: **محافظة → ولاية → نيابة**. ليست إمارة إماراتية ولا منطقة سعودية.
