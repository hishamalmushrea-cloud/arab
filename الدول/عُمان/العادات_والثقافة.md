## 1. الموسيقى والفنون الشعبية 🟢

> عُمان = **ثراء استثنائي في الفنون الشعبية** (13 عنصرًا على قائمة اليونسكو للتراث غير المادي).

### (أ) الرزحة 🟢 — الفن الوطني
- **الوصف:** فن جماعي للرجال — صفوف متقابلة + سيوف/عصي + **تبارز بالسيوف** + مطارحة شعرية (مدح/فخر/شجاعة/هجاء/ألغاز) + الطبل العُماني.
- **الأصل:** **عُماني أصيل** — كان وسيلة إعلان الحرب + حشد المحاربين.
- **المناسبة:** الأعياد + الأعراس + استقبال الضيوف + المناسبات الوطنية.
- **يونسكو 2015.**

### (ب) العازي 🟢
- **الوصف:** نمط إنشاد شعبي — فن السيف والحماسة والحكمة — إنشاد فردي/جماعي + شعر حماسي.
- **يونسكو 2012.**

### (c) العيالة 🟢
- **الوصف:** صفوف متقابلة + تبارز + غناء + طبول — مشترك خليجي.
- **يونسكو 2014.**

### (د) البرعة 🟢 — ظفار
- **الوصف:** فن الرجولة والفروسية — ظفار — شبيب بالرزحة لكن بإيقاع/لحن مختلف.
- **يونسكو 2010.**

### (هـ) التغرود 🟢
- **الوصف:** فن إنشادي — مدح الإبل/الخيل — بدوي.
- **يونسكو 2012.**

### (و) الليوا 🟢
- **الوصف:** فن إفريقي الأصل (من زنجبار/شرق أفريقيا) — حمله العُمانيون من شرق أفريقيا — طبول + رقص.

### (ز) فنون بحرية 🟢
- **النهمة/المديمة:** أغاني البحر — صيد + غوص + إبحار.

### (ح) فنون نسائية 🟢
- **الدان دان:** فنون نسائية — الباطنة/الداخلية.
- **تشح تشح:** فنون نسائية — الشرقية.

## 2. القهوة العُمانية 🟢 — تراث يونسكو

- **الوصف:** قهوة عُمانية — بن أخضر + هيل + زعفران + تمر — ركيزة الضيافة العُمانية.
- **يونسكو:** ضمن قائمة التراث غير المادي.
- **«تُقدَّم في كل مكان»** — رمز الكرم العُماني.

## 3. الأعراس والمناسبات 🟢

### (أ) العرس العُماني — عدة أيام 🟢
- **الخطوبة → الحناء → العرس (الرزحة/العازي/العيالة) → الدخلة.**
- العريس: الدشداشة + البشت + الكمة + الخنجر.
- العروس: الثوب المطرَّز + السروال («النقشة») + حلي + الحناء.
- فنون: الرزحة + العيالة + الهبوت (ظفار).

## 4. العمارة 🟢

### (أ) العمارة التقليدية 🟢
- **قلعة بهلاء** (يونسكو 1987): حصن طيني ضخم + المدينة القديمة — تراث عالمي.
- **حصن نزوى** (الداخلية): أكبر حصن في عُمان — قاعدة دائرية + تاريخ إباضي.
- **حصن الرستاق** + **حصج جبرين** + **حصن صحار** + **حصن مطرح** — حصون/hصون.
- **المدينة القديمة (مسقط):** أزقة + بيوت طين + أسواق + أبواب (باب العلاء/bاب الكبير).
- **الفلج:** نظام الري التقليدي — 4,000+ فلج — **يونسكو 2006**.
- **مسقط القديمة:** مطرح + القرم.

### (ب) العمارة الحديثة 🟢
- **مسجد السلطان قابوس الأكبر** (مسقط — 2001): أحد أضخم المساجد + قبة + صحن + زخارف.
- **المتحف الوطني** (مسقط — 2016).
- **دار الأوبرa** (مسقط).
- **ميناء الدقم** (الوسطى — استراتيجي).
- **مطار مسقط الدولي**.

### (c) المواقع الأثرية 🟢
- **بهلاء** (يونسكو 1987): قلعة + المدينة القديمة.
- **الفلج** (يونسكو 2006): نظام الري.
- **أرض اللبان** (ظفار — يونسكو 2000): أشجار اللُبان + طريق التجارة.
- **قلعة الرستاق** + **قلعة نزوى**.

## 5. الحرف اليدوية 🟢

| الحرفة | الوصف |
|---|---|
| **الخنجر العُماني** | صناعة الخناجر الفضية/الذهبية — رمز وطني |
| **الكمة** | تطريز الكمة العُمانية («التنجيم») |
| **الفلج** | بناء وصيانة قنوات الفلج |
| **صناعة السفن** | سفن خشبية (سنبوك) — تراث بحري |
| **اللُبان** | جمع وتصدير اللُبان الظفاري |
| **الخزف/الفخار** | أواني فخارية (بهلا) |
| **صياغة الفضة/الذهب** | حلي عُمانية تقليدية |
| **نسيج السدو** | نسيج صوفي |

## 6. القيم الاجتماعية 🟢

- **الكرم والضيافة:** قيم عليا — القهوة العُمانية + التمر + المجالس.
- **النخوة/الشهامة/الفروسية:** قيم بدوية.
- **العائلة الممتدة** + احترام الكبار.
- **التسامح الديني-المذهبي:** عُمان = نموذج تعايش (إباضية + سُنة + شيعة + هندوس/مسيحيين).
- **السلام:** سياسة خارجية وساطة (إيران/الغرب + اليمن).

## خلاصة العادات والثقافة

الثقافة العُمانية = **مزيج عُماني-إباضي-خليجي-إفريقي** يتجلى في: **الرزحة** (الفن الوطني — تبارز بالسيوف) + **العازي** + **العيالة** + **البرعة** (ظفار) + **الليوا** (إفريقي) + **القهوة العُمانية** (تراث يونسكو) + **الفلج** (يونسكو) + **بهلاء** (يونسكو) + **أرض اللبان** (يونسكو) + **الخنجر العُماني** (رمز وطني) + **المسجد السلطاني** + **حصون نزوى/الرستاق**. عُمان = **5 مواقع تراث يونسكو** + **13 عنصرًا تراثًا غير مادي** (أكثر دولة عربية في التراث غير المادي) + **نموذج تعايش ديني-مذهبي** + **سياسة وساطة دولية**. 🟢
