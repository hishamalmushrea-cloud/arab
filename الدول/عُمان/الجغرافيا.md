# سلطنة عُمان — الجغرافيا

> منهجية: تربط التضاريس بالمناخ والمياه والثقافة. علامات الثقة: 🟢/🟡/🟠.
> المصادر: ويكيبيديا (جغرافيا عُمان/جبال الحجر)، أرابيكا، arabicatlas، وكالة الأنباء العمانية، sultanqaboos.net.

---

## 1. الموقع والمساحة 🟢

- **أقصى جنوب شرق شبه الجزيرة العربية** — جنوب غرب آسيا.
- **المساحة:** 309,500 كم² — **ثالث أكبر دولة في شبه الجزيرة العربية** (بعد السعودية واليمن).
- **الإحداثيات:** 16°–26°N و51°–60°E.
- **الحدود:** السعودية (غرب، 676 كم) + الإمارات (شمال غرب، 410 كم) + اليمن (جنوب غرب، 288 كم) + خليج عُمان (شمال) + بحر العرب (شرق/جنوب).
- **الساحل:** **3,165 كم** — على خليج عُمان + بحر العرب + مضيق هرمز.
- **الموقع الاستراتيجي:** على **مضيق هرمز** (20% من إمدادات النفط العالمية) — مسندم العُمانية.

---

## 2. التضاريس الكبرى 🟢

> عُمان = **تنوع جغرافي استثنائي** (جبال + صحارى + سواحل + وديان + واحات) — 4 أنماط رئيسية.

### (أ) سلسلة جبال الحجر 🟢 — العمود الفقري
- تمتد من **رأس مسندم** (شمال/مضيق هرمز) إلى **رأس الحد** (شرق) — على شكل قوس — ~700 كم.
- **جبل شمس** (الجبل الأخضر/الداخلية): **3,009 م** — **أعلى قمة في شبه الجزيرة العربية** (وأول نقطة تشرق عليها الشمس في الوطن العربي).
- يقسمها **وادي سمائل** إلى: **الحجر الغربي** (الجبل الأخضر/الرستاق) + **الحجر الشرقي** (سمائل/بدبد).
- **الأثر الثقافي:** زراعة (الجبل الأخضر) + عمارة جبلية + فلج + لُبان.

### (ب) الصحارى 🟢
- **الربع الخالي** (غرب/جنوب غرب): أحد أكبر الصحاري الرملية عالميًّا — غير مأهول + كثبان نجمية.
- **رمال الشرقية** (شرق): كثبان رملية + سياحة صحراوية.
- **82% من مساحة عُمان صحراء** (معظمها رملية/حصوية).

### (c) السهول الساحلية 🟢
- **ساحل الباطنة** (شمال غرب): سهل خصيب بين جبال الحجر والبحر — ~270 كم — **أخصب منطقة في عُمان** + زراعة (تمر/موز/خضراوات).
- **ساحل ظفار** (جنوب): سهل صلالة + الرياح الموسمية (الخريف).
- **ساحل مسقط** (شمال): صخري + خلجان.

### (د) ظفار (الجنوب) 🟢
- **جبال ظفار** (جبال القرا): هضبة جيرية + الرياح الموسمية (يونيو–سبتمبر) → **الخريف الظفاري** (أمطار + مراعي + ضباب) — ظاهرة فريدة.
- **سهل صلالة** الساحلي: خصب + مطيار + لُبان.

### (هـ) الوديان والواحات والفلج 🟢
- **الوديان:** وادي سمائل + وادي بني خالد + وادي غول + وادي الحوقين — موسمية.
- **الواحات:** نزوى + بهلا + البريمي — نخيل + زراعة.
- **الفلج:** نظام الري التقليدي العُماني — **4,000+ فلج** — قنوات تحت أرضية — **تراث يونسكو**.

## 5. المناخ 🟢

> المناخ **متنوع** — صحراوي حار (معظم البلاد) + استوائي موسمي (ظفار) + جبلي معتدل (الحجر).

- **الصيف (معظم عُمان):** حار جدًّا (40–50°م) + جاف.
- **الشتاء:** معتدل (17–24°م) + أمطار شتوية.
- **الجبل الأخضر:** معتدل صيفًا + بارد شتاءً (~16°م + قد تصل للصفر).
- **ظفار (يونيو–سبتمبر):** **الخريف الظفاري** — الرياح الموسمية → أمطار + ضباب + مراعي + اعتدال (~25°م) — **ظاهرة فريدة في شبه الجزيرة العربية**.
- **الأمطار:** قليلة (100–300 مم/سنة في الشمال + <50 مم في الوسط/الربع الخالي + 300+ مم في الجبل الأخضر وظفار).

### ربط الجغرافيا بالثقافة 🟢

| المنطقة | المناخ/التضاريس | الأثر الثقافي |
|---|---|---|
| مسقط/الباطنة (الساحل) | حار رطب + سهل | حضر + تجارة + موانئ + صيد بحري |
| الجبل الأخضر (الداخلية) | معتدل + جبال | زراعة (فواكه/ورد) + فلج + عمارة جبلية |
| ظفار (الجنوب) | موسمي + خريف | لُبان + سياحة الخريف + ثقافة ظفارية |
| الربع الخالي (الغرب/الجنوب) | حار جاف + صحراء | بدوي + رعي + سياحة صحراوية |

## 6. التربة والغطاء النباتي 🟢

- **الباطنة:** تربة رسوبية خصبة — تمر + موز + خضراوات.
- **الجبل الأخضر:** تربة جبلية + غابات (ورد/لوز/خوخ).
- **ظفار:** تربة جيرية + مراعي موسمية + لُبان.
- **الصحراء:** رملية/حصوية — نباتات صحراوية متفرقة.
- **اللُبان:** شجرة اللُبان الظفارية — تراث اقتصادي-ثقافي عُماني.

---

## 7. المناطق الطبيعية والمحميات 🟢

- **محمية جبال القرى** (ظفار) — تنوع حيوي + لُبان.
- **محمية مصيرة** — طيور + سلاحف + حياة بحرية.
- **محمية رمال الشرقية** — كثبان + حياة برية.
- **محمية الجبل الأخضر** — غابات + تنوع نباتي.
- **كهف مجلس الجن** — ثاني أكبر كهف عالمي + اكتشافات.
- **محمية الحلانيات** (جزر) — طيور + حياة بحرية.

## 8. التحديات البيئية 🟡

1. **الحرارة الشديدة** + العواصف الرملية.
2. **ندرة المياه** — اعتماد على الفلج + تحلية.
3. **التصحّر** + زحف الربع الخالي.
4. **البصمة الكربونية** — من النفط/الغاز.
5. **الإعصاران** (غونو 2007 + فايت 2024) — تأثر الساحل.

## خلاصة جغرافية

عُمان = **دولة شاسعة متنوعة** (309,500 كم² — ثالث أكبر في الجزيرة) تجمع بين **جبال الحجر** (جبل شمس 3,009m — أعلى قمة عربية) + **الربع الخالي** (82% صحراء) + **ساحل الباطنة** (أخصب منطقة) + **ظفار** (الخريف الموسمي — ظاهرة فريدة) + **4,000 فلج** (تراث يونسكو) + **ساحل 3,165 كم** (مضيق هرمز → بحر العرب). هذا التنوع (جبال + صحارى + سواحل + موسمي) هو **أساس التباين الثقافي** بين الداخلية (إباضية/فلج/نزوى) + الباطنة (حضر/زراعة) + ظفار (موسمي/لُبان/سُنة) + البادية (بدو/ربع الخالي). 🟢
