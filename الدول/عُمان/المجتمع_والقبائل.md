## 3. القبائل 🟢

> القبيلة = **إطار اجتماعي قوي** في عُمان — أساس النظام السياسي (البوسعيد) + التاريخ (الهناوية/الغافرية).

### (أ) آل بو سعيد — الأسرة الحاكمة 🟢
- **الأصل:** **الأزد** القحطانية (من اليمن → عُمان).
- **الحكم:** عُمان منذ 1749 (أحمد بن سعيد) → 14 سلطان → **هيثم بن طارق** (الحالي).
- **أقدم أسرة حاكمة عربية مستمرة.**

### (ب) الأزد — أكبر القبائل 🟢
- **الأصل:** قحطانية (من اليمن بعد انهيار سد مأرب).
- **الفروع:** آل بو سعيد + النباهنة + بني ريام + بني رواحة + المعاولي + الشحوح + الشرقيون.

### (c) الأحزاب القبلية التاريخية 🟡
- **الحلف الهناوي** (الأزد/القحطانية): الداخلية + نزوى + إزكي + بهلا + بني هناءة + الحبوس + الحرث + الحجريون + المعاولي + الدروع + اليعاربة + بني ريام.
- **الحلف الغافري** (العدنانية): الباطنة + شمال عُمان + بني غافر + الحواسنة + بني عمر + الهدم + الظواهر + القشابرة + القواسم.
- 🟡 **ملاحظة:** التحزب الهناوي/الغافري **لا يرتبط بالنسب** بشكل صارم — كلا الحلفين يضم عدنانية وقحطانية. تُعرض بحياد.

### (د) قبائل بارزة أخرى 🟢
| القبيلة | الأصل | الملاحظة |
|---|---|---|
| **النباهنة** | أزد | حكموا عُمان قرونًا (1500–1624) |
| **اليعاربة** | أزد | طردوا البرتغاليين (1650) |
| **المعاولي** | أزد (زهران) | كبيرة |
| **الشحوح** | أزد | جبال مسندم/ظفار — لغة شحرية |
| **الشرقيون** | أزد | مسندم |
| **البلوش** | بلوشستان | شمال الباطنة/الظاهرة |
| **القواسم** | عدنانية | مسندم/الساحل |
| **الحبوس** | عدنانية | الداخلية |
| **بني هناءة** | أزد | الداخلية |
| **النعيم** | أزد | شمال |
| **الدروع** | أزد | عُمان + الإمارات |
| **الجنبة** | قحطانية | ظفار |

## 4. الدين 🟢

| الدين | النسبة | التفاصيل | الثقة |
|---|---|---|---|
| **الإسلام** | ~95% | **إباضية ~45%** (أغلبية المواطنين) + **سُنة ~45%** (مالكية/شافعية — ظفار/السواحل) + **شيعة ~5%** (مسقط/مطرح) | 🟢 |
| **الهندوسية** | ~5% (وافدون) | هنود | 🟢 |
| **المسيحية** | ~3.6% (وافدون) | كاثوليك + بروتستانت | 🟢 |
| **أخرى** | ~1% | بهائية + بوذية | 🟢 |

### الإسلام في عُمان 🟢
- دستوريًّا: **الإسلام الدين الرسمي** + الشريعة مصدر التشريع.
- **المذهب الإباضي:** **~45% من المواطنين** — عُمان = **معقل الإباضية عالميًّا** — مذهب فريد (لا سُنة ولا شيعة) — منذ القرن 1 هجري.
- **السُّنة:** ~45% — مالكية + شافعية + حنبلية — يتركزون في **ظفار** (الساحل الجنوبي) + مسقط + الباطنة.
- **الشيعة:** ~5% — مسقط + مطرح (ال LAWATIA = الجمعية الشيعية العُمانية).
- **التسامح:** عُمان = **نموذج تعايش ديني-مذهبي** (إباضية + سُنة + شيعة + هندوس + مسيحيون + بهائيون).

> 🟢 **الحياد:** التقسيم المذهبي (إباضية/سُنة/شيعة) تُعرض بحياد — عُمان = نموذج تعايش.

## 5. الهوية الوطنية 🟢

- **الهوية = عربية-إسلامية-إباضية-خليجية-عُمانية** متجانسة.
- **القبيلة** إطار اجتماعي قوي (البوسعيد/الأزد).
- **الخنجر العُماني** + **الكمة** + **الدشداشة** = رموز الهوية.
- **القهوة العُمانية** = ضيافة.
- **اللغة:** العربية (رسمية) + اللهجات العُمانية + لغات محلية (شحرية/بلوشية/سواحيلية).
- **التسامح:** قيمة وطنية + سياسة وساطة دولية.

## 6. لامساواة/تحديات اجتماعية 🟡

- **التركيبة السكانية:** 57% عمانيين + 43% وافدين — أقل حدة من جيران.
- **البطالة بين العمانيين** + «التعمين» (إحلال العمالة الوطنية).
- **اللامساواة الجهوية:** مسقط/الباطنة متقدِّمة vs الوسطى/مسندم متأخرة.
- **التوتر المذهبي** (إباضية/سُنة) — محدود لكن تاريخي (الهناوية/الغافرية) 🟡.

## 7. الحركات والتنظيمات الاجتماعية 🟢

- **المجالس** — مؤسسة اجتماعية-سياسية.
- **مجلس الشورى العُماني** — نصف منتخَب (1991 — أول مجلس شورى).
- **مجلس الدولة** — معيَّن.
- **المرأة العُمانية:** مشاركة متنامية (وزيرات + نائبات + رياضيات + تعليم).
- **الشباب:** قوة تغيير + رؤية 2040.

## خلاصة المجتمع

مجتمع عُمان = **مجتمع متجانس نسبيًّا** (57% عمانيين + 43% وافدين) + **معقل الإباضية عالميًّا** (~45% من المواطنين) + سُنة (~45% — ظفار) + شيعة (~5%). القبائل: **آل بو سعيد** (الأزد — الحاكمة) + النباهنة + اليعاربة + المعاولي + الشحوح + البلوش + الحبوس + القواسم + الأحزاب التاريخية (الهناوية/الغافرية). الهوية = عربية-إسلامية-إباضية-عُمانية + الخنجر + الكمة + القهوة العُمانية + التسامح. التحديات: التركيبة السكانية + البطالة + اللامساواة الجهوية + التاريخ المذهبي (الهناوية/الغافرية). عُمان = **نموذج تعايش ديني-مذهبي**. 🟢/🟡
