# سلطنة عُمان — الطعام والمطبخ

> منهجية: لكل طبق يُذكَر اسمه المحلي + المكونات + المناسبة + المنطقة + الأصل.
> المصادر: elaph، lnkoman، alwatanpress، om77.net، alkhabarkw، sayidaty، connsect.

---

## 1. نظرة عامه 🟢

> المطبخ العُماني = خليط **عُماني أصيل + خليجي + هندي/فارسي (تجارة) + إفريقي (زنجبار) + ظفاري (يمني)**. سمة الغالبة: **البهارات العُمانية (البذار/اللومي/الزعفران/الهيل)** + الأرز + اللحم + القمح + السمك + **القهوة العُمانية**.

- **الأرز:** ركيزة الأطباق الرئيسية.
- **اللحم:** ضأن + ماعز + دجاج + سمك + روبيان.
- **القمح:** الهريس + العرسية (بدوي/داخلية).
- **البهارات:** البذار (خلطة عُمانية) + لومي + زعفران + هيل + كمون + قرفة.
- **التمر + القهوة العُمانية:** ضيافة — بن أخضر + هيل + زعفران.
- **الشوا:** طهي تحت الأرض — ميزة عُمانية فريدة.

---

## 2. الأطباق الرئيسية

### (1) الشوا 🟢 — الطبق الوطني (ظفار/المناسبات)
- **الوصف:** لحم ضأن/ماعز كامل يُتبَّل بالبذار + يُلف في ورق الموز/النخيل + يُدفن في حفرة تحت الأرض + يُطهى ببطء لساعات/ليلة كاملة.
- **المناسبة:** الأعياد + الأعراس + المناسبات الكبرى — «ملك الأطباق العُمانية».
- **الأصل:** **عُماني فريد** — لا يوجد في مكان آخر.

### (2) القبولي (المكبوس) 🟢
- **الوصف:** أرز + لحم/دجاج + بهارات (بذار + لومي + زعفران) + حمص مجروش + زبيب + بطاطا.
- **المناسبة:** الولائم + الأعراس + يومي.

### (3) الهريس 🟢 — رمضان
- **الوصف:** قمح مجروش + لحم → يُطهى ساعات حتى يصير عصيدة ناعمة + سمن.
- **المناسبة:** **رمضان** + المناسبات.

### (4) العرسية 🟢 — سيدة المطبخ العُماني (الأعياد)
- **الوصف:** أرز مهروس + دجاج/لحم → يُطهى حتى ينعقد (شبيب بالهريس لكن بقوام متماسك).
- **المناسبة:** **صبيحة العيد** — «سيدة الأطباق في العيد» + تُزاحم الحلويات.
- **الأصل:** عُماني تقليدي.

### (5) الثريد 🟢 — رمضان
- **الوصف:** خبز الرقاق + مرق لحم + خضار — رمضاني.

### (6) المضروبة 🟢
- **الوصف:** أرز + دجاج/سمك → يُضرب حتى ينعقد + بهارات.

### (7) البرياني 🟢
- **الوصف:** أرز + لحم/دجاج + بهارات — شبيب بالخليجي.

### (8) السالونة 🟢
- **الوصف:** مرق لحم/سمك/دجاج + طماطم + بطاطا + فلفل + بهارات — يُقدَّم مع الأرز.

### (9) العوال 🟢 — بحري
- **الوصف:** نوع سمك يُعدّ بطريقة عُمانية — ساحل.

### (10) القاشع 🟢
- **الوصف:** سمك البلميدة المجفف — ظفار.

### (11) المعجون العُماني 🟢
- **الوصف:** شرائح لحم مجففة + نكهة مدخنة — ظفار.

## 3. الحلويات 🟢

| الحلوى | الوصف | المناسبة |
|---|---|---|
| **الحلوى العُمانية** | سكر + نشا + ماء ورد + زعفران + هيل + مكسرات — **أشهر حلوى عُمانية** | ضيافة + الأعياد + مع القهوة |
| **اللقيمات** | كرات عجين مقلية + دبس التمر/العسل | رمضان + الأعياد |
| **الخبيصة** | دقيق/سميد + سكر + زعفران | — |
| **البثيثة** | تمر + دقيق + زبدة | — |
| **القشاط** | طحين + عسل + سكر (مربعات) | — |
| **العصيدة** | دقيق/تمر + سمن | — |
| **الساقو** | ساغو + سكر + حليب | رمضان |

---

## 4. الخبز والمشروبات والضيافة 🟢

- **القهوة العُمانية:** ركيزة الضيافة — **بن أخضر** + هيل + زعفران + تمر — «تُقدَّم في كل مكان» — تراث يونسكو.
- **شاي الكرك/العُماني:** شاي + حليب + سكر.
- **التمر:** ضيافة يومية (خاصة العُماني).
- **خبز الرقاق:** أساسي مع الثريد.
- **اللبن العُماني:** لبن جاهز.

---

## 5. مأكولات رمضان والأعياد 🟢

- **الإفطار:** تمرة + هريس + ثريد + قبولي + لقيمات.
- **العيد:** **العرسية** (سيدة العيد) + الشوا + اللحم المقلي + الخبز + العسل + الحلوى العُمانية.

---

## 6. ربط الطعام بالجغرافيا 🟢

| المنطقة | الأطباق المميزة | السبب |
|---|---|---|
| مسقط/الباطنة (الساحل) | قبولي/مكبوس + العوال (سمك) + سالونة | بحري + صيد + تجارة |
| الداخلية (الجبال/الفلج) | الهريس + العرسية + الثريد + لحم | بدوي/فلاحي + قمح + فلج |
| ظفار (الجنوب) | الشوا + القاشع + المعجون العُماني | ظفاري + يمني + إفريقي |
| البادية (الصحراء) | الهريس + الجريش + لحم | بدوي + رعي |

---

## 7. ملاحظات ثقافية 🟢

- **الشوا = الطبق الوطني** — طهي تحت الأرض — ميزة عُمانية فريدة.
- **العرسية = سيدة العيد** — «تُزاحم الحلويات في العيد».
- **الحلوى العُمانية = رمز الضيافة** — مع القهوة العُمانية.
- **القهوة العُمانية = تراث يونسكو** — بن أخضر + هيل + زعفران.
- **البذار = البصمة العُمانية** — خلطة بهارات فريدة.
- **الإرث الإفريقي:** بعض الأطباق من زنجبار/شرق أفريقيا (إمبراطورية عُمان).

---

## خلاصة الطعام

المطبخ العُماني = **مطبخ متوسطي-خليجي-إفريقي-ظفاري بهاراتي** قائم على الشوا (الطبق الوطني — طهي تحت الأرض) + القبولي + الهريس (رمضان) + العرسية (العيد) + الحلوى العُمانية + القهوة العُمانية (تراث يونسكو). تتمايز الأطباق: بحري (سمك) على الساحل + بدوي/فلاحي (قمح/لحم) في الداخلية + ظفاري (شوا/قاشع) في الجنوب. البذار + اللومي + الزعفران = البصمة العُمانية. 🟢
