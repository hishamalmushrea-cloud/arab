## أهم ما يميز عُمان

- **ثالث أكبر دولة في شبه الجزيرة العربية** مساحةً (309,500 كم²) — 82% صحراء.
- **معقل المذهب الإباضي عالميًّا** (~45% من المواطنين) — ميزة فريدة.
- **أقدم أسرة حاكمة عربية مستمرة** (البوسعيدية منذ 1749) — 14 سلطان.
- **السلطان قابوس** («باني النهضة» — 50 سنة — أطول حاكم عربي).
- **5 مواقع تراث يونسكو** (بهلاء/الفلج/أرض اللبان).
- **13 عنصرًا تراثًا غير مادي** (أكثر دولة عربية) — الرزحة/العازي/العيالة/البرعة/القهوة.
- **الخنجر العُماني** + **الكمة** = رموز الهوية الوطنية.
- **جبل شمس** (3,009m) = أعلى قمة في شبه الجزيرة العربية.
- **الفلج** (4,000+) = نظام ري تراثي فريد (يونسكو).
- **الخريف الظفاري** = ظاهرة مناخية فريدة (الرياح الموسمية).
- **رؤية عُمان 2040** = تنويع اقتصادي (سياحة/لوجستيات/صناعة/صيد/تعدين).
- **مضيق هرمز** (مسندم) = موقع استراتيجي عالمي.
- **نموذج تعايش ديني-مذهبي** (إباضية + سُنة + شيعة + هندوس + مسيحيون).

## أهم المناطق

- **مسقط:** العاصمة + الحضر + الميناء + المطار + المسجد السلطاني.
- **الباطنة (شمال/جنوب):** ساحل + زراعة + صناعة (صحار).
- **الداخلية (نزوى):** الجبل الأخضر + الفلج + نزوى التاريخية + إباضية.
- **ظفار (صلالة):** جنوب + الخريف + اللُبان + سياحة.
- **الوسطى (الدقم):** أكبر محافظة مساحةً + ميناء استراتيجي.
- **مسندم:** جيب شمالي + مضيق هرمز.

6. **الخنجر العُماني** + **الكمة** = رموز الهوية الوطنية.
7. **جبل شمس** (3,009m) = أعلى قمة في شبه الجزيرة العربية.
8. **الفلج** (4,000+) = نظام ري تراثي فريد (يونسكو).
