## 2. النباهنة واليعاربة (القرن 15–18)

| الفترة | الحدث | التصنيف |
|---|---|---|
| القرن 15–17 | **النباهنة** حكموا عُمان قرونًا (1500–1624). | 🟢 |
| **1507** | **الاحتلال البرتغالي** — البرتغاليون يحتلون مسقط + الساحل العُماني. | 🟢 |
| **1624** | **الدولة اليعربية** — **ناصر بن مرشد اليعربي** أول إمام → توحيد القبائل + مقاومة البرتغاليين. | 🟢 |
| **1650** | **تحرير مسقط** — **سلطان بن سيف اليعربي** يطرد البرتغاليين نهائيًّا من عُمان. | 🟢 |
| **1692** | استرجاع ممباسا + كلوة + زنجبار من البرتغاليين (سيف بن سلطان اليعربي). | 🟢 |
| 1718 | انقسام عُمان بعد وفاة سلطان الثاني → **الحلف الهناوي vs الحلف الغافري**. | 🟢 |
| **1743–1749** | الغزو الفارسي + انهيار دولة اليعاربة. | 🟢 |

> 🟢 اليعاربة = **أول دولة عُمانية مركزية حديثة** + طرد البرتغاليين + بناء إمبراطورية بحرية.

## 3. الدولة البوسعيدية (1749–الحاضر)

| الفترة | الحدث | التصنيف |
|---|---|---|
| **1749** | **أحمد بن سعيد البوسعيدي** يطرد الفرس → **مؤسس الدولة البوسعيدية** (أقدم أسرة حاكمة عربية مستمرة). | 🟢 |
| **1784–1792** | حمد بن سعيد ينقل العاصمة من الرستاق إلى **مسقط**. | 🟢 |
| **1804–1856** | **سعيد بن سلطان** — «العصر الذهبي» → إمبراطورية عُمانية تمتد من الهند إلى زنجبار + شرق أفريقيا. | 🟢 |
| **1856** | وفاة سعيد بن سلطان → **انقسام الإمبراطورية** إلى سلطنة مسقط وعُمان + سلطنة زنجبار. | 🟢 |
| 1891 | **الحماية البريطانية** — معاهدة الصداقة (فيصل بن تركي + بريطانيا). | 🟢 |

## 5. عهد السلطان قابوس — النهضة (1970–2020)

| الفترة | الحدث | التصنيف |
|---|---|---|
| **23 يوليو 1970** | **السلطان قابوس بن سعيد** يتولى الحكم (انقلاب أبيض على والده سعيد) → **بدء النهضة العُمانية الحديثة**. | 🟢 |
| 1970–2020 | **50 سنة** من الحكم — بناء دولة حديثة + بنية تحتية + تعليم + صحة + جيش + تنويع اقتصادي. | 🟢 |
| **1971** | انتهاء الحماية البريطانية + انضمام عُمان للأمم المتحدة + جامعة الدول العربية. | 🟢 |
| **1981** | عُمان عضو مؤسِّس في **مجلس التعاون الخليجي**. | 🟢 |
| 2000s | تنويع اقتصادي + سياحة + صناعة + الدقم. | 🟢 |
| **2013** | تشكيل **اللجنة الرئيسية للرؤية المستقبلية «عُمان 2040»** (رئيس: هيثم بن طارق). | 🟢 |
| **10 يناير 2020** | وفاة السلطان قابوس (79 سنة) — **أطول حاكم عربي** (50 سنة). | 🟢 |

> 🟢 قابوس = **«باني النهضة العُمانية الحديثة»** — نقل عُمان من العصور الوسطى إلى العصر الحديث في 50 سنة.

## خلاصة المسار التاريخي

عُمان = **أقدم دولة عربية مستقلة** + **معقل الإباضية** + **أقدم أسرة حاكمة عربية مستمرة** (البوسعيدية منذ 1749). تأسست كمملكة مجان (3000 ق.م) → آل الجلندي (629) → الإمامة الإباضية (751) → النباهنة → اليعاربة (طرد البرتغاليين 1650) → **البوسعيدية** (1749) + إمبراطورية سعيد بن سلطان (الهند→زنجبار) → الحماية البريطانية → **النهضة القابوسية** (1970–2020) → **هيثم بن طارق** (2020–). عُمان = **دولة عريقة بحضارة بحرية + إمامة إباضية + استمرارية بوسعيدية**. 🟢
