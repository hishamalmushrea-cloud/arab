> منهجية: لكل لهجة تُذكَر مناطق انتشارها وخصائص النطق ومفردات مميزة. تُذكر كل لفظة: الكلمة ← النطق التقريبي ← المعنى بالفصحى ← المنطقة ← مثال ← ملاحظات.

## 1. اللغات واللهجات: نظرة عامة 🟢

- **اللغة الرسمية:** العربية (الفصحى في الإدارة/التعليم/الإعلام).
- **العبرية:** بين فلسطينيي 1948 (الذين يحملون الجنسية الإسرائيلية) + في القدس/الضفة (التعامل مع الإسرائيليين).
- **الإنجليزية:** محدودة (السياحة/الأكاديميا).
- **اللهجة الفلسطينية:** شامية جنوبية — قريبة من الأردنية/اللبنانية/السورية الجنوبية. تنوع كبير بين المدن/القرى/البادية/غزة.
- **اللهجة البيضاء (المشتركة):** وسط بين اللهجات — مفهومة عربيًّا.

## 2. اللهجات الفلسطينية الكبرى 🟢

### (أ) اللهجة المدنية (المدن) 🟢 — القدس/يافا/نابلس/الخليل/حيفا/عكا
- **خصائص النطق:**
  - **القاف تُنطق همزة**: «قال» → «آل»، «قتل» → «أتَل»، «قريب» → «أريب». 🟢
  - قريبة من اللهجات الشامية الشمالية (دمشق/بيروت).
  - نبرة حضرية ناعمة.
- **مفردات:** «شو» (ماذا)، «ليش» (لماذا)، «وين» (أين)، «هَلّق» (الآن).

### (ب) اللهجة القروية (الفلاحية) 🟢 — قرى الضفة/الجليل
- **خصائص النطق:**
  - **الكاف تُقلب شينًا معطشة (ch)**: «كيف حالك» → «تشيف حالك» (تشرم) — «كلب» → «تشلب». 🟢 (سمة قروية فلسطينية مميزة).
  - **القاف تُقلب كافًا**: «قتل» → «كتل»، «قلم» → «كلم»، «قال» → «كال». 🟢 (طولكرم/جنين/قلقيلية).
  - **العنعنة** (إبدال الهمزة عينًا): «أن» → «عن» (بدو/قرى).
  - **قلب العين نونًا**: «أعطيني» → «انطيني» (شمال — يمنية/بدوية).
  - **قلب الضاد ظاءً**: «ضربني» → «ظربني».
  - **كسر نهاية الكلمة**: «طاولة» → «طاولي»، «حلوة» → «حلوي» (الضفة).
- **مفردات:** قريبة من اللهجة البدوية/الحورانية.

### (ج) اللهجة البدوية 🟢 — النقب/الجنوب/بادية الضفة
- **خصائص:**
  - القاف تُنطق **g** (الجيم الحنكية) — بدوية أصيلة.
  - العنعنة (إبدال الهمزة عينًا).
  - أقرب للهجات بدو الجزيرة/سيناء/الأردن.
- **القبائل:** الترابين/الحمالات/العزازمة/الحناجرة (النقب) + الكعابنة/الجهالين (بادية الضفة).

### (د) اللهجة الغزاوية (قطاع غزة) 🟢
- **خصائص:**
  - **القاف تُضخَّم** (مثل الجيم المصرية/القاف البدوية الخليجية): «قال» → «گال». 🟢
  - متأثرة باللهجة **المصرية** (الإدارة المصرية 1948–1967 + الجوار): «هلَّأ» (الآن)، «إديني» (أعطيني)، «كندرة» (حذاء)، «يمَّه» (أمي)، «ياخي» (أخي).
  - **فتح نهاية الكلمة** (بدل كسر الضفة): «طاولة» (بدل «طاولي»)، «حلوة» (بدل «حلوي»).
  - نبرة قوية/ساحلية.
- **مفردات مصرية/بدوية:** «كبّاية» (كوب)، «أواعي» (ملابس)، «أبضاي» (قوي).

## 5. ملاحظات على التطور اللهجي

- **الجذور:** كنعانية/آرامية (Substrat) + عربية (بعد الفتح) + بدوية (القبائل) + مصرية (غزة — الإدارة 1948–1967) + أردنية (الضفة — الإدارة 1948–1967) + عبرية (فلسطينيو 1948).
- **التمايز الإقليمي:** المدن (قاف همزة — شامية) × القرى (كاف شين + قاف كاف — فلاحية) × البادية (قاف g — بدوية) × غزة (قاف مضخَّم + مصرية).
- **التأثير التاريخي:** الضفة تحت الأردن (1948–1967) → مفردات أردنية/شامية؛ غزة تحت مصر (1948–1967) → مفردات مصرية.
- **فلسطينيو 1948:** يتحدثون الدارجة الفلسطينية + العبرية (ثنائية لغوية).
- **الشتات الفلسطيني:** اللاجئون في الأردن/لبنان/سوريا/الخليج يحافظون على اللهجة الفلسطينية + يتأثرون بلهجات بلدان اللجوء.
- **الإعلام:** اللهجة الفلسطينية (المدنية) منتشرة عبر الإعلام/الدراما الفلسطينية/السورية/الأردنية — مفهومة لكل العرب.
