## 2. اللباس الرجالي 🟢

### القطع الأساسية

| القطعة | الوصف | المنطقة/الاستخدام |
|---|---|---|
| **القنباز (القمباز)** | رداء طويل فضفاض (أبيض/داكن) | المدن — تاريخي |
| **الدامر (السديري)** | سترة قصيرة فوق القمباز | المدن |
| **السروال** | فضفاض تحت القمباز | — |
| **الكوفية (الحطة)** | غطاء رأس مربع — أبيض/أسود (المعروف) أو أبيض/أحمر | كل فلسطين — **رمز وطني فلسطيني** 🟢 |
| **العقال** | حبل أسود يثبّت الكوفية | رمز الرجولة |

| **الجلابية (الثوب)** | رداء طويل قطني/صوفي | الريف/البادية |
| **العباءة** | رداء خارجي صوف | البادية/المناسبات |
| **البلغة (البابوش)** | حذاء جلدي | مع القمباز |

### الكوفية الفلسطينية 🟢 — رمز الهوية
- **الكوفية البيضاء/السوداء** (الحطة) — رمز وطني فلسطيني منذ ثورة 1936 (اعتمدها الثوار بدل الطربوش). 🟢
- **العقال** — يميِّز الرجل.
- **الكوفية الحمراء** — أيضاً مستخدمة (أقل شيوعًا من البيضاء/السوداء).
- **الأثر الحالي:** الكوفية الفلسطينية رمز النضال الفلسطيني عالميًّا.

## 3. اللباس النسائي 🟢 — الثوب المطرَّز (تراث يونسكو)

### (أ) الثوب الفلسطيني (الجلاية/الثوب) 🟢
- **الوصف:** ثوب طويل (قطني/كتاني/حريري) + **تطريز يدوي** بخيوط حرير/قطن ملوّنة — كل منطقة لها أنماطها:
  - **ثوب رام الله:** أبيض + تطريز أحمر/أسود (صليبية/هندسية) — أشهر.
  - **ثوب بيت لحم:** حرير + تطريز ذهبي/فضي (الصلصة) — فاخر.
  - **ثوب الخليل:** أسود + تطريز أحمر/أخضر (المردّن).
  - **ثوب نابلس:** قطني + تطريز هندسي.
  - **ثوب القدس (أبو قطبة):** حرير حمصي + تطريز فاخر.
  - **ثوب الجليل:** مفتوح (الروب) — أبيض/ملوّن.
  - **ثوب غزة:** أسود + تطريز أحمر/بنفسجي.
  - **ثوب أريحا (الصاية):** أسود طويل (20 ذراعًا) + تطريز ممتد من الكتفين.
  - **ثوب البدوية:** أسود + تطريز + حلي فضية/مرجان.
- **التطريز (التتريز):** 🟢
  - **القبة:** تطريز الصدر.
  - **الزوائد:** تطريز الأكمام.
  - **البنايق/المناجل:** تطريز الجوانب.
  - **أسفل الظهر:** تطريز مساحات.

### (ب) المعاطف النسائية 🟢
- **الصدرية/التقصيرة/القفطان/الصلصة** — فوق الثوب.

### (ج) غطاء الرأس النسائي 🟢
- **الحطة/المنديل المطرَّز/الطرحة** — غطاء رأس.
- **الشطوة (العصبة):** طاقية + صفوف من النقود الفضية + المرجان (ريف).
- **الطفطاف/الشكة/العرقية:** نقود فضية (الخليل/القدس/يافا).
- **القنعة:** قطن أسود + نقود فضية (بئر السبع).
- **البرقع:** غطاء وجه + نقود فضية (بدويات/بئر السبع).

### (د) الزي البدوي 🟢
- **النساء:** ثوب أسود + تطريز + جبة مطرَّزة + حلي فضية/مرجان + البرقع.
- **الرجال:** جلابية + كوفية + عقال + عباءة + خنجر.

---

## 4. الحلي والمجوهرات 🟢

- **النقود الفضية:** على الرأس (الشطوة/الطفطاف) — صفوف.
- **الأقراط:** مثلثة الشكل + سلاسل + كهرمان.
- **المرجان:** على الرأس (البدويات).
- **الذهب:** في المناسبات (القدس/بيت لحم).
- **الخنجر:** للرجال (البادية).

---

## 5. اللباس التاريخي 🟢

- **الكنعاني/اليبوسي:** تاريخي.
- **البيزنطي/الإسلامي:** تاريخي (القدس/الخليل).
- **العثماني:** القمباز + الطربوش + الكوفية (تاريخي).
- **الثورة 1936:** الكوفية/العقال تحل محل الطربوش — رمز وطني.
- **النكبة 1948 + الشتات:** الحفاظ على الثوب المطرَّز + الكوفية في الشتات.
- **الحديث:** ملابس غربية في المدن + الثوب/الكوفية في المناسبات/التراث.

## 6. الفروق بحسب البيئة 🟢

| البيئة | اللباس | السبب |
|---|---|---|
| المدن (القدس/نابلس/يافا/الخليل) | القمباز + الطربوش (تاريخي)/الكوفية + ثوب مطرَّز فاخر (نساء) | حضري + تجارة |
| المرتفعات (رام الله/بيت لحم/نابلس) | الثوب المطرَّز (أنماط كل منطقة) + الكوفية/العقال | زراعة (زيتون) + هوية قروية |
| الأغوار (أريحا) | الصاية السوداء + تطريز ممتد | مناخ استوائي |
| قطاع غزة | ثوب أسود + تطريز + تأثير مصري/ساحلي | ساحل + جوار مصري |
| البادية (النقب/الجنوب) | الجلابية + الكوفية/العقال + العباءة + البرقع (نساء) + حلي فضية | بدو + رعي |

## 7. التطور الحديث 🟢

- **الكوفية الفلسطينية** رمز وطني عالمي (تُلبس في المظاهرات/التضامن الدولي).
- **التطريز الفلسطيني (Tatreez)** تراث يونسكو 2021 🟢 — حرفية محفوظة + مشاريع نسائية.
- **الثوب المطرَّز** في المناسبات/الأعراس/التراث + ملابس حديثة يوميًّا.
- **الحجاب/النقاب:** في الأوساط المحافظة (غزة/بعض الضفة).
- **الشتات:** الحفاظ على الثوب/الكوفية في الأردن/لبنان/سوريا/الخليج.
