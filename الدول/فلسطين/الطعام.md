# دولة فلسطين — الطعام (المطبخ الفلسطيني)

> منهجية: لا تُنسب الأطباق إلى «فلسطين» ككتلة بل إلى منشئها حيثما أمكن. كل طبق يُربَط بمكانه.
> المصادر: ويكيبيديا (مطبخ فلسطيني)، أرابيكا (مطبخ فلسطيني)، botanydwelling، arab48، pal48.ps.

---

## 1. نظرة عامة 🟢

- **المطبخ الفلسطيني:** جزء من المطبخ الشامي — يعتمد على **زيت الزيتون** (العمود الفقري) + القمح/البرغل/الفريكة + الحبوب (الحمص/العدس) + السماق + الخضار الموسمية.
- **الجذور:** كنعاني/شامي + بدوي + متوسطي + عثماني.
- **الارتباط بالأرض:** موسم قطف الزيتون (الخريف) — رمز الهوية الفلسطينية.
- **الانتشار:** عالمي عبر الشتات الفلسطيني + المطاعم الفلسطينية/الشامية.

---

## 2. الأطباق الوطنية الكبرى 🟢

### (1) المسخن 🟢 — الطبق الوطني الفلسطيني
- **الأصل:** شمال فلسطين (جنين/طولكرم) — أصيل فلسطيني.
- **الوصف:** **خبز الطابون** + دجاج مشوي + بصل مقلي + **سماق** + زيت زيتون + صنوبر — يُخبز في الفرن.
- **المناسبة:** موسم قطف الزيتون (الخريف) — رمز الهوية + الضيافة.
- **الانتشار:** كل فلسطين + الشتات — **لا يُعرف خارج فلسطين** (فلسطيني أصيل 100%). 🟢

### (2) المقلوبة 🟢 — شامي/فلسطيني
- **الأصل:** الشام (فلسطين/الأردن/سوريا — مشترك).
- **الوصف:** أرز + لحم/دجاج + باذنجان/زهرة/فول → تُقلب في صحن التقديم.
- **المناسبة:** غداء الجمعة + المناسبات.

### (3) الكنافة النابلسية 🟢 — نابلس أصيلة
- **الأصل:** نابلس (فلسطين) — انتشرت عالميًّا.
- **الوصف:** عجين الكنافة (الخشنة) + جبنة عكاوي/قشطة + شراب سكر + مكسرات + لون برتقالي.
- **المناسبة:** رمضان/المناسبات.
- **الانتشار:** كل العالم العربي + عالميًّا (نسبة إلى نابلس).

### (4) القدرة الخليلية 🟢 — الخليل أصيلة
- **الأصل:** الخليل.
- **الوصف:** أرز + لحم غنم + ثوم كامل + حمص حب + سمن — تُطهى في فرن الحطب داخل **قدر نحاسي**.
- **المناسبة:** الأعراس/الجمعات/المناسبات الكبرى.

### (5) المفتول (الكسكسي الفلسطيني) 🟢 — فلسطيني/شامي
- **الأصل:** فلسطين (الأرياف + غزة).
- **الوصف:** برغل/كسكسي مفتول يدويًّا + حمص + قرع + مرق دجاج/لحم — يُطهى على البخار.
- **المناسبة:** الشتاء/المناسبات.

## 3. أطباق أخرى بارزة 🟢

| الطبق | الأصل/المنطقة | الوصف | المناسبة |
|---|---|---|---|
| **السمّاقية** | غزة أصيلة | لحم + سماق + خبز + حمص — حلو/مالح (لا تطبخ خارج غزة) | مناسبات غزاوية |
| **الزرب** | بدوي/جنوب | لحم + أرز في حفرة (تنور) | وليمة بدوية |
| **ورق العنب (الدوالي)** | شامي/فلسطيني | ورق عنب محشو بأرز/لحم | مناسبات/رمضان |
| **المحاشي** | شامي | كوسا/باذنجان/فلفل/كرنب محشو | مناسبات |
| **الكبة (النابلسية)** | نابلس | برغل + لحم — مقلية/نية | وليمة |
| **الصيادية** | غزة/ساحل | أرز + سمك (ساحلي) | غداء |
| **الفتّوش/التبولة** | شامي | سلطة + خبز/برغل | مقبلات |
| **الحمص بطحينة/الفتة** | شامي | حمص + طحينة + خبز | مقبلات/فطار |
| **السلطة الفلاحية** | فلسطيني | خيار/طماطم/بصل/زيت زيتون/ليمون | مقبلات |
| **المناقيش** | شامي/فلسطيني | خبز + زعتر/جبن/لحم | فطار |
| **الصفيحة** | شامي | فطيرة لحم مفتوحة | وليمة |
| **الفريكة** | شامي | قمح أخضر محمَّص + لحم | شتوي |
| **البيصارة** | شامي | فول مجفف + زيت زيتون | فطار |
| **الكشك** | شامي/فلسطيني | لبن + قمح + مرق | شتوي |
| **الششبرك** | شامي | عجين محشى بلحم + لبن | مناسبات |
| **المجدرة** | شامي | عدس + برغل/أرز + بصل | يومي/صيامي |
| **الفول المدمس** | مصري/شامي | فول مدمس + زيت + ليمون | فطار |

---

## 4. الخبز 🟢

- **خبز الطابون** — خبز فلسطيني أصيل (على الحجارة الساخنة في فرن طيني) — أساس المسخن.
- **خبز التنور** — في الريف/البادية.
- **الخبز العربي (البيتا)** — حضري.
- **المناقيش** — خبز + زعتر/جبن.

---

## 5. المشروبات والحلويات 🟢

- **القهوة العربية** — مع الهيل، رمز الضيافة البدوية/الفلسطينية.
- **الشاي** — مع النعناع/المريمية.
- **عرقسوس/تمر هندي/قمر الدين/خروب** — رمضانية.
- **الحلويات:**
  - **الكنافة النابلسية** (نابلس — عالمي الصيت).
  - **الكعك/المعمول المقدسي** (القدس — أعياد).
  - **النمورة/المدلوقة النابلسية** (نابلس).
  - **كعك القزحة** (حبة البركة).
  - **الحلبة/الهريسة (البسبوسة)**.
  - **الزلابية/القطايف** (رمضان).

---

## 6. المأكولات بحسب البيئة (ربط الجغرافيا بالطعام) 🟢

| البيئة | أطعمة بارزة | السبب |
|---|---|---|
| شمال الضفة (جنين/طولكرم/نابلس) | المسخن + الكنافة (نابلس) + الكبة + الزيتون/زيت الزيتون | زيتون + سهول + قمح |
| وسط الضفة (القدس/رام الله/بيت لحم) | المقلوبة + المحاشي + المناقيش + القدرة | مرتفعات + زيتون + مدن |
| جنوب الضفة (الخليل) | القدرة الخليلية + الزرب (بدوي) + اللحم | جبال + بدو + أغنام |
| الأغوار (أريحا/طوباس) | الموز/التمر/الخضر الاستوائية | مناخ استوائي |
| قطاع غزة | السمّاقية + الصيادية (سمك) + المفتول + تأثير مصري | ساحل + جوار مصري |
| البادية (النقب/جنوب) | الزرب + القهوة العربية + المنسف (بدوي) | بدو + رعي |

---

## 7. أطعمة المناسبات 🟢

- **الأعراس:** القدرة (الخليل) + المسخن (الشمال) + المقلوبة + الكنافة.
- **رمضان:** فتة حمص + ورق العنب + المقلوبة + الكنافة + القطايف + قمر الدين.
- **موسم الزيتون (الخريف):** المسخن — رمز الهوية.
- **الأعياد:** المعمول المقدسي + الكعك + المقلوبة.

---

## 8. البهارات والمكوّنات المحلية 🟢

- **بهارات:** السماق (مميز للمسخن) + زيت الزيتون (العمود الفقري) + الكمون + الفلفل الأسود + القرفة + الخردل.
- **مكوّنات محلية:** **زيت الزيتون البكر** (المرتفعات — رمز فلسطين 🟢) + الزيتون + التين/اللوز/الجوز/العنب + الحمص + البرغل/الفريكة/السميد.
- **الجبن:** العكاوي (عكا — في الكنافة) + الجبن النابلسي (نابلس).
- **ملاحظة:** زيت الزيتون الفلسطيني عالمي الصيت + رمز الهوية/الارتباط بالأرض.

---

## 9. ملاحظة نقدية

- **المسخن فلسطيني أصيل 100%** — لا يُعرف خارج فلسطين (موثَّق).
- **الكنافة النابلسية** نابلسية أصيلة (انتشرت عالميًّا).
- **القدرة الخليلية** خليلية أصيلة.
- **السمّاقية** غزاوية أصيلة (لا تطبخ خارج غزة).
- المطبخ الفلسطيني **موروث شامي مشترك** مع الأردن/سوريا/لبنان لكن له أطباق فريدة (المسخن/القدرة/السمّاقية/الكنافة النابلسية).
- **النضال الثقافي:** الفلسطينيون يُؤكدون أصالة موروثهم الغذائي ضد محاولات الانتساب الإسرائيلي (المسخن/الحمص/الفلافل/التبولة).
