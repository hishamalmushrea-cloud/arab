# محافظة الخليل — مدينة الديانات الثلاث والحرم الإبراهيمي

> 🟢🟡🟠 (مصادر: ويكيبيديا العربية + المعرفة + الجزيرة + ajnet + alquds + trt.global + tourism.ps + الجهاز المركزي للإحصاء الفلسطيني). علامات الثقة: 🟢 موثَّق / 🟡 اختلاف بين المصادر / 🟠 حصر أو غير مؤكد. كل رقم مقرون بسنة.
>
> **ملاحظة منهجية:** الخليل محافظة فلسطينية جنوب الضفة، مركزها الخليل، مدينة مقدسة للديانات الثلاث (الحرم الإبراهيمي). هنا تُدرَس المحافظة بوحداتها الإدارية دون تكرار معلومات الدولة أو العاصمة. 🟢

## التاريخ 🟢🟡🟠

- **العصر القديم:** أسسها الكنعانيون؛ أقدم سكن على تل الرميدة (4500–3200 ق.م). مدينة مقدسة للديانات الثلاث.
- **الحرم الإبراهيمي:** أساساته هيرودس الأدومي (37–4 ق.م، سور عظيم حجارة ضخمة طول بعضها 7 م). مغارة المكفيلة — مقابر الأنبياء إبراهيم/إسحاق/يعقوب وزوجاتهم (روايات).
- **الإسلام (636 م):** حوّله المسلمون إلى مسجد؛ رابع مقدسات الإسلام (بعد الحرمين والأقصى).
- **الأمويون/الفاطميون:** اهتمام + بناء قباب + شواهد.
- **الصليبيون (1100 م):** حوّلوه إلى كنيسة «القديس إبراهام» + قلعة (90 عامًا).
- **الأيوبيون (1187 م):** حرره صلاح الدين بعد حطين؛ جلب منبرًا من عسقلان + 4 مآذن (بقي منها 2).
- **المماليك + العثمانيون + الانتداب البريطاني:** تعاقب الحكم.
- **الحديث (1967– ):** تحت الاحتلال الإسرائيلي منذ 1967 + مستوطنات في قلب المدينة + تقسيم المسجد (1994 بعد مذبحة) + إجراءات أمنية + 2010 يونسكو (قائمة التراث اليهودي — احتجاجات) — تُتناول بحياد 🟠.

## الأسواق والمعالم والمساجد والآثار 🟢

### الحرم الإبراهيمي (المسجد الإبراهيمي) 🟢
- **مغارة المكفيلة** — مقابر الأنبياء إبراهيم/إسحاق/يعقوب وزوجاتهم (عمق 18 م).
- **السور الهيرودي** (37–4 ق.م، حجارة ضخمة طول بعضها 7 م).
- تحوّلات: مسجد (636) → كنيسة (1100) → مسجد (1187، صلاح الدين) → تقسيم (1994 بعد مذبحة) — 🟠.
- **مآذن:** 4 (بقي منها 2) + **منبر صلاح الدين** (من عسقلان، تحفة خشبية).

### معالم إسلامية أخرى 🟢
- **التكية القلاوونية** (1279، صلاح الدين الأيوبي) — «المدينة التي لا تعرف الجوع».
- **مسجد/جامع الإبراهيمي** + **المسجد العمري** + **مسجد الشيخ علي البكا** + **أضرحة/مقامات** (نبياء + أولياء).
- **الحارات القديمة:** حارة السوق + حارة المشارقة (مجاورة للحرم) + حارة خيطون (تجار الحرير) + حارة الشيخ + حارة الدروز.

### أخرى 🟢
- **تل الرميدة** (أقدم سكن، 4500 ق.م) + **كروم عنب الخليل** + **متحف الخليل**.
- **المستوطنات:** 5 مواقع استيطانية في محيط المدينة (تل الرميدة/الدبويا/مدرسة أسامة بن المنقذ/سوق الخضار/استراحة) — 🟠.

## خاتمة

محافظة الخليل = **مدينة الديانات الثلاث** (الحرم الإبراهيمي) + **أكبر محافظات الضفة سكانًا** (711,223 نسمة 2017). جنوب الضفة، 1,049 كم²، كثافة 678 نسمة/كم². تاريخها الممتد من الكنعانيين (تل الرميدة، 4500 ق.م) عبر الديانات الثلاث (الحرم الإبراهيمي — سور هيرودي + مغارة المكفيلة) والإسلام (636، رابع مقدسات الإسلام) والصليبيين (1100، كنيسة) والأيوبيين (1187، صلاح الدين، منبر عسقلان) والعثمانيين (تكية قلاوون 1279). معالمها: **الحرم الإبراهيمي** (مغارة المكفيلة + سور هيرودي + مآذن + منبر صلاح الدين) + التكية القلاوونية + المسجد العمري + أضرحة/مقامات + تل الرميدة + كروم عنب. تحت الاحتلال منذ 1967 + مستوطنات في قلب المدينة (~700 مستوطن) + تقسيم الحرم (1994) + إجراءات أمنية + يونسكو 2010 — يُتناول بحياد تام. الأرقام تباينة وتُذكر بالسنة، واللاحق موصون بـ🟠.
