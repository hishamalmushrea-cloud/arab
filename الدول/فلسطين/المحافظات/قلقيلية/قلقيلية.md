# محافظة قلقيلية — أصغر محافظات الضفة (نقطة التقاء الطرق)

> 🟢🟡🟠 (مصادر: ويكيبيديا العربية + mawdoo3 + aljazeera + beitananusa + prealmedia + cvpalestine + palqura + الجهاز المركزي للإحصاء الفلسطيني). علامات الثقة: 🟢 موثَّق / 🟡 اختلاف بين المصادر / 🟠 حصر أو غير مؤكد. كل رقم مقرون بسنة.
>
> **ملاحظة منهجية:** قلقيلية محافظة فلسطينية شمال غرب الضفة، مركزها مدينة قلقيلية — نقطة التقاء طرق تجارية تاريخية. هنا تُدرَس المحافظة بوحداتها الإدارية دون تكرار معلومات الدولة أو العاصمة. 🟢

## التاريخ 🟢🟡🟠

- **العصر القديم:** «قلقيلية» كنعانية (تناثرت فيها الجلجالات الحجارية المستديرة) → «كاليكيليا» رومانية. نقطة التقاء طرق القوافل (الشام/مصر + الحجيج).
- **الإسلام:** مركز طرق تجارية + قوافل حجيج + خط سكة الحديد.
- **العثمانيون + الانتداب البريطاني:** ناحية الحرم → قضاء طولكرم.
- **الحديث (1948/1967– ):** 1948 النكبة (لاجئون من يافا/حيفا) + 1967 الاحتلال (دُمر 80% من المنازل) + جدار الفصل (يخنقها) + مستوطنات + معابر — تُتناول بحياد 🟠.
