# محافظات فلسطين — المرحلة الرابعة (الوحدات الإدارية العُليا)

> **المرجع الإداري:** التقسيم الرسمي الفلسطيني = **16 محافظة** (11 في الضفة الغربية + 5 في قطاع غزة) → مدن/مجالس قروية/مخيمات/أحياء → قرى/عزبات/خرب. 🟢
>
> **نطاق المرحلة الرابعة:** ملف موسوعي مستقل لكل محافظة من الـ16، وفق القالب 5-ج في `02_منهجية_المصادر_والتحقق.md`. العاصمة القدس مُغطاة في المرحلة الثالثة `العواصم/القدس/القدس.md` — لا تكرار، لكن هنا تُغطى المحافظة بحدودها الإدارية.
>
> **مصادر الأرقام:** الجهاز المركزي للإحصاء الفلسطيني (2017) + ويكيبيديا العربية + المعرفة + أرابيكا + مركز المعلومات الوطني الفلسطيني. 🟢
>
> **تنبيه حياد:** فلسطين تحت الاحتلال الإسرائيلي منذ 1948/1967. البنية الإدارية الرسمية (16 محافظة) تبقى المرجع الفلسطيني. الواقع الميداني مُجزّأ (مناطق أ/ب/ج حسب أوسلو + انقسام الضفة/غزة منذ 2007 + الحرب على غزة 2023–2024). يُعرض الواقع بحياد تام، مع تصريح صريح بالحياد في كل ملف. 🟡🟠
>
> **علامات الثقة:** 🟢 موثَّق / 🟡 اختلاف بين المصادر / 🟠 حصر أو غير مؤكد. كل رقم سكاني مقرون بسنة مرجعه.
>
> **قاعدة منهجية:** كل محافظة تُدرَس بذاتها (هوية/وحدات تابعة/جغرافيا/تاريخ/لهجة/لباس/طعام/عادات/اقتصاد/معالم/شخصيات/فجوات) دون تكرار معلومات الدولة أو العاصمة. لا اختلاق: عند غياب المصدر يُكتب «لم أجد معلومات موثوقة كافية».

## ملاحظات منهجية خاصة بفلسطين

- **الاحتلال الإسرائيلي:** فلسطين تحت الاحتلال منذ 1948/1967. كل ملف يفتح بتنبيه حياد صريح ويُعرض الواقع الميداني بحياد تام (مناطق أوسلو + المستوطنات + الجدار + الحصار + الحرب على غزة).
- **الانقسام الفلسطيني:** الضفة تحت السسلطة الوطنية (فتح) + غزة تحت حكم حماس منذ 2007 — يُعرض بحياد.
- **المستوطنات + الجدار:** نحو 700 ألف مستوطن إسرائيلي في الضفة + جدار الفصل العنصري — يُعرض بحياد (قانونية متنازَع عليها دوليًّا).
- **اللاجئون:** نحو 6 مليون لاجئ فلسطيني في الشتات (UNRWA) — يُعرض بحياد.
- **القدس:** العاصمة المعلَنة (تحت الاحتلال منذ 1967 — لا تعترف بها إسرائيل كعاصمة فلسطينية) — ملفها في المرحلة الثالثة؛ هنا تُغطى المحافظة.
