# محافظة نابلس — جبل النار وعاصمة الكنافة

> 🟢🟡🟠 (مصادر: ويكيبيديا العربية + أرابيكا + المعرفة + mawdoo3 + cvpalestine + palqura + الجهاز المركزي للإحصاء الفلسطيني). علامات الثقة: 🟢 موثَّق / 🟡 اختلاف بين المصادر / 🟠 حصر أو غير مؤكد. كل رقم مقرون بسنة.
>
> **ملاحظة منهجية:** نابلس محافظة فلسطينية شمال الضفة، مركزها نابلس، تشتهر بجبلي جرزيم وعيبال والكنافة وعمقها التاريخي الكنعاني. هنا تُدرَس المحافظة بوحداتها الإدارية دون تكرار معلومات الدولة (`الدول/فلسطين/`) أو العاصمة (`العواصم/القدس/القدس.md`). 🟢
>
> **تنبيه حياد:** نابلس تحت الاحتلال الإسرائيلي منذ 1967 + مستوطنات + معابر + انقسام فلسطيني — يُعرض الواقع بحياد تام، مع تصريح صريح بالحياد في كل ملف. 🟠

## الهوية

- **الاسم الرسمي:** محافظة نابلس | **النوع:** محافظة (وحدة إدارية عُليا) | **الدولة:** فلسطين | **المركز الإداري:** مدينة نابلس.
- **الموقع:** شمال الضفة الغربية — في وادٍ بين جبلي جرزيم (870 م جنوبًا) وعيبال (940 م شمالًا) 🟢 | **الإحداثيات:** 32.2211°N, 35.2811°E 🟢🟡 | **الارتفاع:** ~550 م (المدينة) | **المساحة:** 605 كم².
- **السكان (تعداد 2017):** 388,321 نسمة (المحافظة) 🟢؛ مدينة نابلس ~388,321 (تشمل المخيمات). **الكثافة:** 642 نسمة/كم².

## التاريخ 🟢🟡🟠

- **العصر القديم:** **شكيم** — مدينة كنعانية قديمة (4500 ق.م / 3600 ق.م)، من أقدم مدن العالم؛ أسسها الكنعانيون فوق تل بلاطة. ورد اسمها في نصوص إيبلا + رسائل تل العمارنة (1400 ق.م).
- **الرومان:** فلافيا نيابوليس (72 م، تيتوس) بين الجبلين؛ معبد جوبيتر/زيوس على جرزيم (القرن2 م، اكتُشف 1930) + مدرج سباق خيل + شارع أعمدة + مسرح + مقبرة عسكر.
- **البيزنطيون:** كنيسة بئر يعقوب + كنيسة مريم العذراء على جرزيم (القرن5 م).
- **الإسلام (636 م):** فتحها عمرو بن العاص بعد اليرموك/أجنادين؛ أصبحت لغتها العربية + مركزًا إسلاميًّا.
- **الصليبيون (1099 م):** استولى عليها تنكرد؛ بنى بالدوين الأول قلعة على جرزيم.
- **الأيوبيون (1187 م):** حررها صلاح الدين بعد حطين.
- **المماليك + العثمانيون + الانتداب البريطاني:** تعاقب الحكم.
- **الحديث (1948/1967– ):** تحت الاحتلال الإسرائيلي منذ 1967 + مستوطنات + معابر + انقسام — تُتناول بحياد 🟠.

## الأسواق والمعالم والمساجد والآثار 🟢

### معالم كنعانية/رومانية 🟢
- **تل بلاطة** (شكيم الكنعانية) + **معبد جوبيتر/زيوس** (جرزيم، القرن2 م، اكتُشف 1930) + **مدرج سباق الخيل** (ساحة الشهداء) + **شارع الأعمدة الروماني** + **مقبرة عسكر البيزنطية** + **المسرح الروماني** + **تل الرأس**.
- **سبسطية** — مدينة أثرية شمال غرب نابلس، مدارج رومانية + شارع أعمدة.

### معالم إسلامية 🟢
- **الجامع الكبير الصلاحي** (الطرف الشرقي للمدينة القديمة، أساساته بيزنطية/إسلامية) + **مسجد الخضرا** (الجنوب الغربي) + **مقام رجال العامود** (سفح جرزيم الشمالي، 1396، 7 غرف متلاصقة) + **برج الساعة** (المدينة القديمة) + **خربة الرأس**.
- **قبور الأنبياء في عورتا:** قبر العزير + قبر يوشع بن نون (خادم موسى) + قبر هارون (قريب).
- **الطائفة السامرية + متحف سامري** (جرزيم، 1997) + **متقف القصبة** (آثار رومانية).

### أخرى 🟢
- **جامعة النجاح الوطنية** (كبرى الجامعات الفلسطينية وأقدمها) + **بلدية نابلس** (1869).
- **الأحياء القديمة:** الحبلة + القيسارية + العقبة + القريون + الياسمينة + الشوبترة (حارة الغرب) — امتد العمران فوق منحدرات الجبلين.

## خاتمة

محافظة نابلس = **جبل النار** (جرزيم/عيبال) + **عاصمة الكنافة** + أقدم مدن العالم (شكيم الكنعانية، 3600 ق.م). شمال الضفة، 605 كم²، 388,321 نسمة (2017، كثافة 642 نسمة/كم²). تاريخها الممتد من شكيم الكنعانية (تل بلاطة) عبر الرومان (فلافيا نيابوليس، معبد جوبيتر + مدرج + شارع أعمدة) والبيزنطيين (كنائس) والإسلام (636، عمرو بن العاص) والصليبيين (1099) والأيوبيين (1187، صلاح الدين) والعثمانيين والانتداب. معالمها: تل بلاطة + معبد جوبيتر + مدرج + شارع الأعمدة + الجامع الصلاحي + مسجد الخضرا + مقام رجال العامود + قبور أنبياء عورتا + الطائفة السامرية + متحف سامري. الكنافة النابلسية (أيقونة) + زيتون/صابون. اللهجة النابلسية (شامية/دمشقية). تحت الاحتلال منذ 1967 + مستوطنات + معابر + انقسام — يُتناول بحياد تام. الأرقام تباينة وتُذكر بالسنة، واللاحق موصون بـ🟠.
