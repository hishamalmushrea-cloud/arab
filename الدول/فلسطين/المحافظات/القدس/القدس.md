## التاريخ 🟢🟡🟠

- **العصر القديم:** **يبوس** (الكنعانيون، الألفية الرابعة ق.م) → **أورشاليم** (داود 1000 ق.م، عاصمة مملكة إسرائيل الموحدة) → **الهيكل** (سليمان) → الفرس (538 ق.م، إعادة بناء) → **إيلياء/بيت المقدس** (البيزنطيون).
- **الإسلام (621 م):** الإسراء والمعراج (من المسجد الحرام إلى الأقصى). **الفتح العمري (636 م):** عمر بن الخطاب + عهدة/أمانة. بنى عبدالملك بن مروان **قبة الصخرة** (691) + الوليد بن عبدالملك **المسجد الأقصى** (709).

- **الانتداب البريطاني (1917):** الانتداب.

## الأسواق والمعالم والمساجد والآثار 🟢

### مقدسات إسلامية 🟢
- **المسجد الأقصى** (أولى القبلتين + ثالث الحرمين، 709، الوليد) + **قبة الصخرة** (691، عبدالملك بن مروان) + **المصل المرواني** + **بوابات/أبواب الحرم** + **حائط البراق**.
- **مسجد عمر** (الموقع الذي صلّى به عمر) + **الزاوية/المدارس/القباب** (الأموية/الفاطمية/المملوكية/العثمانية).

### مقدسات مسيحية/يهودية 🟢
- **كنيسة القيامة** (القرن4 م، قسطنطين/هيلانة — مكان صلب/قيامة المسيح) + **كنيسة العائلة المقدسة** + **كهف/مغارة المهد**.
- **حائط البراق/المبكى** (يقدّس اليهود — جزء من سور الحرم).

### البلدة القديمة 🟢
- **4 حارات:** الحي الإسلامي + حارة النصارى + حي الأرمن + حارة اليهود (المغاربة دُمرت 1967).
- **أسوار القدس** (العثماني سليمان القانوني 1535–1542) + **الأبواب** (العمود/الساهرة/الأسباط/...).
- **أسواق:** سوق العطارين + سوق القطّانين + سوق الحصر + الأسواق المفعمة بالحياة.
