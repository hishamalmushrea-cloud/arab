## خاتمة

محافظة الشرقية = **عاصمة الدلتا** (الزقازيق) + ثالث أكبر محافظات مصر سكانًّا (~7.53 مليون). شرق الدلتا، 4,911 كم²، فرع النيل الدمياطي + قناة السويس + بحيرة المنزلة. تاريخها الممتد من تل برسيوم (الفراعنة) عبر الإسلام والعثمانيين والانتداب. محمد علي + قناة السويس. معالمها: تل/خربة برسيوم + قناة سبتو + بحيرة المنزلة + خربة بيهايت + المسجد الكبير + مقامات + قناة السويس. اللهجة الشرقية (دلتاوية). الأرقام تباينة (إسقاط 2015) وتُذكر بالسنة، واللاحق موصون بـ🟠.
