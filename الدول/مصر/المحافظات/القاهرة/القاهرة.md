## التاريخ 🟢🟡🟠

- **العصر القديم:** «أون» (هليوبوليس — الفراعنة) + مصر القديمة.
- **الإسلام (969 م):** أسسها جوهر الصقلي (الخليفة المعز الفاطمي) — «القاهرة» (قاهرة المعز) + «مدينة الألف مئذنة» + «مصر المحروسة» + «جوهرة الشرق». بنى **جامع الأزهر** (970) + القصر الفاطمي.
- **الأيوبيون (1171 م):** صلاح الدين — افتح أبواب القاهرة + قلعة الجبل.
- **المماليك (1250 م):** قلعة الجبل مقر الحكم + قصبة القاهرة + مساجد/مدارس/أسواق.
- **العثمانيون (1517 م):** المماليك + المساجد + السبل + العمائر.
- **الحديث (1880–1930):** عصر الخديوي إسماعيل — أحياء أوروبية (الحزبكية/التوفيقية) + كباري. 1903 السيارة. 1919 ثورة 1919. 1952 ثورة يوليو. 2011 ثورة 25 يناير.

## الأسواق والمعالم والمساجد والآثار 🟢

### معالم إسلامية 🟢
- **جامع الأزهر** (970، جوهر الصقلي — أنشر المذهب الشيعي + جامعة) + **جامع الحاكم** + **جامع الأقمر** + **مسجد عمرو بن العاص** (الفسطاط) + **مسجد ابن طولون** (876) + **مسجد محمد بك أبو الدهب** + **مسجد قوصون** + **مسجد بشتاك** + **مسجد الطنبغا**.
- **قلعة الجبل (القلعة)** — مقر الحكم (الأيوبيون/المماليك/العثمانيون/محمد علي).
- **مساجد/قباب/أضرحة:** الحسين + السيدة زينب + قلعة صلاح الدين + الإمام الشافعي.

### معالم قبطية/مسيحية/يهودية 🟢
- **مصر القديمة** (الفسطاط — كنسيسة معلقة + كنسيسة القديس جورج + المتحف القبطي) + **الكنيسة المعلقة** + **الكنيسة اليونانية**.
- **القاهرة القبطية:** الكنسيس اليونانية + معابد يهودية.

### القاهرة القديمة (تراث اليونسكو 1979) 🟢
- **أسوار/أبواب:** باب الفتوح + باب النصر + باب زويلة + باب الشعرية + باب المحروق.
- **أسواق:** خان الخليلي + الصناعة + الغورية + درب الجماميز + شارع المعز (قصبة القاهرة).
- **قصور:** قصر الأمير محمد علي + بيت السحيمي + قصور السكاكيني/الأمير طاز.
- **أحياء:** الحسين + السيدة زينب + الدرب الأحمر + باب الشعرية + الجمالية + الخليفة.

### أخرى 🟢
- **برج القاهرة** + **المتحف المصري** (1896) + **دار الكتب** + **دار الأوبرا** + **جامعة القاهرة** + **جامعة الأزهر** (أقدم جامعة مصرية) + **المشفى القلاوني**.
- **سبل:** سبيل خسرو باشا + سبيل عبدالرحمن كتخدا + سبيل محمد بك أبو الدهب.

## خاتمة
