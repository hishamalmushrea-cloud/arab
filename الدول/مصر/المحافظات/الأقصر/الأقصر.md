# محافظة الأقصر — عاصمة الحضارة الفرعونية («مدينة المائة باب»)

> 🟢🟡 (مصادر: ويكيبيديا العربية + المعرفة + الجزيرة + الجهاز المركزي للتعبئة والإحصاء). علامات الثقة: 🟢 موثَّق / 🟡 اختلاف بين المصادر. كل رقم مقرون بسنة.
>
> **ملاحظة منهجية:** الأقصر محافظة مصرية حديثة النشأة (2009)، مركزها مدينة الأقصر — عاصمة الحضارة الفرعونية. هنا تُدرَس المحافظة بحدودها الإدارية دون تكرار معلومات الدولة أو العاصمة. 🟢

## الهوية

- **الاسم الرسمي:** محافظة الأقصر | **النوع:** محافظة (وحدة إدارية عُليا) | **الدولة:** مصر | **المركز الإداري:** مدينة الأقصر.
- **الموقع:** جنوب الصعيد — وادي النيل + الضفة الغربية 🟢 | **الإحداثيات:** 25.6871°N, 32.6396°E 🟢🟡 | **الارتفاع:** ~89 م | **المساحة:** 2,960 كم² (تأسست 9 ديسمبر 2009) — أصغر محافظات مصر مساحةً.
- **السكان (إسقاط 2024):** ~1.30 مليون نسمة (المحافظة) 🟡؛ مدينة الأقصر ~128,000 (إسقاط 2014: 127,994). **العيد القومي:** 4 نوفمبر (اكتشاف مقبرة توت عنخ آمون).

## الجغرافيا والتضاريس 🟢🟡

- **جنوب الصعيد** — وادي النيل + الضفة الغربية (وادي الملوك) + الضفة الشرقية (الكرنك) + جبال.
- **المناخ:** صحراوي شبه استوائي (صيف حار + شتاء معتدل + أمطار نادرة).
- **المياه:** نهر النيل + قناطر + آبار + بحيرة مقدسة.

## التاريخ 🟢🟡

- **العصر القديم:** «طيبة» (عاصمة مصر القديمة — عصر الأسرة الحادية عشر، منتوحتب الأول) → «الأقصر» (مدينة المائة باب — عصر الدولة الحديثة، الأسرة الثامنة عشر) — عاصمة الحضارة الفرعونية.
- **الإسلام + العثمانيون:** تعاقب الحكم. الأقصر عاصمة (مراكزها موزعة بين قنا/إسنا).
- **الحديث:** محمد علي + استحداث محافظة الأقصر (9 ديسمبر 2009) + سياحة عالمية.

## الأسواق والمعالم والمساجد والآثار 🟢

### معالم تاريخية (ثلث آثار العالم) 🟢
- **معبد الأقصر** (عصر الدولة الحديثة — الأسرة الثامنة عشر) + **معابد الكرنك** (معبد آمون رع — عصر الدولة الوسطى) + **وادي الملوك/وادي الملكات** (مقابر ملكية) + **معابد/مقابر جنائزية** + **معبد إسنا** (إن وُجد) + **متحف الأقصر**.
- **البحيرة المقدسة** (بئر مياه — سر بقاء لألفي عام) + **محمية الدبابية** (أول وحدة زمنية جيولوجية خارج أوروبا) + **دير المدينة** (قرية عمال المقابر).

### معالم إسلامية/قبطية 🟢
- **المسجد الكبير** + **مساجد/قباب** + **مقامات/أضرحة** + **كنائس/أديرة**.
- **مسجد أبو الحجام** (أبو الحجام — إن وُجد).

### أخرى 🟢
- **سياحة أثرية عالمية** (ثلث آثار العالم) + **بركة النيل** + **خلال الشتاء**.

## خاتمة

محافظة الأقصر = **عاصمة الحضارة الفرعونية** («مدينة المائة باب» — ثلث آثار العالم) + أصغر محافظات مصر مساحةً (2,960 كم²، استُحدثت 9 ديسمبر 2009) + العيد القومي 4 نوفمبر (اكتشاف مقبرة توت عنخ آمون). جنوب الصعيد، وادي النيل + الضفة الغربية (وادي الملوك) + الضفة الشرقية (الكرنك). تاريخها الممتد من طيبة (عاصمة مصر القديمة — الأسرة الحادية عشر) → الأقصر (عصر الدولة الحديثة — الأسرة الثامنة عشر) عبر الإسلام والعثمانيين. معالمها: **معبد الأقصر** + **معابد الكرنك** (آمون رع) + **وادي الملوك/وادي الملكات** (مقابر ملكية) + معابد/مقابر جنائزية + متحف الأقصر + البحيرة المقدسة + محمية الدبابية + المسجد الكبير + مسجد أبو الحجام. اللهجة الأقصرية (صعيدية/نوبية). الأرقام تباينة (إسقاط 2024) وتُذكر بالسنة، واللاحق موصون بـ🟠.
