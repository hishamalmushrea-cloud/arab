# محافظة الإسكندرية — عروس البحر المتوسط («مكتبة الإسكندرية»)

> 🟢🟡 (مصادر: ويكيبيديا العربية + أرابيكا + المعرفة + الجزيرة + eg.wingie + nabdalarab + egyptra + الجهاز المركزي للتعبئة والإحصاء). علامات الثقة: 🟢 موثَّق / 🟡 اختلاف بين المصادر. كل رقم مقرون بسنة.
>
> **ملاحظة منهجية:** الإسكندرية محافظة مصرية ساحلية، مركزها مدينة الإسكندرية — ثاني أكبر مدن مصر. هنا تُدرَس المحافظة بحدودها الإدارية (مدينة + أحياء) دون تكرار معلومات الدولة أو العاصمة. 🟢
>
> **تنبيه:** الإسكندرية مدينة تاريخية عريقة (مكتبة + منارة) + انقسامات سياسية حديثة — يُعرض التاريخ بحياد.

## الهوية

- **الاسم الرسمي:** محافظة الإسكندرية | **النوع:** محافظة (وحدة إدارية عُليا) + مدينة | **الدولة:** مصر | **المركز الإداري:** مدينة الإسكندرية.
- **الموقع:** شمال مصر — ساحل البحر المتوسط 🟢 | **الإحداثيات:** 31.2001°N, 29.9189°E 🟢🟡 | **الارتفاع:** ~5 م (ساحلي) | **المساحة:** 2,300 كم² (المحافظة) / ~2,791 كم² (المدينة الكبرى).
- **السكان (تقديرات 2024):** ~5.4 مليون نسمة (المحافظة) 🟡؛ المدينة ~5.4 مليون (إسقاط 2017: 5,039,975) — ثاني أكبر مدن مصر.

## التاريخ 🟢🟡🟠

- **العصر القديم:** «راكتوس/راقودة» (قرية صغيرة) → **الإسكندرية** (331 ق.م، الإسكندر الأكبر) — عاصمة لمصر + إحدى عجائب الدنيا السبع. **مكتبة الإسكندرية** (331 ق.م، ~700,000 مجلد) + **منارة الإسكندرية** (إحدى عجائب الدنيا السبع — قلعة قايتباي).
- **البيزنطيون + الصليبيون (1365 م):** هجمات + نهب.
- **الإسلام (642 م):** دخلتها عمرو بن العاص + صارت تابعة لجند مصر.
- **المماليك (1480 م):** قايتباي بنى قلعة قايتباي على موقع المنارة.
- **العثمانيون + محمد علي:** نهضة + ميناء + قناة السويس (1867) + خط سكة حديد (1856).
- **الحديث (1882–1956):** احتلال بريطاني + ثورة 1919 + جالية يهودية (هاجروا 1948) + 1956 تأميم القناة + 2011 ثورة.

## الأسواق والمعالم والمساجد والآثار 🟢

### معالم تاريخية 🟢
- **قلعة قايتباي** (1477، على موقع منارة الإسكندرية القديمة — إحدى عجائب الدنيا السبع) + **مكتبة الإسكندرية القديمة** (331 ق.م، ~700,000 مجلد).
- **المنارة** (إحدى عجائب الدنيا السبع — تهدمت 1302 زلزال، قايتباي بنى قلعتها) + **أبو قير** (خليج) + **بحيرة مريوط**.
- **عمود السواري** (عمود بومبي) + **معبد سيرابيوم** + **آثار رومانية/إغريقية** + **كوم الدكة** (راكتوس القديمة).

### معالم إسلامية 🟢
- **مساجد:** مسجد أبي العباس + مسجد النبي دانيال + مسجد المرسي أبو العباس + **مقامات/أضرحة**.

### أخرى 🟢
- **المتحف اليوناني الروماني** + **المتحف البحري** + **قصر رأس التين** + **حدائق المنتزهات** (المنتزة/الشاطبي/أنفوشي) + **سياحة ساحلية**.
- **قناة المحمودية** + **خط سكة حديد** (1856، أول في مصر/أفريقيا).
