## الأسواق والمعالم والمساجد والآثار 🟢

### مجمع أهرامات الجيزة (تراث اليونسكو 1979) 🟢
- **الهرم الأكبر (هرم خوفو)** — أكبر الأهرامات (~2580–2560 ق.م، 146.5 م، آخر عجائب الدنيا السبع الباقية) + **هرم خفرع** + **هرم منقرع**.
- **أبو الهول** (تمثال أسد + رأس إنسان — نحت من حجر كلسي) + **معبد الوادي** + **الممرات/المقابر**.
- **مقابر الشرقية/الغربية** (الملكات/كبار الموظفين) + **قرية العمال** + **جبانة** (مقابر).

### معالم إسلامية/حديثة 🟢
- **مساجد:** المسجد الكبير + **مسجد أحمد بن طولون** (إن وُجد) + غيره.
- **متحف مصر الكبير** (الجيزة) + **متحف الضمام** + **متحف النوبارية** + **متحف الشمع** + **دار الأوبرا**.
- **مشروع العاصمة الإدارية الجديدة** (عاصمة مصر الجديدة) + **حدائق الأهرامات**.

### أخرى 🟢
- **أهرامات الجيزة وأبو الهول** (تراث عالمي لليونسكو 1979 ضمن «منف وجبانتها») 🟢 · **سقارة** بهرم زوسر المدرج · **دهشور** بالهرمين المنحني والأحمر · **ميت رهينة** موقع **منف** العاصمة القديمة 🟢 · **المتحف المصري الكبير** بالقرب من الأهرامات 🟢.

## خاتمة

محافظة الجيزة = **موطن أهرامات مصر** («مجمع أهرامات الجيزة» — عجائب الدنيا السبع، تراث اليونسكو 1979) + ثاني أكبر محافظات مصر سكانًّا (~9.07 مليون). على الضفة الغربية لنهر النيل مشارف القاهرة، 13,184 كم². موطن حضارة الفراعنة: **مجمع أهرامات الجيزة** (2600–2500 ق.م، الأسرة الرابعة) = **الهرم الأكبر (خوفو)** — آخر عجائب الدنيا السبع الباقية + **هرم خفرع** + **هرم منقرع** + **أبو الهول** + مقابر/معابد + قرية العمال. الإسلام + العثمانيون + محمد علي. معالمها: الأهرامات + أبو الهول + مقابر + مساجد + متاحف (مصر الكبير/الضمام) + مشروع العاصمة الإدارية الجديدة + حدائق. اللهجة الجيزية (قاهرية/ريفية). التاريخ الفرعوني يُعرض بحياد. الأرقام تباينة (إسقاط 2015) وتُذكر بالسنة، واللاحق موصون بـ🟠.
