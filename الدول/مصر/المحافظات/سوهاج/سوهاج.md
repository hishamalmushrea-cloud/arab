# محافظة سوهاج — قلب الصعيد (سوهاج)

> 🟢🟡 (مصادر: ويكيبيديا العربية + المعرفة + الجزيرة + الجهاز المركزي للتعبئة والإحصاء). علامات الثقة: 🟢 موثَّق / 🟡 اختلاف بين المصادر. كل رقم مقرون بسنة.
>
> **ملاحظة منهجية:** سوهاج محافظة مصرية في وسط الصعيد، مركزها مدينة سوهاج. هنا تُدرَس المحافظة بحدودها الإدارية دون تكرار معلومات الدولة أو العاصمة. 🟢

## الهوية

- **الاسم الرسمي:** محافظة سوهاج | **النوع:** محافظة (وحدة إدارية عُليا) | **الدولة:** مصر | **المركز الإداري:** مدينة سوهاج.
- **الموقع:** وسط الصعيد — وادي النيل بين أسيوط شمالًا وقنا جنوبًا 🟢 | **الإحداثيات:** 26.5569°N, 31.6948°E 🟢🟡 | **الارتفاع:** ~67 م | **المساحة:** 11,218 كم².
- **السكان (إسقاط 2017):** ~5.32 مليون نسمة (المحافظة) 🟡 — تاسع أكبر محافظات مصر سكانًّا؛ مدينة سوهاج ~600,000 (إسقاط 2014: 523,000).

## التاريخ 🟢🟡

- **العصر القديم:** «أبيدوس» (عاصمة مصر القديمة — الأسرة الأولى/الثانية، مركز الحج للفراعنة) + «ثنى» (مدينة تاريخية) + «طيبة» (عاصمة الأسرة الحادية عشر).

## خاتمة

محافظة سوهاج = **قلب الصعيد** (سوهاج) + تاسع أكبر محافظات مصر سكانًّا (~5.32 مليون). وسط الصعيد بين أسيوط وقنا، 11,218 كم²، وادي النيل. تاريخها الممتد من **أبيدوس** (عاصمة مصر القديمة — الأسرة الأولى/الثانية، مركز الحج) + ثنى/طهطا (مدن تاريخية) + طيبة (عاصمة الأسرة الحادية عشر) عبر الإسلام والعثمانيين (ولاية جرجا/الصعيد). معالمها: أبيدوس + ثنى + طيبة + تاسا + مسجد السيوطي (معهد ديني) + دير العذراء (درنكة) + دير المحرق + المسجد الكبير + بركة النيل. اللهجة السوهاجية (صعيدية) + منسوجات (أخميم/مراغة). الأرقام تباينة (إسقاط 2017) وتُذكر بالسنة، واللاحق موصون بـ🟠.
