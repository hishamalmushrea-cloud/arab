## ملاحظة منهجية

- **التقسيم الهرمي:** محافظة → مركز → مدينة/قرية/حي. المراكز في المحافظات الريفية؛ المحافظات الحضرية (القاهرة/الإسكندرية/بور سعيد) تنقسم لأحياء. 🟢
- **القاهرة:** العاصمة + أكبر محافظات مصر سكانًّا — ملفها في المرحلة الثالثة؛ هنا المحافظة بحدودها الإدارية (مدينة + 37 حيًّا).
- **التاريخ:** مصر حضارة عريقة (الفراعنة + اليونان/الرومان + الإسلام) — في ملفات المحافظات يُبرز التاريخ المحلي لكل محافظة.
- **اليونسكو:** مجمع أهرامات الجيزة (التراث العالمي 1979) + القاهرة القديمة (1979) + أبو مينا بالإسكندرية (التراث العالمي 1979).
