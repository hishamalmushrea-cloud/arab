# محافظة المنيا — عاصمة الصعيد الأوسط (المنيا)

> 🟢🟡 (مصادر: ويكيبيديا العربية + المعرفة + الجهاز المركزي للتعبئة والإحصاء). علامات الثقة: 🟢 موثَّق / 🟡 اختلاف بين المصادر. كل رقم مقرون بسنة.

- **الموقع:** وسط الصعيد — وادي النيل 🟢 | **الإحداثيات:** 28.0871°N, 30.8316°E 🟢🟡 | **الارتفاع:** ~46 م | **المساحة:** 32,279 كم² — أكبر محافظات مصر مساحةً (بعد الوادي الجديد).
