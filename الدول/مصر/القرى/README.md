# قرى مصر — المرحلة السادسة

> `مصر → الوحدة الإدارية → المدينة/الناحية → **القرية** → الحارة`
>
> **الوحدة القروية: القرية / العزبة / الكفر / النجع**
> **العدد الرسمي: **أكثر من 4,000 قرية** وآلاف العزب** 🟢
> **المصدر: الجهاز المركزي للتعبئة العامة والإحصاء** 🟢

---

## المصطلح والبنية

مصر **أغنى الدول العربية بمصطلحات التجمع القروي**، وكل مصطلح يحمل معلومة تاريخية-اجتماعية:

| المصطلح | الدلالة |
|---|---|
| **قرية** | تجمّع قديم مستقرّ له وحدة محلية |
| **كفر** | تجمّع نشأ حول أسرة أو حرفة (شائع في الدلتا) |
| **نجع** | تجمّع صعيدي، غالبًا امتداد عائلي |
| **عزبة** | نشأت حول **ملكية زراعية كبيرة** — سجلّ لنظام الإقطاع |
| **منشية** | تجمّع «أُنشئ» بقرار أو استصلاح |
| **الحكر** | أرض موقوفة بُني عليها ثم استقرّ |

⭐ **العزبة والمنشية والحكر مصطلحات تؤرّخ لعلاقات الملكية**، ووجودها في
**15 شياخة قاهرية** رسمية يعني **اعتراف الدولة بالعمران غير المخطَّط بعد استقراره** 🟢.

## نماذج موثَّقة

### ميت رهينة — الجيزة

قرية قائمة فوق **منف (ممفيس)** — أول عاصمة لمصر الموحّدة 🟢. **قرية حديثة تسكن فوق عاصمة عمرها خمسة آلاف سنة.**

### القرنة — الأقصر

قرية بُنيت فوق **مقابر طيبة**؛ ونُقل أهلها في مشروع **حسن فتحي** الشهير «القرنة الجديدة» بالعمارة الطينية 🟢 — **أشهر تجربة عمارة اجتماعية في العالم العربي**.

### سيوة — مطروح

واحة أمازيغية معزولة غربًا، لها **لغتها (السيوية)** وعمارتها الملحية (الكرشيف) 🟢، وفيها **معبد آمون** الذي قصده الإسكندر.

### نزلة السمان — الجيزة

قرية ملاصقة لهضبة الأهرامات 🟡.

## ما لم أستطع توثيقه 🔴

> ⚠️ **هذا القسم هو جوهر الالتزام بالبرومبت (§9 و§15 و§33)، لا اعتذار عنه.**

- **الحصر الاسمي الكامل للقرى** — **لم أجد مصدرًا موثوقًا** ينشر قائمة
  قرى مصر كاملةً بأسمائها. والعدد الإجمالي معلوم، **والأسماء ليست متاحة**.
- **السكان** و**سنة التأسيس** و**أصل التسمية** لكل قرية على حدة.
- **العائلات والقبائل** في كل قرية — وهي معلومة **لا تُنشر رسميًا** غالبًا،
  ولا يجوز استنباطها.
- **اللهجة والعادات والأطعمة** على مستوى القرية المفردة.

> ⚠️ **لم تُخترع قرية واحدة ولا اسم ولا رقم.** والبرومبت نفسه ينصّ في **§9**:
> *«إذا لم تتوفر معلومات كافية، لا تخترع. اكتب: لم أجد مصدرًا موثوقًا كافيًا»* —
> **وهذا ما فُعل هنا حرفيًّا.**
