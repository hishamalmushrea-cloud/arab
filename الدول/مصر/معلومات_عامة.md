## 2. الموقع الجغرافي والحدود

### الموقع
- في الوطن العربي: شمال شرق أفريقيا + سيناء في آسيا — ملتقى ثلاث قارات (أفريقيا/آسيا/أوروبا بحريًا).
- بالنسبة لخط الاستواء: شمالي (22°–31°37′ شمالًا تقريبًا)، يمر به مدار السرطان.
- بالنسبة لخط غرينتش: شرقي (24°–37° شرقًا تقريبًا).
- بالنسبة للبحار: يطل على البحر المتوسط شمالًا (ساحل 995 كم) والبحر الأحمر شرقًا (ساحل 1941 كم). 🟢

### الخلجان والسواحل
- **خليج السويس** + **خليج العقبة** (شمال البحر الأحمر) — بينهما شبه جزيرة سيناء. 🟢
- **خليج الجميل/أبو قير** (شمال، قرب الإسكندرية).
- ساحل المتوسط: منخفض، رمال وبحيرات (إدكو/البرلس/مريوط/المنزلة).
- ساحل البحر الأحمر: مرجاني، رؤوس وخلجان (رأس غارب/الحماة/بناس).

### الجزر
- جزيرة **شدوان** (مجرى البحر الأحمر)، جزيرة **فرعون/تيران** (خليج العقبة — تابعة لشرم الشيخ، متنازَع عليها تاريخيًا مع السعودية قبل الترسيم). 🟢
- جزر النيل: الروضة/الزمالك/أبو الفدا/الورّاق وغيرها (القاهرة/الجيزة). 🟢

### الحدود
- **شمالًا:** البحر المتوسط 🟢 (ليبيا غربًا، فلسطين المحتلة شرقًا).
- **شرقًا:** البحر الأحمر + منطقة فلسطين المحتلة (إسرائيل) + قطاع غزة (ساحل رفح) 🟢 — 265 كم مع فلسطين.
- **جنوبًا:** السودان 🟢 — 1280 كم.
- **غربًا:** ليبيا 🟢 — 1115 كم.

### أنواع المحافظات
- **حضرية بالكامل:** القاهرة، الإسكندرية، بورسعيد، السويس → تنقسم إلى **أحياء** فقط.
- **خليط حضري/ريفي:** الأغلبية → تنقسم إلى **مراكز** + أحياء المدينة + وحدات محلية قروية.
- **حدودية/صحراوية:** مطروح/البحر الأحمر/الوادي الجديد/شمال وجنوب سيناء → تنقسم إلى **مدن** فقط (لا مراكز). 🟢

### التسلسل الإداري للوحدات السفلى 🟢
```
محافظة → مركز (ريف) أو قسم/حي (مدينة) → وحدة محلية (مدينة/قرية قاعدة) → قرية → كفر/عزبة/نجع
```
- القرية لها عزب وكفور ونجوع تابعة لها (خاصة في الدلتا والصعيد).
- المركز قاعدته مدينة + عدد من الوحدات المحلية القروية.
