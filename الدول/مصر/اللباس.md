## 1. ملاحظة أولى: لا يوجد «زي مصري واحد» 🟢

> مصر لم تجمع على زي واحد عبر تاريخها؛ الأزياء تتنوع بحسب المنطقة (القاهرة/الصعيد/الدلتا/سينا/النوبة/سيوة) والمرحلة التاريخية (فرعوني/يوناني/روماني/إسلامي/عثماني/حديث). 🟢 (ملاحظة الباحث جمال الدين: aajsa.)

## 2. اللباس الرجالي 🟢

### القطع الأساسية

| القطعة | الوصف | المنطقة/الاستخدام |
|---|---|---|
| **الجلابية (الجلباب)** | رداء فضفاض طويل بأكمام | كل مصر؛ ريف/صعيد/مدن |
| **القفطان** | رداء خارجي فوق الجلابية | المدن/المناسبات |
| **العمامة** | تُلف على الرأس | الصعيد/العلماء/الأزهريون |
| **الطربوش** | غطاء رأس أحمر أسطواني | دخله محمد علي (1805) زيًّا رسميًّا؛ ارتبط بالطبقة المتعلمة حتى انتهاء العصر الملكي 🟢 |
| **العباءة (العباية)** | رداء خارجي أسود/أبيض من الصوف/الوبر | ريف/صعيد، رمز هيبة |
| **اللبدة** | شال صوف يُوضع على الكتف | الصحراء/البدو |
| **الكوفية/العقال** | كوفية حمراء/بيضاء + عقال | سيناء/البدو/الشرقية |

### أنواع الجلابية بحسب المنطقة 🟢
- **جلابية الفلاح:** قطني سميك، أكمام طويلة، ياقة مغلقة — للعمل في الحقل.
- **جلابية الصعيدي:** داكنة (غالبًا) مع العمامة/الشال.
- **جلابية المناسبات:** حرير/ساتان مطرَّز بخيوط ذهبية/فضية.
- **جلابية الصوف** البيضاء — شتاءً (الدلتا/الصعيد).
- **الجلابية القصيرة + سروال + صدرية + طاقية** — سيوة. 🟢

## 3. اللباس النسائي 🟢 — أشدّ تنوعًا

### (أ) الزي الفلاحي (الدلتا/الريف) 🟢
- **جلابية منزلية** قطنية منقوشة ألوان زاهية + أكمام طويلة + تكسيمة في الصدر.
- **ثياب الخروج:** غالبًا سوداء + الملاية اللف.
- **الملاية اللف** 🟢 — رداء أسود كبير يُلف حول الجسم، رمز نساء الدلتا/الإسكندرية القديمة (زنقة الستات بالمنشية).
- **الطرحة/الشيلة** — غطاء رأس.

### (ب) الزي الصعيدي 🟢
- **المُلس (الملس)** — جلباب أسود فضفاض غير مزين، فوق الثوب المنزلي (المنيا/بني سويف). 🟢
- **الجبة** — نساء الأقصر. 🟢
- **القفطان البلدي الطويل** — نساء إسنا (قنا/الأقصر).
- **البردة** الصوفية السوداء — أسيوط.
- **الحِبرة** (حرير/قطن) — نساء الصعيد.
- **الطرحة الطويلة السوداء (الشيلة).**

### (ج) الزي الإسكندراني/الساحلي 🟢
- الملاية اللف + الجلباب (قديمًا).
- حديثًا: ملابس متوسطية أكثر انفتاحًا.

### (د) زي بدو سيناء 🟢
- **جلابية طويلة** مع السروال + **كوفية حمراء/بيضاء** للرجال.
- النساء: **عباءات ملونة بالخرز والخيوط الذهبية**، طرحة مزخرفة، الحناء.
- **البرقع** (غطاء وجه بخيط/خرز) — نساء سيناء/البدو.

### (هـ) الزي النوبي 🟢
- **الجلابية النوبية** مطرَّزة بالخرز/الألوان الزاهية (الأصفر/الأحمر/الأخضر).
- طرحة مطرَّزة، حلي فضية/ذهبية ثقيلة.
- للرجال: جلابية بيضاء + عمامة.

### (و) زي سيوة 🟢
- نساء سيوة: زي خاص مطرَّز، ألوان، حلي فضية، حنّاء.
- رجال سيوة: جلباب قصير + سروال + صدرية + طاقية.

### (ز) الحضري (القاهرة/الإسكندرية حديثًا) 🟢
- الجلباب في الأحياء الشعبية.
- حديثًا: الجينز/القمصان + الحجاب (الإسلامي الحديث).
- النقاب (أسود) في بعض الأحياء الشعبية (القاهرة).

---

## 4. الحلي والمجوهرات 🟢

- **الحلي الفضية/الذهبية** — للنساء (أقراط/أساور/خلاخل/غُوّاش).
- **الخرز** في النوبة/سيوة — سمة مميزة.
- **الذهب** في الأعراس (الشبكة).
- **تاريخ:** صناعة الحلي في مصر منذ الفراعنة (توت عنخ آمون).

---

## 5. اللباس التاريخي 🟢

- **الفرعوني:** كتان (أبيض)، الرجال تنانير قصيرة، النساء فساتين طويلة ضيقة + مجوهرات/خرز.
- **اليوناني/الروماني (الإسكندرية):** التأثير الهلنستي.
- **الإسلامي:** الجلابيب + العمائم + الحجاب (بعد الفتح).
- **العثماني:** القفاطين + البراقع (النقاب) + الطربوش. 🟢
- **محمد علي/Victorian:** البدلة الرسمية + الطربوش + الزي الغربي للطبقة العليا.
- **الحديث:** مزيج غربي/شرقي، الجلابية في الأحياء الشعبية/الريف، الجينز + الحجاب للنساء حديثًا.

---

## 6. الفروق بحسب البيئة 🟢

| البيئة | اللباس | السبب |
|---|---|---|
| الصعيد | جلابية داكنة + عمامة (رجال) + ملس/جبة/حبرة (نساء) | حرارة/برد الجبال + عرف محافظ + تراث قديم |
| الدلتا (الريف) | جلابية قطنية + ملاية لف (نساء) | زراعة + حرارة |
| الإسكندرية/الساحل | ملاية لف + تأثير متوسطي | مناخ ساحلي + ميناء |
| سيناء/البدو | كوفية + عقال (رجال) + خرز (نساء) | بداوة |
| النوبة | جلابية مطرزة بالخرز + ألوان زاهية | ثقافة نوبية مستقلة |
| سيوة | جلباب قصير + طاقية (رجال) + مطرز (نساء) | عزلة الأمازيغ |

## 7. ملاحظة نقدية

- **لا يوجد زي مصري فلكلوري موحد** (على عكس الساري الهندي/القفطان المغربي) — تنوع قومي/بيئي/تاريخي. 🟢
- العودة للزي التقليدي في المناسبات الشعبية (الأفراح/الموالد) دون الحياة اليومية (تأثير التحضّر/الغرب).
- الطربوش سقط مع انتهاء العصر الملكي (1952) — لم يعد زيًّا شعبيًّا.
