## خصوصية النظام المصري: ثلاثة مسميات لا مسمى واحد 🟢

خلافًا لليمن (مديرية) أو العراق (قضاء) أو سوريا (منطقة)، **لا يستخدم النظام المصري
مصطلحًا واحدًا للمستوى الثاني**، بل ثلاثة بحسب طبيعة العمران:

| المصطلح | يُستخدم في | يرأسه | ملاحظة |
|---|---|---|---|
| **المركز** | المحافظات ذات الطابع الريفي/المختلط | رئيس المركز | يضم مدينة (قاعدة إدارية) + وحدات محلية قروية |
| **القسم** | المدن الكبرى (تقسيم شرطي/إداري) | — | كأقسام المنصورة وطنطا |
| **الحي** | المحافظات الحضرية بالكامل | رئيس الحي | القاهرة والإسكندرية وبورسعيد والسويس |

> ⚠️ **لا يُخلط** «المركز» المصري بـ«المركز» السعودي (وحدة أصغر تتبع المحافظة)،
> ولا بـ«المديرية» اليمنية ولا «القضاء» العراقي.

**التسلسل داخل المركز:** مركز → مدينة (القاعدة الإدارية) + **وحدات محلية قروية** →
**قرى** → **عزب ونجوع وكفور**.
