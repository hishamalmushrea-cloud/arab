# المصادر والمراجع — دولة مصر

> مرتبة حسب المستوى. تاريخ آخر مراجعة: 2026-08-11.

## المستوى الأول — رسمي
- **الجهاز المركزي للتعبئة العامة والإحصاء (مصر):** بيانات المحافظات والمراكز والسكان. 🟢
- **وزارة التنمية المحلية / محافظة القاهرة (cairo.gov.eg):** تضاريس مصر، الأزياء التراثية. 🟢
- **الهيئة العامة للمنطقة الاقتصادية لقناة السويس:** بيانات الاستثمارات (2025). 🟢

## المستوى الثاني — أكاديمي/مراجع
- **ويكيبيديا العربية:** قائمة محافظات مصر، قائمة مدن مصر، قائمة مراكز مصر (marefa)، تاريخ مصر، ثورة 23 يوليو، المطبخ المصري، قائمة المأكولات المصرية، الاحتلال البريطاني لمصر — مع مراجعها الأصلية. 🟢
- **موسوعة عين (ainpedia.com):** معلومات عن محافظات مصر. 🟡
- **موقع محيط (m7et.com):** محافظات مصر وتوزيعها حسب الأقاليم، تقسيمات المحافظات. 🟢/🟡
- **موقع لحظات (7hob.com):** محافظات مصر (الأقاليم/المدن/المراكز/الأحياء). 🟢/🟡
- **المعرفة (marefa.org):** قائمة مراكز مصر. 🟢
- **daralhikma.org:** لهجة صعيدية. 🟢/🟡
- **eladawy.blog:** جذور اللهجات العامية المصرية. 🟡 (بحث لغوي)
- **coptic.org:** الكلمات العامية المصرية ذات الأصل القبطي. 🟢 (مرجع لغوي قبطي)

## ملاحظة منهجية
- المصادر الرسمية والأكاديمية اعتمدت للإدارات/التاريخ/الجغرافيا.
- المصادر المحلية للثقافة/الطعام/اللباس/اللهجات — تُعرض مع 🟡 حيثما يلزم.
- الأنساب البعيدة (قحطان/عدنان/بنو هلال) رواية تاريخية 🟠.
- أرقام النسب القومية/الدينية تقديرات 🟡 (لا إحصاء رسمي قاطع).
- رواية «مينا = نارمر» (شخص واحد) محل بحث أركيولوجي 🟠.

## ملاحظة على الأرقام
- سكان المحافظات: قاعدة 2014 معروفة + تقديرات 2024. 🟢/🟡
- المساحات: تباين طفيف (الجيزة 13,184 مصلحة / 85,153 شاملة الصحاري) 🟡.
- السكان الكلي: تقديرات 105–110 مليون 🟡.

## تحديث التدقيق التصحيحي — 2026-08-13

> أُجري تدقيق تصحيحي شامل لمحافظات مصر بعد كشف السكربت الآلي `scripts/تدقيق.py`
> عن مواقع أثرية غير موثَّقة وأرقام سكانية مخلوطة. التالي مصادر التصحيح.

### المستوى الأول — رسمي
- **الجهاز المركزي للتعبئة العامة والإحصاء (CAPMAS) — الساعة السكانية:** أعداد سكان المحافظات
  2023 و2024 و2025 وترتيبها. 🟢
- **الهيئة العامة للاستعلامات:** بطاقات المحافظات (المساحة، المراكز، المدن، العيد القومي). 🟢
- **وزارة السياحة والآثار / المجلس الأعلى للآثار:** تصريحات رسمية عن تل الربع (منديس)،
  تل الأبقعين، تل اليهودية، أتريب، بوتو. 🟢

### المستوى الثاني — أكاديمي
- **جامعة المنصورة — صفحة السياحة بالدقهلية:** جرد التلال الأثرية (تل الربع، تمي الأمديد،
  تل المقدام، تل البلامون، تل بله). 🟢
- دراسات الآثار المنشورة عن **تل الأبقعين** (اكتشاف دارسي 1903، سيف رمسيس الثاني). 🟢

### المستوى الرابع — موسوعات
- **المعرفة (marefa.org)** و**أرابيكا** و**ويكيبيديا العربية:** محافظات الدقهلية والبحيرة
  والقليوبية والمنيا والشرقية. 🟢/🟡

### المستوى الخامس — صحافة
- **اليوم السابع / الأهرام / الوطن / أخبار اليوم / صدى البلد:** تقارير عن المناطق الأثرية
  بالمنيا (تل العمارنة، بني حسن، الأشمونين، تونا الجبل) والبحيرة والقليوبية. 🟡
