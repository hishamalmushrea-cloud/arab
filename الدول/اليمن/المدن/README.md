# مدن اليمن — المرحلة الخامسة (المدن)

> **المرجع الإداري:** التقسيم الرسمي لليمن = **22 وحدة إدارية عُليا** → **333 مديرية** → عزل → قرى → محلات/حارات. 🟢
>
> **نطاق المرحلة الخامسة:** ملف موسوعي مستقل لكل مدينة بارزة في اليمن (مركز محافظة أو مدينة تاريخية/تراثية كبرى)، وفق القالب 5-د في `02_منهجية_المصادر_والتحقق.md`. المدن التي هي عواصم الدولة (صنعاء) مُغطاة في المرحلة الثالثة `العواصم/صنعاء/صنعاء.md` — لا تكرار.
>
> **مصادر الأرقام الكبرى:** ويكيبيديا العربية + المركز الوطني للمعلومات اليمني + الجزيرة + 3rabica + marefa + reefyemen. 🟢
>
> **تنبيه حياد:** الواقع الميداني مُجزّأ منذ 2014–2015 (حكومات متعددة + نزاع + نزوح). البنية الإدارية الرسمية تبقى المرجع الموثَّق وتُعرض مع الإشارة إلى الواقع حيث يلزم. 🟡🟠 — يُتناول بحياد تام.
>
> **علامات الثقة:** 🟢 موثَّق / 🟡 اختلاف بين المصادر / 🟠 حصر أو غير مؤكد. كل رقم سكاني مقرون بسنة مرجعه.
>
> **قاعدة منهجية:** كل مدينة تُدرَس بذاتها (هوية/تاريخ/مجتمع/ثقافة/جغرافيا/أماكن/فجوات) دون تكرار معلومات الدولة أو المحافظة. لا اختلاق: عند غياب المصدر يُكتب «لم أجد معلومات موثوقة كافية».

## ملاحظة منهجية

- **المدينة تُدرَس بذاتها:** هوية + تاريخ + مجتمع + ثقافة + جغرافيا + أماكن + فجوات. لا تكرار لمعلومات المحافظة (المُغطاة في المرحلة الرابعة) أو الدولة (المرحلة الثانية).
- **المدن التراثية** (زبيد/شبام/تريم/صنعاء القديمة) تُبرز قيمتها اليونسكوية ومكانتها العلمية/المعمارية.
- **عدن** عاصمة اقتصادية وتاريخية (لم تُغطَّ في المرحلة الثالثة لأن العاصمة السياسية هي صنعاء) — تُدرَس هنا كمدينة.
