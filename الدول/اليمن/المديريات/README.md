# مديريات اليمن — المستوى الإداري الثاني

> **موقع هذه الطبقة في التسلسل:**
> `الجمهورية اليمنية → المحافظة (22) → **المديرية (333)** → العزلة → القرية → المحلة/الحارة`

**المديرية** هي الوحدة الإدارية الثانية في اليمن، يرأسها **مدير عام المديرية**، ولها
**مجلس محلي منتخب** بموجب **قانون السلطة المحلية رقم 4 لسنة 2000**. 🟢
ويتفرع عنها **العزلة** (تجمع قروي إداري) ثم **القرية** ثم **المحلة/الحارة**.

> ⚠️ **لا يُخلط** بين «المديرية» اليمنية و«القضاء» العراقي أو «المركز» المصري أو
> «الولاية» العُمانية أو «الدائرة» الجزائرية — لكلٍّ نظامه ومسماه الرسمي.

## منهجية ملفات المديريات

لكل مديرية تُوثَّق الحقول التالية — وما لا يُعثر له على مصدر يُكتب صراحةً
«لم أجد معلومات موثوقة كافية»:

1. الاسم الرسمي + الأسماء البديلة + النطق اللاتيني
2. المحافظة التابعة لها + مركز المديرية
3. المساحة (كم²) + الإحداثيات + الارتفاع
4. السكان (تعداد 2004 🟢 + إسقاط 2022 🟡) + الكثافة
5. العزل والقرى والأحياء التابعة (حيث توثَّق)
6. الجغرافيا والتضاريس والمناخ المحلي
7. التاريخ ونشأة الاسم
8. المعالم والأسواق والمساجد والمواقع الأثرية
9. الاقتصاد والمهن والزراعة
10. الخصائص المحلية المميزة عن الجارات
11. المصادر + تقرير الفجوات
