# محافظات اليمن — المرحلة الرابعة (الوحدات الإدارية العُليا)

> **المرجع الإداري:** التقسيم الرسمي لليمن = **22 وحدة إدارية عُليا** (21 محافظة + أمانة العاصمة) → **333 مديرية** → عزل → قرى → محلات/حارات. 🟢
>
> **مصادر الأرقام الكبرى:** ويكيبيديا العربية «التقسيم الإداري في اليمن» و«محافظات اليمن» (إسقاط سكاني 2022) + المركز الوطني للمعلومات اليمني (إحصاء 2004) + 3rabica (قوائم المديريات بالمساحات والسكان). 🟢
>
> **تنبيه حياد:** الواقع الميداني مُجزّأ منذ 2014–2015 (حكومات متعددة + نزاع + نزوح). البنية الإدارية الرسمية تبقى المرجع الموثَّق وتُعرض مع الإشارة إلى الواقع حيث يلزم. 🟡🟠 — يُتناول بحياد تام.
>
> **علامات الثقة:** 🟢 موثَّق / 🟡 اختلاف بين المصادر / 🟠 حصر أو غير مؤكد. كل رقم سكاني مقرون بسنة مرجعه.
>
> **قاعدة منهجية:** كل محافظة تُدرَس بذاتها (هوية/مديريات/جغرافيا/تاريخ/عمارة وثقافة/لهجة/اقتصاد/معالم/شخصيات/فجوات) دون تكرار معلومات الدولة أو العاصمة. لا اختلاق: عند غياب المصدر يُكتب «لم أجد معلومات موثوقة كافية».

## ملاحظة على المساحة والسكان

- أرقام المساحة والسكان وإحصاء المديريات مأخوذة من جدول «التقسيم الإداري في اليمن» (ويكيبيديا العربية) المعتمد على بيانات المركز الوطني للمعلومات. تتباين بعض الأرقام بين المصادر (مثل مساحة شبوة 47,728 مقابل 42,584 كم²، ومساحة المهرة 82,405 مقابل ~67,000 كم²، وسكان المهرة 180,000 مقابل ~100,000) → تُذكر بعلامة 🟡.
- سكان المحافظات على مستوى المديريات في الجداول الداخلية مأخوذة غالبًا من **تعداد 2004** (آخر إحصاء شامل موثَّق)، بينما رقم إجمالي المحافظة المُعلَن قد يكون **إسقاط 2022** — يُشار إلى السنة دائمًا.
