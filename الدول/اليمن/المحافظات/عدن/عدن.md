- **مدينة عدن (العاصمة الاقتصادية):** أحياء: البيضاء (حي الحشيد + حي جمال + حي السلام + حي السعادة + حي الرشيد) + أحياء حولها: أكتوبر + الصمود + حي 22 يونيو + حي 22 مايو + حي سالم عمر.
- **مديرية خور مكسر:** أحياء: حي المدينة البيضاء + حي الرشيد + حي السعادة + حي جمال + حي السلام + حي أكتوبر (خور مكسر).
- **مديرية صيرة:** أحياء: حي الصمود + حي السلفي + حي مايو (صيرة) + حي التلال الملتهبة + حي الكبسي.

- **مديرية التواهي:** أحياء: حي التحالف + حي الشهداء + حي فقم + حي الفارسي + حي الزحف الأحمر.
- **مديرية البريقة:** أحياء: حي الشهداء + حي الحارسي + حي ناجي + حي القاضي + حي أكتوبر (البريقة).
- **مديرية المنصورة:** أحياء: حي تلال شمسان + حي الثورة + حي ريمي + حي 22 يونيو (المنصورة).
- **مديرية الشيخ عثمان:** أحياء: حي الوحدة + حي أول مايو (الشيخ عثمان) + حي عبود.

## التاريخ 🟢🟡🟠

- **قبل الإسلام:** آثار قديمة (قصر غمدان) + مركز تجاري حضري.
- **الإسلام (627–635 م):** ازدهار + مدارس/أسواق — جامع الصنعاء (أقدم مسجد في اليمن بعد جامع الصروة بن نافع).
- **الدولة الأموية/العباسية:** ازدهار.
- **الدولة اليعفرية:** المهراني + الصليحية + الإمامة.
- **الدولة الطاهرية:** القرامطة + الأشراف.
- **الدولة العثمانية (القرن 16–1918 م):** مركز إداري + ولايات.
- **الدولة اليعفرية (1918–1962 م):** أئمة علكيون — عاصمة.
- **الجمهورية العربية اليمنية (1962–1990):** عاصمة الشطرين.
- **الجمهورية اليمنية (1990–2012):** عاصمة صنعاء → عاصمة اليمن.

## خاتمة

محافظة عدن = **ثاني محافظات اليمن بالسكان** + **عاصمة اليمن** (المركز الاقتصادي) + **أكبر محافظات اليمن بالسكان**. على ساحل خليج عدن، صاغت المطبخ اليمني (السلتة — الطبق الوطني) و**القهوة** (الضيافة) و**الشاي** (الضيافة — مع القهوة). تاريخها الممتد من آثار قديمة (قصر غمدان) عبر الإسلام والدولة الأموية إلى العثمانية إلى الجمهورية. تنقسم إلى **8 مديريات** (إجمالي ~8 كم²؛ ~3 مليون نسمة) تضم أحياءًا بارزة في العاصمة عدن (البيضاء + جمال + السلام + السعادة + الرشيد + أكتوبر + الصمود + 22 يونيو/22 مايو). القبائل يمنية أصيلة مع بعض القبائل ذات أصول هجرة عربية (عيسى) — تُصنَّف بحياد. اللهجة العدنية (تعزية) قاف همزة + إمالالات + إنتِ. الواقع الميداني مُجزّأ منذ 2014 — يُتناول بحياد، مع تصريح صريح بالحياد في تقرير الفجوات. الأرقام السكانية تباينة (إحصاء2022) وتُذكر بحصر، والأرقام اللاحقة موصونة بـ🟠.
