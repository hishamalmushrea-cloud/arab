# الجمهورية التونسية — الطعام والمطبخ

> منهجية: لكل طبق يُذكَر اسمه المحلي + المكونات + المناسبة + المنطقة + الأصل.
> المصادر: الجزيرة نت (الكسكسي)، أطيب طبخة، layalina، topsarabia، globaltribes، CNN العربي، sotor.

---

## 1. نظرة عامة 🟢

> المطبخ التونسي = خليط **أمازيغي + عربي + أندلسي + تركي + إيطالي + متوسطي**. سمة الغالبة: **الحرّاقة** (الهريسة — صلصة الفلفل الأحمر الحار) + زيت الزيتون + السميد (الكسكسي).

- **الزيتون وزيت الزيتون:** ركيزة أساسية (تونس من كبار المنتجين والمصدِّرين).
- **السميد:** أساس الكسكسي والخبز والحلويات.
- **الهريسة التونسية:** صلصة الفلفل الأحمر الحار + ثوم + بهارات — **روح المطبخ التونسي** (تميّزه عن جيرانه بقوة الحرّ).
- **التمر (دقلة نور):** في الجنوب/الواحات.

---

## 2. الأطباق الرئيسية

### (1) الكسكسي (الكسكسي) 🟢 — الطبق الوطني (تراث يونسكو 2020)
- **الوصف:** سميد قمح يُطهى على البخار في «الكسكاس» (وعاء من طابقين) + مرق أحمر متبَّل بالخضر (جزر/قرع/بطاطا) + لحم أو دجاج أو سمك + حمص + زبيب + بيض مسلوق + فلفل مقلي.
- **الأصل:** **أمازيغي** — وُجدت أوانٍ (منها الكسكاس) تعود للملك النوميدي **ماسينيسا** 🟢.
- **التراث:** الكسكسي مُدرَج في قائمة اليونسكو للتراث الثقافي غير المادي (2020) — ملف مشترك مع الجزائر/المغرب/موريتانيا 🟢.
- **المناسبة:** وجبة الجمعة + الأعراس والأفراح والأتراح + «الوعدة» (زيارة الأولياء).
- **الأصناف:**
  - **المسفوف:** كسكسي رقيق بالزبيب/الفواكه الجافة/اللبن.
  - **الكسكسي المغموم:** بالبهارات/البصل/الفلفل/الطماطم (الجنوب).
  - **كسكسي المؤونة:** يُحضَّر مرة بالبخار ثم يُجفَّف تحت الشمس (2–3 أيام) ويُخزَّن (من مايو إلى يناير) — «بيت المونة».
- **الفوارق الجهوية 🟢:**
  - **سيدي بوزيد/الوسط:** بلحم العلوش (الخروف).
  - **صفاقس/الساحل الشرقي:** بالسمك (الحوت).
  - **الساحل (سوسة/المنستير):** بالعصبان (الفوارغ المحشية).

### (2) البريك (البوراك) 🟢 — ملك مائدة رمضان
- **الوصف:** عجينة «الملسوقة» الشفافة الدائرية تُحشى بالبيض + تونة + بطاطا + بقدونس + هريسة + جبن أحيانًا، ثم تُقلى.
- **الأصل:** **أندلسي** 🟡.
- **المناسبة:** فطور رمضان + مقبَّل يومي.
- **التنوع:** بريك بالتونة / بالبيض / بالقديد / الحلو.

### (3) اللبلابي 🟢 — أكلة الشتاء الشعبية
- **الوصف:** حمص مسلوق + كمون + قطع خبز + عصير ليمون + زيت زيتون + هريسة + بيض مسلوق/تونة (حسب الرغبة).
- **المناسبة:** فصل الشتاء (مقاوم للبرد).
- **النسخة باللحم:** «هرقمة» (تُضاف قطع لحم البقر).

### (4) الشكشوكة 🟢
- **الوصف:** طماطم + فلفل (أحمر/أخضر/أصفر) + ثوم + بصل + بيض يُطهى فوق الخلطة + كمون + هريسة.
- **المناسبة:** فطور/غداء شعبي (خاصة رمضان).

### (5) الكفتاجي 🟢
- **الوصف:** بطاطا + يقطين + فلفل + بيض (كلٌّ يُقلى وحده) + صلصة طماطم/ثوم/كزبرة/هريسة — تُخلط وتُقدَّم مع الخبز.
- **المناسبة:** طبق شعبي سريع.

### (6) العصبان (الفقاس) 🟢
- **الوصف:** فوارغ (أمعاء) محشية باللحم المفروم + الخضر + التوابل + الأرز أحيانًا — تُطبخ في المرق.
- **المناسبة:** مع الكسكسي في الساحل.

### (7) الطاجين التونسي 🟡
- **الوصف:** شبيه بالفرطاسة — لحم/دجاج + خضر + بيض + جبن — يُخبَز في الفرن (يختلف عن الطاجين المغربي).

### (8) النواصر 🟢
- **الوصف:** دجاج + بصل + بطاطا + حمص + زيت زيتون + بهارات تونسية — عجينة تُقطَّع مربعات.
- **الأصل:** مدينة **تينجة** (ولاية بنزرت) 🟢.

### (9) عين السبنيورية 🟡
- **الوصف:** لحم طازج + بيض مسلوق + بقدونس + بهارات + جبن — يُلف حول البيضة.
- **الأصل:** **أندلسي** — قدِم بها الوافدون من الأندلس.

### (10) الحريرة/الشوربة التونسية 🟢
- **الوصف:** حساء بالحمص/العدس/الطماطم/اللحم/البهارات — رمضان.

### (11) السلطة المشوية (الفولية) 🟢
- **الوصف:** فلفل + طماطم + ثوم مشوي على الجمر + زيت زيتون + كمون + تونة + بيض + زيتون — مقبَّل تونسي شهير.

## 3. الحلويات 🟢

| الحلوى | الوصف | المناسبة |
|---|---|---|
| **البقلاوة** | رقائق + لوز/فستق/عسل — شرقية/أندلسية | المناسبات |
| **غريبة الحمص** | حمص مرحي + نشا + سكر + زبدة — تقليدية | الأعياد |
| **الزلابية** | عجينة مقلية بالعسل/السكر | رمضان |
| **المقروط** | سميد + تمر + عسل — صحراوي/جنوبي | الجنوب |
| **المعمول / الكعك** | تمر/لوز/مكسرات | الأعياد |
| **حلوة الصميد** | سميد + سكر + ماء زهر | يومي |
| **البقلاوة التونسية** | بالفستق الحلبي/اللوز/البندق | المناسبات |

---

## 4. الخبز والمشروبات 🟢

- **الخبز التونسي:** أنواع منها «الطابونة» (خبز تقليدي مخبوز في فرن طيني) + الخبز الفرنسي (الباغيت — إرث الحماية).
- **البوكا (Boukha):** مشروب فوار تقليدي بنكهة التين/اللوز/ماء الزهر — تونسي أصيل.
- **القهوة التونسية:** قهوة مُحيَّاة (مضاف إليها ماء زهر/ورد أحيانًا) — «قهوة الصباح».
- **الشاي بالنعناع:** ضيافة (أقل طقوسًا من «أتاي» المغربي).

---

## 5. ربط الطعام بالجغرافيا 🟢

| المنطقة | الأطباق المميزة | السبب |
|---|---|---|
| الشمال (التل) | الحبوب + الكروم + البيض + الزبدة | مناخ ممطر + غابات |
| الساحل الشرقي | الكسكسي بالسمك + زيت الزيتون + المالوف | ساحل + زيتون + حضر |
| الوسط | الكسكسي بلحم العلوش + الزيتون | سهول + رعي |
| الجنوب (الواحات) | التمر (دقلة نور) + المقروط + الكسكسي المغموم | صحراء + نخيل + بهارات |

---

## 6. ملاحظات ثقافية 🟢

- **الكسكسي = هويّة اجتماعية:** وجبة الفقراء والأغنياء، في الأفراح والأتراح والوعدة — رمز الجماعة («اللمّة»).
- **الهريسة = بصمة تونسية:** تميّز المطبخ التونسي بقوة الحرّ عن جيرانه (المغرب/الجزائر).
- **الزيتون:** رمز اقتصادي-ثقافي (تونس من كبار منتجي زيت الزيتون عالميًّا).
- **رمضان:** موسم الطبخ الذروة — البريك + الشكشوكة + الحريرة + الزلابية + «لمّة» العائلة.
- **الإرث الأندلسي:** البريك + عين السبنيورية + بعض الحلويات.

---

## خلاصة الطعام

المطبخ التونسي = **مطبخ متوسطي-مغاربي حارّ** قائم على الكسكسي (تراث يونسكو) + الهريسة + زيت الزيتون + البريك الأندلسي + اللبلابي الشتوي + العصبان الساحلي + حلويات التمر الجنوبية. تتمايز الأطباق جهويًّا: السمك في صفاقس، لحم العلوش في سيدي بوزيد، العصبان في الساحل، التمر في الجنوب. 🟢
