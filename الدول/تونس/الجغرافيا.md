# الجمهورية التونسية — الجغرافيا

> منهجية: تربط التضاريس بالمناخ والمياه والثقافة (اللباس/الطعام/العمارة/السكن). علامات الثقة: 🟢/🟡/🟠.
> المصادر: ويكيبيديا (جغرافيا تونس/مناخ تونس)، المعرفة، أرابيكا، موقع إدارة المعلومات (economy.gov.tn)، موضوع.

---

## 1. الموقع والمساحة 🟢

- **شمال أفريقيا / المغرب العربي** — أصغر دول المغرب العربي مساحةً.
- **المساحة:** 163,610 كم² (المرتبة 91 عالميًّا).
- **الإحداثيات:** 30°–38°N و7°–12°E — في منتصف الطريق بين المحيط الأطلسي ودلتا النيل.
- **الحدود:** الجزائر (غرب، 965 كم) + ليبيا (جنوب شرق، 459 كم) + البحر المتوسط (شمال وشرق، ساحل 1,148–1,566 كم).
- نسبة المياه: 5.04%.

---

## 2. التضاريس الكبرى: ثلاثة أقاليم كبرى 🟢

> تونس تضاريس متضادة: **شمال جبلي أخضر** + **وسط سهلي جاف** + **جنوب صحراوي**. هذا التقسيم هو مفتاح فهم توزيع السكان والثقافة.

### (أ) التل الأعلى (الشمال) 🟢
- امتداد **سلسلة الأطلس** (الظهرة التونسية + جبال **خمير/نميشة** في الشمال الغربي) — جبال غابات وموارد مائية.
- **أعلى قمة:** جبل **الشعانبي** (1,544 م) — ولاية القصرين.
- سهول ساحلية ضيقة + وادي مجردة.
- **الأثر الثقافي:** لباس صوفي دافئ (البرنوس/القشابية) + زراعة الحبوب والكروم + الغابات.

### (ب) الوسط التونسي (السهول/الفيافي) 🟢
- هضبة مركزية + الفيافي العليا والمنخفضة تنتهي عند الساحل الشرقي.
- سهل وادي مجردة الوسطى + سهل **الجفارة** (تونس الكبرى) + سهل **الساحل** (سوسة/المنستير).
- **الأثر الثقافي:** زراعة الزيتون (الساحل) + المدن الحضرية القديمة + اللباس الحضري (السفساري/الكبوس الغارق).

### (ج) الجنوب الصحراوي 🟢
- الصحراء الكبرى + **العرق الشرقي الكبير** (الكثبان الرملية) + سلسلة **الشطوط** (بحيرات ملحية) + الهضاب الصخرية + الواحات.
- **أدنى نقطة:** **شط الغرسة** (17− م تحت سطح البحر).
- **الشطوط:** شط الجريد + شط الفجاج + شط الغرسة (خط شرقي–غربي عند حافة الصحراء، من خليج قابس إلى الجزائر).
- **الواحات:** توزر + نفطة + قبلي + دوز — نظام الري التقليدي **«الفجّارات»** (قنوات تحت أرضية).
- **الأثر الثقافي:** عمارة محفورة في الصخر (مطماطة) + زراعة النخيل (دقلة نور) + اللباس الصحراوي + السياحة الصحراوية.

---

## 3. الخط الساحلي والجزر 🟢

- **الساحل الشمالي:** صخري مرتفع + خلجان واسعة (خليج تونس) + رؤوس (الرأس الطيب).
- **الساحل الشرقي:** رملي منخفض + خلجان (خليج الحمامات + خليج قابس) + جزر.
- **الجزر:**
  - **جربة** (الجنوب الشرقي — مربوطة بالبر بطريق روماني قديم).
  - **أرخبيل قرقنة** (الشرق — منخفض، أقصى ارتفاع 13 م) + **كركوان** الأثرية (بونيقية).
  - جبل وقراقر وغيرها.
- **الأثر الثقافي:** صيد بحري (السمك/الحوت) + سياحة شواطئ + مطبخ بحري (الكسكسي بالسمك في صفاقس).

| العنصر | الوصف |
|---|---|
| **وادي مجردة (المجردة)** | أطول أنهار تونس (نحو 450 كم) — **النهر الوحيد الدائم الجريان**؛ ينبع من الجزائر ويعبر التل. |
| الموارد المائية | نحو 4.5 مليار م³ (2.7 سطحية + 1.8 جوفية) — **نسبة منخفضة** مقارنة بمغاربية أخرى. |

| السدود | شبكة سدود وبحيرات جبلية لتعويض ندرة الأمطار. |
| التحدي | **الإجهاد المائي** — تونس من أكثر دول العالم إجهادًا للمياه (المرتبة 18 عالميًّا) 🟡. |

## 5. المناخ 🟢

> المناخ **متدرّج** من الشمال إلى الجنوب: متوسطي → شبه جاف → صحراوي. تونس تقع في التقاء المؤثرات البحرية المتوسطية والصحراوية.

- **الشمال والساحل:** مناخ **متوسطي** (شتاء معتدل ممطر + صيف حار جاف). أمطار > 400 مم/سنة (طبرقة ~1,025 مم؛ بنزرت 636 مم).
- **الوسط:** **شبه جاف** (200–400 مم).
- **الجنوب:** **صحراوي جاف** (< 200–100 مم؛ أقصى الجنوب < 50 مم في البرمة).
- **الحرارة:** متوسط سنوي نحو 18°م؛ قد تتجاوز 40°م صيفًا (الصحراء حتى ~50°م) وتنزل دون الصفر شتاءً في جبال خمير (تالة −15°م سُجِّلت).
- **الرياح:** بحرية رطبة (الشمال) + شرقية/قارية حارة جافة (الجنوب).
- **7 مناطق بيومناخية** بين المتوسطي والصحراوي.
- **تغير المناخ 🟡:** تونس أكثر بلد متوسطي تضررًا — ارتفاع حرارة + جفاف + تآكل سواحل + ارتفاع بحر.

### ربط الجغرافيا بالثقافة 🟢

| المنطقة | المناخ/التضاريس | الأثر الثقافي |
|---|---|---|
| التل (الشمال الغربي) | جبلي + ممطر + غابات | برنوس/قشابية صوفي + زراعة حبوب/كروم + لهجة محافظة قريبة من الفصحى (الجنوب الغربي) |
| الساحل الشرقي | متوسطي + سهول زيتون | لباس حضري (سفساري/كبوس غارق) + زيت الزيتون + المالوف + سياحة |
| الوسط | شبه جاف + سهول | زراعة الزيتون + مدن (قيروان/سيدي بوزيد) + الكسكسي بلحم العلوش |
| الجنوب | صحراوي + واحات + شطوط | عمارة محفورة (مطماطة) + النخيل/التمر + اللباس الصحراوي + سياحة صحراوية |

## 6. التربة والغطاء النباتي 🟢

- **الشمال:** تربة حمراء متوسطية خصبة (التل) — حبوب + كروم + غابات (بلوط/صنوبر).
- **الوسط:** تربة رسوبية + اللِّس — زيتون + حبوب + رعي.
- **الجنوب:** تربة رملية/حصوية + سبخات — نخيل + رعي بدوي.
- **الغطاء الغابي:** ضعيف (نحو 5%) — يتركز في خمير/عين دراهم/الشمال الغربي.
- **التصحّر 🟡:** زحف الصحراء شمالًا — تحدٍّ بيئي كبير.

---

## 7. المناطق الطبيعية المحمية 🟢

- **8 حدائق وطنية** (المحميات) — أبرزها **محمية إشكل الوطنية** (تراث يونسكو الطبيعي 1980 — طيور مهاجرة).
- محمية بوكورنين (قرب تونس) — الغابة الأخيرة قرب العاصمة.
- محمية جبل الشعانبي (القصرين).

---

## 8. التحديات البيئية 🟡

1. **الإجهاد المائي** (المرتبة 18 عالميًّا) + موجات جفاف متكررة (2016–2023) → ضر زراعي وهجرة ريفية.
2. **التصحّر** — زحف رمال الجنوب.
3. **تآكل السواحل** + ارتفاع البحر (تهديد المناطق الساحلية/السياحية).
4. **تلوث السبخات** والمناطق الصناعية (قابس/صفاقس).
5. **ضعف الغطاء الغابي** + الحرائق.

---

## خلاصة جغرافية

تونس = **دولة صغيرة المساحة لكن متنوعة التضاريس** (جبال + سهول + صحراء + ساحل + واحات + شطوط) في **1,300 كم** من الساحل المتوسطي. هذا التنوع هو **أساس التباين الثقافي** بين التل (أمازيغي/حبوب) والساحل (حضري/زيتون) والوسط (فلاحي) والجنوب (صحراوي/واحات). 🟢
