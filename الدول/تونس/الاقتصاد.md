## 2. القطاعات الاقتصادية

### (أ) الصناعة التحويلية 🟢 — ركيزة التصدير
- **النسيج والألبسة:** أكبر قطاع تصديري — معظم الإنتاج للاتحاد الأوروبي (تجميع وتصنيع).
- **الأقطاب الصناعية:** تكنولوجيا المعلومات + الطيران (إيرباص/PDMA) + الصناعات الميكانيكية والكهربائية + الكابلات.
- **الأحذية** + المنتجات الغذائية + المشروبات.

### (ب) التعدين والطاقة 🟢
- **الفوسفات:** تونس كانت **ثاني منتج عالمي للفوسفات** — الحوض المنجمي بـ**قفصة** (الرديف/المتلوي/المظيلة) → المركب الكيميائي بصفاقس وقابس (تحويل + أسمدة).
  - 🟡 **تراجع حاد بعد 2011** بسبب الإضرابات والاحتجاجات + خسارة أسواق → «ثروة ضائعة».
- **النفط/الغاز (الهيدروكربونات):** إنتاج متناقص — تونس مستورد صافٍ للطاقة في السنوات الأخيرة 🟡 (باطن/العديد/الشطر).
- خام الحديد (جريسة/أم العرائس).

### (ج) الزراعة والبحر 🟢
- **الزيتون وزيت الزيتون:** تونس من **كبار مصدِّري زيت الزيتون** عالميًّا — تصدر نحو **90% بالجملة**؛ أحيانًا تتجاوز عائداته السياحة والفوسفات (موسم 2023/2024 ~1.1 مليار $).
- **التمر (دقلة نور):** الجنوب/الواحات — تصدير.
- **الحبوب (قمح/شعير):** التل — لكن العجز يُستورَد.
- **الحمضيات:** الوطن القبلي (نابل).
- **الصيد البحري:** صفاقس (أولى) + قابس + بنزرت — سمك/سردين/قشريات.
- 🟡 **الجفاف** يضرب الزراعة بشدة (2016–2023) → تراجع إنتاج + هجرة ريفية.

### (د) السياحة 🟢 — ركيزة العملة الصعبة
- تمثل نحو **9% من الناتج المحلي**.
- **أنواعها:**
  - **سياحة الشواطئ:** الحمامات/سوسة/المنستير/جربة (معظم الوافدين أوروبيون).
  - **سياحة الآثار:** قرطاج + الجم + دقة + القيروان.
  - **سياحة صحراوية:** توزر + تطاوين (مطماطة) + دوز.
  - **سياحة علاجية:** المياه الحرارية (الجنوب الغربي/قفصة) — متصاعدة.
  - **سياحة ثقافية/دينية:** الموالد + جربة (كنيس الغريبة).
- 🟡 **تضررت بالإرهاب** (هجمات باردو 2015 + سوسة 2015) + كوفيد (2020) — ثم انتعاش بعد 2022.

### (هـ) الخدمات 🟢
- الخدمات (تجارة + نقل + اتصالات + مالية + إدارة) أكبر قطاع تشغيل (~55%).
- **الاقتصاد الرقمي** + مراكز النداء (نسبة كبيرة من الشباب).

## 3. الصادرات والواردات 🟢

- **الصادرات (نحو 13.8 مليار $):** الألبسة/المنسوجات + **زيت الزيتون** + الفوسفات/الكيماويات + الكابلات/الأجهزة الكهربائية + المنتجات الميكانيكية + الهيدروكربونات + التمور + الحمضيات.
- **الواردات:** النفط/الطاقة + المعدات + المواد الأولية + القمح + الأدوية + السيارات.
- **عجز مزمن** في الميزان التجاري (تونس تستورد أكثر مما تصدر) — يُخفَّف جزئيًّا بزيت الزيتون + السياحة + التحويلات.

## 4. التحديات الاقتصادية 🟡

| التحدي | الوصف | الثقة |
|---|---|---|
| **الدين العام** | تجاوز 80–100% من الناتج — عبء خدمة الدين يستحوذ على جزء كبير من الميزانية | 🟢 |
| **البطالة** | ~15%؛ بطالة الشباب وحاملي الشهادات العليا من الأعلى في المنطقة + لامساواة جهوية (الداخل/الجنوب) | 🟢 |
| **تآكل القدرة الشرائية** | ارتفاع الأسعار + ثبات الأجور → تراجع مستوى المعيشة | 🟢 |
| **الشركات العمومية المتعثرة** | الشركات الحكومية (نقل/طاقة/أسمدة) تثقل الميزانية | 🟢 |
| **نقص بعض السلع** | قيود الاستيراد (2022+) → نقص القهوة/الشاي/الزيت/القمح/الأدوية أحيانًا | 🟢 |
| **الجفاف وتغير المناخ** | ضرب الزراعة + نقص المياه | 🟢 |
| **اللامساواة الجهوية** | تونس الكبرى/الساحل متقدمان vs الداخل/الجنوب متخلفان — محرض احتجاجات | 🟢 |
| **الفوسفات المعطَّل** | الإضرابات → خسارة عملة صعبة + تراجع التصنيف | 🟢 |
| **صندوق النقد الدولي** | مفاوضات متعثرة لإصلاحات (أجور/دعم/شركات عمومية) | 🟡 |

## 5. السياق السياسي-الاقتصادي (حياد 🟡)

- **2011 (الثورة):** قطع مع سياسة بن علي الليبرالية المُوجَّهة → ضغوط اجتماعية + زيادة دعم + توظيف عمومي.
- **2020 (كوفيد):** انكماش 8.6% + عجز 9.4% + قفزة الدين.
- **2021 (الإجراءات الاستثنائية):** قيس سعيد → سياسة مالية توسعية باهظة + زيادة دعم → عجز كبير 4 سنوات.
- **2022–2025:** محاولة استقرار — تراجع الدين نسبيًّا (82%) + نمو هش + نقص سلع.
- **النمو الهش:** متوسط العقد ~1% — لا يكفي لاستيعاب الشباب ولا رفع الدخل. 🟢

> **حياد 🟡:** تقييم الإجراءات الاستثنائية اقتصاديًّا محل خلاف (السلطة: تجنُّب الانهيار؛ منتقدون: تراكم ديون + تآكل قطاع خاص). يُعرض كخلاف.

## 6. ربط الاقتصاد بالجغرافيا 🟢

| المنطقة | النشاط الاقتصادي |
|---|---|
| تونس الكبرى | خدمات + صناعة + إدارة + موانئ |
| الساحل (سوسة/المنستير/نابل) | سياحة شاطئية + زيتون + حمضيات + صناعة |
| الشمال الغربي (باجة/جندوبة/الكاف) | حبوب + غابات + كروم |
| الوسط (القيروان/سيدي بوزيد/القصرين) | زراعة + رعي + فلاحة (الأقل تنمية) |
| صفاقس | زيتون + صناعة + فوسفات (التحويل) + صيد بحري |
| الجنوب الغربي (قفصة/توزر/قبلي) | فوسفات + تمور + سياحة صحراوية |
| الجنوب الشرقي (قابس/مدنين/تطاوين) | صناعة كيميائية + سياحة + تجارة حدودية |

## 7. التحويلات والهجرة 🟢

- **تحويلات المغتربين:** مصدر مهم للعملة الصعبة (أكثر من ملياري دينار/سنة) — جالية كبيرة في فرنسا/إيطاليا/ألمانيا.
- **الهجرة غير النظامية:** ظاهرة متصاعدة (شباب الداخل/الساحل) نحو أوروبا — محرك اجتماعي-اقتصادي 🟡.

## خلاصة الاقتصاد

الاقتصاد التونسي = **اقتصاد هش متعدد الأقطاب** (صناعة تصديرية + زيت زيتون + فوسفات + سياحة + تحويلات) لكنه **مثقل بالدين والبطالة وتآكل القدرة الشرائية**، مع **لامساواة جهوية** بين الساحل/العاصمة (متقدم) والداخل/الجنوب (متخلف). الفوسفات ثروة ضائعة، وزيت الزيتون شريان متصاعد، والسياحة نصف تعافٍ. النمو هش (~2%) ولا يكفي. مستقبل تونس الاقتصادي رهين بإصلاحات هيكلية + قطاع خاص + معالجة اللامساواة الجهوية. 🟢/🟡
