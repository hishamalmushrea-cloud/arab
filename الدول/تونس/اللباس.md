# الجمهورية التونسية — اللباس التقليدي

> منهجية: لكل قطعة يُذكَر اسمها المحلي + المناسبة + المنطقة + الأصل (أمازيغي/عربي/تركي/أندلسي).
> المصادر: ويكيبيديا (لباس تقليدي تونسي)، أرابيكا، areq.net، البيان، CNN العربي، taqaled، al-ain.

---

## 1. ملاحظة أولى: تنوع إقليمي/تاريخي 🟢

> اللباس التونسي = خليط **أمازيغي (الركيزة) + عربي + تركي عثماني + أندلسي**. يختلف من معتمدية إلى أخرى في القماش وطريقة التطريز. يُقتصَر اليوم على المناسبات الدينية والحفلات والأعراس والموالد والختان.
> **اليوم الوطني للباس التقليدي التونسي:** **16 مارس** (من كل عام — إحياء وإعزاز الهوية). 🟢

---

## 2. الأصول التاريخية 🟢

| الأصل | القطع |
|---|---|
| **أمازيغي** (الركيزة) | الجبة + البرنوس + القشابية + التخليلة + البخنوق |
| **عربي** | السفساري (العباءة) + العمامة + السروال + الجلباب + البدعية |
| **تركي عثماني** | الشاشية + الكسوة + الكبوس الغارق (أرستقراطي) |
| **أندلسي** | الطريون + القمجة + بعض الحلويات/المطرزات |

> بعض المصادر ترجع أصول الملية والبدعية والعمامة والسفساري إلى **حضارة قرطاج** 🟡.

## 3. اللباس الرجالي 🟢

### القطع الأساسية

| القطعة | الوصف | الأصل/الاستخدام |
|---|---|---|
| **الجبة** | لباس خارجي فضفاض مغلق، فتحة مطرَّزة عند الرقبة + فتحتان للذراعين | **أمازيغي** (تستعمل في بلدان المغرب كله — الجبة القبائلية الجزائرية) — يُلبس فوق قميص + سروال |
| **البرنوس (البرنس)** | معطف صوفي طويل فضفاض بلا أكمام + غطاء رأس — شتوي | أمازيغي — فوق الجبة |
| **القشابية** | برنوس بتصميم خطوط بيضاء/بينة — يطلق عليها «البرنوس» في بعض المناطق | أمازيغي |
| **الفرملة** | جاكيت مطرَّز (مفتوح أمامي) — نسخة رسمية | — |
| **الصدرية** | نسخة غير رسمية من الفرملة (3 فتحات للرأس والذراعين) | — |
| **السروال** | بنطلون فضفاض بحزام حريري | عربي — مع الجبة/الصدرية |
| **البلغة** | حذاء جلدي تقليدي بلا كعب | — |
| **الشاشية** | قبعة حمراء مخروطية | **تركي عثماني** |
| **العمامة** | غطاء رأس | عربي |

> زي العريس في الأعراس: **الجبة + السروال العربي + البلغة + الشاشية**. 🟢

## 4. اللباس النسائي 🟢 — تنوع إقليمي استثنائي

### (أ) السفساري 🟢 — رمز المرأة التونسية
- **الوصف:** قطعة قماش بيضاء من الحرير تتلحف بها المرأة كامل جسدها.
- **الاستخدام:** لباس الخروج التقليدي (الحضر) — تراجع لكن يُحافَظ عليه في المناسبات.
- **الأصل:** عربي (العباءة التونسية).

### (ب) الملية / الحرام 🟢
- **الوصف:** لحاف ترتديه المرأة وتشدّه بمشبكين («الخلال») + حزام.
- **التنوع:** **الملية الحمراء** للمناسبات (الأعراس/الختان)؛ ألوان أخرى يوميًّا.
- **الانتشار:** الشمال (الملية) + الوسط والجنوب (الحرام).

### (ج) الفوطة والبلوزة 🟢
- **الوصف:** قطعة سفلية (الفوطة) + قطعة علوية (البلوزة) — لباس شعبي ساحلي.

### (د) الكبوس الغارق 🟢 — تونس العاصمة
- **الوصف:** بلوزة + سروال واسع + تطريز حسب الذوق.
- **الأصل:** **تركي** — لباس الطبقة الأرستقراطية الحضرية.

### (هـ) الطريون 🟢 — القيروان
- **الوصف:** بلوزة أنيقة من المخمل + سروال واسع (يبدو كالتنورة) + تطريز بخيوط الذهب/العدس/الكنتيل.
- **الظهور:** القرن 19.
- **الألوان:** الأسود الأكثر شيوعًا + أخضر/أزرق.

### (و) الجبة العكري 🟢
- **الوصف:** قطعتان من القماش بلونين داكنين + تطريز بخيوط الذهب.
- **المناسبة:** الأعراس.

### (ز) المرساوي 🟢 — لباس العروس
- **الوصف:** بلوزة + سروال واسع + تطريز ذهبي/فضي — اللباس الرسمي للعروس ليلة الزفاف.

### (ح) الدخلة 🟢
- **الوصف:** لباس العروس في حفل الزفاف (الفستان الفاخر).

### (ط) الكدرون 🟢 — الحمامات
- **الوصف:** جاكيت طويل إلى الركبة مطرَّز بالعدس/الكنتيل/التل — مطوَّق بحزام ذهبي عند العنق.

### (ي) قفطان الحمامات 🟢
- **الوصف:** أحد أقدم الألبسة التقليدية التونسية — مطرَّز.

### (ك) كسوة الجوهر 🟢
- **الوصف:** زي عروس فاخر — بلوزة (بتصميم يشبه الأجنحة) + سروال فاشكة — مطرَّز كاملًا بالجوهر.

### (ل) البخنوق 🟢 — أمازيغي
- **الوصف:** غطاء المرأة أحمر مطرَّز — لباس بربري.

### (م) لباس جربة 🟢
- **الملحفة الجربية:** لحاف من الحايك مخطَّط بألوان — لباس خروج.
- **الجبة الجربية:** فستان من قماش الحايك الجربي/البسكري.

### (ن) جبة قرقنة 🟢
- أنواع: جبة غولي/شطار (لونان) + جبة ملف + جبة صادة + جبة بَستري.

## 5. الإكسسوارات والحلي 🟢

| القطعة | الوصف |
|---|---|
| **الشمروخ** | حلي لتزين اللباس — الجنوب مع الحرّام/الملية |
| **الفرق المكني** | حلي مطرَّز بالجوهر — الجبين/الحزام |
| **الدبلون الجربي** | قلادة بقطع معدنية — الرقبة/الجبين |
| **الخلخال الذهبي** | يزين ساق العروس (عادات الأعراس) |
| **الخلال** | مشبك لشد الملية/الحرام |
| **الطاقية** | قبعة مطرَّزة بالعدس/الكنتيل |

## 6. التطريز بحسب المنطقة 🟢

| المنطقة | طريقة التطريز |
|---|---|
| **الشمال** | خيوط الفضة + العدس + الكنتيل |
| **المدن الساحلية** | خيوط الحرير + الذهب — أشكال أشخاص/أزهار/حيوانات |
| **الجنوب** | نماذج هندسية مخرمة |

## 7. الفروق بحسب البيئة 🟢

| البيئة | اللباس | السبب |
|---|---|---|
| العاصمة (تونس) | الكبوس الغارق + السفساري + القفطان | حضري + تركي + كوزموبوليتي |
| الساحل (سوسة/المنستير/الحمامات) | الفوطة والبلوزة + القفطان + الفرملة | متوسطي + زيتون |
| القيروان (الوسط) | **الطريون** (مخمل + ذهب) | حضر ديني/تاريخي |
| الشمال الغربي (خمير/الكاف) | القشابية + البرنوس الصوفي | جبلي + برد |
| الجنوب (توزر/قبلي/مدنين) | الحرام + الملية + البخنوق + الجبة الصحراوية | صحراوي + أمازيغي |
| جربة (الجنوب الشرقي) | الملحفة الجربية + الجبة الجربية | جزيرة + أمازيغي/يهودي |

## 8. التطور الحديث 🟢

- **السفساري** تراجع لكن يُحافَظ عليه في المناسبات + إحياء («خليك تونسي» 2016).
- **الجبة/الطريون/المرساوي** قوية في الأعراس والمناسبات.
- **حملات إحياء:** «خليك تونسي» (CNN 2016) + اليوم الوطني للباس التقليدي (16 مارس) + مسيرة «الخارجة» في المدن.
- **الحجاب/اللباس المحتشم:** في الأوساط المحافظة (تنامٍ بعد 2011 ثم نسبية).
- **البدلة الغربية/الجينز:** لباس يومي سائد (إرث الحماية + عولمة).

---

## 9. ملاحظة نقدية

- اللباس التونسي **فسيفساء إقليمية-تاريخية** — لا يُعمَّم.
- **الجبة** (أمازيغية) و**السفساري** (عربية) و**الشاشية/الكبوس الغارق** (تركية) و**الطريون** (قيرواني) = أبرز الرموز.
- يربط اللباس بين **الأعراس والهوية الجهوية**: ترتدي العروس لباس منطقتها وتتوشح بالحلي الذهبية.
- الإحياء الوطني (16 مارس) محاولة لمواجهة «التغريب» والحفاظ على الذاكرة الثقافية. 🟢
