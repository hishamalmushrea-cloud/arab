# الجمهورية التونسية — العادات والثقافة

> منهجية: العادات + المناسبات + الفنون + العمارة + الحرف. ربط الجغرافيا بالثقافة.
> المصادر: ويكيبيديا (مالوف/ثقافة تونس)، الجزيرة نت، fanack، ديوان العرب، الموسوعة التونسية، الاتحاد.

---

## 1. الموسيقى والفنون 🟢

### (أ) المالوف — الموسيقى الكلاسيكية التونسية 🟢
- **الوصف:** موسيقى كلاسيكية مغاربية ذات **أصول أندلسية** — قوامه الشعر والموشحات والزجل والدوبيت + إضافات لحنية محلية.
- **النوبة:** القالب الأساسي — **13 نوبة** تونسية موثَّقة كاملة (تونس = الدولة الوحيدة بتراث مدوَّن كامل للنوبات).
- **الأنواع:** مالوف الجدّ (صوفي — مدائح) + مالوف الهزل (بلاط/أمراء).
- **المراكز:** تونس العاصمة + **تستور** (أندلسي/يهودي) + الكاف + بنزرت + صفاقس.
- **المؤسسات:** **المعهد الرشيدي** (1934 — أول معهد موسيقي مغاربي) + الفرقة الوطنية + **«بيت المالوف»** (مدينة الثقافة — توثيق وتكوين).
- **الآلات:** العود التونسي + الكمنجة + القانون + القرنيطة + الناي + الدربوكة + الطار (البندير) + النقرة + الغيطة.
- **اليونسكو 🟡:** المالوف ضمن النقاشات للتراث غير المادي (مجال مغاربي مشترك).

### (ب) الموسيقى الشعبية 🟢
- **الآلات:** الزكرة + القصبة (الفحل) + المزود + الطار + الطبل + البندير + القصعة + الشقاشق (الكراكب).
- **الفزاعي:** إيقاع شمالي/وسطي — قرع طبول في بداية الأعراس لجمع الناس.
- **مخمَّس الخيل:** إيقاع رقصة الخيول في الحفلات الشعبية.
- **غناء الجحافي:** أغاني العروس في «الجحفة» (الهودج) من بيت أهلها إلى بيت زوجها.
- **غناء الجنوب:** أصوات مرتفعة بالحنجرة (قبائل غبنتن/الحمارنة — جنوب).

### (ج) الرقص 🟢
- الرقص التونسي شبيه بالمصري لكن **أسرع** + لمسات أسلوبية مختلفة — في الأفراح والمناسبات.

## 2. الأعراس والمناسبات 🟢

### (أ) العرس التونسي — عدة أيام 🟢
- **الخطوبة** → **الحنة** (ليلة الحناء) → **الحمام** (الطهارة) → **الجلوة** (عرض العروس) → **الوطية** (لباس العروس الجهوي) → **الدخلة** (الزفاف).
- ترتدي العروس **اللباس التقليدي لمنطقتها** + **الخلخال الذهبي** + حلي ذهبية.
- يرتدي العريس **الجبة + السروال العربي + البلغة + الشاشية**.
- يُخصَّص يوم للباس التقليدي خلال الأعراس («الخارجة»).

### (ج) الأعياد الدينية 🟢
- **المولد النبوي:** مواكب الزوايا الصوفية (العيساوية، العروسية، السعدية) — «الموكب المولدي» + النوبة.
- عيد الفطر + عيد الأضحى + رأس السنة الهجرية + المولد.
- **زيارة الأولياء («الوعدة»):** مواسم للصالحين + الكسكسي.

## 3. العمارة 🟢

### (أ) المدينة العتيقة (المدن الإسلامية) 🟢
- **مدينة تونس العتيقة** (تراث يونسكو 1979) — نحو 700 نصب (قصور/مساجد/أضرحة/مدارس/أسواق/زوايا) — أزقة ضيقة + أسواق متخصصة + منازل بأحواش داخلية.
- **القيروان** (تراث يونسكو 1988) — جامع عقبة بن نافع + المدينة العتيقة.
- **سوسة** (تراث يونسكو 1988) — الرباط + القصبة + المدينة العتيقة.
- **العناصر:** المداميك + الأقواس + الزليج + الصومعة المربعة (مالكية) / المثمنة (حنفية/تركية) + الأحواش + المقابر.

### (ب) العمارة الأمازيغية الجنوبية 🟢
- **مطماطة:** منازل محفورة في الصخر (حفر فناء ثم غرف حوله) — تكيُّف حراري طبيعي (برد صيفًا + دفء شتاءً) 🟢.
- القباب/القباء الصحراوية + المخازن الحصينة («القصبة»).

### (ج) العمارة الفينيقية/الرومانية 🟢
- قرطاج + الجم + دقة + سبيطلة + زغوان + حيدرة + أوتيك — مدن رومانية + معابد + مدرجات + قنوات مياه.

### (د) العمارة العثمانية 🟢
- جامع سيدي محرز (1692–1697 — قبة مركزية على طراز إسطنبول) + الجامع الجديد (1726 — سيراميك إزنيق) + حمودة باشا (1655).

## 4. الحرف اليدوية 🟢

| الحرفة | الوصف | المنطقة |
|---|---|---|
| **السجاد القيرواني** | سجاد صوفي يدوي — ازدهر القرن 18 (تأثير أناضول) | القيروان |
| **الفسيفساء (الموزاييك)** | أكبر مجموعة رومانية في العالم (متحف باردو) | — |
| **الخزف/الفخار** | خزف نابل (ملوَّن) + خزف تونس العتيقة | نابل |
| **الزليج** | بلاطات خزفية ملوَّنة | — |
| **النحاس** | أواني ومصابيح منقوشة | تونس العتيقة |
| **الجلد** | أحذية (البلغة) + حقائب + جلديات | تونس/قيروان |
| **الحلي الفضية** | حلي أمازيغية تقليدية | الجنوب/جربة |
| **النقش على الخشب** | منابر وأبواب | — |

> الحرف التونسية مزيج **إسلامي + روماني + عثماني + أمازيغي**. 🟢

## 5. القيم الاجتماعية والعادات 🟢

- **اللمّة:** مائدة العائلة الممتدة — رمز الجماعة والألفة.
- **الكرم والضيافة:** من قيم المجتمع التونسي («سلام على بلد الخيرات»).
- **احترام الكبار** + روابط العائلة الممتدة (رغم التحضر).
- **العلاقة بالأولياء:** الزيارات («الوعدة») + الموالد + الزوايا الصوفية (خاصة الريف).
- **المجلة (الأحوال الشخصية):** قيم الحداثة وقانون الأسرة الرائد عربيًّا (ميراث/طلاق/تعدد/أسرة) — أساس الفخر التونسي «الحداثي».

---

## 6. الفنون المعاصرة 🟢

- **السينما التونسية:** رائدة في العالم العربي — فيروزة (المرأة البحرية) + «صيف حلق الوادي» + المهرجانات.
- **المسرح والكوميديا:** علي الدوعاجي (الساخر) + فرق.
- **الأدب:** محمود المسعدي + أبو القاسم الشابي + الطاهر الحداد + الطاهر بن جلون (مغربي-تونسي الجذور).
- **المهرجانات:** قرطاج الدولي + المسرح بقرطاج + الحمامات + صفاقس + الموسيقى الصوفية.

## 7. ربط الجغرافيا بالثقافة 🟢

| المنطقة | البصمة الثقافية |
|---|---|
| تونس العاصمة | حضر + كوزموبوليتي + الكبوس الغارق + جامع الزيتونة + المالوف |
| القيروان | عاصمة إسلامية + الطريون + السجاد القيرواني + جامع عقبة |
| الساحل (سوسة/المنستير) | بحري + الفوطة والبلوزة + السياحة + الرباط |
| الشمال الغربي (خمير/الكاف) | جبلي أمازيغي + البرنوس + الغابات + اللهجة المحافظة |
| الجنوب (توزر/تطاوين) | صحراوي + مطماطة المحفورة + النخيل + سياحة صحراوية + الشابي |
| جربة | جزيرة + الملحفة الجربية + الأمازيغية/الإباضية/اليهود (الغريبة) |

## خلاصة العادات والثقافة

الثقافة التونسية = **ملتقى حضاري** (أمازيغي-عربي-إسلامي-أندلسي-عثماني-متوسطي-فرنسي) يتجلى في: **المالوف** (موسيقى الأندلسيين)، **المدينة العتيقة** (تونس/قيروان/سوسة)، **الأعراس الجهوية** (الطريون/المرساوي/الجبة)، **الزوايا الصوفية** (الموالد)، **مجلة الأحوال الشخصية** (الحداثة)، و**8 مواقع تراث يونسكو**. تونس = أصغر دول المغرب لكنها من أكثرها تنوعًا ثقافيًّا بفضل موقعها «المفترق». 🟢
