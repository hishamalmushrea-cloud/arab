## 3. الفتح الإسلامي والدول الإسلامية

| الفترة | الحدث | التصنيف |
|---|---|---|
| 647م | بدء **الفتح الإسلامي** لإفريقية (عصر الخليفة عثمان بن عفان). | 🟢 |
| 670م | **عقبة بن نافع** يؤسس مدينة **القيروان** (أول حاضرة إسلامية في المغرب العربي) + **جامع عقبة بن نافع** — أقدم مسجد في المغرب العربي. | 🟢 |
| 698م | تأسيس **جامع الزيتونة** في مدينة تونس (حسان بن النعمان). | 🟢 |
| 800 – 909م | **الدولة الأغلبية** — إبراهيم بن الأغلب يؤسس إمارة شبه مستقلة عن العباسيين، عاصمتها القيروان. ازدهار العمارة + فتح صقلية. | 🟢 |
| 909 – 972م | **الدولة الفاطمية** (الشيعية الإسماعيلية) — أطاحت بالأغالبة؛ عاصمتها **المهدية**؛ ثم انتقال مركزها إلى مصر بعد فتحها 969م. | 🟢 |
| 972 – 1148م | **الزيريون** (الصنهاجيون الأمازيغ) — ولاة الفاطميين على إفريقية ثم يستقلون. | 🟢 |
| 1050–1052 | هجرة **بني هلال وبني سليم** إلى إفريقية (تغريبة بني هلال) — رواية شعبية شهيرة؛ حجمها وتأثيرها موضع خلاف 🟡. | 🟡/رواية شعبية |
| 1148 – 1236م | **الموحدون** يضمون إفريقية. | 🟢 |
| 1228/1236 – 1574م | **الدولة الحفصية** — أول سلالة تونسية بمدتها (نحو 340 سنة)؛ عاصمتها تونس؛ ازدهار التجارة المتوسطية مع البندقية والجنوة. | 🟢 |

| الفترة | الحدث | التصنيف |
|---|---|---|

| **1934** | **الحبيب بورقيبة** يؤسس **الحزب الحر الدستوري الجديد** (النيودستور) — قيادة الحركة نحو الاستقلال. | 🟢 |

| 31 يوليو 1954 | خطاب قرطاج — بيار منديس فرانس يَعِد بالاستقلال الداخلي. | 🟢 |
| 3 جوان 1955 | اتفاقيات الاستقلال الداخلي. | 🟢 |
| **20 مارس 1956** | **الاستقلال التام** عن فرنسا — بورقيبة رئيسًا للحكومة. | 🟢 |

## 6. الدولة الحديثة: عهد بورقيبة (1956–1987)

| الفترة | الحدث | التصنيف |
|---|---|---|
| 25 مارس 1956 | المجلس القومي التأسيسي. | 🟢 |
| **13 أوت 1956** | **مجلة الأحوال الشخصية** — قانون رائد عربيًّا في حقوق المرأة (منع تعدد الزوجات، الطلاق القضائي، السن القانوني) — **عيد المرأة**. | 🟢 |
| **25 جويلية 1957** | إلغاء الملكية وإعلان **الجمهورية التونسية** — بورقيبة أول رئيس. | 🟢 |
| **1961** | **أحداث بنزرت** — القتال لإجبار فرنسا على إخلاء قاعدتها. | 🟢 |
| **15 أكتوبر 1963** | **الجلاء** — مغادرة آخر جندي فرنسي → **عيد الجلاء**. | 🟢 |
| الستينات | تجربة التعاضد الفلاحي (أحمد بن صالح) ثم تراجعها. | 🟢 |
| 1970–1980 | تحديث اقتصادي + تعليم + تصنيع + تحرير المرأة — لكن استبداد الحزب الواحد. | 🟢 |
| 1978 / 1984 | أحداث الخبز وأحداث 26 جانفي 1978 — احتجاجات اجتماعية قُمعت. | 🟢 |
| **7 نوفمبر 1987** | **حركة 7 نوفمبر** — **زين العابدين بن علي** يخلف بورقيبة (انقلاب أبيض دستوري). | 🟢 |

## 7. عهد بن علي والثورة التونسية (1987–2011)

| الفترة | الحدث | التصنيف |
|---|---|---|
| 1987–2010 | تحرير اقتصادي جزئي + استقرار أمني — لكن تسلط أمني وفساد ومحاباة. | 🟢 |
| **17 ديسمبر 2010** | **اندلاع الثورة التونسية** — محمد البوعزيزي يحرق نفسه في **سيدي بوزيد**. | 🟢 |
| ديسمبر 2010 – يناير 2011 | انتشار الاحتجاجات إلى القيروان وسوسة وتونس العاصمة وغيرها. | 🟢 |
| **14 يناير 2011** | **فرار بن علي** إلى السعودية — سقوط النظام (عيد الثورة والشباب = 17 ديسمبر). | 🟢 |

> تونس هي **مُطلقة «الربيع العربي»** — أول ثورة شعبية أطاحت حاكمًا عربيًّا 2011. 🟢

## خلاصة المسار التاريخي

تونس = **ملتقى حضارات**: أمازيغية → فينيقية/قرطاجية → رومانية → وندالية → بيزنطية → إسلامية (أغالبة/فاطميون/زيريون/موحدون/حفصيون) → عثمانية (حسينية) → حماية فرنسية → استقلال (بورقيبة) → بن علي → ثورة 2011 → انتقال ديمقراطي → إجراءات استثنائية. هذا التعاقب هو **أساس التنوع الثقافي التونسي** (عربي-أمازيغي-متوسطي-أندلسي-عثماني-فرنسي). 🟢
