# الجمهورية الجزائرية — الطعام (المطبخ الجزائري)

> منهجية: لا تُنسب الأطباق إلى «الجزائر» ككتلة بل إلى منشئها حيثما أمكن. كل طبق يُربَط بمكانه.
> المصادر: ويكيبيديا (مطبخ جزائري)، arb6 (الحلويات الجزائرية)، alkhaleej، sahhawhana، atyabtabkha.

---

## 1. نظرة عامة 🟢

- **المطبخ الجزائري:** مغاربي + متوسطي + صحراوي + أمازيغي + عثماني + فرنسي — تنوع كبير.
- **الخصائص:** بهارات (رأس الحانوت/الكركم/الزعفران/الكمون/القرفة) + زيت الزيتون + الفواكه المجففة + مخلل الليمون + الحلو-الحار.
- **الجذور:** أمازيغي (الكسكس/الشخشوخة) + عربي/أندلسي (البقلاوة/المعجنات) + عثماني (البريك) + فرنسي (حديث).
- **الانتشار:** مغاربي + عالمي (المغتربون).

---

## 2. الأطباق الوطنية الكبرى 🟢

### (1) الكسكس 🟢 — الطبق الوطني
- **الأصل:** أمازيغي/مغاربي — «الكسكس النوميدي» 🟢.
- **الوصف:** كسكس (سميد) + خضار (جزر/كوسا/بطاطس/بصل) + لحم/دجاج + مرق + حمص.
- **الأنواع:** كسكس بالعصبان (الجزائر) + كسكس بالدجاج + كسكس حلو (زبيب/سكر/مكسرات + لبن).
- **المناسبة:** غداء الجمعة + الأعراس/المناسبات.
- **2020:** أُدرج في **تراث اليونسكو** (المغرب/الجزائر/تونس/موريتانيا مشتركًا). 🟢

### (2) الطاجين (Tagine) 🟢 — مغاربي
- **الوصف:** لحم/دجاج + خضار + بهارات + زيتون/مخلل ليمون/برقوق — في وعاء فخاري.
- **الأنواع:** طاجين اللحم بالزيتون + طاجين الدجاج + طاجين الحلو (لحم + فواكه مجففة + قرفة).

### (3) الشخشوخة 🟢 — جزائرية/أمازيغية أصيلة
- **الأصل:** شرق الجزائر (الأوراس/قسنطينة/بسكرة).
- **الوصف:** رقائق عجين (الكسكس المفتت) + مرق لحم/دجاج + خضار + بهارات — أكلة احتفالية.
- **المناسبة:** الأعراس/المناسبات الكبرى.

### (4) البريك (Brik) 🟢 — تونسي/جزائري
- **الأصل:** تونسي/جزائري (عثماني).
- **الوصف:** ورق رقيق + لحم/بيض/تونة/خضر — مقلو — مقبلات/فطار.

### (5) الحريرة/الشوربة (Chorba) 🟢 — مغاربي
- **الوصف:** شوربة (لحم + طماطم + قمح/شعيرية + بهارات + نعناع) — رمضانية.

## 3. أطباق أخرى بارزة 🟢

| الطبق | الأصل/المنطقة | الوصف | المناسبة |
|---|---|---|---|
| **المروزية** | مغاربي | لحم غنم + زبيب + لوز + قرفة (عيد الأضحى) | عيد الأضحى |
| **الدولمة** | مغاربي/عثماني | ورق عنب/كروم/خضار محشو | مناسبات |
| **المحاجب** | جزائري | خبز سميد + صلصة طماطم + بهارات | فطار/غداء |
| **القارانطيطة** | جزائرية | حمص + دقيق + زيت + كمون | فطار |
| **البوراك (البريك)** | جزائري/تونسي | ورق + لحم/بيض — مقلو | فطار/مقبلات |
| **الرفيس/الرفايس** | جزائري/أمازيغي | قمح + تمر + سمن + لوز | مناسبات |
| **السفة/المسفوف** | مغاربي | كسكس بدون مرق + سكر/قرفة/زبيب | حلو |
| **الملة** | صحراوي/أمازيغي | خبز صحراوي في الرماد | ريف |
| **الشخشوخة** | شرق الجزائر | رقائق + مرق | أعراس |
| **الحميس** | مغاربي | لحم + خضار + بهارات | غداء |
| **الكسرة** | أمازيغي | خبز دائري من سميد | يومي |
| **المبسس/المسمن** | مغاربي | فطائر مدهونة | فطار |

---

## 4. الحلويات والمشروبات 🟢

- **الحلويات:**
  - **المقروط** (سميد + تمر — شرق/جنوب الجزائر) — أشهر حلوى 🟢.
  - **البقلاوة** (عثماني — اللوز/الجوز + عسل).
  - **الغريبية** (سميد + سمن — غرب).
  - **المحنشة** (ورق + لوز — حلزوني).
  - **كعب الغزال/البريوات** (لوز + عسل).
  - **الزلابية** (مقلو بالعسل — رمضان).
  - **القلب اللوز** (الجزائر — اللوز).
  - **المشوك** (سميد + سكر).
  - **صابلي/دزيرية/مخبوزة** (الجزائر العاصمة — اللوز).
- **المشروبات:**
  - **الشاي (أتاي):** مع النعناع — رمز الضيافة.
  - **القهوة (الإسبريسو):** حضرية (تأثير فرنسي).
  - **لبن/أيران:** مع الكسكس.
  - **عصير/قمر الدين/تمر هندي:** رمضانية.

---

## 5. الخبز 🟢

- **الكسرة** — خبز دائري من سميد (أمازيغي).
- **خبز الدار/المحاجب** — خبز سميد + صلصة.
- **المسمن/المبسس** — فطائر.
- **الملة** — خبز صحراوي (في الرماد).
- **خبز الفرن** — حضري.

---

## 6. المأكولات بحسب البيئة (ربط الجغرافيا بالطعام) 🟢

| البيئة | أطعمة بارزة | السبب |
|---|---|---|
| الساحل (الجزائر/وهران/عنابة) | السمك + المأكولات البحرية + الكسكس/الطاجين + تأثير فرنسي/أندلسي | بحر + متوسطي |
| المرتفعات (القبائل/الأوراس) | الشخشوخة + الكسكس + الأمازيغي + الزيتون | جبال + أمازيغ |
| الهضاب (سطيف/تيارت) | القمح/الكسكس + اللحوم + الحبوب | زراعة حبوب |
| الصحراء (ورقلة/غرداية/تمنراست) | الملة + التمر + الواحات + الطاجين الصحراوي | واحات + صحراء |
| الشرق (قسنطينة/عنابة) | الشخشوخة + الطاجين + تأثير تونسي | شرق + تونس |

---

## 7. أطعمة المناسبات 🟢

- **الجمعة:** الكسكس (تقليد).
- **رمضان:** الشوربة/الحريرة + البريك + المقروط + الزلابية + قمر الدين.
- **عيد الأضحى:** المروزية + الطاجين + الكسكس.
- **الأعراس:** الشخشوخة + الكسكس + المقروط/البقلاوة.

---

## 8. البهارات والمكوّنات المحلية 🟢

- **بهارات:** **رأس الحانوت** (خلطة 20+ بهار) + الكركم + الزعفران + الكمون + القرفة + الزنجبيل + الفلفل الأسود + الهريسة (فلفل حار) + مخلل الليمون.
- **مكوّنات محلية:** زيت الزيتون (الشمال) + التمر (الواحات — دقلة نور) + اللوز/الجوز + الحمضيات + الزيتون + التين/العنب + القمح/السميد.
- **ملاحظة:** **الكسكس تراث يونسكو 2020** (مشترك مع المغرب/تونس/موريتانيا) 🟢.

---

## 9. ملاحظة نقدية

- المطبخ الجزائري **مغاربي مشترك** (مع المغرب/تونس) لكن له أطباق فريدة (الشخشوخة/المحاجب/المقروط).
- **الكسكس** أمازيغي/نوميدي أصيل (تراث يونسكو مشترك).
- **المقروط** جزائري أصيل (سميد + تمر).
- **الشخشوخة** أمازيغية/شرق جزائري.
- التأثيرات: أمازيغي (الكسكس/الشخشوخة) + عثماني (البريك/البقلاوة) + أندلسي (المعجنات) + فرنسي (حديث).
