# الجمهورية الجزائرية — اللباس التقليدي

> منهجية: لكل قطعة يُذكَر اسمها المحلي + المناسبة + المنطقة + الاختلاف بين المناطق والقوميات.
> المصادر: المجلة (لباسي ذاكرتي)، العربي الجديد (عودة الحايك)، BBC (الجبة القبائلية)، amouchia (الحايك)، ultraalgeria.

---

## 1. ملاحظة أولى: تنوع قومي/إقليمي/تاريخي 🟢

> اللباس الجزائري فسيفساء — عربي/أمازيغي/عثماني/أندلسي/صحراوي — كل منطقة لها زيها الفريد.

---

## 2. اللباس الرجالي 🟢

### القطع الأساسية

| القطعة | الوصف | المنطقة/الاستخدام |
|---|---|---|
| **القفطان (الجزائري)** | رداء طويل مفتوح من الأمام + حزام | المناسبات — رجالي/نسائي تاريخيًّا |
| **الجلابة (الجلباب)** | رداء طويل بأكمام + قلنسوة | كل الجزائر — يومي/مناسبات |
| **البرنوس (البرنوص)** | عباءة صوفية بقلنسوة (بلا أكمام) — شتاء | المرتفعات/الصحراء |
| **السروال** | فضفاض تحت القفطان/الجلابة | — |
| **البابوش (البلغة)** | حذاء جلدي بلا كعب | مع القفطان/الجلابة |
| **العمامة/الشاشية** | غطاء رأس — الشاشية الحمراء (تلمسان/الجزائر) | العلماء/المناسبات |
| **القميص/البدلة (حديثة)** | بدلة غربية | المدن/الرسمي |

### البرنوس 🟢 — رمز جزائري
- رداء صوفي بقلنسوة (بلا أكمام) — شتاء (المرتفعات/الصحراء) + رمز وطني (يرتديه الرئيس).

---

## 3. اللباس النسائي 🟢 — تنوع إقليمي استثنائي

### (أ) الشدة التلمسانية 🟢 — تلمسان (تراث يونسكو قيد الدراسة)
- **الوصف:** لباس العروس الفاخر — **12 قطعة** (البلوزة + القفطان + الشاشية + الفوطة) + **50+ صنف من المجوهرات** 🟢.
- **الوزن:** نحو 15 كغم — من بيت أهلها إلى بيت زوجها.
- **الجذور:** عربي (البلوزة) + أمازيغي (الفوطة) + عثماني (القفطان) + أندلسي (الشاشية).
- **المناسبة:** عرس تلمساني — من أفخم الأزياء العربية.
- **اليونسكو:** مصنَّفة ضمن التراث الإنساني المشترك. 🟢

### (ب) القفطان الجزائري 🟢
- **الوصف:** جلابة مفتوحة من الأمام + مطرَّزة + حزام (المضمّة).
- **المناسبة:** الأعراس/الحفلات.
- **الأنواع:** القفطان العاصمي/القسنطيني/التلمساني.

### (c) الكراكو 🟢 — العاصمة/قسنطينة
- **الوصف:** قطعة علوية (الكاراكو) + قطعة سفلية (القفطان) — مطرَّز بالذهب.
- **المناسبة:** الأعراس/المناسبات.

### (د) الجبة القبائلية 🟢 — القبائل (أمازيغي)
- **الوصف:** قطعة قماش طويلة تغطي الرأس والجسم + تطريز بألوان زاهية (برتقالي/أحمر/أخضر/أصفر) + أشكال هندسية.
- **المناسبة:** عرس قبائلي — لا يكمل العرس دونها 🟢.
- **الأثر:** قضية طرد طالبة (2023) بسبب ارتدائها → جدل وطني حول الأمازيغية. 🟡

### (هـ) الحايك 🟢 — رمز المرأة الجزائرية (تاريخي)
- **الوصف:** قطعة قماش بيضاء كبيرة تُلف حول الجسم + تغطي نصف الوجه (العجار/النقاب).
- **الأنواع:** حايك مرمّا (العاصمة) + حايك العشعاشي (تلمسان — أبيض ناصع + حرير + خيوط ذهبية).
- **التاريخ:** لباس الخروج (قبل/بعد الاستقلال) + استعمله الفدائيون في الثورة (التخفي) 🟢.
- **التراجع:** منذ الثمانينات (الحجاب/الجلابة/الموضة) — لكن يُحافَظ عليه في الأعراس + إحياء (موعد مع الحايك). 🟡

### (و) اللباس الشاوي 🟢 — الأوراس (أمازيغي)
- **الوصف:** ثوب مطرَّز بألوان زاهية + حلي فضية + الشاشية.
- **المناطق:** باتنة/خنشلة/تبسة/أم البواقي.

### (ز) اللباس النايلي 🟢 — أولاد نايل (الجلفة/الأغواط)
- **الوصف:** ثوب مطرَّز + حلي + الشاشية — تراث قبيلة أولاد نايل.

### (ح) اللباس المزابي 🟢 — وادي مزاب (إباضي)
- **الوصف:** ثوب محتشم + نقاب + ألوان محددة — تراث إباضي.
- **المناطق:** غرداية/الوادي.

### (ط) اللباس الصحراوي/الطوارقي 🟢 — تمنراست/جانت
- **الوصف:** ثوب أزرق (أنقار) + حلي فضية + خنجر — تراث الطوارق.
- **الرجال:** يغطون الوجه (بدل النساء) — عكس المعتاد.

---

## 4. الحلي والمجوهرات 🟢

- **الذهب/الفضة** — للنساء (أقراط/أساور/خلاخل/العقد/المجوهرات التلمسانية).
- **الفضة الأمازيغية** — ثقيلة + تقليدية (القبائل/الأوراس/مزاب/الطوارق).
- **الشاشية** — قبعة حمراء (تلمسان/الجزائر).
- **المجوهرات التلمسانية** — 50+ صنف في الشدة التلمسانية.

---

## 5. اللباس التاريخي 🟢

- **الأمازيغي القديم:** الرداء/الجلابة الصوفية + الحايك.
- **الأندلسي (تلمسان/الجزائر):** الشدة التلمسانية + القفطان (1492 — الموريسكيون).
- **العثماني (1516–1830):** القفطان + الشاشية + البرنوس + العمامة.
- **الاحتلال الفرنسي (1830–1962):** البدلة الغربية (الرجال) + الفستان (النساء) — الأوروبيون.
- **الحديث:** الجلابة/القفطان (المناسبات) + البدلة/الجينز (يومي) + الحجاب (الأوساط المحافظة).

---

## 6. الفروق بحسب البيئة 🟢

| البيئة | اللباس | السبب |
|---|---|---|
| الساحل (الجزائر/وهران) | قفطان + كراكو + بدلة (يومي) + حايك (تاريخي) | حضري + فرنسي |
| المرتفعات (تيزي وزو/بجاية/الأوراس) | الجبة القبائلية + اللباس الشاوي + حلي فضية | أمازيغي |
| الشرق (قسنطينة/عنابة) | القفطان القسنطيني + الشدة (تاريخي) | تراث حضري + أندلسي |
| الغرب (تلمسان) | **الشدة التلمسانية** (تراث يونسكو) + القفطان | أندلسي + عثماني |
| الهضاب (الجلفة/الأغواط) | اللباس النايلي | قبائل أولاد نايل |
| الصحراء (غرداية/تمنراست) | اللباس المزابي (إباضي) + اللباس الطوارقي | إباضي + طوارق |

---

## 7. التطور الحديث 🟢

- **الحايك** تراجع (الثمانينات) لكن يُحافَظ عليه في الأعراس + إحياء (موعد مع الحايك).
- **القفطان/الشدة** في الأعراس/المناسبات (بقاء قوي).
- **الجبة القبائلية** رمز هوية أمازيغية (جدل 2023).
- **الحجاب/الجلابة** في الأوساط المحافظة.
- **البرنوس** رمز وطني (يرتديه الرئيس).

---

## 8. ملاحظة نقدية

- اللباس الجزائري **فسيفساء قومية/إقليمية** — لا يُعمَّم.
- **الشدة التلمسانية** من أفخم الأزياء العربية (تراث يونسكو قيد الدراسة).
- **الحايك** رمز المرأة الجزائرية التاريخي + الثورة (التخفي).
- **الجبة القبائلية** رمز الهوية الأمازيغية.
- التأثيرات: أمازيغي (الجبة/الحايك) + أندلسي (الشدة) + عثماني (القفطان/الشاشية).
