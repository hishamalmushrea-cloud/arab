# الجمهورية الجزائرية — اللهجات واللغة

> منهجية: لكل لهجة تُذكَر مناطق انتشارها وخصائص النطق ومفردات مميزة. تُذكر كل لفظة: الكلمة ← النطق التقريبي ← المعنى بالفصحى ← المنطقة ← مثال ← ملاحظات.

## 1. اللغات واللهجات: نظرة عامة 🟢

- **اللغتان الرسميتان:** العربية + **الأمازيغية** (تعديل 2016) 🟢.
- **الدارجة الجزائرية (الجزائرية):** لهجة عربية مغاربية — خليط من العربية + الأمازيغية (تركيب/قواعد/مفردات) + الفرنسية + التركية/الإسبانية. 🟢
- **الأمازيغية (تِمازِغت):** لهجات كبرى:
  - **القبائلية (تاقبايلت):** القبائل (تيزي وزو/بجاية/البويرة) — أكبر مجال أمازيغي.
  - **الشاوية (تاشاویت):** الأوراس (باتنة/خنشلة/تبسة/أم البواقي).
  - **المزابية (تومزابْت):** وادي مزاب (غرداية) — الإباضية.
  - **الطوارقية (تاماهق):** الهقار (تمنراست/جانت) — الصحراء.
  - **الشنوية (تاشناويت):** الشلف/تنس.
- **الفرنسية:** لغة عمل/إدارة/تعليم عالٍ/اقتصاد (الاحتلال 1830–1962) — راسخة في الدارجة.
- **الجدل اللغوي:** خلاف حول أصل الدارجة (عربية/أمازيغية/هجينة) 🟡 — يُعرض بحياد.

> **ملاحظة:** الدارجة الجزائرية **غير مفهومة للمشارقة** بسهولة (تركيب أمازيغي + مفردات فرنسية + اختزال حروف العلة) — سمة فريدة.

## 2. الدارجة الجزائرية 🟢

### خصائص النطق
- **اختزال حروف العلة** → مجموعات حرفية طويلة (سمة مغاربية).
- **تسكين الحروف** (بخلاف المشرق).
- **لا مثنى** (فقط مفرد + جمع — كالأمازيغية).
- **قواعد أمازيغية** في التراكيب + النفي + الاستفهام.
- **مفردات فرنسية راسخة:** «طوموبيل» (سيارة) + «بلاصة» (مكان) + «فورماج» (جبن) + «طابلو» (لوح) + «بالون» (كرة) + «لافابو» (صنبور) + «تريسيتي» (كهرباء) + «كوفيرطة» (بطانية) + «بونكا» (بنك).
- **مفردات أمازيغية:** «أضرار» (أرض) + «تيفي» (نار) + «أزرو» (حجر).

## 3. لهجات الدارجة الفرعية 🟢

- **اللهجة العاصمية (الجزائر):** متأثرة بالفرنسية + الأمازيغية — أكثر المفردات الفرنسية.
- **اللهجة الوهرانية (غرب):** متأثرة بالإسبانية (الأندلس/تلمسان) + الفرنسية.
- **اللهجة القسنطينية (شرق):** **أقرب اللهجات للعربية الفصحى** 🟢 — نطق أوضح + مفردات فصيحة + تأثير تونسي.
- **اللهجة القبائلية/الشاوية:** متأثرة بالأمازيغية (تركيب/مفردات).
- **اللهجة الصحراوية (الجنوب):** متأثرة بالبدوية/الحسانية + الطوارقية.

## 4. ملاحظات على التطور اللهجي

- **الجذور التاريخية:** أمازيغية (Substrat قوي) + عربية (بعد الفتح 647) + فرنسية (الاحتلال 1830–1962) + تركية (العثمانيون 1516–1830) + إسبانية (الشمال/الأندلس).
- **الدارجة الجزائرية** فريدة في المغرب العربي — مشابهة للدارجة المغربية/التونسية لكن مع فرنسية أكثر.
- **ثنائية/تعددية لغوية:** العربية + الأمازيغية + الفرنسية — ثلاثية لغوية فريدة.
- **الإعلام:** الدارجة في الإعلام/السينما/الأغاني (الراي/الشعبي/المالوف).
- **الأمازيغية** لغة رسمية + تعليم + إعلام (قناة أمازيغية) — تعافي الهوية الأمازيغية.
- **الجدل اللغوي:** خلاف حول أصل الدارجة (عربية/أمازيغية/هجينة) 🟡 — يُعرض بحياد.
