# سوريا — الطعام (المطبخ السوري)

> منهجية: لا تُنسب الأطباق إلى «سوريا» ككتلة بل إلى منشئها حيثما أمكن. كل طبق يُربَط بمكانه.
> المصادر: ويكيبيديا (مطبخ سوري)، المعرفة (مطبخ سوري)، layalina، موضوع (أشهر الأكلات السورية).

---

## 1. الأطباق الوطنية الكبرى 🟢

### (1) الكبة 🟢 — رمز المطبخ السوري/الشامي
- **الأصل:** الشام (حلب مشهورة بها خصوصًا).
- **الوصف:** عجينة برغل + لحم مدقوق، تُحشى بلحم مفروم ومكسرات، تُقلى أو تشوى أو تطبخ.
- **الأنواع:** كبة مقلية، كبة مشوية، كبة بالصينية، كبة نية (لحم نيء + برغل)، كبة لبنية (باللبن)، كبة سماقية، كبة سفرجلية، كبة حلبية، كبة مبرومة، كبة بطاطا.
- **المناسبة:** وليمة/مناسبات/رمضان.

### (2) الفتة الشامية 🟢 — دمشقية
- **الوصف:** خبز مقطَّع/محمَّص يُسكى بمرق (حمص/لحم/دجاج) + سمن/زيت + مكسرات (صنوبر/جوز/فستق حلبي).
- **الأنواع:** فتة المكدوس، فتة المقادم، فتة بالسمنة، فتة بالزيت، فتة دجاج، فتة حمص.

### (3) الحمص بطحينة 🟢 — شامي
- **الوصف:** حمص مهروس + طحينة + زيت زيتون + ليمون + ثوم.
- **الانتشار:** كل سوريا + بلاد الشام.

### (4) المكدوس 🟢 — شامي (شمالي)
- **الوصف:** باذنجان صغير محشو بالجوز/الفلفل/الثوم، مخلل في زيت الزيتون.
- **المناسبة:** فطار/مقبلات شتوية.

### (5) المحمرة 🟢 — حلبية أصيلة
- **الأصل:** حلب.
- **الوصف:** غميس فلفل حار (الفلفل الحلبي المجفف) + جوز + دبس الرمان + خبز.
- **الانتشار:** حلب ثم كل سوريا/بلاد الشام.

### (6) الفلفل الحلبي (الحلبي) 🟢 — حلب
- **مكوّن:** الفلفل الأحمر الحلو/الحار المجفف (علامة المطبخ الحلبي).
- **الاستعمال:** في المحمرة/الكبة/الكباب الحلبي.

## 2. أطباق أخرى بارزة 🟢

| الطبق | الأصل/المنطقة | الوصف | المناسبة |
|---|---|---|---|
| **التبولة** | الشام (سوريا/لبنان) | بقدونس + برغل + طماطم + ليمون | مقبلات |
| **الفتوش** | الشام | سلطة خضار + خبز مقرمش + دبس الرمان | مقبلات |
| **الكباب الحلبي** | حلب | لحم غنم مطحون على سيخ + فلفل حلبي | وليمة |
| **الشيش طاووق** | عام | دجاج مشوي على السيخ | وليمة |
| **الشاكرية** | دمشق | لحم ضأن مطبوخ في الزبادي | غداء |
| **حراق أصبعه** | دمشق | عدس + عجين (معكرونة صغيرة) | شتوي |
| **المجدرة** | عام | عدس + أرز/برغل + بصل مقلي | يومي/صيامي |
| **اليبرق/ورق العنب** | شامي/عثماني | ورق عنب محشو بأرز/لحم | مناسبات |
| **الأوزي** | دمشقي | عجين + أرز + لحم + بازلاء | مناسبات |
| **الشيشبرك** | شامي | عجين محشى بلحم/لبن | مناسبات |
| **المعمول/المأمونية** | دمشق | سميد/فريكة + سمن + قشطة | فطار/مناسبات |
| **المحاشي** | عام | كوسا/باذنجان/فلفل/كرنب محشو | مناسبات/رمضان |
| **المنسف** | حوران/الجنوب/البدو | لحم + أرز/جريش + لبن جميد | وليمة قبلية |
| **البامية** | حماة/الشرق | بامية في مرق لحم | غداء |
| **المشمشية** | دمشق | مشمش + لحم | موسمي |
| **الكوارع/الممبار** | عام | أمعاء محشوة | مناسبات |
| **الشنكليش** | الشمال/الساحل | جبن متخمر + بهارات | مقبلات |
| **السحلب/المهلبية** | عام | حليب + سحلب | شتوي |
| **حلاوة الجبن** | حمص/حماة | عجينة جبن محلاة + قشطة + فستق | حلويات |
| **البقلاوة/المبروشة** | دمشق/حلب | عجين رقيق + مكسرات + شراب | حلويات |
| **البوظة الدمشقية** | دمشق | آيس كريم تقلب بالممدة | صيفي |
| **المعمول** | شامي | عجين بالتمر/الفستق/الجوز | أعياد |

---

## 3. الخبز 🟢

- **الخبز الشامي** — رقيق دائري، عماد المائدة.
- **خبز التنور** — في الريف/البادية.
- **المرقوق/الشراك** — رقيق جدًّا (الساحل/الجبال).

---

## 4. المشروبات والحلويات 🟢

- **الشاي** — مع النعناع/المريمية، عماد الضيافة.
- **القهوة العربية/الشامية** — مع الهيل (في البادية/الريف).
- **عصير قصب السكر/ليمون/تمر هندي** — صيفًا.
- **السحلب/المهلبية** — شتوي.
- **حلويات:** البقلاوة، البوظة الدمشقية، حلاوة الجبن (حمص)، المعمول، المبروشة، الكنافة، البسبوسة، المعشوقة.

---

## 5. المأكولات بحسب البيئة (ربط الجغرافيا بالطعام) 🟢

| البيئة | أطعمة بارزة | السبب |
|---|---|---|
| دمشق | الفتة/الشاكرية/حراق أصبعه/المكدوس/البوظة | تراث حضري عريق + أسواق |
| حلب | الكبة الحلبية/الكباب الحلبي/المحمرة/الفلفل الحلبي/المعمول | مركز تجاري/صناعي + فلفل حلبي مميز |
| الساحل (اللاذقية/طرطوس) | أسماك + زيتون + حمضيات + جبن | البحر + مناخ متوسطي |
| حمص/حماة | حلاوة الجبن/البامية/المجدرة | وديان زراعية |
| حوران/الجنوب | المنسف/القهوة العربية/اللبن الجميد | بداوة + حياة قبلية |
| الفرات/الشرق (دير الزور/الرقة) | كباب الديري/كباب الباذنجان/أكلات بدوية | الفرات + بادية |
| البادية | المنسف/المظبي/القهوة | بداوة/رعي |

---

## 6. أطعمة المناسبات 🟢

- **رمضان:** الفتوش/التبولة/المحاشي/الكبة/المعمول/الكنافة.
- **الأعياد:** المعمول (الفطر/الأضحى)، الكبة، المحاشي.
- **الأعراس:** الكبة/الكباب/الأوزي/المحاشي/البقلاوة.
- **العزاء:** لحم/أرز (الكرم الشامي).

---

## 7. البهارات والمكوّنات المحلية 🟢

- **بهارات:** الفلفل الحلبي (مميز)، السماق، دبس الرمان، البهارات الحلبية (سبع بهارات)، الهيل، القرفة، جوزة الطيب.
- **مكوّنات محلية:** الفستق الحلبي (عالمي الصيت)، الجوز الشامي، الزيتون/الزيت (الساحل)، العنب/الزبيب، المشمش، التين.
- **الأجبان:** الجبن الشامي، الجبن العكاوي، الحلوم، الشنكليش.

---

## 8. ملاحظة نقدية

- المطبخ السوري **من أعرق المطابخ العربية** — تنوع بحسب المدن (دمشق × حلب × الساحل × الفرات).
- الفستق الحلبي + الفلفل الحلبي علامتان عالميتان للمطبخ الحلبي.
- أطباق مشتركة مع بلاد الشام (التبولة/الفتوش/الحمص/المكدوس) — موروث شامي مشترك، لا تُنسب لدولة دون أخرى.
- الكبة/المحمرة حلبية أصيلة (موثَّقة).
- المنسف بدوي/حوراني (موروث مشترك مع الأردن).
