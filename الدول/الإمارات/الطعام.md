# دولة الإمارات العربية المتحدة — الطعام والمطبخ

> منهجية: لكل طبق يُذكَر اسمه المحلي + المكونات + المناسبة + المنطقة + الأصل.
> المصادر: dubaipress، atyabtabkha، bayut، emaratalyoum، zahratalkhaleej، aletihad.

---

## 1. نظرة عامة 🟢

> المطبخ الإماراتي = خليط **بدوي (نجدي) + بحري (ساحل) + هندي/فارسي (تجارة) + بهارات خليجية**. سمة الغالبة: **البهارات (الزعفران/الهيل/اللومي/البزار)** + الأرز + اللحم + القمح + السمك.

- **الأرز:** ركيزة الأطباق الرئيسية (بسمتي).
- **اللحم:** ضأن + دجاج + سمك + روبيان.
- **القمح:** الهريس + الجريش (بدوي).
- **البهارات:** الزعفران + الهيل + القرفة + **اللومي** (الليمون الأسود) + **البزار** (خلطة بهارات) + الكركم.
- **اللومي:** ركيزة إماراتية-خليجية.
- **التمر + القهوة العربية:** ضيافة.

---

## 2. الأطباق الرئيسية

### (1) المجبوس (المكبوس) 🟢 — الطبق الوطني
- **الوصف:** أرز بسمتي مطبوخ مع اللحم/الدجاج/السمك + بهارات (زعفران + هيل + لومي) + بصل + طماطم.
- **المناسبة:** الولائم + الأعراس + يومي.
- **التنوع:** مجبوس لحم/دجاج/سمك/روبيان.

### (2) الهريس 🟢 — طبق المناسبات
- **الوصف:** قمح مجروش + لحم ضأن → يُطهى ساعات حتى يصير عصيدة ناعمة + سمن بلدي.
- **المناسبة:** **رمضان** + الأعياد + الأفراح + الأتراح.
- **الأصل:** بدوي.

### (3) الثريد 🟢
- **الوصف:** خبز الرقاق مفتوت + مرق اللحم + خضار (بطاطا + كوسا + جزر) — «سيد مائدة رمضان».
- **المناسبة:** رمضان — «جذوره تعود للنبي ﷺ».

### (4) المضروبة 🟢
- **الوصف:** أرز + دجاج/سمك مملح → يُضرب حتى ينعقد + بهارات — كريمي.

### (5) الجشيد 🟢 — بحري
- **الوصف:** سمك صغير مفتوت + لومي + بهارات — دبي/الساحل.

### (6) المالح 🟢
- **الوصف:** سمك مملح محفوظ + أرز — شعبي بحري.

### (7) الأوزي 🟢
- **الوصف:** لحم ضأن مشوي + أرز + مكسرات + زبيب — شبيب بالمندي.

### (8) الجريش 🟢
- **الوصف:** قمح مجروش + لحم/دجاج + بهارات — بدوي.

### (9) المشخول 🟢
- **الوصف:** أرز + لحم/دجاج + بهارات — شبيب بالمجبوس.

### (10) خبز الرقاق 🟢
- **الوصف:** خبز رقيق يُستعمل في الثريد + يُدهن بالسمن/العسل.

### (11) خبز الخمير 🟢
- **الوصف:** خبز بالسمن البلدي + زعفران — حلو.

## 4. الخبز والمشروبات والضيافة 🟢

- **القهوة العربية:** ركيزة الضيافة الإماراتية — هيل + زعفران + تمر (المجلس).
- **الشاي:** شاي أخضر + نعناع.
- **التمر:** ضيافة يومية.
- **حليب الإبل:** تراثي + صحي.

---

## 5. مأكولات رمضان 🟢

- **الإفطار:** تمرة + شوربة + الهريس + الثريد + المجبوس + اللقيمات + البلاليط.
- **تناول الطعام باليد:** عادة محببة — «متعة تناول العيش واللحم باليد».

---

## 6. ربط الطعام بالجغرافيا 🟢

| المنطقة | الأطباق المميزة | السبب |
|---|---|---|
| الساحل (أبوظبي/دبي/الشارقة) | مجبوس السمك + الجشيد + المالح | بحري + صيد + تجارة |
| الداخل (العين/الظفرة) | الهريس + الجريش + الثريد + لحم | بدوي + قمح + رعي |
| الجبال (الفجيرة/رأس الخيمة) | المضروبة + الأوزي | زراعة + رعي |

---

## 7. ملاحظات ثقافية 🟢

- **المجبوس = الطبق الوطني** — يُقدَّم في الولائم + رمز الكرم.
- **الهريس = رمضان** — «سيد مائدة رمضان» + التكافل (يُوزَّع).
- **الثريد = التراث** — ارتباط بالنبي ﷺ.
- **القهوة العربية = ضيافة** — رمز الكرم الإماراتي.
- **اللومي + البزار + الزعفران** = بصمة إماراتية-خليجية.
- **الإرث الهندي/الفارسي:** بعض البهارات + طرق الطبخ (تجارة دبي/أبوظبي القديمة).

---

## خلاصة الطعام

المطبخ الإماراتي = **مطبخ خليجي بهاراتي** قائم على المجبوس (الطبق الوطني) + الهريس (رمضان) + الثريد (التراث) + المضروبة + الجشيد + اللقيمات (الحلوى) + القهوة العربية (الضيافة). تتمايز الأطباق: بحري (سمك) على الساحل + بدوي (قمح/لحم) في الداخل. البهارات (لومي/بزار/زعفران) = البصمة الإماراتية. 🟢
