## 3. القبائل 🟢

> القبيلة = **إطار اجتماعي قوي** في الإمارات — أساس النظام السياسي (الأسر الحاكمة).

### (أ) بني ياس — أكبر القبائل 🟢
- **الأصل:** ياس بن عامر (نزار بن معد بن عدنان — عدنانية).
- **الفروع:** 20+ فرعًا — **آل بوفلاح** (آل نهيان — حكام أبوظبي) + **آل بوفلاسة** (آل مكتوم — حكام دبي) + المزاريع + السودان + القبيسات + المحاربة + الرواشد + الهواميل.
- **التاريخ:** استوطنت ليوا (الصحراء) → انتقلت إلى أبوظبي (1761) → دبي (1833).
- **حلف بني ياس:** ضم قبائل أخرى (المناصير + العوامر + الظواهر + النعيم).

### (ب) القواسم 🟢
- **الأصل:** قوة بحرية — سيطرت على الساحل الشرقي + خليج عمان.
- **الفروع:** العبادلة + المهرة + النقبيون + الحبوس + آل بو مهير.
- **الحكم:** **الشارقة** (القاسمي) + **رأس الخيمة** (القاسمي).

### (c) النعيم 🟢
- **المنطقة:** عجمان (النعيمي) + المنطقة الغربية.
- **التاريخ:** أخضعت الظواهر + امتداد (السعودية/قطر/البحرين).

### (د) قبائل أخرى بارزة 🟢
| القبيلة | المنطقة | الملاحظة |
|---|---|---|
| **الشرقيون (آل شرقي)** | الفجيرة | حكام الفجيرة |
| **المعلا** | أم القيوين | حكام أم القيوين |
| **المناصير** | أبوظبي (الظفرة) | كبيرة + استقلال |
| **العوامر** | أبوظبي/العين | عريقة |
| **الظواهر** | العين | عريقة |
| **الشحوح** | رأس الخيمة (جبال) | أمازيغ/جبليون |
| **الحبوس** | الجبال | — |
| **الكتبي** | دبي/الشارقة | من نجد |
| **المحارزة** | — | — |
| **الطنيجي** | الشارقة | — |

### (هـ) الأحزاب القبلية التاريخية 🟡
- **الحزب الهناوي** (اليمنية): بني ياس + المناصير + الحبوس + الشرقيون + الشحوح + الظواهر + العوامر.
- **الحزب الغافري** (العدنانية): القواسم + النعيم + بني كتب.

## 4. الدين 🟢

| الدين | النسبة | التفاصيل | الثقة |
|---|---|---|---|
| **الإسلام** | ~76%+ | **سُنة غالبية** (مالكية + حنبلية + شافعية) + أقلية شيعية (~15% من المواطنين) | 🟢 |
| **المسيحية** | ~9–10% (وافدون) | كاثوليك + بروتستانت + أرثوذكس | 🟢 |
| **الهندوسية** | ~8–15% (هنود) | — | 🟢 |
| **البوذية** | ~3–5% (آسيويون) | — | 🟢 |
| **أخرى** | ~1–5% | سيخ + بهائية + بارسي | 🟢 |

### الإسلام في الإمارات 🟢
- دستوريًّا: **الإسلام الدين الرسمي** + الشريعة مصدر التشريع.
- **المذهب المالكي:** آل نهيان (أبوظبي) + آل مكتوم (دبي) — الأكثر انتشارًا.
- **المذهب الحنبلي:** القواسم (الشارقة/رأس الخيمة) + الفجيرة/عجمان/أم القيوين.
- **المذهب الشافعي:** أغلب مواطني الإمارات.
- **الشيعة:** أقلية (بحارنة + عجم) — ~15% من المواطنين.
- **التسامح:** «وزارة التسامح» + وثيقة الأخوة الإنسانية (2019) + حرية الأديان للوافدين (كنائس + معابد).

## 5. الهوية الوطنية 🟢

- **الهوية = عربية-إسلامية-خليجية** + تعددية ثقافية (200+ جنسية).
- **القبيلة** إطار اجتماعي قوي (الأسر الحاكمة).
- **الاتحاد** (1971) = فخر وطني.
- **اللغة:** العربية (رسمية) + اللهجة الإماراتية + الإنجليزية (لغة عمل).
- **التركيبة الفريدة:** 12% مواطنين + 88% وافدون → «التعددية الثقافية» + تحدٍّ ديموغرافي.
- **التسامح:** قيمة رسمية + وثيقة الأخوة الإنسانية.

---

## 6. لامساواة/تحديات اجتماعية 🟡

- **التركيبة السكانية:** الإماراتيون أقلية (12%) — تحدٍّ ديموغرافي مستمر.
- **البطالة بين المواطنين** + التوظيف في القطاع العام.
- **الهوية الثقافية:** تأثير الوافدين على القيم + اللغة + العادات.
- **اللامساواة بين الإمارات** (أبوظبي/دبي غني vs الشمالية أصغر).
- **الجالية الأجنبية**: ظروف العمل (خاصة العمالة الآسيوية) 🟡.

## 7. الحركات والتنظيمات الاجتماعية 🟢

- **المجالس** — مؤسسة اجتماعية-سياسية.
- **الجمعيات التعاونية + الأهلية + الثقافية + الرياضية**.
- **المجلس الوطني الاتحادي** — نصف منتخَب (40 عضوًا — 8 لأبوظبي/دبي + 6 للشارقة/رأس الخيمة + 4 للبقية).
- **المرأة الإماراتية:** مشاركة متنامية (وزيرات + نائبات + رياضيات + رائدات فضاء).
- **الشباب:** قوة تغيير + رؤية 2071.

## خلاصة المجتمع

مجتمع الإمارات = **مجتمع متعدد الثقافات** (12% مواطنين + 88% وافدين من 200+ جنسية) — **أعلى نسبة وافدين عالميًّا**. القبائل: **بني ياس** (أكبرها — آل نهيان/آل مكتوم) + **القواسم** (الشارقة/رأس الخيمة) + النعيم + الشرقيون + المناصير. الدين: إسلام غالبية (سُنة مالكية/حنبلية/شافعية + أقلية شيعية) + مسيحية/هندوسية (وافدون). الهوية = عربية-إسلامية-تعددية + التسامح. التحديات: التركيبة السكانية (12% مواطنين) + الهوية الثقافية. الإمارات = **دولة تعددية** مع تجانس مواطنين ديني عالٍ. 🟢/🟡
