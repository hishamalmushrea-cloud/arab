# دولة الإمارات العربية المتحدة — اللباس التقليدي

> منهجية: لكل قطعة يُذكَر اسمها المحلي + المناسبة + المنطقة + الأصل.
> المصادر: ويكيبيديا (لباس تقليدي إماراتي)، bayut، albiladpress، newsroom.info، aletihad.

---

## 1. ملاحظة أولى 🟢

> اللباس الإماراتي = **نجدي/بدوي بالأساس** + ملاءمة للمناخ الصحراوي الحار. محافَظ عليه بقوة — **اللباس الرسمي** في المناسبات + العمل.
> **سمة:** البساطة + العملية + القطن الأبيض (صيفًا) + الصوف (شتاءً).

---

## 2. اللباس الرجالي 🟢

### القطع الأساسية

| القطعة | الوصف | الأصل/الاستخدام |
|---|---|---|
| **الكندورة (الدشداشة)** | ثوب فضفاض طويل أبيض من القطن (صيفًا) — **بدون ياقة** + تطريز غير بارز على الأكمام + فتحة رقبة بأزرار + **«الفروخة/الطربوشة»** (خيوط متدلية من الرقبة) | نجدي — اللباس اليومي + الرسمي |
| **الغترة** | شال أبيض مربع من القطن/الحرير — تُطوى مثلثًا | نجدي — حماية من الشمس/الغبار |
| **العقال** | شريط صوف أسود دائري يثبّت الغترة | نجدي — المناسبات + يومي |
| **القحفية** | طاقية قطنية دائرية تحت الغترة | — |
| **البشت (جناح العرب)** | عباءة صوفية بلا أكمام + مفتوحة أمامي + تطريز ذهبي/فضي (زري) على الصدر + الكتف | نجدي — المناسبات + الوجهاء + العرسان |
| **الإزار** | ثوب داخلي غير مخيط تحت الكندورة | — |
| **العمامة** | قطعة قماش تُلف على الرأس | — أيام الصيف |
| **النعال/الصندل** | جلدي | — |

> زي العريس الإماراتي: **الكندورة + البشت + الغترة + العقال**. 🟢

### **ميزة الكندورة الإماراتية** 🟢
- **بدون ياقة** (عكس السعودي).
- **تطريز غير بارز** على الأكمام.
- **الفروخة/الطربوشة:** خيوط متدلية من الرقبة — ميزة إماراتية فريدة.
- ألوان حديثة: بني + بيج + رمادي + أسود (شتاءً).

---

## 3. اللباس النسائي 🟢

### القطع الأساسية

| القطعة | الوصف | الأصل/الاستخدام |
|---|---|---|
| **الكندورة (الجلابية)** | فستان واسع طويل — أنواع (بوتيلة يومي/المزراوي مناسبات/بوطيرة حرير/بوقليم حرير مخطط/الشال صوف شتاء/صالحني حرير مخطط) | — لباس منزلي + خارجي |
| **الثوب** | رداء حريري شفاف فوق الكندورة — رقبة واسعة + أكمام واسعة + تطريز فضي + ذيل طويل خلفي | — المناسبات |
| **العباءة** | رداء أسود طويل — أنواع (أم القيطان مطرَّز/أم الخدود صوف) | — خارجي |
| **الشيلة** | غطاء رأس أسود | — |
| **البرقع** | قناع ذهبي/أسود يغطي الوجه (ما عدا العينين) — من قماش هندي | — نساء كبار |
| **السروال** | بنطلون فضفاض داخلي + «نسعة» (حبل قطني للخصر) | — |

### **التطريز (التلي والزري)** 🟢
- **التلي:** خيوط ذهبية/فضية مطرَّزة يدويًّا عند الصدر والمعصمين — حرفة نسائية تراثية.
- **الزري:** خيط حرير أصفر لامع (أصل فارسي — «ذهب»).

### **الحلي** 🟢
- **المرتعشة:** طبقات ذهبية على شكل صفوف — النساء يتفاخرن بطولها.
- **الخلال:** دبوس فضي.

---

## 4. الأعراس 🟢

- العريس: الكندورة + البشت + الغترة + العقال.
- العروس: الكندورة المزراوي + الثوب + حلي (المرتعشة) + البرقع + الحناء.

---

## 5. الفروق بحسب البيئة 🟢

| البيئة | اللباس | السبب |
|---|---|---|
| الساحل (أبوظبي/دبي) | كندورة قطن + غترة + عقال + بشت (مناسبات) | حضر + مناخ حار رطب |
| الجبال (رأس الخيمة/الفجيرة) | كندورة + ملابس دافئة شتاءً | جبلي + برد |
| الصحراء (العين/الظفرة) | كندورة + بشت صوف + ملابس بدوية | بدوي + برد صحراوي |

---

## 6. التطور الحديث 🟢

- **الكندورة + الغترة + العقال:** اللباس الرسمي اليومي + العمل — محافَظ عليه بقوة (الأكثر بقاءً في الخليج).
- **البشت:** في المناسبات الرسمية + الوجهاء + العرسان.
- **اللباس الغربي (البدلة/الجينز):** رائج بين الشباب + العمل (وافدون).
- **النساء:** العباءة + الشيلة — شائع + الكندورة المطرزة في المناسبات + تطريز التلي.
- **بيت الكندورة:** علامة تجارية شهيرة للزي التقليدي.

---

## خلاصة اللباس

اللباس الإماراتي = **نجدي-بدوي بالأساس** (كندورة/غترة/عقال/بشت) + نسائي تراثي (كندورة/ثوب/عباءة/برقع/التلي/الزري). الكندورة الإماراتية تتميز بـ**بدون ياقة + الفروخة + تطريز الأكمام**. اللباس التقليدي محافَظ عليه بقوة في المناسبات + يُعد اللباس الرسمي. التلي والزري = حرفة تطريز تراثية نسائية. 🟢
