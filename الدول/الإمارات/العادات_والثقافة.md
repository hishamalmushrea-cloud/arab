# دولة الإمارات العربية المتحدة — العادات والثقافة

> منهجية: العادات + المناسبات + الفنون + العمارة + الحرف. ربط الجغرافيا بالثقافة.
> المصادر: ويكيبيديا، aletihad، u.ae، mofa.gov.ae، nabdh.el-emarat.

---

## 1. الموسيقى والفنون الشعبية 🟢

### (أ) العيالة 🟢 — الرقصة الوطنية
- **الوصف:** رقصة جماعية للرجال — صفان متقابلان + طبول + سيوف/عصي + شاعر + تحريك الأجساد.
- **الأصل:** **بدوي** — تراث بري.
- **المناسبة:** الأعياد الوطنية + الأعراس + المناسبات الرسمية.

### (ب) الردحة / الياولة 🟢
- **الوصف:** رقصة/عرض رجالي + إلقاء شعري + تحريك السلاح.
- **المناسبة:** الأفراح + المناسبات.

### (ج) اليولة 🟢
- **الوصف:** رقصة فردية بالسلاح — تحريك البارود/السيف + شعر.

### (د) الفنون البحرية 🟢
- أغاني البحر (الصيد + الغوص على اللؤلؤ) — على الساحل.

### (هـ) الموسيقى الصوفية 🟡
- بعض الزوايا (محدودة في الإمارات).

---

## 2. المجالس (المجلس/الديوانية) 🟢

- **المجلس:** مكان تجمع الرجال (أسبوعي/يومي) — لتبادل الأفكار + القضايا + الضيافة.
- **الأهمية:** مؤسسة اجتماعية-سياسية + التواصل بين المواطنين والحاكم.
- **«مجلس أبوظبي للتميز»** + مجالس الأسر.

---

## 3. الأعراس والمناسبات 🟢

### (أ) العرس الإماراتي — عدة أيام 🟢
- **الخطوبة → الحناء (ليلة الحناء) → العرس (العيالة/الردحة) → الدخلة.**
- العريس: الكندورة + البشت + الغترة + العقال.
- العروس: الكندورة المزراوي + الثوب + حلي + البرقع + الجلوة + الحناء.
- **الهدايا:** للعروسين + الحلي التراثية + الرسم بالحناء.

### (ب) المناسبات الوطنية 🟢
| التاريخ | المناسبة | الذكرى |
|---|---|---|
| **2 ديسمبر** | **العيد الوطني** | اتحاد 1971 |
| 1 مايو | عيد العمال | — |

### (ج) المناسبات الدينية 🟢
- رمضان (الهريس + الثريد + اللقيمات + المجالس) + عيد الفطر + عيد الأضحى + المولد النبوي.
- **القرقيعان:** منتصف رمضان (أطفال يطوفون + حلوى) — عادة خليجية مشتركة.

---

## 4. العمارة 🟢

### (أ) العمارة التقليدية 🟢
- **البيوت القديمة:** طين + خوص + مرجان + مجاهر هواء (بادقير — تكييف طبيعي) — حي الفهيدي التاريخي (دبي).
- **القصور:** قصر الحسن (الشارقة) + قصر العين (زايد).
- **الأسواق:** سوق نايف (دبي) + سوق العرصة (الشارقة) + سوق الذهب.
- **الحجر:** حي الفهيدي (دبي) + العين القديمة.

### (ب) العمارة الحديثة 🟢
- **برج خليفة** (دبي — أطول برج عالميًّا 828 م).
- **مطار دبي الدولي** (الأكبر عالميًّا بالمسافرين الدوليين).
- **ميناء جبل علي** (أكبر ميناء صناعي عالميًّا).
- **اللوفر أبوظبي** (السعديات) + متحف زايد الوطني.
- **مسرح دبي أوبرا** + **إكسبو 2020 دبي**.
- **مسجد الشيخ زايد الكبير** (أبوظبي — أحد أضخم المساجد).
- **العين** — مواقع تراث يونسكو (2011 — الأفلاج + المواقع الأثرية).

## 5. الحرف اليدوية 🟢

| الحرفة | الوصف |
|---|---|
| **السدو (النسيج)** | نسيج صوفي يدوي — تراث بدوي |
| **التلي** | تطريز خيوط ذهبية/فضية — حرفة نسائية |
| **الزري** | خيط حرير أصفر لامع — تطريز |
| **صناعة السفن (القلافة)** | سفن خشبية (سنبوك/شوعي) — تراث بحري |
| **الخوص** | نسج سعف النخيل — حصر + أواني |
| **الدخون/البخور** | تصنيع العطور والبخور |
| **الحلي** | ذهب/فضة (المرتعشة + الخلال) |

> الحرف الإماراتية مزيج **بدوي (السدو/الخوص) + بحري (القلافة) + حضري (التلي/الزري)**. 🟢

---

## 6. القيم الاجتماعية 🟢

- **الكرم والضيافة:** قيم عليا — القهوة العربية + التمر + المجالس.
- **النخوة/الشهامة:** قيم بدوية.
- **المجلس:** مؤسسة اجتماعية-سياسية.
- **العائلة الممتدة** + احترام الكبار.
- **التسامح:** الإمارات = «وزارة التسامح» + وثيقة الأخوة الإنسانية (2019).

---

## 7. الفنون المعاصرة 🟢

- **الأدب:** أحمد المنصوري + سلطان العميمي.
- **السينما/المسرح:** متنامية (دبي/أبوظبي).
- **الفن التشكيلي:** حسن شريف + محمد أحمد إبراهيم.
- **المهرجانات:** إكسبو 2020 دبي + مهرجان الشارقة المسرحي + أبوظبي (الفنون).
- **المتاحف:** اللوفر أبوظبي + متحف زايد الوطني + الفهيدي (دبي).

---

## 8. ربط الجغرافيا بالثقافة 🟢

| المنطقة | البصمة الثقافية |
|---|---|
| الساحل (أبوظبي/دبي) | حضر + تجارة + المجالس + القلافة + العمارة الحديثة (خليفة/اللوفر) |
| الجبال (رأس الخيمة/الفجيرة) | جبلي + زراعة + الشحوح |
| الصحراء (العين/الظفرة) | بدوي + السدو + الهريس + الأفلاج |

## خلاصة العادات والثقافة

الثقافة الإماراتية = **مزيج بري-بحري-حضري** (بداوة + تجارة بحرية + حضر) يتجلى في: **العيالة** (الرقصة الوطنية) + **المجالس** + **الأعراس** (التلي/المرتعشة) + **القهوة العربية** (الضيافة) + **العمارة** (الفهيدي/خليفة/اللوفر/مسجد زايد) + **الحرف** (السدو/التلي/القلافة). الإمارات = **دولة خليجية حديثة** (نفط + تجارة + سياحة + تنويع) لكن محافِظة على تراثها البري-البحري بقوة + رائدة في التسامح (وثيقة الأخوة الإنسانية). 🟢
