# مدن الإمارات — المرحلة الخامسة

> **المرحلة الخامسة:** ملف لكل **مدينة** موثَّقة داخل إمارة. المستوى الأعلى يبقى **إمارة** (المرحلة الرابعة). ليست محافظة ولا منطقة سعودية. 🟢
>
> **أبوظبي المدينة** في `العواصم/أبوظبي/` — لا تكرار هنا.
>
> **السكان:** لا تعداد اتحادي موحَّد لكل المدن. **SCAD 2024** لمناطق أبوظبي 🟢. دبي من مركز دبي للإحصاء 🟡. سائر المدن تقديرات أو جداول قديمة 🟡. لا يُخلط سكان **الإمارة** بسكان **المدينة** حيث ينفصلان (رأس الخيمة، الفجيرة).
>
> لا تُهمَّش الجيوب والساحل الشرقي: حتا، خورفكان، كلباء، دبا الحصن، دبا الفجيرة، فلج المعلا، مصفوت، منامة عجمان.
