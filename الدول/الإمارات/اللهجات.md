## 2. اللهجات الجهوية 🟢

> اللهجة الإماراتية تتباين بين **الحضر** و**البدو** و**الجبال** + بين الساحل الغربي والشرقي.

### (1) لهجة حضر الساحل الغربي 🟢
- **المنطقة:** أبوظبي (الظبيانية) + دبي + الشارقة + عجمان + حمرية الشارقة.
- **الميزة:** الأكثر شيوعًا في الدولة + ذابت معظم الفروقات مع الزمن.

### (2) اللهجة القيوانية 🟢
- **المنطقة:** أم القيوين — مشابهة للساحل الغربي لكن تختلف في بعض الكلمات.

### (3) لهجة حضر رأس الخيمة 🟢
- **المنطقة:** رأس الخيمة (الساحل + المدينة).

### (4) لهجة حضر الساحل الشرقي 🟢
- **المنطقة:** الفجيرة + كلباء + خورفكان + دبا + ضدنا — **تشبه اللهجة العمانية**.
- **الميزة:** مختلفة عن الساحل الغربي.

### (5) لهجة البدو 🟢
- **المنطقة:** أبوظبي + العين + المنطقة الغربية (الظفرة) + الإمارات الشمالية (داخل).
- **الميزة:** أقرب للفصحى + مفردات بدوية (وايد = كثير، الفتا = الولد/البنت).

### (6) لهجة المناطق الجبلية 🟢
- **المنطقة:** جبال رأس الخيمة (دون الشحوح) + المناطق الجبلية الشرقية.
- **الميزة:** خصائص فريدة + **اللهجة الشحية** (قبيلة الشحوح — مختلفة كليًّا).

## 5. ربط اللهجة بالجغرافيا والتاريخ 🟢

- **الساحل الغربي (أبوظبي/دبي):** حضر + تجارة بحرية → لهجة حضرية.
- **الساحل الشرقي (الفجيرة/خورفكان):** جوار عُمان → لهجة عمانية الطابع.
- **البدو (الداخل/الظفرة):** بداوة + نجد → أقرب للفصحى.
- **الجبال (رأس الخيمة):** عزلة + الشحوح → لهجة فريدة (شحية).

---

## خلاصة اللهجوية

اللهجة الإماراتية = **لهجة عربية خليجية** تتباين بين **حضر الساحل الغربي** (الأكثر شيوعًا) + **الساحل الشرقي** (عمانية الطابع) + **البدو** (أقرب للفصحى) + **الجبال** (الشحوح — فريدة). الثراء المعجمي يعكس تاريخ الإمارات (بحر + صحراء + جبال + تجارة). 🟢
