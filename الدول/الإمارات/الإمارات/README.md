# إمارات الدولة السبع — المرحلة الرابعة (الوحدات الإدارية العُليا)

> **المرجع الإداري:** المستوى الأعلى = **إمارة** — **7 إمارات** اتحادية. كل إمارة لها حاكم وحكومة محلية. لا يوجد «محافظة» اتحادية موحَّدة. 🟢
>
> **المستوى الثاني:** يختلف: أبوظبي **3 مناطق** (أبوظبي / العين / الظفرة). الباقي مدن وبلديات وجيوب بلا مصطلح اتحادي موحَّد. 🟢
>
> **أبوظبي المدينة** في `العواصم/أبوظبي/` — هنا **الإمارة**.
>
> **السكان:** لا تعداد اتحادي حديث موحَّد السنة لكل الإمارات. يُقرن كل رقم بسنته ومصدره. 🟡
>
> **المساحة:** البوابة الرسمية `u.ae`: أبوظبي **67,340 كم² (~84% من اليابسة)**. جداول أخرى تذكر 86–87%. 🟡
