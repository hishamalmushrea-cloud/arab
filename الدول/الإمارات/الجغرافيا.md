# دولة الإمارات العربية المتحدة — الجغرافيا

> منهجية: تربط التضاريس بالمناخ والمياه والثقافة. علامات الثقة: 🟢/🟡/🟠.
> المصادر: ويكيبيديا، mawdoo3، elmjd.com، propertyfinder، modakrati.blogspot، mofa.gov.ae.

---

## 1. الموقع والمساحة 🟢

- **جنوب شرق شبه الجزيرة العربية** — جنوب غرب آسيا.
- **المساحة:** 83,600 كم².
- **الإحداثيات:** 22°–26.5°N و51°–56.5°E.
- **الحدود:** السعودية (غرب/جنوب) + عُمان (شرق/جنوب) + الخليج العربي (شمال 644 كم) + خليج عمان (شرق 90 كم — الفجيرة).
- **الواجهة البحرية:** 1,318 كم إجمالية (الخليج العربي + خليج عمان).

---

## 2. التضاريس الكبرى 🟢

> الإمارات = **صحراء في الغالب** (صحراء الربع الخالي جنوبًا) + شريط ساحلي + جبال في الشرق. تنوع طبوغرافي فريد خليجيًّا.

### (أ) السهول الساحلية 🟢
- **السهل الساحلي الغربي:** يمتد على الخليج العربي (~650 كم) — تتركز عليه المدن الكبرى (أبوظبي + دبي + الشارقة + عجمان + أم القيوين + رأس الخيمة).
- **السهل الساحلي الشرقي:** يمتد على خليج عمان (~90 كم — الفجيرة + خورفكان + كلباء + دبا) — أخصب مناطق الدولة.
- **السهول الداخلية:** سهل الذيد + سهل الدقداقة — كثبان رملية.

### (ب) الجبال (2.6% من المساحة — 155 كم) 🟢
- **جبال الحجر:** تمتد شمالًا–جنوبًا على الحدود الشرقية (عُمان) — تفصل خليج عمان عن الصحراء الغربية.
- **جبل جيس** (رأس الخيمة): **1,925 م** — **أعلى قمة في الإمارات**.
- **جبل حفيت** (العين): ~1,200 م — منطقة جبلية + حدائق.
- **الشحوح** (رأس الخيمة الجبلية): مناطق جبلية وعرة.

### (ج) الصحاري والكثبان الرملية (الأغلب) 🟢
- **الربع الخالي** (جنوب): أحد أكبر الصحاري الرملية عالميًّا — غير مأهول + امتداد سعودي.
- **صحراء الكثبان** (وسط/غرب): كثبان + سبخات (سبخة مطي — أكبر سبخة 120 كم).
- **واحة ليوا** (جنوب غرب أبوظبي): شكل هلالي + نخيل + 220 كم شمال جزيرة أبوظبي.
- **العين/البريمي:** واحات + حدائق + أفلاج.

### (د) الجزر (200+ جزيرة) 🟢
- **أبو موسى + طنب الكبرى + طنب الصغرى:** محتلة من إيران (1971) 🟡.
- **صير بني ياس:** محمية طبيعية (أبوظبي) — 13,000+ حيوان.
- **السعديات + ياس:** منتجعات + ثقافة (اللوفر أبوظبي).
- **دلما + داس + زركوه + أم النار:** نفطية/سياحية.
- **صير بو نعير:** (الشارقة) — محمية.

## 3. المياه 🟢

| العنصر | الوصف |
|---|---|
| الأنهار | **لا أنهار دائمة** — وديان موسمية (وادي حتا + وادي الذيد). |
| المياه الجوفية | محدودة + مالحة — تحلية مياه البحر = المصدر الرئيسي. |
| الأفلاج | قنوات تقليدية (العين/حفيت) — تراث. |
| التحلية | الإمارات من كبار منتجي المياه المحلاة. |
| السدود | سدود في الجبال (الفجيرة/رأس الخيمة/حتا) لتجميع الأمطار. |

---

## 4. المناخ 🟢

> المناخ **صحراوي حار** — حار جدًّا صيفًا (مايو–سبتمبر) + دافئ شتاءً (نوفمبر–فبراير) + ربيع/خريف قصيران.

- **الصيف:** حار جدًّا (38–42°م + قد تتجاوز 50°م) + رطوبة عالية على الساحل (الخليج العربي) + جاف في الداخل.
- **الشتاء:** دافئ (24–26°م + قد ينخفض إلى 10–12°م) + أمطار شتوية قليلة (~100 مم) + ضباب ساحلي.
- **الجبال (رأس الخيمة/الفجيرة):** أكثر أمطارًا + أكثر برودة.
- **الربيع:** عواصف رملية/ترابية.
- **الجنوب (الربع الخالي):** حار جاف جدًّا — غير مأهول.

### ربط الجغرافيا بالثقافة 🟢

| المنطقة | المناخ/التضاريس | الأثر الثقافي |
|---|---|---|
| الساحل الغربي (أبوظبي/دبي) | حار رطب + سهل | حضر + تجارة + كندورة قطن + مأكولات بحرية |
| الجبال (رأس الخيمة/الفجيرة) | معتدل + أمطار | زراعة + لباس دافئ + وديان |
| الصحراء (الداخل/الربع الخالي) | حار جاف | بدوي + رعي + واحات (ليوا/العين) |

## 5. التربة والغطاء النباتي 🟢

- **تربة رملية/حصوية** — قليلة الخصوبة (معظمها صحراء).
- **الواحات:** العين + ليوا + الذيد — نخيل + خضراوات + فواكه.
- **الغطاء النباتي:** متناثر + صحراوي — يزدهر بعد الأمطار + أشجار القرم (مزارع بحرية).
- **السبخات:** سبخة مطي (أكبرها).
- **التصحّر 🟡:** تحدٍّ — لكن الإمارات بدويّة أصلًا + مشاريع تشجير (العين/ليوا).

---

## 6. المناطق الطبيعية والمحميات 🟢

- **محمية صير بني ياس:** محمية طبيعية + 13,000+ حيوان (أبوظبي).
- **محمية رأس الخيمة الجبلية:** جبال + تنوع حيوي.
- **محمية الوثبة/المرفأ:** طيور + سبخات (أبوظبي).
- **محمية حفيت:** جبل + حياة برية (العين).
- **محمية كور القرم:** أشجار القرم (أبوظبي).

---

## 7. التحديات البيئية 🟡

1. **الحرارة الشديدة** + الرطوبة (الساحل).
2. **العواصف الرملية/الترابية** (الربيع).
3. **ندرة المياه** — اعتماد على التحلية (مكلفة + طاقة).
4. **تآكل السواحل** + ارتفاع البحر.
5. **التصحّر** + ضعف الغطاء النباتي.
6. **البصمة الكربونية** — من النفط/الصناعة (الإمارات تطمح للحياد الكربوني).

## خلاصة جغرافية

الإمارات = **دولة صحراوية متنوعة** (83,600 كم²) تجمع بين **الساحلين** (الغربي على الخليج العربي 644 كم + الشرقي على خليج عمان 90 كم) + **جبال الحجر** (جبل جيس 1,925m — أعلى قمة) + **الربع الخالي** (أكبر صحراء رملية) + **200+ جزيرة**. المناخ صحراوي حار (صيف >40°م + رطوبة) + دافئ شتاءً. لا أنهار دائمة — اعتماد على التحلية. هذا التنوع (ساحل + جبل + صحراء + واحات) هو **أساس التباين الثقافي** بين الحضر (أبوظبي/دبي) + الجبليين (رأس الخيمة/الفجيرة) + البدو (الداخل). 🟢
