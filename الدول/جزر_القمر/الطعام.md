# المطبخ القمري

> مطبخ قمري يجمع التأثيرات السواحلية + العربية + الفارسية + الفرنسية + الهندية + الماليزية. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. نظرة عامة
- المطبخ القمري = **مزيج سواحلي + عربي + فارسي (شيرازي) + فرنسي + هندي + ماليزي**.
- يعتمد على: **الأرز** (أساس) + **الأسماك** (ساحل) + **الموز** + **جوز الهند** + **المانيوك** (الكاسافا) + **الكاري** + **اللحوم** (دجاج + ماعز) + **البهارات** (الفانيليا + القرنفل + الكركم + الكزبرة + الهيل).
- **حلال إسلامي:** لا خنزير + لا كحول + لا ميتة — الشعائر الدينية.
- **الأرز في كل وجبة** + «الوجبة على الطراز العائلي» (مشاركة).

## 2. الأطباق الرئيسية 🟢

### اللوكي/الوغو (Langoué/Loco) — اللحم 🟢
- **لحم ماعز/دجاج + كاري + حليب جوز الهند + بهارات** — طبق تقليدي.
- يُقدَّم مع الأرز.

### الكاري (Kari) — الكاري 🟢
- **لحم/دجاج/سمك + كاري (مسحوق جوز الهند + الكركم + الكزبرة + الهيل + القرفة + القرنفل)** — إرث هندي/فارسي.
- يُقدَّم مع الأرز.

### بيلا (Pilau) — الأرز 🟢
- **أرز + لحم/دجاج + بهارات (كاري + كركم + قرفة + هيل)** — إرث هندي/عربي.
- يُقدَّم في المناسبات.

### السمك المشوي/المقلي 🟢
- **سمك مشوي/مقلي + بهارات + ليمون** — ساحل + طازج.
- يُقدَّم مع الأرز + الخبز.

### السومبوكو (Somboko) — اللحم المقدد 🟡
- **لحم مقدد + بهارات** — إرث بدوي.

### الروري (Roué) — اللحم المشوي 🟢
- **لحم مشوي** — إرث فرنسي.

---

## 3. الأطباق الأخرى 🟢

### المانيوك (Manioc) — الكسافا 🟢
- **كسافا (جذر) + طرليات** — أصل أفريقي (برازيلي) — أمن غذائي.
- يُقدَّم مشوي/مقلّى + مع الأرز.

### جوز الهند (Coconut) 🟢
- **جوز الهند + حليب جوز الهند + لحم مبشور** — في أطباق كثيرة.
- «الكوكونو» (أكلة جوز الهند).

### الموز (Banane) 🟢
- **موز + طرليات** — يُقدَّم في كل وجبة + مع الأرز.
- «الوجبة القمرية» = أرز + سمك + موز.

### الخبز اللحوح/الأنجيرا (Roti) 🟢
- **خبز مسطح** — إرث هندي/إثيوبي.
- يُقدَّم مع الكاري/اللوكي.

### الخبز الفرنسي (Baguette) 🟡
- **خبز فرنسي** — إرث استعماري.

### السلطات + الفواكه 🟡
- **سلطة فواكه** (مانجو + أناناس + موز) + **سلطة** + **معجنات**.

---

## 4. الحلويات + المشروبات 🟢

### الحلويات
- **اللوكي/اللوغو:** حلوى + حليب جوز الهند + سكر + بهارات.
- **الكنيكو:** حلوى + موز + دقيق.
- **الدونات:** حلوى + إرث فرنسي.
- **اللونغو:** حلوى + أرز + حليب.

### المشروبات
- **الشاي القمري:** شاي + سكر + هيل + نعناع — مشروب وطني.
- **القهوة:** قهوة + هيل — إرث عربي + فرنسي.
- **عصير الفواكه:** مانجو + أناناس + جوافة.
- **اللبن + الحليب + ماء جوز الهند.**

---

## 5. الأطعمة والمناسبات 🟢
- **رمضان:** الأرز + اللحم + الكاري + السمبوسة + الشاي + القهوة + التمور.
- **الأعراس:** البيلا + اللوكي + الموز + الشاي.
- **العيد:** اللحم المشوي + الأرز + الكاري + الحلويات.
- **الضيافة:** اللوكي + الشاي + القهوة (كرم).

---

## 6. ربط الطعام بالجغرافيا والثقافة
- **المحيط الهندي + ساحل + حيد مرجانية** → الأسماك + الصيد + التجار العرب + الفرس + الهند. 🟢
- **المناخ الاستوائي + الرطوبة** → الموز + النخيل + جوز الهند + الكسافا + الفانيليا + القرنفل + إيلانغ إيلانغ + الغابات المطيرة — تكيف زراعي + ثقافة العطور.
- **الموقع المعبري** (مدغشقر + إفريقيا + الجزيرة العربية + الهند + جنوب شرق آسيا) → تأثيرات: سواحلية (الأفريقية) + عربية (الإسلام + الكاري) + فارسية (الشيرازي) + هندية (البهارات + الكاري + البيلا) + ماليزية/إندونيسية (الهجرات + جوز الهند) + فرنسية (الإستعمار + الخبز الفرنسي + القهوة).
- **الإسلام** → الحلال + لا خنزير/كحول + الشعائر الدينية + الأرز في كل وجبة (إرث سواحلي/هندي).
- **السلطنات الشيرازية** (القرن 11–19) → تجارة + الأنساب (عرب/فارس) + الكاري + البيلا + الفانيليا + القرنفل.
- **الإستعمار الفرنسي** (1841–1975) → الخبز الفرنسي + القهوة + اللوكي (إرث فرنسي) + الزراعة (الفانيليا + القرنفل).
- **الجزر المنفصلة مسافات** → جزر صغيرة + لا قارات + قوارب + حياة جزيرية + أودية.
