# جغرافيا اتحاد جزر القمر

> علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. الموقع والمساحة
- **الموقع:** المحيط الهندي — شمالي قناة موزمبيق — بين مدغشقر + الساحل الإفريقي.
- **الإحداثيات:** 12°10′S ، 44°15′E.
- **المساحة:** نحو **1,861 كم²** للجزر الثلاث المُدارة 🟢. الرقم 2,235 يضم مايوت. **ليست** أصغر دولة عربية.
- **الموقع الاستراتيجي:** قناة موزمبيق (على طريق التجارة: شرق أفريقيا + الجزيرة العربية + الهند + جنوب شرق آسيا). 🟢

## 2. الجزر (الأرخبيل)
- **4 جزر رئيسية بركانية** + جزر صغيرة + صخور.
- **القمر الكبرى (نجازيجيا):** أكبر الجزر (1,148 كم² — 64% من المساحة) + عاصمتها موروني + جبل كارتالا (2,361م — بركان نشط) + ساحل ~167 كم.
- **أنجوان (نزواني):** ثانية الجزر مساحةً (424 كم²) + عاصمتها موتسامودو + جبال (سيما + نيوماكلي + جيميليم — أعلى قمة 1,575م) + ساحل ~88 كم.
- **موهيلي (موالي):** أصغر الجزر (290 كم²) + عاصمتها فومبوني + هضاب + غابات مطيرة + ساحل ~45 كم.
- **مايوت (ماهوري):** أقدم الجزر + جيولوجيًّا (375 كم²) + عاصمتها الإدارية الفرنسية مامودزو (دزاودزي سابقة) + حيد مرجاني + ساحل ~55 كم.
- **جزر صغيرة:** جزر صغيرة حول الثلاث؛ جزر غلوريوز إدارة فرنسية منفصلة لا محافظة قمرية.

## 3. التضاريس
- عمومًا: **جبال بركانية + هضاب + سهول ساحلية** — تضاريس جبلية ترتفع من المحيط.
- **أعلى نقطة:** **جبل كارتالا (نحو 2,361 م)** على نجازيجيا — بركان درعي نشط. **ليس** أكبر براكين العالم. 🟢
- **براكين أخرى:** لا غريل (1,000م — شمال القمر الكبرى + جبال أنجوان (سيما + نيوماكلي + جيميليم) + هضاب موهيلي (860م) + جبال مايوت (بنارا 660م).
- **أنخفض نقطة:** المحيط الهندي (مستوى البحر).
- **حيد مرجانية** تحيط بالجزر (خاصة مايوت) + شعاب مرجانية.
- **سهول ساحلية** + **حقول بركانية** + **غابات مطيرة** (موهيلي).

## 4. المناخ 🟢
- **تصنيف كوبن:** **Af** (استوائي رطب) — حار + رطب + أمطار موسمية.
- **موسم ممطر (الكاسي):** نوفمبر–أبريل (المدار).
- **موسم جاف (الكراني):** مايو–أكتوبر.
- **الأمطار:** ~1,000–3,000 مم (مرتفعة — استوائي).
- **الحرارة:** ~25–30°م (معتدل — جزر) + رطب (مرتفعة — جزر + ساحل).
- **الرياح:** موسمية (موسمية + جنوبية شرقية) + إعصارات (خاصة أنجوان + موهيلي).

## 5. الموارد المائية
- **لا أنهار دائمة** (كلها أودية موسمية + ينابيع).
- **مياه جوفية** (محدودة — آبار + ينابيع).
- **تحلية** محدودة (موروني + موتسامودو).
- **بحيرات:** دزياني بوندوني (موهيلي — بحيرة فوهة بركانية) + سالا (أنجوان).
- **أمطار:** كثيفة + استوائية — مصادر مياه.

## 6. التربة والغطاء النباتي
- **التربة:** بركانية (حصوية + رملية + طينية) + خصبة (من رماد بركاني).
- **الغطاء:** غابات مطيرة (موهيلي) + سافانا + مانغروف (ساحل) + أعشاب + نخيل.
- **غابات:** ~17% من المساحة (محدودة — زحف + قطع).
- **حيد مرجانية** + شعاب.

## 7. الموارد الطبيعية
- **الزراعة:** ~50% من الناتج + >80% من القوى العاملة — الفانيليا + القرنفل + إيلانغ إيلانغ + جوز الهند + الموز + الكسافا + الأرز.
- **الصيد:** ~50% من الناتج — أسماك (تونة + أسماك هندية) — صيد ساحلي + أمن غذائي.
- **التعطور (إيلانغ إيلانغ):** لأغراض العطور + المستحضرات الطبية — تصدير لفرنسا.
- **السياحة:** قطاع ناشيء + غير مستغل (شواطئ + غوص + طبيعة).
- **المعادن:** محدودة + براكين.
- 🟠 **نقص** + موارد محدودة + اعتماد على الزراعة + الصيد + التحويلات.

## 8. المناطق الطبيعية والمحميات
- **جبل كارتالا** (بركان نشط + أعلى نقطة + غابات مطيرة على المنحدرات).
- **بحيرات** (دزياني بوندوني + سالا) + حيد مرجاني + شعاب.
- **شواطئ** (رملية + صخرية + حيد مرجاني).
- **محمية موهيلي البحرية** (شعاب مرجانية + سلاحف + دلافين).
- **غابات موهيلي المطيرة** (محمية).

## 9. النقل والربط
- **الموانئ:** موروني (العاصمة) + موتسامودو (أنجوان) + ماموتزو (مايوت — فرنسا).
- **المطارات:** الأمير سعيد ابراهيم الدولي (هاهايا — القمر الكبرى) + مطارات داخلية.
- **الطرق:** محدودة + ضعيفة (لا قارات بين الجزر — مسافات شاسعة).
- **النقل البحري:** قوارب + عبّارات بين الجزر.
- 🟠 **البنية التحتية ضعيفة** + لا قارات بين الجزر (مسافات: نجازيجيا ~200 كم من مايوت + ~40 كم من موهيلي + ~50 كم من أنجوان).

## 10. ربط الجغرافيا بالثقافة (رؤية تطبيقية)
- **الموقع الاستراتيجي** (قناة موزمبيق + على طريق التجارة) → شبكة تجارية سواحلية-عربية-فارسية-هندية + السلطنات الشيرازية (القرن 11–19) + الإسلام + تجارة. 🟢
- **الأرخبيل البركاني + جبل كارتالا** → جزر بركانية + تضاريس فريدة + براكين نشطة + ثوران + غابات مطيرة + تربة خصبة — تأثير جيو-ثقافي.
- **المحيط الهندي + حيد مرجانية** → ثقافة بحرية + صيد + تجارة + شواطئ + غوص + السلطنات الساحلية.
- **الموقع المعبري** (مدغشقر + إفريقيا + الجزيرة العربية + الهند) → ثقافة هجينة (سواحلية + عربية + فارسية + ماليزية/إندونيسية + هندية) + الإسلام كمكوِّن موحِّد.
- **الإستعمار الفرنسي** (1841–1975) → الإرث الفرنسي (اللغة + العمارة + القهوة + المرفأ + الزراعة).
- **الجزر المنفصلة مسافات** (نجازيجيا ~200 كم من مايوت) → تكيف + حياة جزيرية + قوارب + أودية + عدم قارات + جزر صغيرة.
- **المناخ الاستوائي + الرطوبة** → الموز + النخيل + الفانيليا + القرنفل + إيلانغ إيلانغ + غابات مطيرة + تكيف زراعي.
