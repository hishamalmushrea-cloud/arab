# اقتصاد اتحاد جزر القمر

> اقتصاد زراعي + عطور + فقر + اعتماد على التحويلات + المساعدات. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر.

---

---

## 2. الزراعة — عصب الاقتصاد 🟢
- **~50% من الناتج** + **>80% من القوى العاملة** — كفاف + معيشة.
- **المحاصيل النقدية (الصادرات):**
  - **الفانيليا** (Vanilla — أكبر منتج قمري + ثالث عالميًّا) — تصدير.
  - **القرنفل** (Clove — من أكبر المنتجين عالميًّا) — تصدير.
  - **إيلانغ إيلانغ** (Ylang-ylang — لصناعة العطور) — أكبر منتج + تصدير.
  - **جوز الهند** (Coco) — تصدير.
- **المحاصيل الغذائية:** الموز + الكسافا + قصب السكر + الذرة + الأرز.
- 🟠 **تستورد ~70% من غذائها** (الأرز القسم الأكبر) + الأراضي محدودة (تضاريس + زحف + تربة).

---

## 3. الصيد — ~50% من الناتج 🟢
- **أسماك** (تونة + أسماك هندية) — صيد ساحلي + أمن غذائي.
- **~50% من الناتج** + تصدير محدود.
- **مياه إقليمية** تمتد ~320 كم بعيدًا — إمكانات (لا تُستغل بالكامل).

---

## 4. تقطير العطور + الزيوت العطرية 🟢
- **تقطير العطور** (مصانع في موروني + موتسامودو + فومبوني) — تصدير.
- **الفانيليا + إيلانغ إيلانغ + القرنفل** → تقطير + تصدير لفرنسا (المستحضرات الطبية + العطور).
- «الطقس» (الحرارة) → الناتج محدود + تقلبات السوق.

---

## 5. التحويلات — ~25% من الناتج 🟢
- **التحويلات من المغتربين القمريين** (~25% من الناتج) — مصدر دخل خارجي كبير.
- **المغتربين:** في فرنسا (الأغلبية — خاصة بعد مايوت) + السعودية + الإمارات + مدغشقر + أوروبا.
- **تمويل:** الصادرات + الواردات + الاستهلاك + الاستثمار (غير رسمي).

---

## 6. السياحة — قطاع ناشيء 🟡
- **سياحة طبيعية:** شواطئ (رملية + صخرية) + حيد مرجانية + غوص + براكين + غابات مطيرة.
- **سياحة ثقافية:** مسجد فينديري + موروني + سلطنات + البيوت التقليدية.
- 🟠 **سياحة محدودة** (لا بنية تحتية + لا طيارات مباشرة + الفقر + الحالات السياسية).

---

## 7. الصناعة + التعدين 🟡
- **الصناعة:** ~11% من الناتج — تقطير العطور + الزيوت العطرية + صناعة الأغذية + الحرف اليدوية + مواد البناء.
- **التعدين:** موارد محدودة + لا معادن كبيرة + براكين.
- 🟠 صناعة محدودة + اعتماد على الزراعة + الصيد.

---

## 8. التجارة الخارجية 🟢🟠
- **الصادرات (~20 مليون $ 2012):** الفانيليا + إيلانغ إيلانغ + القرنفل + جوز الهند + الأسماك + العطور + الموز.
- **الواردات (~208 مليون $ 2012):** الأرز + المواد الغذائية + السلع الاستهلاكية + المنتجات البترولية + الأسمنت + معدات النقل.
- **الشركاء التصدير:** فرنسا + الهند + سنغافورة + هولندا + ألمانيا + تركيا + السعودية + الإمارات + الولايات المتحدة.
- **الشركاء الاستيراد:** فرنسا + الصين + الإمارات + باكستان + الهند + كينيا + هونغ كونغ.
- 🟠 **عجز تجاري** (الواردات > الصادرات بـ10 أضعاف) + اعتماد على المساعدات + التحويلات.

---

## 9. المالية العامة 🟠
- **إجمالي الاحتياطي:** ~208 مليون $ (2017).
- **الدين الخارجي:** ~136 مليون $ (2012).
- **المساعدات الأجنبية:** تمويل المشاريع التنموية + دفع العجز.
- **الخصخصة** (بدأت 1996 — خاصة الموانئ + الزراعة).
- 🟠 **العجز المالي + الدين الخارجي + اعتماد على الخارج** + الفقر (~60%).

---

## 10. التحديات الاقتصادية 🟠
- **الفقر** (~60% تحت خط الفقر) + البطالة (~20%) + الأمية + ضعف البنية التحتية.
- **الدين الخارجي** (~136 مليون $) + العجز المالي + اعتماد على المساعدات.
- **تقلبات السوق** (الفانيليا + القرنفل + إيلانغ إيلانغ — أسعار متذبذبة) + «الطقس» (الحرارة).
- **تستورد ~70% من غذائها** + الأراضي محدودة + زحف + قطع الغابات.
- **لا إكتفاء ذاتي** + موارد محدودة + عدم تنويع.
- **السياحة غير مستغلة** (لا بنية تحتية + الفقر + الحالات السياسية).
- 🟠 **مايوت:** فرنسا تديرها + جزر القمر تطالب بها + تقلبات علاقات (إرث استعماري + مايوت أغنى — قضايا حساسة).

---

## 11. ربط الاقتصاد بالجغرافيا
- **المناخ الاستوائي + الرطوبة** → الفانيليا + القرنفل + إيلانغ إيلانغ + جوز الهند + الموز + النخيل + الكسافا + الغابات المطيرة — تكيف زراعي + ثقافة العطور. 🟢
- **المحيط الهندي + حيد مرجانية + شواطئ** → الصيد + التجار العرب + الفرس (الشيرازي) + السلطنات الساحلية. 🟢
- **الموقع المعبري** (مدغشقر + إفريقيا + الجزيرة العربية + الهند + جنوب شرق آسيا) → ثقافة هجينة + تجارة + الأنساب العربية/الفارسية (شيرازي — روايات) + الإسلام.
- **الإستعمار الفرنسي** (1841–1975) → الإرث الفرنسي (اللغة + العمارة + القهوة + الزراعة + المرفأ) + تقطير العطور + تخصيص (1996).
- **المغتربون القمريون** (فرنسا + السعودية + الإمارات + أوروبا) → التحويلات (~25% من الناتج — مصدر دخل خارجي كبير) + المغتربين.
- **الجزر المنفصلة مسافات** → لا قارات + قوارب + حياة جزيرية + موارد محدودة + لا إكتفاء + زراعة كفاف.
- **السوق العالمي** (الفانيليا + القرنفل + إيلانغ إيلانغ — تقلبات + منافسة + «الطقس» (الحرارة) → اقتصاد هش + فقر + اعتماد على التحويلات + المساعدات + الدين الخارجي. 🟠
- **مايوت:** فرنسا تديرها + جزر القمر تطالب بها + الأمم المتحدة تعترف بسيادة جزر القمر — قضايا حساسة (إرث استعماري + مايوت أغنى) → علاقات متقلقة. 🟠
