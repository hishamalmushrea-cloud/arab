# اللباس في اتحاد جزر القمر

> لباس قمري يجمع التأثيرات السواحلية + العربية + الفارسية + الفرنسية + الإسلامية. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. نظرة عامة
- اللباس التقليدي = **محتشم + خفيف + مكيِّف مع الحر** (ألوان فاتحة + أقمشة خفيفة) + **الإسلام** (حشمة).
- زي متنوع عبر الجزر (كل جزيرة لها طابع خاص) + تأثيرات خارجية (عربية + فارسية + فرنسية).
- **اللباس الحديث** منتشر في المدن (أروبي + عربي).

---

## 2. اللباس الرجالي 🟢

### الكوفية (Kofia) — الزي القومي الرجالي 🟢
- **قبعة مطرَّزة** (خياطة يدويًّا + حرير + قطن + تطريز معقَّد) — إرث عربي/سواحلي.
- **ألوان + زخارف:** أبيض + أسود + أزرق + أخضر + ذهبي — رمز الأناقة + المكانة.
- يُرتدى في المناسبات (الأعراس + العيد + الجمعة) + في الحياة اليومية.
- **رمز الهوية القمرية** + الأناقة + الكرم.

### الثوب/الخميص (Khamiis) — إرث عربي 🟢
- **ثوب طويل أبيض** (يشبه الثوب الخليجي) — زي رسمي/ديني.
- يُرتدى في المناسبات + الجمعة.
- تأثير الثقافة العربية + الإسلام.

### السروال
- **بنطال واسع** تحت الثوب — إرث عربي.

### الإكسسوارات
- **السيف:** في المناسبات (إرث بدوي/شيرازي).
- **العكاز:** رمز الهيبة.
- **السبحة:** للشيوخ (إرث صوفي).

---

## 3. اللباس النسائي 🟢

### الشيرماني/الديوهو (Shiromani/Djohu) — الزي القومي النسائي 🟢
- **فستان طويل ملوَّن + مطرَّز + لمعان** — إرث عربي/فارسي/سواحلي.
- **ألوان زاهية + أنماط + تطريز** — رمز الأناقة + الأنوثة + الهوية.
- يُرتدى في **المناسبات** (الأعراس + العيد) + رمز الكرم.
- «شيرماني» = وشاح طويل + «ديوهو» = فستان (نوعان).

### البوبو (Boubou) — إرث سواحلي 🟡
- **ثوب واسع ملوَّن** — إرث سواحلي/إفريقي.
- يُرتدى في الحياة اليومية + المناسبات.

### الشال/الحجاب — إرث إسلامي 🟢
- **شال** على الكتف/الرأس — حشمة + إسلام.
- **الحجاب:** رمز ديني + حشمة (تأثير إسلامي).

### السروال
- **بنطال** تحت الفستان — إرث عربي.

### الإكسسوارات النسائية 🟢
- **الذهب:** قلائد + خلخال + أساور + خواتم — رمز الرخاء + السعادة (الأعراس).
- **الحناء:** في الأعراس + الموالد.
- **الكحل:** للعين (تجميل).
- **«البنية» (Binya):** سوار (أصل عربي/هندي).

---

## 4. اللباس الحديث 🟢
- **اللباس الأروبي** (القمصان + البناطيل + الفساتين) — منتشر في المدن + الأعمال + الشباب.
- **الكوفية + الشيرماني** تبقى للجمعة + المناسبات + الأعراس + العيد.
- **الحجاب + النقاب:** انتشار (نساء محافظات — تأثير إسلامي).
- **اللباس الفرنسي:** إرث استعماري (القمصان + التنورة + المعجنات).

---

## 5. اللباس حسب الجزر والثقافة 🟡
- **القمر الكبرى (نجازيجيا):** الكوفية + الثوب + الشيرماني (تأثير عربي + مركزي).
- **أنجوان:** الكوفية + الشيرماني + البوبو (تأثير أنجواني/سواحلي).
- **موهيلي:** الشيرماني + البوبو + غابات مطيرة (تأثير موهيلي/إفريقي).
- **مايوت:** اللباس الفرنسي + البوبو + تأثير ماليزي/فرنسي.
- كل جزيرة لها طابع خاص في اللباس + تتباين + تفاهم.

---

## 6. ربط اللباس بالجغرافيا والثقافة
- **الحر + الرطوبة الاستوائية** → الكوفية (قطن خفيف + تهوية) + الثوب (أبيض) + الشيرماني (خفيف + فضفاض) + ألوان فاتحة. 🟢
- **الإسلام + المحتشام** → الثوب/الخميص (أبيض + حشمة) + الحجاب + الشال + الكوفية + الكحل + الحناء.
- **الموقع المعبري** (مدغشقر + إفريقيا + الجزيرة العربية + الهند + فارس) → الكوفية (إرث عربي/سواحلي) + الشيرماني (إرث عربي/فارسي) + البوبو (إرث سواحلي/إفريقي) + السروال (إرث عربي) + تأثيرات متبادلة.
- **الإستعمار الفرنسي** (1841–1975) → اللباس الفرنسي (قمصان + بناطيل + معجنات) + إرث استعماري.
- **التجارة التاريخية** (العرب + الفرس/الشيرازي + الهند) → استيراد الحرير + الأقمشة المطبوعة من الجزيرة العربية + فارس + الهند + فرنسا.
- **الكرم + الضيافة** → الكوفية المطرَّزة (للمناسبات) + الذهب (إظهار للكرم).
- **الجزر المنفصلة مسافات** → كل جزيرة لها طابع خاص في اللباس + تتباين + تفاهم.
