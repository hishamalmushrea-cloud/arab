# المجتمع والقبائل والطوائف في اتحاد جزر القمر

> تركيبة عرقية مركّبة: قمريون (عرب/فرس/شيرازي + أفارقة/بانتو + ماليزيون/إندونيسيون + هنود). علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر (مايوت + الانقلابات).

---

## 1. السكان — الأرقام 🟡
- **السكان:** ~0.85–0.95 مليون (2024 تقديري) — أصغر دولة عربية سكانًا.
- **الكثافة:** ~400–450 نسمة/كم² (مرتفعة — أصغر مساحة).
- **التوزيع:** >50% ريف + كثافة مرتفعة (نجازيجيا + أنجوان — الأكثر سكانًا).
- **معدل النمو:** ~2.5% سنويًّا (مرتفع).
- 🟡 لا إحصاء رسمي دقيق (تقديرات UNDP + CIA).

---

## 2. التركيبة الإثنية/العرقية 🟢🟡

### القمريون — مزيج عرقي 🟢🟡
- **القمريون:** مزيج (عرب + فرس/شيرازي + أفارقة/بانتو + ماليزيون/إندونيسيون + هنود).
- **الدين:** الإسلام ~98% (دين الدولة — سُنة + شافعية) + صوفية (قادرية).
- **اللغات:** الشيقمري (قمرية — لهجة سواحلية) + العربية + الفرنسية (رسمية).
- 🟡 *رواية شفهية:* نسب القمريين إلى شيرازي (عرب/فارس من شيراز — فارس) + مهاجرين من عمان + الأحساء + اليمن.

### الأصول (هجرات متتالية) 🟢
- **القرن 5 هـ/11 م:** ماليزيون/إندونيسيون (هجرات + تجارة).
- **القرن 7 هـ/13 م:** عرب + فرس (شيرازي) (تجارة + الإسلام).
- **زنوج من زنجبار + مدغشقر** (البانتو).
- **هنود** (تجارة).
- **أوروبيون** (فرنسيون — إرث استعماري).

### القبائل 🟢🟡
- **مواندرومي (القمر الكبرى):** قبائل نجازيجيا + شياخات (إرث شيرازي/عربي).
- **مواني (أنجوان):** قبائل نزواني + شياخات.
- **موالي (موهيلي):** قبائل موالي + شياخات.
- **ماهوري (مايوت):** قبائل ماهوري + شياخات (إرث ماليزي/إندونيسي — أقدم الجزر).
- نظام القبائل = شياخات + أمراء + سلاطين (تاريخي) + مجالس (حديث).

---

## 3. الأديان والمذاهب 🟢
- **الإسلام ~98%** (دين الدولة + الهوية):
  - **سُنة + شافعية** (غالبية).
  - **الصوفية:** قادرية (الأكثر انتشارًا) + شاذلية + رفاعية + أحمدي.
- **المسيحية ~2%:** رومان كاثوليك — أوروبيون (فرنسيون — إرث استعماري) + أقليات.
- 🟢 جزر القمر بلد إسلامي + عضو جامعة الدول العربية (منذ 1993) + العربية لغة رسمية.

---

## 4. العائلات والزعامات 🟢🟠
- **آل أحمد عبد الله عبدريمان** (المؤسس — رئيس 1975–1978 + 1978–1989).
- **آل سعيد محمد جوهر** (رئيس 1990–1995).
- **آل محمد تقي عبد الكريم** (رئيس 1996–1998).
- **آل عزالي أسومان** (الحالي — منذ 1999 — أُعيد 4 مرات).
- **آل تاج الدين بن سعيد ماسوندي** (رئيس 1998–1999).
- **آل غزالي عثماني** (رئيس 1999–2002).
- الزعامات القبلية: شياخات + أمراء + سلاطين (تاريخي).
- الزعامات الدينية: شيوخ الطرق الصوفية (قادرية).

---

## 5. السياسة والمشاركة 🟢🟠
- نظام: **جمهورية اتحادية رئاسية** (تناوب الرئاسة بين الجزر الثلاث — دستور 2001).
- **الرئاسة:** عزالي أسومان (2016–الآن — أُعيد 2024).
- **الجمعية الوطنية:** برلمان (33 مقعد) + 3 جزائر ذات حكم ذاتي (القمر الكبرى + أنجوان + موهيلي) + مايوت (فرنسا — متنازَع عليها).
- **الأحزاب:** التجمعة الوطنية + Convention pour le renouveau national + أحزاب أخرى.
- 🟠 *القضايا الحساسة* (مايوت — فرنسا تديرها + جزر القمر تطالب بها + الأمم المتحدة تعترف بسيادة جزر القمر) تُورَد بحياد.
- **تناوب الرئاسة** = حل توافقي (القمر الكبرى → أنجوان → موهيلي كل 4 سنوات) + دستور 2001.

---

## 6. التحديات الاجتماعية 🟠
- **مايوت:** فرنسا تديرها + جزر القمر تطالب بها + الإستفتاءات المتتالية في مايوت (1974 + 1976 + 2009) + الأمم المتحدة تعترف بسيادة جزر القمر — قضايا حساسة.
- **الفقر** (~60% تحت خط الفقر) + البطالة (~20%) + الأمية + ضعف البنية التحتية.
- **الدين الخارجي** (~136 مليون $) + العجز المالي + اعتماد على المساعدات + التحويلات.
- **الجزر المنفصلة مسافات** + لا قارات + حياة جزيرية + موارد محدودة + زحف + قطع الغابات.
- **20+ انقلابًا** (1975–1999) + تدخلات «بوب دينار» — تأريخ مضطرب (إرث استعماري + ضعف مؤسسي).
- **تقلقات العلاقات مع فرنسا** (مايوت + المصالح + الإستفتاءات).

---

## 7. ربط المجتمع بالجغرافيا والتاريخ
- **الموقع المعبري** (مدغشقر + إفريقيا + الجزيرة العربية + الهند + فارس) → اختلاط عرقي (عرب + فرس/شيرازي + أفارقة/بانتو + ماليزيون/إندونيسيون + هنود) + الإسلام (القرن 7 هـ/13 م) + التجار (شيرازي) — «القمريون» = مزيج. 🟢
- **المحيط الهندي + حيد مرجانية + شواطئ** → ثقافة بحرية + صيد + التجار العرب + الفرس (الشيرازي) + زنوج من زنجبار + مدغشقر.
- **الإسلام + التجار العرب/الفرس** (القرن 7 هـ/13 م) → الإسلام ~98% + العربية لغة الدين + الأنساب العربية/الفارسية (شيرازي — روايات) + الشافعية + الصوفية (قادرية) + الختان + الموالد + الزيارات.
- **الإستعمار الفرنسي** (1841–1975) → الإرث الفرنسي (اللغة + العمارة + القهوة + اللباس) + المسيحية ~2% (أوروبيون) + مايوت (إقليم فرنسي).
- **الجزر المنفصلة مسافات** (نجازيجيا ~200 كم من مايوت + ~40 كم من موهيلي + ~50 كم من أنجوان) → تباين جزيري + قبائل + لهجات + ثقافة + حياة جزيرية + لا قارات + قوارب.
- **السلطنات الشيرازية** (القرن 11–19) → نظام سياسي محلي (سلاطين + شياخات + أمراء) + تجارة + الإسلام + الأنساب.
- **الانقلابات + «بوب دينار» + مايوت** → تأريخ مضطرب (إرث استعماري + ضعف مؤسسي + المصالح الفرنسية + الانفصال) + دستور 2001 (تناوب الرئاسة = حل توافقي). 🟠
