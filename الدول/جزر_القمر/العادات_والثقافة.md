# العادات والثقافة في اتحاد جزر القمر

> ثقافة قمرية مركّبة: سواحلية + عربية إسلامية + فارسية (شيرازي) + ماليزية/إندونيسية + فرنسية. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر (مايوت حساس).

---

## 1. القبائل + القمريون 🟢

### القمريون — مزيج عرقي 🟢🟡
- **القمريون:** مزيج (عرب + فرس/شيرازي + أفارقة/بانتو + ماليزيون/إندونيسيون + هنود).
- 🟡 *رواية شفهية:* نسب القمريين إلى شيرازي (عرب/فارس من شيراز — فارس) + مهاجرين من عمان + الأحساء + اليمن.
- **الإسلام:** دين الدولة ~98% (سُنة + شافعية) + صوفية.
- **اللغات:** الشيقمري (قمرية — لهجة سواحلية) + العربية + الفرنسية (رسمية).

### القبائل
- **مواندرومي (القمر الكبرى):** قبائل نجازيجيا + شياخات (إرث شيرازي/عربي).
- **مواني (أنجوان):** قبائل نزواني + شياخات.
- **موالي (موهيلي):** قبائل موالي + شياخات.
- **ماهوري (مايوت):** قبائل ماهوري + شياخات (إرث ماليزي/إندونيسي).
- نظام القبائل = شياخات + أمراء + سلاطين (تاريخي) + مجالس (حديث).

---

## 2. الأعراس والزواج 🟢

### مراحل الزفاف
1. **المهر:** الخطوبة + تقديم المهر (إرث إسلامي).
2. **«الدوهو» (الزفاف):** الفستان (الشيرماني) + الوليمة.
3. **الحناء:** للعروس + العريس.
4. **«السمبوا» (Sambwa):** الحفل + الرقصات + الغناء.
5. **الوليمة:** الأرز + اللحم + الموز + الشاي.

### عادات
- **الختان:** للذكور (إرث إسلامي).
- **«الدوهو»:** الزفاف + الفستان + الحفل.
- **الأمارة القمرية:** حي القمريين + البيوت التقليدية.

---

## 3. المناسبات الدينية 🟢

### رمضان
- **الأرز + اللحم + الكاري + السمبوسة + الشاي + القهوة + التمور.**
- موائد جماعية + التراويح + الختمات.

### العيد
- صلاة العيد + الذبيحة (الأضحى) + الأرز + اللحم المشوي + الحلويات + الموز.
- **«السمبوا»:** الرقصات + الغناء.

### الموالد (المولد النبوي)
- مواكب + مدائح صوفية + قهوة + توزيع الحلويات.
- **«الزيارة» (Ziyara):** موالد الأولياء + الشيوخ (إرث صوفي).

---

## 4. الطرق الصوفية 🟢
- **القادرية** (عبد القادر الجيلاني — إرث إسلامي).
- **الشاذلية + الرفاعية + الأحمدية.**
- الزوايا + المدائح + الذكر + الختان.
- الصوفية مكوّن ديني/اجتماعي عميق.

---

## 5. العادات الاجتماعية 🟢
- **الكرم/الضيافة:** وجبة كاملة للغريب + الشاي + القهوة + الموز — قيمة أساسية (القرن 11–19).
- **«الدوهو» (الزفاف/الحفل):** المناسبات + الفستان + الوليمة.
- **المجالس (القعدات):** مجالس الرجال (المسيد) + النساء.
- **التكافل:** الجار + الأسرة + الأفراح + المآتم الجماعية (إرث سواحلي/عربي).
- **«الزيارة» (الزيارات):** موالد الأولياء + الزيارات (إرث صوفي).
- **السلام + المصافحة:** إرث إسلامي/عربي.

---

## 6. الفنون الشعبية 🟢
- **الرقصات:** «السمبوا» (Sambwa) + «التوسي» (Twarabu — أنجوان) + «الشيعنجا» (القمر الكبرى) + «الرسمية» (موهيلي).
- **الموسيقى:** تقليدي + تأثيرات عربية (العود + القنبوس) + سواحلية + إفريقية + فرنسية + هندية.
- **الشعر:** شيقمري (غنائي) + عربي + فرنسي + سواحلي.
- **الفنون الحرفية:** النسيج (الشيرماني/الديوهو) + صناعة الكوفية + الجلود + الخشب + الصياغة (الذهب).

---

## 7. العمارة التراثية 🟢

### العمارة الإسلامية + الشيرازية
- **مسجد فينديري (Vendredi):** على القمر الكبرى — رمز معماريا + تاريخي + يُرى منه مدينة موروني.
- **مسجد الجمعة القديم (Badjanani):** في موروني.
- **البيوت التقليدية:** «الدوهو» + الحي القمري + العمارة الشيرازية (أصل فارسي/عربي).
- **السلطنات:** آثار سلطنة القمر الكبرى + أنجوان + مايوت + موهيلي (إرث شيرازي).

### العمارة الفرنسية (إرث استعماري)
- **مدينة موروني:** عمارة فرنسية قديمة + الميناء + السكة.
- **العمارة الاستعمارية:** المباني + الشوارع المرصوفة.

### العمارة الحديثة
- **المطار + المرفأ + القصور** — عمارة حديثة.

---

## 8. الثقافة المعاصرة 🟢
- **الشعر:** شيقمري (غنائي) + عربي + فرنسي + سواحلي.
- **الأدب الحديث:** أدب قمري + أدب فرنسي (الإستعمار) + أدب عربي.
- **الموسيقى:** تقليدي + حديثة — مطربون + فرق (نابحيا + أحراد).
- **الإعلام:** إذاعة (الإذاعة الفرنسية + شيقمري) + تلفزيون (أورشاد) + صحف.
- **التعليم:** عربية + فرنسية (إرث استعماري) + شيقمري (لغة وطنية).

---

## 9. ربط الجغرافيا بالثقافة
- **الموقع المعبري** (مدغشقر + إفريقيا + الجزيرة العربية + الهند + فارس) → تأثيرات: سواحلية (الأفريقية) + عربية (الإسلام) + فارسية (الشيرازي) + ماليزية/إندونيسية (الهجرات) + فرنسية (الإستعمار) + هندية (الكاري + البهارات). 🟢
- **المحيط الهندي + حيد مرجانية + شواطئ** → ثقافة بحرية + صيد + تجارة + السلطنات الساحلية (القرن 11–19) + التجار العرب + الفرس (شيرازي). 🟢
- **الإسلام + التجار العرب/الفرس** (القرن 7 هـ/13 م) → الإسلام ~98% + العربية لغة الدين + الأنساب العربية/الفارسية (شيرازي — روايات) + المفردات الدينية + الشافعية + الصوفية (قادرية) + الحلال + الختان + الموالد + الزيارات.
- **الإستعمار الفرنسي** (1841–1975) → الفرنسية (لغة رسمية) + العمارة الفرنسية + اللباس الفرنسي + القهوة + الإرث الفرنسي + المرفأ.
- **الجزر المنفصلة مسافات** → كل جزيرة لها ثقافة خاصة + لهجة + قبائل + تتباين + تفاهم.
- **المناخ الاستوائي + الرطوبة** → الموز + النخيل + الفانيليا + القرنفل + إيلانغ إيلانغ + الغابات المطيرة — تكيف زراعي + ثقافة العطور.
- **التركيبة العرقية المركّبة** (عرب/فرس/شيرازي + أفارقة/بانتو + ماليزيون/إندونيسيون + هنود) → «السواحلي-العربي-الفارسي-الماليزي» (القمريون) + الإسلام كمكوِّن موحِّد + الشيقمري (لهجة سواحلية + تأثيرات). 🟢
