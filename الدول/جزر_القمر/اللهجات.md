# اللهجات في اتحاد جزر القمر

> جزر القمر بلد متعدد اللغات: 3 رسمية (شيقمري + عربية + فرنسية) + لهجات جزيرية. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. نظرة عامة
- اللغات الرسمية: **الشيقمري (قمرية — Shikomori) + العربية + الفرنسية** (ثلاثها رسمية دستوريًّا). 🟢
- **الشيقمري (قمرية):** لهجة سواحلية (Bantu + عربية + فارسية) — لغة وطنية + الأكثر انتشارًا.
- **اللغات المحلية:** الماهوري (مايوت) + لهجات جزيرية + ماكوا (تنزانية).
- **الدين:** الإسلام ~98% → العربية لغة الدين + القرآن + الثقافة.
- جزر القمر بلد متعدد اللغات (3 رسمية + لهجات + تأثيرات).

## 2. اللغة الشيقمري (قمرية) — الوطنية 🟢

### الأصل
- **الشيقمري (Shikomori / قمرية):** لهجة سواحلية (Bantu) + تأثيرات عربية + فارسية + ماليزية/إندونيسية.
- يتحدث بها غالبية السكان (الأكثر انتشارًا) — لغة وطنية.
- **التأثيرات:**
  - **عربية (الإسلام):** مفردات دينية + ثقافية + قرآنية (صلاة + قرآن + رمضان + زكاة + حج + محراب + شيخ + سطنة).
  - **فارسية (الشيرازي):** مفردات (سلطان + بازار + ديوان + مرزبة + فتنة).
  - **سواحلية (البانتو):** مفردات + بنية (أصل بانتو + تأثير عربي/فارسي).
  - **ماليزية/إندونيسية:** مفردات + هجرات (نخيل + بهارات).

### اللهجات الجزيرية 🟡
- **نجازيجيا (القمر الكبرى):** لهجة القمر الكبرى.
- **نزواني (أنجوان):** لهجة أنجوان.
- **موالي (موهيلي):** لهجة موهيلي.
- **ماهوري (مايوت):** لهجة مايوت (لغة محلية + تأثير ماليزي/إندونيسي + أقدم اللغات).
- **ماكوا (تنزانية):** لهجة ماكوا (ساحل تنزانيا).
- تتباين بين اللهجات (كل جزيرة لها لهجة) + تفاهم متبادل.

---

## 3. اللغة العربية — الرسمية + الدينية 🟢
- **اللغة الرسمية الثانية** (مع الشيقمري + الفرنسية).
- **لغة الدين** (الإسلام ~98%) + القرآن + الثقافة + الأنساب (عرب/شيرازي).
- **اللهجة القمرية العربية:** لهجة عربية مع تأثير شيقمري + فرنسي (مفردات + نطق).
- **الأنساب القمرية:** إلى عرب/فارس (شيرازي — روايات شفهية).

---

## 4. اللغة الفرنسية — الرسمية + الإرث 🟢
- **اللغة الرسمية الثالثة** (مع الشيقمري + العربية).
- **لغة الإدارة + التعليم + القانون + الأعمال** (إرث استعماري 1841–1975).
- يتحدث بها النخبة + المدن + الإدارة + القانون.
- تأثير على الشيقمري (مفردات فرنسية + نطق).

---

## 5. التأثيرات اللغوية الخارجية 🟢

### العربية (الإسلام + التجار)
- مفردات دينية + ثقافية: «صلاة» + «قرآن» + «رمضان» + «زكاة» + «حج» + «محراب» + «شيخ» + «سطنة» + «سلطان» + «أمير» + «ديوان» + «مرزبة» + «فتنة».
- **الأنساب:** عرب/فارس (شيرازي) — روايات شفهية + الإسلام (القرن 7 هـ/13 م).

### الفارسية (الشيرازي + التجارة)
- مفردات: «سلطان» + «بازار» + «ديوان» + «مرزبة» + «فتنة».
- **الأنساب:** شيرازي (عرب/فارس من شيراز — فارس) — روايات شفهية + هجرات.

### السواحلية (البانتو + التجارة الإفريقية)
- مفردات + بنية (أصل بانتو) + تأثير على الشيقمري (القمرية = لهجة سواحلية + تأثيرات).

### الماليزية/الإندونيسية (الهجرات + التجارة)
- مفردات: «بهارات» + «كمون» + «كزبرة» + «هيل» + «قرفة» + «كركم» + «فلفل» + «نخيل».
- **الهجرات:** ماليزيون/إندونيسيون + تجارة المحيط الهندي.

### الفرنسية (الإستعمار)
- مفردات إدارية + تقنية + قانونية + تعليمية (إرث استعماري).
- «موزير» (Monsieur) + «مدموزيل» (Mademoiselle) + «بونابوي» (Bonaparte) + «كومسيار» (Commisariat) + «أدميرال» (Amiral).

## 7. أمثال وتعبيرات 🟡
- «Marahaba tsana» = مرحبًا كثيرًا (أدب).
- «Habari njema?» = ما الأخبار الجميلة? (استفهام).

---

## 8. الكتابة 🟢
- **الشيقمري:** تُكتب باللاتينية (مع تأثير عربي/سواحلي) + العربية (أحيانًا).
- **العربية + الفرنسية:** الكتابة الرسمية.

## 9. الموسيقى + الفنون 🟢
- **الرقصات:** القمري (traditionnel) + التوسي (أنجوان) + الشيعنجا (القمر الكبرى) + الرسمية (موهيلي).
- **الموسيقى:** تقليدي + تأثيرات عربية (العود + القنبوس) + سواحلية + إفريقية + فرنسية + هندية.
- **الشعر:** شيقمري (غنائي) + عربي + فرنسي.
- مطربون: نابحيا + أحراد (فرقة موسيقية قمرية).

---

## 10. ربط اللهجة بالثقافة والجغرافيا
- **الموقع المعبري** (مدغشقر + إفريقيا + الجزيرة العربية + الهند + جنوب شرق آسيا) → تأثيرات: سواحلية (البانتو) + عربية (الإسلام) + فارسية (الشيرازي) + ماليزية/إندونيسية (الهجرات) + فرنسية (الإستعمار) + هندية (البهارات). 🟢
- **الأرخبيل البركاني + حيد مرجانية** → جزر بركانية + صيد + شواطئ + غوص + التجار العرب + الفرس (شيرازي).
- **الإسلام + التجار العرب/الفرس** (القرن 7 هـ/13 م) → الإسلام ~98% + العربية لغة الدين + الأنساب العربية/الفارسية (شيرازي — روايات) + المفردات الدينية + الشافعية.
- **الإستعمار الفرنسي** (1841–1975) → الفرنسية لغة رسمية + إدارة + تعليم + قانون + إرث فرنسي (العمارة + القهوة + اللباس).
- **الجزر المنفصلة مسافات** (نجازيجيا ~200 كم من مايوت + ~40 كم من موهيلي + ~50 كم من أنجوان) → لهجات جزيرية + قوارب + حياة جزيرية + لا قارات + جزر صغيرة.
- **المناخ الاستوائي + الرطوبة** → الموز + النخيل + الفانيليا + القرنفل + إيلانغ إيلانغ + الغابات المطيرة — تكيف زراعي + ثقافة العطور.
