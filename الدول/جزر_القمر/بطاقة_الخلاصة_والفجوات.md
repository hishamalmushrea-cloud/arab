> ⚠ **تنبيه:** جزر القمر بلد صغير (مساحةً + سكانًا) + فقير (~60%) + تأريخ مضطرب (20+ انقلابًا) + مايوت المتنازَع عليها مع فرنسا — الوضع متغير والقضايا حساسة. علامة 🟠.

## أهم ما يميز جزر القمر

- **أرخبيل بركاني** في المحيط الهندي (4 جزر + براكين نشطة).
- **جبل كارتالا** (نحو 2,361 م — بركان نشط في نجازيجيا، ليس أكبر براكين العالم).
- **موقع استراتيجي** في قناة موزمبيق + على طريق التجارة (شرق أفريقيا + الجزيرة العربية + الهند).
- **مايوت المتنازَع عليها:** فرنسا تديرها + جزر القمر تطالب بها + الأمم المتحدة تعترف بسيادة جزر القمر — قضايا حساسة.
- **أكثر من 20 انقلابًا** (1975–1999) — تدخلات المرتزق الفرنسي «بوب دينار» + دستور 2001 (تناوب الرئاسة).
- **صغيرة المساحة** (~1,861 كم²) وليست أصغر عربية (البحرين أصغر).
- **الإسلام دين الدولة** (~98%) + الشيقمري (لهجة سواحلية) + العربية + الفرنسية (رسمية).
- **السلطنات الشيرازية** (القرن 11–19) — عرب + فرس (شيرازي) + تجارة + الإسلام.
- **الإستعمار الفرنسي** (1841–1975) + الإستقلال 6 يوليو 1975 (إلا مايوت).
- **اقتصاد زراعي** — الفانيليا (أكبر منتج) + القرنفل + إيلانغ إيلانغ + الزراعة + الصيد + التحويلات (المغتربين ~25% من الناتج) + الفقر (~60%).
- **تركيبة عرقية مركّبة:** قمريون (عرب/فرس/شيرازي + أفارقة/بانتو + ماليزيون/إندونيسيون + هنود).

## أهم المناطق

- **موروني:** العاصمة + أكبر مدينة + المطار الدولي + المرفأ + مقر حكومة الاتحاد.
- **موتسامودو:** عاصمة أنجوان + مرفأ صناعي.
- **فومبوني:** عاصمة موهيلي.
- **ماموتزو (دزاودزي):** عاصمة مايوت (فرنسا).
- **ميتساميولي:** ثانية مدن أنجوان + تاريخية.

## أهم المدن (تُفصَّل في المرحلة الخامسة)

موروني · موتسامودو · فومبوني · ماموتزو · ميتساميولي · دوموني · هاهايا · بامباو · إتساندرا · هنبو · تشيلي · همفو.

## أهم الأطعمة

الأرز (أساس) + المانيوك (الكاسافا) + الموز + جوز الهند + الأسماك + الكاري + اللوكي (لحم) + بيلا (أرز) + سومبوكو (لحم مقدد) + الخبز اللحوح. الحلويات: لوكي/لوغو + كنيكو + دونات. المشروبات: الشاي القمري + القهوة + عصير الفواكه (مانجو + أناناس).

## أهم الملابس

رجالي: **الكوفية** (قبعة مطرَّزة — الزي القومي) + الثوب/الخميص (أبيض) + السروال + السيف. نسائي: **الشيرماني/الديوهو** (فستان ملوَّن مطرَّز) + البوبو (إرث سواحلي) + الشال/الحجاب + الحناء + الذهب.

## أهم اللهجات

**الشيقمري** (قمرية — لهجة سواحلية + تأثيرات عربية/فارسية/ماليزية — الوطنية) + **الماهوري** (مايوت — لغة محلية) + **العربية** (رسمية + لغة الدين) + **الفرنسية** (رسمية + إرث استعمار) + لهجات جزيرية (نجازيجيا + نزواني + موالي) + ماكوا (تنزانية) + تأثيرات (هندية/إثيوبية).

## أهم الكلمات المحلية

«Lalo» (لا) · «Ndiyo» (نعم) · «Marahaba» (مرحبًا/سلام) · «Habari?» (ما الأخبار؟) · «Shari?» (ماذا؟) · «Wapi?» (أين؟) · «Bwana» (سيدي/رجل) · «Nyumba» (بيت) · «Maji» (ماء) · «Siku» (يوم) · «Jua» (شمس) · «Samaki» (سمك).

## أهم العادات

**الأعراس** («الدوهو» زفاف + «سمبوا» رقصات + مهر + حناء + وليمة) + **رمضان** (أرز + كاري + سمبوسة + شاي) + **العيد** (مشوي + أرز + حلويات) + **الموالد/الزيارة** (صوفية — قادرية) + **الختان** + الكرم/الضيافة.

## أهم المواقع التاريخية

**مسجد فينديري** (على القمر الكبرى — رمز معماريا + تاريخي) + **مسجد الجمعة القديم** (موروني) + **موروني** (العاصمة — عمارة فرنسية + مرفأ + 1888) + **موتسامودو** (أنجوان — مرفأ + سلطنة) + آثار السلطنات الشيرازية.

## أهم المواقع الطبيعية

**جبل كارتالا** (2,361م — بركان نشط + أكبر البراكين) + **بحيرات** (دزياني بوندوني + سالا) + شواطئ (رملية + صخرية) + **حيد مرجانية** + **غابات موهيلي المطيرة** + **محمية موهيلي البحرية** (شعاب + سلاحف).

## أهم المنتجات

**الفانيليا** (أكبر منتج قمري + ثالث عالميًّا) + **القرنفل** (من أكبر المنتجين عالميًّا) + **إيلانغ إيلانغ** (للعطور) + جوز الهند + الموز + الكسافا + الأسماك + العطور + التحويلات (~25% من الناتج).

## أهم الشخصيات

**أحمد عبد الله** (المؤسس — 1975–1978 + 1978–1989 — اغتيل) + سعيد محمد جوهر (1990–1995) + محمد تقي عبد الكريم (1996–1998 — وفاة) + **عزالي أسومان** (الحالي — 2002–الآن) + تاج الدين بن سعيد ماسوندي (1998–1999 — أُطيح) + غزالي عثماني (1999–2002) + الشيخ عبد القادر الجيلاني.

## أهم الأحداث التاريخية

سلطنات الشيرازي (القرن 11–19) → الإستعمار الفرنسي (1841–1975) → **الإستقلال (6 يوليو 1975 — إلا مايوت)** → **20+ انقلابًا** (1975–1999 — «بوب دينار») → **أنجوان + موهيلي يُعلنان استقلالهما** (1997 — أنهت 2001) → **دستور 2001** (تناوب الرئاسة + فيدرالية) → **عزالي أسومان** (2016 — ديمقراطية) → **مايوت تصبح مقاطعة فرنسية** (2009).

## ما يجب أن يعرفه من يريد فهم جزر القمر

1. **أرخبيل بركاني** في المحيط الهندي (4 جزر + براكين نشطة) + **جبل كارتالا** (2,361م — أكبر البراكين + ثوران >20 مرة).
2. **مساحة صغيرة** (~1,861 كم² للجزر الثلاث) **ليست** أصغر عربية.
3. **موقع استراتيجي** في قناة موزمبيق + على طريق التجارة (شرق أفريقيا + الجزيرة العربية + الهند).
4. **مايوت المتنازَع عليها:** فرنسا تديرها + جزر القمر تطالب بها + الأمم المتحدة تعترف بسيادة جزر القمر — قضايا حساسة.
5. **تركيبة عرقية مركّبة:** قمريون (عرب/فرس/شيرازي + أفارقة/بانتو + ماليزيون/إندونيسيون + هنود) + الإسلام ~98%.
6. **السلطنات الشيرازية** (القرن 11–19) — عرب + فرس (شيرازي) + تجارة + الإسلام.
7. **الإستعمار الفرنسي** (1841–1975) + الإستقلال 6 يوليو 1975 (إلا مايوت).
8. **20+ انقلابًا** (1975–1999) — تدخلات المرتزق الفرنسي «بوب دينار» + دستور 2001 (تناوب الرئاسة).
9. **اقتصاد زراعي** — الفانيليا (أكبر منتج) + القرنفل + إيلانغ إيلانغ + الزراعة + الصيد + التحويلات (~25% من الناتج) + الفقر (~60%).
10. **3 لغات رسمية:** الشيقمري (قمرية — لهجة سواحلية) + العربية + الفرنسية + لغات جزيرية.
