# الشخصيات والآثار في اتحاد جزر القمر

> رؤساء + زعامات + أعلام + جبل كارتالا + مسجد فينديري. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر.

---

## 1. رؤساء جزر القمر المعاصرين 🟢🟠

### أحمد عبد الله عبدريمان (1919–1989) 🟢🟠
- **الرئيس المؤسس** (1975–1978 + 1978–1989) — زعيم حركة الإستقلال.
- **1975 (6 يوليو):** أول رئيس بعد الإستقلال (إلا مايوت).
- **1978:** أُطيح به بمساعدة المرتزق الفرنسي «بوب دينار» + أُعيد + **1989:** اغتيل بمساعدة دينار.

### سعيد محمد جوهر (1932–2006) 🟢🟠
- رئيس الجمعية الوطنية (1990–1995) — ثاني رئيس.
- **1995:** دينار يحاول انقلاب + يحتجز رهينة + تدخل فرنسي.

### محمد تقي عبد الكريم (1936–1998) 🟢
- **رئيس** (1996–1998) — دستور يُوسع سلطة الرئيس.
- **1997:** أنجوان + موهيلي يُعلنان استقلالهما (محاولة — أنهت 2001).
- **1998 (نوفمبر):** وفاة (نوبة قلبية).

### تاج الدين بن سعيد ماسوندي (1950–) 🟠
- قائم أعمال الرئيس تقي (1998–1999).
- **1999 (30 أبريل):** أُطيح (الانقلاب الـ20+ — العقيد غزالي عثماني).

### غزالي عثماني (1962–) 🟠
- **رئيس** (1999–2002) — انتقالي.
- فشل في تعزيز سلطته + فرض السيطرة على الجزر.

### عزالي أسومان (1959–) 🟢
- **الحالي** (2002–2006 + 2006–2011 + 2011–2016 + 2016–الآن) — أُعيد 4 مرات (الإنتخابات 2006 + 2011 + 2016 + 2024).
- **2010:** تعديل دستوري (تناوب الرئاسة كل 10 سنوات).
- **2018:** عزالي يفوز (ديمقراطية — أُعيد).

## 2. أعلام دينيون + زعامات 🟢

### شيوخ الطرق الصوفية 🟢
- **الشيخ عبد القادر الجيلاني:** مؤسس الطريقة القادرية (إرث إسلامي — الأكثر انتشارًا).
- **الشاذلية + الرفاعية + الأحمدية.**

### سلاطين الشيرازي التاريخيون 🟡
- **محمد بن حسن بن محمد بن عيسى:** زعيم القمر الكبرى (إرث شيرازي — رواية).
- **أمراء أنجوان + موهيلي + مايوت** (إرث سياسي/تجاري).
- السلطنات (القرن 11–19) — قبل الإستعمار الفرنسي.

---

## 3. أعلام ثقافيون 🟢
- **نابحيا (Nabahya):** مطربة + مغنية + فرقة موسيقية قمرية.
- **أحراد (Ahrad):** فرقة موسيقية قمرية.
- **شعراء:** شيقمري (غنائي) + عربي + فرنسي + سواحلي.

---

## 4. مواقع التراث العالمي (يونسكو) — مسجد فينديري 🟢

### مسجد فينديري (Vendredi) 🟢
- على القمر الكبرى (نجازيجيا) — قرب موروني + مرفأ — **رمز معماريا + تاريخي**.
- «السوق القديم» — موروني — العمارة القمرية الأصيلة (الشيرازية + العربية).
- «الحي القمري» — موروني — البيوت التقليدية (الدوهو).
- المسجد = أثر + معلم سياحي (يُرى منه مدينة موروني بأكملها).

### موروني (العاصمة) 🟢
- **العاصمة + أكبر مدينة** + المطار الدولي + المرفأ + مقر حكومة الاتحاد.
- **التاريخ:** تأسست كقرية + المرفأ + مقر الإدارة الفرنسية.
- **المعالم:** مسجد فينديري + المرفأ + المطار + السوق القديم + العمارة الفرنسية + حي القمري.

---

## 5. المواقع الأثرية الأخرى 🟢

### السلطنات الشيرازية
- **آثار سلطنة القمر الكبرى:** موروني (القرن 11–19) — إرث شيرازي/عربي.
- **سلطنة أنجوان:** موتسامودو + مرفأ + آثار.
- **سلطنة موهيلي:** فومبوني + آثار.
- **سلطنة مايوت:** ماموتزو + أقدم الجزر.

### المساجد التاريخية 🟢
- **مسجد فينديري** (القمر الكبرى) — أثر + رمز معماريا.
- **مسجد الجمعة القديم (Badjanani):** في موروني.
- الطراز: **إسلامي + شيرازي + عربي** (أحيانًا) + تصميم محلي.

## 6. المعالم الطبيعية 🟢

### جبل كارتالا (Mount Karthala) 🟢
- **أعلى نقطة في جزر القمر** (2,361م) — على القمر الكبرى + بركان نشط.
- فوهة واسعة تُذكر نحو 3×4 كم — **ليس** أكبر براكين العالم.
- **غابات مطيرة** على المنحدرات (آخر غابات جزر القمر) + طبيعة خلابة.
- **خطر:** ثوران + رماد بركاني + إخلاء (2005 آخر ثوران كبير).

### بحيرات 🟡
- **بحيرة دزياني بوندوني** (موهيلي) — بحيرة فوهة بركانية + محمية.
- **بحيرة سالا** (أنجوان) — محمية.

### شواطئ + حيد مرجانية + غابات 🟢
- **شواطئ رملية + صخرية** (بكرة + نيوماتشوا + سامبيا).
- **حيد مرجانية** تحيط بالجزر (خاصة مايوت) + غوص.
- **غابات مطيرة** (موهيلي) + مانغروف (ساحل).

### محمية موهيلي البحرية 🟢
- **شعاب مرجانية + سلاحف + دلافين + حيتان** — محمية.
- «نيوماتشوا» + «سامبيا» + «تتنوع مظاهر السياحة في موهيلي» — شواطئ خلابة.

---

## 7. المعالم الحديثة 🟢🟠
- **المطار الدولي (الأمير سعيد ابراهيم — هاهايا):** على القمر الكبرى + أكبر مطار.
- **المرفأ** (موروني + موتسامودو + ماموتزو — فرنسا تدير ماموتزو).
- **القصور الرئاسية + السفارات** — موروني.
- 🟠 **البنية التحتية ضعيفة** + لا قارات بين الجزر + الفقر + السياحة محدودة.

## 8. ربط الآثار بالتاريخ والجغرافيا
- **الموقع المعبري** (مدغشقر + إفريقيا + الجزيرة العربية + الهند + فارس) → التجار العرب + الفرس (الشيرازي) + الإسلام + السلطنات (القرن 11–19) + الأنساب (روايات). 🟢
- **المحيط الهندي + حيد مرجانية + شواطئ** → ثقافة بحرية + صيد + تجارة + السلطنات الساحلية + زنوج من زنجبار + مدغشقر. 🟢
- **الإسلام + التجار العرب/الفرس** (القرن 7 هـ/13 م) → الإسلام ~98% + العربية لغة الدين + الأنساب العربية/الفارسية (شيرازي — روايات) + المفردات الدينية + الشافعية + الصوفية (قادرية) + المساجد (فينديري + الجمعة).
- **الإستعمار الفرنسي** (1841–1975) → العمارة الفرنسية (موروني) + المرفأ + المطار + اللباس الفرنسي + القهوة + المسيحية ~2% (أوروبيون) + الإرث الفرنسي.
- **البراكين + جبل كارتالا** → جزر بركانية + بركان نشط + أكبر البراكين + ثوران + غابات مطيرة + طبيعة خلابة + جيولوجيا فعالة.
- **الانقلابات + «بوب دينار»** (1975–1999) → تأريخ مضطرب + تدخلات المرتزق الفرنسي + الإطاحة بالرؤساء + ضعف مؤسسي + دستور 2001 (تناوب الرئاسة = حل توافقي). 🟠
- **مايوت:** فرنسا تديرها + جزر القمر تطالب بها + الأمم المتحدة تعترف بسيادة جزر القمر + الإستفتاءات المتتالية → قضايا حساسة (إرث استعماري + مايوت أغنى). 🟠
