# جزر اتحاد جزر القمر — المرحلة الرابعة (الوحدات الإدارية العُليا)

> **المرجع الإداري النافذ:** المستوى الأعلى = **جزيرة ذاتية الحكم** (île autonome). العدد **3** تديرها حكومة الاتحاد. ليست محافظة ولا إقليم جيبوتي. 🟢
>
> **ISO 3166-2:KM:** **KM-G** نجازيجيا · **KM-A** أنجوان · **KM-M** موهيلي. مايوت رمزها **YT** (فرنسا) وليست وحدة ISO لاتحاد جزر القمر. 🟢
>
> **المستوى الثاني:** **محافظة / préfecture** — الجرد الشائع **16** (8+5+3). بعض الخرائط **17**. ثم **بلدية** نحو **54–55** وقرى نحو **318** 🟡.
>
> **موروني المدينة** في `العواصم/موروني/` — هنا **جزيرة نجازيجيا** وعاصمة الاتحاد معًا.
>
> **السكان:** تعداد INSEED **RGPH 15 ديسمبر 2017** = **758,316** للجزر الثلاث 🟢. لا يُخترع توزيع 2024 جزري. تقديرات 2024 الوطنية ~850–950 ألف 🟡.
>
> **المساحة النافذة للاتحاد:** نحو **1,861 كم²** (1,147+424+290) 🟢 في citypopulation/الجداول الشائعة. الرقم **2,235** يضم مايوت فلا يُقدَّم كمساحة الدولة المُدارة. 🟢
>
> جزر القمر **ليست** أصغر دولة عربية مساحةً (البحرين أصغر). قد تكون الأصغر **سكانًا** بين أعضاء الجامعة — 🟡 لأن التقديرات تتقاطع مع جيبوتي قبل تعداد جيبوتي 2024.
>
> **مايوت / ماهوري:** مطالَب بها من الاتحاد؛ تحت إدارة فرنسا كإقليم/إدارة ما وراء البحار منذ **31 مارس 2011**. تُعرض في ملف مستقل بحياد. 🟠
