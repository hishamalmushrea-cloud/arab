# المصادر والمراجع — مملكة البحرين

> مرتبة حسب المستوى. تاريخ آخر مراجعة: 2026-08-11.

## المستوى الأول — رسمي
- **البوابة الوطنية البحرينية الرسمية (bahrain.bh):** المساحة (يابسة 786.8 كم² + مياه 7,482.2 كم²) + الإحداثيات + السكان (1,588,670 — 2024 — بحرينيون 46.6% + وافدون 53.4%) + الكثافة + GDP + الإنتاج النفطي + المؤسسات المصرفية (368) + الزوّار (14.9 مليون) + محو الأمية (97.86%). 🟢
- **وزارة الخارجية البحرينية (mofa.gov.bh):** الخط الزمني التاريخي + حكام البحرين + الاستقلال + تحوّل المملكة 2002. 🟢
- **وزارة الإعلام (mia.gov.bh):** الواقع التجاري والاقتصادي + التقسيم الإداري + الديانات. 🟢
- **هيئة البحرين للثقافة والآثار (bahrainculture.org):** المواقع الأثرية + مسار اللؤلؤ + مهرجان التراث. 🟢
- **هيئة البحرين للسياحة والمعارض (BTEA/btea.bh):** السياحة + الموسم السياحي. 🟢
- **وزارة المالية والاقتصاد الوطني (mofne.gov.bh):** التقرير الاقتصادي 2024 + نمو الناتج 2.6%. 🟢
- **مركز البحرين لتنمية الاستثمار (bahrainedb.com):** تقارير التنافسية + النمو. 🟢
- **البنك المركزي البحرين (CBB):** النقد + المؤسسات المصرفية. 🟢
- **مرسوم بقانون رقم 17 لسنة 2002 بشأن نظام المحافظات** + تعديلاته (إلغاء الوسطى 2014): التقسيم الإداري. 🟢

## المستوى الثاني — أكاديمي/مراجع
- **ويكيبيديا العربية:** البحرين، تاريخ البحرين، محافظات البحرين، قائمة مدن البحرين، ديموغرافيا البحرين، آل خليفة، عجم البحرين، بحارنة، ثقافة بحرينية، قلعة البحرين، مدافن دلمون، مسار اللؤلؤ، السياحة في البحرين، اقتصاد البحرين، المعلومات العامة + حكام آل خليفة (13) — مع مراجعها الأصلية. 🟢
- **ويكيبيديا الإنجليزية:** History of Bahrain، Economy of Bahrain، Bahrain Island، Dilmun، Muharraq Island — مع مراجعها. 🟢
- **المعرفة (marefa.org):** محافظات البحرين، تاريخ البحرين، آل خليفة، عيسى بن علي آل خليفة، دلمون. 🟢
- **Wikiwand/أرابيكا:** محافظات البحرين + قائمة مدن البحرين + السكان بالمحافظات (2020). 🟢

## المستوى الثالث — دولي
- **اليونسكو:** قلعة البحرين (2005) + مسار اللؤلؤ (2012) + مدافن دلمون (2019) — مواقع التراث العالمي. 🟢
- **البنك الدولي:** الناتج المحلي + السكان + تصنيف (دخل مرتفع) + HDI. 🟢
- **FocusEconomics:** توقعات الاقتصاد البحريني (GDP 2020–2025 + التضخم + الدين). 🟢
- **Worldometers/التقديرات الدولية:** السكان (2024 — 1.59 مليون). 🟢
- **محكمة العدل الدولية (لاهاي):** حكم جزر حوار (2001) — السيادة البحرينية. 🟢
- **الأمم المتحدة:** استفتاء البحرين (1970 — بعثة فيتسيس مينتاشي). 🟢

- **الجزيرة نت:** المنامة عاصمة البحرين + عاشوراء في البحرين + رمضان في البحرين (النقصة والمجالس) + مقاومة النفوذ البريطاني. 🟢

- **الخليج (alkhaleej.ae):** المطبخ البحريني + ملامح حضارة البحرين. 🟢
- **BBC Arabic:** ماي بنت محمد آل خليفة (إقالة 2022) + البحرين تاريخ التوتر الطائفي. 🟢
- **البلاد برس (albiladpress.com):** اللهجات الشعبية في البحرين وجذورها. 🟢
- **الرأي (مرايا البحرين/ Bahrainmirror):** عاشوراء البحرين. 🟢
- **شبكة النبأ (annabaa.org):** عاشوراء في البحرين. 🟡
- **موقع قافلة (qafilah.com):** قلاع البحرين وحصونها + تاريخ التنقيب الدلموني. 🟢
- **ثقافة البحرين الشعبية (folkculturebh.org):** الفجري/الفنون الغنائية + ملابس الرجال. 🟢
- **الوسط (alwasatnews.com):** الأزياء التراثية البحرينية. 🟢
- **2thar.com/mawdoo3.com:** آثار البحرين + مواقع اليونسكو. 🟢
- **شبكة التراث (malturath.wordpress.com):** كبير العجم في البحرين + العوائل الأحسائية + تاريخ العرق الفارسي. 🟡

- **hukam.net:** آل خليفة في البحرين (1783). 🟢
- **المركز الإعلامي (bhreport.info):** الملك + المراسيم. 🟢
- **المنتديات التراثية (thajr/mogameh/elbadi/tarout/حواوور العالم):** قواميس اللهجة البحرينية + الأزياء الشعبية. 🟡 (مصادر شعبية غير رسمية — تُستخدم للمفردات فقط).

## ملاحظة منهجية
- الأرقام الإدارية/السكانية/الاقتصادية مُوثَّقة من المصادر الرسمية (bahrain.bh) أو الأكاديمية (ويكيبيديا + مراجعها).
- المفردات اللهجية والعادات مُجمَّعة من مصادر تراثية محلية (مستوى خامس) — تُورَد كمادة تراثية لا كحقائق إحصائية.
- القضايا السياسية الحساسة (التركيبة الطائفية، احتجاجات 2011، اتفاقيات أبراهام 2020، النزاع الإيراني) مُوثَّقة من مصادر متعددة (ويكيبيديا/الجزيرة/BBC) وتُورَد **بحياد تام** كوقائع دبلوماسية/اجتماعية دون تبني موقف.
- النسبة الطائفية (سُنة/شيعة) تقديرات متفاوتة (لا إحصاء رسمي طائفي) → 🟡.
