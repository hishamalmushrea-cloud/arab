## ملاحظة منهجية — لا تخلط بعد 2014 ولا مع قطر

| المكان | المحافظة الصحيحة | ليس |
|---|---|---|
| سترة | **العاصمة** | الوسطى الملغاة |
| مدينة عيسى | **الجنوبية** | الشمالية / الوسطى |
| مدينة حمد | **الشمالية** | الجنوبية |
| الرفاع | **الجنوبية** | الوسطى |
| مسار اللؤلؤ / المطار / أمواج | **المحرق** | العاصمة |
| قلعة البحرين / باربار / مسجد الخميس | **الشمالية** | المنامة المدينة |
| مدافن دلمون (عالي) | **الشمالية** في مراجع شائعة 🟡 | الجنوبية في بعض الخرائط |
| جزر حوار / الصخير / شجرة الحياة / جبل الدخان | **الجنوبية** | قطر / دخان قطر |
| جسر الملك فهد (طرف البحرين) | **الشمالية** (جسرة/أم النعسان) | العاصمة |

- المسمى: **محافظة → مدينة/قرية/فريج**. ليست ولاية عُمانية.
- لا تُعاد الوسطى كوحدة قائمة.
