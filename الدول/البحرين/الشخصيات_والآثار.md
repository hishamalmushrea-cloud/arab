# الشخصيات والآثار في مملكة البحرين

> حكام آل خليفة + أعلام ثقافيون ودينيون + 3 مواقع تراث عالمي (يونسكو) + متاحف وقلاع. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. حكام آل خليفة (1783–الآن) 🟢
- **أحمد الفاتح (1782–1795):** فاتح البحرين (1783) — مؤسس حكم آل خليفة.
- **سلمان بن أحمد (1795–1821):** نقل القاعدة إلى المحرق.
- **عيسى بن علي (1869–1932):** أطول فترة حكم؛ عهد المعاهدات البريطانية (1892) + المقاومة الوطنية + بداية النفط.
- **حمد بن عيسى (1932–1942):** عهد اكتشاف النفط (1932) + افتتاح المطار.
- **سلمان بن حمد (1942–1961):** بناء الدولة الحديثة (تعليم/صحة).
- **عيسى بن سلمان (1961–1999):** **الاستقلال (1971)** + بناء مؤسسات الدولة + مدينتا عيسى وحمد + «أمير القلوب».
- **حمد بن عيسى (1999–الآن):** أمير (1999) → **ملك (2002)** + ميثاق العمل الوطني (2001) + المملكة + إصلاحات.
- **خليفة بن سلمان آل خليفة:** رئيس الوزراء 1971–2020 (أطول رؤساء وزراء العالم خدمةً).
- **سلمان بن حمد آل خليفة:** ولي العهد + القائد العام لقوة دفاع البحرين + رئيس الوزراء (من 2020).

## 2. أعلام ثقافيون ودينيون 🟢
- **ميثم البحراني:** فيلسوف/متكلم/مفسر شيعي (القرن 7 هـ/13 م) — «خطيب الشيعة».
- **السيد هاشم التوبلاني:** صاحب تفسير «البرهان في تفسير القرآن» (شيعي).
- **الشيخ يوسف البحراني:** فقيه شيعي (القرن 12 هـ/18 م) — «الحدائق الناضرة».
- **الشيخ حسين العصفور:** فقيه شيعي («العلامة»).
- **الشيخ حسن الدمستاني:** شاعر شعبي.
- **الملا عطية الجمري:** خطيب عاشوراء (اشتهر خليجيًّا) — رائد المدرسة البحرانية في الإحياء الحسيني.
- **الشيخة مي بنت محمد آل خليفة:** باحثة تاريخية + وزيرة إعلام/ثقافة (2008–2010) + رئيسة هيئة البحرين للثقافة والآثار (2015–2022) + مؤسِّسة مركز الشيخ إبراهيم للثقافة + المركز الإقليمي للتراث العالمي — من أبرز الشخصيات النسائية الثقافية + مصنّفة (فوربس) ضمن أكثر 50 امرأة تأثيرًا عربيًّا (2005). مؤلفات: «القرامطة من فكرة إلى دولة»، «سبزآباد ورجال الدولة البهية»، «محمد بن خليفة: الأسطورة والتاريخ الموازي». 🟢
- أعلام معاصرون: شعراء/كتّاب (إبراهيم بن محمد الخليفة «شيخ الأدباء»، علي الشرقاوي، قاسم عودي...) + فنانون + رياضيون.

## 3. مواقع التراث العالمي (يونسكو) — 3 مواقع 🟢

### قلعة البحرين (Qal'at al-Bahrain) — يونسكو 2005 🟢
- أول موقع بحريني في قائمة التراث العالمي (تموز/يوليو 2005).
- العاصمة الرسمية لحضارة دلمون + ميناؤها + مقر حكامها (الألف الثالث ق.م).
- تلّة اصطناعية بطبقات حضارية متعاقبة (دلمون → تايلوس → إسلامية → برتغالية) — «مدن مبنية فوق بعضها».
- **القلعة الإسلامية + القلعة البرتغالية (القرن 16):** ثلاثة حصون + أبراج.
- المساحة: 70.4 هكتار (موقع) + 1,311.8 هكتار (منطقة عازلة).
- الإحداثيات: 26°14′N 50°31′E.
- الحفريات منذ 1954 (بعثات دنماركية/فرنسية) — لم يُنقَّب إلا ~25%.

### مسار اللؤلؤ (طريق اللؤلؤ / Pearling Path) — يونسكو 2012 🟢
- في **محافظة المحرق** (العاصمة التاريخية للؤلؤ) — طول ~3.5 كم.
- = شهادة على ازدهار تجارة اللؤلؤ (القرن 19 – بداية 20) قبل انهيارها 1930ات.
- يضم: **3 أسرّة محار (oyster beds)** + **17 مبنى** (بيوت تجار + متاجر + مساجد + قلعة بو ماهر).
- مرتبط بتراث الغوص (الفجري/الطوّاش/النهّام).
- المحرق = «عاصمة اللؤلؤ».

### مدافن دلمون (مقابر عالي / Dilmun Burial Mounds) — يونسكو 2019 🟢
- **21 موقعًا أثريًّا** (necropolis) + **+11,700 تلّة دفن** (وقدرها الرحالة بـ80,000–170,000 أصلاً) — أكبر مقبرة للعالم القديم مساحةً.
- تعود إلى **2050–1750 ق.م** (دلمون المبكرة).
- قبور أسطوانية منخفضة بغرف حجرية + مدافن ملكية في عالي — تعكس تدرّجًا اجتماعيًا.
- واجهت محاولات هدم (نزاع حضري/أثري) → أُدرجت لحمايتها.

## 4. المواقع الأثرية الأخرى 🟢
- **معبد باربار:** 3 معابد (الألف الثالث ق.م) حول نبع ماء عذب — اكتُشف 1954.
- **عين أم السجور** (الدراز): نبع/مستوطنة قديمة.
- **معبد الدراز**.
- **مستوطنة سار (Saar):** آثار دلمونية + مقابر متشابكة.
- **مسجد الخميس:** من أقدم مساجد الإسلام (القرن 8/عمر بن عبد العزيز ~692 م) — مئذنتان توأمتان (الأثر الإسلامي الأبرز).
- **جامع سماهيج** (الدير).

## 5. القلاع 🟢
- **قلعة البحرين** (قلعة البرتغال) — المنامة/السيف.
- **قلعة عراد** — المحرق (القرن 15–16).
- **قلعة الرفاع** (قلعة الشيخ سلمان بن أحمد الفاتح) — الرفاع.
- **قلعة بو ماهر** — المحرق (بداية مسار اللؤلؤ).
- **قلعة أبو ماهر / قلعة الدمام** (تاريخيًّا).

## 6. العمارة التراثية والبيوت 🟢
- **بيت سيادي** (تاجر لؤلؤ) + **بيت الشيخ عيسى بن علي** (المحرق) + **بيت جمشير** + **بيت خلف بن مطر** — بيوت تجار في المحرق.
- **مدرسة الهداية الخليفية** (1893 — من أقدم المدارس النظامية).
- **سوق القيصرية** (المنامة).
- **برج الساعة** (الرفاع الغربي).

## 7. المتاحف 🟢
- **متحف البحرين الوطني** (المنامة — 1988): الآثار الدلمونية + التراث + الفنون.
- **متحف الغوص واللؤلؤ** (المحرق).
- **متحف موقع قلعة البحرين** (افتُتح 2008).
- **بيت القرآن** (مخطوطات).
- **متحف النفط** + متحف راشد العريفي.

## 8. المعالم الحديثة 🟢
- **مسجد الفاتح الكبير** (أكبر مسجد — قبة + مئذنة + متحف).
- **حلبة البحرين الدولية** (الصخير — الفورمولا 1 منذ 2004).
- **سيتي سنتر البحرين** + **مجمع السيف** + **الدانة** + **الواجهة البحرية**.
- **شجرة الحياة** (الصخير) — رمز سياحي.
- **برج البحرين المالي** + **أبراج البحرين التوأم** (المنطقة الدبلوماسية).
- **المنامة عاصمة الثقافة العربية 2012.**

## 9. المعالم الطبيعية 🟢
- **جزر حوار** — محمية طبيعية (يونسكو candidacy) + طيور + دوغونغ.
- **محمية العرين** — حيوانات صحراوية.
- **جبل الدخان** (134 م).
- **شواطئ:** عراد، البسيتين، الحد، حالة بو ماهر، الدير، كرباباد.

## 10. ربط الآثار بالتاريخ والجغرافيا
- **دلمون** (الألف الثالث ق.م) = جلّ الآثار البحرينية → قلعة البحرين + معبد باربار + مدافن عالي — البحرين «مستودع الخليج» التجاري. 🟢
- **الموقع الوسيط** (وادي الرافدين ↔ وادي السند) → أختام دلمونية + فخار أصيل + بضائع مستوردة (كارنيول/نحاس).
- **المحرق** (عاصمة اللؤلؤ) → مسار اللؤلؤ + بيوت التجار + الفجري — ذروة ما قبل النفط.
- **الوجود البرتغالي/الصفوي** → قلعة البرتغال + قلعة عراد.
- **الإسلام** → مسجد الخميس + جامع سماهيج + العصر الأموي.
- **النفط (1932)** → متحف النفط + عوالي + بابكو — تحوّل إلى دولة حديثة.
