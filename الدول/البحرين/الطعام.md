# المطبخ البحريني

> مطبخ بحريني متنوع متعدد الأصول (عربي خليجي + فارسي + هندي/باكستاني + عراقي) بحكم الموقع التجاري. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. نظرة عامة
- المطبخ البحريني = **مزيج شرقي خليجي** ببهارات تشبه المطبخ الهندي/الباكستاني (الزعفران، الهيل، القرفة، البهارات المشكّلة «بهار»/«كمون»/«كزبرة»/«لومي») مع أثر فارسي وعراقي. 🟢
- **الأرز** + **اللحم** (ضأن/دجاج) + **السمك/الربيان** = أركان الوجبة.
- **التمر** (من الواحات) + **اللؤلؤ/الغوص** (تاريخيًّا) → ثقافة بحرية وغذائية.
- التأثير الفارسي واضح في الأطباق الحلوة (المحمر بالدبس) والهندي في البهارات.

## 2. الأطباق الرئيسية 🟢

### المجبوس (المطبق/البرياني البحريني) — الطبق الوطني 🟢
- **أرز** متبّل (زعفران + هيل + قرفة + لومي) + **دجاج أو لحم أو سمك/ربيان** + طماطم/خضار.
- يُعدّ **الطبق الوطني** البحريني (وفي الخليج)؛ يُقدَّم مع «الطحينة» أو «الدفّة» (بصل محمّر + زبيب/لوز).
- يرتبط بالأعياد والمناسبات.

### المحمَّر — الطبق البحراني التقليدي 🟢
- **أرز محلّى بدبس التمر** (أو السكر) + سمن + **سمك** (غالبًا) أو لحم.
- طبق شعبي **بحراني** (شيعي) مرتبط بتراث النخيل والواحات (دبس التمر من نخيل الجزيرة).
- رمز للهوية المحلية (يُذكر مع المجبوس كأشهر طبقين).

### الهريس — رمز رمضان والأعراس 🟢
- **قمح (حب الهريس)** + **لحم** (ضأن/بقر) يُطهى ببطء ساعات طويلة حتى يذوب ويهرس بـ«المضرابة» (ملعقة خشبية كبيرة) + سمن + سكر بودرة + قرفة للتزيين.
- طبق تراثي ضارب في القدم — قيل إنه كان يمدّ **الغوّاصين** بالطاقة في رحلات اللؤلؤ. 🟡 *رواية تاريخية*
- يُقدّم في **رمضان** والأعراس والمآتم (وجبات جماعية).

### البلاليط — فطور شعبي 🟢
- **شعيرية** حلوة بالهيل/الزعفران/ماء الورد + بيض مقليّ فوقها (مزيج حلو/مالح).
- فطور بحريني/خليجي شائع.

### الخنفروش 🟢
- **كعك/فطائر** حلوة بنكهة الهيل والزعفران + السكر — تُقلى وتُقدَّم في رمضان والمناسبات.

### القبوط (كبة بحرينية) 🟡
- كرات عجين محشوة باللحم/البصل/البهارات تُطبخ داخل المرق/المجبوس.

### المضروبة 🟢
- طبق «مضروب» (مهروس): أرز/عدس/خضار + لحم يُهرس معًا + بهارات (مضروبة الجريش، مضروبة الربيان).

### المحشي البحريني 🟢
- خضار (كوسا/باذنجان/طماطم/فلفل) محشوّة بخليط أرز + لحم مفروم + حمص + بهارات.

### الثريد 🟢
- خبز (ثريد) مغموس بمرق اللحم/الدجاج والخضار — طبق رمضاني وعاشورائي.

### صالونة (مرق بحريني) 🟢
- شوربة/مرق لحم أو سمك + خضار (بطاطا/بامية/جزر) + بهارات + لومي/تمر هندي.

### الكباب البحريني 🟢
- كرات/أقراص لحم مفروم متبّلة + بصل + بهارات — مقلي/مشوي.

## 3. المأكولات البحرية 🟢
- **الهامور، الصافي، الربيان (الجمبري)، الصبور، البغّاة** — أسماك الخليج.
- سمك محشوّ بالأرز، مطبق الهامور، مجبوس الربيان، برياني الربيان.
- **اللؤلؤ والغوص** شكّلا ثقافة بحرية عميقة — الأسماك والربيان مكون أساسي (قبل النفط).

## 4. الحلويات 🟢
- **الحلوى البحرينية (الحلاوة البحرينية):** مهلبية/حلاوة بالزعفران الأحمر + المكسرات + ماء الورد — حلوى وطنية تُصدَّر وتُهدى.
- **الساقو:** بودينغ نشا الساقو + السكر + المكسرات.
- **اللقيمات:** كرات عجين مقلية + دبس/عسل.
- **الخبيصة:** حلوى دبس/تمر + سمن + دقيق.
- **المعمول/الكنافة** (تأثير شامي).
- **الزلابية/القيمات** في رمضان.

## 5. المقبلات والخبز 🟢
- **الحمص، الفلافل، المتبّل، التحميرة (دبس/طماطم حار)، الصحن البحريني**.
- الخبز: خبز التنور، «مخمخ» (خبز + بيض)، «رقاق».

## 6. المشروبات 🟢
- **القهوة العربية** (هيل + زعفران) — ضيافة.
- **شاي الكرك** (حليب + هيل).
- قهوة بحرينية + «لنتي» (شاي أحمر).
- عصائر رمضانية (تمر هندي، قمر الدين).

## 7. الطعام والمناسبات 🟢
- **رمضان:** الإفطار الجماعي + الهريس + الثريد + السمبوسة + البلاليط + القرقاعون (ليلة 15). + «الغبقة» (تجمع مسائي بعد التراويح) + «النقصة» (زيارات).
- **الأعراس:** المجبوس + المحمر + الهريس + الحلوى البحرينية.
- **عاشوراء:** توزيع «البركة» (وجبات خفيفة/حساء/بريد) في المآتم والمواكب — أطباق جماعية (هريس/ثريد/شوربة).
- **العيد:** المحشي + المجبوس + الخبيصة + القهوة.

## 8. ربط الطعام بالجغرافيا والثقافة
- **الواحات والنخيل** شمالًا → التمر + دبس التمر → المحمّر (الهوية البحرانية). 🟢
- **الخليج والغوص** → الأسماك والربيان + ثقافة الغوّاصين (الهريس طاقة الرحلات). 🟢
- **الموقع التجاري** (هند/فارس/عراق) → البهارات الهندية + الحلويات الفارسية + التأثير العراقي. 🟢
- **الماء العذب النادر** → اعتماد على التمر والقمح (غذاء جاف قابل للتخزين) لا على الزراعة الكثيفة.
- **المجتمع المتعدد الطوائف** → أطباق بحرانية (المحمر) مقابل عامة خليجية (المجبوس) + عجمية (أطباق فارسية).
