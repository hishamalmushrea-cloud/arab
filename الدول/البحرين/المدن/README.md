# مدن البحرين — المرحلة الخامسة

> **المرحلة الخامسة:** ملف لكل **مدينة** موثَّقة داخل **محافظة**. ليست بلدية قطرية ولا إمارة. 🟢
>
> **المنامة المدينة** في `العواصم/المنامة/` — لا تكرار هنا.
>
> **السكان:** تعداد الجهاز المركزي للمعلومات **17 مارس 2020** للمحافظات 🟢. **لا تعداد مدينة موحَّد منشور 2020** لكل المدن — يُذكر تعداد **2001** (CIO عبر citypopulation) 🟢 وجداول 2020 المتداولة بلا تفصيل نواة 🟡. لا يُخلط سكان **المحافظة** بسكان **المدينة**.
>
> **الوسطى** أُلغيت 22 سبتمبر 2014 — ليست وحدة قائمة. سترة في العاصمة؛ عيسى في الجنوبية.
>
> لا تُهمَّش الجزيرة والقرى: الحد، عراد، سماهيج، أمواج، عالي، الدراز.

### لا تخلط المواقع

| المعلم | المكان الصحيح | ليس |
|---|---|---|
| سوق القيصرية / مسجد الفاتح / المتحف الوطني | **المنامة** | المحرق |
| مسار اللؤلؤ / بو ماهر / المطار / أمواج | **المحرق** | العاصمة |
| قلعة البحرين / باربار / مسجد الخميس | **الشمالية** | المنامة المدينة |
| مدافن دلمون (عالي) | **الشمالية** 🟡 | الجنوبية في بعض الخرائط |
| مدينة حمد | **الشمالية** | الجنوبية |
| مدينة عيسى / الرفاع / الصخير / حوار / جبل الدخان | **الجنوبية** | الشمالية / الوسطى / دخان قطر |
| سترة | **العاصمة** بعد 2014 | الوسطى الملغاة |
| جسر الملك فهد (طرف البحرين) | **الشمالية** (جسرة) | العاصمة |
| منامة عجمان | **الإمارات** | هذه المنامة |
