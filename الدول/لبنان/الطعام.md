# الجمهورية اللبنانية — الطعام (المطبخ اللبناني)

> منهجية: لا تُنسب الأطباق إلى «لبنان» ككتلة بل إلى منشئها حيثما أمكن. كل طبق يُربَط بمكانه.
> المصادر: ويكيبيديا (مطبخ لبناني)، أرابيكا (مطبخ لبناني)، النهار (Taste Atlas)، arz.wikipedia.

---

## 1. نظرة عامة 🟢 — مطبخ عالمي الصيت

- **الشهرة:** المرتبة **25 عالميًّا** + **الأول عربيًّا** بحسب Taste Atlas (2024) 🟢.
- **الخصائص:** صحي (زيت زيتون/ثوم/ليمون/خضر) + متنوع (مازة/مشاوي/مقالي/يخنات) + بهارات غير حارة (السماق/البهار الحلو).
- **الجذور:** فينيقي/روماني (آلاف السنين) + عثماني (خروف/معجنات) + عربي + متوسطي.
- **الانتشار:** عالمي عبر المغتربين اللبنانيين (المازة/الحمص/الفلافل/الشاورما).

---

## 2. الأطباق الوطنية الكبرى 🟢

### (1) الكبة 🟢 — رمز المطبخ اللبناني/الشامي
- **الأصل:** الشام (لبنان/سوريا — مشترك).
- **الوصف:** برغل + لحم مدقوق، تُحشى بلحم مفروم/مكسرات، تُقلى أو تشوى أو تطبخ.
- **الأنواع (لبنانية):** كبة نية (لحم نيء) + كبة مقلية + كبة باللبن (بالزبادي) + كبة بطاطس + كبة زحلاوية (زحلة) + كبة بالكشك (كفر مشكي) + كبة صاجية + كبة السفرجلية.
- **المناسبة:** وليمة/مناسبات/رمضان.

### (2) الحمص بطحينة 🟢 — شامي
- **الوصف:** حمص مهروس + طحينة + زيت زيتون + ليمون + ثوم.
- **الانتشار:** كل لبنان + بلاد الشام + عالمي.
- **«حمص بيروتي»** — نوع بيروتي خاص.

### (3) التبولة 🟢 — لبنانية أصيلة
- **الوصف:** بقدونس مفروم ناعم + برغل + طماطم + نعناع + بصل + ليمون + زيت زيتون (نسبة البقدونس عالية).
- **التقديم:** بأوراق الخس/ورق العنب/الملفوف كمغرفة.
- **الانتشار:** كل لبنان + عالمي.

### (4) الفتوش 🟢 — لبناني
- **الوصف:** سلطة خضار (خيار/طماطم/فلفل/بصل/نعناع/بقدونس) + خبز مقرمش + دبس الرمان/ليمون/سماق.
- **الانتشار:** كل لبنان.

### (5) المكدوس 🟢 — شامي/لبناني
- **الوصف:** باذنجان صغير محشو بالجوز/الفلفل/الثوم، مخلل في زيت الزيتون.
- **المناسبة:** فطار/مقبلات شتوية.

### (6) ورق العنب (اليبرق) 🟢 — شامي/عثماني
- **الوصف:** ورق عنب محشو بأرز/لحم (أو صيامي)، يخنة في صلصة/لبن.
- **الانتشار:** كل لبنان.

## 3. أطباق أخرى بارزة 🟢

| الطبق | الأصل/المنطقة | الوصف | المناسبة |
|---|---|---|---|
| **الفلافل (الطعمية الشامية)** | شامي | أقراص حمص/فول مقلية | فطار/شارع |
| **الشاورما** | شامي/عثماني | لحم/دجاج مشوي عمودي + خبز + طحينة | شارع |
| **بابا غنوج** | شامي | باذنجان مشوي + طحينة | مقبلات |
| **متبل** | شامي | باذنجان + طحينة | مقبلات |
| **الصفيحة** | النبطية/بعلبك | فطيرة لحم ضأن مفتوحة | وليمة |
| **الكبة النية** | لبنان | لحم مفروم نيء + برغل + ملح/فلفل | مقبلات (تحذير صحي) |
| **شيش برك** | لبناني | كرات عجين محشوة بلحم، مطبوخة باللبن | وليمة |
| **الشيخ محشي** | لبناني | باذنجان محشو باللحم | وليمة |
| **المحاشي** | عام | كوسا/باذنجان/فلفل/كرنب محشو | مناسبات |
| **المجدرة** | طرابلس/عام | عدس + برغل/أرز + بصل مقلي | يومي/صيامي |
| **الصيادية** | صور | أرز + سمك (ساحلي) | غداء |
| **كوسا بلبن** | بشري | كوسا محشوة بالأرز/اللبن | غداء |
| **يخنة القرع** | عام | قرع + لحم | موسمي |
| **كفتة** | عام | لحم مفروم + بهارات + طماطم | وليمة |
| **حريشة** | عين زبدة | قمح + لحم بقر | يومي |
| **قفطان بيثين** | بيت الدين | لحم متبل + مركز السمسم | وليمة |

## 4. الحلويات والمشروبات 🟢

- **الحلويات:** البقلاوة (عثماني) + الكنافة + القطايف العصافيري (رمضان) + معلومة/حلاوة الجبن + المهلبية/السحلب + الراحة الحلقوم + المعمول (أعياد).
- **المشروبات:**
  - **العَرَق** (مشروب كحولي عنبي — لبناني أصيل 🟢).
  - **النبيذ اللبناني** (بعلبك/الشوف/الكورة — عالمي الصيت: شاتو مسقى/شاتو كفارعا).
  - **القهوة التركية/السادة** — مع الهيل.
  - **الشاي** — مع النعناع/المريمية.
  - **عصير ليمون/تمر هندي/جلاك** — صيفًا.
  - **اللبن/اليران** — مع الأكل.

---

## 5. الخبز 🟢

- **خبز البيتا (الخبز العربي)** — رقيق دائري بجيب، عماد المائدة.
- **خبز التنور/المرقوق** — رقيق جدًّا (الجبال).
- **الصاج** — خبز رقيق على الصاج.

---

## 6. المأكولات بحسب البيئة (ربط الجغرافيا بالطعام) 🟢

| البيئة | أطعمة بارزة | السبب |
|---|---|---|
| الساحل (بيروت/طرابلس/صيدا/صور) | الحمص/الفلافل/الشاورما/الصيادية (صور)/المجدرة (طرابلس) | موانئ + تجارة + سمك |
| جبل لبنان (عاليه/الشوف/بشري) | الكبة الجبلية/كوسا بلبن/قفطان بيثين/حريشة | جبال + مزارع + كرم |
| البقاع (زحلة/بعلبك/الهرمل) | الكبة الزحلاوية/الصفيحة البعلبكية/النبيذ + العرق | سهل زراعي + كروم + ممر دمشق |
| الجنوب (صور/بنت جبيل/النبطية) | الصفيحة النبطية/ورق العنب/الصيادية | ساحل + جبال + زراعة |

---

## 7. أطعمة المناسبات 🟢

- **المازة اللبنانية:** مجموعة مقبلات (حمص/متبل/تبولة/فتوش/كبة/ورق عنب/مكدوس) — أساس كل مائدة احتفالية.
- **الأعراس:** الكبة/المشاوي/المازة + البقلاوة/الكنافة.
- **رمضان:** الفتوش/التبولة/المحاشي/القطايف/الكنافة.
- **الأعياد:** المعمول (الفطر/الأضحى) + الكبة/المشاوي.
- **العزاء:** أرز/لحم (في الجنوب/البقاع — «الوليمة»).

---

## 8. البهارات والمكوّنات المحلية 🟢

- **بهارات (غير حارة):** السماق (مميز) + البهار الحلو (قرفة/قرنفل/جوزة الطيب) + الفلفل الأسود/الأبيض + الكمون + الكزبرة + المحلب + الحلبة + الهيل + الزنجبيل.
- **مكوّنات محلية:** زيت الزيتون (الشمال/الجنوب) + الثوم + الليمون (الحامض) + الخضار (البقاع/الساحل) + الجوز (الجبال) + العنب/النبيذ/العرق.
- **الأجبان:** الحلوم (صور) + اللبنة + الجبن العكاوي + الشنكليش (شمالي/أرثوذكسي).

---

## 8. ملاحظة نقدية

- المطبخ اللبناني **موروث شامي مشترك** مع سوريا/فلسطين/الأردن — لا يُنسب كله للبنان.
- التبولة/الفتوش **لبنانية أصيلة** (نسبة البقدونس/السماق مميزة).
- الكبة **شامية مشتركة** (لبنان/سوريا/العراق) — لكن «الكبة النية» لبنانية/شامية.
- العَرَق والنبيذ **لبنانيان أصيل** (تأثير فينيقي/روماني + مناخ البقاع).
- المطبخ اللبناني تأثر بـ: الفينيقي/الروماني (العنب/الزيتون) + العثماني (البقلاوة/الشاورما/الخروف) + المتوسطي (زيت الزيتون/الثوم/الليمون).
