# الجمهورية اللبنانية — اللباس التقليدي

> منهجية: لكل قطعة يُذكَر اسمها المحلي + المناسبة + المنطقة + الاختلاف بين الطوائف والمناطق.
> المصادر: ويكيبيديا (اللباس اللبناني)، culturein2030vision (مقارنة شامية)، إضافات متقاطعة.

---

## 1. ملاحظة أولى: تنوع طائفي/إقليمي/تاريخي 🟢

> اللباس اللبناني متنوع بحسب الطائفة (مسلم/مسيحي/درزي) والمنطقة (الساحل × الجبل × البقاع × الشمال × الجنوب) والتاريخ (عثماني/انتداب/حديث). لبنان صغير لكنه فسيفساء ثقافية.

---

## 2. اللباس الرجالي 🟢

### القطع الأساسية (تاريخية)

| القطعة | الوصف | المنطقة/الاستخدام |
|---|---|---|
| **الشروال (السروال)** | سروال فضفاض جدًّا منخفض الوسط | الجبل/الريف (تاريخي) |
| **القميص** | قميص قطني طويل | تحت القمباز |
| **القفطان/القمباز** | رداء طويل فضفاض | المدن/المناسبات (تاريخي) |
| **العباءة/المشلح** | رداء خارجي صوف/حرير | المناسبات |
| **العمامة/الطربوش** | غطاء رأس | العلماء/المثقفون (تاريخي — الطربوش عثماني) |
| **الحطة/الكوفية** | غطاء رأس مربع | الريف/البدو (الشمال/البقاع) |
| **الحزام/الزنار** | جلدي/قماشي | فوق الشروال |
| **الخنجر/الجنبيّة** | خنجر يُحمل على الخصر (تاريخي) | الجبل/الأعيان |

### اللباس الحديث 🟢
- **المدن (بيروت/المدن الساحلية):** بدلة/قميص/جينز — أزياء غربية (تأثير فرنسي/متوسطي).
- **الريف/الجبل:** أقل رسمية، لكن اللباس التقليدي في المناسبات/القرى.
- **المناسبات:** البدلة + ربطة العنق (رسمي) أو القمباز (تراثي في الأعراس).

---

## 3. اللباس النسائي 🟢 — تنوع طائفي/إقليمي

### (أ) الزي المسيحي (الماروني/الأرثوذكسي) 🟢
- **العباءة/الملاية** (تاريخي) — أسود للخروج.
- **النقاب/البرقع** — محدود (بعض القرى المسلمة).
- **المسح/الحِبرة** — رداء أبيض/ملوّن (تاريخي — الجبل).
- **الجلباب** — قطني/صوفي (الريف).
- **المسرح/الهاشمي** — فساتين احتفالية مطرَّزة (المناسبات).
- **حديثًا:** فساتين/تنانير/جينز + حجاب محدود (المسيحيات غالبًا بدون حجاب).

### (ب) الزي الإسلامي (السُّني/الشيعي) 🟢
- **الحجاب/الشيلة** — غطاء رأس (في الأوساط المحافظة — أكثر في البقاع/الجنوب/الشمال).
- **العباءة/الجلباب** — رداء فضفاض.
- **النقاب** — محدود (بعض المناطق المحافظة — البقاع/طرابلس).
- **الشيعية (الجنوب/الضاحية):** حجاب + عباءة سوداء (بعد 1980s — تأثير حزب الله).
- **السُّنية (طرابلس/صيدا/عكار):** حجاب/نقاب في الأوساط المحافظة (تأثير سلفي في طرابلس).

### (ج) الزي الدرزي 🟢
- **المشايخ (رجال):** الشاش/العمامة السوداء + السروال + القمباز (للمشايخ الدينيين).
- **النساء:** العباءة السوداء + المنديل (تغطية تامة) + الحجاب (الأرملة ترتدي الأبيض).
- **الزي التقليدي الدرزي** محافظ جدًّا + رمزي.

### (د) الزي الأرمني 🟢
- **النساء:** فساتين مطرَّزة (تأثير أرمني تقليدي) + الحلي.
- **الرجال:** بدلة/قميص (حديث).

### (هـ) الزي البقاعي/الشمالي (ريفي) 🟢
- **الجلباب/العباءة** — قطني/صوفي (يومي).
- **الحطة/الكوفية** — للرجال (تأثير بدوي/شامي داخلي).

---

## 4. الحلي والمجوهرات 🟢

- **الذهب/الفضة** — للنساء (أقراط/أساور/خلاخل/صليب للمسيحيات).
- **الصليب** — للمسيحيات (مارونية/أرثوذكس).
- **الحلي الفضية** — الدروز + البقاع.
- **الخرز/التراث** — في القرى الجبلية.

---

## 5. اللباس التاريخي 🟢

- **الفينيقي/الروماني:** الكتان + الأرجوان (صباغ فينيقي) — تاريخي.
- **العثماني (1516–1918):** القمباز + الطربوش + الشروال + العباءة + البراقع (تأثير قوي).
- **الانتداب الفرنسي (1920–1943):** البدلة الغربية + الفستان (الطبقة المثقفة/الحضر).
- **الحديث (1943+):** أزياء غربية (تأثير فرنسي/متوسطي) — لبنان أكثر الدول العربية انفتاحًا ملابسيًّا.
- **1975–1990 (الحرب):** تباين طائفي (شرق مسيحي/غرب مسلم) + محافظة تدريجية في المناطق الإسلامية.
- **1980s–الحاضر:** انتشار الحجاب/العباءة في المناطق الإسلامية (الجنوب/البقاع/طرابلس/الضاحية) — تأثير إسلامي/حزب الله + بقاء الانفتاح في بيروت/الجبل المسيحي.

---

## 6. الفروق بحسب البيئة/الطائفة 🟢

| البيئة/الطائفة | اللباس | السبب |
|---|---|---|
| بيروت/الساحل (حضري/متنوع) | أزياء غربية + تنوع طائفي (حجاب/بدون) | متوسطي + فرنسي + تنوع |
| جبل لبنان (ماروني/درزي) | تاريخي محافظ + حديث منفتخ (المسيحي) + محافظ (الدرزي) | جبال + هوية طائفية |
| طرابلس/عكار/الشمال (سُني) | حجاب/نقاب في الأوساط المحافظة + بدلة (رجال) | سُنة + تأثير سلفي (طرابلس) |
| البقاع/بعلبك/الهرمل (شيعي/سُني) | حجاب/عباءة (نساء) + بدلة/شروال (رجال) | محافظة + ريف |
| الجنوب (شيعي) | حجاب + عباءة سوداء (نساء) + كوفية/عقال (رجال ريف) | محافظة + حزب الله |
| الدروز (الشوف/عاليه/حاصبيا) | محافظ جدًّا + الشاش (المشايخ) | هوية درزية |

---

## 7. التطور الحديث 🟢

- **لبنان أكثر الدول العربية انفتاحًا ملابسيًّا** (تأثير فرنسي/متوسطي/سياحي).
- **بيروت/الجبل المسيحي:** أزياء غربية + شاطئ (بيروت/جونية).
- **المسلمات (الجنوب/البقاع/طرابلس):** حجاب/عبائية (محافظة).
- **المناسبات:** البدلة (رسمي) + القمباز/المسرح (تراثي).

---

## 8. ملاحظة نقدية

- اللباس اللبناني **فسيفساء طائفية/إقليمية** — لا يُعمَّم.
- **الطربوش** سقط بعد الاستقلال (زي عثماني).
- **الانفتاح** في بيروت/الجبل المسيحي + **المحافظة** في البقاع/الجنوب/طرابلس (إسلامي).
- **الدروز** زي محافظ/رمزي (الشاش/العمامة السوداء للمشايخ).
- **الأرمن** زي تقليدي خاص.
