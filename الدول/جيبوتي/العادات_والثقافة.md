# العادات والثقافة في جمهورية جيبوتي

> ثقافة جيبوتية مركّبة: صومالية + عفرية + عربية إسلامية + فرنسية + هندية. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر.

---

## 1. القبائل + القوميات 🟢

### أ. الصوماليون (60% — عيسى)
- **قبيلة عيسى (Issa):** من دِر (صومالي — رعاة نبيلون) — الأغلبية في العاصمة + جنوب + شرق.
- **نظام العشائر الصومالي** (نظام 4 قبائل — انظر `الصومال/العادات_والثقافة.md`).
- **اللهجة:** الصومالية + الديراك/الغارباسار (لباس) + المكاوييس.

### ب. العفر (35%)
- **قومية العفر (Afar):** من كوشي (حامي) — رعاة بدو — شمال + غرب + وسط.
- **السلطنات العفرية التاريخية:** عفت + تاجورة.
- **اللهجة:** العفرية + ثوب العفر.

### ج. العرب (5%)
- **يمنيون** (~4.5%):** تجار + صيادون (من اليمن + حضرموت + عدن) — ساحل + مدن.
- **عمانيون + أحمر:** تجار + بحارة.
- **الأنساب:** عيسى → عرب (رواية شفهية) + عفر → عرب (مصاهرات).

### د. الأقليات
- **إثيوبيون + إرتريون:** لجؤون (حروب أهلية).
- **أوروبيون (فرنسيون + إيطاليون + سويديون):** إرث استعماري + مقيمون.
- **هنود:** تجار.

---

## 2. الأعراس والزواج 🟢

### مراحل الزفاف
1. **المهر (الصومالي):** الخطوبة + تقديم المهر.
2. **القران:** العقد الشرعي.
3. **الحناء:** للعروس + العريس.
4. **ليلة الزفاف:** الديراك + الغارباسار + الذهب + الوليمة + «أروسي» (الحفل).
5. **الفطور:** أهل العروس يقدّمون فطورًا للعريس + هدايا.

### عادات
- **الختان:** للذكور (إرث إسلامي).
- **الديا (Diya):** الدية — تسوية القتل بالنسب العشائري (إرث صومالي).
- **القات:** «الإفطار» + رمضان + السهرات + الجلسات الإنشاد — ثقافة اجتماعية.

---

## 3. المناسبات الدينية 🟢

### رمضان
- **السمبوسة + الإنجيرا + الحساء + القات + حليب + الشاي.**
- **ذبح الذبائح + توزيع لحوم** على الفقراء والأغنياء سواسية.
- **القات:** «السهرات» — استورد كبير (أكبر مستورد) + توزيع في جلسات الإنشاد الديني.
- موائد جماعية + التراويح + الختمات.

### العيد
- صلاة العيد + الذبيحة (الأضحى) + الأرز + اللحم المشوي + الكاك كاك + الديراك + الذهب.

### المولد النبوي
- مواكب + مدائح صوفية + قهوة + توزيع الحلوى.

---

## 4. الطرق الصوفية 🟢
- **القادرية:** الأكثر انتشارًا (إرث إسلامي).
- **الأحمدية + الصالحية + الرفاعية + السمانية.**
- الزوايا + المدائح + الذكر + الختان.
- الصوفية مكوّن ديني/اجتماعي عميق + الأحزاب.

---

## 5. العادات الاجتماعية 🟢
- **الكرم/الضيافة:** وجبة كاملة للغريب + الشاي + القهوة + القات — قيمة أساسية.
- **المجالس (القعدات):** مجالس الرجال (المسيد) + النساء.
- **التكافل:** الجار + الحِلّة + الأفراح + المآتم الجماعية (إرث بدوي/صومالي).
- **الصِل + الأمانة + الوفاء بالعهد** — قيم إسلامية/عشائرية.
- **السلام + المصافحة:** إرث إسلامي/عربي.

---

## 6. الفنون الشعبية 🟢
- **الشعر الصومالي (الغنائي + البطوش):** فن شفهي عريق — «بلد المليون شاعر» (إرث صومالي).
- **الرقصات:** البوبلي + البنتلاند (صومالية) + Afar dance (عفرية).
- **الموسيقى:** الطبل + الناي + العود + تأثيرات عربية + فرنسية + هندية + إفريقية.
- **الفنون الحرفية:** النسيج (الديراك/الغارباسار + المكاوييس) + الجلود + الخشب + الصياغة (الذهب).

---

## 7. العمارة التراثية 🟢

### العمارة الفرنسية (إرث استعماري)
- **مدينة جيبوتي:** عمارة فرنسية قديمة (الإدارة الاستعمارية + الميناء + السكة الحديدية).
- «اللإإرنسيب»: المباني الاستعمارية + الشوارع المرصوفة.
- **أبوك:** عمارة فرنسية + ميناء تاريخي.

### العمارة الإسلامية
- **مساجد:** مسجد عبد القادر الكبير (القرن 19؟) + مساجد تاريخية في أبوك + تاجورة.
- **السلطنات:** آثار سلطنة عفت + سلطنة تاجورة (زيلع + تاجورة).
- **المدن المينائية:** أبوك + تاجورة + جيبوتي (إرث إسلامي/عربي/فرنسي).

### العمارة الحديثة
- **ميناء دوراليه + منطقة التجارة الحرة** (الصين) — عمارة صناعية حديثة.
- **المطار الدولي + القصور الرئاسية + السفارات.**

---

## 8. الثقافة المعاصرة 🟢
- **الشعر:** صومالي (الغنائي) + عفاري + فرنسي.
- **الأدب الحديث:** أدب صومالي + أدب فرنسي (الإستعمار).
- **الموسيقى:** تقليدي + حديثة — مطربون (محمود أحمد + أعلام عفر).
- **الإعلام:** إذاعة (الإذاعة الفرنسية + جيبوتي) + تلفزيون + صحف.
- **التعليم:** عربية + فرنسية (إرث استعماري) + صومالية + عفرية (لغتان وطنيتان).

---

## 9. ربط الجغرافيا بالثقافة
- **الموقع الاستراتيجي** (باب المندب + خليج عدن) → ثقافة تجارية + مركز لوجستي + القواعد العسكرية (6 دول) + الميناء + السكة الحديدية + التجار العرب. 🟢
- **الصحراء + البدو الرعاة** (العفر + عيسى) → حياة رعوية بدوية + القات (السهرات) + المكاوييس + الديراك + الشاي + الكرم. 🟢
- **البحر الأحمر + خليج تاجورة + خليج عدن** → ثقافة بحرية + صيد + تجارة + مدن مينائية (أبوك + تاجورة + جيبوتي) + الإسلام (القرن 8).
- **الإسلام + التجار العرب** (القرن 8) → العربية + الأنساب العربية (عيسى) + المفردات الدينية + الشافعية + الصوفية (قادرية) + الحلال + الختان + القات.
- **الإستعمار الفرنسي** (1862–1977) → الفرنسية (لغة رسمية) + العمارة الفرنسية + اللباس الفرنسي + القهوة + المعجنات + الإرث الفرنسي.
- **الموقع المعبري** (إثيوبيا/اليمن/الصومال) → ثقافة هجينة متعددة الأصول (صومالي + عفاري + عربي + فرنسي + هندي) + تأثيرات متبادلة + التجار اليمنيين (السمك اليمني — الطبق الوطني).
- **التركيبة العرقية المركّبة** (صومالي 60% + عفر 35% + عرب 5%) → توازن سياسي (عيسى × عفار) + حرب أهلية 1991 + سلام 2001.
