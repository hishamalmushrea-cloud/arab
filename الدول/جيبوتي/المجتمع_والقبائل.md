# المجتمع والقبائل والطوائف في جمهورية جيبوتي

> تركيبة عرقية مركّبة: صوماليون (60%) + عفر (35%) + عرب (5%) + أقليات. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر (النزاع الإقليمي حساس).

---

## 1. السكان — الأرقام 🟡
- **السكان:** ~1.17 مليون (2024) — تباين 992,000–1.17 مليون.
- **الكثافة:** ~37 نسمة/كم² (منخفض — رعاة + ساحل + عاصمة).
- **التوزيع:** ~73% في العاصمة جيبوتي + ~76% حضر + 24% رعاة/ريف.
- **معدل النمو:** ~2.2% سنويًّا (تقديري).
- 🟡 لا إحصاء رسمي دقيق (تقديرات CIA + Worldometers).

---

## 2. التركيبة الإثنية/العرقية 🟢🟠

### أ. الصوماليون (60%) 🟢
- **قبيلة عيسى (Issa):** من دِر (صومالي — رعاة نبيلون) — الأغلبية في العاصمة + جنوب + شرق.
- **نظام العشائر الصومالي** (نظام 4 قبائل — انظر `الصومال/المجتمع_والقبائل.md`).
- **الدين:** الإسلام (سُنة + شافعية) + الطرق الصوفية (قادرية).
- **اللغة:** الصومالية (كوشية) + الديراك/الغارباسار (لباس).
- **المناطق:** العاصمة + جنوب + شرق.
- 🟡 *رواية شفهية*: نسب قبيلة عيسى إلى عرب (إراب + هبر أوال + هبر يونس + عيسى موسى + عرب + أيوب + سعد موسى + زبير).

### ب. العفر (35%) 🟢
- **قومية العفر (Afar):** من كوشي (حامي) — رعاة بدو — شمال + غرب + وسط.
- **السلطنات العفرية التاريخية:** عفت + تاجورة (إرث سياسي/تجاري).
- **الدين:** الإسلام (سُنة + شافعية) + الصوفية.
- **اللغة:** العفرية (كوشية) + ثوب العفر.
- **المناطق:** شمال (عرتا + أبوك) + غرب (تاجورة) + وسط.
- 🟡 *رواية شفهية*: نسب قومية العفر إلى عرب (هجرات + مصاهرات من قحطان اليمن).

### ج. العرب (5%) 🟢
- **يمنيون** (~4.5%):** تجار + صيادون (من اليمن + حضرموت + عدن) — ساحل + مدن.
- **عمانيون + أحمر:** تجار + بحارة (من عمان + ساحل عمان).
- **الدين:** الإسلام (سُنة + شافعية).
- **اللغة:** العربية (لهجة تعزية-عدنية) + الثوب/الخميص.
- **المناطق:** ساحل + مدن + أبوك.
- 🟢 «العمانيون + اليمنيون» — تجار تاريخيون + جالية كبيرة.

### د. الأقليات 🟡
- **إثيوبيون + إرتريون:** لجؤون (حروب أهلية + حدود).
- **أوروبيون (فرنسيون + إيطاليون + سويديون):** إرث استعماري + مقيمون.
- **هنود:** تجار (تأثير هندي على المطبخ + البهارات).

---

## 3. الأديان والمذاهب 🟢
- **الإسلام ~94%** (دين الدولة + الهوية):
  - **سُنة + شافعية** (غالبية).
  - **الصوفية:** قادرية (الأكثر انتشارًا) + أحمدي + صالحية + رفاعية + سمانية.
- **المسيحية ~6%:** أرثوذكس + كاثوليك + بروتستانت — أوروبيون (فرنسيون + إيطاليون) + أقليات.
- 🟢 جيبوتي بلد إسلامي + عضو جامعة الدول العربية (منذ 1977) + العربية لغة رسمية.

---

## 4. العائلات والزعامات 🟢
- **آل غوليد أبتيدون** (المؤسس — رئيس 1977–1999).
- **آل جيلي** (الحالي — منذ 1999).
- **آل أحمد ديني أحمد** (رئيس وزراء سابق).
- **آل عبد القادر كميل محمد** (رئيس وزراء — 2024).
- **آل محمود حربي** (زعيم النضال الوطني).
- الزعامات القبلية: شيوخ عيسى + سلاطين عفر (سلطنة عفت + سلطنة تاجورة).
- الزعامات الدينية: شيوخ الطرق الصوفية (قادرية + أحمدي).

---

## 5. السياسة والمشاركة 🟢🟠
- نظام: **جمهورية شبه رئاسية** (تعددية حزبية منذ 1992).
- **الرئاسة:** إسماعيل عمر جيلي (1999–الآن).
- **رئيس الوزراء:** عبد القادر كميل محمد (2024–الآن).
- **الجمعية الوطنية:** برلمان أحادي (65 مقعد).
- **الأحزاب:** التجمع الشعبي من أجل التقدم (RPP — حزب الواحد سابقًا) + حزب الإتحاد الديمقراطي (UDT) + حزب الإصلاح + أحزاب أخرى.
- 🟠 *القضايا الحساسة* (النزاع الإثيوبي-الإرتري على الحدود + الصومال + التأثير الأجنبي العسكري) تُورَد بحياد.
- **التوازن العرقي** (عيسى × عفار) = أساس الاستقرار السياسي + الحرب الأهلية 1991 + سلام 2001.

---

## 6. التحديات الاجتماعية 🟠
- **النزاع العرقي** (عيسى × عفار): حرب أهلية 1991 + إنهاء بسلام 2001 + توترات متواصلة.
- **النزاع الإقليمي** (إثيوبيا × إرتريا): على الحدود + تأثير على الاستقرار + التجارة.
- **الفقر + البطالة + الأمية + ضعف البنية التحتية** (خارج العاصمة).
- **الدين العام** (~85% من الناتج) + عجز مالي + اعتماد على الخارج.
- **الإعتماد على القواعد العسكرية + الترانزيت + الإستثمارات الصينية + المعونات** — مصادر دخل خارجية.
- **تستورد >90% من غذائها** (إثيوبيا بدون ساحل + الأراضي محدودة).

---

## 7. ربط المجتمع بالجغرافيا والتاريخ
- **الموقع المعبري** (إثيوبيا/إرتريا/الصومال/اليمن + باب المندب) → اختلاط عرقي + هجرات عربية (يمن + عمان + أحمر) + مصاهرات + التجار + الإسلام (القرن 8). 🟢
- **الصحراء + البدو الرعاة** (العفر + عيسى) → حياة رعوية بدوية + الإبل + الأغنام + نظام العشائر (صومالي) + السلطنات (عفر) + القات. 🟢
- **البحر الأحمر + خليج تاجورة + خليج عدن** → ثقافة بحرية + صيد + تجارة + مدن مينائية (أبوك + تاجورة + جيبوتي) + التجار اليمنيين + العرب.
- **الإسلام + التجار العرب** (القرن 8) → الإسلام ~94% + العربية لغة رسمية + الشافعية + الصوفية (قادرية) + الأنساب العربية (عيسى + عفر — روايات).
- **الإستعمار الفرنسي** (1862–1977) → الإرث الفرنسي + الفرنسية (لغة رسمية) + القواعد الفرنسية + العمارة الفرنسية + اللباس الفرنسي + القهوة + المسيحية ~6% (أوروبيون).
- **التركيبة العرقية المركّبة** (صومالي 60% + عفر 35% + عرب 5%) → توازن سياسي (عيسى × عفار) + حرب أهلية 1991 (جبهة عفار — FRUD) + سلام 2001 + إنشاء إقليم عرتا 2003 (آخر تعديل).
- **القواعد العسكرية الأجنبية** (6 دول — 1977+) → بدل مادي + إجار = ~20% من الناتج + حماية أمنية + استقرار + «وكر لجواسيس العالم» + التأثير الأجنبي.
- **النزاع الإقليمي** (إثيوبيا × إرتريا) → توترات على الحدود + التجارة + الاستقرار + اللاجئين. 🟠
