# اقتصاد جمهورية جيبوتي

> اقتصاد خدماتي مينائي + قواعد عسكرية + إستثمارات صينية + هش. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر.

---

## 2. الميناء — عصب الاقتصاد 🟢
- **خدمات الميناء + اللوجستيات:** ~70% من الناتج المحلي.
- **ميناء جيبوتي:** العاصمة + الميناء الرئيسي + بوابة إثيوبيا (~90% من وارداتها).
- **ميناء دوراليه متعدد الأغراض (Doraleh):** بناء صيني (590 مليون $ — 2012) + أكبر ميناء للمياه العميقة + افتُتح 2018.
- **محطة حاويات دوراليه:** الصين (2021) — رسوم الشحن + تصدير منتجات صينية للأسواق الأوروبية.
- **منطقة التجارة الحرة (DFTZ):** الصين (3.5 مليار $ — افتُتحت 2018) — أكبر منطقة تجارة حرة في أفريقيا (تكمل 2028).
- **مبادرة «الحزام والطريق» (BRI):** الصين (2013) — تطوير الموانئ + البنية التحتية + طريق الحرير.

---

## 3. القواعد العسكرية الأجنبية (6 دول) — مصدر دخل قومي 🟢
- **بدل الإيجار + الحماية:** مصدر دخل قومي كبير + ~20% من الناتج.
- **6 قواعد:**
  - **فرنسا:** أكبر قاعدة فرنسية في أفريقيا (إرث استعمار — 1977).
  - **أميركا:** **ليمونييه** — أكبر قاعدة أميركية في أفريقيا (~4,000 جندي — استراتيجي).
  - **الصين:** أول قاعدة صينية في الخارج (2017 — 1,000 جندي — قرب دوراليه).
  - **اليابان:** قاعدة يابانية (~600 جندي).
  - **إيطاليا:** قاعدة إيطالية.
  - **السعودية:** قاعدة (تحت الإنشاء — 2019).
- 🟢 *حقيقة موثقة*: 6 قواعد عسكرية + بدل مادي + إجار = مصدر دخل قومي + حماية أمنية + «وكر لجواسيس العالم» (BBC).

---

## 4. تجارة الترانزيت + الميناء 🟢
- **جيبوتي بوابة إثيوبيا:** ~90% من واردات إثيوبيا عبر ميناء جيبوتي + سكة حديد.
- **الترانزيت:** يمر عبر جيبوتي صادرات الخليج النفطية للأسواق الأوروبية/الأميركية + إيرادات الميناء.
- **خطوط أنابيب:** من إثيوبيا (مياه).
- **سكة حديد جيبوتي–أديس أبابا:** تاريخية (1897) + كهربائية (الصين) — خط النقل الرئيسي لإثيوبيا.

---

## 5. الإستثمارات الصينية 🟢
- **أكبر مستثمر أجنبي:** استثمارات >4 مليار $ (دوراليه + منطقة التجارة الحرة + سكة حديد).
- **الصين تدفع 100 مليون $ سنويًّا** إيجار (يفوق ما تدفعه أميركا + فرنسا).
- **ميناء دوراليه:** 23.5% مملوك للصين (هيئة موانئ الصين التجارية).
- **كابلات الألياف الضوئية:** هواوي (Huawei) — ربط آسيا + شرق أفريقيا + أوروبا.
- 🟠 «تحويل جيبوتي إلى دبي ثانية» (الصين) + خلاف مع الإمارات (إستيلاء حكومي على دوراليه 2018).

---

## 6. الزراعة + الثروة الحيوانية + الصيد 🟡
- **الأراضي الصالحة:** محدودة جدًّا (~0.09% من المساحة — 23,200 كم²) — صحراء + براكين.
- **المحاصيل:** خضار + فواكه (مانجو + موز) + حبوب — محدودة + تستورد معظم الغذاء.
- **الثروة الحيوانية:** أغنام + ماعز + إبل (رعاة بدو) — محدودة + قمحلي.
- **الصيد:** ساحل غني بالأسماك — تونة + أسماك — تصدير + أمن غذائي محدود.
- 🟡 **تستورد >90% من غذائها** (إثيوبيا بدون ساحل + الأراضي الصالحة محدودة).

---

## 7. التعدين + الطاقة 🟡
- **الملح:** بحيرة عسل = أكبر احتياطي ملح في العالم + استغلال.
- **الطاقة الجيوحرارية:** مصادر حرارية + براكين + مداخن (إمكانيات — لم تُستغل).
- **النفط + الغاز:** مكتشفات بعالية (لم تُستغل).
- **المعادن:** محدودة + جبس + فوسفات.

---

## 8. التجارة الخارجية 🟢
- **الصادرات:** خدمات الميناء + لوجستيات + الترانزيت + القوات العسكرية (بدل) + الصيد + الماشية + القات.
- **الواردات:** الآلات + المعدات + النفط ومشتقاته + المواد الغذائية (>90%) + السيارات + السلع الاستهلاكية.
- **الشركاء:** الصين (الأكبر) + إثيوبيا + فرنسا + السعودية + الإمارات + الولايات المتحدة + الاتحاد الأوروبي.
- 🟠 **عجز تجاري** + اعتماد على الترانزيت + القواعد العسكرية + التحويلات + المعونات + الدين العام (~85%).

---

## 9. السياحة + الآثار 🟢🟠
- **سياحة طبيعية:** بحيرة عسل (أنخفض نقطة) + بحيرة أبي (براكين) + جبال موسى علي + شعاب + غوص (القرن الإفريقي).
- **سياحة ثقافية:** أبوك + تاجورة (مدن تاريخية) + مساجد + سلطنات.
- **سياحة شاطئية:** ساحل البحر الأحمر + خليج تاجورة + خليج عدن.
- 🟠 سياحة محدودة (الحر + البنية التحتية الضعيفة).

---

## 10. التحديات الاقتصادية 🟠
- **اقتصاد هش:** معتمد على الميناء + القواعد العسكرية + الترانزيت + الإستثمارات الصينية — تنوع محدود.
- **الدين العام مرتفع** (~85% من الناتج) + عجز مالي.
- **البطالة + الفقر + الأمية + ضعف البنية التحتية** (خارج العاصمة).
- **الإعتماد على الخارج:** المعونات + التحويلات + القواعد العسكرية + الترانزيت.
- **النزاع الإثيوبي-الإرتري** على الحدود (تأثير على الاستقرار + التجارة).
- **الصين × الإمارات:** تنافس + خلاف قانوني (دوراليه 2018) + مخاوف أميركية.

---

## 11. ربط الاقتصاد بالجغرافيا
- **الموقع الاستراتيجي** (باب المندب + خليج عدن) → الميناء + الترانزيت + القواعد العسكرية (6 دول) + اللوجستيات + «وكر لجواسيس العالم» (BBC) + التجارة العالمية. 🟢
- **إثيوبيا بدون ساحل** → جيبوتي بوابة إثيوبيا (~90% من وارداتها) → الميناء + سكة حديد + تجارة + المركز اللوجستي.
- **البحر الأحمر + خليج تاجورة + خليج عدن** → الصيد + الميناء + مدن مينائية (أبوك + تاجورة + جيبوتي) + الترانزيت + القواعد العسكرية.
- **الصحراء + الحر + الجفاف** → الأراضي الصالحة محدودة (~0.09%) + تستورد >90% من غذائها + الزراعة محدودة + الثروة الحيوانية محدودة.
- **الإستعمار الفرنسي** (1862–1977) → الإرث الفرنسي + القواعد الفرنسية + الفرنك + اللباس الفرنسي + القهوة + المعجنات + الإدارة.
- **الصين** (2010ات) → أكبر مستثمر أجنبي + ميناء دوراليه + منطقة التجارة الحرة + سكة حديد + كابلات هواوي + 100 مليون $ إيجار + مخاوف أميركية + خلاف مع الإمارات.
- **القواعد العسكرية (6 دول)** → بدل مادي + إجار = ~20% من الناتج + حماية أمنية + استقرار سياسي.
