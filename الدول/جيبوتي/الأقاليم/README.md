# أقاليم جيبوتي — المرحلة الرابعة (الوحدات الإدارية العُليا)

> **المرجع الإداري:** المستوى الأعلى = **إقليم / région**. العدد **6** (خمسة أقاليم + **مدينة جيبوتي** التي يعاملها ISO كـ ville مساوية للإقليم). ليست محافظة ولا غوبول صومالي. 🟢
>
> **ISO 3166-2:DJ:** DJ-AS · DJ-AR · DJ-DI · DJ-DJ · DJ-OB · DJ-TA. **دخيل = DJ-DI** لا DJ-DK. مدينة جيبوتي = **DJ-DJ** لا DJ-DI. 🟢
>
> **المستوى الثاني:** في جداول تعداد **2024** تُعرض **مقاطعات فرعية (sous-préfectures)** داخل الأقاليم، و**بلديات (communes)** داخل مدينة جيبوتي. الجرد القديم يذكر **11 مقاطعة**. بعض الخرائط تسرد نحو **20**. لا يُغلق رقم واحد. 🟡
>
> **مدينة جيبوتي** في `العواصم/جيبوتي/` — هنا **إقليم/مدينة جيبوتي**.
>
> **السكان:** تعداد **29 مايو 2009** 🟢 (818,159 في جمع الأقاليم عبر statoids + citypopulation). تعداد **INSTAD 20 مايو 2024** الوطني **1,066,809** 🟢. التوزيع الإقليمي 2024 أدناه من جداول citypopulation التي تجتمع إلى هذا المجموع؛ ويكيبيديا تختلف في جيبوتي/أوبوك/تاجورة → 🟡.
>
> جيبوتي **ليست** أصغر دولة عربية مساحةً (البحرين ثم جزر القمر أصغر). هي من أصغر الدول في البر الأفريقي. 🟢
