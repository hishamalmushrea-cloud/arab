## 1. ما قبل الإسلام — الممالك الإسلامية 🟢

### الممالك القديمة
- **منطقة العفر:** استيطان قديم (القرن 9–13 م) + مملكة أدال (حوالي 900–1285 م) — عاصمتها زيلع.
- **سلطنة عفت (Awdal/Afal — 1285–1415):** عاصمتها زيلع — أسستها القبائل العفرية + الصومالية المحلية — تجارية + إسلام.
- **سلطنة عدال (Adal — 1415–1577):** عاصمتها زيلع — حرب ضد إثيوبيا المسيحية (المد المسيحي).
- **إيالة الحبشة (1554–1882):** الحكم العثماني المصري.

### وصول الإسلام 🟢
- **القرن 8 م:** أول المجامع العرقية الأفريقية التي تعتنق الإسلام (الصوماليون + العفر) — عبر التجار العرب (من اليمن + حضرموت + عمان) عبر باب المندب.
- **التأثير العربي:** هجرات + مصاهرات (عرب من قحطان اليمن) + أنساب قبائل (عيسى → عرب/صومالي + عفار → عرب/كوشي).

## 2. الإستعمار الفرنسي (1862–1977) 🟢

### بدايات الإستعمار
- **1862:** فرنسا تشتري ميناء **أبوك** من زعيم العفر (راييتا ديني أحمد) — أول موطئ قدم.
- **1862–1888:** فرنسا تتوسع + إنشاء مستعمرة **«الصومال الفرنسي»** + مدينة جيبوتي (1888) + بناء سكة حديد إلى أديس أبابا (إثيوبيا).
- **1889:** محاولة روسية (أشينوف — تاجورة) فاشلة (طردها فرنسا).
- **1894:** لونس لاغارد يؤسس الإدارة الفرنسية الدائمة + يسمى المنطقة «الصومال الفرنسي».
- **1896:** سكة حديد جيبوتي–أديس أبابا (1897) → مركز تجاري + ميناء رئيسي لإثيوبيا.

### المقاومة + النضال الوطني
- **1940ات:** مقاومة + تدمير منشآت فرنسية (إحتجاج ضد دعم إسرائيل في حرب 1956).
- **1950:** مجلس تشريعي (نصفه صوماليون + نصفه أجانب) + فوز حزب الإتحاد الجمهوري.
- **1956:** إستفتاء (رفض دستور ديجول بنسبة 75% حسب الرواية الصومالية — فرنسا تدعي المؤيد) + مظاهرات.
- **1958:** إنتخاب محمود حربي للجمعية الفرنسية + مقاومة + مطالبة بالاستقلال.
- **1966:** مظاهرات ضد زيارة شارل ديجول + مطالبة بالاستقلال.
- **1967 (مارس):** إستفتاء (60% للبقاء مع فرنسا) + تغيير الاسم → «العفر والعيسى الفرنسي» + تعديل الحكم (مفوض سامي + مجلس حكومة 9 أعضاء).
- **1970ات:** تصاعد المقاومة + تأسيس الأحزاب (الحركة الإستقلالية + الحركة الإشتراكية).
- **1975:** فرنسا تبدأ في التفاوض على الإستقلال.
- **1977 (8 مايو):** إستفتاء (98.8% للاستقلال) → **27 يونيو 1977: الإستقلال** + تأسيس جمهورية جيبوتي.

> 🟢 *حقيقة موثقة*: جيبوتي آخر مستعمرة فرنسية تحصل على الإستقلال في أفريقيا.

## 3. الإستقلال + الأنظمة المعاصرة (1977–الآن) 🟢

### حسن غوليد أبتيدون (1977–1999) 🟢
- **أول رئيس** + زعيم حركة الإستقلال.
- **1979:** تأسيس «التجمع الشعبي من أجل التقدم» (RPP) — حزب الواحد.
- **1981:** الحزب الواحد رسميًّا (دستور جديد).
- **1991 (نوفمبر):** حرب أهلية بين العفر + عيسى (جبهة عفار لاستعادة الوحدة — FRUD) — أنتهت بسلام 2001.

### إسماعيل عمر غيلي (1999–الآن) 🟢
- **1999:** انتخابات + إنهاء حزب الواحد + تعيين غيلي رئيسًا.
- **2000ات:** إصلاحات + تخصيص + ديون + شركة الصين (دوراليه + 2012).
- **2005:** إعادة انتخاب غيلي + توترات مع جيبوتي (حزب الواحد سابقًا).
- **2010:** إعادة انتخاب (الترشح لفترة ثالثة — تعديل دستوري 2011).
- **2013:** مبادرة «الحزام والطريق» الصينية + منطقة التجارة الحرة.
- **2016:** إنشاء ميناء دوراليه متعدد الأغراض (590 مليون $) + سكة حديد كهربائي إلى إثيوبيا.
- **2017 (أغسطس):** القاعدة العسكرية الصينية (أول قاعدة صينية في الخارج).
- **2018:** إنهاء اتفاقية دوراليه مع موانئ دبي (إستيلاء حكومي) + خلاف قانوني.
- **2021:** إنشاء محطة حاويات دوراليه (الصين).
- **2024:** تعيين عبد القادر كميل محمد رئيس وزراء + إتفاقيات إقتصادية أفريقية.

## 5. الأحداث الجارية (2001–2024) 🟢
- **2001:** إتفاق سلام بين الحكومة + جبهة عفار (إنهاء الحرب الأهلية).
- **2003:** إنشاء إقليم عرتا (آخر تعديل إداري).
- **2010:** تعديل دستوري (ترشح غيلي لفترة ثالثة).
- **2013:** مبادرة «الحزام والطريق» + إنشاء منطقة التجارة الحرة.
- **2017:** القاعدة الصينية + سكة حديد كهربائي.
- **2018:** إنهاء اتفاقية دوراليه مع دبي + خلاف قانوني.
- **2021:** محطة حاويات دوراليه (الصين).
- **2024:** تعيين رئيس وزراء جديد + إتفاقيات إقتصادية أفريقية.

## 7. ملاحظة: التركيبة السياسية 🟢
- جيبوتي تحتفظ باستقرار سياسي نسبي + توازن عرقي (عيسى × عفار) + حزب واحد سابق + تعددية حزبية.
