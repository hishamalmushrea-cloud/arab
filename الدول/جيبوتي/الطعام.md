# المطبخ الجيبوتي

> مطبخ جيبوتي يجمع التأثيرات الصومالية + العفرية + اليمنية + الفرنسية + الهندية. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. نظرة عامة
- المطبخ الجيبوتي = **مزيج صومالي + عفاري + يمني + فرنسي + هندي (بهارات)**.
- يعتمد على: **السمك** (ساحل — مشوي) + **اللحوم** (ماعز + ضأن + بقر + **جمل**) + **خبز الإنجيرا/اللاهوه** + **الأرز** + **البهارات** (الزعفران + القرفة + الهيل + الكمون + الكزبرة) + **القهوة (بونا)** + **الشاي (شاه)**.
- **حلال إسلامي:** لا خنزير + لا كحول + لا ميتة — الشعائر الدينية.
- **القات:** ثقافة اجتماعية — السهرات (الرمضان) + أكبر مستورد.

## 2. الأطباق الرئيسية 🟢

### السمك اليمني المشوي — الطبق الوطني 🟢
- **سمك مشوي** بالتنور اليمني (موفا) — يُفتح إلى نصفين + يُطهى في الفرن — **الطبق الوطني** لجيبوتي.
- تأثير يمني (التجار اليمنيين — مطاعم يمنية في جيبوتي) + شعبي جدًّا.
- يُقدَّم مع الخبز اليمني الساخن + صلصة السحاوق الحارة + الجبن.

### الإنجيرا/اللاهوه (Injera/Lahoh) — الخبز 🟢
- **خبز مسطح إسفنجي مخمّر** (بطعم حامض) — من دقيق التيف (إثيوبي) — يُقدَّم مع اليخنات.
- تأثير إثيوبي (تجاور + الحدود + تجار).

### السمبوسة (Sambusa) 🟢
- **فطيرة مثلثية مقلية** محشوة بـ: اللحم المفروم + العدس + الخضار + البصل + البهارات.
- شعبية + رمضان + تأثير هندي/عربي/صومالي.

### اليخنات (Maraq/Wat) — الحساء 🟢
- **حساء لحم/خضار** + بهارات — يُقدَّم مع الأرز + الإنجيرا.
- «وات» (Wat) = حساء لحم بقري مسلوق حار.
- «فاه-فاه» (Fah-Fah) = حساء تقليدي حار.
- «Yetakelt wet» = حساء خضار مختلطة حار.

### سوقار (Suqaar) — اللحم المشوي/المقلي 🟢
- **لحم دجاج/بقر مقلّى + خضار + بهارات** — تذبيلة.

### جاروبي (Garoubi) — العصيدة 🟡
- **عصيدة بنقع الشوفان في الحليب + كمون/بهارات** — طبق رئيسي.

### باجيوس (Bajiyos) — فطائر العدس 🟢
- **فطائر العدس المقلية** (نسخة الباكورا الهندية) — رمضان + مع الشاي.
- شعبية + في الشوارع + المحلات.

---

## 3. الأطباق الأخرى 🟢
- **البرياني (Bariis):** أرز + لحم + توابل — أشهر أطباق الأرز.
- **الكبدة:** لحم بقر + بصل + زيت + بطاطا — مع خبز اللحوح/الأنجيرا.
- **العدس + الأرز:** طبق جانبي — مع الصلصات.
- **الموز (Moos):** يُقدَّم مع كل وجبة (تأثير صومالي) — رمز غذائي.
- **القرع العسل:** قرع محلى بالعسل — رمضان.
- **اللحم بالعسل والسمن:** وجبة تقليدية (بدو) — مع الشاي.
- **السمك المشوي + السمك المقلي + السمك المقدد.**
- **أطباق بحرية:** تونة + أسماك هندية + أسماك المحيط.

---

## 4. المشروبات 🟢
- **الشاي (الشاه):** شاي + حليب + سكر + هيل + قرفة + زنجبيل — المشروب الوطني + طقس اجتماعي.
- **القهوة (البونا):** قهوة + هيل + زنجبيل — إرث عربي + يمني.
- **القهوة الحبشية:** قهوة + بهارات (تأثير إثيوبي).
- **اللبن + اللبن المخيض.**
- **عصير المانجو (المانجو) + غافا (الجوافة) + الموز (الموس) + التمر الهندي (عرديب) + الكركديه (البيسام).**
- **القات:** «الإفطار» + رمضان + السهرات + الجلسات الإنشاد — أكبر مستورد + ثقافة اجتماعية + السهر (القرض + الفطور).

---

## 5. الأطعمة والمناسبات 🟢
- **رمضان:** السمبوسة + الإنجيرا + الحساء + القات + حليب + الشاي.
- **الأعراس:** البرياني + اللحم المشوي + الموز + الشاي + القات.
- **العيد:** اللحم المشوي + الأرز + الكنترة (اللاهوه) + القات.
- **الضيافة:** القات + الشاي + القهوة (كرم).

---

## 6. ربط الطعام بالجغرافيا والثقافة
- **الساحل + البحر الأحمر + خليج عدن + خليج تاجورة** → السمك (مشوي بالتنور) + الصيد + الميناء + مدن مينائية (أبوك + تاجورة + جيبوتي) + التجار اليمنيين (السمك اليمني — الطبق الوطني). 🟢
- **السهول + السافانا + البدو** (العفر + عيسى) → اللحوم (الماعز + الضأن + **الجمل**) + المكاوييس + القات + البهارات + التكيف مع الجفاف. 🟢
- **الموقع المعبري** (إثيوبيا/اليمن/الصومال) → تأثيرات: إثيوبية (الإنجيرا + القهوة الحبشية + اليخنات) + يمنية (السمك المشوي + الخبز + السحاوق) + صومالية (السمبوسة + الموز + الباستو) + عربية (البهارات + الإنجيرا) + هندية (الباجيوس + السمبوسة + الكنترة).
- **الإسلام** → الحلال + لا خنزير/كحول + القات (السهرات) + الشعائر الدينية.
- **الإستعمار الفرنسي** (1862–1977) → الخبز الفرنسي + القهوة + الصلصات + المعجنات (إرث فرنسي).
- **الجوار الجغرافي** (إثيوبيا + اليمن + الصومال) → مطبخ هجين متعدد الأصول + تأثيرات متبادلة.
