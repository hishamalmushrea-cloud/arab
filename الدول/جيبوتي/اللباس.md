# اللباس في جمهورية جيبوتي

> لباس جيبوتي يجمع التأثيرات الصومالية + العفرية + العربية + الفرنسية + الإسلامية. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. نظرة عامة
- اللباس التقليدي = **محتشم + خفيف + مكيِّف مع الحر** (ألوان فاتحة + أقمشة خفيفة) + **الإسلام** (حشمة).
- زي متنوع عبر القوميتين (صومالي + عفر) + مناطق + تأثيرات خارجية (عربية + فرنسية).
- **اللباس الحديث** منتشر في المدن (أروبي + عربي خليجي).

---

## 2. اللباس الرجالي 🟢

### المكاوييس (Macawiis / Ma'awiis) — إرث صومالي 🟢
- **وشاح/ثوب طويل** (يشبه السارونغ) يُلَف حول الخصر + ألوان متعددة + أقمشة قطنية خفيفة.
- متكيِّف مع الحر + البدو + الرعي — مريح.
- يُرتدى مع قميص خفيف + أحيانًا وشاح على الكتف (حماية من الشمس/الريح).

### الثوب/الخميص (Khamiis / Thawb) — إرث عربي 🟢
- **ثوب طويل أبيض** إلى الكاحل (يشبه الثوب الخليجي) — زي رسمي/ديني.
- يُرتدى في المناسبات (الأعراس + الجنائز + العيد + الجمعة).
- تأثير الثقافة العربية + الإسلام.

### الكوفية/الطاقية (Koofiyad) — رأس 🟢
- **طاقية صغيرة مطرَّزة** (taqiyah) — تغطي الرأس + رمز اجتماعي/ديني.
- أحيانًا **عمامة/ turbans** ملوَّنة — رمز مكانة/احترام.

### ثوب العفر (Afar dress) — إرث عفاري 🟡
- **ثوب/وشاح عفاري** — يُلَف حول الجسم — ألوان + تصاميم خاصة.
- متكيِّف مع الحر + الرعي + البيئة الصحراوية.

### الإكسسوارات
- **السيف/الحربة:** في المناسبات (إرث بدوي).
- **العكاز:** رمز الهيبة.
- **السبحة:** للشيوخ (إرث صوفي).

---

## 3. اللباس النسائي 🟢

### الديراك (Dirac) — إرث صومالي 🟢
- **فستان طويل خفيف شفاف** من قماش ملوَّن + مطرَّز + لمعان.
- **ألوان نابضة بالحياة** + أنماط + مطبوعات.
- يُرتدى في **المناسبات** (الأعراس + العيد + الاستقلال) + رمز الأناقة + النعمة + الأنوثة.
- تأثير صومالي (يعود للأصل اليمني/الإثيوبي).

### الغارباسار (Garbasaar) — التنورة الداخلية 🟢
- **فستان طويل متدفق غير شفاف** (تحت الديراك) — الطبقة الأساسية.
- يُنسَّق مع الديراك.

### القورقوراد (Gorgorad) — التنورة الحريرية 🟡
- **تنورة حرير** (petticoat) تحت الديراك — أناقة + راحة.

### الشال/الحجاب — إرث إسلامي 🟢
- **شال** على الكتف/الرأس — حشمة + إسلام.
- **الحجاب:** رمز ديني + حشمة (تأثير إسلامي/عربي).

### لباس العفر النسائي — إرث عفاري 🟡
- **ثوب/وشاح عفاري** ملوَّن — يُرتدى في مناطق العفر.
- تأثير ثقافي عفاري.

### الإكسسوارات النسائية 🟢
- **الذهب:** قلائد + خلخال + أساور + خواتم — رمز الرخاء + السعادة (الأعراس).
- **الحناء:** في الأعراس + الموالد.
- **الكحل:** للعين (تجميل).

---

## 4. اللباس الحديث 🟢
- **اللباس الأروبي** (القمصان + البناطيل + الفساتين) — منتشر في المدن + الأعمال + الشباب.
- **الديراك + الغارباسار + المكاوييس** تبقى للجمعة + المناسبات + الأعراس + العيد.
- **الحجاب + النقاب:** انتشار (نساء محافظات — تأثير إسلامي/خليجي).
- **اللباس الفرنسي:** إرث استعماري (القمصان + التنورة + المعجنات).

---

## 5. اللباس حسب المناطق والقوميات 🟡
- **صوماليون (عيسى — جنوب + شرق + عاصمة):** المكاوييس + الديراك + الغارباسار (تأثير صومالي/يمني).
- **عفر (شمال + غرب + وسط):** ثوب العفر + وشاح ملوَّن (تأثير عفاري).
- **عرب (يمنيون + عمانيون — ساحل + مدن):** الثوب/الخميص + العمامة + الحجاب (إرث عربي).
- **مدن + عاصمة:** لباس أروبي + فرنسي (إرث استعماري) + حديث.

---

## 6. ربط اللباس بالجغرافيا والثقافة
- **الحر الشديد + الجفاف + الشمس** → المكاوييس (خفيف + قطني + تهوية) + الديراك (خفيف + فضفاض) + الكوفية (حماية الرأس) + ألوان فاتحة + ثوب العفر (خفيف). 🟢
- **الإسلام + المحتشام** → الثوب/الخميص (أبيض + حشمة) + الحجاب + الشال + الكوفية + الكحل + الحناء.
- **البدو + الرعي + الصحراء** (العفر + عيسى) → المكاوييس (سارونغ — عملي للتنقل) + ثوب العفر + السيف + النعل.
- **الموقع المعبري** (إثيوبيا/اليمن/الصومال) → الديراك/الغارباسار (إرث يمني/إثيوبي — صومالي) + الثوب/الخميص (إرث عربي) + ثوب العفر (إرث عفاري) + تأثيرات متبادلة.
- **الإستعمار الفرنسي** (1862–1977) → اللباس الفرنسي (قمصان + بناطيل + معجنات) + إرث استعماري.
- **التجارة التاريخية** (اليمن + إثيوبيا + الصومال + الجزيرة العربية) → استيراد الأقمشة من الهند + اليمن + فرنسا.
- **الكرم + الضيافة** → الديراك المزخرف الملوَّن (للمناسبات) + الذهب (إظهار للكرم).
