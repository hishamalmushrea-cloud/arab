# الشخصيات والآثار في جمهورية جيبوتي

> رؤساء + زعامات دينية + أعلام + بحيرات + ميناء + قواعد عسكرية. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر.

---

## 1. رؤساء جيبوتي المعاصرين 🟢

### حسن غوليد أبتيدون (1916–2006) 🟢
- **الرئيس المؤسس** (1977–1999) — زعيم حركة الإستقلال.
- من قومية **العيسى** (صومالي) — أول رئيس بعد الاستقلال 27 يونيو 1977. ليست نسبة إلى إقليم عفر الشمالي. 🟢
- أسس «التجمع الشعبي من أجل التقدم» (RPP) + حزب الواحد (1981).
- أُعيد انتخاب 1993 + 1999 (تنازل).

### إسماعيل عمر جيلي (1949–) 🟢
- **الحالي** (1999–الآن) — من قومية **العيسى** (صومالي). 🟢
- انتخابات 1999 + 2005 + 2010 + 2016 (تعديل دستوري 2011 للترشح الثالث) + 2024 (مع توترات).
- إصلاحات + تخصيص + ديون + الصين (دوراليه + 2012) + القاعدة الصينية (2017) + منطقة التجارة الحرة (2018).
- إتفاقيات إقتصادية أفريقية (2024).

### أحمد ديني أحمد 🟢
- **رئيس وزراء** (27 يونيو 1977–12 يوليو 1977) — انتقالي — من قومية العفر.

### عبد القادر كميل محمد 🟢
- **رئيس وزراء** (2024–الآن) — تعيين.

## 2. أعلام دينيون + زعامات 🟢

### محمود حربي 🟢
- **زعيم النضال الوطني** (1950ات) — انتخابات الجمعية الفرنسية 1956 + مقاومة.
- ضد دستور ديجول + مطالبة بالإستقلال.

### شيوخ الطرق الصوفية 🟢
- **الشيخ عبد القادر الجيلاني:** مؤسس الطريقة القادرية (إرث إسلامي — الأكثر انتشارًا).
- **الشيخ أحمد بن إدريس:** مؤسس الطريقة الأحمدية (الأشراف).
- **الشيخ علي صالح:** مؤسس الطريقة الصالحية (بعالية).

### سلاطين العفر التاريخيون 🟡
- **راييتا ديني أحمد:** زعيم عفر — باع ميناء أبوك لفرنسا (1862).
- **سلطنة عفت + سلطنة تاجورة:** سلاطين عفر حكموا مناطق (إرث سياسي).

## 3. أعلام ثقافيون 🟢
- **محمود أحمد:** مطرب صومالي (قيثارة + موسيقى).
- **أعلام عفر:** مطربون + شعراء + كتاب.
- **شعراء جيبوتيون:** شعر صومالي (غنائي) + عفاري + فرنسي.

## 4. المواقع الطبيعية — البحيرات + الجبال 🟢

### بحيرة عسل (Lake Assal) 🟢
- **أنخفض نقطة في أفريقيا** (-155م تحت مستوى البحر) — ثالث أنخفض في العالم (بعد البحر الميت + بحيرة طبريا).
- **أكبر احتياطي ملح في العالم** + استغلال + مركز سياحي.
- مركز جيبوتي + غرب خليج تاجورة + ~120 كم غرب العاصمة.
- ملوحة 10 أضعاف مياه البحر + لا مصب لها (تبخر).

### بحيرة أبي (Lake Abbe) 🟢
- **بحيرة ملحية** على حدود إثيوبيا — براكين + مداخن (أعمدة كلسية) — استقطاب سياحي + علمي.
- نهر أواش (إثيوبيا) يصب فيها + «منطقة الحفرة العفرية» (التقاء الصفائح التكتونية).

### جبل موسى علي (Moussa Ali) 🟢
- **أعلى نقطة في جيبوتي** (2,063 م) — على حدود إرتريا/إثيوبيا.
- هضاب + مرتفعات + براكين.

### بحيرات أخرى 🟡
- غوباد + أفا-دمبو + غوماري + باريو (محدودة).

## 5. المواقع الأثرية + الميناء 🟢🟠

### مدينة جيبوتي (العاصمة) 🟢
- **العاصمة + أكبر مدينة** (~600,000) + الميناء الرئيسي + المطار الدولي + مقر الحكومة.
- **التاريخ:** تأسست 1888 (الفرنسيون) + مقر الإدارة الاستعمارية + السكة الحديدية.
- **المعالم:** الميناء القديم + المطار + السفارات + السكة الحديدية + الشوارع الفرنسية.

### أبوك (Obock) 🟢
- **مدينة مينائية تاريخية** (شمال) + مدخل البحر الأحمر + مقر الإدارة الفرنسية الأوى (1862–1894).
- «أرض عفار وعيسى الفرنسي» (إرث استعماري) — أول عاصمة.
- مطار أمبولي الدولي في **مدينة جيبوتي** (ليس أوبوك).

### تاجورة (Tadjoura) 🟢
- **مدينة مينائية تاريخية** (شمال غرب) + خليج تاجورة + ميناء + سلطنة تاجورة التاريخية.
- **المعالم:** الميناء + آثار السلطنة + الشوارع التاريخية + المساجد.

### علي صبيح (Ali Sabieh) 🟢
- **ثانية أكبر مدن** + حدود إثيوبيا + مركز تجاري + ربط.

### دخيل (Dikhil) 🟡
- **مدينة جنوب غرب** + بحيرة أبي + مركز إداري + حدود إثيوبيا.

### عرتا (Arta) 🟢
- **مدينة شمال** + الجبال + مركز إداري (إقليم منذ 2003).

## 6. الميناء + القواعد العسكرية 🟢🟠

### ميناء جيبوتي + دوراليه
- **ميناء جيبوتي:** العاصمة + الميناء الرئيسي + بوابة إثيوبيا (~90% من وارداتها) + ~70% من الناتج.
- **ميناء دوراليه متعدد الأغراض:** الصين (590 مليون $ — 2012) + أكبر ميناء للمياه العميقة + 2018.
- **محطة حاويات دوراليه:** الصين (2021) — رسوم الشحن.
- **منطقة التجارة الحرة (DFTZ):** الصين (3.5 مليار $ — 2018) — أكبر منطقة تجارة حرة في أفريقيا.

### القواعد العسكرية الأجنبية (6 دول) 🟢
- **فرنسا:** أكبر قاعدة فرنسية في أفريقيا (إرث استعمار — 1977).
- **أميركا:** **ليمونييه** — أكبر قاعدة أميركية في أفريقيا (~4,000 جندي — استراتيجي).
- **الصين:** أول قاعدة صينية في الخارج (2017 — 1,000 جندي — قرب دوراليه).
- **اليابان:** قاعدة يابانية (~600 جندي).
- **إيطاليا:** قاعدة إيطالية.
- **السعودية:** قاعدة (تحت الإنشاء — 2019).

> 🟢 «وكر لجواسيس العالم» (BBC) — بدل مادي + إجار = ~20% من الناتج + حماية أمنية + استقرار.

## 8. ربط الآثار بالتاريخ والجغرافيا
- **الموقع الاستراتيجي** (باب المندب + خليج عدن) → القواعد العسكرية (6 دول) + الميناء + الترانزيت + التجار العرب + «وكر لجواسيس العالم» (BBC). 🟢
- **البحر الأحمر + خليج تاجورة + خليج عدن** → مدن مينائية تاريخية (أبوك + تاجورة + جيبوتي) + السلطنات العفرية (عفت + تاجورة) + الصيد + التجارة + الإسلام (القرن 8). 🟢
- **الإستعمار الفرنسي** (1862–1977) → العمارة الفرنسية + الميناء + السكة الحديدية + المطار + اللباس الفرنسي + القهوة + المسيحية ~6% + الإرث الفرنسي.
- **الإسلام + التجار العرب** (القرن 8) → الإسلام ~94% + العربية لغة رسمية + الشافعية + الصوفية (قادرية) + الأنساب العربية (عيسى + عفر — روايات) + المساجد.
- **الصحراء + البراكين + بحيرات** (عسل + أبي) → تضاريس فريدة + أنخفض نقطة (-155م) + أعلى نقطة (2,063م) + جيولوجيا فعالة (التقاء الصفائح التكتونية) + سياحة طبيعية.
- **الصين** (2010ات) → ميناء دوراليه + منطقة التجارة الحرة + سكة حديد + القاعدة العسكرية + كابلات هواوي + مخاوف أميركية + خلاف مع الإمارات.
- **التركيبة العرقية المركّبة + التوازن** (صومالي 60% + عفر 35% + عرب 5%) → استقرار سياسي + حرب أهلية 1991 + سلام 2001 + إقليم عرتا 2003.
