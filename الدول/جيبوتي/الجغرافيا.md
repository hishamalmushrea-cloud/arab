# جغرافيا جمهورية جيبوتي

> علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. الموقع والمساحة
- **الموقع:** القرن الإفريقي — على البحر الأحمر + خليج عدن + باب المندب.
- **الإحداثيات:** 11°35′–12°N ، 42°26′–43°E.
- **المساحة:** **23,200 كم²** في المراجع الشائعة 🟡 — **ليست** أصغر دولة عربية (البحرين ثم جزر القمر أصغر).
- **الموقع الاستراتيجي:** **باب المندب** — يمر عبره ~10–12% من التجارة العالمية + صادرات الخليج النفطية. 🟢

## 2. التضاريس
- عمومًا: **سهول صحراوية + هضاب + براكين + سهول ساحلية** — تضاريس منخفضة مع هضاب.
- **أعلى نقطة:** **جبل موسى علي (Moussa Ali — 2,063 م)** — على حدود إرتريا/إثيوبيا. 🟢
- **أنخفض نقطة في أفريقيا:** **بحيرة عسل (Lake Assal — -155م تحت مستوى البحر)** — ثالث أنخفض في العالم (بعد البحر الميت + بحيرة طبريا) + أكبر احتياطي ملح في العالم. 🟢
- **خليج تاجورة (Gulf of Tadjoura):** ذراع من البحر الأحمر يقطع البلاد شمالًا + ميناء تاريخي.
- **خليج عدن:** جنوب.
- **بحيرة أبي (Lake Abbe):** براكين + مداخن (أعمدة كلسية) + حدود إثيوبيا + نهر أواش يصب فيها.
- **بحيرات أخرى:** غوباد + أفا-دمبو + غوماري + باريو.
- لا أنهار دائمة (كلها أودية موسمية — wadis).

## 3. المناخ 🟢
- **تصنيف كوبن:** **BWh** (صحراوي حار) — حار جدًّا + جاف + أمطار نادرة (<130 مم).
- **الصيف (مايو–سبتمبر):** حار جدًّا >40°م (قد يصل >50°م في الدناقل) + رطب ساحليًا.
- **الشتاء (أكتوبر–مارس):** معتدل 25–30°م + ليالي أبرد (في المرتفعات).
- **الأمطار:** <130 مم (نادرة) — أبريل الأكثر (28.9 مم) + يونيو الأجف (0.1 مم).
- **الرياح:** شمالية + شمالية شرقية + موسمية.
- **البحر الأحمر + خليج عدن:** تأثير بحري (رطب ساحلي).
- **تغير المناخ:** ارتفاع البحر + جفاف + أمطار متطرفة.

## 4. الموارد المائية
- **لا أنهار دائمة** (كلها أودية موسمية — wadis).
- **مياه جوفية** محدودة + آبار + ينابيع (تاريخية).
- **تحلية** محدودة (جيبوتي + أبوك + تاجورة).
- **بحيرات:** عسل + أبي + غوباد + أفا-دمبو + غوماري + باريو.
- 🟢 الموقع + باب المندب = مركز تجاري + لوجستي + قواعد عسكرية + تأثيرات جيو-استراتيجية.

## 5. التربة والغطاء النباتي
- **التربة:** رملية + حصوية (سهول) + بركانية (هضاب) + ملحية (بحيرات).
- **الغطاء:** صحراوي (شيح + عوسج + رتم) + أعشاب شوكية + نادرة.
- **واحات:** نخيل (وادي أبي + أودية).
- الغطاء نادر جدًّا + زحف الصحراء.

## 6. الموارد الطبيعية
- **الملح:** بحيرة عسل = أكبر احتياطي ملح في العالم + استغلال.
- **الطاقة الجيوحرارية:** مصادر حرارية + براكين + مداخن (إمكانيات).
- **الصيد:** ساحل غني بالأسماك (البحر الأحمر + خليج عدن + خليج تاجورة) — تونة + أسماك.
- **الثروة الحيوانية:** أغنام + ماعز + إبل (رعاة بدو).
- **النفط + الغاز:** مكتشفات بعالية (لم تُستغل).
- **المعادن:** محدودة + جبس + فوسفات.

## 7. المناطق الطبيعية والمحميات
- **بحيرة عسل** (أنخفض نقطة + أكبر احتياطي ملح) + جبال حولها.
- **بحيرة أبي** (براكين + مداخن) + حدود إثيوبيا.
- **خليج تاجورة** (ذراع بحري) + ميناء + شعاب مرجانية.
- **جبال موسى علي** (أعلى نقطة) + هضاب + مرتفعات.
- **ساحل البحر الأحمر** (أبوك + جيبوتي + تاجورة) — شواطئ + غوص.
- **محمية داي فورست** (غابة + حيوانات نادرة) + محميات أخرى.

## 8. النقل والربط
- **الموانئ:** جيبوتي (العاصمة — الرئيسي) + دوراليه (الصين) + أبوك (تاريخي) + تاجورة.
- **المطارات:** أمبولي الدولي (**مدينة جيبوتي**) + مهابط داخلية (أوبوك وغيرها). لا يُنسب المطار الدولي إلى أوبوك.
- **الطرق:** جيبوتي–أديس أبابا (إثيوبيا) + جيبوتي–علي صبيح + جيبوتي–تاجورة.
- **السكة الحديدية:** جيبوتي–أديس أبابا (تاريخية — الكهربائي) — خط النقل الرئيسي لإثيوبيا.
- **خط أنابيب:** من إثيوبيا (مياه).
- **الموقع + باب المندب** → مركز لوجستي + تجارة عبور + قواعد عسكرية + ميناء رئيسي.

## 9. ربط الجغرافيا بالثقافة (رؤية تطبيقية)
- **الموقع الاستراتيجي** (باب المندب + خليج عدن) → ثقافة تجارية + مركز لوجستي + قواعد عسكرية (6 دول) + ميناء + سكة حديد. 🟢
- **الصحراء + الحر + الجفاف** → حياة بدوية رعوية + المكاوييس (ثوب خفيف) + الواحات + التكيف مع البيئة القاسية. 🟢
- **البحر الأحمر + خليج تاجورة + خليج عدن** → ثقافة بحرية + صيد + تجارة + الميناء + أبوك/تاجورة (مدن مينائية تاريخية).
- **البراكين + بحيرة أبي + بحيرة عسل** → تضاريس فريدة + أنخفض نقطة + مناخ حار + جيولوجيا فعالة (التقاء الصفائح التكتونية).
- **الموقع المعبري** (إثيوبيا/إرتريا/الصومال/اليمن) → ثقافة هجينة + هجرات عربية + تجارة + القواعد العسكرية + تأثير فرنسي (الإستعمار).
- **إثيوبيا بدون ساحل** → جيبوتي بوابة إثيوبيا (~90% من وارداتها) + مركز تجاري.
