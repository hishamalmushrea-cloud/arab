# اللهجات في جمهورية جيبوتي

> جيبوتي بلد متعدد اللغات: رسميتان (عربية + فرنسية) + وطنيتان (عفرية + صومالية). علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. نظرة عامة
- اللغات الرسمية: **العربية + الفرنسية**. 🟢
- اللغات الوطنية (الأم): **العفرية (Afar) + الصومالية (Somali)** — كلاهما كوشية (أفروآسيوية).
- **الدين:** الإسلام ~94% → العربية لغة الدين + القرآن + الثقافة.
- جيبوتي بلد متعدد اللغات (4 لغات رئيسية + لهجات + تأثيرات).

## 2. اللغات الرئيسية 🟢

### أ. العفرية (Afar language)
- من الأسرة الكوشية (أفروآسيوية) — كوشية شرقية.
- يتحدث بها **العفر** (35% من السكان) — شمال + غرب + وسط.
- الانتشار: جيبوتي + إثيوبيا (عفار) + إرتريا.
- **التأثير العربي:** مزيج عربي (سامي) + كوشي (حامي) — نتيجة هجرات + مصاهرات عرب من قحطان اليمن.
- **الخصائص:** لغة إلصاقية + أصوات حلقية (c, q, x) + نطق خاص (الحروف الحلقية).

### ب. الصومالية (Somali language)
- من الأسرة الكوشية (أفروآسيوية) — كوشية شرقية.
- يتحدث بها **الصوماليون** (60% من السكان — عيسى) — جنوب + شرق + عاصمة.
- الانتشار: جيبوتي + الصومال + إثيوبيا (أوغادين + هرر) + كينيا.
- **اللهجات:** محاتري (معياري — شمال/وسط) + ماي (جنوب — مستقلة عن المحاتري).
- (انظر `الصومال/اللهجات.md` للتفصيل).

## 3. التأثيرات اللغوية الخارجية 🟢

### العربية (الإسلام + التجار)
- مفردات دينية + ثقافية: «سلام» + «صلاة» + «قرآن» + «رمضان» + «زكاة» + «حج» + «محراب» + «شيخ» + «ملا» + «إمام» + «أمير» + «سطنة» + «ديوان».
- **اللهجة الجيبوتية (اللهجة التعزية-العدنية):** يتحدث بها ~59,000 كلغة أولى — تأثير عربي يمني مباشر.
- **أنساب قبائل عيسى:** إلى عرب (إراب + هبر أوال + هبر يونس + عيسى موسى + عرب + أيوب + سعد موسى + زبير — روايات شفهية.

### الفرنسية (الإستعمار 1862–1977)
- لغة الإدارة + التعليم + القضاء + الأعمال.
- يتحدث بها ~17,000 كلغة أولى + معظم النخبة + المدن.
- إرث استعماري + لغة عمل + ثقافة فرنسية.

### الإنجليزية (القواعد الأميركية + التجارة)
- لغة أعمال + تجارة + صحة + تعليم عالي + قواعد عسكرية (ليمونييه).
- منتشرة في الشركات + القطاع الخاص.

### الهندية (تجارة المحيط الهندي)
- مفردات: «بهارات» + «كمون» + «كزبرة» + «هيل» + «قرفة» + «كركم» + «أنجيرا» (canjeero) + «سمبوسة» (samusa).
- أسماء: «مانجو» (cambo) + «باباي» + «ليمن» (liin).

## 5. أمثال وتعبيرات عفرية 🟡
- «Kaa astu maleh» = نعم، شكرًا (أدب).
- «Annah tetqal?» = ماذا تقول? (استفهام).
- «Maleh galgal» = تحدث بلطف.

---

## 6. الكتابة 🟢
- **العفرية + الصومالية:** تُكتبان باللاتينية + العربية (أحيانًا).
- **العربية + الفرنسية:** الكتابة الرسمية.

## 7. الموسيقى + الفنون 🟢
- **الرقصات:** Afar dance + الصومالية (البوبلي + بنتلاند).
- **الموسيقى:** تقليدي + تأثيرات صومالية + عفرية + عربية + فرنسية.
- **الشعر:** عفاري + صومالي (غنائي).
- مطربون: محمود أحمد (صومالي) + أعلام عفر.

## 8. ربط اللهجة بالثقافة والجغرافيا
- **الموقع المعبري** (إثيوبيا/إرتريا/الصومال/اليمن + باب المندب) → تأثيرات عربية (تجار + إسلام) + هجرات + مصاهرات + الفرنسية (الإستعمار) + الهندية (تجارة المحيط الهندي) + الإنجليزية (القواعد الأميركية). 🟢
- **القرن الإفريقي + البحر الأحمر + خليج تاجورة** → ثقافة بحرية + تجارية + مدن مينائية (أبوك + تاجورة + جيبوتي) + الإسلام (القرن 8). 🟢
- **الصحراء + البدو الرعاة** (العفر + عيسى) → حياة رعوية بدوية + الإبل + الأغنام + المكاوييس + العفرية (كوشية) + الصومالية (كوشية).
- **الإسلام + التجار العرب** (القرن 8) → العربية لغة الدين + الأنساب العربية (عيسى — روايات) + المفردات الدينية + الشافعية + الصوفية.
- **الإستعمار الفرنسي** (1862–1977) → الفرنسية لغة رسمية + إدارة + تعليم + إرث.
- **القواعد الأميركية + الصينية** (2010ات) → الإنجليزية لغة أعمال + قواعد عسكرية + الإستثمارات الصينية.
- **إثيوبيا بدون ساحل** → جيبوتي بوابة إثيوبيا → تأثير ثقافي + تجاري (السمك اليمني + الإنجيرا).
