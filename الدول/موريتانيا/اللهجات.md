# اللهجات في الجمهورية الإسلامية الموريتانية

> موريتانيا بليغوية وعرقية: العربية + الأمازيغية + الإفريقية. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. نظرة عامة
- اللغة الرسمية: **العربية** (الوحيدة) + الفرنسية (لغة عمل/إرث استعمار) + الإنجليزية (محدودة). 🟢
- **الدين:** الإسلام 100% → العربية لغة الدين + التعليم + المحاضر.
- التنوع اللغوي: **الحسانية** (لهجة البيضان) + **لغات إفريقية** (ولوف + سوننكي + فولار/فلان + تكرور) + أمازيغية (بقايا صنهاجية).

## 2. اللهجة الحسانية — لهجة البيضان 🟢

- **الحسانية (Hassānīya):** لهجة بدوية مشتقة من العربية + أثر بربري صنهاجي.
- يتحدث بها **البيضان** (عرب بني حسان + أمازيغ صنهاجة) — 30% من السكان.
- **الانتشار:** موريتانيا + الصحراء الغربية + جنوب المغرب + جنوب الجزائر + شمال مالي + شمال بوركينافاسو + غرب النيجر + السنغال — «تراب البيظان» (من وادي درعة شمالًا إلى نهر السنغال جنوبًا + من المحيط غربًا إلى النيجر شرقًا). 🟢
- **التاريخ:** فرضها بني حسان (القرن 15–17) كلغة تواصل بدل البربرية الصنهاجية.
- 🟡 *رواية باحثين*: الحسانية أصلها بربري صنهاجي تأثر بالعربية (لا عربية صرفًا) — رأي أستاذ محمد سيدي محمد + بعض الباحثين.
- 🟢 الرأي الراجح: لهجة عربية بدوية مع أثر بربري.

### خصائص الحسانية 🟢
- **نطق الحروف:**
  - **الضاد:** تُنطق ظاء (أبيض → أبيظ).
  - **السين:** تُنطق صادًا أحيانًا (يصرق = يسرق).
  - **القاف:** تُنطق جيمًا مصرية (g) — لا قاف في الحسانية (أصلها الشرقي).
  - **الكاف:** معقودة (كَاف فوقها خط).
- **قواعد:**
  - **بدء الكلمات بساكن:** قبر → قْبر (بتسكين القاف).
  - **قصر التاء المربوطة:** الحجامة → الحجام (فتح الميم).
- **أبجد:** تُكتب بالعربية (في موريتانيا) أو اللاتينية (في السنغال وفق مرسوم 2005-980).

### قاموس كلمات حسانية (مختارات) 🟢🟡

| الحسانية | المعنى | الحسانية | المعنى |
|---|---|---|---|
| ماشي | ذاهب | حنش | أفعي |
| دبوس | عصي | أهل لخلة | الجن |
| جيرة | صحن | خش/أدخل | أدخل/أحكم |
| أكبظ | أمسك | الكدية | الجبل |
| يخطي عْلي | يسبني | أسم حالة | كيف |
| أسم وقت | متى | القايلة/الظهر | الظهيرة |
| السيبة | لا مبالات | الذيب | الذئب |
| النوصة/المشة/القطة | القطة | لحصيرة | الحصير |
| لخنافر | أنف | أشحالك | كيف الحال |
| اشطاري | ماذا طرأ | أهل بسم الله الرحمن الرحيم | الجن |

### تعابير شهيرة 🟢
- «الشهر مات» = انتهى الشهر.
- «اشطاري» = ما أهم الأحداث المستجدة.
- «أهل بسم الله الرحمن الرحيم» = الجن (تفائلًا).
- «أشحالك» = كيف الحال (السلام).

## 3. اللغات الإفريقية (الزنوج — 30%) 🟢

### أ. الولوف (Wolof)
- من السنغال + شمال موريتانيا (ترارزة + كوركول) — لغة نيجري-كونغو.
- يتحدث بها: الولوف في موريتانيا + السنغال + غامبيا.

### ب. السوننكي (Soninke)
- من غانا/مالي تاريخيًّا + جنوب موريتانيا.
- لغة تجارية + إفريقية.

### ج. الفولار/الفلان (Pulaar/Fulfulde)
- من فولاني + غرب أفريقيا + جنوب موريتانيا (غيديماغا).
- لغة رعاة + تجارة.

### د. التكرور (Toucouleur)
- من وادي السنغال (فوتا تورو) — هاجروا لموريتانيا (القرن 20).
- 🟡 *رواية تاريخية*: ثورة تورودو 1776 ضد البيضان.

## 4. الأمازيغية (بقايا صنهاجية) 🟡
- **الصنهاجية القديمة** اندثرت (إلا جيوب قليلة جنوب غرب — حتى القرن 17).
- أثرها في الحسانية + بعض المفردات (مثل: الكدية = الجبل — بربري).
- **الزناگية** (لغة الزوايا؟) — منقرضة.
- 🟡 *تأثير بربري* على الحسانية (الرأي الباحثي).

## 5. الفرنسية (لغة العمل) 🟢
- إرث استعمار (1904–1960).
- لغة الإدارة + التعليم العالي + الشركات + التجارة الخارجية.
- منتشرة بين النخبة + المدن.

## 6. ربط اللهجة بالثقافة والجغرافيا
- **الصحراء + البدو الرحَّل** (البيضان) → الحسانية (لهجة بدوية) + مشوي + دراعة + خيام + قوافل. 🟢
- **وادي السنغال** (الجنوب) → اللغات الإفريقية (وولوف + فولار + تكرور) + الزراعة + الحراطين.
- **الموقع الجسري** (مغرب × إفريقيا) → العربية + الأمازيغية + الإفريقية (3 طبقات) + الإسلام كمكوِّن موحِّد.
- **الإسلام + المحاضر** → العربية الفصحى (لغة الدين) + تعليم القرآن + الحسانية كلغة عامية.
- **التاريخ المرابطي + الحساني** → الحسانية حلَّت محل البربرية الصنهاجية (القرن 15–17) + وحدة لغوية للبيضان.
- **الاستعمار الفرنسي** → الفرنسية كلغة عمل (إرث) + ثنائية لغوية محدودة.
- **تنوع اللغات الإفريقية** → تعكس التنوع القبلي للزنوج (وولوف + سوننكي + فولار + تكرور) — كل له أصول تاريخية وعمق في غرب إفريقيا.
