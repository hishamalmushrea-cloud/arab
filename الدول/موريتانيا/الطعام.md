# المطبخ الموريتاني

> مطبخ موريتاني يجمع بين المغرب العربي (شمال) وإفريقيا جنوب الصحراء (جنوب) + إرث بدوي صحراوي. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. نظرة عامة
- المطبخ الموريتاني = **مزيج مغربي (شمال) + سنغالي/إفريقي (جنوب) + بدوي صحراوي**.
- يعتمد على: **اللحوم** (ضأن + جمال + ماعز + بقر) + **الأسماك** (الساحل) + **الأرز** + **الكسكس** (الدخن/القمح) + **التمر** + **الحليب/الزبدة**.
- **بسيط + سريع التحضير + قليل التوابل** — تكيف مع البيئة الصحراوية + ندرة الموارد + البدو الرحَّل.
- **كرم الضيافة** = قيمة أساسية (موائد كبيرة للمضيوفين + الغرباء).

## 2. الأطباق الرئيسية 🟢

### مارو والحوت (Thieboudienne) — الطبق الوطني 🟢
- **سمك + أرز** في صلصة حمراء/بيضاء من البندورة + خضار (جزر + باذنجان + قرع + بطاطا + بامية).
- يُسمى محليًّا «ثيبوديان» (نسخة سنغالية) — أكلة منتشرة في غرب إفريقيا.
- يُعتبر **الطبق الوطني** لموريتانيا (وللسنغال أيضًا).
- سمك القرش متبَّل + بهارات + فلفل حار + مقلي + طهي مع الخضار.

### المشوي (Méchoui) 🟢
- **لحم ضأن مشوي** على الفحم — طقس اجتماعي في الأعراس + الأعياد (الأضحى).
- طريقة بسيطة: قطع طرية (كبد + كتف + أضلاع) + ملح + فحم طبيعي.

### الكسكس الموريتاني (العيش) 🟢
- **كسكس** من دقيق الدخن/القمح/الشعير — يُقدَّم في الأعراس + الأعياد + المناسبات.
- رمز الضيافة + الكرم.
- مع مرق اللحم أو الخضار.

### المهراس (العصيدة) 🟢
- **عجينة من دقيق الذرة/القمح** + ماء + ملح — تُقدَّم مع اللبن/الزبدة.
- وجبة شتوية بدوية أصيلة — في التجمعات العائلية + الأعياد.

### مارو واللحم (Maru we-lham) 🟢
- **لحم + أرز + خضار** — يشبه مارو الحوت لكن بلحم الإبل/الضأن.

### مافي (Mahfe) 🟢
- **لحم ماعز/جمال** في صلصة من **الفول السوداني + البندورة + الفاصولياء + البامية** — يُقدَّم مع الأرز.
- نسخة نباتية متوفرة.

### ياسا (Yassa) 🟡
- **دجاج + خضار** + صلصة بصل + يُقدَّم فوق البطاطس المقلية/الأرز — إرث سنغالي (وولوف/بولار).

### بنافا (Banafa) + بونافا (Bonava) 🟡
- **لحم + بطاطس** (بنافا) + **لحم + خضار** (بونافا) — أطباق مرق.

### لاخ (Lakh) 🟢
- **خثارة الجبن/اللبن الرائب** + جوز الهند المبشور + عصيدة دخن حلوة — حلوى.

### الكسكس البلغماني + الكسكس بالمحم
- قمح مجروش + فاكهة مجففة + كسكس بلحم الغنم.

## 3. الأطباق الأخرى 🟢
- **الثريد (مارو):** خبز مفتوت + مرق لحم/خضار — أساسي في المناسبات.
- **التشطار:** لحم الغزلان المجفف (إرث رحلات البر + الصيد).
- **الكرات السمكية + السمك المقدد + سمك متبل + السمك المشوي.**
- **الجمل العربي (لحم الإبل):** الفلكة + أطاجين + بنافا.
- **جبن الكارافان (Caravane cheese):** جبن من حليب الإبل.
- **العيش + القمح المجروش + المارولايم** (لحم + أرز + خضار).
- **الحريرة:** شوربة (إرث مغربي).
- **الشباكية + البسطيلة:** حلويات/أطباق مغربية (إرث المغرب — في رمضان).

## 4. المشروبات 🟢
- **الشاي الموريتاني (الوطني الأول):** طقس يومي + طريقة تقليدية — شاي أخضر + نعناع + سكر كثير (يُسكر 3 مرات: مر +وسط + حلو).
- **الكركديه (البيسام):** من أزهار الكركديه — حامض، بارد/ساخن.
- **عصير المانجو** + **الزريك (Azreg):** حليب + ماء + سكر.
- **الحساء (الحريرة):** شوربة (رمضان).
- **اللبن + الحليب + الشاي الأخضر.**

## 5. الأطعمة والمناسبات 🟢
- **الأعراس:** الكسكس + المشوي + مارو واللحم + الشاي.
- **رمضان:** الحساء + التمر + لبن الإبل + الشاي + (طاجين لحم مشوي إن سمح الحال).
- **عيد الأضحى:** المشوي (لحم الضأن) + الكسكس.
- **الضيافة:** الكسكس + الشاي (كرم).

## 6. ربط الطعام بالجغرافيا والثقافة
- **الصحراء + البدو الرحَّل** → المشوي (لحم الضأن/الإبل) + المهراس (عصيدة) + الشاي (طقس) + قلة التوابل + قلة الخبز (يعتمد على الأرز/الكسكس لا الدقيق). 🟢
- **المحيط الأطلسي + الساحل** → مارو الحوت (الطبق الوطني — سمك + أرز) + الصيد + نواذيبو (العاصمة الاقتصادية) + الثروة السمكية + تصدير لأوروبا/آسيا.
- **وادي السنغال + الجنوب** → الأرز + التمر + الثقافة السنغالية/الإفريقية (ياسا + مافي + لاخ) + الحراطين (مزارعون).
- **الموقع الجسري** (مغرب × إفريقيا) → المطبخ مزيج مغربي + سنغالي + بدوي صحراوي — الشباكية/البسطيلة (مغربي) + ياسا/مافي (سنغالي) + المشوي/المهراس (بدوي).
- **ندرة الموارد + الجفاف** → أطباق بسيطة + سريعة + مكتفية بالمتوفر (لحم + أرز + دقيق + حليب) + قلة البهارات.
- **كرم الضيافة** → موائد كبيرة + وجبات غنية بالطاقة (لحوم + حليب + دقيق) — قيمة أساسية في الثقافة.
- **الهارماتان + قلة الموارد** → تجفيف اللحم (التشطار) + تجفيف السمك + تخزين التمر — للرحلات الطويلة.
