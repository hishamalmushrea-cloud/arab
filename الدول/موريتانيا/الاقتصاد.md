## 2. التعدين — عصب الاقتصاد 🟢

### الحديد (أكبر منتج عربي) 🟢
- **خام الحديد:** عالي الجودة — أكبر منتج عربي للحديد + ثاني أكبر منتج أفريقي (13 مليون طن 2022).
- شركة **سنيم (SNIM)** الوطنية — احتكار إنتاج/تصدير الحديد.
- **منجم أتوماي** (الجديد) — 25–28 مليون طن سنويًّا + مصنع تكوير بجنوب نواذيبو + سكة حديد 640 كم.
- **كدية الجِل** (915 م) — أعلى نقطة + قطعة هماتيت.
- يساهم التعدين بـ**24% من الناتج** (2022) + ثاني أكبر قطاع تصديري.
- الطموح: مضاعفة إنتاج الحديد إلى >45 مليون طن بحلول 2030.

### الذهب 🟢
- **620.8 ألف أوقية** (2022) + إنتاج تقليدي صاعد + منقبين تقليديين.
- شركة «تازيازت موريتانيا» + تنظيم القطاع.
- احتياطيات كبيرة + فرص استثمار.

### النحاس + الفوسفات + الجبس + الملح + الفضة
- موارد متنوعة + استكشافات + استثمارات.

---

## 3. الصيد البحري — ثاني أكبر قطاع 🟢
- **~50% من إجمالي الصادرات** (تقليدي + صناعي).
- شواطئ موريتانيا من **أغنى شواطئ العالم بالأسماك** (نواذيبو + نواكشوط + اناملان + تيشيت).
- أساطيل محلية + دولية + مصانع تعليب/تجميد + تصدير لأوروبا/آسيا.
- **الصيد التقليدي:** ~80% من الإنتاج الوطني + ركيزة للأمن الغذائي (نواذيبو + اناملان + تيشيت).
- تعاون مع السنغال (مراقبة + تفتيش صحي).

---

## 4. الغاز الطبيعي — الطفرة الجديدة 🟢
- **مشروع غراند تورتو أميم (GTA):** غاز مشترك مع السنغال — بدأ الإنتاج 2025.
- **اكتشافات قبالة السواحل** الموريتانية (نفط + غاز).
- طفرة غير مسبوقة + تحوُّل من اقتصاد التعدين إلى طاقة + استدامة.
- الطموح: **الهيدروجين الأخضر** + تصدير الطاقة النظيفة (الشمس + الريح + الصحراء).

---

## 5. الطاقة المتجددة 🟢
- وصلت حصة الطاقة المتجددة إلى **34% من الاستهلاك** (2020) + خطة للوصول إلى **50% بحلول 2030**.
- مشاريع شمس + رياح + صحراء.

---

## 6. الزراعة + الثروة الحيوانية 🟢
- **الأراضي الصالحة:** ~0.5% من المساحة فقط (وادي السنغال) — محدودة.
- **المحاصيل:** الأرز + الذرة + التمر + السورغم + القمح + الدخن + الحبوب الزيتية.
- **الثروة الحيوانية:** ~110–130 مليون رأس (أبقار + ضأن + ماعز + جمال) — من أكبر قطعان أفريقيا + تصدير لحوم/حياة للسعودية/مصر/الإمارات.
- رغم ذلك: **تستورد 80% من القمح** (إمكانات كامنة مهملة).
- «سلة غذاء العالم» (محتملة) لكن قليلة الاستغلال.

---

## 7. الصناعة 🟡
- **معالجة الأسماك** + تعليب + تصدير.
- **التعدين + تكوير** (الحديد + الذهب).
- **مجمع جياد الصناعي** (سيارات + معدات — متوقف/محدود).
- **صناعة الجلود + الفخار + النسيج + الصباغة.**
- الصناعة محدودة + معظم الاستهلاك مستورد.

---

## 8. التجارة الخارجية 🟢
- **الصادرات:** الحديد (الأكبر) + الأسماك + الذهب + الثروة الحيوانية (لحوم/حياة) + الصمغ العربي (محدود).
- **الواردات:** الآلات + المعدات + النفط ومشتقاته + المواد الاستهلاكية + القمح (80%!) + الأدوية.
- **الشركاء:** الصين (الأكبر) + الاتحاد الأوروبي (فرنسا تاريخيًّا) + الإمارات + السعودية + السنغال + مالي.
- الدين الخارجي: 3.233 مليار $ (2023) — منخفض نسبيًّا.

---

## 9. السياحة والآثار 🟢🟠
- **المدن التاريخية الأربع** (يونسكو 1996): شنقيط + وادان + تيشيت + ولاته — مهرجان سنوي.
- **سياحة السفاري** (كثبان أدرار + رمال + هضاب) + رالي داكار (تاريخي — توقف).
- **سياحة بحرية** (نواذيبو + شواطئ + صيد + غوص).
- **سياحة ثقافية** (محاضر + مكتبات + مخطوطات + مساجد تاريخية).
- 🟠 تحديات: الجفاف + ندرة البنية التحتية + أمن الساحل + العزلة.

---

## 10. السياسات الاقتصادية والإصلاحات 🟢
- **رؤية استراتيجية 2030:** تنويع القاعدة الاقتصادية + تعزيز الحوكمة + الاستثمار في رأس المال البشري.
- **إصلاحات الغزواني (2019–2025):** حرية الصحافة + محاربة الفساد + مكافحة العبودية + بناء عشرات المحاكم + سلطة وطنية لمحاربة الفساد + قانون استثمار جديد + إصلاح النظام القضائي.
- **برنامج تكافل:** يغطي 128,658 أسرة فقيرة.
- **مشروع الهيدروجين الأخضر:** تصدير الطاقة النظيفة.
- **البينة التحتية:** جسر روصو مع السنغال + تطوير المدن الوسيطة + الرقمنة (الهوية الرقمية).
- 🟢 أول انتقال سلمي للسلطة (2019) — استقرار سياسي نسبي + تحسن مناخ الاستثمار.

---

## 11. التحديات والفرص 🟠
### التحديات
- الاعتماد على السلع الأولية (~80% من الصادرات) + تذبذب أسعارها.
- تأثر بالتغير المناخي (جفاف + فيضانات + زحف صحراء).
- مخاطر أمنية إقليمية (منطقة الساحل).
- بطالة الشباب المرتفعة (31%).
- العبودية الباقية (تركة اجتماعية).
- الدين العام (47.2%).

### الفرص
- الثروات الطبيعية (غاز + معادن + طاقات متجددة).
- الموقع الاستراتيجي (بوابة إفريقيا إلى أوروبا — المحيط الأطلسي).
- الاستقرار السياسي النسبي (انتقال 2019).
- طفرة الغاز GTA 2025 + الهيدروجين الأخضر.

---

## 12. ربط الاقتصاد بالجغرافيا
- **الصحراء + هضبة أدرار + كدية الجِل** (شمال) → الحديد (أكبر منتج عربي) + مناجم + سكة حديد + بدو رحَّل + سياحة سفاري + الجفاف. 🟢
- **المحيط الأطلسي** (ساحل غرب) → الصيد (50% من الصادرات) + نواذيبو (العاصمة الاقتصادية + الميناء + تصدير الحديد) + الثروة السمكية + تصدير لأوروبا/آسيا.
- **وادي السنغال** (جنوب) → الزراعة (الأراضي الصالحة الوحيدة — 0.5%) + الثروة الحيوانية + الحراطين + الأرز + التمر.
- **الموقع الجسري** (مغرب × إفريقيا) → تجارة مع المغرب + السنغال + مالي + الصين + أوروبا — بوابة عبور.
- **الإمكانات الكامنة المهملة** → «سلة غذاء العالم» محتملة + قلة الاستغلال (0.5% فقط صالح + 80% من القمح مستورد).
- **الطاقة الجديدة** (GTA 2025 + الهيدروجين الأخضر) → تحوُّل من اقتصاد التعدين إلى تنويع + الغاز.
- **الإصلاحات 2019** → تحسن مناخ الاستثمار + رؤية 2030 + نمو 6.3%.
