# الشخصيات والآثار في الجمهورية الإسلامية الموريتانية

> رؤساء + زعامات دينية + أعلام + 4 مدن تاريخية يونسكو + مساجد. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر.

---

## 1. رؤساء موريتانيا المعاصرين 🟢

### المختار ولد داداه (1924–2003) 🟢
- **الرئيس المؤسس** (1960–1978) — المحامي + أول رئيس.
- قاد الاستقلال (28 نوفمبر 1960) + فترة الحزب الواحد (الاتحاد الاشتراكي) + حرب الصحراء الغربية.
- انقلاب 1978 أطاح به (مصطفى بن محمد السالك).

### مصطفى بن محمد السالك (19378–1979) 🟢
- انقلاب 1978 + انتقالي.

### محمد خونا ولد هيداله (1940–2003) 🟢
- انقلاب 1979 + حكم 1979–1984 + توقيع اتفاقية مع البوليزاريو (1979 — انسحاب من الصحراء الغربية).

### معاوية ولد سيدي أحمد الطايع (1941–2003) 🟢
- انقلاب 1984 + حكم 1984–2005 (انتخابات 1992 + 1997) + دستور 1991 (تعددية حزبية) + تنازل 2005.

### محمد ولد عبد العزيز (1956–) 🟢
- انقلاب 2008 + انتخابات 2009 + 2014 + 2019 + دستور 2017 + محاولة انقلاب 2019 فاشلة.

### محمد ولد محمد ولد الغزواني (1956–) 🟢
- **الحالي** (1 أغسطس 2019) + أول انتقال سلمي للسلطة.
- إصلاحات: حرية الصحافة (المرتبة 1 أفريقيًّا + 33 عالميًّا 2024) + محاربة الفساد + مكافحة العبودية + الرؤية 2030 + الرقمنة + جسر روصو.

## 2. أعلام دينيون + زعامات تقاومية 🟢

### الشيخ سيديا الكبير (الترارزة) 🟢
- قاد المقاومة ضد الفرنسيين + طلب العتاد + صنع البارود («كثيب البارود») + الهجرة بعد الاحتلال.

### الأمير سيد أحمد ولد أحمد عيدة (آدرار) 🟢
- استشهد في معركة وديان الخروب (1932) — آخر قادة المقاومة المسلحة.

### محمد الحبيب (ترارزة) 🟢
- أمير ترارزة + عقد تحالفات مع إمارة والو (فوتا تورو).

### الحاج عمر تال 🟡
- قاد ثورة التكاكر (القرن 19) — أسس دولة إسلامية في غانا/مالي — تأثير على موريتانيا.

### ناصر الدين (القرن 17) 🟡
- *رواية تاريخية*: قاد الحركة الإصلاحية الثانية + غزو فوتاتورو + الوالو — توسع جنوبًا — إرث المرابطين.

## 3. أعلام ثقافيون 🟢
- **محمد ولد إبراهيم ولد السيد:** شاعر + أدبي.
- **موسى ولد إبنو:** شاعر + كاتب.
- **أحمد ولد عبد القادر:** شاعر + روائي.
- **محمد المختار ولد السيد:** شاعر حساني كبير.
- **سيدي محمد ولد بابا:** شاعر + إعلامي.
- **البروفيسور محمد المختار ولد سيدي:** أديب + سياسي + شاعر.
- **محمد فال ولد عميني:** شاعر.

## 4. مواقع التراث العالمي (يونسكو) — 4 مدن تاريخية 🟢

### المدن التاريخية الأربع (يونسكو 1996)
> مصنفة ضمن «المدن التاريخية الأربع» (quatre villes anciennes) — تراث عالمي إنساني مشترك.

### أ. شنقيط 🟢
- **المدينة الأشهر** — «بلاد شنقيط» اسم تاريخي لموريتانيا.
- **التأسيس:** القرن 13 م (8 قرون) — مستوطنة «أبير» 777 م/160 هـ → شنقيط الحالية ~1262 م/666 هـ.
- هضبة أدرار + 500 م + 400 كم شرقي المحيط.
- **الدور:** ملتقى قوافل الحج + العلم + التجارة + الفقه + المحاضر.
- **المعالم:**
  - **مسجد شنقيط العتيق** (القرن 13) — حجر جاف + مئذنة مربعة بزخارف بيض النعام — رمز معماريا وطنيًّا.
  - **5 مكتبات أصلية** بالمخطوطات النادرة (إسلاميات + علوم + أدب) — أواخر العصور الوسطى.
  - **الحي القديم** — عمارة صحراوية + حجر أحمر مصقول.
- «بلد المليون شاعر» (إرث ثقافي).
- **المؤسسة الوطنية لحماية المدن القديمة** — إدارة + ترميم.

### ب. وادان 🟢
- **التأسيس:** القرن 6 هـ/12 م — طريق القوافل (المغرب × إفريقيا) — «أقدم جامعة في الصحراء».
- شارع الأربعين (تجاري عالمي) + أم المدارس الفقهية في موريتانيا (المحاضر تفرعت منها).
- **المعالم:** مسجد وادان + المعالم الأثرية + المكتبات.
- 100 كم من شنقيط + قلب الصحراء الكبرى.

### ج. تيشيت 🟢
- **التأسيس:** القرن 12 م — واحات + صناعات جلدية + فخارية.
- **المعالم:** مسجد تيشيت + مئذنة طينية مستطيلة (من أجمل المآذن الطينية في البلاد) + طراز مغربي أندلسي + تصاميم محلية.
- بحيرة تيشيت (محمية + طيور).

### د. ولاته 🟢
- **التأسيس:** القرن 13 م — ملتقى تجاري + علمي + فكري + طريق قوافل.
- **المعالم:** مسجد ولاته + المكتبات + المخطوطات.
- وارثة على طرق القوافل + تجارة الذهب + الصمغ + العبيد.

> كلها يونسكو 1996 + مهرجان سنوي (المدن التاريخية).

## 5. المساجد التراثية 🟢
- **مسجد شنقيط العتيق** (القرن 13) — أقدم + أشهر.
- **مسجد وادان** (القرن 12) — معلم ديني في قلب الصحراء.
- **مسجد تيشيت** (القرن 12) — إرث إسلامي عريق.
- **مسجد ولاته** (القرن 13) — جوهرة أثرية في الصحراء.
- **مسجد نواذيبو الكبير** — رمز إسلامي على الساحل.
- الطراز: **مغربي أندلسي + تصاميم محلية صحراوية** — طين + حجر + مآذن مربعة.

## 6. المواقع الأثرية الأخرى 🟢
- **أوداغست (Aoudaghost):** مدينة تاريخية قديمة (القرن 10 م) — تجارة الذهب + الملح — قرب تيشيت.
- **كمبي صالح:** مدينة تاريخية (إمبراطورية غانا) — جنوب موريتانيا.
- **آزوكي (Azougui):** قاعدة الدولة اللمتونية في الصحراء (إرث المرابطين).
- **أبير:** مستوطنة شنقيط الأصلية (777 م).

## 7. المعالم الحديثة 🟢
- **قصر الرئاسة** (نواكشوط) + **البرلمان** + **المطار الدولي** (نواكشوط).
- **الميناء** (نواكشوط — صيني حديث) + **ميناء الصداقة**.
- **سكة حديد زويرات–نواذيبو** (نقل الحديد).
- **متحف نواكشوط الوطني** + **المكتبات** (شنقيط + ولاته + وادان + تيشيت).

## 8. المعالم الطبيعية 🟢
- **هضبة أدرار + كثبان** (سياحة السفاري) — شمال وسط.
- **كدية الجِل** (915 م — أعلى نقطة) — قطعة هماتيت — شمال غرب.
- **سبخة ندرهامشة** (-5 م — أنخفض نقطة) — شمال نواكشوط.
- **وادي السنغال + دلتا** (محمية دياراولينغ + طيور) — جنوب.
- **ساحل الأطلسي** (محمية البنك أرغين — رامسار) — غرب.
- **بحيرة تيشيت** (محمية + طيور) — وسط.
- **محمية الجول Loading** (السلاحف + الطيور المهاجرة).

## 9. ربط الآثار بالتاريخ والجغرافيا
- **الصحراء + هضبة أدرار + قلاع** → المدن التاريخية (شنقيط + وادان + تيشيت + ولاته) + المحاضر + المخطوطات + المساجد الطينية + طرق القوافل + التجارة + العلم. 🟢
- **الموقع الجسري** (مغرب × إفريقيا) → طراز مغربي أندلسي (المساجد) + الإسلام كمكوِّن موحِّد + ثقافة هجينة + المدن التاريخية كبؤر تلاق + تجارة + فقه.
- **التاريخ المرابطي** (القرن 11) → الإسلام + العربية + الزوايا + المحاضر + المدن التاريخية + المخطوطات.
- **إمبراطورية غانا + مالي** (الجنوب) → كمبي صالح + أوداغست + تجارة الذهب + الصمغ + العبيد — تأثير تاريخي على الجنوب.
- **إمارات بني حسان** (القرن 15–17) → إرث بدوي + الزعامات + المقاومة ضد الاستعمار + سيديا الكبير + عيدة.
- **الاستعمار الفرنسي** (1904–1960) → الحدود الحديثة + البوابة + الإرث + المقاومة (حتى 1932).
- **الاستقلال 1960 + الأنظمة** → نواكشوط (العاصمة الحديثة) + المطار + الميناء + القصر الرئاسي + التحديث.
