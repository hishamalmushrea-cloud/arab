# ولايات موريتانيا — المرحلة الرابعة (الوحدات الإدارية العُليا)

> **المرجع الإداري:** المستوى الأعلى = **ولاية** — **15 ولاية**. ليست محافظة ولا جهة مغربية ولا دائرة جزائرية. 🟢
>
> **المستوى الثاني:** **مقاطعة**. الجداول الحديثة تجرد **63** مقاطعة (2023/2024) 🟡. قوائم أقدم: 44 ثم 53–56. ثم **بلدية** (~216–218) 🟡.
>
> **مدينة نواكشوط** في `العواصم/نواكشوط/` — هنا **ثلاث ولايات** (شمالية / غربية / جنوبية) منذ مرسوم **2014-162** في **25 نوفمبر 2014**. ليست ولاية واحدة. 🟢
>
> **السكان:** تعداد المكتب الوطني للإحصاء **25 مارس 2013** (المجموع 3,537,368) أساس أوثق 🟢. أرقام **25 ديسمبر 2023** (المجموع 4,927,532) من تجميع citypopulation/ويكيبيديا عن RGPH-5 🟡 حتى يُثبَّت المنشور الرسمي الكامل.
>
> **ليست أكبر دولة عربية مساحةً.** المساحة الوطنية **1,030,700 كم²**. الجزائر أكبر عربيًا وأفريقيًا. فهرس الدولة السابق أخطأ في هذه النقطة. 🟢

## ملاحظة منهجية — لا تخلط المواقع

| المعلم | الولاية الصحيحة | ليس |
|---|---|---|
| شنقيط / وادان / آزوكي | **أدرار** | إينشيري / تكانت / أدرار الجزائر |

| كيفة | **لعصابة** | كوركول |

| سيليبابي | **غيديماغا** | لعصابة |
