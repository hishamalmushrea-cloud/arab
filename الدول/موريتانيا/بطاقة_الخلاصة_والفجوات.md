## أهم ما يميز موريتانيا

- **أكبر دولة عربية مساحةً** (1,030,700 كم²) لكن **من أقلها كثافةً** (~5 نسمة/كم²) — 3/4 المساحة صحراء.
- **جسر بين المغرب العربي وإفريقيا جنوب الصحراء** + على المحيط الأطلسي.
- **مهد حركة المرابطين** (القرن 11م) + إمبراطورية إسلامية شملت إسبانيا + المغرب + السنغال.
- **إمارات بني حسان** (القرن 15–17): آدرار + ترارزة + لبراكنة + إيدوشلي — نظام أميري قبلي.
- **أربع مدن تاريخية يونسكو (1996):** شنقيط + وادان + تيشيت + ولاته (تراث عالمي).
- **اللغة الرسمية:** العربية + **الحسانية** (لهجة البيضان البدوية) + لغات إفريقية.
- **دين الدولة:** الإسلام 100% — سُنة + مالكية + طرق صوفية (تجانية + قادرية + تيجانية).
- **العبودية:** أُلغيت قانونيًّا 1981 + جُرِّمت 2007 (آخر دولة) — تركة اجتماعية حساسة.
- **اقتصاد:** الحديد (أكبر منتج عربي) + الصيد البحري + الذهب + الغاز GTA 2025 + الثروة الحيوانية.
- **تاريخ حديث مضطرب:** استقلال 1960 → حرب الصحراء الغربية (1975–1979) → انقلابات (6 رؤساء عسكريين) → **2019** (الغزواني — أول انتقال سلمي).
- **الطبقات (تاريخية):** العرب/الزوايا/الحراطين/المعلمين/أزناگه — اندثر القانوني لكن البقايا.

## أهم المناطق

- **نواكشوط:** العاصمة + 28% من السكان + الحاضر + الإدارية + المحيط.
- **نواذيبو:** العاصمة الاقتصادية + الميناء + تصدير الحديد + أقصى الشمال الغربي.
- **أطار:** هضبة أدرار + المدن التاريخية (شنقيط + وادان).
- **تجكجة:** تكانت + وسط.
- **روصو:** ترارزة + وادي السنغال + الجنوب.
- **كيهيدي:** كوركول + الجنوب (زراعة).
- **كيفة:** لعصابة + الجنوب الغربي.
- **النعمة:** الحوض الشرقي + الشرق.
- **الزويرات:** تيرس زمور + الشمال (الحديد).
- **أكجوجت:** إينشيري + الغرب.

## أهم المدن (تُفصَّل في المرحلة الخامسة)

نواكشوط · نواذيبو · أطار · تجكجة · روصو · كيهيدي · كيفة · النعمة · سيليبابي · أكجوجت · الزويرات · عيون العتروس · ألاك · بومديد · وادان · شنقيط · تيشيت · ولاته · الجنينة · الضعين · النعمة.

## أهم الأطعمة

مارو الحوت (الطبق الوطني — سمك + أرز) · المشوي (لحم ضأن) · الكسكس (العيش) · المهراس (العصيدة) · مارو واللحم · مافي (فول سوداني + بامية) · ياسا (دجاج) · بنافا · لاخ (حلوى جبن + جوز هند) · التشطار (لحم غزلان مجفف) · جمل عربي (لحم إبل). المشروبات: **الشاي الموريتاني** (الوطني الأول) + الكركديه (البيسام) + عصير المانجو + الزريك.

## أهم الملابس

رجالي: **الدراعة** (الزي القومي — فضفاضة زرقاء/بيضاء) + السروال + العمامة/الطاقية + السيف + النعل. نسائي: **الملحفة** (الزي القومي — قطعة قماش ملوّنة تُلَف حول الجسم) + النقاب الحساني + الدراعة النسائية + الحناء + الكحل + الذهب. إفريقي: الثوب الإفريقي (للزنوج).

## أهم اللهجات

**الحسانية** (لهجة البيضان البدوية — عربية بدوية مع أثر بربري) + لغات إفريقية (**وولوف** + **سوننكي** + **فولار/فلان** + **تكرور**) + بقايا أمازيغية صنهاجية + الفرنسية (إرث استعمار).

## أهم الكلمات المحلية

«ماشي» (ذاهب) · «حنش» (أفعي) · «دبوس» (عصي) · «جيرة» (صحن) · «الكدية» (الجبل) · «أسم حالة» (كيف) · «أسم وقت» (متى) · «السيبة» (لا مبالات) · «الذيب» (الذئب) · «أشحالك» (كيف الحال) · «اشطاري» (ماذا طرأ) · «أهل بسم الله الرحمن الرحيم» (الجن — تفائل) · «الشهر مات» (انتهى الشهر).

## أهم العادات

**الشاي** (طقس يومي — الوطني الأول) · **الأعراس** (قولة الخير + خطوبة + عقد + حنة + دخلة + فطور العريس) · **الختان/الشلوخ** · **المولد النبوي** (مواكب + مدائح) · **الطرق الصوفية** (تجانية + قادرية + تيجانية + المحاضر + الزوايا) · كرم/ضيافة (وجبة كاملة للغريب) · **العصبية القبلية** (النسب + العمدة + النظار) · **الشعر الحساني** (القصيد).

## أهم المواقع التاريخية

**المدن التاريخية الأربع (يونسكو 1996):** شنقيط + وادان + تيشيت + ولاته · أوداغست + كمبي صالح · مساجد تاريخية (شنقيط العتيق + وادان + تيشيت + ولاته).

## أهم المواقع الطبيعية

**هضبة أدرار + كثبان** (سياحة سفاري) · **كدية الجِل** (915م — أعلى نقطة) · **سبخة ندرهامشة** (-5م — أنخفض نقطة) · وادي السنغال + دلتا (رامسار) · ساحل الأطلسي (محمية البنك أرغين) · بحيرة تيشيت.

## أهم المنتجات

**الحديد** (أكبر منتج عربي — 13 مليون طن 2022) + **الصيد البحري** (~50% من الصادرات) + **الذهب** + **الغاز** (GTA 2025) + **الثروة الحيوانية** (~130 مليون رأس) + الفوسفات + النحاس + الجبس + الأرز + التمر + السورغم.

## أهم الشخصيات

**المختار ولد داداه** (المؤسس) · مصطفى السالك · ولد هيداله · الطايع · ولد عبد العزيز · **الغزواني** (الحالي) · الشيخ سيديا الكبير (مقاومة) · الأمير سيد أحمد عيدة · محمد الحبيب · الحاج عمر تال · أعلام أدب (محمد ولد إبراهيم ولد السيد + موسى ولد إبنو).

## أهم الأحداث التاريخية

البافور (قبل الإسلام) → صنهاجة + المرابطون (القرن 11) → إمبراطورية غانا/مالي (الجنوب) → **إمارات بني حسان** (القرن 15–17) → الاستعمار الفرنسي (1904–1960) → مقاومة (حتى 1932) → **الاستقلال (28/11/1960)** → حرب الصحراء الغربية (1975–1979) → انقلابات (6 رؤساء عسكريين) → دستور 1991 (تعددية) → انقلاب 2008 (ولد عبد العزيز) → **2019** (الغزواني — أول انتقال سلمي) → إصلاحات + رؤية 2030.

## ما يجب أن يعرفه من يريد فهم موريتانيا

1. **أكبر دولة عربية مساحةً** (1.03 مليون كم²) لكن **من أقلها كثافةً** (~5 نسمة/كم²) — 3/4 المساحة صحراء.
2. **جسر المغرب العربي × إفريقيا جنوب الصحراء** + على المحيط الأطلسي — ثقافة هجينة.
3. **مهد حركة المرابطين** (القرن 11) + إمبراطورية إسلامية (إسبانيا + المغرب + السنغال).
4. **إمارات بني حسان** (القرن 15–17) + نظام أميري قبلي (آدرار + ترارزة + لبراكنة + إيدوشلي).
5. **أربع مدن تاريخية يونسكو (1996):** شنقيط + وادان + تيشيت + ولاته — تراث عالمي.
6. **الإسلام 100%** + الطرق الصوفية (تجانية + قادرية + تيجانية) + المحاضر + الزوايا — مكون ديني/اجتماعي/سياسي عميق.
7. **الحسانية** لهجة البيضان (عربية بدوية + أثر بربري) + لغات إفريقية (وولوف + سوننكي + فولار + تكرور) — تنوع لغوي.
8. **الحديد** أكبر منتج عربي + الصيد (50% من الصادرات) + الذهب + الغاز GTA 2025.
9. **العبودية + الطبقات** (تاريخ) — أُلغيت 1981/2007 لكن تركة باقية + قضايا حساسة.
10. **استقلال 1960 + 6 انقلابات عسكرية** → **2019** (الغزواني — أول انتقال سلمي + إصلاحات + رؤية 2030).
