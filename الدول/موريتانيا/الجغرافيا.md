# جغرافيا الجمهورية الإسلامية الموريتانية

> علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر.

---

## 1. الموقع والمساحة
- **الموقع:** شمال غرب أفريقيا — على المحيط الأطلسي — جسر بين المغرب العربي (شمال) وإفريقيا جنوب الصحراء (جنوب).
- **الإحداثيات:** 16°–27°N ، 5°–17°W (مدار السرطان يخترقها).
- **المساحة:** **1,030,700 كم²** — أكبر دولة عربية مساحةً (أكبر من مصر + الجزائر ضمن المغرب العربي) لكن **من أقلها كثافةً** (~5 نسمة/كم²).
- **ميزة فريدة:** أكبر دولة في العالم تقع عمومًا تحت ارتفاع 1,000 م. 🟢

## 2. الأحزمة الجغرافية الأربع (إيكولوجية) 🟢

### أ. الحزمة الصحراوية (الشمال — 2/3 المساحة)
- **الصحراء الكبرى** + **إل جوف** (الفجوة) — كثبان رملية شاسعة.
- **هضبة أدرار** (500 م) — شمال وسط — تلال/قلاع + واحات.
- **تيرس زمور** — أقصى الشمال (الزويرات + أكجوجت).
- **البيوضة** (الفجوة الصحراوية) — صحراء جافة.
- أمطار <50–100 مم + حار >40°م صيفًا + ليالي باردة.
- سكان: بدو رحَّل + واحات (أطار + وادان + شنقيط).

### ب. الحزمة الساحلية (الغرب — المحيط)
- **ساحل الأطلسي** (~754 كم) — شواطئ رملية + ثروة سمكية.
- **نواكشوط** + **نواذيبو** (العاصمة الاقتصادية).
- سحلية + رطوبة محدودة + رياح المحيط.
- أمطار ~140 مم (نواكشوط).

### ج. الحزمة الساحلية (وادي السنغال — الجنوب)
- **وادي نهر السنغال** (الحدود مع السنغال) — 0.5% من المساحة (الأراضي الصالحة الوحيدة).
- **غيديماغا** + **كوركول** + **ترارزة** + **لعصابة** — زراعة (أرز + ذرة + تمر + سورغم).
- أمطار ~600–800 مم (يوليو–أكتوبر) + استوائي شبه.
- سكان: حراطين + زنوج (وولوف + فولار + تكرور) — مزارعون.

### د. حزمة السهل شبه الجاف (الوسط)
- **تكانت** + **لبراكنة** + **الحوضين** — سهول رملية + أعشاب + سنط + باوباب.
- أمطار 150–300 مم + رعي + قوافل.
- سكان: بدو بني حسان + زوايا.

## 3. التضاريس
- عمومًا: **سهل شاسع منخفض** + هضاب رملية + قلاع صخرية متفرقة.
- **أعلى نقطة:** **كدية الجِل (Kediet ej Jill)** — 915 م (شمال غرب — قطعة هماتيت — أكبر منجم حديد). 🟢
- **أنخفض نقطة:** **سبخة ندرهامشة** — -5 م تحت مستوى البحر (شمال نواكشوط). 🟢
- **هضبة أدرار** (500 م) — شمال وسط + قلاع + غدران + واحات.
- **جبال/قلاع:** تكانت + آسا (على حدود السنغال) + مغمات (أدرار).
- **النهر الوحيد:** **نهر السنغال** (الحدود الجنوبية) — يصب في المحيط الأطلسي.

## 4. المناخ 🟢
- **تصنيف كوبن:** **BWh** (صحراوي حار) شمال + **BSh** (شبه جاف) جنوب + متأثر بمحيط غربًا.
- **الصيف (مارس–أكتوبر):** حار >40°م في الصحراء (قد يصل 49°م) + ليالي باردة (قد تنزل لـ12°م).
- **الشتاء (نوفمبر–فبراير):** معتدل 25–30°م + ليالي باردة.
- **الأمطار:** <100 مم شمال → ~600–800 مم جنوب (يوليو–أكتوبر — موسم Hivernage).
- **الرياح:**
  - **الهارماتان:** ريح جافة محملة بالغبار من الصحراء (سائدة) — عواصف رملية.
  - **التريدات:** ريح محيطية (ساحل غرب).
- **تغير المناخ:** زحف الصحراء (جنوبًا) + جفاف متكرر (1970ات + 1980ات) + التأثير الكبير على البدو (توطين قسري).

## 5. الموارد المائية
- **نهر السنغال** = المصدر الرئيس للمياه العذبة + الزراعة (سدود مع السنغال).
- **مياه جوفية** (طبقات رملية) — محدودة + آبار.
- **تحلية** محدودة (ساحل نواكشوط + نواذيبو).
- لا أنهار دائمة داخل البلاد (كلها أودية موسمية).

## 6. التربة والغطاء النباتي
- **التربة:** رملية صحراوية (شمال) + طينية (وادي السنغال) + حصوية (قلاع).
- **الغطاء:** صحراوي (شيح + رتم + عوسج) شمال + ساحلي (أعشاب + سنط) وسط + سافانا (سنط + باوباب + عشار) جنوب وادي السنغال.
- **غابات النهر:** متاخمة لوادي السنغال (أكاسيا + صفصاف + نخيل).

## 7. الموارد الطبيعية
- **الحديد:** خام عالي الجودة (أكبر منتج عربي — كدية الجِل + أتوماي) — شركة SNIM.
- **الذهب** + **النحاس** + **الجبس** + **الفوسفات** + **الملح**.
- **الغاز الطبيعي** (مشروع GTA مع السنغال 2025) + **النفط** (اكتشافات قبالة الساحل).
- **الثروة السمكية:** شواطئ غنية (نواذيبو + نواكشوط + اناملان + تيشيت).
- **الثروة الحيوانية:** ~110–130 مليون رأس (أبقار + ضأن + ماعز + جمال) — مراعي شاسعة.
- **الأراضي الزراعية:** ~0.5% من المساحة (وادي السنغال) — أرز + ذرة + تمر + سورغم + قمح + دخن.

## 8. المناطق الطبيعية والمحميات
- **هضبة أدرار + كثبان** (سياحة السفاري + مدن تاريخية).
- **وادي السنغال** + دلتا (محمية دياراولينغ + طيور).
- **ساحل الأطلسي** (محمية البنك أرغين — رامسار).
- **محمية الجول Loading** (السلاحف + الطيور المهاجرة).
- **بحيرة تيشيت** (محمية + طيور).

## 9. النقل والربط
- **الموانئ:** نواكشوط (العاصمة) + نواذيبو (الصيد + الحديد) + روصو (السنغال).
- **المطارات:** نواكشوط – الدولي (أكبر مطار) + نواذيبو + أطار + نعمة.
- **الطرق:** نواكشوط–نواذيبو + نواكشوط–روصو + نواكشوط–أطار (ممهدة — «طريق الأمل»).
- **السكة الحديدية:** **زويرات–نواذيبو** (نقل خام الحديد) — الأشهر.
- **ميناء الصداقة:** نواكشوط (ميناء صيني حديث).

## 10. ربط الجغرافيا بالثقافة (رؤية تطبيقية)
- **الصحراء الكبرى** (3/4 المساحة) → حياة البدو الرحَّل + القوافل + الخيام + الدراعة + المشوي + الحسانية + الجفاف والتوطين القسري 1970ات/1980ات. 🟢
- **المحيط الأطلسي** (ساحل غرب) → الصيد + نواذيبو (العاصمة الاقتصادية) + نواكشوط + الثروة السمكية + مارو الحوت (الطبق الوطني).
- **وادي السنغال** (جنوب) → الزراعة + الحراطين + الأرز + التمر + الثقافة السنغالية/الإفريقية (وولوف + فولار + تكرور).
- **هضبة أدرار + تكانت** (وسط/شمال) → المدن التاريخية (شنقيط + وادان + تيشيت + ولاته) + العلم + المحاضر + طرق القوافل.
- **الموقع الجسري** (مغرب × إفريقيا) → ثقافة هجينة (عربية + أمازيغية + إفريقية) + الإسلام + المطعم الموريتاني (مزيج مغربي + سنغالي).
- **كبر المساحة + قلة الكثافة** → بدوية + حضرية متزايدة (نواكشوط 28% + نواذيبو) + تدهور الريف + العزلة (القرن 16–20).
