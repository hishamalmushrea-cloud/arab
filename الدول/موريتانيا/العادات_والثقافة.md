# العادات والثقافة في الجمهورية الإسلامية الموريتانية

> ثقافة موريتانية مركّبة: عربية إسلامية + أمازيغية صنهاجية + إفريقية + بدوية صحراوية. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر (قضايا العبودية حساسة).

---

## 1. الأعراس والزواج 🟢

### مراحل الزفاف
1. **قولة الخير:** طلب الزواج (أهل العريس + أعيان العائلة).
2. **الخطوبة:** تقديم الشبكة (ذهب) + المهر + المرطبات (وجبة خفيفة).
3. **العقد:** الكتابة الشرعية عند المأذون + «الشيلة» (6 أطقم ثياب + أحذية + حقائب) + «المقنع» (ثوب لأم العروس).
4. **حنة العريس:** تخضيب يدي/رِجلي العريس بالحناء (رجال فقط + إقامة حفل).
5. **ليلة الدخلة:** الزفاف + الولائم.
6. **الفطور:** أهل العروس يقدّمون فطورًا للعريس + هدايا (جلابية + مصلاة لوالد العريس + عطور لأمه).

### عادات جهريمة
- **الختان/الشلوخ:** للذكور (إرث إسلامي/إفريقي).
- **العصبية القبلية:** النسب + العمدة + النظار (مؤسسات عرفية).

---

## 2. المناسبات الدينية 🟢

### رمضان
- **الحساء + التمر + لبن الإبل + الشاي** (إفطار).
- **الشباكية + البسطيلة** (حلويات مغربية — إرث المغرب).
- **طاجين اللحم المشوي** (إن سمح الحال).
- موائد جماعية + التراويح + المسحراتي.
- **الشاي** طقس يومي (3 مرات).

### المولد النبوي 🟢
- مواكب + مدائح صوفية + قهوة + توزيع الحلوى.
- **الموالد الكبرى** (الطرق الصوفية): تجانية + قادرية + تيجانية.

### العيدان
- صلاة العيد + الذبيحة (الأضحى) + الكسكس + المشوي + زيارات الأهل + هدايا.

---

## 3. الطرق الصوفية 🟢
- **التجانية** (أحمد التجاني — فاس) — الأشهر + الأكثر انتشارًا.
- **القادرية** (عبد القادر الجيلاني) — منتشرة.
- **التيجانية** + **الشاذلية** + **الدركاوية** + **العركية** + **السمنية.**
- **المحاضر:** مدارس قرآنية تقليدية (جريد + طين) — تحفيظ القرآن + الفقه + العلوم.
- **الزوايا/الزوايا:** طبقة العلم + الفتوى + التعليم (مكتبات).
- السودان من أكثر بلاد المغرب تمسُّكًا بالصوفية + المحاضر + تأثيرها الاجتماعي + السياسي.

---

## 4. العادات الاجتماعية 🟢
- **كرم/ضيافة:** لا يمكن زيارة بيت موريتاني دون تقديم شاي + قهوة + (وجبة كاملة للغريب) — قيمة أساسية.
- **المجالس (القعدات):** مجالس الرجال (المسيد + المضيفة) + النساء.
- **التكافل:** الجار + الحِلّة (الحي) + الأفراح + المآتم الجماعية (إرث بدوي).
- **العفو + المصاهرة + التحالفات** (إرث إمارات بني حسان).
- **الشعر الشعبي (القصيد/الغمي):** الشعر الحساني (نظمة + إلقاء).

---

## 5. الفنون الشعبية 🟢
- **الشعر الحساني:** فن شعبي عريق (نظمة + إلقاء + إرث بدوي).
- **الغناء + الطبل + الرباب** (إرث صنهاجي/مغربي).
- **الرقصات:** القصيد + الركبي + التermo (إفريقي).
- **الخط (Hassani calligraphy):** فن الخط العربي الصحراوي.
- **الحرف التقليدية:** الجلد + الفخار + النسيج + الصياغة (الذهب).

---

## 6. العمارة التراثية 🟢

### العمارة الصحراوية
- **المساجد الطينية:** مسجد شنقيط العتيق (القرن 13) + مسجد وادان (القرن 12) + مسجد تيشيت (القرن 12) + مسجد ولاته (القرن 13) — **يونسكو**.
- طراز مغربي أندلسي + تصميم محلي — مآذن مربعة + حجر جاف + طين.
- **المدن التاريخية الأربع:** شنقيط + وادان + تيشيت + ولاته (يونسكو 1996 — تراث عالمي).
- **البيوت الطينية + الحجر الأحمر المصقول** — عمارة صحراوية أصيلة.
- **الزوايا + المحاضر:** مدارس قرآنية + مكتبات المخطوطات.
- **الخيام + البيوت البدوية** (إرث البدو الرحَّل).

### العمارة الحديثة
- **نواكشوط** (عاصمة حديثة — 1960) + المباني الإسمنتية + السفارات.
- **نواذيبو** (ميناء + مبناني صناعية).

---

## 7. المدن التاريخية الأربع (يونسكو 1996) 🟢

### شنقيط
- المدينة الأشهر — «بلاد شنقيط» اسم تاريخي لموريتانيا.
- القرن 13 م (8 قرون) + ملتقى قوافل الحج + العلم + التجارة.
- **مسجد شنقيط العتيق** + 5 مكتبات بالمخطوطات النادرة.
- «بلد المليون شاعر» (إرث ثقافي).
- هضبة أدرار + 500 م + 400 كم شرقي المحيط.

### وادان
- القرن 6 هـ/12 م + طريق القوافل (المغرب × إفريقيا).
- **مسجد وادان** + المعالم الأثرية + «أقدم جامعة في الصحراء».
- يونسكو 1996.

### تيشيت
- القرن 12 م + مسجد تيشيت + مئذنة طينية.
- واحات + صناعات جلدية + فخارية.
- يونسكو 1996.

### ولاته
- القرن 13 م + مسجد ولاته + طريق القوافل.
- ملتقى تجاري + علمي + فكري.
- يونسكو 1996.

> كلها ضمن «المدن التاريخية الأربع» المصنفة تراثًا عالميًّا.

---

## 8. الحرف التقليدية 🟢
- **الجلدية:** صناعات جلدية (شنقيط + تيشيت).
- **الفخارية:** فخار عريق (تيشيت + أدرار).
- **النسيج:** البنيانية + الشالة + البسط.
- **الصياغة:** الذهب + الفضة.
- **الحناء + الكحل + العطور.**

---

## 9. الثقافة المعاصرة 🟢
- **الشعر الحساني:** فن أدبي عريق (القصيد + النظمة).
- **الأدب الموريتاني الحديث:** محمد ولد إبراهيم ولد السيد + موسى ولد إبنو + أحمد ولد عبد القادر.
- **الموسيقى:** الموسيقى الحسانية + الموسيقى الإفريقية (السنغالية).
- **المهرجانات:** مهرجان المدن التاريخية (سنوي) + مهرجان نواذيبو + مهرجان المدينة.
- **التعليم:** المحاضر (قرآنية) + المدارس الحكومية + الجامعة (نواكشوط 1981).
- **الإعلام:** إذاعة + تلفزيون (تلفزيون موريتانيا) + صحف (الشروق + الصحراء + المستقبل).

---

## 10. القضايا الحساسة 🟠
- **العبودية:** أُلغيت قانونيًّا 1981 + جُرِّمت 2007 (آخر دولة) — تركة اجتماعية باقية + محاربة مستمرة. 🟠
- **الطبقات (تاريخية):** العرب/الزوايا/الحراطين/المعلمين/أزناگه — اندثر القانوني لكن البقايا الاجتماعية. 🟡
- **النزاع مع المغرب** (الصحراء الغربية): حساس — يُورَد بحياد. 🟠
- **البدو × الحضر:** توطين قسري بعد الجفاف (1970ات + 1980ات) + نواكشوط (28% من السكان).

---

## 11. ربط الجغرافيا بالثقافة
- **الصحراء + البدو** → الخيام + المشوي + المهراس + الدراعة + الحسانية + الشعر الحساني + المحاضر + القوافل. 🟢
- **المحيط + الساحل** → الصيد + مارو الحوت + نواذيبو + الثروة السمكية.
- **وادي السنغال + الجنوب** → الزراعة + الحراطين + الثقافة الإفريقية + الأرز + التمر.
- **الموقع الجسري** (مغرب × إفريقيا) → العمارة المغربية الأندلسية (المساجد) + الثقافة الإفريقية (ياسا/مافي/لاخ) + الإسلام كمكوِّن موحِّد.
- **الإسلام + الصوفية** → المحاضر + الموالد + الطرق + المدارس القرآنية + المخطوطات.
- **التاريخ المرابطي + الحساني** → إرث المرابطين (الإسلام + اللغة العربية) + إمارات بني حسان (الدراعة + السيف + العصبية) + المدن التاريخية (العلم + التجارة).
- **العبودية + الطبقات** (تاريخ) → تأثير اجتماعي باقي + قضايا حساسة (حياد + تقرير الفجوات). 🟠
