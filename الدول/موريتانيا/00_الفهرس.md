## التقسيم الإداري سريعًا (مرجع)

### الولايات الـ15 (منذ 25 نوفمبر 2014) 🟢
- **نواكشوط (3):** الشمالية (دار النعيم) + الغربية (تفرغ زينة) + الجنوبية (عرفات).
- **الشمال:** أدرار (أطار) + تيرس زمور (**الزويرات** لا افديرك).
- **الوسط:** تكانت (تجكجة) + البراكنة (ألاك) + الحوض الغربي (عيون العتروس).
- **الجنوب:** الترارزة (روصو) + لعصابة (**كيفة**) + كوركول (**كيهيدي**) + غيديماغا (سيليبابي).
- **الشرق:** الحوض الشرقي (النعمة).
- **الغرب:** داخلة نواذيبو (نواذيبو) + إينشيري (أكجوجت).

### التسلسل الإداري 🟢
- **ولاية → مقاطعة → بلدية**. مقاطعات: 44 قديمًا ثم 53–56 ثم **63** في جرد 2023/2024 🟡. بلديات ~216–218 🟡.

## العاصمة
- **نواكشوط** — العاصمة السياسية + الإدارية + أكبر مدينة (~1 مليون نسمة — 28% من سكان البلاد) + على المحيط الأطلسي. 🟢
- **نواذيبو** — العاصمة الاقتصادية + الميناء الرئيسي + تصدير الحديد + أقصى الشمال الغربي.
- **كيهيدي/روصو** — الجنوب (وادي السنغال).
- **أطار** — الشمال (هضبة أدرار + المدن التاريخية).
- **تجكجة** — الوسط (تكانت).

(دراسة كل عاصمة في ملف مستقل ضمن مجلد `العواصم/` في المرحلة الثالثة.)

## ما يميز موريتانيا باختصار
- مساحة **1,030,700 كم²** وكثافة منخفضة (~5 ن/كم²) — 3/4 صحراء. **ليست** أكبر دولة عربية (الجزائر أكبر).
- **جسر بين المغرب العربي وإفريقيا جنوب الصحراء** + على المحيط الأطلسي.
- **مهد حركة المرابطين** (القرن 11م) + إمبراطورية إسلامية شملت إسبانيا + المغرب + السنغال.
- **إمارات بني حسان** (القرن 15–17): آدرار + ترارزة + لبراكنة + إيدوشلي — نظام أميري قبلي.
- **أربع مدن تاريخية يونسكو:** شنقيط + وادان + تيشيت + ولاته (تراث عالمي).
- **دين الدولة:** الإسلام 100% — سُنة + مالكية + زوايا/محاضر + طرق صوفية (تجانية + قادرية).
- **اللغة الرسمية:** العربية + اللهجة الحسانية (لهجة البيضان).
- **العبودية:** أُلغيت قانونيًّا 1981 + جُرِّمت 2007 (آخر دولة) — تركة اجتماعية حساسة.
- **اقتصاد:** الحديد (أكبر منتج عربي) + الصيد البحري + الذهب + الغاز GTA 2025 + الثروة الحيوانية.
- **تاريخ حديث مضطرب:** استقلال 1960 → حرب الصحراء الغربية → انقلابات (6 رؤساء عسكريين) → 2019 (الغزواني).
