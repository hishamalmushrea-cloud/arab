# اللباس في الجمهورية الإسلامية الموريتانية

> لباس موريتاني صحراوي بدوي محتشم متكيِّف مع الحر + الإسلام. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. نظرة عامة
- اللباس التقليدي = **محتشم + فضفاض + يغطي الجسم** — متكيِّف مع **الحر الصحراوي + الإسلام + البدو الرحَّل**.
- زي قومي موحِّد عبر المكونات (البيضان + الحراطين + الزنوج — تمايز محدود).
- اللباس الغربي منتشر في المدن + الشركات + الأعمال.

---

## 2. اللباس الرجالي 🟢

### الدراعة (الدربالة) — الزي القومي الرجالي 🟢
- **رداء طويل فضفاض** (إلى الكاحل) + أكمام واسعة + يُربط بـ«الفوقية» (وشاح).
- **الألوان:** **الأزرق (الشهير — «الدراعة الزرقاء»)** + الأبيض + البني/الأسود + الأبيض/الأسود (الأنصار).
- **القماش:** قطن خفيف (صيفًا) + صوف (شتاءً).
- **الفتحة/اللجام:** شق أمامي للدراعة (أحيانًا).
- تعكس **الهوية الصحراوية** + محتشام + بدوي.

### السروال
- **بنطال واسع** تحت الدراعة — يشبه السروال المغربي.

### العمامة/الطاقية
- **عمامة** (قطن أبيض) — تُلَف حول الرأس (إرث مغربي + صنهاجي).
- **الطاقية:** تحت العمامة (مغربية + طرابلسية).
- يُغطى الرأس حماية من الشمس + رمز ديني/اجتماعي.

### النعل/الصندل
- **نعل جلدي** أو صندل بسيط — متكيِّف مع الرمل + الحر.

### الإكسسوارات
- **السيف:** في المناسبات (إمارات بني حسان — إرث بدوي).
- **ال العكاز:** رمز الهيبة (إرث مغربي).
- **السبحة:** للزوايا/الشيوخ.

---

## 3. اللباس النسائي 🟢

### الملحفة — الزي القومي النسائي 🟢
- **قطعة قماش طويلة ملوّنة** تُلَف حول الجسم كاملًا + تغطي الرأس والشعر.
- تعكس **الأناقة + الاحتشام + الهوية الصحراوية**.
- **أقمشة:** حرير + ساتان + قطن — ملونة + مزخرفة (للمناسبات) أو بسيطة (يومي).
- **اللف:** طرق لف تتفاوت بين المناطق + الفئات العمرية.

### النقاب الحساني 🟡
- بعض النساء يرتدين **نقابًا** (غطاء وجه — إرث بدوي/خليجي) — تراجع لكن ينتشر في الأجيال المحافظة.

### الدراعة النسائية
- نسخة نسائية من الدراعة — في بعض المناطق.

### الإكسسوارات النسائية 🟢
- **الحناء:** في الأعراس + الموالد + المناسبات (إرث مشترك).
- **الذهب/الفضة:** حلي + قلائد + خلخال + خواتم.
- **الكحل:** للعين (تجميل تقليدي).
- **الشلوخ (الوشوم):** علامة جمال عند بعض القبائل (تراجعت — خاصة في الزنوج).

### اللباس الإفريقي (الزنوج) 🟡
- **الثوب الإفريقي** (للولوف/السوننكي/الفولار) — ملوّن + مطرز — إرث سنغالي/غرب إفريقيا.
- **البوبو/البوبي** (للنساء المسنات في الزنوج).

---

## 4. اللباس الحديث 🟢
- **اللباس الغربي** (القمصان + البناطيل + الفساتين) — منتشر في المدن + الأعمال + الشركات + الشباب.
- **الدراعة + الملحفة** تبقى للجمعة + المناسبات + الأعراس + البيت + الفلوات.
- **النقاب + الحجاب** (نساء محافظات — تأثير إسلامي خليجي حديث).
- مصممات موريتانيات يبتكرن تصاميم حديثة للملحفة + الدراعة.

---

## 5. ربط اللباس بالجغرافيا والثقافة
- **الحر الشديد + الجفاف + الشمس** → الدراعة الفضفاضة (تهوية + عكس الشمس) + العمامة (حماية الرأس) + القطن الخفيف + الألوان الفاتحة. 🟢
- **الإسلام + المحتشام** → تغطية الجسم + الحجاب + النقاب + الكحل + الحناء (مكونات إسلامية).
- **البدو الرحَّل + الصحراء** → الدراعة (زي عملي للتنقل) + السيف (إرث حساني) + العكاز + النعل الجلدي.
- **الموقع الجسري** (مغرب × إفريقيا) → الدراعة + العمامة (مغربي/صنهاجي) + الملحفة (مزيج) + اللباس الإفريقي (سنغالي/غرب إفريقيا للزنوج) — تمايز ثقافي محدود.
- **إمارات بني حسان** (القرن 15–17) → الدراعة + الفوقية + السيف + العمامة (إرث حساني بدوي).
- **التجارة التاريخية** (قوافل) → استيراد الأقمشة من المغرب + غرب إفريقيا + أوروبا + الهند.
- **الكرم + الضيافة** → الملحفة المزخرفة (للمناسبات) + الذهب (إظهار للكرم).
