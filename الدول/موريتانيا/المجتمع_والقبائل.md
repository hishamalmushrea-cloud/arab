# المجتمع والقبائل والطوائف في الجمهورية الإسلامية الموريتانية

> تركيبة عرقية وطبقية معقّدة: بيضان + حراطين + زنوج + طبقات تاريخية. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر (العبودية + الطبقات قضايا حساسة). تُورَد بحياد تام.

---

## 1. السكان — الأرقام 🟡
- **السكان:** ~4.9 مليون (2023) — تباين 4.5–5.2 مليون.
- **الكثافة:** ~5 نسمة/كم² (من أقل كثافات العالم — 3/4 المساحة صحراء).
- **التوزيع:** 61.2% حضر + 90% صحراوي/شبه صحراوي.
- **معدل النمو:** 2.5% سنويًّا.
- **مؤشر التنمية البشرية:** 0.556 (متوسط — 2023).
- **التعليم:** 4.2 سنة متوقعة للطفل (منخفض) + الفقر 26.9% (2025 متوقع — انخفاض من 33%).
- 🟡 الوضع في تحسُّن لكن الأرقام تقديرية.

---

## 2. التركيبة الإثنية/العرقية 🟢🟠

### أ. البيضان (30%) — عرب + أمازيغ صنهاجة 🟢
- **العرب (بني حسان):** من عرب المعقل (الهلاليون) — وصلت طلائعهم أدرار ~1409 م + سيطروا على الصحراء الموريتانية (القرن 15–17).
  - نسب: جعفر بن أبي طالب (الطالبيون) — أو من عرب اليمن القحطانيين (ابن خلدون) — 🟡 *رواية تاريخية* (خلاف).
  - قبائل: **أولاد أحمد بن دامان** (ترارزة) + **أولاد عبد الله** (لبراكنة) + **أولاد يحيا بن عثمان** (آدرار) + **أولاد أمبارك** (إيدوشلي) + أولاد دليم + أولاد الناصر + المعاركة + إيدافگ + أولاد باريكل + القلااد.
  - نظام أميري قبلي (القرن 15–19).
- **الأمازيغ (صنهاجة):** البربر البدو — أساس حركة المرابطين.
  - قبائل: **لمتونة + جدالة + مسوفة** (المرابطون) + بقايا اندثرت (إلا جيوب قليلة).
- **اللغة:** الحسانية (لهجة عربية بدوية) — موحِّدة للبيضان.
- **الدين:** الإسلام (سُنة + مالكية) + الطرق الصوفية.
- **المناطق:** عموم البلاد (الشمال + الوسط + الغرب) + نواكشوط + نواذيبو.

### ب. الحراطين (40%) — سود أحرار 🟢🟠
- **الحراطين (أهرضنن):** سود أحرار — أصولهم من **إيزگارن + إيرناكن** (البربر) — مزارعون في الواحات + وادي السنغال.
  - كلمة «حرطاني» = بربري (الذي يزرع البساتين) — أصلهم غير إفريقي خالص.
  - تهجين مع البيض (السود القادم من الجنوب + البيض القادم من الشمال).
- يتكلمون **الحسانية** (لغة البيضان) — اندثرت لغاتهم الأصلية.
- **المناطق:** الجنوب + الغرب (وادي السنغال + واحات أدرار) + زراعة.

### ج. الأفارقة الزنوج (30%) — من غرب إفريقيا 🟢🟠
- **الوولوف (Wolof):** من السنغال — ترارزة + كوركول + نواكشوط.
- **السوننكي (Soninke):** من غانا/مالي تاريخيًّا — جنوب موريتانيا.
- **الفولار/الفلاتا (Pulaar/Fulfulde):** من الفلان + غرب إفريقيا — غيديماغا + كوركول.
- **البولار (Pulaar):** subgroup من الفولار.
- **التكرور (Toucouleur):** من وادي السنغال (فوتا تورو) — هاجروا للبلاد (القرن 20) — 🟡 *رواية*: ثورة تورودو 1776 ضد البيضان.
- **المناطق:** الجنوب (وادي السنغال) + نواكشوط + المدن.
- يتكلمون لغات إفريقية (نيجري-كونغو) + العربية (ثنائية).

> 🟠 **النزاع العرقي (البيضان × الزنوج):** تركة استعمارية (سياسة الأجناس) + تركة ما بعد الاستقلال — قضايا سياسية + اجتماعية حساسة تُورَد بحياد.

---

## 3. النظام الطبقي (تاريخي) 🟢🟠

- **العرب/الحَسّان:** القوة المسلحة + الحماية + الإمارات (السيف).
- **الزوايا:** العلم + التعليم + الفتوى + المحاضر + المكتبات (الكتاب).
- **الحراطين:** الزراعة + البساتين (الحراثة).
- **المعلمين/الصناع:** الصناعات التقليدية — الجلد + الفخار + النسيج.
- **أزناگه:** الخدمة (سابقًا — من رقيق إيزگارن/إيرناكن — اندثر القانوني لكن بقايا اجتماعية).

> 🟠 **الطبقات + العبودية:** نظام تراتبي غير مكتوب لكنه حكم أنماط التملك + القرابة + التحالف. تركة باقية + قضايا حساسة + محاربة مستمرة.

---

## 4. الأديان والمذاهب 🟢
- **الإسلام 100%** (دين الدولة + الهوية) — لا أقليات دينية تذكر.
- **المذهب:** **سُنة + مالكية** (غالبية) + **الطرق الصوفية** (تجانية + قادرية + تيجانية + شاذلية + دركاوية + عركية + سمنية).
- **المحاضر:** مدارس قرآنية تقليدية — تحفيظ القرآن + الفقه + العلوم.
- **الزوايا:** طبقة العلم + الفتوى + التعليم.
- موريتانيا من أكثر بلاد المغرب تمسُّكًا بالصوفية + تأثيرها الاجتماعي + السياسي (الأحزاب: التجمع الديمقراطي — التجانيون + الاتحاد الديمقراطي — الختمية).

---

## 5. العائلات والزعامات الدينية/السياسية 🟢
- **آل المختار ولد داداه** (المؤسس).
- **آل الطايع** (العسكريون).
- **آل ولد عبد العزيز** (العسكريون).
- **آل الغزواني** (الحالي).
- **آل الشيخ سيديا** (الزوايا — مقاومة الاستعمار).
- **آل أحمد بن دامان** (إمارة ترارزة).
- **آل يحيا بن عثمان** (إمارة آدرار).
- **آل عبد الله** (إمارة لبراكنة).
- **آل بابا ولد الشيخ سيديا** (التجاني).
- **آل سيديا** (العلاء — الزوايا).
- **الناظر + العمدة + الشيخ** (زعامات قبلية — إرث بدوي).

---

## 6. السياسة والمشاركة 🟢🟠
- نظام: **جمهورية رئاسية** (انتقال ديمقراطي منذ 2019).
- **الرئاسة:** الغزواني (2019–الآن) + انتخابات (2019 + 2024).
- **البرلمان:** مجلسين (الشيوخ + الوطني) + انتخابات برلمانية.
- **الأحزاب:** التجمع الديمقراطي (التجانيون) + الاتحاد الديمقراطي (الختمية) + حزب التكتل + حزب العدالة + حزب البناء + أحزاب أخرى.
- 🟠 *القضايا الحساسة* (العبودية + الطبقات + النزاع العرقي + الصحراء الغربية) تُورَد بحياد.
- **العسكر في السياسة:** 6 رؤساء من أصل 8 من المؤسسة العسكرية (إرث انقلابات 1978–2008) — تحسُّن بعد 2019.

---

## 7. التحديات الاجتماعية 🟠
- **العبودية:** أُلغيت 1981 + جُرِّمت 2007 — تركة اجتماعية باقية + محاربة مستمرة + محكمة متخصصة.
- **الطبقات:** اندثر القانوني لكن البقايا الاجتماعية (البيضان × الحراطين × الزنوج).
- **الفقر + البطالة (31%) + الأمية + ضعف الخدمات** (خارج نواكشوط).
- **النزاع العرقي** (البيضان × الزنوج): تركة + قضايا حساسة.
- **تغير المناخ:** زحف صحراء + جفاف + فيضانات.
- **الهجرة الريفية → الحضر** (نواكشوط 28% + نواذيبو) — توطين قسري بعد الجفاف 1970ات/1980ات.
- **الأقليات** (السنغاليون/الماليون) — اندماج محدود.

---

## 8. ربط المجتمع بالجغرافيا والتاريخ
- **الموقع الجسري** (مغرب × إفريقيا) → اختلاط عرقي عميق (عرب + أمازيغ صنهاجة + إفريقية) + ثقافة هجينة + الإسلام كمكوِّن موحِّد. 🟢
- **الصحراء + البدو** (البيضان) → البدو الرحَّل + الإمارات + القوافل + العصبية + الزوايا + المحاضر.
- **وادي السنغال** (الجنوب) → الحراطين + الزنوج (مزارعون + إفريقية) + الأرز + التمر.
- **التاريخ المرابطي** (القرن 11) → الإسلام + العربية + الزوايا + المحاضر + المدن التاريخية.
- **إمارات بني حسان** (القرن 15–17) → النظام الأميري + الطبقات + العصبية + العبودية.
- **الاستعمار الفرنسي** (1904–1960) → سياسة الأجناس (البيضان × الزنوج) + الحدود الحديثة + بذور النزاع.
- **الجفاف 1970ات/1980ات** → توطين قسري للبدو + حضر سريع (نواكشوط 28%) + تغيرات اجتماعية.
- **العبودية + الطبقات** (تاريخ) → تركة باقية + قضايا حساسة (حياد + تقرير الفجوات + محاربة مستمرة). 🟠
