# اقتصاد جمهورية السودان

> اقتصاد زراعي/رعوي/تعديني مدمر بفعل الحرب (2023–الآن). علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر.

## 2. الذهب — المحرك الحالي 🟢
- **الذهب = ~70% من الصادرات الرسمية** (46.3% غير النفطية) + 2.02 مليار $ (2022) → تراجعت إلى 1.6 مليار (2024).
- **الإنتاج:** 107 طن (ذروة 2017) → 41.8 (2018) → 6.4 (2023 بسبب الحرب) → **65 طن (2024)** → 37 طن (النصف الأول 2025).
- **المركز:** خامس/ثالث منتج أفريقي للذهب.
- **الاحتياطيات:** ~533 طن مؤكدة + >1,100 طن قيد التقييم.
- 🟠 **التهريب:** ~50–80% من الإنتاج يُهَرَّب (قيمته 7.5–10.5 مليار $/سنة بأسعار 2026) — شبكات تصل لدول الجوار.
- **التعدين التقليدي (الأهلي):** ~80–90% من الإنتاج + ~4 مليون عامل (ارتفعوا بعد الحرب).
- مناجم رئيسية: ولاية نهر النيل (الأكبر) + البحر الأحمر + كردفان + جبال النوبة + دارفور (متنازَع عليها).

## 3. الصمغ العربي — السلعة الاستراتيجية 🟢
- السودان = **أكبر منتج للصمغ العربي عالميًّا** (~70–80% من الإنتاج العالمي).
- يُستخرج من شجر **السنط (الهشابة)** في كردفان + دارفور.
- يُستخدم في: المشروبات الغازية + الحلويات + الأدوية + الطباعة + مستحضرات.
- صادرات لـ: أوروبا + الولايات المتحدة + الصين.

## 4. النفط — الضربة الكبرى 🟢
- **النفط** كان المصدر الأساسي (~500 ألف برميل/يوم قبل 2011).
- **انفصال الجنوب (2011):** فقد السودان **~75% من موارده النفطية** + ~90% من إيرادات النقد الأجنبي.
- الإنتاج الحالي: محدود (حقول وسط/جنوب شرق) + بعض أنابيب نقل لجنوب السودان (رسوم عبور).
- **مصفاة الخرطوم** + شركة Sudapet + شركاء (الصين + ماليزيا + الهند).
- 🟠 الحرب شلّت إنتاج/تصدير النفط.

## 5. الزراعة + الثروة الحيوانية 🟢
- **الأراضي الزراعية:** ~16.9 مليون هكتار صالحة (مستغل ~45%) + ~84 مليون هكتار مراعي.
- **مشروع الجزيرة (المشروع الكبير):** أكبر مشروع ري في أفريقيا (~2 مليون فدان بين النيلين) — قطن + قمح + ذرة.
- المحاصيل: **القطن + السمسم + الفول السوداني + الذرة + الدخن + القمح + قصب السكر + الكركديه + الصمغ.**
- **السكر:** سكر كنانة + سكر سنار + سكر الجنيد — اكتفاء ذاتي + تصدير.
- **الإيثانول:** من سكر كنانة — أول دولة عربية تنتج الوقود الحيوي.
- **الثروة الحيوانية:** ~110–130 مليون رأس (أبقار + ضأن + ماعز + جمال) — من أكبر قطعان أفريقيا + تصدير حي/لحوم (السعودية + مصر + الإمارات).
- «سلة غذاء العالم» (محتملة) لكن مهملة.

## 6. الصناعة والتعدين 🟢
- **مجمع جياد الصناعي** (سيارات + معدات) — متوقف.
- **الألمنيوم + الأسمنت + الصلب + البتروكيماويات + الجلود + الغزل.**
- التعدين: ذهب + فضة + نحاس + زنك + حديد + كروم + منغنيز + جبس + رخام + يورانيوم (محدود).
- الحرف التقليدية: المركوب + الفخار + النسيج.

## 7. التجارة الخارجية 🟢
- **الصادرات:** الذهب + الصمغ + القطن + السمسم + الماشية + الفول السوداني + السكر + الماشية.
- **الواردات:** آلات + مركبات + مواد غذائية (قمح — يستورد 80%!) + أدوية + سلع استهلاكية.
- **الشركاء:** الإمارات (الأكبر ~55%) + مصر (~15%) + السعودية (~9%) + الصين + الاتحاد الأوروبي.
- 🟠 العجز التجاري + انهيار الجنيه + التهريب.

## 8. السياسات الاقتصادية والتحديات 🟠
- **التنويع بعيدًا عن النفط** (بعد 2011) → الذهب + الزراعة + الصمغ.
- **الإصلاحات (حمدوك 2020–2021):** تعويم الجنيه + رفع الدعم + إصلاحات صندوق النقد.
- 🟠 **الحرب (2023):** دمرت البنية التحتية + إنتاج + توقفت الصادرات + مجاعة + نزوح ~10 مليون + انهيار الجنيه.
- **الدَّيْن العام + العجز المالي + التضخم + الفساد + اقتصاد الحرب** (الدعم السريع يسيطر على مناجم الذهب في دارفور).
- **رفع اسم السودان من قائمة الرعاية للإرهاب** (2020 — أمريكا) → فتح أبواب الاستثمار → قُطعت بالحرب.

## 9. السياحة والآثار 🟢🟠
- آثار عريقة: **جبل البركل + مروي (يونسكو)** + كرمة + النقعة + المصورات البجراوية.
- سياحة البحر الأحمر (بورتسودان + سواكن) + صيد + غوص.
- سياحة صحراوية + نيلية.
- 🟠 الحرب أوقفت السياحة + تهدد الآثار (الرمال + السيول + النهب).

## 10. ربط الاقتصاد بالجغرافيا
- **النيل + الواحات** → مشروع الجزيرة (أكبر ري) + القطن + القمح + الزراعة المروية. 🟢
- **السافانا + المراعي** (كردفان/دارفور) → الصمغ العربي (السنط) + الثروة الحيوانية (البقارة) + الماشية.
- **البحر الأحمر** → بورتسودان (الميناء الرئيسي + التصدير) + السياحة.
- **المعادن** (نهر النيل + البحر الأحمر + كردفان + جبال النوبة) → الذهب + المعادن.
- **الموقع المعبري** (مصر/إثيوبيا/تشاد) → تجارة عبور + رسوم نفط (أنبوب جنوب السودان) + سد النهضة (تحدٍّ).
- **اتساع المساحة + قلة الاستغلال** (~20–45% فقط) → إمكانات هائلة مهملة.
- 🟠 **الحرب** حولت كل مورد (ذهب/نفط/صمغ/ماشية) إلى «وقود للحرب» واقتصاد موازي (الدعم السريع يسيطر على مناجم + رسوم عبور + نهب).
