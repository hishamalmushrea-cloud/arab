## أهم ما يميز السودان

- **أكبر دولة عربية مساحةً** (1,886,068 كم²) + ثالث أكبر دولة أفريقية.
- **مهد حضارات عريقة:** كرمة (~2500 ق.م) → كوش/نبتة (الأسرة 25 المصرية) → **مروي** (أكثر من 200 هرم — أكثر من مصر) → الممالك النوبية المسيحية → الفونج + الفور.
- **الموقع الاستراتيجي:** معبر بين العرب وأفريقيا جنوب الصحراء + ساحل البحر الأحمر (853 كم) + ملتقى النيلين.
- **النيل:** ملتقى الأبيض + الأزرق في الخرطوم (المقرن).
- **أكبر منتج للصمغ العربي عالميًّا** (~70–80%) + منتج ذهب كبير (التهريب 70–80%).
- **تركيبة معقّدة:** >500 مجموعة عرقية + عرب (~70%) + نوبيين + فور + زغاوة + بجا + جبال النوبة.
- **تاريخ حديث مضطرب:** استقلال 1956 → حروب أهلية (1955–72 + 1983–2005) → **انفصال جنوب السودان 2011** → ثورة 2019 → **حرب 2023 (الجيش × الدعم السريع)**.
- **الطرق الصوفية** (الأنصار + الختمية) مكوّن أساسي اجتماعي وسياسي.
- **موقعا يونسكو:** جبل البركل/نبتة (2003) + جزيرة مروي (2011).
- **الطيب صالح** (موسم الهجرة إلى الشمال) + **محمد وردي** (الأغنية السودانية).
- **الجلابية + التوب** = زي قومي موحَّد عبر الأعراق + **المركوب** (حذاء دارفور).

## أهم المناطق

- **الخرطوم + أم درمان + بحري:** العاصمة المثلثة + المقرن + الديوان + الوزارات.
- **بورتسودان:** الميناء الرئيسي + البحر الأحمر + ملاذ للحكومة بالحرب.
- **نيالا:** عاصمة جنوب دارفور (أكبر مدن دارفور).
- **الفاشر:** عاصمة شمال دارفور + سلطنة الفور + محاصر في الحرب.
- **الأبيض:** عاصمة شمال كردفان + تجارة + صمغ.
- **كسلا + القضارف:** الشرق + زراعة + بجا.
- **ودمدني:** عاصمة الجزيرة + المشروع الزراعي الكبير.
- **دنقلا + مروي:** الشمال + الآثار + النوبة + سد مروي.

## أهم المدن (تُفصَّل في المرحلة الخامسة)

الخرطوم · أم درمان · بحري · بورتسودان · نيالا · الفاشر · الأبيض · كسلا · القضارف · ودمدني · دنقلا · مروي · سنار · الدمازين · كادقلي · الجنينة · زالنجي · الضعين.

## أهم الأطعمة

الكسرة (الخبز الوطني) · العصيدة · **الملاح** (ويكة/تقلية/روب/نعيمية/أم رقيقة) · الفول المدمس · الشية · **الأقاشي** (نيء) · الكمونية · الكوارع · أم فتفت · الملوخية. الحلويات: مديدة + **حلو مر/آبري** + بسبوسة + كليجا. المشروبات: **الكركديه** + عرديب (تمر هندي) + قونقليز + قهوة الجبنة + الشاي.

## أهم الملابس

رجالي: **الجلابية** (الزي القومي — بيضاء + بدون ياقة) · العمامة · على الله · ثوب السرتي · الجبة المهدوية · السروال · **المركوب** (حذاء جلدي — دارفور). نسائي: **التوب/الثوب السوداني** (تُلَف حول الجسم — توتل + حرير) · العباية · الشيلة · الحجاب · الحناء + الذهب (الزمام/الحجول).

## أهم اللهجات

اللهجة السودانية (جعلية + شايقية + خرطومية + بقّارية) — فصاحة عربية + أثر نوبي/إفريقي/مصري/تركي. لغات غير عربية: النوبية (دنقلاوية/محس/كنز) + البداويت (البجا) + الفور + الزغاوية + المساليت + لغات النوبة.

## أهم الكلمات المحلية

«زول» (شخص) · «سمح» (جيد) · «كعب» (سيئ) · «داير» (أريد) · «هسي/هسع» (الآن) · «إديني» (أعطني) · «شنو» (ماذا) · «كديسة» (قطة) · «عنجريب» (سرير حبال) · «الليلة» (اليوم) · «سقط/سجط» (برد) · «عليك الله» (لو سمحت) · «الدوبيت» (شعر رباعي).

## أهم العادات

**الجرتق** (قطع حبل الحلاوة + بخ الحليب) · الأعراس (قولة الخير + حنة + رقيص العروس + فطور العريس) · رمضان («الضراء» + الحلومر/آبري + النوبة الصوفية + الدافوري) · **المولد النبوي** (الزفة + الطبل) · **الطرق الصوفية** (أنصار + ختمية + خلاوي + حضرة) · الكرم/الضيافة · الشلوخ (وشوم — تراجعت).

## أهم المواقع التاريخية

**جبل البركل + نبتة** (يونسكو 2003) · **جزيرة مروي/أهرامات البجراوية** (يونسكو 2011) · كرمة · النقعة + المصورات · سوبا (علوة) · دنقلا العجوز (المقرة) · سنار (الفونج) · الفاشر (الفور) · سواكن · القبة المهدي (أم درمان).

## أهم المواقع الطبيعية

## أهم المنتجات

**الذهب** (~70% صادرات) + **الصمغ العربي** (70–80% عالميًّا) + النفط (محدود بعد 2011) + القطن + السمسم + الفول السوداني + الذرة + السكر + الماشية (~130 مليون رأس) + الكركديه + الجلود.

## أهم الشخصيات

## أهم الأحداث التاريخية

كرمة (2500 ق.م) → كوش/نبتة (الأسرة 25) → مروي (~300 ق.م–350 م) → النوبة المسيحية (~543–1504) → الفونج (1504–1821) + الفور → التركية (1820–1885) → **المهدية (1881–1899)** → الحكم الثنائي (1899–1956) → **الاستقلال (1/1/1956)** → حرب أهلية 1 (1955–1972) → النميري (1969–1985) + الشريعة (1983) → حرب أهلية 2 (1983–2005) → البشير (1989–2019) → انفصال الجنوب (2011) → ثورة 2019 → **حرب 2023 (الجيش × الدعم السريع)**.

## ما يجب أن يعرفه من يريد فهم السودان

1. **أكبر دولة عربية مساحةً** (1.88 مليون كم²) + ثالث أكبر أفريقية + معبر بين العرب وأفريقيا.
2. **مهد حضارات عميقة:** كوش/نبتة/مروي (أهرامات أكثر من مصر) + الأسرة 25 المصرية.
3. **النيل** = العصب (ملتقى الأبيض + الأزرق في الخرطوم) + الزراعة + السدود.
4. **تركيبة >500 عرقية** + عرب (~70%) + نوبيين + فور + زغاوة + بجا + النوبة + صوفية (الأنصار/الختمية).
5. **استقلال 1956** + حروب أهلية + **انفصال الجنوب 2011** (فقد ~75% من النفط) + **حرب 2023** (انهيار + نزوح 10+ مليون).
6. **الذهب + الصمغ العربي** = العمود الفقري الحالي + التهريب الكبير + اقتصاد حرب.
7. **الجلابية + التوب** = زي قومي موحَّد + **المركوب** (حذاء) + **الجرتق** (عرس) + **الكركديه** (مشروب).
8. **المهدي + المهدية** (1881–1899) + **الأنصار** = مكون ديني/سياسي عميق.
9. **موقعا يونسكو:** جبل البركل (2003) + مروي (2011) — مهددة بالحرب.
10. **الطيب صالح** (موسم الهجرة) + **محمد وردي** = أيقونات ثقافية عربية.
