# المصادر والمراجع — جمهورية السودان

> مرتبة حسب المستوى. تاريخ آخر مراجعة: 2026-08-11.

## المستوى الأول — رسمي
- **البوابة الرسمية لحكومة السودان (sudan.gov.sd):** معلومات عامة + وزارات. 🟢
- **وزارة الخارجية السودانية (mofa.gov.sd):** نبذة تاريخية + استقلال. 🟢
- **البنك المركزي السوداني (bankofsudan.gov.sd):** النقد + الجنيه + إنتاج الذهب. 🟢🟠
- **وزارة المعادن / الشركة السودانية للموارد المعدنية:** إنتاج الذهب + التهريب + الاحتياطيات (533 طن). 🟢
- **هيئة الآثار والمتاحف السودانية:** المواقع الأثرية + المتاحف. 🟢
- **وكالة السودان للأنباء (SUNA):** أخبار + تقارير. 🟢
- **دستور تحالف "تأسيس" الانتقالي لسنة 2025 (edraaknewspaper + sudanakhbar):** 8 أقاليم فيدرالية + المجلس الرئاسي + مجلس الوزراء. 🟠
- **مرسوم دستوري 2021 (البرهان):** نظام الأقاليم (لم يُطبَّق). 🟢

## ملاحظة منهجية
- الأرقام الإدارية/السكانية/الاقتصادية مُوثَّقة من المصادر الرسمية أو الأكاديمية — **لكن الحرب (2023–الآن) جعلت معظم الأرقام قديمة أو تقديرية** → علامة 🟠.
- القضايا السياسية الحساسة (الحرب، دارفور، النيل الأزرق، مثلث حلايب، سد النهضة، التطبيع، دستور 2025) مُوثَّقة من مصادر متعددة (ويكيبيديا/الجزيرة/BBC/العربي الجديد) وتُورَد **بحياد تام** كوقائع دبلوماسية/عسكرية دون تبني موقف.
- **عدد السكان** تقديرات متفاوتة (46–52.9 مليون) → 🟡.
- **التقسيم الإداري:** الواقع الرسمي = 18 ولاية + مسار 8 أقاليم (2025 — لم يُطبَّق) + واقع ميداني منقسم بالحرب → 🟠.
- **أصول القبائل العربية في السودان:** موضوع فيه جدل علمي (روايات نسب × دراسات جينية × استعراب) → يُورَد بحياد دون تبني رواية دون أخرى 🟡.
- المفردات اللهجية والعادات مُجمَّعة من مصادر تراثية محلية (مستوى خامس) — تُورَد كمادة تراثية لا كحقائق إحصائية.
