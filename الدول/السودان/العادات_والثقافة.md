# العادات والثقافة في جمهورية السودان

> ثقافة سودانية مركّبة: عربية إسلامية + إفريقية + صوفية + قبلية. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. الأعراس والزواج 🟢

### مراحل الزواج
1. **قولة الخير:** طلب الزواج (أهل العريس + أعيان العائلة).
2. **الخطوبة:** تقديم الشبكة (ذهب) + الدبلة + المرطبات.
3. **العقد:** الكتابة الشرعية عند المأذون + «الشيلة» (6 أطقم ثياب + أحذية + حقائب) + «المقنع» (ثوب لأم العروس).
4. **حنة العريس:** تخضيب يدي/رِجلي العريس بالحناء (رجال فقط).
5. **الجرتق:** أهم طقس — العروس ترتدي قميصًا أحمر + «قرمصيص» + حبل من الحلاوة حول وسطها → العريس يقطع الحبل وينثر الحلوى + يوزع المال على صديقات العروس + يتبادلان الحليب (بخ الحليب = بركة) + «الفال» (صناديق حلوى/بخور/دلكة).
6. **رقيص العروس (الصبحية):** صباح الدخلة — نساء فقط + العريس + العروس ترقص على أنغام سودانية (تتعلم الرقص من معلمة قبل العرس).
7. **الفطور:** أهل العروس يقدّمون فطورًا للعريس + هدايا (جلابية ومصلاة لوالد العريس).
- تختلف التفاصيل بين المناطق (الجرتق في الشمال/الحناء في الغرب والشرق/زواج الأشباح في الجنوب — سابقًا).

## 2. المناسبات الدينية 🟢

### رمضان
- **الضراء:** موائد إفطار في الشوارع لعابر السبيل (تقاليد عريقة).
- **الحلومر/الآبري:** تشييد نسائي مبكر (إنبات الذرة + تجفيف + طحن).
- **التراويح + الاعتكاف + ختم القرآن** + المسحراتي («يا صايم قوم اتسحر»).
- **النوبة (الحضرة الصوفية):** ذكر + مدائح نبوية + جلاليب خضراء + حلقات دائرية (في مساجد الطرق الصوفية).
- **الدافوري:** كرة قدم ليلي للشباب.
- إفطارات جماعية (العمل/الدراسة/الأهل).

### المولد النبوي 🟢
- **الزفة:** موكب في كل مدينة + طبل + قصائد ومدائح صوفية.
- **الموالد الكبرى:** مولد الحسن (كرمة) + مولد السيد/الحسين (داخل السودان) + الموالد الصوفية.
- **شعر المديح النبوي** حاضر في الأعراس + الأعياد + العزاء.

### العيدان
- صلاة العيد + الذبيحة (الأضحى) + الكليجا/كعك العيد + زيارات الأهل.

## 3. الطرق الصوفية 🟢
- **الأنصار** (أتبار المهدي — أم درمان).
- **الختمية** (المرغني — كسلا/الشرق).
- **القادرية + السمانية + التيجانية + البرعية + الدركاوية + الشاذلية**...
- الخلاوي (تحفيظ القرآن) + الموالد + الذكر + الحضرة.
- السودان من أكثر البلاد الإسلامية تمسُّكًا بالطرق الصوفية + تأثيرها الاجتماعي والسياسي.

## 4. العادات الاجتماعية 🟢
- **الكرم/الضيافة:** قهوة/شاي + وجبة كاملة للزائر — لا يمكن زيارة بيت سوداني دون تقديمها.
- **المجالس (القعدات):** مجالس الرجال (المسيد + المضيفة) + النساء.
- **التكافل:** الجار + الحِلّة (الحي) + الأفراح والمآتم الجماعية.
- **الشلوخ (الوشوم):** علامة جمال عند بعض القبائل (النوبة + البقارة) — تراجعت.
- **العصبية القبلية:** الأنساب + العمدة + النظار (مؤسسات عرفية).

## 5. الفنون الشعبية 🟢
- **الدوبيت:** شعر شعبي رباعي (حماسة + غزل + حكمة) — الأشهر.
- **الطبل البقعة/الطبل العادي + الكرنك + الناي + الرق.**
- **الرقصات الشعبية:** الكردري (الشرق) + النبال + الشمباتي + الدليب (النوبة) + رقصة السيف (الجعليون/البقارة).
- **غناء البنات:** في الأعراس (رومانسي + مدح).
- **المديح النبوي + المدائح الصوفية.**
- مطربون كبار: محمد وردي + مصطفى سيد أحمد + عبد الكريم الكابلي + أبو عركي البخاري.

## 6. العمارة التراثية 🟢
- **العمارة النوبية:** قباب + ألوان زاهية + نقوش + بوابات (شمال السودان) + «الراكوبة» (مظلات سعف).
- **بيوت الطين + الحصى** (دارفور + كردفان).
- **الخلاوي:** مدارس قرآنية تقليدية (جريد + طين).
- **القبة المهدي** (أم درمان) + مسجد المهدي + المساجد التاريخية (سنار + سواكن).
- **سوق أم درمان + السوق العربي** (الخرطوم) + سواكن (عمارة مرجانية/خشب).
- «الراكوبة» = مظلة من سعف النخيل — رمز الضيافة.

## 7. الحرف التقليدية 🟢
- **صناعة المركوب** (الجلدي) — دارفور.
- **صناعة العنجريب** (السرير الحبالي).
- **نسيج البنيانية + الشالة** (الصوف).
- **صناعة الفخار + الزينة الذهبية + الحناء.**
- **الصمغ العربي** (تنظيف + تجميع) — كردفان.
- **السفن النوبية** (الأخشاب).

## 8. الثقافة المعاصرة 🟢
- السودان بلد **شعراء + مطربين + فنانين** كبار (الطيب صالح في الأدب — «موسم الهجرة إلى الشمال»).
- التعليم العالي (جامعة الخرطوم — 1902 + أم درمان الإسلامية + الجزيرة).
- المسرح + السينما (تراجعت) + الفنون التشكيلية (إبراهيم الصلابي).
- الإذاعة (أم درمان) — من أقدم الإذاعات العربية.

## 9. ربط الجغرافيا بالثقافة
- **النيل + الواحات** → عمارة نوبية + خلاوي + راكوبة + سفن + الأسماك في المائدة. 🟢
- **السافانا + المراعي** (كردفان/دارفور) → البقارة + خيام + رقصات السيف + الكرم البدوي + الصمغ.
- **الصحراء + الحر** → الجلابية البيضاء + العمامة + الكسرة + الكركديه + الحلومر.
- **الإسلام + الصوفية** → الموالد + الحضرة + الختمية + الأنصار + المديح النبوي + الخلاوي.
- **التنوع العرقي/القبلي** → تمايز في العادات (الجرتق/الحناء/الشلوخ) + رقصات متعددة + لغات متعددة + «تسامح تعايشي».
- **الموقع المعبري** (مصر/إثيوبيا/الجزيرة) → تأثرات ثقافية متبادلة + مطبخ مختلط + موسيقى متأثرة بالإفريقية والعربية.
- **الحرب (2023–الآن)** → تدمير جزء كبير من التراث + نزوح الثقافة + تغيُّر ديموغرافي. 🟠
