# المطبخ السوداني

> مطبخ سوداني متنوع يجمع العربي + الأفريقي + المصري + التركي + الهندي. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. نظرة عامة
- المطبخ السوداني = **مزيج عربي + أفريقي + مصري + تركي + هندي** بحكم الموقع المعبري. 🟢
- يعتمد على: **الذرة + الدخن + القمح** (خبز) + **الفول + العدس** + **اللحم** (ضأن/بقر/جمال) + **الأسماك** (النيل) + **الخضار** + **الصمغ العربي** (مشروبات).
- **«الملاح»** = المرق/الإدام الذي يُغمس بالخبز — أساس الوجبة.
- **«الويكة»** = البامية المجففة المطحونة (ت Thickener) — سمة سودانية.
- تأثر بـ: المصري (الفول/الطعمية) + التركي (الكباب/الكفتة/الشاورمة/البقلاوة) + الهندي (الكاري/السمبوسة/البرياني) + الشامي (الحلويات).

## 2. الخبز (أركان الوجبة) 🟢
- **الكسرة:** خبز رقيق من دقيق الذرة (أو الدخن/القمح) يُخبز على صاج — الأشهر + الوطني.
- **القراصة:** أثخن من الكسرة + قد تُحشى بالتمر/اللحم.
- **العصيدة:** عجينة من دقيق الذرة/الدخن + ماء + ملح — تُقدَّم مع الملاح.
- **اللغة/الجروف:** أنواع خبز.
- **الفطير/المخبازة:** فطائر محلاة.
- **الرغيف/العيش البلدي:** الخبز المدني.

## 3. الملاح (المرق/الإدام) 🟢
- **ملاح الويكة:** البامية المجففة المطحونة + لحم + طماطم + بصل + بهارات — الأشهر.
- **ملاح التقلية:** طماطم + لحم + ثوم + كزبرة.
- **ملاح الروب:** زبادي + لحم + بهارات (أحمر/أبيض).
- **ملاح نعيمية:** لحم + طماطم + «الويكة» + بهارات (نسبة لنعيمة).
- **ملاح أم رقيقة:** قرع + لحم.
- **ملاح السمك (المسقعة):** سمك النيل + طماطم + بهارات.
- **الملوخية:** أوراق الجوت + لحم/دجاج.
- **الرجلة (البقلة):** أعشاب خضراء مطبوخة.
- **البامية المفروكة:** بامية + طماطم + توابل.

## 4. الأطباق الرئيسية 🟢
- **الفول المدمس:** فول + زيت + توابل — فطور/عشاء مدن (تأثر مصري).
- **العصيدة بالويكة:** وجبة رمضانية وعيد.
- **الشية:** لحم مشوي + توابل حارة.
- **الأقاشي:** لحم نيء مفروم + توابل + ليمون (نوع من الكبة النيئة — شائع في الخرطوم).
- **الكمونية:** أمعاء الضأن + كمون.
- **الكوارع:** أقدام الضأن.
- **أم فتفت:** المعدة (الكرش) نيئة + كبد + ليمون (شائعة في الشمال).
- **المحشي:** طماطم + كوسة + باذنجان + عجور.
- **الكبسة السودانية:** أرز + لحم + بهارات (نسخة محلية).
- **الطعمية السودانية:** فلافل (تأثر مصري).

## 5. الحلويات والمشروبات 🟢
- **الحلويات:**
  - **مديدة النشأ/الدخن/الذرة/التمر هندي/الحلبة:** حساء حلو مكثف.
  - **الحلو مر (آبري):** رقائق طحين ذرة + بهارات (كزبرة + قرفة + هيل + عرق سوس + تمر هندي + كركديه + كمون) — حلو/مر.
  - **بسبوسة + أم علي + زلابية + كليجا + مربى التمر** + «السمن بالعسل».
  - **الدبس:** مركّز من تمر/خروب/رمان (حشوات).
- **المشروبات:**
  - **الكركديه (الكركدي):** من زهور الكركديه الحمراء — حامض، بارد/ساخن — الوطني.
  - **عرديب (تمر هندي):** حلو/لاذع.
  - **قونقليز (التبلدي):** من ثمرة الباوباو (غرب السودان).
  - **السوبيا:** عصير شعير مخمر خفيف.
  - **الحلومر (الآبري):** مشروب رمضاني.
  - **قهوة الجبنة:** قهوة سودانية + زنجبيل + قرنفل + فلفل.
  - **الشاي:** شاي أحمر + نعناع + سكر (السودانيون مدمنو شاي).

## 6. المقبلات والسلطات 🟢
- **الدكوة:** فول سوداني مطحون + ليمون + خضار.
- **البل/الخيار/البندورة:** سلطات جانبية.
- **الطحينة/التحميرة:** صلصة دبس/طماطم حار.

## 7. الطعام والمناسبات 🟢
- **رمضان:** إفطار جماعي + «الضراء» (إفطار في الشارع لعابر سبيل) + الحلومر/آبري + التراويح + «الدافوري» (كرة قدم ليلي) + النوبة الصوفية + المسحراتي.
- **العيد:** الكليجا + كعك العيد + الأقاشي + الشية.
- **الأعراس:** الجرتق + الأقاشي + الشية + الفطور للعريس.
- **العزاء (المآتم):** ولائم + الشية + الفول.

## 8. ربط الطعام بالجغرافيا والثقافة
- **النيل + الواحات** → الذرة + الدخن + القمح + الفول + الأسماك (الهامور/البلطي/البطة). 🟢
- **السافانا + المراعي** (كردفان/دارفور/الجزيرة) → الماشية + اللحوم (شية/أقاشي) + الحليب + «الصمغ» (السنط).
- **الموقع المعبري** (مصر/الحبشة/الجزيرة العربية/الهند) → المطبخ متعدد الأصول (مصري/تركي/هندي/شامي/إثيوبي).
- **الصحراء + الحر** → الكسرة الرقيقة (سريعة الطبخ على الحطب) + الملاحات المكثفة + المشروبات الباردة (الكركديه/عرديب).
- **الصوفية + رمضان** → «الضراء» + الحلومر + النوبة.
- **المجتمع القبلي** → الولائم الجماعية + «الزول» كرم الضيافة + إفطار الجار.
