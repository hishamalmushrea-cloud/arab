# المجتمع والقبائل والطوائف في جمهورية السودان

> تركيبة عرقية ولغوية بالغة التعقيد: >500 مجموعة عرقية. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر. تُورَد القضايا الحساسة بحياد.

---

## 1. السكان — الأرقام 🟡
- **السكان:** ~50–53 مليون (2025 تقديري) — تباين 46–52.9 مليون.
- **الكثافة:** ~27 نسمة/كم² (منخفضة — تتركز في النيل + الخرطوم + الوسط).
- **النمو:** ~2.5% سنويًّا (تقديري).
- 🟡 الوضع متغير بسبب الحرب + النزوح (~10–12 مليون نازح/لاجئ 2023–2026).

---

## 2. التركيبة الإثنية/القبلية 🟢🟡

### أ. عرب السودان — ~70% من السكان 🟢
- ينتشرون في **الشمال + الوسط + كردفان + دارفور (مستعربة)**.
- مسلمون سُنة + طرق صوفية.
- **المجموعة الجعلية العباسية** (الشمال + الوسط): الجعليون + الشايقية + البديرية + الرباطاب + المناصير + الميرفاب + الجموعية + البطاحين + العبابدة.
- **جهينة + الكواهلة** (كبرى + رعوية).
- **رفاعة + الشكرية + الدباسين** (النيل الأزرق + شرق).
- **البقارة** (كردفان + دارفور + رعوية): المسيرية + الرزيقات + الحوازمة + الهبانية + التعايشة + بنو هلبة.
- **الأشراف + الفونج** (الشرق + الوسط).
- 🟡 *رواية تاريخية + جدل علمي* حول أصول بعض القبائل (تعد عربية بنسبها + دراسات جينية تظهر اختلاطًا أفريقيًّا — السودانيون «خليط» لا عرق واحد).

### ب. النوبيون (الشمال) 🟢
- **الدناقلة + المحس + الكنوز + الحلفاويون** — شمال السودان (وادي النيل).
- لغات نوبية (الدنقلاوية + المحسية + الكنزية) + عربية.
- مسلمون + حضارة كوشية قديمة.
- اختلطوا بالعرب (ربيعة + كنز الدولة).

### ج. البجا/البداويت (الشرق) 🟢
- **الهدندوة + البني عامر + الحلنقة + الأمرار + البشاريين + العبابدة** — شرق السودان + ساحل البحر الأحمر + إريتريا.
- لغة «بداويت» (البجا) + عربية.
- مسلمون + رعاة + تجارة.

### د. الفور + الزغاوة + المساليت + البرتي + الداجو (دارفور) 🟢
- **الفور** (أكبر قبائل دارفور — السلطنة التاريخية).
- **الزغاوة + المساليت + البرتي + الداجو + التامة + الميدوب** — غير عربية + مسلمة.
- لغات نيلية صحراوية.
- 🟠 نزاعات قبلية + عرقية (دارفور 2003– + الحرب 2023).

### ه. جبال النوبة (كردفان) 🟢
- مجموعات متعددة غير عربية: **الكاوليب + الميري + النوبا + الكواليب + التيرال + الكواليب...** (~50 مجموعة لغوية).
- مسلمون + معتقدات إفريقية + لغات نوبية/كردوفانية.

### و. لغات نيلية (سابقًا — أصبحت في جنوب السودان) 🟡
- قبل انفصال الجنوب 2011: **الدينكا + النوير + الشلك + الأنواك + الباري + الزاندي** — انتقلت مع جنوب السودان.

---

## 3. الأديان والمذاهب 🟢🟡
- **الإسلام** = الغالبية (~97%) — **سُنة** (مالكية + شافعية) + **الطرق الصوفية** (أنصار + ختمية + قادرية + سمانية + تجانية + برعية + دركاوية).
- **المسيحية** (~2–3%) — كاثوليك + أنجليكان + أرثوذكس — أكبر في جبال النوبة + النيل الأزرق + الخرطوم.
- **معتقدات إفريقية تقليدية** — في جبال النوبة + دارفور + الجنوب (سابقًا).
- 🟡 النسب تقديرات (لا إحصاء رسمي ديني دقيق).

---

## 4. الطرق الصوفية (مكوّن أساسي) 🟢
- **الأنصار** (أتباع المهدي — أم درمان + كردفان) — تأثير سياسي (حزب الأمة).
- **الختمية** (المرغني — كسلا + الشرق + الخرطوم) — تأثير سياسي (الحزب الاتحادي الديمقراطي).
- **القادرية + السمانية + التيجانية + البرعية + الدركاوية + الشاذلية + العركية.**
- الخلاوي (تحفيظ القرآن) + الموالد + الحضرة.
- السودان من أكثر بلاد الإسلام تمسُّكًا بالصوفية + تأثيرها الاجتماعي والسياسي.

---

## 5. العائلات/الزعامات الدينية والسياسية 🟢
- **آل المهدي** (الصادق المهدي — الأنصار + حزب الأمة).
- **آل المرغني** (الختمية + الحزب الاتحادي).
- **آل الأزهري** (الأول).
- **آل البشير + آل البرهان + آل دقلو (حميدتي)** (الحرب 2023).
- الزعامات القبلية: الناظر + العمدة + الشيخ (في البقارة + الجعليين + غيرهم).

---

## 6. السياسة والمشاركة 🟠
- نظام: جمهورية اتحادية (دستوريًّا) — واقعيًّا **حرب + انتقال متعثر**.
- **مجلس السيادة الانتقالي** (البرهان) + الجيش + الدعم السريع (حميدتي).
- 🟠 *القضايا الحساسة* (الحرب + دارفور + النيل الأزرق + مثلث حلايب) تُورَد بحياد.
- **تأثير القبيلة في السياسة** كبير — زعامات قبلية + أحزاب (الأمة/الاتحادي/المؤتمر الوطني سابقًا/الحركة الشعبية شمال...).

---

## 7. التحديات الاجتماعية 🟠
- **الحرب (2023–الآن):** نزوح ~10–12 مليون + مجاعة + دمار بنيوي + انقسام ميداني.
- **النزاعات القبلية** (دارفور + كردفان + النيل الأزرق) — بين القبائل العربية وغير العربية.
- **الفقر + الأمية + الخدمات الضعيفة** (خارج الخرطوم).
- **الهجرة العكسية** (نزوح ريفي → مدن → نزوح بسبب الحرب).
- **تأثير تغير المناخ** (زحف صحراء + جفاف + سيول).

---

## 8. ربط المجتمع بالجغرافيا والتاريخ
- **الموقع المعبري** (عرب/أفريقيا) → اختلاط عرقي/لغوي عميق + هجرات عربية متتالية + ثقافة هجينة. 🟢
- **النيل** → استيطان نوبي + حضارات كوشية + الزراعة + وحدة وادي النيل.
- **السافانا + المراعي** (كردفان/دارفور) → البقارة الرعوية + قبائل غير عربية (فور/زغاوة) + الصمغ.
- **الجبال** (مرة/النوبة) → عزلة + حفظ ثقافات غير عربية + لغات متعددة.
- **الصحراء الشمالية** → نوبيون + تجارة + خلاوي + إسلام قديم.
- **الإسلام + العرب** (القرن 7–16) → أسلمة/تعريب + الطرق الصوفية + الأنساب العربية.
- **الاستعمار + الحكم الثنائي** (1899–1956) → المناطق المغلقة + فصل شمال/جنوب + بذور الصراع.
- **الحروب الأهلية + انفصال الجنوب + الحرب 2023** → تشظي المجتمع + نزوح + هويات متعددة. 🟠
