# اللباس في جمهورية السودان

> اللباس السوداني يجمع بين الأصالة العربية الإسلامية والظروف المناخية (حر + رطوبة منخفضة). علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. نظرة عامة
- اللباس التقليدي السوداني = زي وطني يجمع كل القبائل والأعراق + متكيّف مع الحرارة (فضفاض + قطني + ألوان فاتحة). 🟢
- **الجلابية** (رجالي) + **التوب/الثوب** (نسائي) = الزي القومي الموحَّد عبر القبائل + الأديان.
- اللباس الغربي منتشر في المدن + العمل.

---

## 2. اللباس الرجالي 🟢

### الجلابية السودانية (الزي القومي)
- ثوب طويل فضفاض أبيض (غالبًا) + أكمام طويلة واسعة + **بدون ياقة** (مفتوح حتى الصدر).
- قماش قطني خفيف (يستورد الفاخر من سويسرا/اليابان + الهند للتوب السرتي).
- أنواع:
  - **الجلابية العادية:** بيضاء يومية.
  - **جلابية الأنصارية (جناح أم جكو):** بجيبين أمامي وخلفي — أنصار المهدي.
  - **القميص السواكني:** ياقة + أزرار (شرق السودان) + الصديري + سروال السربادوب الواسع.
  - **ثوب السرتي:** ناصع البياض + زيق أحمر — للعرس (الجرتق).
  - **الجلابية الصوفية (المرقعة):** خضراء + رقبة وأكمام حمراء — للطرق الصوفية (الختمية).
  - **جلابية على الله:** قميص قصير + سروال (شائعة حديثًا).

### السروال
- بنطال واسع تحت الجلابية — أنواع: سربادوب (شرق) + أبو تكة.

### العمامة (العمة)
- قماش قطني أبيض (4–5 أم) من التوتال الإنجليزي/السويسري — تُلَف حول الرأس.
- طرق لفّ تعكس الشريحة الاجتماعية/الدينية (طريقة الأنصار/الختمية/الشايقية...).
- تحتها طاقية (قديمًا حرير أحمر).

### المركوب (الحذاء)
- نعل جلدي يدوي — يصنع في **دارفور** (الفاشر/الجنينة) + أم درمان.

### الإكسسوارات
- **السيف/الكرنك:** في المناسبات (البقارة/الجعليون).
- **العكاز:** رمز الهيبة (شعر المتنبي).
- **الجبة المهدوية:** أربع قطع (جبة + عراقي + سروال + طاقية) — أنصار المهدي.

---

## 3. اللباس النسائي 🟢

### التوب (الثوب السوداني) — الزي القومي النسائي 🟢
- قطعة قماش طويلة (4–9 أم) تُلَف حول الجسم فوق قميص/تنورة/بنطلون — تغطي الجسم كاملًا + الرأس عادة.
- أقمشة: **توتال** (إنجليزي/سويسري) + حرير + ساتان + كتان.
- الأنواع والأرقى: **توب رسالة لندن + توب أبو قجيجة + تياب الحرير الطبيعي + توتل ديانا لندن + عشكوب.**
- للمناسبات + المتزوجات (الألوان الزاهية + التطريز).
- عادة + **مؤشر اجتماعي** (المستوى المادي).

### الفستان/الدرايع (للأطفال/البنات)
- فساتين بسيطة + تطريز.

### العباية/الحجاب/النقاب
- انتشار حديث (تأثير إسلامي) + «الشيلة» (غطاء رأس).
- النساء المتزوجات: التوب + غطاء رأس.

### الإكسسوارات النسائية 🟢
- **الذهب:** الزمام (أنف) + الفال/الشليقر + الحجول (أرجل) + القلائد (برقناب).
- **الشلوخ (الوشوم):** علامات جمال تقليدية (عند بعض القبائل — تراجعت).
- **الحناء:** في الأعراس والموالد.
- **الطِّلق/التقصوت:** خرز + أحجار كريمة.

---

## 4. اللباس القبلي/الإقليمي 🟡
- **البقارة:** جلابية قصيرة + سروال + السيف + «البقارية» (نمط خاص).
- **النوبيون:** ألوان زاهية + طراز كوشي + عمامة صغيرة.
- **البجا (الشرق):** السواكنية + السربادوب.
- **الفور + الزغاوة:** ثياب أفريقية + تطريز + ألوان.
- **جبال النوبة:** ثياب قطنية + وشم.

---

## 5. اللباس الحديث 🟢
- الملابس الغربية منتشر في المدن (القمصان + البناطيل + الفساتين).
- الجلابية تبقى للجمعة + المناسبات + الأعراس + البيت.
- مصممات سودانيات يبتكرن تصاميم حديثة للتوب (الحرير + التطريز + الترتر).

---

## 6. ربط اللباس بالجغرافيا والثقافة
- **الحرارة الشديدة + الجفاف** → الجلابية الواسعة القطنية البيضاء (تهوية + عكس الشمس) + التوب الطويل الفضفاض (حماية + تهوية) + العمامة (حماية الرأس). 🟢
- **الإسلام + المحافظة** → تغطية الجسم + الحشمة + العباية/الحجاب (انتشار حديث).
- **التراث المهدوي + الصوفية** → الجلابية الأنصارية + الجبة المهدوية + الجلابية الخضراء للطرق.
- **التنوع القبلي/الإقليمي** → تمايز طفيف في الجلابية والتوب بين القبائل (سواكنية/بقارية/نوبية).
- **الهوية الموحَّدة** → الجلابية + التوب = رمز الهوية السودانية المشتركة عبر الأعراق (عرب + نوبيين + فور + غيرهم) — «نقطة التقاء». 🟢
- **التجارة التاريخية** → استيراد التوتال من إنجلترا/سويسرا + الحرير من الهند — تراث قديم.
- **المناسبات** → ثوب السرتي للجرتق + ثوب النشل/التوب في الأعراس + الجبة في الموالد.
