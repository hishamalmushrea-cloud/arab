# اللهجات في جمهورية السودان

> اللهجة السودانية موحَّدة نسبيًّا لكنها تتنوع تبعًا للقبيلة والمنطقة + لغات إفريقية محلية. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. نظرة عامة
- اللغة الرسمية: **العربية الفصحى** (التعليم/الإعلام/القانون) + الإنجليزية (دستوريًّا). 🟢
- **اللهجة السودانية** = عربية محكية أصيلة (بفصاحة لاحظها كثير من الباحثين — تشابه مع العربية الكلاسيكية) + أثر نوبي/إفريقي.
- **السودان من أكثر البلاد العربية تحدُّثًا بالعربية الفصحى** + لهجات إفريقية محلية (نوبية/فور/زغاوية/بداويت/نيلية).

## 2. المتغيرات الرئيسية للهجة السودانية 🟢🟡

### أ. اللهجة الجعلية (وسط وشمال)
- يتحدث بها **الجعليون + الشايقية + الرباطاب + المناصير + البديرية** (المجموعة الجعلية العباسية).
- فصاحة + إمالة + حذف (ود بدل ولد) + ضمائم.
- الشايقية: نبرة موسيقية + إمالة في أواخر الكلمات.

### ب. اللهجة الريفية/الخرطومية
- لهجة العاصمة + المدن (مزيج جعلي + نوبي + ريفي) — الأكثر انتشارًا إعلاميًّا.
- تأثر بـ: المصرية + الإنجليزية + التركية.

### ج. لهجة البقارة (كردفان/دارفور)
- رعوية بدوية + إمالة + خمسة → "خمسي" + فاطمة → "فاطني".
- قرابة باللهجات التشادية + الأفريقية.

### د. اللهجة الشرقية (البجا/البداويت)
- «الهداريت»/«البداويت» (لغة البجا) + عربية متأثرة.

### ه. اللهجة النوبية (الشمال)
- الدنقلاوية + المحسية + الكنزية + الحلفاوية (لغات نوبية) + عربية.

### و. لغات غير عربية (دارفور + جبال النوبة)
- **الفور + الزغاوية + المساليت + البرتي + الداجو + الميدوب** + لغات النوبة (كاوليب/ميري/تيرال...).

## 3. التأثيرات اللغوية الخارجية 🟢
- **النوبية:** مفردات (زول = رجل/شخص، كديسة = قطة، جداد = دجاج، عنجريب = سرير حبال).
- **المصرية:** (شفيخانة، أدبخانة، أوضة، طوبونة) — تأثير التركية المصرية.
- **التركية:** (تكل = مطبخ، جر = زير، شفيخانة = مستشفى، أدبخانة = مرحاض).
- **الإنجليزية:** تأثير الحكم الثنائي + التعليم.
- **الإفريقية:** مفردات البقارة + البجا + الفور.

## 5. الأمثال والتعبيرات الشعبية 🟡
- "أكل يا كمي قبل فمي" (مثل جحا السوداني).
- "امشي مقيَّد" (تسلّك كالناقة المربوطة).
- "الزول ده كسّار ثلج" (يتملّق).
- "الزول ده دقس" (وقع في ورطة).
- "الوعة عند ناس فلان" (العزومة/الأكل).
- "اللي يبغي العرس ما يقعد في البيت" (مَن يطلب المجد يجتهد).
- "القرش الأبيض ينفع اليوم الأسود" (الادخار).

## 6. شعر الدوبيت 🟢
- **الدوبيت** = فن شعبي سوداني (رباعية بالفصحى/العامية) — حماسة + غزل + حكمة.
- من أشهر أبياته: "أحمر لونو من دم الرجال دُكَّرنا / وتتبعنا السباع في رواحنا وإن بكَّرنا / وين يجد المجال عازلناشِن أنكَرنا / تعرفنا الدهور تثبت نبانا ذِكِرنا".

## 7. الموسيقى والغناء 🟢
- **الطبل البقعة** + **الناي** + **الرقصات الشعبية** (الكردري/النبال/الشمباتي).
- **غناء البنات** (أعراس) + **المديح النبوي** (صوفي).
- مطربون كبار: محمد وردي + مصطفى سيد أحمد + عبد الكريم الكابلي.

## 8. ربط اللهجة بالثقافة والجغرافيا
- **الجغرافيا الشاسعة + التعدد القبلي** → تباين لهجي قبلي/مناطقي (جعلي/شايقي/بقّاري/نوبي/بجاوي). 🟢
- **التراث البدوي + الرعي** (كردفان/دارفور) → مفردات الإبل + الماشية + الصحراء.
- **النيل** → مفردات النوبيين + الزراعة + المراكب.
- **التاريخ العربي الإسلامي** → الفصاحة (يحفظ السودانيون القرآن + الشعر) + تأثير المصرية (التركية المصرية).
- **المجتمع المتعدد الأعراق** → استيعاب مفردات إفريقية (زول/كديسة/عنجريب) في العامية العربية.
