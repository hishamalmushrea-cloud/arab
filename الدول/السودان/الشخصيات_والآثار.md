# الشخصيات والآثار في جمهورية السودان

> حكام + زعماء + أعلام دينيون/ثقافيون + 2 موقع تراث عالمي (يونسكو) + حضارة كوش/مروي. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر.

---

## 1. الشخصيات التاريخية والدينية 🟢

### محمد أحمد المهدي (1844–1885) 🟢
- زعيم ديني + سياسي — أعلن المهدية في جزيرة أبا (1881) → حرّر الخرطوم (1885) + قتل غوردون باشا.
- توفي 22 يونيو 1885 (حمى) + دُفن في أم درمان (القبة).
- من الدناقلة (نسب حسيني) + الطريقة السمانية.
- مؤسس الدولة المهدية + زعيم «الأنصار».

### عبد الله التعايشي (الخليفة) 🟢
- خليفة المهدي (1885–1899) + من البقارة (التعايشة).
- حكم أم درمان + قاوم الإنجليز حتى مقتله في أم دبيكرات (1899).

### الزبير باشا رحمة 🟢
- تاجر + فاتح دارفور + بحر الغزال (القرن 19) — أبرز زعماء السودان قبل المهدية.

### علي عبد اللطيف 🟢
- زعيم ثورة 1924 (اللواء الأبيض) — أول حركة وطنية سودانية حديثة (من النوبيين + الجيش).

## 2. رؤساء/حكام السودان المعاصرين 🟢

### إسماعيل الأزهري (1901–1969) 🟢
- أول رئيس مجلس سيادة (1956–1958) + (1965–1969) — زعيم الاستقلال + حزب الأمة القومي.
- من البديرية الدهمشية الجعلية.

### إبراهيم عبود (1900–1983) 🟢
- أول انقلاب عسكري (1958–1964) — رئيس المجلس العسكري الأعلى.

### جعفر النميري (1930–2009) 🟢
- ثورة مايو 1969 + حكم 1969–1985 + اتفاقية أديس أبابا (1972) + الشريعة (1983) + الحرب الأهلية الثانية.

### الصادق المهدي (1935–2020) 🟢
- آخر رئيس وزراء منتخب (1986–1989) + زعيم حزب الأمة + الأنصار + حفيد المهدي.

### عمر البشير (1944–) 🟢
- انقلاب الإنقاذ (1989) + حكم 1989–2019 + المؤتمر الوطني + اتفاقية نيفاشا (2005) + انفصال الجنوب (2011) + محكمة الجناية (2008) + ثورة 2019.

### عبد الفتاح البرهان 🟠
- رئيس مجلس السيادة الانتقالي (2019–الآن) + قائد الجيش + انقلاب 2021 + حرب 2023 (مع حميدتي).

### محمد حمدان دقلو (حميدتي) 🟠
- قائد قوات الدعم السريع (RSF — تأسست 2013 من الجنجويد) + نائب المجلس السيادي + خصم البرهان في حرب 2023.
- من البقارة (التعايشة) + دارفور.

### عبد الله حمدوك 🟢
- رئيس وزراء مدني (2019–2021 + 2021–2022) — تكنوقراط + اقتصادي + أُقيل بانقلاب 2021.

## 3. أعلام ثقافيون وفنانون 🟢
- **الطيب صالح** (1929–2009): أديب — «موسم الهجرة إلى الشمال» + «عرس الزين» + «منصيص» — من أعظم روائيي العرب.
- **محمد وردي** (1932–2012): مطرب + ملحن + رمز الأغنية السودانية (نوبي).
- **عبد الكريم الكابلي** (1932–2021): مطرب + باحث فولكلور.
- **مصطفى سيد أحمد** (1949–2017): مطرب.
- **إبراهيم الصلابي**: فنان تشكيلي.
- **البروفيسور عبد الله الطيب** (1922–2003): لغوي + شاعر + عميد الآداب.
- **خليل فرح** (شاعر الدوبيت + «عرس أم درمان»).

## 4. مواقع التراث العالمي (يونسكو) — 2 موقع 🟢

### جبل البركل ومواقع نبتة — يونسكو 2003 🟢
- في الولاية الشمالية قرب كريمة (400 كم شمال الخرطوم).
- جبل صغير (98–104 م) + قمة مسطحة — **العاصمة الدينية لمملكة نبتة** + مركز تتويج ملوك كوش.
- 13 معبدًا + 3 قصور + 15 هرمًا (الأسرة 25 المصرية — بعانخي + شباكا + شبتكو + طهرقا).
- معبد آمون + موت + البصل.
- مدافن: **الكرو + نوري** (هرم طهرقا — أكبر أهرام السودان) — فلكي (تعامد 31 يوليو + 16 نوفمبر).
- معبد صنم أبو دوم.

### جزيرة مروي — يونسكو 2011 🟢
- في ولاية نهر النيل (البجراوية — 200 كم شمال الخرطوم).
- ثلاث مجموعات: المدينة الملكية + مدافن مروي (أهرامات البجراوية) + موقع النقعة.
- **أكثر من 200 هرم** (أكثر من مصر) — شديدة الانحدار + صغيرة + تعود للقرن 8 ق.م–4 م.
- معابد + قصور + منشآت مائية + حمام ملكي.
- الكتابة المروية (لم تُفكَّك بالكامل).
- تأثيرات متوسطية + مصرية + أفريقية + هندية.
- 🟠 مهددة بالحرب + الرمال + السيول + النهب.

## 5. المواقع الأثرية الأخرى 🟢
- **كرمة** (الشلال الثالث) — أقدم مملكة سودانية (~2500 ق.م) + سور + قصر.
- **النقعة + المصورات البجراوية** — معابد مروية (الأيون + أبودم).
- **سوبا** (علوة) — **ولاية الخرطوم**.
- **دنقلا العجوز** (المقرة) — **الشمالية**.
- **سنار** (الفونج) — **ولاية سنار** (الحاضرة الإدارية **سنجة**).
- **الفاشر** (الفور) — **شمال دارفور**.
- **سواكن** — **البحر الأحمر**.
- **الدندر** (محمية) — **سنار**.
- **أم دبيكرات** — نطاق **شمال كردفان** غالبًا 🟡.

- **متحف جبل البركل** (كريمة — 1996) + متحف مروي.

## 7. المعالم الحديثة 🟢
- **القبة المهدي + مسجد المهدي** (أم درمان).
- **جامع الخرطوم الكبير + جامع النيلين** (على المقرن).
- **قصر الجمهورية + المقرن + كوبري الخرطوم** (البريطانيون).
- **سد مروي** — **الولاية الشمالية** (محلية مروي) لا نهر النيل.
- **شجرة التبلدي** (شجرة الباوباو — رمز غرب السودان).
- **الخرطوم (3 مدن):** الخرطوم + بحري + أم درمان — العاصمة المثلثة.

## 9. ربط الآثار بالتاريخ والجغرافيا
- **كرمة + كوش + مروي** = جلّ الآثار السودانية → أكبر مدافن أهرامات في العالم (أكثر من مصر) + حضارة مستقلة عن الفرعونية لكن متأثرة بها. 🟢
- **النيل** = العصب الذي حمل هذه الحضارات (مدن على الضفاف + معابد + مقابر).
- **الموقع المعبري** (مصر/إثيوبيا/البحر الأحمر/وسط أفريقيا) → تجارة + تأثيرات متبادلة + الكتابة المروية + الفلك.
- **الإسلام + العرب** → مساجد سنار + الفاشر + سواكن + المهدية (القبة).
- **الممالك النوبية المسيحية** → سوبا + دنقلا العجوز + كنائس.
- **التراث المهدوي** → القبة + بيت الخليفة + أم درمان عاصمة المهدية.
- 🟠 **الحرب (2023–الآن):** تهدد الآثار بالرمال + السيول + النهب + توقف الفرق الدولية — معظم المواقع بلا حراسة.
