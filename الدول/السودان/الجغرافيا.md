# جغرافيا جمهورية السودان

> علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر.

---

## 1. الموقع والمساحة
- **الموقع:** شمال شرق أفريقيا — معبر بين العرب (شمال) وأفريقيا جنوب الصحراء (جنوب) + ساحل البحر الأحمر.
- **الإحداثيات:** 8°–23° شمالًا، 21°–39° شرقًا (يخترقه مدار السرطان ~23.5° ش).
- **المساحة:** **1,886,068 كم²** — ثالث أكبر دولة في أفريقيا (بعد الجزائر + الكونغو الديمقراطية) + **أكبر دولة عربية مساحةً**. 🟢
- (قبل انفصال الجنوب 2011: ~2,505,813 كم² — أكبر دولة في أفريقيا).

## 2. التضاريس (ثلاثة أحزمة) 🟢
- **الشمال:** صحراء **النوبية + البيوضة** + صخور جيرية + كثبان رملية — قاحلة باردة ليلًا.
- **الوسط:** سهول **الجزيرة** (بين النيلين) الخصبة + السافانا الجافة + المشاريع الزراعية.
- **الجنوب (سابقًا — أصبح جنوب السودان):** السافانا الرطبة + مستنقعات **السدّ (Sudd)** + غابات.
- **الغرب (دارفور):** جبال **مرة (Marrah)** — بركانية + جبل مرة **3,042 م** (أعلى قمة) + بحيرة فوهة.
- **الشرق:** تلال البحر الأحمر + صحراء + ساحل + سهول.
- **أعلى نقطة:** **جبل مرة** (3,042 م) في دارفور. 🟢
- عمومًا: سهل شاسع يجري فيه النيل شمالًا.

## 3. النيل (العصب الحيوي) 🟢
- **النيل الأبيض:** يأتي من البحيرات العظمى (أفريقيا شرق) — مارًّا بجنوب السودان (السدّ) → الخرطوم.
- **النيل الأزرق:** يأتي من **بحيرة تانا** (إثيوبيا) — يحمل الطمي + الفيضان → الخرطوم.
- **المقرن (الملتقى):** عند **الخرطوم** يلتقي النيلان → **النيل الرئيسي** يجري شمالًا نحو مصر.
- ظاهرة فريدة: **خط ظاهر** بين المياه (الرمادية للأزرق + الصافية للأبيض) عند الملتقى. 🟢
- **سد مروي:** الـ4 شلالات في الشمال → سد مروي الكهربائي (الـ4).
- **بحيرة النوبة ( Nass er):** جنوب (على الحدود مع مصر).

## 4. المناخ 🟢
- **تصنيف:** شمال صحراوي (BWh) → وسط سافانا (BSh) → جنوب استوائي/سافانا رطبة (سابقًا في جنوب السودان).
- **الصيف (أبريل–يونيو):** شديد الحرارة في الوسط والشمال — >40°م في الخرطوم + >45°م في الشمال.
- **الشتاء (نوفمبر–فبراير):** معتدل/بارد — 15–25°م (الشمال أبرد + «سقط/سقطة» = برد قارس).
- **الأمطار:** <50 مم شمالًا → ~800–1200 مم جنوبًا (يونيو–سبتمبر).
- **الرياح:** «المعمار» شتاء + «الهبوب» صيفًا + «الشمالي» جاف + «الجنوبي» رطب.
- **تغير المناخ:** زحف صحراء + موجات جفاف + سيول (2020–2024) هددت آثار مروي.

## 5. الموارد المائية
- **النيل** = المصدر الرئيسي للمياه + الزراعة + الكهرباء (سد مروي + خزان سنار + خزان الروصيرص).
- **أمطار موسمية** (الخريف) في الوسط والغرب والجنوب.
- **مياه جوفية** (طبقة النوبة الرملية) — شاسعة لكن محدودة الاستغلال.
- 🟠 نزاع سد النهضة الإثيوبي: السودان + مصر + إثيوبيا — حساس (يُورَد بحياد).

## 6. التربة والغطاء النباتي
- **التربة:** غرينية خصبة في وادي النيل + الجزيرة + طينية سوداء (الجزيرة) + رملية صحراوية شمالًا.
- **الغطاء النباتي:** صحراوي شمالًا → سافانا أعشاب + شوكية وسطًا → سافانا أشجار (السنط/الدليب/الطلح) + غابات جنوبًا.
- **غابات الهشابة** (السنط) = مصدر الصمغ العربي (كردفان + دارفور).

## 7. الموارد الطبيعية
- **الذهب** (الاحتياطيات ~533 طن + >1100 قيد التقييم) — خامس/ثالث منتج أفريقي. 🟢
- **النفط** (فقد ~75% بعد انفصال الجنوب) — حقول وسط + جنوب شرق.
- **الصمغ العربي** (السنط) — 70–80% عالميًّا. 🟢
- **الحديد + النحاس + الكروم + الفضة + اليورانيوم** (محدودة الاستغلال).
- **الثروة الحيوانية:** ~110–130 مليون رأس (أبقار + ضأن + ماعز + جمال) — كبيرة أفريقيًّا.
- **الأراضي الزراعية:** ~16.9 مليون هكتار صالحة + ~84 مليون هكتار مراعي.

## 8. المناطق الطبيعية والمحميات
- **جبال مرة** (دارفور) + **السدّ (Sudd)** (جنوب — أصبح في الجنوب).
- **حظائر البحر الأحمر** (شعاب مرجانية) + **محمية الدندر** (الحظيرة الوطنية — أكبر محمية).
- **محمية الرهد** + جبال النوبة + جبال البحر الأحمر.

## 9. النقل والربط
- **الموانئ:** **بورتسودان** (البحر الأحمر — الرئيسي) + سواكن + عثمان دقنة.
- **المطارات:** الخرطوم (دولي — متوقف بالحرب) + بورتسودان + نيالا + الأبيض + كسلا. 🟠
- **السكك الحديدية:** شبكة قديمة (الخرطوم–بورتسودان + وادي حلفا–الخرطوم) — متدهورة.
- **الطرق:** شاسعة لكن ضعيفة الصيانة — الخرطوم–بورتسودان + الخرطوم–الجنينة.
- **النيل:** ملاحة في بعض المقاطع (الخرطوم–دنقلا محدودة).

## 10. ربط الجغرافيا بالثقافة (رؤية تطبيقية)
- **النيل** = العصب الذي ربط الحضارات (كرمة/كوش/مروي/الممالك النوبية) + أوجد الزراعة في الجزيرة + حسَّس السودانيين بمركزية المياه. 🟢
- **الصحراء الشمالية** → استيطان نوبي على ضفاف النيل + طرق تجارية + تسامح صحراوي + الجلابية البيضاء الواسعة للحر. 🟢
- **السافانا + المراعي** (كردفان/دارفور/الجزيرة) → حياة **البقارة** الرعوية + الخيام + الثروة الحيوانية + الصمغ العربي.
- **جبال مرة + جبال النوبة** → عزلة + حفظ ثقافات غير عربية (الفور + الزغاوة + النوبة) + زراعة مدرّجية.
- **البحر الأحمر** → بورتسودان + سواكن + تجارة تاريخية + ثقافة البجا/البداويت.
- **الموقع المعبري** (عرب–أفريقيا) → ثقافة هجينة + لغات متعددة + مطبخ متنوع + قبائل عربية مستعربة مع إفريقية.
- **اتساع المساحة + التباين** → تقسيمات إدارية معقدة + نزاعات طرفية (دارفور/الجنوب/النيل الأزرق) + فدرالية.
