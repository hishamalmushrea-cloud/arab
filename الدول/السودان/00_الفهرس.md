## العاصمة
- **الخرطوم** — العاصمة السياسية + مقر الرئاسة + ملتقى النيلين (الأبيض والأزرق). 🟢
- **أم درمان** — العاصمة الوطنية التاريخية + المهدية + القبة.
- **الخرطوم بحري** — الثالثة (الصناعية + شمال).
- مدن رئيسية أخرى: بورتسودان (الميناء الرئيسي — البحر الأحمر) + نيالا (دارفور) + الأبيض (كردفان) + كسلا + دنقلا + الفاشر + ودمدني (الجزيرة) + سنار.

(دراسة كل عاصمة في ملف مستقل ضمن مجلد `العواصم/` في المرحلة الثالثة.)

## ما يميز السودان باختصار
- **ثالث أكبر دولة في أفريقيا** مساحةً (1,886,068 كم²) بعد الجزائر + الكونغو الديمقراطية — و**أكبر دولة عربية** مساحةً.
- **مهد حضارات عريقة:** كرمة (~2500 ق.م) → كوش/نبتة → **مروي** (أكثر من 200 هرم — أكثر من مصر) → الممالك النوبية المسيحية (نوباتيا/المقرة/علوة) → سلطنة الفونج/سنار + سلطنة الفور.
- **موقع استراتيجي:** ملتقى العرب وأفريقيا جنوب الصحراء + البحر الأحمر (853 كم ساحل).
- **النيل:** ملتقى النيلين (الأبيض + الأزرق) في الخرطوم (المقرن).
- **أكبر منتج للصمغ العربي عالميًّا** (~70–80%) + منتج ذهب كبير + سلة غذاء محتملة.
- **تاريخ حديث مضطرب:** استقلال 1956 → حروب أهلية (1955–1972، 1983–2005) → انفصال جنوب السودان 2011 → ثورة 2019 → حرب 2023.
- **تركيبة عرقية معقّدة:** >500 مجموعة عرقية + عرب (~70%) + نوبيين + فور + زغاوة + مساليت + غيرهم.
- **موقعان تراث عالمي (يونسكو):** جبل البركل/نبتة (2003) + جزيرة مروي (2011).
