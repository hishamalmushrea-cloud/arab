# دولة ليبيا — الجغرافيا

> منهجية: تربط التضاريس بالمناخ والمياه والثقافة (اللباس/الطعام/العمارة/السكن). علامات الثقة: 🟢/🟡/🟠.
> المصادر: ويكيبيديا (جغرافيا ليبيا)، الجزيرة، البوابة الرسمية، aspdkw، wildlife.org.ly.

---

## 1. الموقع والمساحة 🟢

- **شمال أفريقيا / المغرب العربي** — أقصى شرق المغرب العربي — حلقة وصل بين المشرق والمغرب.
- **المساحة:** 1,759,540 كم² — **رابع أكبر دولة أفريقية** + **أكبر دولة مغاربية**.
- **الإحداثيات:** 18°–33°N و9°–25°E.
- **الحدود:** مصر (شرق) + السودان (جنوب شرق) + تشاد + النيجر (جنوب) + الجزائر + تونس (غرب) + البحر المتوسط (شمال، ساحل ~1,770–2,000 كم).
- **الحدود البرية:** ~4,300 كم (الأطول مغاربيًّا) — معظمها صحراوية.

---

## 2. التضاريس الكبرى: ثلاثة نطاقات 🟢

> ليبيا = **صحراء في 95%** + شريط ساحلي خصب + مرتفعات. هذا التقسيم هو مفتاح فهم توزيع السكان (90% في الساحل الشمالي) والثقافة.

### (أ) نطاق السهول الساحلية 🟢
- يمتد على طول البحر المتوسط (شمال) — يتسع في الوسط + يضيق في الشرق.
- **السهول:** سهل **الجفارة** (طرابلس غربًا) + سهل **الخمس** + سهل **مصراتة** + سهل **بنغازي** + سهل **سرت** + السهول الشرقية (برقة).
- **الأهمية:** يضم **معظم السكان + المدن + الزراعة** (شريط 2% من المساحة).
- **الأثر الثقافي:** زراعة (زيتون/تمور/حبوب) + حضر + موانئ + مطبخ متوسطي.

### (ب) نطاق المرتفعات الشمالية 🟢
- **الجبل الأخضر** (شرق/برقة): ارتفاع ~865 م — **أعلى أمطار** (400–600 مم/سنة) + غابات + أخصب منطقة في ليبيا + الزراعة (فواكه/حبوب) + مدينة البيضاء.
- **الجبل الغربي / جبل نفوسة** (غرب): هضبة جيرية + أمازيغ (نفوسة) + زراعة محدودة.
- **هضبة البطنان والدفنة** (أقصى شرق): تلال.
- **الأثر الثقافي:** زراعة + غابات + مناخ معتدل + لباس صوفي دافئ + أمازيغ.

### (ج) النطاق الصحراوي (95% من المساحة) 🟢
- **الصحراء الكبرى** — تنوع تضاريسي:
  - **الحمادة الحمراء:** هضبة صخرية صلبة (أعظم اتساعًا).
  - **العرق/الرملة/الأدهان:** مسطحات رملية (الكثبان) — **بحر الرمال الكبير** (أقصى شرق) + **عرق مرزوق** (جنوب).
  - **الأودية:** وادي الشاطئ + وادي الحياة + وادي الأجال.
  - **المنخفضات الشمالية:** منخفض الجغبوب + أوجلة + جالو + مرادة.
  - **الأحواض:** حوض أوباري + حوض مرزق + حوض الكفرة (واحات + مياه جوفية).
  - **الجبال الصحراوية:** **جبال تيبستي** (أقصى جنوب — قمة **بكو بيتي/Bikku Bitti** 2,286 م — **أعلى قمة في ليبيا**) + **جبال أكاكوس** (جنوب غرب — آثار + نقوش) + جبل العوينات (ثلثي الحدود مع مصر/السودان) + جبل الهروج + جبل السودا.
- **الأثر الثقافي:** واحات (تمور/زيتون) + رعي بدوي + سياحة صحراوية + الطوارق/التبو + «النهر الصناعي العظيم» (مياه جوفية).

## 4. المياه 🟢

| العنصر | الوصف |
|---|---|
| الأنهار | **لا أنهار دائمة الجريان** — وديان موسمية (تجري بعد الأمطار). |
| المياه الجوفية | **طبقات ضخمة تحت الصحراء** (حوض الكفرة + فزان + أوباري) — مياه fossil عتيقة. |
| **النهر الصناعي العظيم** | **أكبر مشروع ري تحت أرضي عالميًّا** — ينقل المياه الجوفية من الصحراء (الكفرة/تسرير/سرير) إلى الساحل (طرابلس/بنغازي) عبر أنابيب ضخمة — بدأ 1983/1991 + مراحل. 🟢 |
| تحلية المياه | محطات تحلية على الساحل. |
| التحدي | **إجهاد مائي** شديد — ليبيا من أكثر الدول شُحًّا للمياه العذبة. |

---

## 5. المناخ 🟢

> المناخ **متدرّج** من الشمال إلى الجنوب: متوسطي → شبه جاف → صحراوي. ليبيا تقع في التقاء المؤثرات المتوسطية والصحراوية (الصحراء الكبرى 95% + المتوسط).

- **الساحل الشمالي:** **متوسطي** — شتاء معتدل ممطر + صيف حار جاف (~30°م) + رطوبة.
- **المرتفعات (الجبل الأخضر):** معتدل — لا يتجاوز 30°م صيفًا + ثلوج شتاءً (أعلى أمطار 400–600 مم).
- **الداخل/الصحراء:** **صحراوي جاف** — صيف حار جدًّا (>50°م أحيانًا) + شتاء بارد (~5°م) + أمطار < 50 مم + عواصف رملية (القبلي).
- **5 مناطق مناخية** (متوسطي/شبه جاف/صحراوي/جبلي).

### ربط الجغرافيا بالثقافة 🟢

| المنطقة | المناخ/التضاريس | الأثر الثقافي |
|---|---|---|
| الساحل (طرابلس/مصراتة) | متوسطي + سهول | حضر + زيتون/تمور + موانئ + الكسكسي/البوريك |
| الجبل الأخضر (برقة) | معتدل + أمطار + غابات | زراعة (فواكه/حبوب) + لباس صوفي + مقاومة (عمر المختار) |
| الجبل الغربي (نفوسة) | جبلي + أمازيغ | زراعة + أمازيغ (نفوسية) + إباضية |
| الصحراء/الواحات (فزان/الكفرة) | صحراوي + واحات | تمور + رعي + الطوارق/التبو + سياحة صحراوية + «النهر الصناعي» |

---

## 6. التربة والغطاء النباتي 🟢

- **الساحل:** تربة متوسطية خصبة (محدودة) — زيتون + تمور + حبوب + خضراوات.
- **الجبل الأخضر:** أخصب تربة + غابات (صنوبر/بلوط/سرو) — ~0.01% غابات.
- **الصحراء:** رملية/حصوية + سبخات — نباتات صحراوية متفرقة + واحات (نخيل).
- **الغطاء النباتي:** متناثر — يزدهر بعد الأمطار في الداخل.
- **التصحّر 🟡:** زحف الصحراء + جفاف → تحدٍّ بيئي.

---

## 7. المناطق الطبيعية والمحميات 🟢

- **محمية الكوف (الجبل الأخضر)** — غابات + تنوع حيوي.
- **محمية بحيرة أفينيا** (أقصى شرق) — سبخات + طيور.
- **محمية جبال أكاكوس** — تراث يونسكو (آثار + نقوش صخرية).
- **محمية غدامس** — واحة + تراث يونسكو.

---

## 8. التحديات البيئية 🟡

1. **الإجهاد المائي** — شُح المياه العذبة + اعتماد على الجوفية (غير متجددة) + تحلية.
2. **الحرارة الشديدة** + العواصف الرملية (القبلي).
3. **التصحّر** — زحف الصحراء.
4. **تآكل السواحل** + ارتفاع البحر.
5. **تلوث النفط** — الانسكابات + حرق الآبار.
6. **الضعف المؤسسي** (بعد 2011) — غياب إدارة بيئية فعالة.

---

## خلاصة جغرافية

ليبيا = **دولة شاسعة** (1.76 مليون كم² — رابع أفريقيا) **95% صحراء** + شريط ساحلي متوسطي خصب (يضم 90% من السكان) + مرتفعات (الجبل الأخضر + نفوسة) + جبال صحراوية (تيبستي/أكاكوس) + واحات (الكفرة/أوباري). المناخ متوسطي→صحراوي. لا أنهار دائمة — اعتماد على **النهر الصناعي العظيم** (أكبر مشروع ري تحت أرضي عالميًّا). هذا التنوع (ساحل + جبل + صحراء + واحات) هو **أساس التباين الثقافي** بين طرابلس (حضري/متوسطي) + برقة (جبلي/أمازيغ) + فزان (صحراوي/طوارق/تبو). 🟢
