## 2. القطاعات الاقتصادية

### (أ) النفط والغاز 🟢 — عصب الاقتصاد
- **الاحتياطي:** **أكبر احتياطي نفطي مؤكد في أفريقيا** (~48 مليار برميل) + خام عالي الجودة (خفيف حلو).
- **الإنتاج:** ~1.6 مليون برميل/يوم قبل 2011 → تذبذب (0.4 مليون 2015 + 0.4 مليون حصار 2020 + ~1.4 مليون 2024 عند الاستقرار).
- **الحقول:** الهلال النفطي (سرت + رأس لانوف + البريقة + الزاوية) + الكفرة + الواحات + أوباري + الحمادة.
- **المؤسسة الوطنية للنفط (NOC):** إنتاج + صادرات (انقسامتان 2014–2021: طرابلس + بنغازي).
- **الموانئ النفطية:** رأس لانوف + البريقة + الزاوية + مصلة + الخُمسة + بنغازي + طبرق (مرسى الحريقة).
- **الغاز:** احتياطي ثاني أفريقي + تصدير (أنبوب الغاز الليبي-الإيطالي Greenstream).
- 🟡 **التحدي الكارثي:** توقفات الإنتاج المتكررة بسبب الصراع + إغلاق الموانئ على أيدي المليشيات → خسائر بمليارات الدولارات + انكماش الناتج.

### (ب) القطاع غير النفطي 🟡
- **الزراعة:** محدودة (الصحراء 95%) — الساحل + الجبل الأخضر + الواحات — زيتون/تمور/حبوب/فواكه/خضار + الصيد البحري. أقل من 2% من الأراضي صالحة.
- **الصناعة:** petrochemicals + تكرير + مواد بناء + غذائية — محدودة.
- **الخدمات:** تجارة + نقل + اتصالات + مالية — متضررة بعد 2011.
- **السياحة:** **كامنة ضخمة** (آثار + صحراء + شواطئ) لكن شبه معدومة بعد 2011 (الأمن).
- **النهر الصناعي العظيم:** أكبر مشروع ري تحت أرضي عالمي (مياه جوفية للساحل).

### (ج) القطاع العام 🟢
- يهيمن على الاقتصاد — يوظف **85% من القوى العاملة** (تضخم الجهاز الإداري).
- ثلث الميزانية للرواتب + الأجور.
- بطالة مقنعة كبيرة.

## 3. الصادرات والواردات 🟢

- **الصادرات:** **النفط الخام (90%+)** + المكرر + الغاز + البتروكيماويات.
- **الواردات:** machinery + غذاء + سيارات + سلع استهلاكية + مواد أولية.
- **الحاجة للواردات:** ~30 مليار $ سنويًّا (تمويل من النفط).
- **الميزان التجاري:** فائض (بفضل النفط) — لكن يتقلَّب بشدة.
- **العمالة الأجنبية:** ~1.5 مليون عامل (تحويلات).

## 4. التحديات الاقتصادية 🟡 (كارثية بعد 2011)

| التحدي | الوصف | الثقة |
|---|---|---|
| **الانقسام السياسي** | حكومتين (طرابلس + بنغازي) → سياسات موازية + إنفاق موازٍ + طباعة نقود | 🟢 |
| **توقفات النفط** | إغلاق الحقول/الموانئ على أيدي المليشيات → خسائر بمليارات + انكماش | 🟢 |
| **الفساد المستشري** | في المؤسسات + قطاع النفط → عرقلة التنمية | 🟢 |
| **تدهور الدينار** | فقد 35%+ من قيمته → تضخم + تآكل القدرة الشرائية | 🟢 |
| **الدين العام** | ارتفع (137 مليار دينار 2021) → عبء | 🟢 |
| **البطالة** | ~20% (رسميًّا) + بطالة مقنعة في القطاع العام | 🟢 |
| **الاقتصاد الموجَّه** | الدولة تسيطر + القطاع الخاص ضعيف → ضعف التنويع | 🟢 |
| **البنية التحتية المتضررة** | حروب + إهمال → كهرباء + خدمات | 🟢 |
| **العمالة الأجنبية** | 1.5 مليون → تحويلات + ضغط | 🟢 |
| **اللامساواة الجهوية** | الساحل/طرابلس متقدِّم vs الجنوب/الداخل — محرك احتجاجات | 🟢 |
| **التدخلات الأجنبية** | مرتزقة + قوات أجنبية → تعقيد | 🟡 |

## 5. السياق السياسي-الاقتصادي (حياد 🟡)

- **قبل 2011 (القذافي):** اقتصاد موجَّه + رعاية اجتماعية + نفط + عقوبات (1996–2003) → تحسن 2003–2010 (نمو 10.6% 2010).
- **2011 (الثورة):** انهيار الإنتاج → −41.8% → تعافٍ 2012 (+20.1%).
- **2014 (الانقسام):** حكومتين → حصار نفطي متكرر + إنفاق موازٍ + طباعة نقود → تضخم + تدهور الدينار.
- **2020 (حصار حفتر):** −31% انكماش + خسائر.
- **2020–2021:** وقف إطلاق النار + اتفاق الصخيرات + حكومة الوحدة + إعادة فتح النفط → تعافٍ.
- **2021–2026:** تأجيل الانتخابات + استمرار الانقسام + توقفات نفطية متقطعة + تحديات.

> **حياد 🟡:** تقييم ما بعد 2011 محل خلاف (الثورة: تحرر/كرامة؛ منتقدون: انهيار/حرب). يُعرض بحياد.

## 6. ربط الاقتصاد بالجغرافيا 🟢

| المنطقة | النشاط الاقتصادي |
|---|---|
| طرابلس (الغرب) | إدارة + موانئ + تجارة + خدمات |
| الهلال النفطي (سرت/رأس لانوف) | **حقول النفط + مصافي + موانئ** — عصب الاقتصاد |
| مصراتة | تجارة + صناعة + موانئ |
| برقة (الشرق) | زراعة (الجبل الأخضر) + بنغازي + نفط (الواحات) |
| الجبل الغربي (نفوسة) | زراعة محدودة + أمازيغ |
| فزان (الجنوب) | واحات (تمور) + رعي + سياحة صحراوية (كامنة) + مهربات |
| الكفرة | واحات + مياه جوفية (النهر الصناعي) |

## 7. التحويلات والهجرة 🟡

- **العمالة الأجنبية:** ~1.5 مليون (مصريون/تونسيون/أفارقة جنوب الصحراء) — تحويلات ضخمة.
- **الهجرة غير النظامية:** ليبيا = **معبر رئيسي للهجرة نحو أوروبا** — تجارة بشر + مأساة.
- **النفط مقابل الواردات.**

## خلاصة الاقتصاد

الاقتصاد الليبي = **اقتصاد ريعي نفطي ضخم** (أكبر احتياطي أفريقي — 48 مليار برميل) لكنه **مُنكفئ بشدة منذ 2011** بسبب **الانقسام السياسي + الحرب + الفساد + توقفات النفط + تدهور الدينار + الدين العام**. قبل 2011: اقتصاد موجَّه + نفط + رعاية اجتماعية (نمو 10.6% 2010). بعد 2011: −41.8% ثم تذبذب + حصار + انقسام حكومتين. النفط = 90%+ من الإيرادات. التحديات: تنويع + استقرار سياسي + مكافحة الفساد + إعادة بناء + معالجة اللامساواة الجهوية. المستقبل رهن بـ**الاستقرار السياسي + الانتخابات + إصلاحات**. 🟢/🟡
