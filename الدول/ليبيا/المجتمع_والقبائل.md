## 3. القبائل 🟢

> القبيلة = **إطار اجتماعي قوي** في ليبيا (خاصة برقة + الجنوب) — لعبت دورًا في المقاومة + الثورة.

### (أ) القبائل العربية 🟢
- **بنو سليم (السعادي):** شرق ليبيا (برقة) — بدو — **العبيدات + البراعصة + العواقير + المسامير + المنفة + الفواخر + الجبارنة**.
- **بنو هلال:** غرب ليبيا (طرابلس) — **ورفلة + الحساولة + أولاد سليمان**.
- **ورفلة:** **أكبر قبائل ليبيا** (~1 مليون = سدس السكان) — أمازيغية الأصل (هوارة) تعرَّبت — سرت + بنغازي + فزان + سبها.
- **أولاد سليمان:** سرت + فزان + امتداد (مصر/تونس/تشاد).
- **الزنتان + بني وليد + ترهونة + مسلاتة:** قبائل وسط/غرب.
- **المقارحة + زناتة + القدادفة:** (القدادفة = قبيلة القذافي).

### (ب) القبائل الأمازيغية 🟢
- **هوارة + زناتة + نفوسة + صنهاجة + لمتونة** — أصول أمازيغية — معرَّبة أحيانًا.
- **المرابطون:** أحفاد إدريس الأكبر (الأدارسة) — الفواتير + أولاد الشيخ عبد السلام الأسمر + الأسرة السنوسية.

### (ج) الطوارق 🟢
- **أمازيغ صحراويون** — غات + أقصى جنوب غرب — لثام أزرق + رحل + «إيموهاغ» — امتداد (مالي/النيجر/الجزائر/بوركينا فاسو).
- تهميش تاريخي (الرقم الوطني/جواز السفر).

### (د) التبو 🟢
- **تيدا + دازا** — مرزق + القطرون + أوباري — رحل — امتداد (تشاد/النيجر/السودان).
- تهميش تاريخي.

### (هـ) القبائل والانقسام 🟡
- القبائل تلعب دورًا في الانقسام السياسي (حفتر = برقة الشرقية + طرابلس = الغرب).

## 4. الدين 🟢

| الدين | النسبة | التفاصيل | الثقة |
|---|---|---|---|
| **الإسلام** | 97%+ | **سُنة مالكية** غالبية (90–95%) + **إباضية** (~4.5–6% — الأمازيغ: نفوسة/زوارة/غدامس) | 🟢 |
| **المسيحية** | ~0.5–3% (وافدون) | أقباط (~60,000 — مصريون) + كاثوليك (~40,000 — إيطاليون/أفارقة) + أنجليكان | 🟢 |
| **أخرى (بوذية/هندوسية/بهائية)** | <1% (وافدون) | — | 🟢 |
| **اليهودية** | ضئيلة جدًّا (تاريخية) | غادرت بعد 1967 | 🟡 |

### الإسلام في ليبيا 🟢
- **المذهب المالكي:** الأغلبية (90%+ من المسلمين).
- **المذهب الإباضي:** الأمازيغ (نفوسة + زوارة + غدامس + بعض أوجلة) — ~4.5–6%.
- **الطرق الصوفية:** العيساوية + السنوسية + العروسية + القادرية — قوية تاريخيًّا (المقاومة).
- لا توجد جماعات شيعية تُذكر.
- دستوريًّا: الإسلام دين الدولة + الشريعة مصدر التشريع.

### المسيحية في ليبيا 🟢
- **تاريخ:** ليبيا = أول مكان للدعوة المسيحية في أفريقيا + مولد القديس مرقس (برقة).
- **اليوم:** وافدون فقط (أقباط مصريون + كاثوليك إيطاليون/أفارقة) — لا مواطنين مسيحيين.

---

## 5. الهوية الوطنية 🟢

- **الهوية = عربية-إسلامية-أمازيغية-متوسطية-صحراوية** متجانسة دينيًّا.
- **القبيلة** إطار اجتماعي قوي (خاصة برقة + الجنوب).
- **الأقاليم الثلاثة:** طرابلس + برقة + فزان — هويات جهوية قوية.
- **اللغة:** العربية (رسمية) + اللهجة الليبية + الأمازيغية (أقلية).
- **الانتماء القبلي + الوطني** معًا.

---

## 6. لامساواة/تحديات اجتماعية 🟡

- **اللامساواة الجهوية:** الساحل/طرابلس/بنغازي متقدِّمون vs الداخل/الجنوب متخلفون — محرك الثورة 2011 + الانقسام.
- **الطوارق/التبو:** تهميش تاريخي (حقوق/جنسية).
- **بطالة الشباب** + تضخم الجهاز الإداري.
- **الانقسام السياسي** → معاناة اجتماعية + خدمات.
- **الهجرة غير النظامية** — شباب + تجارة بشر.

---

## 7. الحركات والتنظيمات الاجتماعية 🟡

- **الزوايا الصوفية** — مؤثرة (العيساوية/السنوسية).
- **القبائل** — تنظيم اجتماعي-سياسي.
- **المجتمع المدني** — ضعيف (بعد 2011 انفتاح محدود).
- **المرأة الليبية** — مشاركة محدودة (أقل من تونس/مصر).

## خلاصة المجتمع

مجتمع ليبيا = **مجتمع متجانس دينيًّا** (97%+ مسلم) لكن **متعدد إثنيًّا/قبليًّا**: **عرب (90%+) + أمازيغ (5–10%) + طوارق + تبو**. القبائل: ورفلة (أكبر) + بنو سليم (برقة) + بنو هلال (طرابلس) + الطوارق (غات) + التبو (مرزق). الدين: سُنة مالكية (غالبية) + إباضية (أمازيغ). الهوية = عربية-إسلامية-أمازيغية. التحديات: اللامساواة الجهوية + تهميش الطوارق/التبو + الانقسام السياسي + بطالة الشباب. ليبيا = **دولة قبلية-دينية** مع تجانس ديني عالٍ. 🟢/🟡
