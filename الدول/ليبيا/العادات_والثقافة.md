# دولة ليبيا — العادات والثقافة

> منهجية: العادات + المناسبات + الفنون + العمارة + الحرف. ربط الجغرافيا بالثقافة.
> المصادر: ويكيبيديا (ثقافة الكويت... لا/ليبيا)، الجزيرة (المالوف)، arabmusicmagazine، alquds، hadithwatan.

## 1. الموسيقى والفنون 🟢

### (أ) المالوف — الموسيقى الأندلسية الليبية 🟢
- **الوصف:** موسيقى أندلسية مغاربية — غناء بطيء متمهَّل + إيقاع هادئ + مقامات مغاربية («النوبة» — 12 نوبة وصلت من أصل 24).
- **الأصل:** **أندلسي** — جاء مع المهاجرين الأندلسيين بعد سقوط الأندلس (القرن 13/16) + تبنتها **الزوايا الصوفية (العيساوية)**.
- **المركز:** **طرابلس** + مصراتة (زاوية مصراتة 1842) — **مالوف طرابلسي حصرًا** (لم ينتشر في الشرق/الجنوب بقدر الغرب) 🟡.
- **المناسبة:** **المولد النبوي** (مواكب الزوايا) + الأعراس + المناسبات الدينية.
- **الآلات:** العود + الكمنجة + الربابة + القانون + الناي + البندير/الدفوف + الطبلة (الدربوكة) + النقرة + المزمار + الغيطة.
- **الفرق:** نحو **35 فرقة مالوف** في ليبيا (فرقة حسن عريبي + فرقة مصراتة).
- **المؤثرات:** الأندلسي (الأساس) + صوفي (العيساوية) + مشرقي مصري (المكاواتي — مع حجاج) + تركي (إيقاع قاتيقوفتي).
- **اليونسكو 🟡:** المالوف ضمن النقاشات للتراث غير المادي (مجال مغاربي مشترك مع تونس/الجزائر).

### (ب) الفنون البحرية والشعبية 🟢
- **التخمير/لالي/المسعودية/باين الدار/الصمباني (إفريقي):** غناء شعبي في الجنوب (مرزق) — جذور إفريقية.
- **أغاني البحر:** على الساحل (طرابلس/مصراتة) — صيد + تجارة.
- **أغاني الأطفال الجماعية.**

### (ج) الموشحات 🟢
- من نصوص أبي الحسن الششتري (القرن 13) — وصلت مع الصوفية.

## 2. الزوايا الصوفية 🟢 — مؤسسة دينية-ثقافية

- **الطريقة العيساوية:** الحاضنة الكبرى للمالوف — الشيخ محمد بن عيسى المكناسي — زوايا في طرابلس + مصراتة + درنة.
- **الطريقة السنوسية:** صوفية + سياسية (مقاومة الاستعمار) — محمد بن علي السنوسي.
- **الطريقة العروسية + القادرية.**
- **الزوايا:** مراكز دينية + تعليم + مقاومة (عمر المختار من الزاوية السنوسية).

---

## 3. الأعراس والمناسبات 🟢

### (أ) العرس الليبي — عدة أيام 🟢
- **الخطوبة → الحناء → اليوم الوردي (البودري — العروس بالفستان الوردي) → الجلوة (عرض العروس) → الدخلة (الزفاف).**
- العريس: **الجرد + الفرملة + الشاشية**.
- العروس: **الحولي/الرداء + حلي + الجلوة**.
- المالوف في الأعراس (طرابلس).

- عيد الفطر (العصيدة) + عيد الأضحى + رأس السنة الهجرية.
- **زيارة الأولياء/الزوايا:** مواسم صوفية.

## 4. العمارة 🟢

### (أ) العمارة التقليدية 🟢
- **غدامس (يونسكو 1986):** **واحة + مدينة تقليدية** — بيوت طينية + أسقف جريد + أنظمة تبريد طبيعي (ممرات مظللة) + طبقات (الأرضية للمخزون/الحيوانات + العليا للسكن) — تحفة معمارية صحراوية.
- **القصر القديم (طرابلس):** المدينة العتيقة (المدينة القديمة) — أزقة + أسواق + مساجد + بيوت بأحواش.
- **لبدة الكبرى (يونسكو 1982):** آثار رومانية — مسرح + حمامات + قوس سيبتيموس سيفيروس (الإمبراطور الليبي المولد).
- **صبراتة (يونسكو 1982):** مسرح روماني + معابد.
- **قورية (يونسكو 1982):** مدينة إغريقية (برقة).
- **البيضاء/شحات (قورينا):** آثار إغريقية-رومانية.

### (ب) العمارة الأمازيغية الجنوبية 🟢
- **نالوت/كاباو/جالو:** مخازن حصينة (القصور) — غلال + زيتون.
- **القبايا/القباب الصحراوية.**

### (c) العمارة العثمانية 🟢
- **قصر أحمد باشا القرمانلي** (طرابلس) + المساجد العثمانية + الأسواق المغطاة.

### (د) العمارة الحديثة 🟢
- **القصر الملكي (طرابلس)** + المشاريع النفطية + «النهر الصناعي العظيم» (أنابيب).

## 5. الحرف اليدوية 🟢

| الحرفة | الوصف | المنطقة |
|---|---|---|
| **نسيج الجرد/الحولي** | نسيج صوفي يدوي على النول | عام (برقة/طرابلس) |
| **السدو** | نسيج صوبي (زروع + بيوت شعر) | بدوي |
| **التطريز (التلّيك)** | خيوط فضة/ذهب على الفرملة/الكردية | طرابلس/عثماني |
| **صناعة الحلي الفضية** | حلي أمازيغية/طوارقية | الجنوب/الأمازيغ |
| **الفخار** | أواني فخارية | — |
| **صناعة السفن (القلافة)** | سفن خشبية (ساحل) | مصراتة/طرابلس |
| **صناعة الجلود** | أحذية + حقائب | — |

> الحرف الليبية مزيج **ليبي أصيل (الجرد) + أمازيغي + عثماني + صحراوي (طوارق)**. 🟢

## 6. القيم الاجتماعية 🟢

- **الكرم والضيافة:** قيم عليا — الشاي العالة (3 درجات) + القهوة + التمر.
- **النخوة/الشهامة/الفروسية:** قيم بدوية (عمر المختار).
- **العائلة الممتدة + القبيلة:** روابط قوية.
- **الزوايا الصوفية:** مراكز اجتماعية-دينية.
- **التفاؤل:** قلب الأسماء لمعكوسها (فحم=بياض، نار=عافية).

---

## 7. الفنون المعاصرة 🟢

- **الأدب الليبي:** **إبراهيم الكوني** (روائي عالمي — الصحراء) + أحمد إبراهيم الفقيه.
- **الشعر النبطي:** تراث بدوي.
- **السينما/المسرح:** محدودة (بعد 2011 انفتاح نسبي).
- **المهرجانات:** مهرجان المالوف + مهرجان غدامس الثقافي + ليبيا الدولي.

## خلاصة العادات والثقافة

الثقافة الليبية = **مزيج متوسطي-صحراوي** (طرابلسية-برقاوية-فزانية) يتجلى في: **المالوف** (موسيقى أندلسية-صوفية — طرابلسي) + **الزوايا الصوفية** (العيساوية/السنوسية) + **الأعراس** (البودري/الجلوة/الجرد) + **المولد النبوي** (موسم المالوف) + **العمارة** (غدامس اليونسكو + لبدة + صبراتة + قورية) + **الحرف** (الجرد/السدو/التطريز) + **الشاي العالة** (الضيافة). ليبيا = **حلقة وصل بين المشرق والمغرب** (طرابلس مغاربية + برقة مشرقية) + بين المتوسط والصحراء. 🟢
