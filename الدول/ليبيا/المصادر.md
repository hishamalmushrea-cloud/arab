## ملاحظة منهجية
- المصادر الرسمية والأكاديمية اعتمدت للإدارات/التاريخ/الجغرافيا/الإحصاءات.
- المصادر المحلية للثقافة/الطعام/اللباس/اللهجات/القبائل — تُعرض مع 🟡 حيثما يلزم.
- **التقسيم الإداري الليبي معقد جدًّا** (7+ إعادة تنظيم) — اعتمدنا الشعبيات الـ22 (2007) كمرجعي + البلديات الحالية (~120) 🟡.
- **هجرة بني هلال/سليم** رواية تاريخية موضع خلاف (حجمها) — تُعرض كلا الرأيين 🟡.
- **الانقسام السياسي** (حكومتين) + **ثورة 2011** + **مقتل القذافي** — تُعرض بحياد 🟡.
- **الأمازيغية غير مُرسَّمة** رسميًّا بعد (دستور 2011 نص على الحماية) — نقاش هوية 🟡.
- **الطوارق/التبو** مُهمَّشون تاريخيًّا — تُعرض بحياد 🟡.
- **مواقع يونسكو الـ5** كلها على **قائمة المهددة بالخطر** (النزاع + الإهمال) — 🟡.
- تقديرات سكان الشعبيات 2020 (متفاوتة) — اعتمدنا إحصاء 2006 كأساس أوثق 🟢 + تقديرات 2020 🟡.
- **الوضع الاقتصادي** (انكماش + دينار + دين) متغير بشدة بعد 2011 — 🟡.
