## 1. العصر القديم: الأمازيغ والفينيقيون والإغريق

| الفترة | الحدث | التصنيف |
|---|---|---|
| العصر البرونزي المتأخر | **الأمازيغ (البربر)** هم **السكان الأصليون** لليبيا — الليبو/الجرمنت/المشوش. | 🟢 |
| القرن 10 ق.م | **الفينيقيون** يستقرون في غرب ليبيا + يؤسسون مراكز تجارية: **أويا (طرابلس) + صبراتة + لبدة الكبرى** (المدن الثلاث = «تريبوليس»). | 🟢 |
| القرن 7 ق.م | القرن 6 ق.م: **الإغريق** يستعمرون برقة شرقًا + يؤسسون **قورينا** + المدن الخمس (سيرينايكا). | 🟢 |
| 814 ق.م | تأسيس قرطاج (تونس) — نفوذها يمتد لغرب ليبيا. | 🟢 |
| القرن 6 ق.م | صعود قرطاج + الملك النوميدي **ماسينيسا** ينتزع غرب ليبيا (201 ق.م). | 🟢 |
| **74 ق.م** | **الرومان** يغزون ليبيا — ليبيا ضمن الإمبراطورية الرومانية (ولاية أفريكا + طرابلسية 285م). | 🟢 |
| 146 ق.م | سقوط قرطاج → ليبيا تحت الرومان. | 🟢 |
| 431م | **الوندال** يحتلون ليبيا. | 🟢 |
| 534م | **البيزنطيون** يستعيدون ليبيا (جستينيان/بلزاريوس). | 🟢 |

> 🟢 ليبيا كانت **مركزًا مبكرًا للمسيحية** — القديس مرقس (مولود في برقة) + أوغسطينوس (مغاربة).

## 3. العصر العثماني والأسرة القرمانلية (1551–1911)

| الفترة | الحدث | التصنيف |
|---|---|---|
| 1510 | **الإسبان** يحتلون طرابلس (شارلكان). | 🟢 |
| 1530 | تسليم طرابلس لفرسان القديس يوحنا. | 🟢 |
| **1551** | **العثمانيون** يطردون الفرسان + يضمون ليبيا (ولاية طرابلس) — توحيد طرابلس/برقة/فزان. | 🟢 |
| **1711–1835** | **الأسرة القرمانلية** (أحمد باشا القرمانلي) تحكم ليبيا بحكم ذاتي واسع — ازدهار + قرصنة. | 🟢 |
| 1835 | العثمانيون يستعيدون الحكم المباشر (العهد العثماني الثاني). | 🟢 |
| 1837–1859 | **الحركة السنوسية** (محمد بن علي السنوسي) تنتشر في برقة + فزان + تشاد. | 🟢 |

|---|---|---|

| **18 أكتوبر 1912** | **معاهدة أوشي/لوزان** — العثمانيون يتنازلون عن ليبيا (نهاية 360 سنة حكم). | 🟢 |

## 6. عهد القذافي (1969–2011)

| الفترة | الحدث | التصنيف |
|---|---|---|
| **1 سبتمبر 1969** | **انقلاب الفاتح** — **معمر القذافي** (27 سنة) + ضباط أحرار يطيحون بالملك إدريس (في تركيا للعلاج) → **الجمهورية العربية الليبية**. | 🟢 |
| 1970 | **الجلاء** — طرد آخر جندي إيطالي + تأميم. | 🟢 |
| **1973** | تأميم النفط + «الثورة الشعبية» + «الجماهيرية». | 🟢 |
| **2 مارس 1977** | إعلان **«الجماهيرية العربية الليبية الشعبية الاشتراكية العظمى»** — «سلطة الشعب» (مؤتمرات شعبية + لجان شعبية) — نظام فريد. | 🟢 |
| 1977 | الحرب المصرية-الليبية (4 أيام). | 🟢 |
| 1980s | دعم الإرهاب + التوتر مع الغرب → قصف أمريكي 1986. | 🟢 |
| 1988 | تفجير لوكربي (بان أم 103) → عقوبات دولية. | 🟢 |
| 1999–2003 | تسليم المتهمين + التخلي عن أسلحة الدمار الشامل → رفع العقوبات + عودة العلاقات. | 🟢 |
| 2009 | القذافي رئيس الاتحاد الأفريقي. | 🟢 |
| **42 سنة** | حكم القذافي (أطول حاكم عربي وقتها). | 🟢 |

> 🟡 **حياد:** نظام القذافي محل خلاف (إنجازات: تنمية/تعليم/صحة + رفع الريفيين vs استبداد/فساد/إهمال البنية). يُعرض بحياد.

## 7. ثورة 17 فبراير والحاضر (2011–الآن)

| الفترة | الحدث | التصنيف |
|---|---|---|
| **17 فبراير 2011** | **اندلاع الثورة الليبية** (على غرار تونس/مصر) — من بنغازي + الشرق. | 🟢 |
| مارس 2011 | التدخل العسكري الدولي (الناتو) بقرار أممي. | 🟢 |
| **20 أكتوبر 2011** | **مقتل القذافي** في سرت + ابنه المعتصم + أبو بكر يونس → نهاية 42 سنة. | 🟢 |
| **23 أكتوبر 2011** | إعلان **التحرير** (عيد التحرير). | 🟢 |
| 2012 | انتخابات المؤتمر الوطني العام. | 🟢 |
| **2014** | **الانقسام** — حكومتين: طرابلس (الوفاق/الغرب) + بنغازي/طبرق (الشرق — حفتر). | 🟢 |
| 2014–2020 | حرب أهلية + حصار نفطي متكرر + تدخلات أجنبية. | 🟢 |
| 2015 | اتفاق الصخيرات (حكومة الوفاق). | 🟢 |
| 2020 | وقف إطلاق النار + إعادة فتح الحقول النفطية. | 🟢 |
| 2021 | حكومة الوحدة (عبد الحميد الدبيبة) — لكن الانقسام persists. | 🟢 |
| 2021–2026 | تأجيل الانتخابات + استمرار الانقسام السياسي + تحديات اقتصادية. | 🟡 |

> **ملاحظة الحياد 🟡:** ثورة 2011 + مقتل القذافي + الانقسام + التدخلات الأجنبية — محل خلاف سياسي داخلي وحساسية — تُعرض بحياد دون تبني رأي.

## 9. الأقاليم التاريخية الثلاثة 🟢

| الإقليم | المنطقة | الأهمية |
|---|---|---|
| **طرابلس** | الغرب + الساحل الشمالي الغربي | العاصمة + المدن الفينيقية (لبدة/صبراتة/أويا) |
| **برقة** | الشرق + الجبل الأخضر | المقاومة (عمر المختار) + بنغازي + قورينا |
| **فزان** | الجنوب الصحراوي | واحات + سبها + الطوارق/التبو + الكفرة |

## خلاصة المسار التاريخي

ليبيا = **ملتقى حضارات** (أمازيغية-فينيقية-إغريقية-رومانية-بيزنطية-إسلامية-عثمانية-إيطالية) ذات **3 أقاليم تاريخية** (طرابلس + برقة + فزان). تعاقب عليها: الأمازيغ → الفينيقيون/الإغريق → الرومان → الوندال → البيزنطيون → الفتح الإسلامي (642) → الأغالبة/الفاطميون/الزيريون/الموحدون/الحفصيون → العثمانيون (1551) + القرمانلية → الاستعمار الإيطالي (1911) + مقاومة عمر المختار → الاستقلال (1951) + الملك إدريس → انقلاب القذافي (1969) + 42 سنة → ثورة 2011 + مقتل القذافي → الانقسام السياسي. 🟢/🟡
