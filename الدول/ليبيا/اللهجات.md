# دولة ليبيا — اللهجات

> منهجية: اللهجة الليبية + اللهجات الجهوية (طرابلسية/برقاوية/فزانية) + الأمازيغية + قاموس.
> المصادر: ويكيبيديا (لغات ليبيا/ليبيون)، areq.net، shanti.jordanforum، hawaaworld، salem-cyrenaica.

## 1. نظرة عامة 🟢

| الحقل | المحتوى | الثقة |
|---|---|---|
| الاسم المحلي | **اللهجة الليبية** | 🟢 |
| العائلة | أفرو-آسيوية → سامية → عربية وسطى → مغاربية | 🟢 |
| الانتشار | ليبيا (الأغلبية) | 🟢 |
| القرابة | قريبة من لهجة شرق تونس + غرب مصر (برقاوية) — حلقة وصل بين المشرق والمغرب | 🟢 |

| مكانة الأمازيغية | لغة أقلية (نفوسية/أوجلية/طارقية/تيدا) — دستور 2011 نص على حمايتها لكن لم تُرسَّم رسميًّا بعد 🟡 | 🟡 |

> 🟢 ليبيا = **حلقة الوصل بين المشرق والمغرب العربي** لهجيًّا: طرابلس (غرب) = مغاربية (قريبة من تونس)؛ برقة (شرق) = مشرقية (قريبة من بدو الأردن/الخليج).

## 2. التأثيرات اللغوية 🟢

الليبية = خليط متعدد الطبقات:

| الأصل | أثره | المثال |
|---|---|---|
| **الأمازيغية** (السكان الأصليون) | مفردات + نطق + بنى | دلاع (بطيخ)، زغ، متكنطي (قمة الغضب)، منداف (فخ) |
| **العربية الهلالية/السليمية** (القرن 11) | الأساس — بنو هلال (طرابلس) + بنو سليم (برقة) | باهي، هلبة، متاعي |
| **الإيطالية** (الاستعمار 1911) | مفردات (خاصة طرابلس) | سبيزه (تموين)، رتادجو، فياشكة، تيمبو، كازيرمه (مركز شرطة)، فوندو |
| **التركية** (العثمانيون) | مفردات | غانجو (قفل الباب) |
| **الإنجليزية** (حلفاء/نفط) | مفردات حديثة | كوول |

> 🟢 **سمة ليبية فريدة:** قلب الأسماء لمعكوسها تفاؤلًا (الفحم = «البياض»، الأعمى = «البصير»، النار = «العافية») — عكس التشاؤم.

## 3. اللهجات الجهوية (3 رئيسية) 🟢

> اللهجة الليبية تتباين بين 3 مناطق كبرى (طرابلس/برقة/فزان) + بين الحضر والبدو.

### (1) اللهجة الطرابلسية (الغرباوية) 🟢
- **المنطقة:** غرب ليبيا (طرابلس + الجفارة + الزاوية + الخمس + مصراتة + الجبل الغربي).
- **الميزة:** **أسرع في النطق** + **أقرب لشرق تونس** (مغاربية) + **مُثأثرة بالإيطالية** (بديل الفرنسية في تونس) + **إمالة شديدة للألف** + قلب الجيم زايًا أحيانًا (زوز = زوج، زردة = جردة) + القاف جيم قاهرية.
- **أمثلة:** اشكون (مَن)، علاش (لماذا)، زنقة (شارع)، يا حويجة (يا عجب).

### (2) اللهجة البرقاوية (الشرقاوية) 🟢
- **المنطقة:** شرق ليبيا (برقة: بنغازي + المرج + البيضاء + طبرق + درنة + أجدابيا).
- **الميزة:** **أقرب للهجات بدو الأردن والخليج** (مشرقية) + **الجيم تُلفظ جيمًا** (رجاجيل) + أصفى من الطرابلسية + القاف گ أحيانًا.
- **أمثلة:** كنك (ما لك)، حوش (البيت)، نوض (استيقظ)، نرقد (أنام)، يا را (يا رجل)، ينعلي (ويلي).

### (3) اللهجة الفزانية (الجنوب) 🟢
- **المنطقة:** جنوب ليبيا (فزان: سبها + أوباري + مرزق + غات + الكفرة).
- **الميزة:** **خليط عربي-أمازيغي-صحراوي** + تأثير الطوارق/التبو + مفردات صحراوية.
- **أمثلة:** دقانة (عربة صغيرة)، بو طبيلة (كثير الكلام)، تيتوه (انظر).

### (4) لهجة البادية 🟢
- **المنطقة:** بادية برقة + الجنوب.
- **الميزة:** **أقرب للفصحى** + قريبة من بدو الأردن/الخليج/الشام + مفردات (واجد = كثير، الفتا = الولد/البنت، ردغة = طين).
- تنتشر في قبائل بني سليم وبني هلال.

## 4. الأمازيغية في ليبيا 🟡

- **الحضور:** أقلية (نحو 5–10% من السكان) — يتحدثون الأمازيغية كلغة أم.
- **التركز:**
  - **جبل نفوسة** (غرب — الجبل الغربي) — نفوسية (الأكثر تمسكًا).
  - **زوارة** (ساحل غرب) — زوارية.
  - **غدامس** (جنوب غرب) — غدامسية.
  - **أوجلة/الجوف** (شرق/واحات) — أوجلية.
  - **الطوارق** (غات/أقصى جنوب) — طارقية (تمازيغت).
  - **التبو** (مرزق/القطرون) — تيدا/دازا (لغة نيلو-صحراوية ليست أمازيغية).
- **الترسيم 🟡:** دستور 2011 نص على حماية اللغات المحلية (الأمازيغية/التبو) لكن لم تُرسَّم رسميًّا بعد (عكس الجزائر/المغرب).
- **المذهب:** معظم الأمازيغ الليبيين **إباضية** (نفوسة/زوارة/غدامس) + بعض سُنة.

## 6. ظواهر لغوية 🟢

- **القاف البدوية:** تُنطق «كا» في بعض الكلمات (طرابلس).
- **الإمالة:** أشد في طرابلس («مشي» بإمالة).
- **قلب الأسماء لمعكوسها:** تفاؤل (فحم=بياض، نار=عافية، أعمى=بصير).
- **تحوّل الألف → نون:** أحيانًا (اطلب → نطلب).
- **الجيم → زاي** (طرابلس أحيانًا): زوز (زوج).

---

## 7. ربط اللهجة بالجغرافيا والتاريخ 🟢

- **طرابلس (غرب):** جوار تونس + الاستعمار الإيطالي → مغاربية + مفردات إيطالية.
- **برقة (شرق):** جوار مصر + هجرة بني سليم (بدو) → مشرقية + قربى من الأردن/الخليج.
- **فزان (جنوب):** صحراء + الطوارق/التبو → خليط صحراوي + أمازيغي.
- **الأصول القبلية:** بني هلال (طرابلس) + بني سليم (برقة) → لهجتان متمايزتان.

## خلاصة اللهجوية

اللهجة الليبية = **حلقة وصل بين المشرق والمغرب** (طرابلسية مغاربية + برقاوية مشرقية + فزانية صحراوية) بطبقات أمازيغية/إيطالية/تركية. ليبيا = **حلقة جغرافية-لغوية** بين تونس (غرب) ومصر (شرق). الأمازيغية لا تزال حاضرة كلغة أم للأقلية (نفوسية/أوجلية/طارقية) في الجبل الغربي + زوارة + غدامس + أوجلة + غات. الترسيم الأمازيغي لم يكتمل بعد. 🟢/🟡
