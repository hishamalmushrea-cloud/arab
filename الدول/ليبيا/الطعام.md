# دولة ليبيا — الطعام والمطبخ

> منهجية: لكل طبق يُذكَر اسمه المحلي + المكونات + المناسبة + المنطقة + الأصل.
> المصادر: ويكيبيديا (مطبخ كويتي/ليبي)، encyclopediacooking، dar.el-emarat، mawdoo3، almalomat، io.hsoub.

---

## 1. نظرة عامة 🟢

> المطبخ الليبي = خليط **مغاربي (تونسي) + مصري/مشرقي (برقة) + صحراوي/بدوي + إيطالي**. سمة الغالبة: **البهارات (الكمون/الفلفل الحار/الكركم)** + القمح/الشعير + اللحم + الطماطم + **الطبيخة** (المرق الأحمر).

- **القمح/الشعير:** أساس البازين + العصيدة + الخبز.
- **الطبيخة:** المرق الأحمر (طماطم + لحم + بهارات) — أساس معظم الأطباق.
- **اللحم:** ضأن + بقري + دجاج + سمك (ساحل).
- **البهارات:** فلفل حار + كمون + كركم + ثوم + طماطم — **الحرّ** سمة ليبيّة.
- **الزيتون/الزيت:** الساحل.

## 2. الأطباق الرئيسية

### (1) البازين 🟢 — الطبق الوطني (جنوب/أرياف)
- **الوصف:** دقيق شعير يُغلى + يُشكَّل هرمًا + يُضاف إليه **الطبيخة** (بطاطا/فول مدشش/لحم/بيض مسلوق) + فلفل أخضر + ليمون.
- **الأصل:** **بدوي/صحراوي** — القمح/الشعير + بساطة الصحراء.
- **المناسبة:** وجبة رئيسية + المناسبات في الأرياف + البادية.
- **الأدوات:** قدر فخار/نحاس + معصدة (مغرف خشب الزيتون) + قصعة.

### (2) الكسكسي (المفتول) 🟢 — غرب/طرابلس
- **الوصف:** سميد قمح/شعير يُطهى على البخار + طبيخة (لحم/بصل/حمص) + سمن بلدي.
- **المناسبة:** وجبة يومية (غرب) + المناسبات + الأعراس.
- **التنوع:** كسكسي بالخضار + كسكسي بالبصلة (طبيخ بصل/حمص/لحم) + كسكسي بالسمك.
- **الأصل:** مغاربي مشترك (تونس/الجزائر).

### (3) العصيدة 🟢 — الأعياد
- **الوصف:** عجينة دقيق قمح + ماء → كرة + **شراب التمر (الرُّب)** + زبدة ذائبة + سمن.
- **المناسبة:** **عيد الفطر** (فطور الصباح) + عيد المولد النبوي + المناسبات الدينية.
- **الأصل:** بدوي/صحراوي.

### (4) المبكبكة (المكرونة المبكبكة) 🟢
- **الوصف:** مكرونة + طبيخة حارة (لحم/دجاج/بحري) + بهارات — تُقدَّم حارة (يلذع اللسان).
- **المناسبة:** وجبة شعبية يومية.

### (5) العصبان (المصارين) 🟢
- **الوصف:** أمعاء ضأن محشوة (لحم مفروم + أرز + بقدونس + بهارات) → تُطهى في الطبيخة.
- **المناسبة:** طبق جانبي/مناسبات.

### (6) الرشدة (رشتة البرمة) 🟢
- **الوصف:** معكرونة تقليدية (عجين يُقطَّع) + طبيخة (لحم + مرق) — شتوية دسمة.
- **المناسبة:** شتاء + مناسبات.

### (7) الشربة (الشوربة الليبية) 🟢
- **الوصف:** حساء دسم (لحم/عدس/خضار/طماطم/بهارات) — أكثر دسامة من الشوربة العادية.
- **المناسبة:** رمضان + شتاء.
- **التنوع:** شربة الحوت + شربة العدس.

### (8) المبطن 🟢
- **الوصف:** بطاطا محشية (لحم مفروم + بهارات) + طبيخة — طبق جانبي.

### (9) الضولمة (الدولمة) 🟢
- **الوصف:** خضار محشي (ورق عنب/قرعة/بطاطا/طماطم/بصل/فلفل/كرنب) بخلطة (لحم + أرز + بقدونس + نعناع + طماطم) + طبيخة.
- **الأصل:** مشرقي/مغاربي مشترك.

### (10) الفتات 🟢
- **الوصف:** خبز مفتوت + طبيخة — شتوي.

### (11) طبيخة الحلبة 🟢
- **الوصف:** حلبة + طماطم + لحم + بهارات — شعبية.

### (12) القلاية 🟢
- **الوصف:** لحم + طماطم + بهارات — شعبية.

### (13) بوريك (بريك) 🟢
- **الوصف:** عجينة محشوة (لحم/جبن/سبانخ/بيض) + تُقلى — مقبَّل.
- **الأصل:** مغاربي/أندلسي.

### (14) الشخشوخة 🟡
- **الوصف:** عجين مفتوت + طبيخة — شبيبة بالشخشوخة الجزائرية.

### (15) الكفتة الليبية 🟢
- **الوصف:** كفتة + طبيخة + باذنجان.

## 3. الحلويات 🟢

| الحلوى | الوصف | المناسبة |
|---|---|---|
| **المقروض (المقروض)** | سميد + تمر/لوز + عسل — **أشهر حلوى ليبية** (طرابلس) | المناسبات + رمضان |
| **المعمول** | عجين محشي (تمر/لوز) | الأعياد |
| **المغروق** | عجين + تمر + سمن | رمضان |
| **الدبلة** | حلوى مقلية | — |
| **الغريبة** | سمن + سكر + دقيق | — |
| **الكحك** | — | الأعياد |

## 4. الخبز والمشروبات 🟢

- **الخبز الليبي:** خبز التنور (رقائقي) + خبز الفرن + «الدشيشة» — أساسي مع الطبيخة.
- **الشاي الليبي:** شاي أخضر + نعناع + سكر كثير + لوز («الشاي العالة») — يُقدَّم في 3 درجات (الثالثة «الثلثة» مُرة).
- **القهوة الليبية:** قهوة عربية + هيل.

---

## 5. مأكولات رمضان 🟢

- **الإفطار:** تمرة + شوربة + العصيدة (عيد) + الكسكسي/المبكبكة + بوريك + شربة + مقروض.
- **السحور:** فتات + مبطن.

---

## 6. ربط الطعام بالجغرافيا 🟢

| المنطقة | الأطباق المميزة | السبب |
|---|---|---|
| الساحل (طرابلس/مصراتة) | الكسكسي + البوريك + شربة الحوت + زيتون | متوسطي + تجارة + موانئ |
| الجبل الأخضر (برقة) | العصيدة + المبكبكة + لحم | جبلي + رعي + فواكه |
| الجنوب/الصحراء (فزان) | البازين + التمر + الفتات | صحراوي + قمح/شعير + واحات |

---

## 7. ملاحظات ثقافية 🟢

- **الطبيخة = هويّة الطبخ الليبي:** المرق الأحمر الحار — أساس كل الأطباق.
- **الشاي العالة = ضيافة:** تقديم الشاي بـ3 درجات (الأولى حلوة، الثانية متوسطة، الثالثة مُرة) — طقس ضيافة.
- **العصيدة = الأعياد:** رمز الاحتفال الديني (عيد الفطر + المولد).
- **المقروض = الحلوى الوطنية:** طرابلسية + الأكثر شهرة.
- **الإرث الإيطالي:** بعض المعجنات + القهوة + الخبز.

---

## خلاصة الطعام

المطبخ الليبي = **مطبخ مغاربي-مشرقي-صحراوي حارّ** قائم على البازين (الجنوب/البدوي) + الكسكسي (الغرب) + المبكبكة + العصيدة (الأعياد) + العصبان + الشربة + المقروض (الحلوى) + الشاي العالة (الضيافة). تتمايز الأطباق جهويًّا: بحري (سمك) في الساحل + بدوي (قمح/لحم) في الجبل + صحراوي (بازين/تمر) في الجنوب. الطبيخة الحارة = البصمة الليبية. 🟢
