## 2. المواقع الأثرية والتراثية

### (أ) مواقع تراث يونسكو العالمي (5 مواقع) 🟢

> ليبيا تضم **5 مواقع تراث يونسكو**:

| الموقع | سنة الإدراج | المنطقة | النوع | الأهمية |
|---|---|---|---|---|
| **لبدة الكبرى** | 1982 | **المرقب** (الخمس) لا طرابلس | ثقافي | مدينة رومانية — قوس سيبتيموس سيفيروس |
| **صبراتة** | 1982 | **الزاوية** لا طرابلس ولا زوارة | ثقافي | مسرح روماني — فينيقية/رومانية |
| **غدامس** | 1986 | **نالوت** لا الجبل الغربي | ثقافي | المدينة العتيقة |
| **طادرارت أكاكوس** | 1985 | **غات** لا مرزق | ثقافي | نقوش صخرية |
| **قورينا (شحات)** | 1982 | **الجبل الأخضر** لا بنغازي | ثقافي | مدينة إغريقية |

> 🟡 جميع مواقع يونسكو الليبية على **قائمة التراث العالمي المهدد بالخطر** (منذ 2016 — بسبب النزاع + الإهمال).

### (ب) مواقع أثرية أخرى 🟢
| الموقع | الوصف |
|---|---|
| **أويا (طرابلس القديمة)** | المدينة العتيقة + القصر + الأسواق |
| **شحات (قورينا)** | آثار إغريقية-رومانية |
| **سوسة (أبولونيا)** | ميناء إغريقي |
| **لِمطة (لبتس ماغنا)** | آثار |
| **جرمة** | عاصمة الجرمنت (الأمازيغ الصحراويين) — جنوب |
| **زويلة** | آثار إسلامية (فزان) |
| **طبرق/الجغبوب** | زوايا سنوسية |

### (ج) المعالم التراثية 🟢
| المعلم | الوصف |
|---|---|
| **قصر أحمد باشا القرمانلي** | طرابلس — عمارة عثمانية |
| **القصر الأحمر** | طرابلس — مقر الحكم (تاريخي) |
| **الزاوية السنوسية (الجغبوب/الكفرة)** | مراكز الحركة السنوسية |
| **زاوية مصراتة العيساوية** | 1842 — مركز المالوف |
| **النهر الصناعي العظيم** | أكبر مشروع ري تحت أرضي عالميًّا — أنابيب |

### (د) المساجد 🟢
- **جامع أحمد باشا القرمانلي** (طرابلس — عثماني).
- **جامع الناقة** (طرابلس — 16).
- **جامع الغرابة** (غدامس).
- **المسجد الأزهر/الدرجي** (طرابلس القديمة).

## 3. ربط الآثار بالحقب التاريخية 🟢

| الحقبة | المواقع المميزة |
|---|---|
| فينيقية | لبدة + صبراتة + أويا |
| إغريقية | قورية (قورينا) + سوسة |
| رومانية | لبدة (سيبتيموس سيفيروس) + صبراتة + لِمطة |
| إسلامية | زويلة + المساجد |
| عثمانية/قرمانلية | قصر القرمانلي + الجوامع |
| صحراوية/أمازيغية | غدامس + أكاكوس + جرمة |
| سنوسية | الجغبوب + الكفرة + زوايا |

## خلاصة الشخصيات والآثار

ليبيا = **مهد حضارات وأعلام**: من **سيبتيموس سيفيروس** (إمبراطور روماني ليبي) إلى **عمر المختار** («أسد الصحراء»/«شيخ الشهداء») إلى **الملك إدريس** (أبو الاستقلال) إلى **القذافي** (42 سنة) إلى **إبراهيم الكوني** (روائي عالمي). و**5 مواقع تراث يونسكو** (لبدة/صبراتة/غدامس/أكاكوس/قورية) — جميعها مهددة (النزاع) — + جرمة (جرمنت) + زويلة + قصر القرمانلي. ليبيا = **أصغر سكانًا لكن أعرق حضاريًّا في المغرب** (آثار رومانية/إغريقية + آثار صحراوية + نقوش). 🟢/🟡
