# دولة ليبيا — اللباس التقليدي

> منهجية: لكل قطعة يُذكَر اسمها المحلي + المناسبة + المنطقة + الأصل (ليبي أصيل/عربي/عثماني/أمازيغي/طوارقي).
> المصادر: ويكيبيديا (لباس تقليدي ليبي)، raseef22، libyanheritagehouse، maghrebcultures، e3arabi، maghrebvoices.

---

## 1. ملاحظة أولى: تنوع بيئي/إثني/تاريخي 🟢

> اللباس الليبي = **ليبي أصيل (الجرد) + عربي + عثماني + أمازيغي + طوارقي + تبو**. يختلف بين **البر** (الداخل) و**البحر** (الساحل) + بين **العرب/الأمازيغ/الطوارق/التبو**.
> **سمة:** الجرد = **من أعرق الأزياء في العالم** (منذ العصر الروماني) + رمز الهوية + مرتبط بـ**عمر المختار** (ارتداه عند إعدامه).
> **اليوم:** يُلبس في المناسبات الدينية + القومية + الأعراس + رمز فخر وطني.

---

## 2. الأصول التاريخية 🟢

| الأصل | القطع |
|---|---|
| **ليبي أصيل** (الأساس — منذ العصر الروماني) | **الجرد/الحولي** + الفراشية + الكردية |
| **عربي** (بني هلال/سليم) | البدلة العربية + السروال + الفرملة (تأثير عثماني أيضًا) |
| **عثماني** | الفرملة (التطريز) + الزبون + الشاشية |
| **أمازيغي** | تلابا + حلي فضية |
| **طوارقي** | اللثام الأزرق (تلغلموست) + أنقار |
| **تبو** | لباس صحراوي مميز |

> 🟢 النقوش المصرية القديمة تُظهر الليبيين القدامى بأزياء مشابهة للجرد (روابط قديمة مع إتروريا/إيطاليا).

## 3. اللباس الرجالي 🟢

### القطع الأساسية

| القطعة | الوصف | الأصل/الاستخدام |
|---|---|---|
| **الجرد (الحولي)** | قطعة قماش كبيرة من الصوف/القطن (~6 م) تُلف حول الجسد + تترك الكتف الأيمن حرًا + تُثبَّت على الكتف الأيسر بربطة (حبة مشمش) | **ليبي أصيل (منذ الرومان)** — الأبيض (الأفراح/المناسبات) + البني/البيج (يومي) — رمز الهوية |
| **الحولي الحريري الطرابلسي** | حاف صوف أبيض/رمادي خشن ثقيل + يُغلَّف به من القدم للرأس | — |
| **العباءة البنية** | صوف بني ثقيل + خطان أبيضان — شتاء — لا تُلبس في الأفراح/المآتم | — |
| **الفرملة (الصدرية)** | سترة بلا أكمام مطرَّزة بخيوط الفضة/الذهب (التلّيك) — تُلبس فوق قميص قطني (سورية) | **عثماني/ليبي** — المناسبات الرسمية |
| **الزبون** | جاكيت مخيط مطرَّز + يُلبس فوق الجلابية | عثماني |
| **الجلابية (البدلة العربية)** | ثوب طويل + سروال فضفاض + سترة | عربي |
| **السروال** | فضفاض طويل | — |
| **الشاشية (الكبّوس/الشنة/المعرقة)** | غطاء رأس — **أسود** (طرابلس/غرب) + **أحمر** (برقة/شرق) | عثماني |
| **الطاقية** | قبعة بيضاء تحت الشاشية | — |
| **الفروة** | معطف مبطَّن بفروة خراف — شتاء بارد | بدوي |

> زي العريس الليبي: **الجرد + الفرملة + الشاشية** («نقاب بالشوكات» — طريقة لف محددة). 🟢

## 4. اللباس النسائي 🟢

### القطع الأساسية

| القطعة | الوصف | الأصل/الاستخدام |
|---|---|---|
| **الحولي (الرداء)** | رداء أساسي للمرأة — شبيب بالجرد الرجالي لكن من حرير ملوّن منقوش — يُلف حول الجسد + يُثبَّت عند الكتف الأيسر بـ**خلال** من الفضة/الذهب | ليبي أصيل — أنواع (حولي الحصيرة + حولي بوخطين) |
| **الفراشية** | قطعة صوفية (أبيض/أحمر/أسود) + نقوش زخرفية ليبية — شبيبة بالجرد | ليبي أصيل |
| **الرداء** | رداء حريري للمرأة + «القمجّة» (قميص مطرَّز) + «فرملة» مطرَّزة + سروال واسع مطرَّز (شبر من أسفله) | — |
| **العبروق** | رداء أحمر/أسود — الجنوب | — |
| **الكردية** | لباس مطرَّز — غرب: تحت الرداء + شرق: فوقه | — |
| **البدلة الكبيرة والصغيرة** | أزياء مناسبات نسائية | — |
| **الجلوة** | لباس العروس | — |

### الأعراس 🟢
- **اليوم الوردي (البودري):** ترتدي العروس **فستانًا ورديًّا مخططًا** يُطوى وسائد/أقواسًا في الظهر/الوركين + وشاح مطابق + حلي كثيرة + مروحة تقليدية — تتلقى هدايا (ملابس/حلي/مكياج) من أهل العريس.

## 5. زي الأقليات الثقافية 🟢

### (أ) زي الطوارق (جنوب/غات) 🟢
- **الرجال:** **اللثام الأزرق (تلغلموست/Tagelmust)** — يغطي الوجه كاملًا ما عدا العينين (عكس المعتاد!) — قدسية + حماية من الرمال + «رجال الصحراء الزرق».
- **النساء:** فساتين فضفاضة داكنة (أسود/أزرق) + زخارف ألوان + حلي فضية + ظفائر + خرز + حلقان (نجمة/هلال).
- **الإمزاد:** آلة تشبه الربابة بعُود واحد — تعزفها نساء الطوارق.

### (ب) زي التبو (جنوب/مرزق) 🟢
- لباس صحراوي مميز (تبو/تيدا/دازا) — يتلاءم مع الحرارة.

### (ج) زي الأمازيغ (نفوسة/زوارة/غدامس) 🟢
- **تلابا:** garment أمازيغي تقليدي + حلي فضية (الخلال).
- الفضة = «بركة» (حماية من العين).

### (د) زي اليهود الليبيين (تاريخي) 🟡
- مشابه للباس الليبي العام (سروال + فرملة + جرد أبيض في المناسبات).

## 6. الحلي والمجوهرات 🟢

| القطعة | الوصف |
|---|---|
| **الخلال (التخلالت)** | دبوس/مشبك مثلث لتثبيت الحولي/الرداء — فضة + نقوش + أحجار شبه كريمة |
| **الفضة** | الأكثر استخدامًا (خاصة الأمازيغ/الطوارق) — «بركة»/حماية من العين |
| **الذهب** | مدن كبرى (طرابلس) — أعراس فاخرة |

## 7. الفروق بحسب البيئة 🟢

| البيئة | اللباس | السبب |
|---|---|---|
| الساحل (طرابلس/مصراتة) | حضر + زبون + فرملة + شاشية سوداء + حلي ذهب | متوسطي + تجارة + عثماني |
| الجبل الأخضر (برقة) | جرد + فرملة + شاشية حمراء + فروة شتاءً | جبلي + برد + بدوي |

| الجنوب (فزان/غات) | جرد + عبروق + لباس طوارقي (لثام أزرق) + تبو | صحراوي + طوارق/تبو |

## 8. التطور الحديث 🟢

- **الجرد/الفرملة:** محافَظ عليه بقوة في المناسبات الدينية + القومية + الأعراس — رمز فخر.
- **اليوم الوطني للزي التقليدي:** يُحتفل به الليبيون.
- **الحجاب/اللباس المحتشم:** في الأوساط المحافظة (تنام بعد 2011).
- **اللباس الغربي (البدلة/الجينز):** لباس يومي سائد (مدن + شباب).
- **إحياء التراث:** حفظ اللباس عبر المتاحف + الأعراس + الأيام التراثية.

---

## 9. ملاحظة نقدية

- اللباس الليبي **ليبي أصيل بالأساس** (الجرد/الحولي/الفراشية) + تأثيرات عربية/عثمانية/أمازيغية/طوارقية.
- **الجرد** = من أعرق الأزياء في العالم (منذ الرومان) + رمز الهوية + مرتبط بـ**عمر المختار**.
- **الفرملة** = رمز المناسبات الرسمية (تطريز عثماني/ليبي).
- **اللثام الأزرق للطوارق** = فريد (الرجال يغطون الوجه).
- يربط اللباس بين **الأعراس والهوية**: العريس بالجرد + العروس بالبودري الوردي + حلي.

## خلاصة اللباس

اللباس الليبي = **ليبي أصيل بالأساس** (الجرد/الحولي — أعرق أزياء العالم منذ الرومان) + عربي (البدلة العربية) + عثماني (الفرملة/الزبون/الشاشية) + أمازيغي (تلابا/حلي فضية) + طوارقي (اللثام الأزرق). الجرد = رمز الهوية + الفخر + مرتبط بعمر المختار. يختلف بين الساحل (حضر) + الجبل (برودة) + الصحراء (طوارق/تبو). محافَظ عليه بقوة في المناسبات. 🟢
