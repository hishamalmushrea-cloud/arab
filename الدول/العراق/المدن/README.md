# مدن العراق — المرحلة الخامسة

> **المرحلة الخامسة:** ملف لكل **مدينة** موثَّقة داخل **محافظة → قضاء**. ليست ولاية ولا منطقة سعودية. 🟢
>
> **بغداد المدينة** في `العواصم/بغداد/` — لا تكرار هنا. **المحمودية** هنا لأنها ليست ملف العاصمة.
>
> **السكان:** تعداد الجهاز المركزي للإحصاء **25 نوفمبر 2024** عبر جداول citypopulation (سكان حضري للمركز/الناحية) 🟢. **لا يُخلط سكان المحافظة بسكان المدينة** (البصرة المحافظة 3,664,168 ≠ البصرة المدينة 1,293,052).
>
> إقليم كردستان: أربيل والسليمانية ودهوك وحلبجة. كركوك ومخمور: واقع إداري بحياد (المادة 140) 🟡.
>
> لا تُهمَّش الجنوب والغرب والكردستان: السماوة، الرمادي، حلبجة، زاخو، أم قصر.
