# دولة الكويت — الجغرافيا

> منهجية: تربط التضاريس بالمناخ والمياه والثقافة (اللباس/الطعام/العمارة/السكن). علامات الثقة: 🟢/🟡/🟠.
> المصادر: ويكيبيديا، المعرفة، البوابة الرسمية (e.gov.kw)، aspdkw، wikikuwait، kotc.

---

## 1. الموقع والمساحة 🟢

- **شمال شرق شبه الجزيرة العربية** — أقصى شمال غرب الخليج العربي (منفذ طبيعي شمال شرق الجزيرة).
- **المساحة:** 17,818 كم² (ثالث أصغر دولة عربية).
- **الإحداثيات:** 28°30′–30°06′N و46°30′–49°00′E.
- **الحدود:** العراق (شمال/غرب) + السعودية (جنوب) + الخليج العربي (شرق ~500 كم ساحل + حدود بحرية مع إيران).
- **الأهمية الاستراتيجية:** منفذ طبيعي شمال شرق الجزيرة — ربط تجاري قديم بين الجزيرة وبلاد الرافدين والهند.

---

## 2. التضاريس الكبرى 🟢

> الكويت = **صحراء متموّجة بسيطة** — سهل منبسط يتدرج من الشرق (ساحل الخليج، ارتفاع 0) إلى الغرب والجنوب الغربي (أقصى ارتفاع ~300 م — منطقة الشقايا 290 م west). لا أنهر دائمة + لا جبال حقيقية.

### (أ) السهول الرملية (الخبرات) 🟢
- سهول رملية + كثبان — تُسمَّى محليًّا «الخبرات» (أحواض مستديرة) — منها خبرة الروضتين + أم العيش.
- سهل **الدبدبة** (جنوب/غرب) + سهل **الروضتين** (شمال).

### (ب) التلال 🟢
- **حافة جال الزور:** أبرز مظهر تضاريسي — 145 م فوق البحر + انحدار شديد (25–35°) + يمتد 67 كم حول جون الكويت (رأس الصبية شمالًا → المطلاع جنوبًا).
- **تلال اللياح وكراع المرو:** أقل ارتفاعًا، جيرية، توازي جال الزور (شمال شرق).
- **هضبة الأحمدي:** 37 م — طية محدبة (جنوب شرق الأحمدي) — قرب حقول النفط.
- **تلال وارة وبرقان:** تلال مخروطية جنوبًا — بقايا صخور متماسكة.

### (ج) الأودية والمنخفضات 🟢
- **وادي الباطن:** أبرز الأودية — يمتد 180 كم داخل الكويت (1200 كم في السعودية باسم «وادي الرمة») — يفصل الحدود الكويتية-العراقية.
- **منخفض البرقان** + منخفض أم الرمم (15 م عمق، 16.5 كم²) + منخفض الروضتين.
- **الخبرات:** أحواض صحراوية (خبرة أم عمارة + خبرة الشق + خبرة الرفيعي) — تجمع مياه الأمطار مؤقتًا.

### (د) الخلجان والجروف 🟢
- **جون الكويت:** خليج داخلي ضحل (مأوى طبيعي — عليه مدينة الكويت).
- **خليج كاظمة + خليج الأحمدي.**
- **الأخوار:** خور عبد الله + خور بوبيان + خور الصبية + خور المفتح + خور الأعمى.
- **الجروف الساحلية:** 25 م — حواف حادة (رأس الجليعة) + وادي المسننات.

### (هـ) ظواهر ريحية 🟢
- غطاءات حصوية (الصلبوخ) شمالًا + كثبان هلالية (القشعانية) — تأثير الرياح الشمالية الغربية.

## 4. المياه 🟢

| العنصر | الوصف |
|---|---|
| الأنهار | **لا أنهار دائمة** — الكويت من أكثر دول العالم شُحًّا بالمياه السطحية. |
| المياه الجوفية | محدودة + مالحة في الغالب — تحلية مياه البحر هي المصدر الرئيسي. |
| **تحلية المياه** | الكويت من أوائل دول الخليج في تحلية مياه البحر (منذ الستينات) — مصدر معظم مياه الشرب. |
| المياه العذبة | استوردتها الكويت تاريخيًّا بالسفن من شط العرب قبل التحلية. |
| الوديان | وادي الباطن + مجموعة الشقاق (شمال غرب) — جريان موسمي. |

## 5. المناخ 🟢

> المناخ **صحراوي حار** — حار جدًّا صيفًا (طويل: مايو–سبتمبر) + دافئ قصير شتاءً (نوفمبر–فبراير) + ربيع/خريف قصيران.

- **الصيف:** طويل + حار جاف — الحرارة قد تتجاوز **50°م** (سُجِّلت 51°م + أعلى مؤشر حرارة عالمي أحيانًا 2016) — رياح مثيرة للغبار (عواصف ترابية).
- **الشتاء:** قصير + دافئ — متوسط ~13–18°م، قد ينخفض إلى **−2°م** (أو الصفر) في بعض الليالي.
- **الأمطار:** شتوية + غير منتظمة + تتفاوت سنة لسنة (~100–250 مم/سنة في المتوسط لكن متغيرة).
- **الرياح:** شمالية غربية جافة (الشمال) + شرقية رطبة أحيانًا.

### ربط الجغرافيا بالثقافة 🟢

| المنطقة | المناخ/التضاريس | الأثر الثقافي |
|---|---|---|
| الساحل (مدينة الكويت + حولي + الأحمدي) | حار رطب + جون | لباس خفيف (دشداشة قطن) + العمارة بمجاهر هواء + مأكولات بحرية (سمك/روبيان) |
| الداخل/الصحراء (الجهراء + برقان) | حار جاف + تلال | لباس صوفي شتاءً + بداوة + مأكولات برية (هريس/جريش) + رعي |
| الجنوب (الأحمدي/الوفرة) | صحراوي + حقول نفط | صناعة نفطية + زراعة محدودة (الوفرة) |

## 6. التربة والغطاء النباتي 🟢

- **تربة رملية/حصوية** — قليلة الخصوبة (معظمها صحراء).
- **الغطاء النباتي:** متناثر + صحراوي (أعشاب + شجيرات قصيرة) — يزدهر بعد الأمطار الشتوية.
- **الواحات الزراعية:** الجهراء (شمال) + الوفرة (جنوب، حدود السعودية) + العبدلي — زراعة محدودة (خضراوات + تمور + أعلاف).
- **التصحّر 🟡:** تحدٍّ بيئي — لكن الكويت صحراوية أصلًا.

---

## 7. المناطق الطبيعية والمحميات 🟢

- **محمية الجهراء الطبيعية** — سبخات + طيور مهاجرة.
- **محمية وارة/بوبيان** — جزر + بيئة بحرية.
- **محمية قاروه/أم المرادم** — طيور + سلاحف نادرة.
- **حدائق وطنية حضرية** — حديقة الشهيد + حديقة الصباحية.

---

## 8. التحديات البيئية 🟡

1. **الحرارة الشديدة** — من أعلى درجات الحرارة عالميًّا صيفًا (تأثير صحي/اقتصادي).
2. **العواصف الرملية/الترابية** — متكررة (الرياح الشمالية الغربية).
3. **ندرة المياه** — اعتماد كامل تقريبًا على تحلية البحر (مكلفة + طاقة).
4. **تآكل السواحل** + ارتفاع البحر.
5. **التلوث النفطي** — حرق الآبار 1991 + الانسكابات.
6. **التصحّر** + ضعف الغطاء النباتي.

## خلاصة جغرافية

الكويت = **دولة صحراوية مسطحة** (17,818 كم²) بلا جبال/أنهار، تطل على الخليج العربي بأطول جون داخلي (مأوى طبيعي)، وتضم **9 جزر** (بوبيان/ربة/فيلكا الأبرز) + **حافة جال الزور** (أبرز مظهر تضاريسي 145 م) + **وادي الباطن**. المناخ صحراوي حار جدًّا (الصيف >50°م) + دافئ شتاءً. هذا المزيج (صحراء + بحر + جون) هو **أساس الهوية الكويتية** (تجارة بحرية + لؤلؤ + بداوة + نفط). 🟢
