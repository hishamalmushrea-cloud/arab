# دولة الكويت — الطعام والمطبخ

> منهجية: لكل طبق يُذكَر اسمه المحلي + المكونات + المناسبة + الأصل.
> المصادر: ويكيبيديا (مطبخ كويتي)، ghamsa، layalina، mhtwyat، encyclopediacooking، aishwzafran.

---

## 1. نظرة عامة 🟢

> المطبخ الكويتي = خليط **نجدي/بدوي + بحري + هندي/فارسي (تجارة)** + بهارات خليجية. سمة الغالبة: **البهارات (الزعفران/الهيل/اللومي)** + الأرز + اللحم + السمك + القمح (الهريس).

- **الأرز:** ركيزة الأطباق الرئيسية (بسمتي + هندي).
- **اللحم:** ضأن + دجاج + سمك (بحري).
- **القمح:** الهريس + الجريش (بدوي).
- **البهارات:** الزعفران + الهيل + القرفة + اللومي (الليمون الأسود) + الكمون + الكاري.
- **اللومي:** ركيزة كويتية (الليمون الأسود المجفف) — نكهة مميزة.
- **التمر + القهوة:** ضيافة (التمر الكويتي/السعودي + القهوة العربية).

---

## 2. الأطباق الرئيسية

### (1) المجبوس (المكبوس) 🟢 — الطبق الوطني
- **الوصف:** أرز بسمتي مطبوخ مع اللحم أو الدجاج أو الروبيان + بهارات (زعفران + هيل + قرفة) + **لومي** + حمص + زبيب أحيانًا.
- **المناسبة:** الأعراس + الأعياد + الولائم (رمز الكرم والضيافة).
- **التنوع:** مجبوس لحم / مجبوس دجاج / مجبوس روبيان / مجبوس فقع (كمأة) / مجبوس سمك.
- **الصلصات:** الدقوس (شطة حمراء) + المعبوج الأخضر (صلصة حارة) — تكمل الطبق.
- **الأصل:** خليجي مشترك (السعودية/البحرين/قطر/الإمارات) — لكن بكنية كويتية.

### (2) الهريس 🟢 — طبق المناسبات
- **الوصف:** قمح مطحون + لحم → يُطهى ساعات حتى يصير عصيدة ناعمة + سمنة بلدي.
- **المناسبة:** رمضان + عيد الأضحى + الأتراح (يُوزَّع على الجيران).
- **الأصل:** **بدوي** — قمح + لحم (بساطة الصحراء).

### (3) الجريش 🟢
- **الوصف:** قمح مجروش + لحم/دجاج + بهارات → يُطهى حتى ينعقد.
- **الأصل:** بدوي — شبيب بالهريس لكن قوام مختلف.

### (4) المرقوق (المرقوقة) 🟢
- **الوصف:** عجينة تُفرد رقائق + تُطهى مع لحم + خضار (قرع + باذنجان + بطاطا) + مرق طماطم + بهارات.
- **المناسبة:** وجبة عائلية.

### (5) القبوط 🟢
- **الوصف:** قطع عجينة صغيرة + لحم ضأن + كركم + طماطم + باذنجان — تُطهى معًا.
- **الأصل:** كويتي تقليدي.

### (6) المضروبة 🟢
- **الوصف:** أرز + لحم/دجاج → يُضرب (يُهرس) حتى ينعقد + بهارات.

### (7) المطبق 🟢
- **الوصف:** سمك (زبيدي/هامور) متبَّل + يقلى + يُقدَّم مع أرز + دقوس.
- **الأصل:** بحري.

### (8) المموش 🟢
- **الوصف:** أرز + عدس + ماش (ثقوب) + بهارات + روبيان أو لحم.
- **المناسبة:** شعبي.

### (9) الزربيان 🟢
- **الوصف:** أرز + لحم + زعفران + بهارات — شبيب بالمجبوس لكن نكهة يمنية/حضرمية.

### (10) المربين 🟢
- **الوصف:** روبيان طري/يابس + فقع (كمأة) + بهارات + أرز.
- **الأصل:** بحري/صحراوي.

### (11) العيش المحمّر 🟢
- **الوصف:** أرز محمَّر بالسكر + بهارات + لحم/دجاج — كويتي.

### (12) التشريبة 🟢
- **الوصف:** خبز يُغمر بالمرق + لحم — شعبي.

### (13) الخثرة 🟢
- **الوصف:** أرز + سمك + صلصة كثيفة (كالسائل).

### (14) محروق صبعه 🟢
- **الوصف:** أصابع عجين محشية + مرق + بهارات.

## 3. الحلويات 🟢

| الحلوى | الوصف | المناسبة |
|---|---|---|
| **اللقيمات** | عجين مقلي + دبس التمر/الشيرة — أشهر حلوى كويتية | رمضان + الأعياد + المناسبات |
| **الغُريّبة** | سمن + سكر + دقيق — حلوى رمضانية | رمضان |
| **الزلابية** | عجين مقلية + شيرة | رمضان |
| **قرص العقيلي** | قرص بهارات + زعفران | المناسبات |
| **الرهش** | طحينة + سكر — صحراوي | يومي |
| **الدربيل** | حلوى تقليدية | — |
| **صب القفشة** | حلوى بالقشطة | — |
| **الكليجة** | عجين محشي (تمر/لوز) | الأعياد |
| **العريكة** | عجين + تمر + سمن | — |
| **البقلاوة** | شرقية (الأندلس/الترك) | المناسبات |

---

## 4. المشروبات والضيافة 🟢

- **القهوة العربية:** ركيزة الضيافة الكويتية — هيل + زعفران + تمر (تُقدَّم في المجالس والديوانيات).
- **الشاي (الكويتي):** شاي أحمر + هيل أحيانًا.
- **اللبن:** يُقدَّم بعد الوجبات الدسمة (يُقال: «ضروري تختمها باللبن»).
- **دبس التمر:** مع اللقيمات + على مائدة رمضان.

---

## 5. مأكولات رمضان 🟢

- **الإفطار:** شوربة (عدس/لحم) + الهريس + المجبوس + السمبوسة + اللقيمات + الغُريّبة.
- **الغبقة:** وجبة ليلية رمضانية تجمع الأسر (سهر + طعام).
- **القرقيعان:** احتفال منتصف رمضان (الأطفال يطوفون + حلوى/مكسرات) — عادة خليجية مشتركة.
- **بوطبيلة:** المسحراتي (يوقظ الناس للسحور).

---

## 6. ربط الطعام بالجغرافيا 🟢

| المنطقة | الأطباق المميزة | السبب |
|---|---|---|
| الساحل (مدينة الكويت + حولي + الأحمدي) | المجبوس بالسمك + المطبق + المربين | بحري + صيد + تجارة |
| الداخل (الجهراء + البادية) | الهريس + الجريش + المرقوق + لحم العلوش | بدوي + قمح + رعي |
| عام | المجبوس (لحم/دجاج) + اللقيمات + القهوة | بهارات خليجية + ضيافة |

---

## 7. ملاحظات ثقافية 🟢

- **المجبوس = هويّة ضيافة:** يُقدَّم في صينية واحدة للجميع (روح الجماعة والتقارب).
- **الهريس = التكافل:** يُوزَّع على الجيران في رمضان والأتراح.
- **القهوة العربية = ضيافة:** رمز الكرم الكويتي (المجالس + الديوانيات).
- **اللومي + الزعفران:** بصمة كويتية-خليجية (نكهة مميزة).
- **الإرث الهندي/الفارسي:** بعض البهارات + طرق الطبخ (تجارة الكويت القديمة مع الهند).

---

## خلاصة الطعام

المطبخ الكويتي = **مطبخ خليجي بهاراتي** قائم على المجبوس (الطبق الوطني) + الهريس (المناسبات) + المرقوق + الجريش + المطبق البحري + اللقيمات (الحلوى) + القهوة العربية (الضيافة). تتمايز الأطباق: بحري (سمك/روبيان) على الساحل + بدوي (قمح/لحم) في الداخل. البهارات (لومي/زعفران/هيل) = البصمة الكويتية. 🟢
