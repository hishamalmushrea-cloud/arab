# دولة الكويت — اللباس التقليدي

> منهجية: لكل قطعة يُذكَر اسمها المحلي + المناسبة + المنطقة + الأصل (نجدي/بدوي/بحري/هندي).
> المصادر: ويكيبيديا (ثقافة الكويت)، wikikuwait، kuwaitmalaysia، kuna، auhm.org، donia-worldwide.

---

## 1. ملاحظة أولى: تنوع بيئي/تاريخي 🟢

> اللباس الكويتي = خليط **نجدي/بدوي (الأساس) + بحري (تجارة) + هندي/فارسي (أقمشة)**. يختلف بين **البر** (الداخل/البدوي) و**البحر** (الساحل/الحضر). اللباس التقليدي = **اللباس الرسمي** في المناسبات + المحافل — محافَظ عليه بقوة.
> **سمة:** البساطة + العملية + ملاءمة المناخ الصحراوي الحار (قطن صيفًا + صوف شتاءً).

---

## 2. الأصول التاريخية 🟢

| الأصل | القطع |
|---|---|
| **نجدي/بدوي** (الأساس) | الدشداشة + الغترة + العقال + البشت + السديري + القحفية |
| **بحري/تجاري** | أقمشة مستوردة (الهند/فارس) + بعض الأنواع |
| **هندي/فارسي** | قماش الزبون (الحرير من الهند) |

---

## 3. اللباس الرجالي 🟢

### القطع الأساسية

| القطعة | الوصف | الأصل/الاستخدام |
|---|---|---|
| **الدشداشة (الثوب/المقطع)** | ثوب فضفاض طويل أبيض من القطن (صيفًا) — المقطع من الصوف (شتاءً) — فتحة عنق ضيقة + فتحة صدر | **نجدي** — اللباس اليومي + المناسبات |
| **الغترة (الشماغ)** | قطعة قطنية للرأس — بيضاء (كويت) أو حمراء/بيضاء (شماغ نجدي) — تُطوى مثلثًا | نجدي — حماية من الشمس/الغبار |
| **العقال** | إطار أسود يثبّت الغترة | نجدي |
| **القحفية** | طاقية من خيوط قطنية شبكية تحت الغترة | نجدي |
| **البشت (المشلح)** | عباءة صوفية/وبر فاخرة — مفتوحة أمامي — ألوان (أسود/بني/رمادي/بيج) — تُطرَّز أطرافها (زري) | **نجدي/بدوي** — المناسبات + الوجهاء + الأمراء |
| **السديري** | سترة بلا أكمام فوق الدشداشة | نجدي |
| **الباركوت (واركوت)** | معطف صوف فوق المقطع (شتاءً) | — |
| **الفروة** | معطف مبطَّن بفروة خراف (شتاءً بارد) | بدوي |
| **السروال المكسر** | بنطلون داخلي طويل للكاحل + مطرَّز (زري/خوار) | — |
| **الزبون** | معطف حريري طويل مزركش بخيوط الذهب/الزري — يُلف حول الجسد + حزام | **هندي** (القماش) — للأثرياء/الوجهاء |
| **الدقلة (الحلاب)** | شبيبة الدشداشة لكن مفتوحة من الجانبين (ركبة→قدم) + أزرار أمامية — سهولة الحركة | — للأثرياء |
| **المشلح (الشلاح)** | ثوب فضفاض بأكمام واسعة جدًّا — قطن/ململ (صيفًا) — بدون ياقة | — الوجهاء + المعرس |
| **القاط** | طقم شتوي صوفي (دشداشة + سديري + سترة) | — |
| **القميص** | قطعة شتوية تحت الدشداشة | — |

> زي العريس الكويتي قديمًا: **الدشداشة + البشت + الغترة + العقال** (+ الزبون/المشلح للأثرياء). 🟢

## 4. اللباس النسائي 🟢

### القطع الأساسية

| القطعة | الوصف | الأصل/الاستخدام |
|---|---|---|
| **الدراعة (الدارا)** | ثوب طويل بأكمام طويلة من القطن/الحرير الهندي المنقوش — مطرَّز بالزري/الخوار/الشك — (سادة أحيانًا) | **لباس منزلي** — النساء |
| **الثوب** | ثوب واسع طويل بأكمام واسعة + فتحة عنق بيضاوية — أنواع (طور/مبعثر/منسوج/مسرح/زاري/متيل/بنونة/مخوص) | — |
| **الزبون (النسائي)** | ثوب طويل فاخر من الحرير + خيوط زري/خوار — فتحة عنق ضيقة + أكمام طويلة + مفتوح أمامي + يُلف حول الجسد | **هندي** — نساء المدينة الموسرات |
| **العباءة** | سوداء تغطي الجسد — صوف/حرير — أنواع (شد/شال/دربوية) | — |
| **البخنق** | غطاء رأس يخيط في الثوب — يغطي الشعر والرأس ما عدا الوجه — أنواع (جرجيس/كريب/شاش/زري/نور) | — |
| **الشيلة** | حجاب شعبي قديم (شبيب الحجاب القصير الحديث) | — |
| **الملفع (الملفوع)** | قماش يغطي الرقبة والرأس — للمسنات | — |
| **البرقع** | قناع مستطيل للوجه (جبهة→عنق) — أنواع (كامل: عيون فقط / مجوف: أجزاء أكبر) | **بدوي** — لا تنزعه المرأة البدوية |
| **البوشية** | غطاء شفاف أسود للوجه (~مترين) — يلتف حول الرأس والجسم | — نساء المدينة |
| **السروال** | ملابس داخلية طويلة + مطرَّز | — |
| **القبقاب / المداس / الجوتي** | حذاء بسيط بظهر مفتوح — أنواع (بوعرام/دبابة/سكربيل) | — |

## 5. الأعراس والدرزة 🟢

- **الدرزة:** مهر العروس الكويتي — ملابس + أقمشة + مفروشات + حلي + مستلزمات الزواج (حسب الحالة المادية).
- **البقشة:** ضمن الدرزة — 6–7 قطع قماش + عباءتان + حلي + مفارش.
- **العرس الكويتي قديمًا:** ليلة الخميس + العرضة والسامر + ولائم + العريس (الدشداشة + البشت + الغترة + العقال) + العروس (الزبون/الدقلة + حلي).
- **الجلوة:** مراسم النساء في الأعراس القديمة.

---

## 6. التطريز بحسب البيئة 🟢

| البيئة | اللباس + الأقمشة |
|---|---|
| **البر (الداخل/البدوي)** | دشداشة قطن + بشت صوف + قحفية + فروة شتاءً — ألوان ترابية |
| **البحر (الساحل/الحضر)** | دشداشة قطن + زبون حرير + دراعة مطرَّزة — أقمشة هندية/فارسية |
| **الشتاء** | المقطع (صوف) + الباركوت + الفروة + القاط |

---

## 7. الفروق بحسب البيئة 🟢

| البيئة | اللباس | السبب |
|---|---|---|
| مدينة الكويت (الحضر) | دشداشة + زبون (الأثرياء) + دراعة نسائية | حضر + تجارة بحرية + أقمشة مستوردة |
| البادية (الجهراء + الأطراف) | دشداشة + بشت + قحفية + فروة + برقع نسائي | بدوي + برد صحراوي |
| الأحمدي (الجنوب) | دشداشة + بشت + ملابس عمل (نفط) | صناعي + صحراوي |

---

## 8. التطور الحديث 🟢

- **الدشداشة + الغترة + العقال:** اللباس الرسمي اليومي + المناسبات — محافَظ عليه بقوة (الأكثر بقاءً في الخليج).
- **البشت:** في المناسبات الرسمية + الوجهاء + الأمراء.
- **اللباس الغربي (البدلة/الجينز):** رائج بين الشباب + العمل.
- **النساء:** العباءة + الشيلة (الحجاب) — شائع + الدراعة في المناسبات.
- **إحياء التراث:** حفظ اللباس التقليدي عبر المتاحف + الأعراس + الأيام التراثية.

---

## 9. ملاحظة نقدية

- اللباس الكويتي **نجدي-بدوي بالأساس** + تأثير بحري/هندي (الأقمشة).
- **الدشداشة + الغترة + العقال** = الزي الرجالي الأبرز (محافَظ عليه).
- **الزبون + الدقلة** = رمز الوجهاء/الأثرياء قديمًا.
- **الدراعة + الثوب + البرقع** = الزي النسائي التراثي.
- يربط اللباس بين **الأعراس والهوية**: العريس بالبشت + العروس بالزبون/الحلي.
- **الفرق بين الكويتي والسعودي:** الثوب الكويتي **أفضفضض** من السعودي. 🟡

---

## خلاصة اللباس

اللباس الكويتي = **نجدي-بدوي بالأساس** (دشداشة/غترة/عقال/بشت) + تأثير بحري/هندي (زبون/أقمشة مستوردة) + نسائي تراثي (دراعة/ثوب/برقع/بخنق). يختلف بين البر (البدوي) والبحر (الحضر). اللباس التقليدي محافَظ عليه بقوة في المناسبات + يُعد اللباس الرسمي. الدرزة + البقشة = ميراث الأعراس. 🟢
