# دولة الكويت — الاقتصاد

> منهجية: قطاعات + صادرات + تحديات + سياق. علامات الثقة 🟢/🟡/🟠.
> المصادر: صندوق النقد الدولي، البنك الدولي، فيتش، بنك الكويت الوطني، الجزيرة، sharqetrade، khaleejborsa.

## 1. نظرة عامة 🟢

| الحقل | القيمة | الثقة |
|---|---|---|
| الناتج المحلي الإجمالي (اسمي) | نحو **160 مليار $** (تقديرات 2024–2025) | 🟢 |
| نصيب الفرد | من **الأعلى عالميًّا** (نحو 30,000–40,000 $) | 🟢 |
| نمو الناتج | **ركود 2023/2024** (−3.2% إلى −3.6%) بسبب خفض إنتاج أوبك+ → **تعافٍ 2025** (+1.3% نصف أول / ~2.6% متوقع) | 🟢 |
| القطاع غير النفطي | نمو ~2–2.5% (2024–2025) | 🟢 |
| التضخم | ~3% (2023–2024) → 2% (متوقع) | 🟢 |
| الدين العام | **منخفض** مقارنة بالنظراء (فضل أصول الهيئة العامة للاستثمار) | 🟢 |
| فائض الحساب الجاري | نحو 28–31% من الناتج (2023–2024) | 🟢 |
| احتياطيات النقد الأجنبي | ~47.6 مليار $ (2023) | 🟢 |
| العملة | **الدينار الكويتي (KWD)** — أعلى عملة عربية قيمةً | 🟢 |
| إيرادات النفط | **85–90%** من الإيرادات العامة | 🟢 |

> الكويت = **اقتصاد ريعي نفطي** ضخم (ثاني أكبر احتياطي عربي بعد السعودية/العراق) + **صندوق سيادي** عملاق (الهيئة العامة للاستثمار) — لكنه **بطيء في التنويع** مقارنة بالإمارات/السعودية/قطر.

## 2. القطاعات الاقتصادية

### (أ) النفط والغاز 🟢 — عصب الاقتصاد
- **الاحتياطي:** نحو **101.5 مليار برميل** (~6% من الاحتياطي العالمي — سادس أكبر احتياطي).
- **الإنتاج:** ~2.6 مليون برميل/يوم (2024 — متفاوت بخفض أوبك+) — يستهدف 3.15 مليون (2026).
- **حقول:** **البرقان** (ثاني أكبر حقل نفط بالغاز في العالم — الأحمدي) + الوفرة + الصابرية + الخفجي (محايدة مع السعودية).
- **مصافي:** الأحمدي + الشعيبة + عبد الله (الزور) — تكرير.
- **شركة البترول الوطنية الكويتية (KPC) + الكويت للنفط (KOC)** — إنتاج + صادرات.
- 🟡 **نقطة ضعف:** الاعتماد على **مضيق هرمز** لتصدير النفط (تأثر حرب إيران 2026 — انخفض الإنتاج إلى 0.78 مليون برميل/يوم مارس/مايو ثم تعافى).

### (ب) الصناعة التحويلية 🟢
- **بتروكيماويات** + تكرير النفط + الأسمدة (PIC).
- الصناعات الغذائية + مواد البناء.
- 🟡 انكمش القطاع التحويلي 1% (2023) بسبب تكرير النفط.

### (ج) القطاع غير النفطي 🟢
- **الخدمات المالية:** البنوك (الكويت الوطني/الخليجي) + بورصة الكويت (أُدرجت في MSCI/FTSE/S&P — أسواق ناشئة).
- **الاتصالات** (زين/Ooredoo) + التجارة + العقار + السياحة (محدودة نسبيًّا).
- **العقار:** قطاع نشط (الشال + مؤشرات).
- يسهم بأكثر من **نصف الناتج المحلي الحقيقي** (نمو تدريجي).

### (د) الزراعة 🟡
- **محدودة جدًّا** (الصحراء + ندرة المياه) — الواحات (الجهراء + الوفرة + العبدلي) — خضراوات + تمور + أعلاف.
- الكويت تستورد **معظم غذائها**.
- الصيد البحري — سمك/روبيان (تقليدي).

### (هـ) السياحة 🟡
- **محدودة** مقارنة بالإمارات/قطر — سياحة عبور + ثقافية + تسوق + شواطئ.
- مشاريع سياحية: الخيران + الجبيل + مرة + صباح الأحمد.
- رؤية 2035 تهدف لتعزيز السياحة.

---

## 3. الصادرات والواردات 🟢

- **الصادرات:** **النفط الخام + المكرر + الغاز + البتروكيماويات** (90%+ من الصادرات) + أسمدة.
- **الواردات:** machinery + سيارات + غذاء + مواد أولية + سلع استهلاكية.
- **فائض تجاري** كبير (بفضل النفط) — فائض الحساب الجاري ~28–31% من الناتج.

---

## 4. الصندوق السيادي + الأصول المالية 🟢

- **الهيئة العامة للاستثمار (KIA):** من أكبر الصناديق السيادية عالميًّا — تدير **صندوق الأجيال القادمة** (يُحوَّل إليه **10% من الإيرادات** سنويًّا منذ 1976).
- **الأصول الخارجية** ضخمة — تحمي الكويت من صدمات أسعار النفط (فيتش 2026: «الأصول تحمي التصنيف»).
- هذه الأصول + انخفاض الدين = دعم الجدارة الائتمانية رغم الاعتماد على النفط.

---

## 5. التحديات الاقتصادية 🟡

| التحدي | الوصف | الثقة |
|---|---|---|
| **الاعتماد على النفط** | 85–90% من الإيرادات → عرضة لتقلب الأسعار + خفض أوبك+ | 🟢 |
| **بطء التنويع** | الكويت أبطأ من السعودية/الإمارات/قطر في التنويع + الاستثمار العام منخفض (أدنى في الخليج) | 🟢 |
| **جمود الإصلاحات** | الخلاف بين الحكومة ومجلس الأمة → تأخير قوانين (الدين العام تأخر سنوات) | 🟢 |
| **فاتورة الأجور العامة** | >50% من الإنفاق — رعاية اجتماعية ضخمة (من المهد إلى اللحد) | 🟢 |
| **العجز المالي** | توقع عجز ~5–11.5% من الناتج (2024–2032) مع انخفاض أسعار النفط | 🟢 |
| **التركيبة السكانية** | الكويتيون 31% vs الوافدون 69% — تحدٍّ ديموغرافي + بطالة شبابية | 🟢 |
| **مضيق هرمز** | نقطة ضعف لتصدير النفط (توترات إيران) | 🟢 |
| **البيروقراطية** | تعيق الاستثمار الأجنبي | 🟡 |
| **نقص الكوادر الوطنية** | في القطاع الخاص + التقني | 🟡 |

## 6. رؤية الكويت 2035 🟢

- **الهدف:** تحويل الكويت إلى **مركز مالي وتجاري إقليمي** + تنويع الاقتصاد بعيدًا عن النفط.
- **المحاور:** خدمات مالية + سياحة + صناعات تحويلية + ابتكار/تكنولوجيا + تعليم.
- **قانون الدين العام (2024):** سمح للكويت بالاقتراض → مساحة تمويلية للاستثمار في البنية التحتية.
- **صندوق الاستثمار المحلي المقترح.**
- صندوق النقد: أشاد بـ«تحول الكويت من دولة رفاهية نفطية إلى اقتصاد ديناميكي» (2026) — لكن حذَّر من بطء الإصلاحات.

---

## 7. السياق السياسي-الاقتصادي (حياد 🟡)

- **البرلمانية الكويتية:** الكويت = **الأكثر ديمقراطية في الخليج** (مجلس أمة منتخَب + صحافة) — لكن الجمود بين الحكومة والمجلس أخر الإصلاحات.
- **2020 (كوفيد + انخفاض نفط):** ضغط مالي → إجراءات مؤقتة.
- **2024–2026:** تعافٍ + قانون الدين + إصلاحات هيكلية.
- **2026 (حرب إيران):** تأثر تصدير النفط (هرمز) لكن الأصول السيادية حمت التصنيف.

> **حياد 🟡:** تقييم الأداء الاقتصادي-السياسي محل خلاف (السلطة: إصلاحات؛ منتقدون: بطء) — يُعرض بحياد.

## 8. ربط الاقتصاد بالجغرافيا 🟢

| المنطقة | النشاط الاقتصادي |
|---|---|
| العاصمة | إدارة + مالية + تجارة + خدمات |
| حولي | تجارة + خدمات + تجزئة (الأفنيوز) |
| الأحمدي | **حقول النفط (البرقان) + مصافي** — عصب الاقتصاد |
| الجهراء | زراعة محدودة + صحراء + حدود (معبر العبدالي/النويصيب) |
| الفروانية | مطار + تجارة + صناعات |
| مبارك الكبير | سكن + خدمات |

## خلاصة الاقتصاد

الاقتصاد الكويتي = **اقتصاد ريعي نفطي ضخم** (ثاني احتياطي عربي) + **صندوق سيادي عملاق** (صندوق الأجيال) + **دينار قوي** + **فائض خارجي** — لكنه **بطيء في التنويع** (أبطأ من جيرانه) + **اعتماد كلي على النفط** (85–90%) + **جمود إصلاحات** (حكومة vs برلمان) + **فاتورة أجور عامة ضخمة** + **تركيبة سكانية مختلة** (31% كويتيون). رؤية 2035 + قانون الدين الجديد محاولات إصلاح. المستقبل رهن بتنويع حقيقي + إصلاحات هيكلية + معالجة الديموغرافيا. 🟢/🟡
