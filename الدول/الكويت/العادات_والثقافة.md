# دولة الكويت — العادات والثقافة

> منهجية: العادات + المناسبات + الفنون + العمارة + الحرف. ربط الجغرافيا بالثقافة.
> المصادر: ويكيبيديا (ثقافة الكويت)، aspdkw، nabdalarab، auhm.org، kuwaitembassy، alanba.

---

## 1. الموسيقى والفنون الشعبية 🟢

### (أ) العرضة 🟢 — الرقصة الوطنية
- **الوصف:** رقصة جماعية للرجال — صفان متقابلان + طبول + سيوف/عصي + شاعر يُلقِّنهم الأبيات.
- **الأصل:** **بدوي** — ارتبط تاريخيًّا بالاستعداد للمعارك + التكاتف القبلي.
- **المناسبة:** الأعياد الوطنية + الأعراس + المناسبات الرسمية — رمز الاعتزاز بالهوية.
- **الأنواع:** العرضة البرية (النجدية) + العرضة البحرية (تستحضر الغوص).

### (ب) السامري 🟢 — فن الأفراح
- **الوصف:** فن غنائي بري — إيقاع هادئ/رزين — صفان متقابلان + الطار/التصفيق + شعر نبطي (غزل/حنين).
- **الأصل:** ارتبط بالسمر (اجتماعات الليل) — فن البر/الداخل.
- **المناسبة:** الأعراس + المجالس.
- **الميزة:** يخزن الشعر النبطي.

### (ج) الخماري 🟢 — رقص نسائي
- **الوصف:** رقصة نسائية بالثوب الشعبي + إيقاع متكرر — في الأفراح.

### (د) فن الصوت 🟢 — الموسيقى الكويتية
- **الوصف:** غناء شعبي يصاحبه العود + المرواس + التصفيق — بيتان من الفصحى في آخر الأغنية (موّال).
- **الآلات:** الصك + العود (حضر) + الربابة (بادية).

### (هـ) الفنون البحرية 🟢
- **الحدادي / الفجرى / العدساني:** أغاني البحارة في جلسات السمر (الغوص على اللؤلؤ).
- **الليوة:** فن بحري-إفريقي.
- **الفجري:** فن الغوص.

### (و) مسرح خيال الظل (القراقوز) 🟢
- فن تمثيل شعبي — تحريك صور على شاشة (بداية مسرح العرائس).

---

## 2. الديوانية 🟢 — مؤسسة اجتماعية كويتية
- **الوصف:** مجلس يجتمع فيه الرجال (أسبوعي/يومي) — لتبادل الأفكار + القضايا السياسية/الاجتماعية + الضيافة.
- **الأهمية:** **مؤسسة شبه ديمقراطية** كويتية فريدة — موقع القرار غير الرسمي + التواصل بين المواطنين والحاكم.
- **الأنواع:** ديوانية عائلية + سياسية + مهنية.
- **التراث:** الديوانية = ركيزة الحياة الاجتماعية الكويتية (لا تزال قوية).

---

## 3. الأعراس والمناسبات 🟢

### (أ) العرس الكويتي — عدة أيام 🟢
- **الخطوبة → الدزة/البقشة (المهر) → الحناء → يوم العرس (ليلة الخميس) → العرضة والسامر → الولائم.**
- العريس: الدشداشة + البشت + الغترة + العقال.
- العروس: الزبون/الدقلة + حلي + الجلوة (مراسم النساء).

### (ب) المناسبات الوطنية 🟢
| التاريخ | المناسبة | الذكرى |
|---|---|---|
| **25 فبراير** | **العيد الوطني** | الاستقلال/الجلوس |
| **26 فبراير** | **يوم التحرير** | التحرير 1991 |
| **10 نوفمبر** | **يوم الدستور** | الدستور 1962 |

### (ج) المناسبات الدينية + الشعبية 🟢
- **رمضان:** الغبقات + قرقيعان (منتصف رمضان — أطفال يطوفون) + بوطبيلة (المسحراتي) + دق الهريس.
- **المولد النبوي** + عيد الفطر + عيد الأضحى.
- **النون:** احتفال ظهور أول سن لطفل (عادة قديمة).

## 4. العمارة 🟢

### (أ) المدينة القديمة (السور القديم) 🟢
- **مدينة الكويت العتيقة:** أزقة ضيقة + فرجان (أحياء سكنية) — سميت بقبائلها (فريج العوازم + فريج المطران + سكة عنزة + براحة السبعان + فريج هلال).
- **السور الثالث (1920):** حماية المدينة — أُزيل مع التوسع.
- **بيت ديكسن (1870):** منزل تاجر كويتي — تراث.
- **قلعة الكوت:** النواة التاريخية + مخزن أسلحة.
- **قصر دسمان + قصر السيف:** مقر الحكم (تاريخي + حديث).
- **ديوان الأمير خزعل:** بجوار قصر دسمان.

### (ب) العمارة التقليدية 🟢
- **البيوت:** طين + خشب + مرجان + مجاهر هواء (بادقير — تكييف طبيعي) — أبرز سمة العمارة الكويتية القديمة (تأثير هندي/فارسي).
- **المساجد:** جامع البدر + السيدة فاطمة + جامع الخالد + جامع الكبير.

### (ج) العمارة الحديثة 🟢
- **أبراج الكويت** (1979 — رمز وطني).
- **مركز الشيخ جابر الأحمد الثقافي** (JACC — دار الأوبرا).
- **مركز الشيخ عبدالله السالم الثقافي** (ASCC — أكبر متحف ثقافي عربي).
- **المسجد الكبير** (1986 — أبرز مسجد).
- **الصالحية + الشويخ الصناعية.**

## 5. الحرف اليدوية 🟢

| الحرفة | الوصف |
|---|---|
| **القلافة (صناعة السفن)** | بناء السفن الخشبية (السنبوك/البوم/الشعَّاف) — تراث بحري |
| **السدو (النسيج)** | نسيج صوفي يدوي (زروع + بيوت شعر) — تراث بدوي 🟢 (يونسكو قيد النقاش) |
| **صناعة الحلي** | ذهب/فضة (المخنق + الشبكة) |
| **الخياطة التقليدية** | البشت + الزبون + الدشداشة (عائلة البحراني/الخياط) |
| **الغوص على اللؤلؤ** | حرفة بحرية قديمة (قبل النفط) — تُحيى رمزيًّا |
| **صناعة الفخار + السجاد** | حرف يدوية |

> الحرف الكويتية مزيج **بحري (القلافة/الغوص) + بدوي (السدو)** — تعكس البيئة المزدوجة. 🟢

---

## 6. القيم الاجتماعية 🟢

- **الكرم والضيافة:** قيم عليا — القهوة العربية + التمر + المجالس.
- **النخوة والشهامة:** قيم بدوية.
- **الديوانية:** مؤسسة اجتماعية-سياسية فريدة.
- **العائلة الممتدة** + احترام الكبار.
- **التكافل:** الهريس يُوزَّع + الصدقات + الأوقاف.

---

## 7. الفنون المعاصرة 🟢

- **السينما الكويتية:** رائدة في الخليج — «باسمة» + «عشاء الوافدين».
- **المسرح الكويتي:** عريق — «خيال الظل» (تاريخي) + فرق معاصرة.
- **الأدب:** الشعر النبطي (مرشد البذال + صقر النصافي) + الرواية.
- **المهرجانات:** مهرجان القرين الثقافي + مهرجان الكويت للمسرح + الهلالي.
- **المتاحف:** المتحف الوطني + مركز عبدالله السالم + مركز طراد الشمالي.

## خلاصة العادات والثقافة

الثقافة الكويتية = **مزيج بري-بحري** (بداوة + تجارة بحرية) يتجلى في: **العرضة** (الرقصة الوطنية) + **السامري** + **فن الصوت** + **الديوانية** (مؤسسة فريدة) + **المجاهر** (العمارة) + **القلافة/السدو** (الحرف) + **الأعراس** (الدرزة/البقشة). تونس = **دولة خليجية حديثة** (نفط + برج消费) لكن محافِظة على تراثها البري-البحري بقوة. 🟢
