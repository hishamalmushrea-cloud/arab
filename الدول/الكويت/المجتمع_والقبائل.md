# دولة الكويت — المجتمع والقبائل

> منهجية: السكان + التركيبة العرقية/الدينية + القبائل + الهوية. حياد في القضايا الحساسة.
> المصادر: ويكيبيديا (العتوب/البدون/سكان الكويت)، المعرفة، الجزيرة، الهيئة العامة للمعلومات المدنية، qabael.

## 2. التركيبة السكانية 🟡

### (أ) الكويتيون (~31%) 🟢
- **عرب كويتيون** (أصول قبلية + حضرية) — الأغلبية.
- **الدين:** الإسلام غالبية (سُنة + شيعة).
- **التركيبة الداخلية:** سُنة غالبية + شيعة ~30% من المواطنين (أصول إيرانية/حساوية/باكستانية + عربية).

### (ب) الوافدون (~69%) 🟢
| الجالية | النسبة التقريبية |
|---|---|
| **الهنود** | ~26–30% (أكبر جالية) |
| **المصريون** | ~10–12% |
| **البنغلاديشيون** | ~6–10% |
| **الفلبينيون** | ~5–6% |
| **النيباليون** | ~5% |
| **السوريون** | ~3–4% |
| **الباكستانيون** | ~4% |
| **الأردنيون** | ~2% |
| **السعوديون** | ~1% |
| آخرون (إيرانيون/أفارقة/أوروبيون/أمريكيون) | — |

### (ج) البدون 🟡 — فئة عديمو الجنسية
- **العدد:** ~tens of thousands (تقديري) — كان ~220–350 ألفًا قبل 1990 → تقلَّص إلى ~100–120 ألفًا (2010) — تتفاوت المصادر.
- **الأصل:** من أبناء البادية الرحل (شمال الجزيرة) + أصول إيرانية/سعودية/سورية/عراقية + لم يسجَّلوا في إحصاء 1965.
- **التركز:** الجهراء + تيماء + الصليبية.
- **القضية:** مطالبة بالجنسية الكويتية + حرمان من التعليم/الصحة/التملك/التنقل.
- **حياد 🟡:** قضية حساسة سياسية/إنسانية — الحكومة: أكثرهم يخفون جنسياتهم؛ البدون: لا وطن لهم سوى الكويت. تُعرض كخلاف.

## 3. القبائل 🟡

### (أ) العتوب — الحلف المؤسِّس 🟢
- **العتوب:** حلف قبلي خرج من نجد (منطقة الهدار/الأفلاج) في القرن 17 → الكويت.
- **الأسر:** **آل صباح** (الحاكمة) + **آل خليفة** (البحرين) + **الجلاهمة** + **آل بن علي**.
- **الأصل 🟡:** موضع خلاف بين المؤرخين:
  - **الرواية الأشهر:** من قبيلة **عنزة** العدنانية (العمارات/أبناء تغلب بن وائل).
  - **رواية أخرى:** آل بن علي = بنو عتبة من بني سليم، وانضم إليهم آل صباح/آل خليفة (وائلية) بالحلف.
  - يُعرض كخلاف تاريخي 🟡 (لا نسب دموي مباشر بالضرورة — حلف + مصاهرة).

### (ب) قبائل كويتية بارزة 🟢
| القبيلة | الأصل | الملاحظة |
|---|---|---|
| **آل صباح** | العتوب (عنزة) | الأسرة الحاكمة منذ 1752 |
| **بني خالد** | عدنانية | حكمت الكويت قبل العتوب (الإحساء) |
| **عنزة** | عدنانية | فروع كثيرة (العنوز) |
| **الدواسر** | عدنانية | تجارة |
| **مطير** | عدنانية | فريج المطران |
| **شمر** | طيئية قحطانية | — |
| **الرشايدة** | قحطانية | بادية + فرسان |
| **النعيم** | قحطانية | — |
| **العوازم** | — | فريج العوازم + الصوابر |
| **الظفير** | — | — |
| **العجمان** | يامية قحطانية | — |
| **بني هاجر** | قحطانية | — |
| **السبعان** | — | براحة السبعان |

> 🟢 كانت الفرجان (الأحياء) القديمة تُسمَّى بقبائلها: فريج العوازم + فريج المطران + سكة عنزة + فريج الرشايدة + براحة السبعان + فريج هلال.

### (ج) الانقسام الحضري/البدوي 🟢
- **الحضر:** سكان مدينة الكويت العتيقة (تجار + بحارة + صنّاع سفن) — من العتوب + أسر من الإحساء/البصرة.
- **البدو:** سكان البادية + الأطراف — رعي + رحل.
- **الخضر (الخضري):** أصول إيرانية/شيعية + تجنيس لاحق.
- لا يوجد فرق عرقي حقيقي بين الحضر والبدو — بل نمط حياة (مدينة vs بادية).

| الدين | النسبة | التفاصيل | الثقة |
|---|---|---|---|
| **الإسلام** | ~85%+ (المواطنون 100% تقريبًا) | **سُنة غالبية** (مالكية + حنبلية) + **شيعة ~30% من المواطنين** (جعفرية) | 🟢 |
| **المسيحية** | ~14% (وافدون) | كاثوليك + أرثوذكس | 🟢 |
| **الهندوسية** | ~8% (هنود) | — | 🟢 |

### الإسلام في الكويت 🟢
- دستوريًّا: **الإسلام دين الدولة** + رئيس الجمهورية... الأمير مسلم.
- **المذهب المالكي:** الأكثر انتشارًا بين السُّنة.
- **المذهب الحنبلي:** حضور (نجدي).
- **الشيعة الجعفرية:** ~30% من المواطنين — أصول إيرانية/حساوية/باكستانية + عربية.
- **الأشاعرة:** حضور بين العلماء.
- حرية الأديان مكفولة للمواطنين + الوافدين.

## 5. الهوية الوطنية 🟢

- **الكويتية = عربية-خليجية** (نجدية + بحرية) متجانسة.
- **انتماء قبلي** قوي + **انتماء وطني** حديث (ما بعد 1961/1991).
- **الهوية المزدوجة:** حضر (مدينة + تجارة) + بدو (بادية + رعي).
- **اللغة:** العربية الفصحى (رسمية) + اللهجة الكويتية + الإنجليزية.
- **التركيبة الفريدة:** 31% كويتيون + 69% وافدون → هوية وطنية قوية + تحدٍّ ديموغرافي.
- **الفخر بالتراث:** العرضة + الديوانية + القهوة العربية + اللباس التقليدي.

## 6. لامساواة/تحديات اجتماعية 🟡

- **التركيبة السكانية:** الكويتيون أقلية (31%) — تهدف الدولة لتعديلها (70% كويتيين).
- **البدون:** قضية عالقة + حرمان من الحقوق.
- **اللامساواة بين الحضر والبدو تاريخيًّا** — تقلَّصت مع التحديث.
- **بطالة الشباب الكويتي** + التوظيف في القطاع العام (الدولة أكبر موظِّف).
- **التعصب القبلي** + الطائفي (سُنة/شيعة) — محدود لكن موجود.

---

## 7. الحركات والتنظيمات الاجتماعية 🟢

- **الجمعيات التعاونية** — قوية (إدارة الأسواق + الخدمات).
- **الجمعيات الأهلية** + الثقافية + الرياضية.
- **مجلس الأمة** — تمثيل شعبي (الأكثر ديمقراطية خليجيًّا).
- **المرأة الكويتية:** نالت حقوقها السياسية 2006 + نواب + وزيرات.
- **الشباب:** قوة تغيير + إعلام (السينما/المسرح).

## خلاصة المجتمع

مجتمع الكويت = **مجتمع خليجي مزدوج** (حضر تجاري + بدوي رعوي) من **31% كويتيين** (عرب/عتوب + قبائل نجدية) و**69% وافدين** (هنود/مصريون/آسيويون). القبائل: العتوب (آل صباح الحاكمة) + بني خالد + عنزة + الدواسر + مطير + شمر + الرشايدة. الدين: إسلام غالبية (سُنة + شيعة 30%). الهوية = عربية-خليجية متجانسة + فخر بالتراث (العرضة/الديوانية). التحديات: الديموغرافيا (70% وافدون) + قضية البدون + بطالة الشباب. الكويت = **الأكثر ديمقراطية خليجيًّا** (برلمان منتخَب). 🟢/🟡
