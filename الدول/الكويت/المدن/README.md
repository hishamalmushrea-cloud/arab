# مدن الكويت — المرحلة الخامسة

> **المرحلة الخامسة:** ملف لكل **منطقة/تجمّع** موثَّق داخل **محافظة → منطقة → قطعة**. ليست ولاية ولا بلدية قطرية. 🟢
>
> **مدينة الكويت** في `العواصم/مدينة_الكويت/` — لا تكرار هنا. الشويخ وفيلكا هنا لأنهما ليستا ملف العاصمة.
>
> **لا يوجد مستوى «مدينة» منفصل** في القانون الكويتي — المناطق امتداد حضري واحد. الملفات أدناه لتجمّعات بأسماء شائعة.
>
> **السكان:** تعداد الإدارة المركزية **30 يونيو 2021** (4,385,717) 🟢. جداول citypopulation تدمج أحيانًا عدة مناطق في «مكان» واحد (حولي 926,170 = المحافظة كلها) — **لا يُعرض كسكان منطقة حولي**. PACI 2024: السالمية **321,190** والمهبولة **218,153** 🟡.
>
> لا تُهمَّش الجنوب والجزيرة والصحراء: الوفرة، فيلكا، الجهراء، القرين.
