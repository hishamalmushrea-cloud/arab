## 2. المواقع التراثية والأثرية

### (أ) المواقع الأثرية 🟢
| الموقع | الوصف |
|---|---|
| **جزيرة فيلكا (إيكاروس)** | آثار يونانية/هلينستية (القرن 3 ق.م) — معبد إيكاروس + آثار إسلامية + كنيسة — أهم موقع أثري كويتي |
| **كاظمة** | آثار إسلامية + خليج تاريخي |
| **الصبيحية** | آثار |

| التراث | الوصف |
|---|---|
| **العرضة** | رقصة وطنية (نقاش يونسكو) |
| **فن الصوت** | موسيقى كويتية (نقاش يونسكو) |
| **السدو** | نسيج بدوي (نقاش يونسكو) |

## خلاصة الشخصيات والآثار

الكويت = **إمارة عربية حديثة** (1752) أسَّسها **آل صباح** — من **صباح الأول** إلى **مشعل الأحمد**، مع أعلام بارزين: **مبارك الكبير** (مؤسِّس الحديثة) + **أحمد الجابر** (النفط) + **عبدالله السالم** (الاستقلال/الدستور) + **جابر الأحمد** (مجلس التعاون/التحرير) + **صباح الأحمد** (الدبلوماسية). المواقع: **فيلكا** (آثار يونانية) + **المدينة العتيقة/المباركية/قصر دسمان** (تراث) + **أبراج الكويت/JACC/ASCC** (حديث). التراث غير المادي: **العرضة/فن الصوت/السدو/الديوانية**. الكويت = **دولة خليجية صغيرة لكن عميقة التاريخ** (العتوب + النفط + الديمقراطية). 🟢
