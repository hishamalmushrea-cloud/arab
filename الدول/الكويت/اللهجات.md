# دولة الكويت — اللهجات

> منهجية: اللهجة الكويتية + لهجاتها الجهوية (حضرية/بدوية) + قاموس مفردات + أمثال.

## 1. نظرة عامة 🟢

| الحقل | المحتوى | الثقة |
|---|---|---|
| الاسم المحلي | **اللهجة الكويتية** | 🟢 |
| العائلة | أفرو-آسيوية → سامية → عربية وسطى → خليجية | 🟢 |
| الانتشار | الكويت + أجزاء من شرق السعودية + جنوب العراق (تقارب لهجي خليجي) | 🟢 |
| القرابة | قريبة من لهجات الخليج (السعودية الشرقية/القطري/الإماراتي/البحريني) — مع فروق نبرة | 🟢 |
| اللغة الرسمية | **العربية الفصحى** (دستوريًّا) — اللهجة الكويتية لغة التواصل اليومي | 🟢 |
| مكانة الإنجليزية | لغة عمل/تجارة واسعة الانتشار | 🟢 |

> 🟢 اللهجة الكويتية = **خليط نجدي/حجازي + فارسي + هندي** في قالب واحد — النجدية الأكبر من حيث المصطلحات. الأصل البدوي قريب من الفصحى.

## 2. التأثيرات اللغوية 🟢

| الأصل | أثره | المثال |
|---|---|---|
| **العربية النجدية** | الأساس النحوي والمعجمي | وايد (كثير)، شنو (ماذا) |
| **العربية البدوية** | مفردات فصيحة | طس (اذهب)، كود (ربما)، بليه (الذكي) |
| **الفارسية** | مفردات (خاصة الحضر) + حرف الجيم المثلثة (چ) | (انظر الفونولوجيا) |
| **الهندية** | مفردات بحرية/تجارية | بعض مصطلحات البحر والتجارة |
| **الإنجليزية** | مفردات حديثة | كوول، يافطة |

> 🟢 **الجيم المثلثة (چ) + حرف (گ):** استعارت اللهجة الكويتية صوتين من الفارسية (28 حرفًا عربيًّا → 30 حرفًا في اللهجة).

## 3. الفونولوجيا — تحولات الحروف 🟢

### (أ) تحوّل الكاف (k) → الجيم المثلثة (چ /t͡ʃ/)
| الفصحى | الكويتية |
|---|---|
| فيلكا | فيلچا |
| سمك | سمچ |
| كلب | چلب |
| كم | چم |

### (ب) تحوّل القاف (q) → گ (G)
| الفصحى | الكويتية |
|---|---|
| قهوة | گهوة |
| قال | گال |
| قمر | گمر |

### (ج) تحوّل القاف (q) → الجيم (j) أحيانًا
| الفصحى | الكويتية |
|---|---|
| قبلة | جبلة |
| طريق | طريج |
| رفيق | رفيج |

### (د) تحوّل الجيم (j) → ياء (y) — **في لهجة الحضر فقط**
| الفصحى | الحضرية |
|---|---|
| مسجد | مسيد |
| فجر | فير |
| رجال | ريال |

> 🟡 في لهجة البدو، الجيم تُلفظ جيمًا (رجاجيل) — عكس الحضر.

## 4. اللهجات الجهوية 🟢

> تختلف اللهجة الكويتية بين **الحضر** و**البدو**، وكذلك بين المناطق (مخارج الكلمة + النبرة + بعض المفردات).

### (1) لهجة الحضر 🟢
- **المنطقة:** مدينة الكويت العتيقة (شرق + جبلة + المرقاب + الفنطاس).
- **الميزة:** تحوّل **الجيم → ياء** (مسيد/فير/ريال) — أبرز سمة حضرية.
- **النبرة:** مخارج كلمات أنعم.

### (2) لهجة البدو 🟢
- **المنطقة:** البادية (الجهراء + الأطراف) + أهل القرى.
- **الميزة:** الجيم تُلفظ جيمًا (رجاجيل) + القاف گ + قرب من الفصحى (أفصح من الحضرية).
- **النبرة:** مخارج صريحة قوية.

### (3) لهجة فيلكا 🟢
- **المنطقة:** جزيرة فيلكا.
- **الميزة:** سمة حضرية + خصائص فريدة (جزيرة معزولة تاريخيًّا).

### (4) لهجة الجهراء 🟢
- **المنطقة:** محافظة الجهراء.
- **الميزة:** بدوية الطابع (أهل القرى).

### (5) لهجة الأصول الأعجمية 🟢
- **المنطقة:** الأسر ذات الأصول الإيرانية/النجدية المتأخرة.
- **الميزة:** نبرة خاصة (مثل لهجة بعض الفنانين) — «شلونييك».

> 🟡 **النقاش اللغوي (خالد الرشيد):** اللهجة الكويتية ليست لهجة واحدة ولا لهجتين (حضرية/بدوية) — بل تختلف بين جبلة وشرق، الفنطاس والجهراء، فيلكا والبادية. يُعرض كرأي أكاديمي 🟡.

## 7. ربط اللهجة بالجغرافيا والتاريخ 🟢

- **مدينة الكويت العتيقة (الحضر)** — تجارة بحرية + جوار الفرس/الهند → لهجة حضرية (جيم → ياء) + مفردات فارسية/هندية.
- **البادية (الجهراء/الأطراف)** — رعي + بداوة + جوار نجد → لهجة بدوية قريبة من الفصحى + نجدية.
- **فيلكا** — عزلة جزيرة → لهجة فريدة.
- **الأصول القبلية** (عنزة/شمر/الدواسر/الرشايدة) → لهجات قبائل متقاربة عبر الجزيرة.

## خلاصة اللهجوية

اللهجة الكويتية = **لهجة عربية خليجية** بطبقات نجدية (الأساس) + فارسية + هندية، تتميز بـ**تحوّلات الحروف** (الكاف→چ، القاف→گ أو ج، الجيم→ياء في الحضر) و**لهجتين رئيسيتين** (حضرية + بدوية) مع تباينات جهوية (فيلكا/الجهراء). البدوية أقرب للفصحى. الثراء المعجمي يعكس تاريخ الكويت (بحر + صحراء + تجارة + بداوة). 🟢
