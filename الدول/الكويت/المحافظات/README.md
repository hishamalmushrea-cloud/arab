# محافظات الكويت — المرحلة الرابعة (الوحدات الإدارية العُليا)

> **المرجع الإداري:** المستوى الأعلى = **محافظة** — **6 محافظات**. يحكمها محافظ تابع لوزارة الداخلية. 🟢
>
> **المستوى الثاني:** **منطقة** (حي سكني) → **قطعة** (بلوك). ليست ولاية ولا قضاء ولا بلدية قطرية. 🟢
>
> **مدينة الكويت** في `العواصم/مدينة_الكويت/` — هنا **محافظة العاصمة**.
>
> **السكان:** جدول الإدارة المركزية للإحصاء (صفحة التعداد حسب المحافظات) — جملة **4,385,717** (لا تشمل بعض فئات الإقامة غير النظامية). السنة غير مبيَّنة في الصفحة؛ أحدث من تقديرات PACI 2008. تقديرات 2023 أعلى. 🟡
