# الشخصيات والآثار في الجمهورية الفيدرالية الصومالية

> رؤساء + زعامات دينية + أعلام + مدن تاريخية + مساجد. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر.

---

## 1. رؤساء الصومال المعاصرين 🟢

### عدن عبد الله عثمان دار (1908–2007) 🟢
- **أول رئيس** (1960–1967) — من قبيلة هوية.
- قاد الاستقلال (1 يوليو 1960) — أول رئيس للجمهورية.

### عبد الرشيد علي شارماركي (1919–1969) 🟢
- رئيس وزراء ثم رئيس (1967–1969) — من قبيلة دارود.
- اغتيل 1969 (أدى إلى انقلاب سياد بري).

### محمد سياد بري (1919–1995) 🟢🟠
- انقلاب 1969 + حكم 1969–1991 + اشتراكية + قمع + حرب أوغادين (1977–1978) + هزيمة + أُطيح 1991.
- لقب: «الديكتاتور».

### علي مهدي محمد (1934–2021) 🟠
- رئيس انتقالي (1991–1997) — من قبيلة هوية + أعلن نفسه رئيسًا بعد انهيار سياد بري.

### عبد القاسم صلاد حسن (1941–2024) 🟠
- رئيس انتقالي (1997–2001) — أعلن حكومة مقديشو + جهادي سابق.

### عبد الله يوسف أحمد (1964–2024) 🟠
- رئيس انتقالي (2001–2004) + رئيس البرلمان الانتقالي — من قبيلة هوية.

### علي محمد جيدي (1952–) 🟠
- رئيس انتقالي (2004–2008) — من قبيلة دارود.

### شريف شيخ أحمد (1964–) 🟢
- رئيس انتقالي (2009–2012) — من قبيلة هوية + أُعيد 2022.
- أطلق المرحلة الفيدرالية + دستور 2012.

### حسن شيخ محمود (HSM — 1965–) 🟠
- رئيس (2012–2017 + 2017–2022 + 2022–الآن) — من قبيلة هوية + أُعيد 2022 + 2017 + 2022.
- أعلان حرب شاملة على الشباب (2023) + أزمة سياسية (2024–2026).

## 2. أعلام دينيون + زعامات 🟢

### الشيخ محمد عبد الله حسن (1864–1920) 🟢
- قاد **حركة الدراويش** ضد الاستعمار البريطاني + الإيطالي (1899–1920) — قاوم 20 عامًا.
- لقب: «الملا المجنون» (Mad Mullah — بالإنجليز).

### الشيخ عبد الرحمن بن إسماعيل الجبرتي (دارود) 🟡
- مؤسس قبيلة دارود (القرن 10–11 م) — رواية شفهية (نسب إلى عقيل بن أبي طالب).
- مدفون في حيلاان (سناج — أرض الصومال).

### الشيخ إسحاق بن أحمد (إسحاق) 🟡
- مؤسس قبيلة إسحاق (القرن 12–13 م) — رواية شفهية (نسب هاشمي).
- مدفون في ميدح.

### الشيخ علي صالح 🟢
- مؤسس الطريقة الصالحية (بعالية) — زعيم صوفي.

- **نورالدين فارح:** شاعر + كاتب + أديب.
- **محمد إبراهيم ورسامي:** شاعر + كاتب.
- **يسلم علي جوهر:** شاعر + كاتب.
- **محمد سليمان طراب:** شاعر + كاتب.
- **مريام ميرسو:** مطربة + مغنية.
- **قمارديد حاجي أحمد:** مطرب + ممثل.
- **سعد علي شيري:** ممثل + كوميدي.
- **أحمد حاجي علي:** ممثل + كوميدي.

## 4. المدن التاريخية 🟢🟠

### مقديشو (Mogadishu)
- **العاصمة + أكبر مدينة** (~1.5–2.5 مليون) + ميناء + مطار دولي.
- **التاريخ:** مركز تجاري إسلامي (القرن 10) + سلطنة مقديشو + مقر الإدارة الإيطالية.
- **المعالم:** مسجد مقديشو القديم (القرن 10) + أركوقو + فاكود + سوق بقراوية + شاطئ ليدو.
- 🟠 متأثرة بالحرب (1991–الآن) + استرداد بطيء.

### هرجيسا (Hargeisa)
- **عاصمة أرض الصومال** (الانفصالية — غير معترف بها دوليًّا).
- **التاريخ:** مقر الإدارة البريطانية (1942) + تدمير 1988 (القوات الحكومية) + إعادة بناء.
- **المعالم:** سوق هرجيسا + ميناء بربرة + مطار دولي.
- «أكبر مدينة في الشمال» + مستقرة نسبة.

### مركة (Merca)
- **مدينة ساحلية تاريخية** (جنوب) + مركز تجاري + ميناء.
- **التاريخ:** من سلطنة عجوران + تجارة المحيط الهندي.

### برعا (Barawe)
- **مدينة ساحلية تاريخية** + مركز تجاري + ثقافي.
- **التاريخ:** تجار عرب + فرس + هند + البندقية + الإسلام.

### هوبيو (Hobyo)
- **مركز تجاري + سلطنة** + ميناء.

### كيسمايو (Kismaayo)
- **عاصمة جوبالاند** + ميناء + ثالثة أكبر مدن.
- **التاريخ:** تجارة + تصدير.

### بيدوا (Baidoa)
- **العاصمة الانتقالية السابقة** + جنوب.
- **التاريخ:** مركز الحكومة الانتقالية (2004) + حصار الشباب (2008–2009).

## 5. المواقع الأثرية الأخرى 🟢
- **زيلع (Seylac):** عاصمة سلطنة عدال التاريخية (شمال) + ميناء + تجارة.
- **أركوقو (Arba'a Rukun):** مسجد تاريخي (مقديشو — القرن 13).
- **فاكود (Fakhr al-Din):** مسجد + مدرسة (مقديشو).
- **المدن الساحلية الأربع** (مقديشو + مركة + برعا + هوبيو) — سلسلة تجارية إسلامية.

## 7. المعالم الحديثة 🟢🟠
- **قصر الرئاسة** (مقديشو) + **البرلمان** + **المطار الدولي** (أدن أدي).
- **الميناء** (مقديشو + كيسمايو + بربرة + مركة).
- **متحف مقديشو الوطني** + **مكتبة** (مقديشو).
- 🟠 متأثرة بالحرب + استرداد بطيء.

## 8. المعالم الطبيعية 🟢
- **ساحل المحيط الهندي** (3,333 كم — شواطئ + شعاب مرجانية + أسماك).
- **جبال شمبريس + سورود** (شمال + شمال شرق).
- **أنهار شبيلي + جوبا** (وسط + جنوب).
- **محميات:** محمية بولامو + محمية لاسعانود + محمية كزموم.
- **صحراء شمال** + **سافانا جنوب**.
- **كثبان** (سياحة صحراوية — رالي تاريخي).

## 9. ربط الآثار بالتاريخ والجغرافيا
- **الساحل + المحيط الهندي + خليج عدن** → مدن ساحلية (مقديشو + مركة + برعا + هوبيو) + سلطنات إسلامية + تجارة المحيط الهندي + المساجد + العمارة الإسلامية. 🟢
- **التاريخ الإسلامي** (القرن 7–19) → سلطنة عجوران + سلطنة عدال + سلطنة مقديشو + هوبيو + جيليدي + الإسلام + العربية + الأنساب العربية (دارود + إسحاق — روايات). 🟢
- **التاريخ الاستعماري** (القرن 19–1960) → تقسيم بريطاني/إيطالي/فرنسي + الإدارة + المقاومة (الداراويش) + مقر الإدارة (مقديشو + هرجيسا). 🟢
- **الحرب الأهلية (1991–الآن)** → تدمير المدن التاريخية + فراغ السلطة + المليشيات + تدهور الآثار + استرداد بطيء (مقديشو). 🟠
- **أرض الصومال** (الانفصال 1991) → هرجيسا (عاصمة) + إعادة بناء + مستقرة نسبة + غير معترف بها دوليًّا. 🟠
- **الموقع الاستراتيجي** (باب المندب) → ملاذ للقرصنة + تجارة + قواعد عسكرية أجنبية + حرب الشباب. 🟠
