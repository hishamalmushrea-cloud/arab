# العادات والثقافة في الجمهورية الفيدرالية الصومالية

> ثقافة صومالية: عربية إسلامية + بدوية رعوية + إفريقية + قبلية (نظام 4 قبائل). علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر.

---

## 1. نظام العشائر (4 قبائل) — الأساس الاجتماعي/السياسي 🟢

### المبدأ
- **«أبتيرسي» (Abtirsi):** إحصاء الآباء — النسب الأبوي = إطار القرابة الأعلى.
- **التسلسل:** القبيلة → العشيرة → البطن → الأفخاذ → العائلة → الفرد.
- **«عاد» (Aad):** عادة/عرف — النظام العشائري.
- **«تول» (Tol):** قبيلة — أعلى درجة الانتماء.
- **«قولو» (Qolo):** عشيرة — وحدة سيطرة + شيخ عشيرة + سطان.
- **«رير» (Reer):** عائلة — أصغر وحدة.
- **«خييان» (Xeer):** قانون عشائري صلح — تسوية النزاعات.

### القبائل الـ5 الكبرى (النظام 4 قبائل) 🟢
1. **در (Dir):** من سمالي (أبو بكر) — شمال + أصل «صومالي».
2. **دارود (Darod):** من عبد الرحمن بن إسماعيل الجبرتي (عقيل بن أبي طالب — رواية).
3. **هوية (Hawiye):** من أحمد بن عبد الرحمن بن عثمان — وسط + مقديشو.
4. **إسحاق (Isaaq):** من الشيخ إسحاق بن أحمد (هاشمي — رواية) — شمال غرب.
5. **رحنوين (Rahanweyn):** ساب (زراعة) — دجل + ميرفلي — جنوب.

### الطبقات 🟢🟠
- **سمالي (الصوماليون):** رعاة نبيلون (در + دارود + هوية + إسحاق) — الصوماليون الأصل.
- **صاب (الزرّاعون):** رحنوين (دجل + ميرفلي) + بانتو — الزراعة.
- **المدجان (المهن):** الصيد + الختان.
- **تومال (الحرف):** الحدادة + الجلود.
- **يبر (الفنون):** الدباغة + السحر.

> 🟠 **العصبية القبلية** = عقبة أمام بناء الدولة + الحرب الأهلية (1991) + «المحاصصة القبلية» في البرلمان الفيدرالي (4.5 لكل قبيلة).

## 2. الأعراس والزواج 🟢

### مراحل الزفاف
1. **«المسا faire»:** الخطوبة + تقديم المهر (مهر الصومالي).
2. **«القران»:** العقد الشرعي (مأذون/إمام).
3. **الحناء:** للعروس + العريس.
4. **ليلة الزفاف:** الديراك + الغارباسار + الذهب + الوليمة.
5. **«أروسي» (Aroosy):** الحفل — رقصات + غناء + إلقاء شعر.

### عادات
- **الختان (المدجان):** للذكور (إرث إسلامي/إفريقي).
- **«الديا» (Diya):** الدية — تسوية القتل بالنسب العشائري.
- **«المحرم» (Mehram):** القريب المحرَّم — الزواج ضمن العشيرة (تقاليد).

---

## 3. المناسبات الدينية 🟢

### رمضان
- **السمبوسة** + الكنترة + الحساء + التمر + حليب الإبل + الشاي + الكاك كاك.
- موائد جماعية + التراويح + الختمات + المسحراتي.
- الإفطار على حليب الإبل («سيد المائدة» — مقاومة العطش).

### العيد
- صلاة العيد + الذبيحة (الأضحى) + الأرز + اللحم المشوي + الكاك كاك + الديراك + الذهب.
- «دب شيد» (إضاءة النار — إرث استقلال).

### المولد النبوي
- مواكب + مدائح صوفية + قهوة + الحلوى.

---

## 4. الطرق الصوفية 🟢
- **القادرية** (عبد القادر الجيلاني — الأكثر انتشارًا).
- **الأحمدية** (أحمد بن إدريس — الأشراف).
- **الصالحية** (الشيخ علي صالح — بعالية).
- **الرفاعي** (أحمد الرفاعي) + **السمانية** (الشيخ محمد السماني).
- الزوايا + المحاضر + المدائح + الذكر.
- الصوفية مكوّن ديني/اجتماعي/سياسي عميق + الأحزاب (الصالح + الجفلي + الإصلاح + الاتحاد).

---

## 5. العادات الاجتماعية 🟢
- **الكرم/الضيافة:** وجبة كاملة للغريب + الشاي + القهوة — قيمة أساسية.
- **المجالس (القعدات):** مجالس الرجال (المسيد) + النساء.
- **«المحرم» + «الصِل» (Xiri):** العلاقات الأسرية + القرابة — واجبات.
- **«المسا faire» + «الأمانة» (Amaan):** الأمانة + الوفاء بالعهد — قيم إسلامية/عشائرية.
- **التكافل:** الجار + الحِلّة (الحي) + الأفراح + المآتم الجماعية (إرث بدوي).

---

## 6. الفنون الشعبية 🟢
- **الشعر الصومالي (الغنائي + البطوش):** فن شفهي عريق (القصيد + الإلقا + الحماسة + الغزل) — «بلد المليون شاعر».
- **الغناء البنتلاندي:** «البنتلان» (رقصة + غناء).
- **الموسيقى:** الطبل + الناي + العود + البنتلان.
- **الرقصات:** البوبلي + دب شيد + البنتلاند + الديفي.
- **الفنون الحرفية:** النسيج (المكاوييس + الديراك) + الجلود + الخشب + الصياغة (الذهب).

---

## 7. العمارة التراثية 🟢
- **المساجد التاريخية:** مسجد مقديشو القديم (القرن 10) + مساجد أركوقو + فاكود.
- **العمارة الإسلامية:** مساجد + أضرحة + مدارس قرآنية (مدن ساحلية).
- **العمارة الاستعمارية:** مقديشو (إيطالي) + هرجيسا (بريطاني) + كيسمايو.
- **المدن الساحلية التاريخية:** مقديشو + مركة + برعا + هوبيو + مركة + بربرة.
- **المقابر الإسلامية:** أضرحة الأولياء + الشيوخ.
- **«البركل» (Berkal):** الحي/الفرجان — وحدة سكنية قبلية.

---

## 8. الثقافة المعاصرة 🟢
- **الشعر الصومالي:** فن أدبي عريق (الغنائي + الحماسة) — «بلد المليون شاعر».
- **الأدب الصومالي الحديث:** نورالدين فارح + محمد إبراهيم ورسامي + يسلم علي جوهر.
- **الموسيقى:** تقليدي + حديثة — مطربون كبار.
- **الإعلام:** إذاعة + تلفزيون (تلفزيون الصومال) + صحف.
- **الإعلام الجديد:** الصومال 24 + راديو مقديشو + شبكة شabelle.

---

## 9. ربط الجغرافيا بالثقافة
- **الساحل + المحيط الهندي** → ثقافة بحرية + تجارة + الإسلام (القرن 7) + مدن ساحلية + الأنساب العربية + العمارة الإسلامية. 🟢
- **السهول + السافانا + البدو** → حياة رعوية بدوية + الإبل + الماعز + نظام 4 قبائل + الكرم + الديراك + المكاوييس + الشعر (الغنائي). 🟢
- **الإسلام + الصوفية** → الطرق (قادرية + أحمدي) + المحاضر + المدائح + الختان + الحلال.
- **الموقع الاستراتيجي + التجارة** → تأثيرات عربية + هندية + إيطالية + إفريقية + الإسلام كمكوِّن موحِّد + المطبخ متعدد الأصول.
- **العصبية القبلية** → نظام اجتماعي/سياسي قوي + «المحاصصة القبلية» في البرلمان + الحرب الأهلية (1991) + عقبة أمام بناء الدولة. 🟠
- **الانقسام الجغرافي + التاريخي** (شمال غرب بريطاني × جنوب إيطالي) → بذور الانفصال (أرض الصومال — الماي) + تباين ثقافي/لهجي + نظام 4 قبائل.
- **الحرب الأهلية + الشباب** → تدمير التراث + فراغ السلطة + المليشيات + الحلال + تدهور المؤسسات + العود للقوانين العرفية (الديا + الخييان). 🟠
