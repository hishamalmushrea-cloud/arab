## التقسيم الإداري سريعًا (مرجع)

### المرجع الجغرافي: 18 غوبول 🟢
أودال (بوراما) · وقويي جالبيد (هرجيسا) · توغدير (برعو) · سناق (عيرغابو) · سول (لاسعانود) · باري (بوصاصو) · نوجال (**غاروي**) · مدج (غالكعيو) · جلجدود (دوسمريب) · هيران (بلدوين) · شبيلي الوسطى (**جوهر**) · بنادر (مقديشو) · شبيلي السفلى (مركة) · باي (**بيدوا**) · باكول (هودور) · جدو (جربهاري) · جوبا الوسطى (بوعال) · جوبا السفلى (كيسمايو).

### الطبقة الاتحادية (سياسية) 🟠
- جوبالاند (كيسمايو) = جدو + جوبا الوسطى + جوبا السفلى — ليست شبيلي السفلى.
- جنوب غرب (**بيدوا**) = باي + باكول + شبيلي السفلى — ليست بنادر.
- هيرشابيلي (**جوهر**) = هيران + شبيلي الوسطى.
- غلمدغ (دوسمريب) = جلجدود + جنوب مدج — ليست جدو/هيران/نوجال.
- بونتلاند (**غاروي**) = باري + نوجال + شمال مدج.
- بنادر = مقديشو — ليست ولاية.
- أرض الصومال (هرجيسا) = انفصال أحادي 1991.
- SSC / الشمالية الشرقية (لاسعانود) = نزاع 2023–2025.

### التسلسل 🟢
- **غوبول → دغمو → حي/قرية.** الولاية الاتحادية طبقة فوق الغوبول لا تستبدله.

## العاصمة
- **مقديشو** — العاصمة + أكبر مدينة + ميناء + مقر الحكومة الاتحادية. ملف: `العواصم/مقديشو/`. 🟢🟠
- **هرجيسا** — مقر إدارة أرض الصومال (انفصال أحادي).
- **غاروي** — عاصمة بونتلاند (نوجال) — ليست «غاروه».
- **كيسمايو** — عاصمة جوبالاند.
- **بيدوا** — عاصمة جنوب غرب (ليست براوة).
- **جوهر** — عاصمة هيرشابيلي.

(دراسة كل عاصمة في ملف مستقل ضمن مجلد `العواصم/` في المرحلة الثالثة.)

## ما يميز الصومال باختصار
- **أطول ساحل في القارة الإفريقية** (~3,333 كم على المحيط الهندي + خليج عدن).
- **القرن الإفريقي** — أقصى شرق أفريقيا + موقع استراتيجي (باب المندب + خليج عدن + ~12% من التجارة العالمية).
- **مهد سلطنات إسلامية:** عجوران (القرن 13–17) + عدال + مقديشو + هوبيو.
- **استعمار ثلاثي:** بريطاني (شمال غرب) + إيطالي (جنوب) + فرنسي (جيبوتي) — تقسيم برلين.
- **الاستقلال:** 1 يوليو 1960 (اتحاد الشطرين البريطاني + الإيطالي).
- **محمد سياد بري** (1969–1991) + الحرب الأهلية + انهيار الدولة.
- **أرض الصومال** (1991 — استقلال من جانب واحد — غير معترف بها — اعتراف إسرائيل 2025).
- **حركة الشباب** (2006–الآن) + اتحاد المحاكم الإسلامية + حرب على الحكومة.
- **نظام العشائر (4 قبائل):** در + دارود + هوية + إسحاق + رحنوين — نظام اجتماعي/سياسي قوي.
- **اللغة الصومالية** (كوشية) + لهجتان: محاتري (معياري) + ماي (جنوب) — + العربية (دين/ثقافة).
- **اقتصاد رعوي + تحويلات** — ثروة حيوانية ضخمة + اتصالات + زراعة + صيد.
- **حرب جارية + أزمة سياسية** (2024–2026 — تعديلات دستورية + الصراع).
