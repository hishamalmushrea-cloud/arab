# المطبخ الصومالي

> مطبخ صومالي يجمع التأثيرات العربية + الهندية + الإيطالية + الأفريقية + البدوية الصحراوية. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. نظرة عامة
- المطبخ الصومالي = **مزيج عربي (تجارة + إسلام) + هندي (بهارات) + إيطالي (باستا) + إفريقي + بدوي صحراوي**.
- يعتمد على: **الأرز + المعكرونة (الباستو)** + **اللحوم** (ماعز + ضأن + بقر + **جمل**) + **الأسماك** (ساحل) + **الموز** + **الخضار** + **البهارات** (الصومال منتج ومصدر للتوابل) + **حليب الإبل**.
- **حلال إسلامي:** لا خنزير + لا كحول + لا ميتة — الشعائر الدينية.
- **تقديم:** على الطراز العائلي (مشاركة على الطاولة) + الموز جنبًا.

## 2. الأطباق الرئيسية 🟢

### الكنترة/أنجيرو (Canjeero/Laxoox) — الخبز الوطني 🟢
- **خبز دائري رقيق مخمّر** (يشبه الإنجيرا الإثيوبية) — يُطهى على صاج/مقلاة دون زيت.
- **الفطور الرئيسي** + يُقدَّم مع اللحم/الكبدة/الحساء.
- جاف أو محلى بالسكر (حلوى).

### الباستو/المكرونة (Baasto) — إرث إيطالي 🟢
- **المعكرونة** (سباغيتي) — تُقدَّم مع مرق ثقيل (إيدام) + موز.
- تأثير الاستعمار الإيطالي.

### البرياني (Bariis) + بريس 🟢
- **أرز + لحم + توابل** (البرياني الصومالي الأصيل) — أشهر أطباق الأرز.
- **بريس اسكوكاليس:** أرز بسمتي + طماطم + بصل + قرفة + قرنفل + هيل + كمون + خضار (لمسات صومالية).
- يُقدَّم في كل الأوقات.

### السمبوسة/السمبوسك (Sambusa) — الإرث الهندي/العربي 🟢
- **فطيرة مثلثية مقلية** محشوة بـ: اللحم المفروم + الخضار + العدس + البصل + البهارات.
- **أكلة الإفطار الرئيسية في رمضان** + رمز الضيافة + شعبية جدًّا.
- تأثر هندي/عربي/مصري.

### الموفو (Muufo) — خبز 🟡
- **خبز دائري خفيف إسفنجي** (يشبه البراتا الهندي) — يُقدَّم مع الصلصات.
- **البسباس (Bisbaas):** صلصة حارة + فلفل + بصل + ثوم + جوز الهند.

### إيدام/مارق (Maraq) — المرق 🟢
- **مرق لحم/دجاج/خضار** + بهارات — يُقدَّم مع الأرز + الباستو + الموفو.

### سوقار (Suqaar) — اللحم المشوي/المقلي 🟢
- **لحم دجاج/بقر مقلّى + خضار + فلفل + بصل + بهارات صومالية** — تذبيلة.

### المحشي (MukBaad) 🟡
- **سمك هامور محشو** بالأرز + التوابل + يُطهى في الفرن/على النار — بحري.
- **مطابق:** مطبق الهامور.

### كبدة الجمل + الكبدة 🟢
- **كبدة الجمل:** كبد + سنام الجمل + زيت + بصل + بطاطا + فلفل — أراضي الصومال.
- يُقدَّم مع خبز (اللحوح/أنجيرو).

---

## 3. الأطباق الأخرى 🟢
- **العانبولو (Caambuulo):** حبوب فاصوليا + زبد + طماطم — مع الشاي/القهوة.
- **العنجيلو (Canjeelo):** شطيرة صومالية لذيذة — مع الكبد/اللحم.
- **الكامبولو:** حبوب + زبد + سكر — حلوى.
- **الجاشاتو:** معجنات من جوز الهند — حلوى.
- **قرع العسل:** قرع محلى بالعسل — رمضان.
- **باجيو (Bajiyo):** فطائر العدس المقلية — رمضان + مع الشاي.
- **نفقة (Nafaq):** مقبلات مقلية (بطاطس + بيض + خبز).
- **موز بالحليب والفراولة:** حلوى.
- **الكاك كاك/الدونات الصومالية:** معجنات مقلية — بعد الإفطار.

---

## 4. المشروبات 🟢
- **الشاي الصومالي (شاي عديس):** شاي + حليب + هيل + قرفة + زنجبيل — **المشروب الوطني** + طقس اجتماعي يومي.
- **حليب الإبل (النوق):** «سيد المائدة» في رمضان — مقاومة العطش + حرق الدهون + الحموضة.
- **اللبن + اللبن المخيض.**
- **عصير فروتلاتو:** مزيج فواكه (مانجو + باباي + موز) — رمضان.
- **التمر الهندي (عرديب):** حلو/لاذع.
- **الكركديه (البيسام):** حامض.
- **القهوة الصومالية:** قهوة + هيل + زنجبيل.

---

## 5. الأطعمة والمناسبات 🟢
- **رمضان:** السمبوسة + الكنترة + الحساء + التمر + حليب الإبل + الموفو + الباستو + الكاك كاك.
- **الأعراس:** البرياني + اللحم المشوي + الموز + الشاي.
- **العيد:** اللحم المشوي + الأرز + الكنترة + الحلوى (العانبولو + الجاشاتو).
- **الضيافة:** السمبوسة + الشاي (كرم).

---

## 6. ربط الطعام بالجغرافيا والثقافة
- **الساحل + المحيط الهندي + خليج عدن** → الأسماك + المحشي + الصيد + مدن ساحلية (مقديشو + مركة + برعا) + تجارة مع الهند/الجزيرة العربية/إيطاليا. 🟢
- **السهول + السافانا + البدو** → اللحوم (الماعز + الضأن + **الجمل**) + حليب الإبل + المكاوييس + الكنترة (خبز سريع) + المشوي + التكيف مع الجفاف + الموز + الذرة. 🟢
- **التأثير الهندي** (تجارة المحيط الهندي) → البهارات + السمبوسة + الكنترة (canjeero) + الكركم + الكزبرة + الهيل + القرفة + الموفو (براتا).
- **التأثير الإيطالي** (الاستعمار) → الباستو (المعكرونة) + الصلصات + أسماء مدن (بنادر).
- **التأثير العربي/الإسلامي** (تجارة + الدين) → الحلال + لا خنزير/كحول + العربية + الأنساب + الصوفية + حليب الإبل في رمضان.
- **أنهار شبيلي/جوبا** (جنوب) → الزراعة (الموز + السمسم + قصب السكر + الذرة) + الماي (لهجة — رحنوين) + الصاب.
- **الموقع المعبري** (إثيوبيا/كينيا/اليمن/جيبوتي) → تجارة + تأثيرات متبادلة + المغتربون (تحويلات) + المطبخ متعدد الأصول.
