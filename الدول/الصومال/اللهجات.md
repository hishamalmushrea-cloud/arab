# اللهجات في الجمهورية الفيدرالية الصومالية

> اللغة الصومالية (كوشية) + العربية + تأثيرات. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. نظرة عامة
- اللغة الرسمية: **الصومالية** (الأولى) + **العربية** (الثانية دستوريًّا). 🟢
- **الدين:** الإسلام ~99% → العربية لغة الدين + الثقافة + القرآن.
- **اللغة الصومالية:** من الأسرة الكوشية (فرع الأفروآسيوية/السامية الحامية) — كوشية شرقية.
- **التأثيرات:** العربية + الفارسية + الإيطالية + الإنجليزية + الهندية.

## 2. اللهجات الرئيسية 🟢🟡

### أ. لهجة المحاتري (Maxaa Maxaa / Mahaadiri) — الشمال + الوسط
- **اللهجة الشمالية-الوسطى** = أساس اللغة الصومالية المعيارية (الرسمية).
- يتحدث بها معظم الصوماليين (شمال + وسط).
- خصائص: نطق «الجيم» (g) مصرية + «القاف» (q) + اللواحق (ma = هل).
- تُستخدم في التعليم + الإعلام + الإدارة.
- 🟢 *حقيقة موثقة*

### ب. لهجة الماي (Maay Maay / Af-Maay) — الجنوب
- **لهجة مستقلة** (لا لهجة من المحاتري) وفق بعض اللغويين (فوزي محمد بارو + آدم معلم محمد حسن).
- يتحدث بها **قبائل الدجل وميرفلي** (رحنوين) في جنوب الصومال + ضفاف النهرين (جوبا + شبيلي) + إثيوبيا + كينيا.
- **خصائص مختلفة جذريًّا** عن المحاتري:
  - صعوبة التفاهم بين متحدثي الماي والمحاتري رغم التجاور.
  - اللواحق للنفي/الاستفهام مختلفة (ma = هل/ألم فقط + لا تُستخدم كـ«هل» + y/a/e حسب الجملة).
  - أصوات غير موجودة في المحاتري (j/χ/ʃ).
  - بنية الجملة: فاعل-فعل-مفعول (SVO) + فاعل-مفعول-فعل (SOV).
  - لغة إلصاقية بدرجة كبيرة + نظام صرفي معقد للأفعال.
- **دستور 2012:** يعتبر اللغة الصومالية في لهجتيها الماي + المحاتري لغات رسمية + باقي الأنماط لهجات محلية. 🟢
- 🟡 *خلاف أكاديمي*: الماي لهغة مستقلة أم لهجة من المحاتري (الرأي الراجح: لغة مستقلة من ضمن اللغات الصومالية).
- لهجة بنيادر (بنادر) + لهجة بكية: شبيهة بالماي.

## 3. التأثيرات اللغوية الخارجية 🟢

### العربية (الإسلام)
- مفردات دينية + ثقافية + قرآنية: «سلام» + «صلاة» + «قرآن» + «رمضان» + «زكاة» + «حج» + «كعبة» + «محراب» + «شيخ» + «ملا» + «أمير» + «سطنة».
- أنساب القبائل (دارود + إسحاق) إلى رجال دين عرب (أرواية شفهية — جدل علمي).

### الفارسية
- مفردات: «إمام» + «ملا» + «خان» + «بازار» + «قرضة» (من التجارة الفارسية في الساحل).

### الإنجليزية (الاستعمار البريطاني)
- مفردات إدارية + تقنية + اقتصادية: «بنك» + «ميناء» + «كومبيوتر» + «تليفون» + «راديو» + «تليفزيون» + «بوليس» + «محكمة».

### الإيطالية (الاستعمار الإيطالي)
- مفردات: «مكرونة/باستو» (pasta) + «صلصة» + «بيتزا» (تأثير المطبخ) + «ماكينة» + «بنزين» + «سيارة».
- أسماء مدن: «بنادر» (Banaadir — من الإيطالية) + «مقديشو» (Muqdisho).

### الهندية (تجارة المحيط الهندي)
- مفردات: «بهارات» + «كمون» + «كزبرة» + «هيل» + «قرفة» + «كركم» + «أرز بسمتي» + «سمبوسة/سمبوسك» (samusa) + «كنترة/أنجيرو» (canjeero) + «بهارات».
- أسماء: «مانجو» (cambo) + «باباي» + «ليمن» (liin).

## 5. الأمثال والتعبيرات 🟡
- «Nin walbaa waa kan» (كل إناء ينضح بما فيه) — مثل.
- «Mar waa kan» (الرجل بمكان).
- «Abtirsi» (إحصاء الآباء — النسب الأبوي) — نظام العشائر.
- «Tol» (قبيلة) + «Qolo» (عشيرة) + «Reer» (عائلة) — وحدات القرابة.

## 6. الكتابة 🟢
- **قبل 1972:** كتابة عربية (للأدب + الدين) — لم تكن رسمية.
- **1920–1972:** أنظمة كتابة متعددة (الشيخ عبد الله يوسف + عثمان يوسف + كناد يوسف + محمود حاجي يوسف) — عربية معدَّلة.
- **1972 (أكتوبر):** سياد بري يُعلن الكتابة اللاتينية الرسمية للصومالية — قرار ثوري.
- **1976:** إقرار الكتابة اللاتينية نهائيًّا.
- اليوم: تُكتب الصومالية باللاتينية في الصومال (بعض الماي يُكتب باللاتينية في السنغال/كينيا).

---

## 7. الموسيقى + الفنون 🟢
- **الشعر الصومالي (الغنائي + البطوش):** فن شفهي عريق (القصيد + الإلقا).
- **الموسيقى الصومالية:** تقليدي + حديثة — الطبل + الناي + العود.
- **الرقصات:** البوبلي + دب شيد (إضاءة النار — استقلال) + بنتلاند.
- مطربون: مريام ميرسو + قمارديد حاجي أحمد + سعد علي شيري + محمد سليمان طراب.

## 8. ربط اللهجة بالثقافة والجغرافيا
- **القرن الإفريقي + ساحل 3,333 كم** → ثقافة بحرية + تجارة + تأثير عربي/هندي/فارسي (لهجة + مفردات) + الإسلام (العربية لغة الدين). 🟢
- **السهول + السافانا** → حياة رعوية بدوية (الصوماليون = رعاة) + الإبل + نظام 4 قبائل + المحاتري (اللهجة الشمالية-الوسطى).
- **الجنوب** (أنهار جوبا/شبيلي) → الزراعة (الصاب) + الماي (لهجة مستقلة — رحنوين) + الموز + السمسم.
- **التأثير الإيطالي/البريطاني** (الاستعمار) → مفردات إدارية + تقنية + الكتابة اللاتينية (قرار سياد بري 1972).
- **الإسلام + العرب** (القرن 7) → العربية (لغة الدين + الثقافة) + الأنساب العربية (دارود + إسحاق — روايات) + الصوفية (قادرية + أحمدي).
- **الموقع الاستراتيجي** (باب المندب + خليج عدن) → هجومات القوافل + تجارة + تأثيرات متبادلة + المغتربون (تحويلات).
- **الانقسام الجغرافي** (شمال × جنوب — استعمار بريطاني × إيطالي) → تباين لهجي (المحاتري شمالًا + الماي جنوبًا) + بذور الانفصال (أرض الصومال — الماي).
