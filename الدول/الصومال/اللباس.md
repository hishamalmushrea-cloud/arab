# اللباس في الجمهورية الفيدرالية الصومالية

> لباس صومالي تقليدي محتشم متكيِّف مع الحر + الإسلام + البدو. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف.

---

## 1. نظرة عامة
- اللباس التقليدي = **محتشم + خفيف + مكيِّف مع الحر** (ألوان فاتحة + أقمشة خفيفة) + **الإسلام** (حشمة).
- زي قومي موحِّد عبر القبائل + مناطق.
- **الباس الحديث** منتشر في المدن (أروبي + خليجي).

---

## 2. اللباس الرجالي 🟢

### المكاوييس (Macawiis / Ma'awiis) — الزي القومي الرجالي 🟢
- **وشاح/ثوب طويل** (يشبه السارونغ) يُلَف حول الخصر + ألوان متعددة + أقمشة قطنية خفيفة.
- متكيِّف مع الحر + البدو + الرعي — مريح.
- يُرتدى مع قميص خفيف + أحيانًا وشاح على الكتف (حماية من الشمس/الريح).

### الثوب/الخميص (Khamiis / Thawb) — إرث عربي 🟢
- **ثوب طويل أبيض** إلى الكاحل (يشبه الثوب الخليجي) — زي رسمي/ديني.
- يُرتدى في المناسبات (الأعراس + الجنائز + العيد + الجمعة).
- تأثير الثقافة العربية + الإسلام.

### الكوفية/الطاقية (Koofiyad) — رأس 🟢
- **طاقية صغيرة مطرَّزة** (taqiyah) — تغطي الرأس + رمز اجتماعي/ديني.
- أحيانًا **عمامة/ turbans** ملوَّنة — رمز مكانة/احترام.

### البشت (Bisht) — إرث عربي 🟡
- **رداء خارجي فاخر** — يُرتدى في المناسبات الرسمية + الزفاف — رمز مكانة.
- تأثير عربي خليجي.

### الإكسسوارات
- **السيف/الحربة:** في المناسبات (إرث بدوي).
- **العكاز:** رمز الهيبة.
- **السبحة:** للزوايا/الشيوخ (إرث صوفي).

---

## 3. اللباس النسائي 🟢

### الديراك (Dirac) — الزي القومي النسائي 🟢
- **فستان طويل خفيف شفاف** من قماش ملوَّن + مطرَّز + لمعان.
- **ألوان نابضة بالحياة** + أنماط + مطبوعات.
- يُرتدى في **المناسبات** (الأعراس + العيد + الاستقلال) + رمز الأناقة + النعمة + الأنوثة.
- تختلف التصاميم بين المناطق (شكل A شمال + مستطيل وسط + فضفاض جنوب).

### الغارباسار (Garbasaar) — التنورة الداخلية 🟢
- **فستان طويل متدفق غير شفاف** (تحت الديراك) — الطبقة الأساسية.
- يُنسَّق مع الديراك + أحيانًا خالص أو نمط أساسي.
- رمز الفخر الثقافي + الهوية.

### القورقوراد (Gorgorad) — التنورة الحريرية 🟡
- **تنورة حرير** (petticoat) تحت الديراك — أناقة + راحة.
- في أحيان أخرى.

### الشال/الشيلة/الحجاب 🟢
- **شال** على الكتف/الرأس — حشمة + إسلام.
- **الحجاب:** رمز ديني + حشمة (تأثير إسلامي).

### الباتي (Baati) — اللباس اليومي 🟡
- **فستان طويل مريح من بوليستر** — يُرتدى يوميًا في المدن + البيوت.

### الإكسسوارات النسائية 🟢
- **الذهب:** قلائد + خلخال + أساور + خواتم — رمز الرخاء + السعادة (الأعراس).
- **الحناء:** في الأعراس + الموالد.
- **الكحل:** للعين (تجميل).

---

## 4. اللباس الحديث 🟢
- **اللباس الأروبي** (القمصان + البناطيل + الفساتين) — منتشر في المدن + الأعمال + الشباب.
- **الديراك + الغارباسار + المكاوييس** تبقى للجمعة + المناسبات + الأعراس + العيد.
- **الحجاب + النقاب:** انتشار حديث (نساء محافظات — تأثير إسلامي/خليجي).
- مصممات صوماليات يبتكرن تصاميم حديثة للديراك + الغارباسار (أقمشة جديدة + لمسات + حجاب أنيق مع الحفاظ على الجذور).

---

## 5. اللباس حسب المناطق 🟡
- **شمال (أرض الصومال):** المكاوييس + الديراك بأشكال مستطيلة + حرير.
- **وسط (مقديشو):** الديراك بأشكال مثلثة + صور ظلية + شعبية.
- **جنوب:** الديراك فضفاض + ألوان زاهية + مطرَّز (شبيلي + جوبا + باكول).
- **شمال شرق (أرض البنط):** المكاوييس + الديراك + تأثير عربي.

---

## 6. ربط اللباس بالجغرافيا والثقافة
- **الحر الشديد + الجفاف + الشمس** → المكاوييس (خفيف + قطني + تهوية) + الديراك (خفيف + فضفاض) + الكوفية (حماية الرأس) + ألوان فاتحة. 🟢
- **الإسلام + المحتشام** → الثوب/الخميص (أبيض + حشمة) + الحجاب + الشال + الكوفية + الكحل + الحناء.
- **البدو + الرعي + الصحراء** → المكاوييس (سارونغ — عملي للتنقل) + السيف + النعل + الثوب في المناسبات.
- **الموقع الجسري** (إثيوبيا/كينيا/اليمن/الجزيرة العربية) → الثوب/الخميص (إرث عربي) + الديراك/الغارباسار (تأثير هندي/صومالي) + الباتي (يومي) + البشت (عربي خليجي).
- **التجارة التاريخية** (المحيط الهندي + الساحل) → استيراد الحرير + الشيفون + الأقمشة المطبوعة من الهند + الصين + الجزيرة العربية + إيطاليا + فرنسا.
- **الكرم + الضيافة** → الديراك المزخرف الملوَّن (للمناسبات) + الذهب (إظهار للكرم + السعادة).
- **الانقسام الجغرافي** (شمال × جنوب) → تمايز طفيف في أشكال الديراك + المكاوييس (أرض الصومال شمال × شبيلي/جوبا جنوب).
