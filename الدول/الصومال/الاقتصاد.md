# اقتصاد الجمهورية الفيدرالية الصومالية

> اقتصاد رعوي + تحويلات + اتصالات + ضعيف بسبب الحرب. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر.

---

## 1. نظرة عامة 🟠

| المؤشر | القيمة | السنة | الثقة |
|---|---|---|---|
| الناتج المحلي | ~10–17 مليار $ (تقديري — تباين) | 2020–2025 | 🟡 |
| نصيب الفرد | ~$400–900 | تقديري | 🟡 |
| السكان | ~18 مليون (2025) | 2025 | 🟡 |
| نمو الناتج | ضعيف (تذبذب — حرب) | 2020–2025 | 🟠 |

| البطالة | ~40–50% | تقديري | 🟡 |

> 🟠 **تنبيه:** اقتصاد ضعيف + غير رسمي كبير + حرب + فساد + اعتماد على المعونات + التحويلات. الأرقام تقديرية ومتغيرة.

---

## 2. الثروة الحيوانية — أكبر مصدر صادر رسمي 🟢
- **الإبل + الماعز + الضأن + الأبقار** — ثروة ضخمة (رعاة بدو + ساحل + وسط).
- **تصدير الحياة:** للسعودية + الإمارات + مصر + اليمن + عمان — عبر موانئ بربرة + بوصاصو.
- **الجلود + اللحوم + منتجات الألبان** — تصدير.
- **«الميرغ» (Muruq):** سوق حياة/لحوم — سوق تقليدي.
- 🟢 **أكبر مصدر صادر رسمي** للصومال.

---

## 3. التحويلات — أكبر مصدر نقد أجنبي 🟢
- **التحويلات من المغتربين الصوماليين** (~20–30% من الناتج) — من كبرى التحويلات عالميًّا.
- الجالية الصومالية: في أوروبا (بريطانيا + السويد + إيطاليا) + الخليج (السعودية + الإمارات) + أمريكا الشمالية + أفريقيا (كينيا + جنوب إفريقيا).
- تموّل الصادرات + الواردات + الاستهلاك + الاستثمار (غير رسمي).

---

## 4. الاتصالات — قطاع رائد 🟢
- **Hormuud Telecom** + **Telcom** + **Somtel** + **Liban** — شركات صومالية رائدة.
- **النتقال:** أعلى نسبة امتلاك في أفريقيا — قطاع تنافسي.
- **البث:** التلفزيون + الإذاعة + الإنترنت — نمو سريع.
- «الدفع عبر النقال» (EVC Plus) — خدمات مالية.

---

## 5. الزراعة + الصيد 🟢🟠
- **الأنهار شبيلي + جوبا** — مروية موسمية + فيضانات.
- **المحاصيل:** الموز + الذرة + السمسم + قصب السكر + السورغم + الحبوب + الفواكه (مانجو + غافا + ليمون) + الأناناس.
- **الموز:** رمز صومالي (يُقدَّم مع كل وجبة) + تجارة.
- **الصيد:** ساحل غني بالأسماك (تونة + أسماك هندية + أسماك المحيط) — تصدير + أمن غذائي.
- 🟠 الزراعة محدودة (جفاف + حرب) — تستورد الصومال معظم غذائها.

---

## 6. التعدين + الطاقة 🟡
- **الذهب:** مكتشفات (بعالية — لم تُستغل).
- **الجبس + الملح + اليورانيوم + الفوسفات** (محدودة).
- **النفط + الغاز:** مكتشفات قبالة الساحل (لم تُستغل — بعالية).
- **الطاقة المتجددة:** شمس + ريح (محدودة) + طاقة كهربائية ضعيفة.

---

## 7. التجارة الخارجية 🟢🟠
- **الصادرات:** الحياة + اللحوم + الجلود + الموز + السمسم + الأسماك + البهارات + الفحم.
- **الواردات:** الآلات + المعدات + النفط ومشتقاته + المواد الاستهلاكية + القمح + الأدوية + السيارات.
- **الشركاء:** الصين + الإمارات + السعودية + كينيا + إثيوبيا + الهند + باكستان + الاتحاد الأوروبي.
- 🟠 **عجز تجاري** + اعتماد على التحويلات + المعونات + اقتصاد غير رسمي + تهريب.

---

## 8. السياحة والآثار 🟢🟠
- **آثار:** مقديشو التاريخية + هرجيسا + مركة + برعا + هوبيو + مساجد + قلاع.
- **سياحة ساحلية:** شواطئ + غوص + صيد (مقديشو + كيسمايو + بربرة + مركة).
- **سياحة صحراوية:** كثبان + رالي (تاريخي — توقف).
- 🟠 الحرب + الشباب + الفساد + غياب الأمن → توقفت السياحة.

---

## 9. التحديات الاقتصادية 🟠
- **الحرب الأهلية + الشباب** (2006–الآن) → تدمير البنية التحتية + فراغ السلطة + نهب.
- **الفساد + غياب الحوكمة + البطالة (~40–50%) + الفقر + المجاعة** في مناطق.
- **الاقتصاد غير الرسمي** (تهريب + تجارة المليشيات + القرصنة + الفاحشة).
- **انهيار العملة** (الشلن — انخفاض قيمة + مزج).
- **الدين العام + العجز المالي** + اعتماد على المعونات (الأمم المتحدة + الاتحاد الأفريقي + السعودية).
- **غياب البنوك الرسمية** + القطاع المالي ضعيف.
- **غياب إحصاءات رسمية** + اقتصاد مبهم.

---

## 10. ربط الاقتصاد بالجغرافيا
- **الساحل + المحيط الهندي + خليج عدن** → الصيد + تجارة + موانئ (مقديشو + كيسمايو + بربرة) + تصدير الحياة. 🟢
- **السهول + السافانا + البدو** → الثروة الحيوانية (الإبل + الماعز + الضأن) — أكبر صادر رسمي + تصدير حياة للخليج/مصر/اليمن.
- **أنهار شبيلي + جوبا** (وسط + جنوب) → الزراعة (الموز + السمسم + قصب السكر + الذرة + الأناناس) — مروية موسمية.
- **الموقع الاستراتيجي** (باب المندب + خليج عدن — ~12% من التجارة العالمية) → ملاذ للقرصنة + تجارة + قواعد عسكرية أجنبية.
- **المغتربون الصوماليون** (أوروبا + الخليج + أمريكا) → التحويلات (أكبر مصدر نقد أجنبي — ~20–30% من الناتج).
- **الجفاف + المناخ القاسي + الحرب** → اقتصاد رعوي + ضعيف + اعتماد على الغير + ثروات غير مستغلة (نفط + ذهب).
- **غياب الدولة المركزية (1991–2004 + حرب)** → اقتصاد غير رسمي + تهريب + مليشيات + فراغ سلطة.
- **الإصلاحات بعد 2004** (الحكومة الفيدرالية + دستور 2012) → إعادة بناء بطيئة + اتصالات رائدة + قطاع خاص + تحويلات. 🟠
