# الولايات الاتحادية — طبقة سياسية فوق الغوبول

> هذه **ليست** بديلًا عن الـ18 غوبول. الدستور المؤقت 2012 يقرّ دولة اتحادية، وعدد الولايات وحدودها **غير مغلَق** في نص نافذ واحد. 🟠
>
> المرجع الجغرافي والإحصائي يبقى [`../المناطق/`](../المناطق/README.md) + ISO 3166-2:SO + PESS 2014.
>
> وزارة التخطيط الاتحادية (mop.gov.so، مراجعة 2026) تسرد **7** كيانات + إدارة بنادر. مصادر أخرى تحصي **5** ولايات فاعلة داخل الاتحاد وتُخرج أرض الصومال. لا يُختار رقم واحد كحقيقة مغلقة. 🟡

## أخطاء شائعة في بطاقة الدولة السابقة

| الخطأ | التصحيح |
|---|---|
| جوبالاند تضم شبيلي السفلى | شبيلي السفلى في **جنوب غرب** |
| غلمدغ تضم جدو وهيران ونوجال | غلمدغ = جلجدود + جنوب مدج فقط |
| هيرشابيلي تضم شبيلي السفلى | هيرشابيلي = هيران + شبيلي الوسطى |
| جنوب غرب تضم بنادر وعاصمتها براوة | بنادر مستقلة؛ العاصمة **بيدوا** |
| بونتلاند تضم باكول | باكول في جنوب غرب |
| إحداثيات جوهر 4.47° / 26.15° | جوهر ≈ **2.78°ش / 45.50°ق** |

## ما لا يُفعل هنا

- لا يُجمع سكان PESS 2014 على مستوى الولاية: مدج وسول وسناق لا تقبل الجمع دون اختلاق نسبة السيطرة.
- لا تُعامل أقاليم أرض الصومال الداخلية (ساحل، مرودي جيح، هايسيما…) كغوبول ISO.
- لا تُعامل أقاليم بونتلاند الداخلية (كركار، غردافول، هيلان…) كغوبول ISO.
- أوغادين ليست ولاية صومالية.
