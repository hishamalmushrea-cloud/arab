# جغرافيا الجمهورية الفيدرالية الصومالية

> علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر.

---

## 1. الموقع والمساحة
- **الموقع:** القرن الإفريقي — أقصى شرق أفريقيا — على المحيط الهندي + خليج عدن.
- **الإحداثيات:** 2°S–12°N ، 41°–52°E.
- **المساحة:** **637,657 كم²** (رقم 46 عالميًّا — رقم 20 أفريقيًّا — أصغر من مصر بقليل). 🟢
- **ميزة فريدة:** **أطول ساحل في القارة الإفريقية** (~3,333 كم على المحيط الهندي + خليج عدن).

## 2. التضاريس
- عمومًا: **سهول ساحلية + هضاب شمالية + سهول + أودية** — تضاريس منخفضة مع هضاب.
- **الشمال:** هضاب + جبال (شمبريس 2,408 م — شمال + سورود — شمال شرق).
- **الوسط:** سهول + أودية + هضاب منخفضة.
- **الجنوب:** سهول + سافانا + أودية.
- **أعلى نقطة:** **شمبريس (Shimbiris — 2,408 م)** في جبال شمال. 🟢
- **أنخفض نقطة:** المحيط الهندي (مستوى البحر).
- لا براكين + أنهار دائمة قليلة (كلها موسمية).

## 3. الأنهار
- **نهر شبيلي (Shabelle):** الأنهر + الأطول — يبدأ من هضاب إثيوبيا → يجري نحو الجنوب الشرقي → يصب في المحيط قرب مركة — الأنهر (790 كم + الأطول 580 كم) = ~1,370 كم.
- **نهر جوبا (Juba):** يبدأ من حدود إثيوبيا/كينيا → يجري جنوبًا → يصب في المحيط قرب كيسمايو — ~1,658 كم + رافد داوا.
- مروية موسمية + فيضانات (غي/هرگاي).
- **أودية أخرى:** نوجال + مدج + هيران + جلجدود.

## 4. المناخ 🟢
- **تصنيف كوبن:** **BSh** (شبه جاف استوائي) + **BWh** (صحراوي حار) في الشمال.
- **المواسم:**
  - **غي (Gu):** الموسم المطري الرئيسي (أبريل–يونيو).
  - **هرگاي (Hagaa):** الموسم الجاف (يونيو–سبتمبر).
  - **دير (Deyr):** الموسم المطري الثانوي (سبتمبر–ديسمبر).
  - **جيلال (Jilaal):** الموسم الجاف الشتوي (ديسمبر–مارس).
  - **تانغمبيلي (Tangambili):** فترات حارة رطبة بين المواسم.
- **الأمطار:** ~150–600 مم (شمال) → ~600 مم (جنوب) — موسمية.
- **الحرارة:** ~25–40°م (شمال أبرد) → ~35–45°م (جنوب حار).
- **الرياح:** موسمية (شمال شرق + جنوب غرب).

## 5. الموارد المائية
- **أنهار شبيلي + جوبا** = المصدر الرئيسي للمياه + الزراعة (مروية موسمية).
- **مياه جوفية** محدودة + آبار.
- **تحلية** محدودة (مقديشو + هرجيسا + كيسمايو).
- لا بحيرات طبيعية كبيرة.

## 6. التربة والغطاء النباتي
- **التربة:** رملية + حصوية (شمال) + طينية (وادي الأنهار) + لترية (ساحل).
- **الغطاء:** صحراوي (شيح + عوسج + رتم) شمال + سافانا (أعشاب + سنط) وسط + غابات استوائية (جنوب — أنهار).
- **غابات:** محدودة (جوبا + شبيلي) — تدهور.

## 7. الموارد الطبيعية
- **الثروة الحيوانية:** الإبل + الماعز + الضأن + الأبقار — **أكبر مصدر صادر رسمي** (تصدير حياة للسعودية/الإمارات/مصر/اليمن).
- **الزراعة:** الموز + الذرة + السمسم + قصب السكر + السورغم + الحبوب + الفواكه (مانجو + غافا + ليمون) — أنهار شبيلي/جوبا.
- **الصيد:** ساحل غني بالأسماك (تنواذيبو + هرجيسا + مركة + كيسمايو) — تونة + أسماك هندية + أسماك المحيط.
- **المعادن:** الذهب + الجبس + الملح + اليورانيوم (محدودة) + الغاز (مكتشفات قبالة الساحل).
- **النفط:** مكتشفات (بعالية — لم تُستغل).
- **الطاقة:** شمس + ريح (محدودة) + طاقة كهربائية ضعيفة.

## 8. المناطق الطبيعية والمحميات
- **ساحل المحيط الهندي** (3,333 كم — شواطئ + شعاب مرجانية + أسماك).
- **جبال شمبريس + سورود** (شمال + شمال شرق).
- **أنهار شبيلي + جوبا** (وسط + جنوب).
- **محميات:** محمية بولامو + محمية لاسعانود + محمية كزموم.
- **صحراء شمال** + **سافانا جنوب**.

## 9. النقل والربط
- **الموانئ:** مقديشو (العاصمة) + كيسمايو (جوبالاند) + بربرة (أرض الصومال) + بوصاصو + مركة + أوبا.
- **المطارات:** مقديشو – الدولي (أدن أدي) + هرجيسا + غاروي + كيسمايو.
- **الطرق:** ضعيفة الصيانة + مقديشو–أفجوي + مقديشو–بيدوا + هرجيسا–برعو.
- **النقل الجوي:** مقديشو – أفجوي – كيسمايو (طرق داخلية).
- 🟠 البنية التحتية متدهورة + النقل محدود بسبب الحرب.

## 10. ربط الجغرافيا بالثقافة (رؤية تطبيقية)
- **القرن الإفريقي + ساحل 3,333 كم** → ثقافة بحرية + صيد + تجارة + مدن ساحلية (مقديشو + مركة + برعا + هوبيو) + الإسلام عبر البحر. 🟢
- **السهول + السافانا + الأودية** (وسط + جنوب) → حياة رعوية بدوية (نظام 4 قبائل) + الإبل + الماعز + الموز + الزراعة (الصاب).
- **الهضاب + الجبال** (شمال) → رعاة نبيلون (سمالي) + مناخ أبرد + استيطان في المرتفعات.
- **الجفاف + المناخ القاسي** → التكيف مع البيئة + حليب الإبل (مقاومة العطش) + المشوي + الكنترة (خبز سريع) + المكاوييس (ثوب خفيف).
- **الموقع الاستراتيجي** (باب المندب + خليج عدن) → تجارة عابرة + قرب اليمن + إثيوبيا + كينيا + جيبوتي — هجومات القوافل التاريخية.
- **الجغرافيا المنقسمة** (شمال غرب بريطاني × جنوب إيطالي تاريخيًّا) → بذور الانفصال (أرض الصومال) + النظام العشائري القوي.
