# المجتمع والقبائل والطوائف في الجمهورية الفيدرالية الصومالية

> تركيبة عرقية لغوية متجانسة (الصوماليون ~99%) لكن منقسمة على 5 قبائل كبرى + نظام عشائري قوي. علامات الثقة: 🟢 موثَّق / 🟡 اختلاف / 🟠 حذر.

---

## 1. السكان — الأرقام 🟡
- **السكان:** ~18 مليون (2025 تقديري — تباين 12.3–18 مليون).
- **الكثافة:** ~28 نسمة/كم² (منخفض — رعاة بدو + ساحل).
- **التوزيع:** ~51% حضر + 26% رعاة بدو + 23% ريف.
- **معدل النمو:** ~2.9% سنويًّا (تقديري — مرتفع).
- **متوسط العمر:** ~57 سنة (منخفض — حرب + مجاعة + صحة ضعيفة).
- 🟡 لا إحصاء رسمي دقيق منذ 1980ات (آخر إحصاء شامل 1975 — 3.5 مليون).

---

## 2. الشعب الصومالي — عنصر واحد متعدد القبائل 🟢🟡

### الأصول
- **الصوماليون:** مجموعة عرقية مسلمة موطنها القرن الإفريقي — أغلبية كوشية (حامية) + تأثير عربي.
- **نسبة الصوماليين:** ~99% من السكان (متجانس عرقيًّا — لا أقليات كبيرة).
- **الدين:** الإسلام ~99% — سُنة + شافعية + صوفية.
- 🟡 *رواية شفهية*: نسب القبائل الكبرى إلى رجال دين عرب (دارود + إسحاق) — جدل علمي (الدراسات الجينية لا تُظهر سلفًا عربيًّا ملحوظًا).

### القبائل الـ5 الكبرى (النظام 4 قبائل) 🟢
1. **در (Dir):** من سمالي (أبو بكر) — شمال + أصل «صومالي» — رعاة نبيلون.
2. **دارود (Darod):** من عبد الرحمن بن إسماعيل الجبرتي (عقيل بن أبي طالب — رواية) — أكبر قبيلة — جنوب + وسط + شمال شرق.
3. **هوية (Hawiye):** من أحمد بن عبد الرحمن بن عثمان — وسط + مقديشو (أكبر قبيلة بالعاصمة).
4. **إسحاق (Isaaq):** من الشيخ إسحاق بن أحمد (هاشمي — رواية) — شمال غرب (أرض الصومال).
5. **رحنوين (Rahanweyn):** ساب (زراعة) — دجل + ميرفلي — جنوب (لهجة الماي).

### الطبقات (النظام 4 قبائل) 🟢🟠
- **سمالي (الصوماليون):** رعاة نبيلون (در + دارود + هوية + إسحاق) — الأصل.
- **صاب (الزرّاعون):** رحنوين (دجل + ميرفلي) + بانتو — الزراعة.
- **المدجان (المهن):** الصيد + الختان.
- **تومال (الحرف):** الحدادة + الجلود.
- **يبر (الفنون):** الدباغة + السحر.

> 🟠 **العصبية القبلية** = عقبة أمام بناء الدولة + «المحاصصة القبلية» في البرلمان (4.5 لكل قبيلة) + الحرب الأهلية (1991).

---

## 3. الأقليات العرقية 🟡
- **البانتو (جنوب):** من زنجبار/موزمبيق — زراعة + فنون — أقلية.
- **العرب (ساحل):** تجار + صيادون + شيوخ — أقلية.
- **البنادر (مقديشو):** خليط مدني من مختلف القبائل — أكبر منطقة سكانًا.
- **الإثيوبيون/الأورومو:** في الحدود (أوغادين + هرر).

---

## 4. الأديان والمذاهب 🟢
- **الإسلام ~99%** (دين الدولة + الهوية):
  - **سُنة + شافعية** (غالبية).
  - **الصوفية:** قادرية (الأكثر انتشارًا) + أحمدي (الأشراف) + صالحية + رفاعية + سمانية.
  - **الوهابية/السلفية:** انتشار محدود (تأثير خليجي).
- **المسيحية:** ~0.2–1% (بعالية + كاثوليك) — بانتو + المدن.
- **المعتقدات الإفريقية:** محدودة (البانتو + بعيدة).

---

## 5. العائلات والزعامات 🟢
- **الصوماليون** (موحَّدون عرقيًّا) — نظام «أبتيرسي» (النسب الأبوي).
- **الزعامات القبلية:** السطان (شيخ العشيرة) + النظار + القاضي.
- **«المهر» (مهار):** المهور — تقالي الزواج.
- **الزعامات السياسية:** رؤساء القبائل + زعامات الأحزاب.

---

## 6. السياسة والمشاركة 🟠
- نظام: **جمهورية فيدرالية برلمانية** (دستور مؤقت 2012).
- **الرئاسة:** حسن شيخ محمود (2022–الآن — أُعيد 2022).
- **البرلمان:** برلمان فيدرالي (مجلس الشعب 275 + مجلس الشيوخ 54) + «المحاصصة القبلية» (4.5 لكل قبيلة).
- **الأحزاب:** حزب الإصلاح (دارود + الإسلاميون) + حزب السلام والتنمية (دارود) + حزب العدالة (هوية) + حزب الوسط (هوية) + اتحاد القوى الاشتراكية + أحزاب أخرى.
- 🟠 *القضايا الحساسة* (الحرب الأهلية + الانفصال + أرض الصومال + أوغادين + النزاع القبلي) تُورَد بحياد.
- **«المحاصصة القبلية»** = نظام توزيع المقاعد بالبرلمان بين القبائل — عقبة أمام الديمقراطية + الوطنية.

---

## 7. التحديات الاجتماعية 🟠
- **الحرب الأهلية (1991–الآن):** تدمير + فراغ سلطة + نزوح + مجاعة + مليشيات.
- **حركة الشباب** (2006–الآن) + اتحاد المحاكم الإسلامية → إرهاب + حرب + أزمة إنسانية.
- **الفقر + البطالة (~40–50%) + الأمية + ضعف الخدمات** + المجاعة.
- **النزوح:** ~3–4 مليون نازح داخلي + ~1–2 مليون لاجئ في الخارج (كينيا + إثيوبيا + اليمن).
- **الفساد + غياب الحوكمة + القرصنة + التهريب** + اقتصاد غير رسمي.
- **العصبية القبلية** + النزاعات العشائرية + التهميش (أرض الصومال — تاريخي).

---

## 8. ربط المجتمع بالجغرافيا والتاريخ
- **القرن الإفريقي + ساحل 3,333 كم** → ثقافة بحرية + تجارة + الإسلام (القرن 7) + الأنساب العربية + الصوماليون كعنصر واحد موحِّد. 🟢
- **السهول + السافانا + البدو** → حياة رعوية بدوية + الإبل + الماعز + نظام 4 قبائل + العصبية القبلية. 🟢
- **الإسلام + الصوفية** → الطرق (قادرية + أحمدي) + المحاضر + المدائح + الختان + الحلال.
- **الانقسام الجغرافي** (شمال × جنوب — استعمار بريطاني × إيطالي) → تباين قبلي (شمال: در + إسحاق — جنوب: هوية + رحنوين) + بذور الانفصال (أرض الصومال — الماي). 🟠
- **العصبية القبلية + نظام «المحاصصة»** → عقبة أمام الديمقراطية + بناء الدولة + الحرب الأهلية (1991) + المليشيات.
- **التاريخ الاستعماري** (بريطاني × إيطالي × فرنسي + إثيوبيا) → التقسيم + بذور النزاع (أرض الصومال + أوغادين + شمال كينيا).
- **الحرب الأهلية + الشباب** → تدمير التراث + فراغ السلطة + المجاعة + النزوح + الانفصال + الانهيار المؤسسي. 🟠
- **المغتربون** → التحويلات (كبرى عالميًّا) + الهوية الصومالية في الخارج + إعادة بناء بطيئة.
