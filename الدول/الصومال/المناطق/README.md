# مناطق الصومال (الغوبول) — المرحلة الرابعة

> **المرجع الجغرافي لهذه المرحلة:** المستوى الأعلى القابل للترميز = **غوبول / gobol** (منطقة) — **18 منطقة**. رموز **ISO 3166-2:SO**. ليست محافظة ولا ولاية سودانية. 🟢
>
> **المستوى الثاني:** **دِغمو / degmo** (مقاطعة). الجداول القديمة نحو **90**؛ جرود أحدث تذكر **72** 🟡. ثم حي/قرية.
>
> **الطبقة السياسية الاتحادية** (ولايات أعضاء + بنادر + أرض الصومال + SSC) في [`../الولايات_الاتحادية/README.md`](../الولايات_الاتحادية/README.md). لا تُخلط حدود الولاية الاتحادية بالغوبول: مدج وسول وسناق مقسومة أو متنازع عليها. 🟠
>
> **مقديشو المدينة** في `العواصم/مقديشو/` — هنا **غوبول بنادر**.
>
> **السكان:** مسح تقدير السكان **PESS 2014** (السلطات الصومالية + UNFPA) للمجموع **12,316,895** في الـ18 🟢. لا تعداد لاحق موثوق على مستوى الغوبول. تقديرات 2025 الوطنية 16–19 مليون لا تُوزَّع هنا اختلاقًا. 🟡
>
> أرض الصومال أعلنت استقلالًا أحاديًا **1991** بلا اعتراف أممي ولا من جامعة الدول العربية. تُعرض كأمر واقع إداري في الشمال الغربي دون تبنّي الانفصال. 🟠

### التغيّر الزمني

| الفترة | التقسيم | الثقة |
|---|---|---|
| الاستعمار | صومال بريطاني (شمال غرب) + صومال إيطالي (جنوب/شرق) | 🟢 |
| 1960–1967 | 8 مقاطعات كبرى بعد الوحدة | 🟢 |
| 1974–1975 | استحداث جدو وباي وباكول وجوبا الوسطى/السفلى؛ انكماش بنادر إلى مقديشو | 🟢 |
| 1982 | إعادة تنظيم إلى 16 منطقة | 🟢 |
| **يونيو 1984** | فصل **أودال** عن وقويي جالبيد و**سول** عن نوجال = **18** | 🟢 |
| 1991– | انهيار المركز؛ أرض الصومال؛ بونتلاند 1998 | 🟠 |
| 2012–2016 | دستور مؤقت + ولايات: جوبالاند / جنوب غرب / غلمدغ / هيرشابيلي | 🟡 |
| 2023–2025 | SSC-خاتومو / الولاية الشمالية الشرقية — نزاع على سول/سناق/عين | 🟠 |

## الطبقة الاتحادية — لا تخلطها بالغوبول

| الكيان | العاصمة | الغوبول المرتبط (تقريبًا) | الحالة |
|---|---|---|---|
| جوبالاند | كيسمايو | جدو + جوبا الوسطى + جوبا السفلى | ولاية اتحادية 2013 🟢 |
| جنوب غرب الصومال | **بيدوا** | باي + باكول + شبيلي السفلى | ولاية 2014 🟢 |
| هيرشابيلي | **جوهر** | هيران + شبيلي الوسطى | ولاية 2016 🟢 |
| غلمدغ | دوسمريب | جلجدود + **جنوب** مدج | 2006 / 2015 🟢 |
| بونتلاند | **غاروي** | باري + نوجال + **شمال** مدج | حكم ذاتي 1998 🟢 |
| إدارة بنادر | مقديشو | بنادر فقط | ليست ولاية اتحادية 🟢 |
| أرض الصومال | هرجيسا | أودال + وقويي جالبيد + توغدير + تطالب بسناق/سول | انفصال أحادي 1991 🟠 |
| SSC / الشمالية الشرقية | لاسعانود | سول + أجزاء سناق + عين (بوهودلي) | اعتراف مقديشو 2025 متنازع 🟠 |

- لا تُخترع أنساب لكل منطقة. الحرب والشباب يُذكران قيدًا على الإحصاء لا كخريطة سيطرة ثابتة.
