## أهم ما يميز الصومال

- **أطول ساحل في القارة الإفريقية** (~3,333 كم على المحيط الهندي + خليج عدن).
- **القرن الإفريقي** — أقصى شرق أفريقيا + موقع استراتيجي (باب المندب + ~12% من التجارة العالمية).
- **مهد سلطنات إسلامية:** عجوران (القرن 13–17) + عدال + مقديشو + هوبيو + جيليدي.
- **استعمار ثلاثي:** بريطاني (شمال غرب) + إيطالي (جنوب) + فرنسي (جيبوتي) — تقسيم برلين.
- **الاستقلال:** 1 يوليو 1960 (اتحاد الشطرين البريطاني + الإيطالي).
- **محمد سياد بري** (1969–1991) + الحرب الأهلية + انهيار الدولة.
- **أرض الصومال** (1991 — استقلال من جانب واحد — غير معترف بها دوليًّا — اعتراف إسرائيل 2025).
- **حركة الشباب** (2006–الآن) + اتحاد المحاكم الإسلامية + حرب على الحكومة.
- **نظام العشائر (4 قبائل):** در + دارود + هوية + إسحاق + رحنوين — نظام اجتماعي/سياسي قوي + «المحاصصة القبلية».
- **اللغة الصومالية** (كوشية) + لهجتان: محاتري (شمال/وسط) + ماي (جنوب — مستقلة).
- **اقتصاد رعوي + تحويلات** — ثروة حيوانية ضخمة + اتصالات + زراعة + صيد.
- **حرب جارية + أزمة سياسية** (2024–2026 — تعديلات دستورية + الصراع).
- **مغتربون كبرى** (تحويلات ~20–30% من الناتب).

## أهم المناطق

- **مقديشو:** العاصمة + أكبر مدينة + ميناء + مقر الحكومة.
- **هرجيسا:** عاصمة أرض الصومال (الانفصالية) + أكبر مدينة في الشمال.
- **غاروي:** عاصمة بونتلاند (غوبول نوجال) — ليست «غاروه».
- **كيسمايو:** عاصمة جوبالاند + ميناء الجنوب.
- **بيدوا:** عاصمة جنوب غرب (ليست براوة).
- **جوهر:** عاصمة هيرشابيلي (شبيلي الوسطى).
- **دوسمريب:** عاصمة غلمدغ.
- **براوة / مركة:** شبيلي السفلى — ليستا عاصمة ولاية.

## أهم الأطعمة

الكنترة/أنجيرو (الخبز الوطني) · الباستو (المعكرونة) · البرياني (الأرز) · **السمبوسة** (رمضان) · الموفو · سوقار · إيدام/مارق · كبدة الجمل · باجيو · العانبولو · الكاك كاك. المشروبات: **الشاي الصومالي** (شاي عديس — الوطني) + **حليب الإبل** (رمضان) + عصير فروتلاتو + التمر الهندي + الكركديه.

## أهم الملابس

رجالي: **المكاوييس** (سارونغ — الزي القومي) + الثوب/الخميص (أبيض) + الكوفية + البشت + النعل. نسائي: **الديراك** (فستان خفيف ملوَّن) + **الغارباسار** (تنورة داخلية) + القورقوراد + الشال/الحجاب + الباتي (يومي) + الحناء + الذهب.

## أهم اللهجات

**اللغة الصومالية** (كوشية) + لهجتان: **محاتري** (شمال/وسط — أساس المعيارية) + **ماي** (جنوب — مستقلة — رحنوين) + العربية (الثانية) + تأثيرات (عربية + فارسية + إيطالية + إنجليزية + هندية).

## أهم الأحداث التاريخية

سلطنة عجوران + عدال + مقديشو (القرن 7–17) → الاستعمار (بريطاني/إيطالي/فرنسي + إثيوبيا) → **الاستقلال (1/7/1960)** → سياد بري (1969–1991) → **الحرب الأهلية + انهيار الدولة (1991)** → **استقلال أرض الصومال (1991 — غير معترف بها)** → الحكومة الانتقالية (2004) → دستور (2012) → **الشباب (2006–الآن)** → استرداد >215 موقعًا (2023) → تعديلات دستورية (2024) → **اعتراف إسرائيل بأرض الصومال (2025)** → أزمة سياسية + قتال في مقديشو (2026).

## ما يجب أن يعرفه من يريد فهم الصومال

1. **أطول ساحل في القارة الإفريقية** (~3,333 كم) + القرن الإفريقي + موقع استراتيجي (باب المندب + ~12% من التجارة العالمية).
2. **مهد سلطنات إسلامية** (عجوران + عدال + مقديشو + هوبيو) + استعمار ثلاثي (بريطاني × إيطالي × فرنسي).
3. **الاستقلال 1 يوليو 1960** (اتحاد الشطرين) → **سياد بري** (1969–1991) → **الحرب الأهلية + انهيار الدولة (1991)**.
4. **أرض الصومال** (1991 — استقلال من جانب واحد — غير معترف بها دوليًّا — اعتراف إسرائيل 2025).
5. **حركة الشباب** (2006–الآن) + اتحاد المحاكم الإسلامية + حرب + أزمة إنسانية + مجاعة.
6. **نظام العشائر (4 قبائل):** در + دارود + هوية + إسحاق + رحنوين — نظام اجتماعي/سياسي قوي + «المحاصصة القبلية» في البرلمان.
7. **اللغة الصومالية** (كوشية) + لهجتان: محاتري (شمال/وسط) + ماي (جنوب — مستقلة) + العربية (الثانية).
8. **اقتصاد رعوي + تحويلات** (ثروة حيوانية + اتصالات + زراعة + صيد + تحويلات المغتربين ~20–30% من الناتب).
9. **مغتربون كبرى** (أوروبا + الخليج + أمريكا) + إعادة بناء بطيئة.
10. **حرب جارية + أزمة سياسية** (2024–2026 — تعديلات دستورية + الصراع + انسحاب القوات الأفريقية 2026).
