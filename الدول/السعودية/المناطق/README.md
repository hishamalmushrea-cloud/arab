# مناطق السعودية — المرحلة الرابعة (الوحدات الإدارية العُليا)

> **المرجع الإداري:** المستوى الأعلى الرسمي = **منطقة** (لا محافظة). العدد **13 منطقة** وفق نظام المناطق 1412هـ/1992م. المستوى الثاني = **محافظة** (فئة أ/ب) + مقر الإمارة / أمانة في كبرى المدن. المستوى الثالث = **مركز** → قرى/هجر. 🟢
>
> **نطاق المرحلة الرابعة:** ملف مستقل لكل منطقة من الـ13 وفق القالب 5-ج. الرياض (المدينة) مُغطاة في `العواصم/الرياض/الرياض.md` — هنا تُدرَس **المنطقة** بحدودها الإدارية دون تكرار ملف العاصمة.
>
> **مصادر الأرقام:** الهيئة العامة للإحصاء (تعداد 2022) كما في `الدول/السعودية/معلومات_عامة.md` + سعوديبيديا + نظام المناطق. 🟢
>
> **لا اختلاق:** قوائم المحافظات تُذكر بالاسم؛ خلاف العدد يُوسم 🟡. القبائل تُحال إلى ملف الدولة ما لم يُنشر حصر رسمي للمنطقة.

## ملاحظة منهجية

- يُستخدم مصطلح **منطقة** للمستوى الأعلى و**محافظة** للمستوى الثاني — لا تُسمّى المنطقة «محافظة».
- العاصمة الدينية (مكة) والعاصمة السياسية (الرياض) مدينتان داخل منطقتيهما؛ ملف العاصمة لا يغني عن ملف المنطقة.
- لا تُنسب المعالم عبر المناطق: المسجد النبوي في المدينة لا مكة؛ الغوار/أرامكو في الشرقية لا الرياض؛ فرسان في جازان لا عسير.
