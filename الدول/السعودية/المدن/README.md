# مدن السعودية — المرحلة الخامسة

> **المرحلة الخامسة:** ملف لكل مدينة موثَّقة (ليست وحدة إدارية عُليا). المصطلح: **مدينة** داخل **منطقة → محافظة**. ليست ولاية ولا غوبول. 🟢
>
> **الرياض المدينة** في `العواصم/الرياض/` — لا تكرار هنا.
>
> **السكان:** تعداد الهيئة العامة للإحصاء **22 مايو 2022** عبر جداول citypopulation المتطابقة مع ويكيبيديا في أغلب المدن 🟢. حيث يختلف تعريف المدينة عن المحافظة يُوسم 🟡. لا يُخلط سكان **المنطقة** بسكان **المدينة** (مكة المنطقة 8,021,463 ≠ مكة المدينة 2,385,509).
>
> الأولوية: العواصم الإقليمية + كبرى المدن + مدن تاريخية/نائية حتى لا تُهمَّش سكاكا وعرعر والقريات ودومة الجندل.
