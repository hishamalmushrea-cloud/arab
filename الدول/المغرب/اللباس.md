# المملكة المغربية — اللباس التقليدي

> منهجية: لكل قطعة يُذكَر اسمها المحلي + المناسبة + المنطقة + الاختلاف بين المناطق.
> المصادر: ويكيبيديا (اللباس التقليدي المغربي)، الخليج (القفطان المغربي)، البيان (خبايا التراث المغربي)، sarabic.ae، steemit.

---

## 1. ملاحظة أولى: زي وطني مغربي مميز 🟢

> المغرب زي تقليدي مميز عن المشرق — الجلابة/القفطان/التكشيتة/الطربوش/البلغة — عريق منذ العصر المريني/السعدي/العلوي. القفطان المغربي عالمي الصيت (إدراج اليونسكو قيد الدراسة).

---

## 2. اللباس الرجالي 🟢

### القطع الأساسية

| القطعة | الوصف | المنطقة/الاستخدام |
|---|---|---|
| **الجلابة (الجلباب)** | رداء طويل بأكمام + قلنسوة (رأس) — قطني صيفًا (أبيض/أصفر) + صوفي شتاءً (داكن) | كل المغرب — يومي/مناسبات/صلاة |
| **الطربوش (الطربوش المغربي الأحمر)** | قبعة حمراء أسطوانية | رمزي — يُلبس مع الجلابة |
| **العمامة** | تُلف على الرأس | العلماء/الأشراف |
| **البلغة (البابوش)** | حذاء جلدي أصفر/أبيض بلا كعب | مع الجلابة |
| **السلهام (البرنس)** | عباءة صوفية بقلنسوة (شتاء) — بلا أكمام | الريف/الأطلس/شتاء |
| **القميص/السروال** | تحت الجلابة | — |
| **البدلة (حديثة)** | بدلة غربية | المدن/الرسمي |

### أنواع الجلابة بحسب المنطقة 🟢
- **جلابة فاسية:** حرير/بروكار فاسي — فاخرة (المناسبات).
- **جلابة رباطية:** قطن/صوف — يومية.
- **جلابة مراكشية:** قطني خفيف — صيفًا.
- **جلابة أمازيغية (سوس/الريف):** صوفية مزخرفة — شتاء.

---

## 3. اللباس النسائي 🟢 — القفطان/التكشيتة عالمي الصيت

### (أ) القفطان المغربي 🟢 — رمز الهوية
- **الوصف:** جلابة بدون قلنسوة، مفتوحة من الأمام، مطرَّزة بخيوط ذهبية/فضية + حزام (المضمّة).
- **القماش:** البروكار الفاسي (منسوج يدويًّا في فاس) + المخمل + الحرير + التافتاه + الدانتيل.
- **المناسبة:** الأعراس/الحفلات/المناسبات — **لباس العروس الرئيسي**.
- **الأنواع بحسب الخياطة:**
  - **الخياطة الفاسية:** أعرق + خيوط صقلية لامعة + الديباج/الحرير.
  - **الخياطة الرباطية (المخزنية):** فضفاضة (كما كانت نساء القصر).
  - **الخياطة المراكشية:** زخارف/تطريز.
- **التاريخ:** كان رجاليًّا (القرن 12) → تحوّل نسائيًّا (القرن 18+) 🟢.

### (ب) التكشيتة (التفشيتة) 🟢
- **الوصف:** فستان من قطعتين (الردف + التحتية) — مطرَّز + حزام.
- **المناسبة:** الأعراس/الحفلات — بديل القفطان.
- **العروس:** التكشيتة البيضاء (للعرس) + قفطان أحمر/أبيض (الكوشة/العقد).

### (ج) الجلابة النسائية 🟢
- **الوصف:** جلابة قطنية/صوفية — يومية (منذ الأربعينات — بديل الحايك).
- **مع اللثام (النقاب):** قديمًا (قبل الاستقلال) → تراجع بعد الاستقلال.

### (د) الحايك (الملاية) 🟢 — تاريخي/ريفي
- **الوصف:** قطعة قماش بيضاء/سوداء تُلف حول الجسم + تُغطي الرأس/الوجه.
- **الانتشار:** ريف/وسط المغرب — تاريخي → تراجع (إلا في الريف/المدينة القديمة).

### (هـ) الزي الأمازيغي 🟢 — سوس/الريف/الأطلس
- **الأمازيغي (سوس):** فستان ملوّن + حلي فضية ثقيلة + تغريفات (تطريز) + الشاش.
- **الزي الريفي:** فستان أحمر/أبيض + حلي + الشاش.
- **الزي الأطلسي:** قفطان أمازيغي + حزام.

### (و) الزي الأندلسي (طنجة/تطوان/شفشاون) 🟢
- **لباس الحضرة الشاونية:** قفطان + حزام مزخرف + «الحراز» (عصابة بيضاء مطرزة) + «السبنية السويسة» (طرحة حريرية).
- **الزي الجبلي:** أندلسي الملامح (الموريسكيون بعد سقوط الأندلس 1492).

---

## 4. الحلي والمجوهرات 🟢

- **الذهب:** للنساء (أقراط/أساور/خلاخل/العقد/الديباج الفاسي).
- **الفضة (الأمازيغية):** ثقيلة + تقليدية (سوس/الريف/الأطلس) — تراث يونسكو قيد الدراسة.
- **اللؤلؤ/المرجان:** في الأعراس الفاسية.
- **التاج:** للعروس (الرباط/فاس — المجوهرات).

---

## 5. اللباس التاريخي 🟢

- **الأمازيغي القديم:** الرداء/الجلابة الصوفية + الحايك.
- **الأندلسي:** القفطان/التكشيتة (بعد 1492 — الموريسكيون).
- **السعدي/العلوي:** القفطان الفاسي + البروكار + الذهب.
- **الانتداب (1912–1956):** دخول البدلة الغربية (الرجال) + الفستان (النساء).
- **الحديث:** الجلابة/القفطان (المناسبات) + البدلة/الجينز (يومي).

---

## 6. الفروق بحسب البيئة 🟢

| البيئة | اللباس | السبب |
|---|---|---|
| الساحل الأطلسي (الدار البيضاء/الرباط) | جلابة + بدلة (يومي) + قفطان (مناسبات) | حضري + فرنسي |
| الشمال (طنجة/تطوان/شفشاون) | جلابة + زي أندلسي (الحضرة الشاونية) + إسباني | أندلسي + متوسطي |
| المرتفعات (فاس/مكناس/الأطلس) | القفطان الفاسي + الجلابة الصوفية | تراث حضري عريق + برد الجبال |
| الجنوب (سوس/أكادير) | الزي الأمازيغي + حلي فضية + زيت الأركان | أمازيغي + أركان |
| الواحات/الصحراء | جلابة خفيفة + الحسانية (صحراوية) | صحراء |

---

## 7. التطور الحديث 🟢

- **القفطان المغربي** عالمي الصيت — يُلبس في كل الدول العربية (الأعراس الخليجية/المصرية) + عروض أزياء عالمية (باريس/دبي).
- **الجلابة** زي يومي + مناسبات (بقاء قوي).
- **الحجاب/النقاب:** تراجع بعد الاستقلال، عودة محدودة في الأوساط المحافظة (1980s+).
- **البلغة/الطربوش:** رمزي — يُلبس في المناسبات.

---

## 8. ملاحظة نقدية

- القفطان المغربي **من أعرق الأزياء العربية** — أصله أندلسي/مريني (القرن 12) → تطوّر مغربي فريد.
- **الجلابة** زي وطني يومي (بقاء قوي).
- **الزي الأمازيغي** فريد (الحلي الفضية + التطريز + الشاش).
- **الزي الأندلسي** (طنجة/تطوان/شفشاون) موروث موريسكي.
- القفطان المغربي انتشر عربيًّا/عالميًّا (الأعراس الخليجية/المصرية/عروض الأزياء).
