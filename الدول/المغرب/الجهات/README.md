# جهات المغرب — المرحلة الرابعة (الوحدات الإدارية العُليا)

> **المرجع الإداري:** المستوى الأعلى = **جهة** — **12 جهة** (إصلاح 2015، القانون التنظيمي 111-14). ليست ولاية تونسية/جزائرية ولا محافظة ولا منطقة سعودية. 🟢
>
> **المستوى الثاني:** **عمالة** (حظر غالب) أو **إقليم** (قروٍ غالب) — **75** (13 عمالة + 62 إقليم). المستوى الثالث: **جماعة** (حضرية/قروية) → دوار/حي. 🟢
>
> **الرباط المدينة** في `العواصم/الرباط/` — هنا **جهة الرباط-سلا-القنيطرة**.
>
> **السكان:** إحصاء المندوبية السامية للتخطيط **شتنبر 2014** و**2024** (RGPH). 🟢
>
> **الصحراء الغربية:** جهة الداخلة بالكامل، والعيون ومعظم السمارة/بوجدور ضمن الإقليم غير المتمتع بالحكم الذاتي أمميًا. كلميم-واد نون معظمها شمال الخط (معترف بها دوليًا كمغرب) مع أسا-الزاك في التداخل. يُعرض التقسيم المغربي الرسمي مع إشارة حيادية دون تبنّي موقف. 🟡
