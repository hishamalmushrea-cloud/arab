# المملكة المغربية — الطعام (المطبخ المغربي)

> منهجية: لا تُنسب الأطباق إلى «المغرب» ككتلة بل إلى منشئها حيثما أمكن. كل طبق يُربَط بمكانه.
> المصادر: ويكيبيديا (مطبخ مغربي/قائمة الأطباق المغربية)، al-ain (10 أطباق)، alsyahaalarabia.

---

## 1. نظرة عامة 🟢 — مطبخ عالمي الصيت

- **الشهرة:** من أعظم المطابخ العالمية (Taste Atlas 2024 — المرتبة 25 عالميًّا + **الأول عربيًّا** 🟢).
- **الخصائص:** تنوع نكهات (الحلو-الحار) + بهارات (رأس الحانوت/الكركم/الزعفران/الكمون/القرفة) + زيت الزيتون/زيت الأركان/السمن + الفواكه المجففة (لوز/تين/تمر) + مخلل الليمون.
- **الجذور:** أمازيغي (الكسكس/الطاجين) + عربي/أندلسي (البهارات/البسطيلة) + إفريقي + فرنسي/إسباني (حديث).
- **الانتشار:** عالمي عبر المغتربين + المطاعم المغربية (القفطان/الطاجين).

---

## 2. الأطباق الوطنية الكبرى 🟢

### (1) الكسكس 🟢 — الطبق الوطني
- **الأصل:** أمازيغي/مغاربي — ذكر في النقوش الأمازيغية 🟢.
- **الوصف:** كسكس (سميد قمح مفتول) + خضار (قرع/جزر/بطاطس/لفت/بصل) + لحم/دجاج + مرق + حمص.
- **التقديم:** في «الكسكاس» (وعاء مثقب على البخار) — غداء **يوم الجمعة** تقليديًّا + الأعراس/المناسبات.
- **الانتشار:** كل المغرب + المغرب العربي + عالمي.
- **2020:** أُدرج الكسكس في **تراث اليونسكو غير المادي** (المغرب/الجزائر/تونس/موريتانيا مشتركًا). 🟢

### (2) الطاجين (Tagine) 🟢 — أمازيغي/مغربي
- **الأصل:** أمازيغي — اسمه من الوعاء الفخاري المخروطي.
- **الوصف:** لحم/دجاج + خضار + بهارات + زيتون/مخلل ليمون/برقوق — يُطهى ببطء في وعاء فخاري.
- **الأنواع:** طاجين البرقوق (لحم + برقوق + لوز) + طاجين الدجاج بالزيتون/الليمون + طاجين السمك + طاجين الخضار.
- **الانتشار:** كل المغرب + عالمي.

### (3) البسطيلة (Pastilla) 🟢 — أمازيغي/أندلسي
- **الأصل:** أمازيغي/أندلسي — فاس/مكناس.
- **الوصف:** ورق رقيق (ورق البسطيلة) + دجاج/حمام + لوز + قرفة + سكر — حلو-مالح فاخر.
- **المناسبة:** الأعراس/المناسبات الكبرى.
- **الأنواع:** بسطيلة الدجاج + بسطيلة الحمام + بسطيلة السمك (حديثة).

### (4) الحريرة 🟢 — مغربية
- **الوصف:** شوربة دسمة (لحم/دجاج + عدس + حمص + طماطم + كزبرة + بهارات + شعيرية) — مع التمر في رمضان.
- **المناسبة:** **فطور رمضان** التقليدي.

### (5) الطنجية المراكشية 🟢 — مراكش أصيلة
- **الأصل:** مراكش.
- **الوصف:** لحم + ثوم + كمون + زعفران + حامض + سمن حر — تُطهى في «الطنجية» (وعاء فخاري) في الحمام العام (تقليد مراكشي).
- **المناسبة:** شتوي/الجمعة.

## 3. أطباق أخرى بارزة 🟢

| الطبق | الأصل/المنطقة | الوصف | المناسبة |
|---|---|---|---|
| **الرفيسة** | مغربي/أمازيغي | خبز (المسمن/الرقاقات) + دجاج + عدس + بهارات | مناسبات |
| **المروزية** | مغربي | لحم غنم + زبيب + لوز + قرفة (عيد الأضحى) | عيد الأضحى |
| **السفة (المدفونة)** | مغربي | كسكس + دجاج + قرفة/سكر (حلو) | مناسبات |
| **الزعلوك** | مغربي | باذنجان + طماطم + ثوم + بهارات | مقبلات |
| **البيصارة** | مغربي/ريف | فول مجفف مهروس + زيت زيتون + كمون | فطار شتوي |
| **المحنشة** | مغربي | ورق البسطيلة + لوز/لحم — تلف على شكل ثعبان | مناسبات |
| **تاكوين** | سوس/أمازيغي | لحم + بهارات + جوز (أكلة أمازيغية) | مناسبات |
| **الكعب/كعب الغزال** | مغربي | عجين + لوز + سكر (شكل كعب الغزال) | حلوى |
| **الغريبة** | مغربي | بسكويت + لوز/سمسم/يانسون | حلوى |
| **الشباكية** | مغربي | عجين مقلو بالعسل + سمسم — رمضانية | رمضان |
| **سلو (سلفو)** | مغربي | طحين محمص + لوز + زبدة + عسل — رمضانية | رمضان/فطار |
| **كعب الغزال/البريوات** | مغربي | عجين + لوز + قرفة + عسل | حلوى |

## 4. الخبز 🟢

- **الخبز المغربي (الخبز البلدي)** — خبز دائري للطاجين.
- **المسمن (الرغايف)** — فطائر مربعة مدهونة (فطار).
- **البغرير** — خبز سميد بالثقوب (فطار — مع عسل/زبدة).
- **البطبوط** — خبز دائري كبير (سوس/الأطلس).
- **الحرشة** — خبز سميد مقلي (فطار).
- **تفرنوت** — خبز مسطح بلدي (سوس — فرن طيني).

---

## 5. المشروبات والحلويات 🟢

- **أتاي (الشاي المغربي بالنعناع):** 🟢 — الشاي الأخضر + النعناع + السكر — يُعدّ بمراسم (العلبة/البراد/الكأس) — رمز الضيافة المغربية + **تراث اليونسكو غير المادي (2024)**. 🟢
- **القهوة (النسكافيه/الإسبريسو):** حضرية (تأثير فرنسي).
- **لبن/حليب/أيران:** مع الكسكس.
- **عصير برتقال/أفوكادو:** صباحي.
- **الحلويات:** الشباكية (رمضان) + كعب الغزال + الغريبة + البريوات + سلو + البقلاوة (مغربية) + فقاص + محنشة.

## 6. المأكولات بحسب البيئة (ربط الجغرافيا بالطعام) 🟢

| البيئة | أطعمة بارزة | السبب |
|---|---|---|
| الساحل الأطلسي (الدار البيضاء/الرباط/أكادير) | السمك + المأكولات البحرية + الكسكس/الطاجين | بحر + متوسطي |
| المرتفعات (فاس/مكناس/الأطلس) | البسطيلة (فاس) + الحريرة + الكسكس + الطاجين الجبلي | تراث حضري عريق + جبال |
| الشمال (طنجة/تطوان/الريف) | الطاجين + الكسكس + تأثير إسباني/أندلسي | متوسطي + إسباني |
| الجنوب (سوس/أكادير) | زيت الأركان + تاكوين (أمازيغي) + الكسكس | أمازيغي + أركان |
| الواحات (درعة/تافيلالت) | التمر + الكسكس + الطاجين الصحراوي | واحات + صحراء |
| الصحراء (العيون/الداخلة) | تأثير حساني/صحراوي + السمك | صحراء + ساحل |

## 7. أطعمة المناسبات 🟢

- **الجمعة:** الكسكس (تقليد وطني).
- **رمضان:** الحريرة + الشباكية + سلو + التمر + أتاي.
- **عيد الأضحى:** المروزية + الطاجين + السفة.
- **الأعراس:** البسطيلة + الكسكس/المروزية + كعب الغزال + أتاي.
- **الضيافة:** أتاي (شاي النعناع) + حلويات (كعب الغزال/الغريبة).

---

## 8. البهارات والمكوّنات المحلية 🟢

- **بهارات:** **رأس الحانوت** (خلطة 20+ بهار) + الكركم + الزعفران (المغربي عالمي الصيت) + الكمون + القرفة + الزنجبيل + الفلفل الأسود + خاواييج + مخلل الليمون.
- **مكوّنات محلية:** **زيت الأركان** (سوس — تراث يونسكو) + زيت الزيتون (المتوسط) + اللوز + التمر (الواحات) + الزعفران (تالوين) + الحمضيات + الزيتون.
- **ملاحظة:** **أتاي (الشاي المغربي بالنعناع) تراث يونسكو 2024** 🟢 + الكسكس تراث يونسكو 2020 🟢.

---

## 9. ملاحظة نقدية

- المطبخ المغربي **من أعظم المطابخ العالمية** (تنوع + بهارات + حلو-حار).
- **الكسكس أمازيغي/مغاربي أصيل** (تراث يونسكو مشترك مع الجزائر/تونس/موريتانيا).
- **البسطيلة أندلسية/أمازيغية** (فاس).
- **أتاي مغربي أصيل** (تراث يونسكو).
- التأثيرات: أمازيغي (الكسكس/الطاجين) + أندلسي (البسطيلة/البهارات) + فرنسي (حديث) + إسباني (الشمال).
