# المملكة الأردنية الهاشمية — الطعام (المطبخ الأردني)

> منهجية: لا تُنسب الأطباق إلى «الأردن» ككتلة بل إلى منشئها حيثما أمكن. كل طبق يُربَط بمكانه.
> المصادر: layalina (المطبخ الأردني)، ajsrp، euronews (المنسف)، العربي نت (المنسف)، ويكيبيديا (قائمة الأطباق العربية).

---

## 1. الأطباق الوطنية الكبرى 🟢

### (1) المنسف 🟢 — الطبق الوطني الأردني
- **الأصل:** الأردن (موروث بدوي/شامي — مرتبط بمملكة مؤاب تاريخيًّا 🟠 بحسب رواية الملك ميشع).
- **الوصف:** لحم غنم مطهو + **لبن الجميد** (لبن مجفف مخمر — الكركي/البلقاوي) + أرز/برغل + خبز الشراك + مكسرات (لوز/صنوبر) + سمن بلدي.
- **التقديم:** على صدر خبز الشراك + يسكب اللبن + يُزيَّن باللحم/الأرز/المكسرات.
- **المناسبة:** «سيد المائدة الأردنية» — رمز الكرم/الضيافة + الأعراس/الأعياد/رمضان.
- **التطور:** تاريخيًّا كان البرغل (القمح المجروش) الأساس قبل الأرز (القرن 19) — لما ظهر الأرز حل محله. 🟢
- **الانتشار:** كل الأردن + فلسطين/سوريا (موروث شامي مشترك).
- **التراث:** مدرج في التراث الثقافي الأردني (وزارة الثقافة). 🟢

### (2) المقلوبة 🟢 — شامي/أردني
- **الأصل:** الشام (الأردن/فلسطين/سوريا — مشترك).
- **الوصف:** أرز + لحم/دجاج + باذنجان مقلي (± قرنبيط/بطاطا) → تُطهى معًا ثم **تُقلب** في صحن التقديم (كعكة).
- **الانتشار:** كل الأردن.

### (3) الكنافة النابلسية 🟢 — فلسطيني الأصل (انتشر للأردن)
- **الأصل:** نابلس (فلسطين) — انتشرت للأردن (اللاجئون الفلسطينيون).
- **الوصف:** عجين الكنافة (الخشنة/الناطق) + جبنة عكاوي/قشطة + شراب سكر + مكسرات + لون برتقالي.
- **المناسبة:** رمضان/فطور.

### (4) المسخن 🟢 — فلسطيني الأصل (انتشر للأردن)
- **الأصل:** فلسطين (الشمال/نابلس/جنين) — انتشر للأردن.
- **الوصف:** خبز + دجاج + بصل + سماق + زيت زيتون + صنوبر.

| **الكبة (نية/مقلية/لبنية)** | شامي/أردني | برغل + لحم، تُحشى/تُقلى/تُطبخ | وليمة |
| **المكمورة** | أردني/شامي | خبز + لحم + بصل + سمن (في التنور) | وليمة |

| **الشاكرية** | شامي/أردني | لحم + لبن | غداء |

| **الفلافل (الطعمية الشامية)** | شامي | أقراص حمص/فول مقلية | فطار |
| **الحمص بطحينة** | شامي | حمص + طحينة | مقبلات |
| **الفتوش/التبولة** | شامي | سلطة + خبز/برغل | مقبلات |

## 3. الخبز 🟢

- **خبز الشراك (الصاج)** — رقيق جدًّا — عماد المنسف.
- **خبز التنور** — في الريف/البادية.
- **الخبز العربي (البيتا)** — حضري.

---

## 4. المشروبات والحلويات 🟢

- **القهوة العربية (السادة/الشاذلية)** — مع الهيل، رمز الضيافة البدوية 🟢.
- **الشاي** — مع النعناع/المريمية.
- **لبن/اليران** — مع الأكل.
- **عصير ليمون/تمر هندي** — صيفًا.
- **الحلويات:** الكنافة النابلسية + المعمول (أعياد) + الهريسة + العوّامة + اللزاقيات (حلوى شعبية) + قطايف (رمضان).

---

## 5. المأكولات بحسب البيئة (ربط الجغرافيا بالطعام) 🟢

| البيئة | أطعمة بارزة | السبب |
|---|---|---|
| المرتفعات (عمّان/إربد/عجلون/البلقاء/الكرك) | المنسف (البلقاوي/الكركي) + المقلوبة + الكبة + الحمص + الزيتون/الزيت | زراعة جبلية + زيتون + قمح |
| الأغوار (وادي الأردن/البحر الميت) | موز/تمر/خضر استوائية + أكلات بحرية | مناخ استوائي + زراعة |
| البادية (الشرق/الجنوب) | المنسف (بدوي) + الرشوف + الهريس + القهوة العربية | بدو + رعي |
| الجنوب (معان/العقبة/الطفيلة) | المنسف (معاني) + أكلات بدوية + سمك (العقبة) | بادية + ساحل (العقبة) |
| الفلسطينيون (في المدن) | المسخن + الكنافة النابلسية + المقلوبة | موروث فلسطيني (1948/1967) |

---

## 6. أطعمة المناسبات 🟢

- **المنسف:** سيد المائدة — أعراس/أعياد/رمضان/ضيافة.
- **رمضان:** المنسف/المقلوبة/الكنافة/القطايف/الشوربة.
- **الأعياد:** المعمول + المنسف/المشاوي.
- **الضيافة البدوية:** القهوة العربية + التمر + المنسف للضيف.

---

## 7. البهارات والمكوّنات المحلية 🟢

- **بهارات:** الهيل (للقهوة)، السماق (للمسخن/السلطات)، البهار الحلو، الكمون، الفلفل الأسود، الكزبرة، الشطة/الدقوس.
- **مكوّنات محلية:** **لبن الجميد** (الكركي/البلقاوي — أساس المنسف) + زيت الزيتون (الشمال/المرتفعات — الأردن من أكبر منتجيه عالميًّا 🟢) + اللحم البلدي (غنم) + السمن البلدي + التمر (الأغوار) + الموز (الأغوار).
- **ملاحظة:** لبن الجميد الكركي + السمن البلقاوي علامتان أردنيتان للمنسف. 🟢

---

## 8. ملاحظة نقدية

- **المنسف أردني أصيل** (موروث بدوي/شامي مشترك مع فلسطين/سوريا) — لكنه رمز الهوية الأردنية الوطنية.
- **الكنافة النابلسية/المسخن** فلسطيني الأصل (انتشرا للأردن عبر اللاجئين 1948/1967).
- **الكبة/المقلوبة/الحمص/الفتوش/التبولة** موروث شامي مشترك — لا يُنسب لدولة دون أخرى.
- المطبخ الأردني **تأثر بـ**: البدوي (المنسف/القهوة) + الشامي (دمشق/نابلس) + الفلسطيني (1948/1967).
