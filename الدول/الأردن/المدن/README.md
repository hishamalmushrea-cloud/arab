# مدن الأردن — المرحلة الخامسة

> **المرحلة الخامسة:** ملف لكل **مدينة** موثَّقة داخل **محافظة → لواء**. ليست قضاء عراقيًا ولا منطقة سورية. 🟢
>
> **عمّان المدينة** في `العواصم/عمّان/` — لا تكرار هنا. **سحاب** هنا لأنها ليست ملف العاصمة.
>
> **السكان:** تعداد دائرة الإحصاءات العامة **30 نوفمبر 2015** عبر جداول citypopulation (تجمّع حضري) 🟢. تقديرات **نهاية 2023** للمحافظات **ليست** سكان المدينة (إربد المحافظة 2,135,000 ≠ إربد المدينة 502,714).
>
> لا تُهمَّش الجنوب والبادية: الطفيلة، معان، المفرق، وادي موسى.
