# المملكة الأردنية الهاشمية — اللباس التقليدي

> منهجية: لكل قطعة يُذكَر اسمها المحلي + المناسبة + المنطقة + الاختلاف بين المناطق.
> المصادر: ويكيبيديا (اللباس الأردني)، culturein2030vision (مقارنة شامية)، إضافات متقاطعة.

---

## 1. ملاحظة أولى: زي وطني موحَّد + تنوع إقليمي 🟢

> الأردن زي وطني موحَّد نسبيًّا (الثوب + الشماغ/الحطة + العقال للرجال، الثوب المطرَّز للنساء) مع تنوع إقليمي في التطريز/الألوان.

---

## 2. اللباس الرجالي 🟢

### القطع الأساسية

| القطعة | الوصف | المنطقة/الاستخدام |
|---|---|---|
| **الثوب (الجلباب)** | رداء طويل أبيض (صيف) أو داكن (شتاء) | كل الأردن |
| **الشماغ (الكوفية)** | غطاء رأس مربع بنقوش حمراء/بيضاء | كل الأردن — رمز وطني 🟢 |
| **الحطة (الكوفية البيضاء)** | غطاء رأس أبيض | المدن/المناسبات |
| **العقال** | حبل أسود يثبّت الشماغ/الحطة | كل الأردن؛ عقال مقصب للمناسبات |
| **العباءة (المشلح/البشت)** | رداء خارجي صوف/حرير | مناسبات رسمية |
| **السديري (الصديري)** | سترة قصيرة فوق الثوب | تاريخي/مناسبات |
| **العمامة** | تُلف على الرأس (للأشراف/العلماء) | تاريخي |
| **الحزام/الزنار** | جلدي/قماشي | بدوي/مناسبات |
| **الخنجر/الجنبيّة** | خنجر يُحمل على الخصر (تاريخي) | البدو/الجنوب |

### أنواع الثوب بحسب المنطقة 🟢
- **الثوب الحضري:** قطني/أبيض (عمّان/المدن).
- **الثوب البدوي:** صوفي/داكن شتاءً (البادية).
- **الثوب الريفي:** قطني (المرتفعات/الأغوار).

---

## 3. اللباس النسائي 🟢 — التطريز الفلسطيني/الأردني

> الثوب النسائي الأردني **موروث شامي/فلسطيني/بدوي مشترك** — التطريز هو الفن الأبرز.

### (أ) الثوب المطرَّز (السروال + الثوب) 🟢
- **الثوب (السروال/الجلباب):** ثوب طويل + سروال فضفاض.
- **التطريز (المَلَمة/الصرمة):** تطريز يدوي بخيوط حرير/قطن ملوّنة — كل منطقة لها أنماطها:
  - **تطريز الكرك/الطفيلة:** هندسية + أحمر/أسود.
  - **تطريز البلقاء/السلط:** زهور + ألوان زاهية.
  - **تطريز مأدبا:** فسيفساء (تأثير بيزنطي).
  - **تطريز عجلون/إربد:** أوراق/زهور (متوسطي).
  - **تطريز البدو:** هندسية + أحمر/أسود/أبيض (حويطات/بني حميدة).
- **الحطة/الشيلة:** غطاء رأس.
- **البرقع:** غطاء وجه (في بعض القرى/البدويات — تاريخي).

### (ب) الزي الحديث 🟢
- **المدن (عمّان/إربد/الزرقاء):** ملابس غربية (تنانير/جينز) + حجاب محدود.
- **الحجاب/العباءة:** في الأوساط المحافظة (الزرقاء/المفرق/بعض عمّان).
- **المسيحيات:** بدون حجاب غالبًا + ملابس غربية.

### (ج) زي الأقليات 🟢
- **الشركس/الشيشان:** زي تقليدي خاص (الشركسية — للرجال: القفطان + الخنجر؛ للنساء: الفستان المطرَّز).
- **الأرمن:** زي تقليدي أرمني.

---

## 4. الحلي والمجوهرات 🟢

- **الذهب/الفضة** — للنساء (أقراط/أساور/خلاخل/صليب للمسيحيات).
- **الخرز/التراث** — في البادية/الريف.
- **الخنجر** — للرجال (رمز).
- **الصليب** — للمسيحيات.

---

## 5. اللباس التاريخي 🟢

- **العموني/المؤابي/الأنبطي:** تاريخي (نقوش/آثار).
- **البيزنطي:** تاريخي (مأدبا/الفسيفساء).
- **العثماني:** الثوب + الشماغ/الحطة + العقال + العباءة (تأثير قوي).
- **البدوي التاريخي:** الثوب الصوفي + الشماغ + العقال + الخنجر.
- **الحديث (القرن 20):** الثوب الأبيض + الشماغ الأحمر + العقال (زي وطني) + ملابس غربية.

---

## 6. الفروق بحسب البيئة 🟢

| البيئة | اللباس | السبب |
|---|---|---|
| المرتفعات (عمّان/إربد/عجلون/البلقاء/الكرك) | الثوب الأبيض/الداكن + الشماغ/العقال + الثوب المطرَّز (نساء) | مناخ معتدل + زراعة + تراث |
| الأغوار (وادي الأردن/البحر الميت) | ثوب خفيف + حطة (حرارة) | مناخ استوائي |
| البادية (الشرق/الجنوب) | الثوب الصوفي + الشماغ + العقال + العباءة + الخنجر (بدوي) | برد الصحراء + هوية بدوية |
| الجنوب (معان/العقبة/الطفيلة) | قريب من البدوي + تأثير حجازي (العقبة) | بادية + ساحل |

---

## 7. التطور الحديث 🟢

- **الشماغ الأحمر + العقال** رمز وطني أردني (يُلبس في كل المناسبات/الرسمي).
- **المدن:** ملابس غربية + الشماغ للرجال (رمز).
- **النساء:** تطريز تراثي في المناسبات/الأعراس + ملابس حديثة يوميًّا.
- **الحجاب/العباءة** في الأوساط المحافظة (الزرقاء/المفرق/بعض عمّان).

---

## 8. ملاحظة نقدية

- الزي الأردني **موروث شامي/بدوي مشترك** (الثوب/الشماغ/العقال) + تطريز نسائي فريد بحسب المناطق.
- **الشماغ الأحمر + العقال** رمز وطني — يُلبس في كل المناسبات.
- التطريز النسائي الأردني متقارب مع الفلسطيني (موروث مشترك) لكن لكل منطقة أنماطها.
- **الشركس/الشيشان** زي تقليدي خاص (هجرة القوقاز).
