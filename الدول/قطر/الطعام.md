# دولة قطر — الطعام والمطبخ

> منهجية: لكل طبق يُذكَر اسمه المحلي + المكونات + المناسبة + المنطقة + الأصل.
> المصادر: encyclopediacooking، layalina، alarab.qa، aljazeera (عائشة التميمي)، sandytimes، topsarabia، yearsofculture.

---

## 1. نظرة عامة 🟢

> المطبخ القطري = خليط **خليجي (بهارات) + بحري (ساحل) + بدوي (داخل) + هندي/فارسي (تجارة)**. سمة الغالبة: **البهارات (اللومي/البزار/الزعفران/الهيل)** + الأرز + اللحم + القمح + السمك.

- **الأرز:** ركيزة الأطباق الرئيسية.
- **اللحم:** ضأن + دجاج + سمك + روبيان.
- **القمح:** الهريس + الجريش (بدوي).
- **البهارات:** لومي (ليمون أسود) + بزار (خلطة) + زعفران + هيل + كركم + كمون.
- **التمر + القهوة العربية:** ضيافة.

---

## 2. الأطباق الرئيسية

### (1) المجبوس (الكبسة) 🟢 — الطبق الوطني
- **الوصف:** أرز بسمتي + لحم/دجاج/سمك/روبيان/فقع + بهارات (لومي + زعفران + هيل + بزار) + بصل + طماطم.
- **المناسبة:** الولائم + الأعراس + يومي.
- **التنوع:** مجبوس لحم/دجاج/سمك (هامور)/روبيان/فقع.

### (2) الهريس 🟢 — رمضان
- **الوصف:** قمح مجروش + لحم/دجاج → يُطهى ساعات حتى يصير عصيدة ناعمة + سمن + قرفة + هيل.
- **المناسبة:** **رمضان** + الأعياد + الأفراح.

### (3) الثريد 🟢
- **الوصف:** خبز الرقاق مفتوت + مرق لحم + خضار (بطاطا + كوسا + جزر + قرع + باذنجان) + بهارات — «لازانيا قطرية».
- **المناسبة:** رمضان — «لا تخلو مائدة قطرية منه».

### (4) المضروبة 🟢
- **الوصف:** أرز + دجاج/سمك مملح → يُضرب حتى ينعقد + بهارات — كريمي.

### (5) الجريش 🟢
- **الوصف:** قمح مجروش + لحم/دجاج + بهارات — بدوي.

### (6) المشخول 🟢
- **الوصف:** أرز + لحم/دجاج + بهارات — شبيب بالمجبوس.

### (7) المرقوق 🟢
- **الوصف:** عجين + لحم + خضار + مرق — شعبي.

### (8) الجشيد (القشيد) 🟢 — بحري
- **الوصف:** سمك صغير مفتوت + لومي + بهارات.

### (9) الحسو 🟢
- **الوصف:** خلطة بهارات (كمون + كزبرة + كركم + فلفل + زنجبيل + دارسين + حبة سوداء + حلبة + رشاد) — طبق بهارات.

### (10) العصيدة 🟢
- **الوصف:** دقيق/تمر + سمن + بهارات — شعبي.

## 3. الحلويات 🟢

| الحلوى | الوصف | المناسبة |
|---|---|---|
| **اللقيمات** | كرات عجين مقلية + دبس التمر/العسل — أشهر حلوى | رمضان + الأعياد |
| **البلاليط** | شعيرية حلوة + زعفران + هيل + بيض | فطور |
| **الخنفروش** | أقراص مقلية + زعفران + ماء ورد | — |
| **الخبيصة** | دقيق/سميد + سكر + زعفران | — |
| **البثيثة** | تمر + دقيق + زبدة | — |
| **الساقو** | ساغو + سكر + حليب — رمضاني | رمضان |
| **المحلبية/العيش** | أرز + حليب + سكر | — |
| **عيش شيلاني محمر** | أرز محمَّر | — |

---

## 4. الخبز والمشروبات والضيافة 🟢

- **القهوة القطرية:** هيل + زعفران + تمر (ضيافة).
- **شاي الكرك:** شاي + حليب + سكر — شعبي.
- **التمر:** ضيافة يومية.
- **خبز الرقاق:** أساسي مع الثريد.

---

## 5. مأكولات رمضان 🟢

- **الإفطار:** تمرة + الهريس + الثريد + المجبوس + اللقيمات + البلاليط + الخنفروش + الساقو + السمبوسة.
- **الغبقة:** وجبة ليلية رمضانية.

---

## 6. ربط الطعام بالجغرافيا 🟢

| المنطقة | الأطباق المميزة | السبب |
|---|---|---|
| الساحل (الدوحة/الخور) | مجبوس السمك + الجشيد + المالح | بحري + صيد + تجارة |
| الداخل (الريان/الشحانية) | الهريس + الجريش + الثريد + لحم | بدوي + قمح + رعي |
| الجنوب (الوكرة/مسيعيد) | المجبوس + المضروبة | صناعي + متنوع |

---

## 7. ملاحظات ثقافية 🟢

- **المجبوس = الطبق الوطني** — يُقدَّم في الولائم + رمز الكرم.
- **الهريس + الثريد = رمضان** — «لا تخلو مائدة قطرية منهما».
- **القهوة القطرية + شاي الكرك = ضيافة**.
- **اللومي + البزار + الزعفران** = بصمة قطرية-خليجية.
- **الشيف عائشة التميمي:** وثقت الأكلات التراثية في كتاب «موائد شعبية قطرية» (59 صنفًا).

## خلاصة الطعام

المطبخ القطري = **مطبخ خليجي بهاراتي** قائم على المجبوس (الطبق الوطني) + الهريس (رمضان) + الثريد (التراث) + المضروبة + الجريش + اللقيمات + البلاليط + الخنفروش + القهوة القطرية + شاي الكرك. تتمايز الأطباق: بحري (سمك) على الساحل + بدوي (قمح/لحم) في الداخل. البهارات (لومي/بزار/زعفران) = البصمة القطرية. 🟢
