# دولة قطر — العادات والثقافة

> منهجية: العادات + المناسبات + الفنون + العمارة + الحرف. ربط الجغرافيا بالثقافة.
> المصادر: ويكيبيديا، الجزيرة، almintaqa، mawdoo3، 2thar، claudeabouchacra.

---

## 1. الموسيقى والفنون الشعبية 🟢

### (أ) العيالة 🟢 — الرقصة الوطنية
- **الوصف:** رقصة جماعية للرجال — صفان متقابلان + طبول + سيوف/عصي + شاعر.
- **الأصل:** **بدوي** — تراث بري.
- **المناسبة:** الأعياد الوطنية + الأعراس + المناسبات الرسمية.

### (ب) الفنون البحرية 🟢
- أغاني البحر (الصيد + الغوص على اللؤلؤ) — على الساحل.

### (c) الموسيقى الصوفية 🟡
- بعض الزوايا (محدودة).

---

## 2. المجالس 🟢

- **المجلس:** مكان تجمع الرجال — لتبادل الأفكار + القضايا + الضيافة.
- مؤسسة اجتماعية-سياسية قطرية.

---

## 3. الأعراس والمناسبات 🟢

### (أ) العرس القطري — عدة أيام 🟢
- **الخطوبة → الحناء (ليلة الحناء) → العرس (العيالة) → الدخلة.**
- العريس: الثوب + البشت + الغترة + العقال.
- العروس: ثوب النشل (مطرَّز بالذهب) + حلي + الحناء.

### (ب) المناسبات الوطنية 🟢
| التاريخ | المناسبة | الذكرى |
|---|---|---|
| **18 ديسمبر** | **اليوم الوطني** | تأسيس قطر (جاسم 1878) |
| **3 سبتمبر** | **عيد الاستقلال** | الاستقلال 1971 |

### (c) المناسبات الدينية 🟢
- رمضان (الهريس + الثريد + اللقيمات + المجالس) + عيد الفطر + عيد الأضحى + المولد النبوي.
- **القرقيعان:** منتصف رمضان (أطفال + حلوى) — خليجي مشترك.

---

## 4. العمارة 🟢

### (أ) العمارة التقليدية 🟢
- **سوق واقف** (الدوحة): أعرق سوق — بيوت طين + أزقة ضيقة + مطاعم + حرف — مرمَّم.
- **مشيرب** (الدوحة): مشروع تراثي + عمارة تقليدية + تخطيط حضري حديث.
- **البيوت القديمة:** طين + خوص + مجاهر هواء (تكييف طبيعي).

### (ب) العمارة الحديثة 🟢
- **متحف الفن الإسلامي** (2008 — تصميم آي إم بي): أحد أكبر متاحف الفن الإسلامي عالميًّا — على جزيرة اصطناعية في خليج الدوحة.
- **متحف قطر الوطني** (2019 — تصميم جان نوفيل): يحاكي «وردة الصحراء».
- **الحي الثقافي كتارا**: مسارح + معارض + مطاعم تراثية + ساحات فنية.
- **مطار حمد الدولي**: واحد من أكبر المطارات الدولية.
- **اللؤلؤة قطر**: مشروع جزر اصطناعية + سكن فاخر.
- **مدينة لوسيل**: مدينة جديدة + ملعب كأس العالم.
- **أبراج الدوحة**: أبراج حديثة (برج أسباير + برج الدوحة).

### (c) المواقع الأثرية 🟢
- **الزبارة** (يونسكو 2013): مدينة تاريخية شمال غرب — تجارة بحرية + لؤلؤ — تراث عالمي.
- **قلعة الزبارة** + **برج الزبارة**.

---

## 5. الحرف اليدوية 🟢

| الحرفة | الوصف |
|---|---|
| **السدو (النسيج)** | نسيج صوفي يدوي — تراث بدوي |
| **الخوص** | نسج سعف النخيل — حصر + أواني |
| **صناعة السفن (القلافة)** | سفن خشبية (سنبوك/شوعي) — تراث بحري |
| **صناعة العباءات/الثياب** | خياطة تقليدية |
| **العطور/البخور** | تصنيع العطور والبخور |
| **صياغة الذهب** | حلي تقليدية |

> الحرف القطرية مزيج **بدوي (السدو/الخوص) + بحري (القلافة) + حضري (العباءات/الذهب)**. 🟢

---

## 6. القيم الاجتماعية 🟢

- **الكرم والضيافة:** قيم عليا — القهوة القطرية + شاي الكرك + التمر + المجالس.
- **النخوة/الشهامة:** قيم بدوية.
- **المجلس:** مؤسسة اجتماعية-سياسية.
- **العائلة الممتدة** + احترام الكبار.

---

## 7. الفنون المعاصرة 🟢

- **قناة الجزيرة** (1996) — شبكة إعلامية عالمية.
- **المدينة التعليمية** — جامعات عالمية (كورنيل + جورجتاون + فرجينيا كومنولث).
- **مهرجانات:** كتارا + الدوحة الدولي للكتاب + سوق واقف.
- **كأس العالم 2022** — مهرجان رياضي/ثقافي عالمي.

## 8. ربط الجغرافيا بالثقافة 🟢

| المنطقة | البصمة الثقافية |
|---|---|
| الدوحة (الساحل) | حضر + سوق واقف + متحف الفن الإسلامي + كتارا + المدينة التعليمية + الجزيرة |
| الداخل (الريان/الشحانية) | بدوي + السدو + الهريس |
| الجنوب (الوكرة/خور العديد) | سياحة صحراوية + خور العديد |

## خلاصة العادات والثقافة

الثقافة القطرية = **مزيج بري-بحري-حضري** يتجلى في: **العيالة** (الرقصة الوطنية) + **المجالس** + **الأعراس** (ثوب النشل/البخنق) + **القهوة القطرية** + **العمارة** (سوق واقف/متحف الفن الإسلامي/متحف قطر الوطني/كتارا) + **الحرف** (السدو/القلافة/الخوص) + **الزبارة** (يونسكو) + **الجزيرة** (إعلام) + **المدينة التعليمية** + **كأس العالم 2022**. قطر = **دولة صغيرة لكن رائدة ثقافيًّا** + **قوة إعلامية** + **أول دولة عربية تستضيف كأس العالم**. 🟢
