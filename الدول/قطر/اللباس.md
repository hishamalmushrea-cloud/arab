# دولة قطر — اللباس التقليدي

> منهجية: لكل قطعة يُذكَر اسمها المحلي + المناسبة + المنطقة + الأصل.
> المصادر: ويكيبيديا (الملابس في قطر)، الجزيرة (ضوابط الزي 2024)، mshireb، mufhras، al-watan.

---

## 1. ملاحظة أولى 🟢

> اللباس القطري = **نجدي/بدوي بالأساس** + ملاءمة للمناخ الصحراوي الحار. محافَظ عليه بقوة — **اللباس الرسمي** في العمل (ضوابط حكومية 2024) + المناسبات.
> **سمة:** الثوب القطري بـ**ياقة + كسرة أمامية + كسرتين خلفيتين** (مميز عن السعودي/الإماراتي).

---

## 2. اللباس الرجالي 🟢

### القطع الأساسية

| القطعة | الوصف | الأصل/الاستخدام |
|---|---|---|
| **الثوب (الدشداشة)** | ثوب أبيض فضفاض طويل بأكمام طويلة — **ياقة + كسرة أمامية + كسرتين خلفيتين** (مميز قطري) — صيفًا قطن أبيض + شتاءً ألوان داكنة (رمادي/أسود) | نجدي — اللباس اليومي + الرسمي |
| **الغترة (الشماغ)** | قطعة قطن مربعة — **بيضاء** (صيفًا — مفضلة قطرية) + حمراء/بيضاء (شتاءً) — تُطوى مثلثًا | نجدي |
| **العقال** | شريط صوف أسود دائري — **العقال القطري = الأكثر تميزًا خليجيًّا** (خيطان تتدلى على الظهر) | نجدي |
| **القحفية** | طاقية قطنية بيضاء تحت الغترة | — |
| **البشت (المشلح)** | عباءة صوفية بلا أكمام + مفتوحة أمامي + تطريز ذهبي (زري) على الأطراف + الكتف — **«جناح العرب»** | نجدي — المناسبات + الوجهاء + العرسان |
| **الدقلة** | معطف طويل فوق الثوب — شتاءً (قطن/صوف/جلد/فرو) | — شتوي |
| **الفروة** | معطف مبطَّن بفروة خراف — شتاءً بارد | بدوي |
| **السديري** | سترة بلا أكمام فوق الثوب | — |
| **الصندل** | حذاء جلدي مفتوح | — |

> زي العريس القطري: **الثوب + البشت + الغترة + العقال**. 🟢

### **ميزة الثوب القطري** 🟢
- **ياقة** (عكس الإماراتي بدون ياقة).
- **كسرة أمامية + كسرتين خلفيتين** (مميز فريد).
- ألوان شتوية: رمادي + أسود + بني.

---

## 3. اللباس النسائي 🟢

### القطع الأساسية

| القطعة | الوصف | الأصل/الاستخدام |
|---|---|---|
| **العباءة** | رداء أسود طويل يغطي الجسم — حرير/قطن + شيلة خفيفة مطرَّزة بالخرز | — خارجي |
| **الجلابية (الدراعة)** | فستان واسع طويل تحت العباءة — منقوش/سادة + مطرَّز عند الجيب والأكمام | — منزلي/مناسبات |
| **ثوب النشل** | ثوب فضفاض مطرَّز بخيوط ذهبية (زري) — من بريسم/حرير/شيفون — ألوان (أحمر/أخضر/أسود) | — المناسبات/الأعراس/رمضان |
| **البخنق** | غطاء رأس وصدر أسود + تطريز ذهبي/فضي — ترتديه **الفتيات الصغيرات** (~12 سنة — علامة بلوغ) | — فتيات |
| **الشيلة** | غطاء رأس أسود | — |
| **النقاب/البرقع** | غطاء وجه (عينان فقط) — من قماش هندي | — بعض النساء |
| **السروال** | بنطلون فضفاض داخلي | — |

---

## 4. الأعراس 🟢

- العريس: الثوب + البشت + الغترة + العقال.
- العروس: ثوب النشل (مطرَّز بالذهب) + الدراعة + حلي + الحناء.
- البخنق للفتيات الصغيرات.

---

## 5. ضوابط الزي الرسمي (2024) 🟢

- **القطريون:** الثوب + الغترة + العقال (الزامب).
- **القطريات:** العباءة + غطاء الرأس.
- **غير القطريين:** البدلة الرسمية الداكنة + ربطة عنق.
- **غير القطريات:** بدلات عمل نسائية محتشمة.
- **البشت الشتوي:** من 1 ديسمبر إلى 1 أبريل.

---

## 6. التطور الحديث 🟢

- **الثوب + الغترة + العقال:** اللباس الرسمي اليومي + العمل — محافَظ عليه بقوة.
- **البشت:** في المناسبات الرسمية + الوجهاء + العرسان.
- **اللباس الغربي (البدلة/الجينز):** رائج بين الوافدين + الشباب.
- **النساء:** العباءة + الشيلة — شائع + ثوب النشل في المناسبات.

---

## خلاصة اللباس

اللباس القطري = **نجدي-بدوي بالأساس** (الثوب/الغترة/العقال/البشت) + نسائي تراثي (العباءة/الجلابية/ثوب النشل/البخنق). الثوب القطري يتميز بـ**ياقة + كسرة أمامية + كسرتين خلفيتين** + العقال القطري بـ**خيطان على الظهر** (الأكثر تميزًا خليجيًّا). اللباس التقليدي محافَظ عليه بقوة + مُلزَم في العمل (ضوابط 2024). 🟢
