# مدن قطر — المرحلة الخامسة

> **المرحلة الخامسة:** ملف لكل **مدينة/تجمّع** موثَّق داخل **بلدية**. ليست محافظة ولا إمارة ولا ولاية. 🟢
>
> **الدوحة المدينة** في `العواصم/الدوحة/` — لا تكرار هنا. **المنطقة الصناعية** (بلدية الدوحة) هنا لأنها ليست ملف العاصمة.
>
> **السكان:** تعداد جهاز التخطيط والإحصاء **31 ديسمبر 2020** عبر جداول citypopulation المطابقة للنشرة 🟢. **لا يُخلط سكان البلدية بسكان المدينة** (الوكرة البلدية 265,102 ≠ الوكرة المدينة 94,272).
>
> لا تُهمَّش الغرب والشمال والصناعة: الدخان، الزبارة، الرويس، مسيعيد، رأس لفان، لوسيل.
