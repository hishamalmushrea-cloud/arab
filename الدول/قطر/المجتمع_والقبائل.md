## 3. القبائل 🟢

> القبيلة = **إطار اجتماعي قوي** في قطر — أساس النظام السياسي (آل ثاني).

### (أ) آل ثاني — الأسرة الحاكمة 🟢
- **الأصل:** **بني تميم** العدنانية (المعاضيد من الوهبة) — من نجد (أشيقر) → قطر (1848).
- **الفروع:** المعاضيد (آل ثاني + العلي + الإبراهيم + العسيري + البادي + الغانم).
- **الحكم:** قطر منذ 1850 (محمد بن ثاني) → جاسم → ... → تميم بن حمد (الحالي).

### (ب) قبائل قطرية بارزة 🟢
| القبيلة | الأصل | الملاحظة |
|---|---|---|
| **آل ثاني** | بني تميم (المعاضيد) | الأسرة الحاكمة |
| **المهانده** | بني هاجر (قحطانية) | حلف — الخور/الذخيرة |
| **البوكوارة (الكواري)** | بني تميم (المشارفه) | كبيرة |
| **السلطة (السليطي)** | بني تميم | الدوحة |
| **البوعينين** | بني تميم (العبادل) | بنوا الدوحة + الوكرة |
| **النعيم** | الأزد (قحطانية) | كبيرة — الساحل الشرقي |
| **المنانعة** | عنزة (عدنانية) | أبوالظلوف + الدوحة |
| **الدواسر** | عدنانية/قحطانية | الدوحة |
| **الهولة** | عرب فارس | الفخرو + الدرويش + العثمان + الخال |
| **البوعلي** | بني سليم (عدنانية) | حلف المهانده |
| **السودان** | بني ياس | الدوحة |
| **الأنصار** | الأوس/الخزرج | قطر |

### (c) الأحزاب القبلية التاريخية 🟡
- **المحانده:** حلف قبلي (المسند + المهانده + البوعلي + القشاقشه + الحسن + العرابيد + الشقيري).
- **المعاضيد:** آل ثاني + العلي + الإبراهيم + العسيري + البادي + الغانم.

### الإسلام في قطر 🟢
- دستوريًّا: **الإسلام الدين الرسمي** + الشريعة مصدر التشريع.
- **المذهب المالكي:** حضور واسع.
- **المذهب الحنبلي:** حضور (تاريخي — الشيخ جاسم حنبلي).
- **الشيعة:** أقلية (بحارنة + عجم) — ~10–15% من المواطنين.
- حرية الأديان للوافدين (كنائس + معابد).

---

## 5. الهوية الوطنية 🟢

- **الهوية = عربية-إسلامية-خليجية** + تعددية ثقافية (88% وافدون).
- **القبيلة** إطار اجتماعي قوي (آل ثاني).
- **اللغة:** العربية (رسمية) + اللهجة القطرية + الإنجليزية (لغة عمل).
- **التركيبة الفريدة:** 12% قطريون + 88% وافدون.
- **كأس العالم 2022:** فخر وطني + هوية عالمية.

---

## 6. لامساواة/تحديات اجتماعية 🟡

- **التركيبة السكانية:** القطريون أقلية (12%) — تحدٍّ ديموغرافي مستمر.
- **البطالة بين القطريين** + التوظيف في القطاع العام.
- **ظروف العمالة الوافدة** (خاصة الآسيوية) — انتقادات دولية 🟡.
- **الهوية الثقافية:** تأثير الوافدين.

---

## 7. الحركات والتنظيمات الاجتماعية 🟢

- **المجالس** — مؤسسة اجتماعية-سياسية.
- **الجمعيات + الأهلية + الرياضية**.
- **المجلس التشريعي (الشورى)** — نصف منتخَب (2021 — أول انتخابات).
- **المرأة القطرية:** مشاركة متنامية (الشيخة موزة + الشيخة المياسة + وزيرات + رياضيات).

## خلاصة المجتمع

مجتمع قطر = **مجتمع متعدد الثقافات** (12% قطريون + 88% وافدون — من أعلى نسب الوافدين عالميًّا). القبائل: **آل ثاني** (بني تميم/المعاضيد — الحاكمة) + المهانده + البوكوارة + السلطة + البوعينين + النعيم + المنانعة + الهولة. الدين: إسلام غالبية (سُنة مالكية/حنبلية + أقلية شيعية) + مسيحية/هندوسية (وافدون). الهوية = عربية-إسلامية-خليجية + كأس العالم 2022. التحديات: التركيبة السكانية (12% قطريون) + ظروف العمالة الوافدة. قطر = **دولة قبلية-حديثة** مع تعددية ثقافية عالية. 🟢/🟡
