## 2. القطاعات الاقتصادية

### (أ) الغاز الطبيعي — عصب الاقتصاد 🟢
- **حقل الشمال:** **أكبر حقل غاز منفرد عالميًّا** (25 تريليون م³ ~13% من الاحتياطي العالمي).
- **الإنتاج:** ~77 مليون طن سنويًّا (2024) → توسعات لـ **127–142 مليون طن بحلول 2030** (+85%).
- **قطر للطاقة (QatarEnergy):** إنتاج + تسييل + تصدير.
- **رأس لفان:** مركز تسييل الغاز (الخور).
- **ثاني عالميًّا** في تصدير الغاز المسال (2025 ~81.5 مليون طن).

### (ب) النفط 🟢
- **حقل دخان:** حقل النفط الرئيسي (غرب) — اكتشاف 1939 + تصدير 1949.
- الإنتاج: ~600–700 ألف برميل/يوم.
- **قطر للبترول:** إنتاج + تكرير.

### (c) القطاع غير النفطي 🟢
- **الخدمات المالية:** مركز قطر المالي (QFC) + بنوك.
- **اللوجستيات/النقل:** مطار حمد الدولي + موانئ (حمد + رأس لفان) + القطرية (الطيران).
- **السياحة:** متنامية (كأس العالم 2022 + متاحف + سوق واقف + خور العديد) — هدف رفاه القطاع السياحي.
- **الصناعة:** بتروكيماويات + أسمدة + صلب (قطر للصلب) + الألمنيوم (Qatalum).
- **الزراعة:** محدودة (صحراء) — تمور + خضراوات + الأمن الغذائي.
- **التكنولوجيا/التحول الرقمي:** الأجندة الرقمية 2030 (3.5% من الناتج غير النفطي).

### (d) الاستثمار السيادي 🟢
- **جهاز قطر للاستثمار (QIA):** أحد أكبر الصناديق السيادية عالميًّا — أصول ضخمة عالميًّا (عقار + أسهم + بنوك).

## 3. الصادرات والواردات 🟢

- **الصادرات:** **الغاز الطبيعي المسال (الأكبر)** + النفط + البتروكيماويات + الأسمدة + الصلب.
- **الواردات:** machinery + غذاء + سيارات + سلع استهلاكية.
- **الأسواق:** آسيا (اليابان/كوريا/الصين — أكبر مستورد) + أوروبا.

---

## 4. رؤية قطر الوطنية 2030 🟢

- **الهدف:** التحول نحو **اقتصاد معرفي** + تنمية مستدامة + رفاه الأجيال.
- **المحاور:** التنمية البشرية + التنمية الاجتماعية + التنمية الاقتصادية + التنمية البيئية.
- **استراتيجية التنمية الوطنية الثالثة (NDS3):** المرحلة الأخيرة من الرؤية.
- **الأجندة الرقمية 2030:** 3.5% من الناتج غير النفطي.
- **الحياد الكربوني 2050:** طاقة نظيفة + كفاءة.

| التحدي | الوصف | الثقة |

| **الاعتماد على الغاز/النفط** | ~90% من الصادرات → عرضة لتقلب الأسعار | 🟢 |

| **البصمة الكربونية** | من الأعلى عالميًّا — استراتيجية حياد | 🟡 |
| **المنافسة** | منتجون جدد للغاز (أمريكا/أستراليا) | 🟡 |
| **التوترات الجيوسياسية** | الأزمة الخليجية (2017–2021) — استوعبتها | 🟡 |

## خلاصة الاقتصاد

الاقتصاد القطري = **اقتصاد ريعي غازي ضخم** (**ثاني أكبر مصدر للغاز المسال عالميًّا** — حقل الشمال أكبر حقل منفرد) + **أعلى نصيب للفرد عالميًّا** + **تنويع ناجح** (القطاع غير النفطي ~60%) + **جهاز قطر للاستثمار** (سيادي عملاق) + **رؤية قطر 2030** (اقتصاد معرفي) + **كأس العالم 2022** (بنية تحتية + سياحة). نمو متوازن (~4%) + مالية صلبة + دين منخفض. التحديات: الاعتماد على الغاز/النفط + نضوب الاحتياطيات + التركيبة السكانية + البصمة الكربونية. المستقبل: توسعات حقل الشمال (127–142 مليون طن بحلول 2030) + اقتصاد المعرفة + الحياد الكربوني. 🟢/🟡
