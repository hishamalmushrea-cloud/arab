# تطبيق «أطلس العرب» لنظام Android

تطبيق Android عربي أصلي يعمل دون إنترنت ويعرض بيانات Schema 2.0.0 كاملة بطريقة
مناسبة للمستخدم العام والباحث. بُني التطبيق بـKotlin وJetpack Compose وMaterial 3،
مع قاعدة SQLite للقراءة فقط مولّدة آليًا من المصدر السلطوي للمشروع.

## ما يحتويه الإصدار الأول

- صفحة رئيسية بهوية عربية وإحصاءات حقيقية.
- بطاقات للدول العربية الـ22.
- ملف لكل دولة يعرض التغطية والطبقات والكيانات والمصادر ووثائق النطاق.
- مكتبة موسوعية تضم النص الكامل لكل ملفات الدول والعواصم والمدن والقرى والأحياء
  والتاريخ والجغرافيا والاقتصاد والثقافة واللهجات والطعام واللباس وغيرها.
- واجهة مستقلة لكل دولة: بطاقة ملخص، وموضوعات أساسية كبطاقات، وأقسام مرتبة
  للمحافظات والمدن والقرى والأحياء، ثم العاصمة والجداول والملفات المرتبطة.
- قارئ Markdown منظم مع فهرس قابل للنقر، وثلاثة أحجام للخط، وعرض مريح للجداول
  والقوائم والاقتباسات، وقارئ كامل لملفات CSV.
- روابط داخلية تفتح ملفات الموسوعة المرتبطة مباشرة، وروابط خارجية تفتح المصدر.
- بحث داخل الملف مع تمييز الكلمات والتنقل بين النتيجة السابقة والتالية.
- مفضلة وسجل قراءة وموضع محفوظ لكل ملف، وبطاقة «تابع القراءة» في الرئيسية؛ كلها
  محلية على الجهاز ولا تُرسل إلى أي خدمة.
- شارات واضحة تميّز: البيانات السلطوية، المادة الموسوعية، التاريخي، الجزئي،
  والنطاق التجريبي، مع وصف كامل لقارئ الشاشة.
- دلالات وصول للعناوين وحالات التحميل والأخطاء، وأوصاف للأزرار، واحترام تكبير خط
  النظام والوضع الداكن وأهداف لمس Material القياسية.
- بحث محلي سريع في الأسماء الرسمية والبديلة وفي نصوص المكتبة العربية كاملة.
- تصفية الكيانات حسب النوع، وملفات المكتبة حسب الدولة والمجموعة والموضوع.
- صفحة مستقلة لكل كيان تشمل الأسماء البديلة والادعاءات والعلاقات والمصدر المرجعي.
- فهرس كامل للمصادر وصفحة تفصيلية للرابط والترخيص والتواريخ.
- عرض manifests ووثائق حالة المجالات الثقافية الأصلية.
- دعم RTL والوضع الداكن والشاشات المختلفة.
- خط **Noto Kufi Arabic** للعناوين و**Noto Sans Arabic** للنصوص، مضمنان داخل
  التطبيق للعمل دون إنترنت بموجب ترخيص SIL Open Font License 1.1.
- جداول Markdown وCSV مرئية بخلايا ورؤوس وصفوف متناوبة بدل النص الخام، وبطاقات
  بيانات أوضح للتغطية والمصادر والكيانات.
- تفضيل الاسم العربي الموثق في العرض عندما يكون الاسم السلطوي الأصلي إنجليزيًا أو فرنسيًا.
- تشغيل كامل للقراءة والبحث دون اتصال بالشبكة؛ يحتاج الإنترنت فقط لفتح رابط خارجي.

## البيانات المضمّنة

الأصل المضمّن هو `app/src/main/assets/database/arab_atlas.db`. يحتوي قاعدة البيانات
على أعمدة محسّنة للبحث، وعلى `raw_json` لكل سجل سلطوي كي لا يسقط أي حقل من العقد.

| العائلة | العدد |
|---|---:|
| الدول | 22 |
| الكيانات | 5,317 |
| الأسماء البديلة | 3,261 |
| العلاقات | 5,706 |
| الادعاءات | 2,245 |
| المصادر | 151 |
| اللقطات | 28 |
| المقامات / التغطية | 112 / 112 |
| صفوف فهرس البحث | 8,578 |
| manifests ووثائق المجالات الثقافية | 42 |
| ملفات المكتبة الموسوعية بالنص الكامل | 2,740 |
| حجم نصوص المكتبة الأصلية | نحو 12.7 MB |

تشمل المكتبة سبع مجموعات كاملة: `الدول/` (2,661 ملفًا)، `العواصم/`،
`الحارات_والأحياء/`، `الخريطة_الثقافية/`، `المقارنات/`،
`قاعدة_بيانات_الأماكن/`، و`المصادر_والمراجع/`. تحفظ النصوص حرفيًا وتُعرض في قسم
مستقل مع تنبيه أنها مواد موسوعية مرجعية وليست جميعها سجلات مقبولة سلطويًا.

لا تُضمّن سجلات `quarantine/` والعينات الداخلية وتقارير سير العمل والعروض المولدة
المكررة في واجهة المستخدم. وهكذا يضم التطبيق **كل بيانات Schema 2.0.0 المقبولة**
و**كل ملفات الموسوعة الموجهة للقارئ**، دون خلط السجلات المحجورة بالمعلومات المنشورة.

## توليد قاعدة التطبيق والتحقق منها

من جذر المستودع:

```bash
make android-data        # يعيد بناء SQLite من data/ وmanifests/
make android-data-check  # integrity + counts + orphans + checksums
```

يسجل المولّد SHA-256 لكل مدخل سلطوي، وبصمة شجرية لجميع ملفات المكتبة، كما يتحقق من
حجم وبصمة محتوى كل وثيقة داخل SQLite. لذلك يفشل الفحص إذا تغير أي سجل أو مصدر أو
manifest أو ملف موسوعي ولم تُعد قاعدة التطبيق.

## بناء APK

المتطلبات:

- JDK 17
- Android SDK 35
- Android Studio حديث أو سطر الأوامر

```bash
cd android
./gradlew :app:assembleDebug
```

الناتج:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

يفحص مسار التحقق الحالي قاعدة البيانات المضمّنة، ويشغّل اختبارات Compose الآلية
للواجهة وإمكانية الوصول عبر Robolectric، ثم يبني نسخة Debug في GitHub Actions عند
كل push أو pull request.

## البنية

```text
android/
├── app/src/main/assets/database/arab_atlas.db
├── app/src/main/java/com/atlasalarab/app/
│   ├── data/          # SQLite + repository + models
│   └── ui/            # navigation, screens, components, theme
└── gradle/            # reproducible Gradle wrapper

scripts/build_android_database.py  # canonical data → SQLite
```

التدفق الوحيد المعتمد:

```text
data/ + manifests/ + data/cultural/ + ملفات الموسوعة السبعة
              ↓
scripts/build_android_database.py
              ↓
arab_atlas.db
              ↓
Kotlin repository
              ↓
Jetpack Compose UI
```

لا تعدّل ملف SQLite يدويًا.

ملفا ترخيص الخطين موجودان في `android/licenses/`. كلا الخطين من مشروع Google Fonts
ويُستخدمان وفق **SIL Open Font License 1.1**.

## إصدار تحديث بيانات

1. حدّث البيانات السلطوية واجتز `make check`.
2. غيّر `DATASET_VERSION` في `scripts/build_android_database.py`.
3. غيّر `ATLAS_DATA_VERSION` في `android/app/build.gradle.kts` إلى القيمة نفسها.
4. نفّذ `make android-data` ثم `make android-data-check`.
5. ارفع `versionCode` و`versionName` عند إصدار APK جديد.

يستخدم التطبيق `ATLAS_DATA_VERSION` لاستبدال النسخة المنسوخة إلى مساحة التطبيق عند
تحديث APK، فلا تبقى قاعدة قديمة بعد تثبيت إصدار جديد.

## حدود الإصدار الأول

- لا توجد خريطة في الإصدار الأول؛ لا يرسم التطبيق حدودًا أو نقاطًا غير موثقة.
- لا يوجد تسجيل دخول أو جمع بيانات شخصية.
- التطبيق قارئ موثوق؛ المساهمة والتحرير يظلان عبر مسار مراجعة المستودع.
- اكتمال طبقة لا يعني اكتمال دولة كاملة، ويظهر هذا التنبيه داخل الواجهة.
