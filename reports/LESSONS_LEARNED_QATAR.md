# Lessons Learned — Qatar

- Current eight-municipality evidence must not be mixed with historical ten-municipality documentation.
- Municipality, city, numbered zone, block, district, and fareej are separate identities.
- PSA and QNMP provide independent census and planning views of the same eight-name universe.
- Arabic/English spelling variants (`Umm Slal`, `Al Daayen`, `Al Sheehaniya`) are Aliases, not duplicate entities.
- Census reference is end December 2020; retrieval is separate.
- Al Zubarah is an archaeological property associated with Qatar, not a municipality or automatically a city entity.
- Lower layers remain unavailable until a current enumerated topology is accepted.

## Depth cycle 1 lessons (2026-09-20)

6. A State Party can appear on an inscription list **only through multi-State files**: Qatar's seven elements are all shared. Recording them as `national` would be a fabrication of exclusivity, so the cycle enforces `shared` for every one of them while still publishing them at `verified`.
7. When an element's official page was not opened, only the meaning of the official **title** is asserted (`official_title_ar` + `description`), and the note says so. Publication does not license description invention.
8. A dialect can be documented honestly by refusing to assert independence: the mirror redirects «لهجة قطرية» to لهجات شبه الجزيرة العربية, so the claims record Gulf/peninsular framing plus 41 glossed words, not a separate-language claim.
9. «الطبق الوطني» is a statement about status, not ownership: المجبوس is recorded `shared` with the national-dish description inside the value, and the validator blocks promoting it.
10. A heritage **market** is a place type of its own (`market`): سوق واقف entered as an entity with `located_in` and a naming narrative, while its crafts stayed separate claims.
11. Zero can be a recorded result: Qatar's language layer is explicitly `not_asserted_in_cycle` with a validator rule rejecting unsourced `language_presence`, which is stronger than silence.
