## 1. القرار التنفيذي

# `READY WITH GUARDS`

أثبتت الطيّارات الأربعة أن نواة Entity/Alias/Relationship/Claim/Source/Snapshot/Denominator/Coverage تعمل عبر أربع مشكلات مختلفة: عمق إداري وتقاطع حدودي، اشتقاق قانوني، حجم كبير وتعارض مقامات، وتعدد بنى داخل البلد الواحد. كما ثبتت الحتمية، وحفظ بيانات البلدان الأخرى، وحداثة المخرجات، والمراجعة المستقلة المسار، والاختبارات السلبية في الطيّارات اللاحقة.

لكن الجاهزية **مشروطة** قبل أول بلد إنتاجي بما يأتي: إغلاق إصدار Schema 2.0.0 المستقل بلا بيانات بلد، gate قطري عام تقوده manifest، عقد تنفيذي موحد للمراجعات والـmutants، dashboard بلا نسبة اكتمال كلية، وسياسة freshness قانونية/مصدرية. لا يجيز القرار توسعًا متوازيًا واسعًا، ولا يبدأ بلدًا خامسًا، ولا يحول أي manifest موجود إلى بيانات مكتملة.

**أول بلد مقترح بعد موافقة مستقلة على التنفيذ واستيفاء الحراس: البحرين، بدورة Direct Structured Expansion، بلد واحد فقط.**

## 3. ما تعلمته الطيّارات

### 3.1 المشكلات المشتركة والمتكررة

1. **المقام خاص بطبقة ولقطة:** قد يكون رسميًا أو متعارضًا أو غير متاح، ولا تنتقل نسبة طبقة إلى البلد كله.
2. **المصدر الذري والمحدد أهم من اسم المؤسسة:** المصدر الصحيح بعنوان أو رابط أو locator خاطئ لا يسند Claim.
3. **هوية المكان ليست الاسم:** الإدارة، المدينة، الموقع التاريخي، ممتلك التراث، والسلطة البلدية قد تتشارك اسمًا ولا تتشارك كيانًا.
4. **الطوبولوجيا ليست شجرة دائمًا:** توجد طبقات موازية، تقاطعات حدودية، آباء مباشرون، واختصاصات مختلفة.
5. **الزمن جزء من المعنى:** التعديل القانوني، اللقطة، current/historical، وعدم معرفة تاريخ النفاذ لا يجوز تسويتها بالاسم.
6. **الثقافة لا تنزل جغرافيًا:** الوطني يبقى وطنيًا، والمشترك يبقى مشتركًا، والمحلي يحتاج دليلًا محليًا.
7. **غياب الدليل نتيجة مشروعة:** `unavailable`, `not_found`, `not_documented`, و`N/A` أفضل من ملء قالب.
8. **المراجعة الدلالية القطرية لازمة:** المدقق العام لا يستطيع اشتقاق قانون الأردن أو تفسير صفوف السعودية أو profiles الإمارات.

### 3.3 ما يجب توحيده

- نماذج السجل الثمانية وmanifest؛ IDs ثابتة؛ مصادر ذرية؛ locators؛ checksums للمدخلات.
- معادلة المقام والتغطية؛ حالات الغياب؛ سياسة A/B والحساسية.
- entity resolution قبل الإدخال؛ فصل الإدارة عن المكان والموقع والشخص.
- حتمية importer/generator؛ حفظ غير البلد؛ freshness؛ idempotence.
- مراجعة مستقلة طبقية ≥10% لكل عائلة مهمة واختبارات سلبية خاصة بالمخاطر.
- شروط الانتقال ومستويات الجاهزية وQuality Dashboard.

### 3.4 ما يجب أن يبقى قطريًا

- أسماء الطبقات وترتيبها والأب المسموح والسلطة المختصة.
- تعريف المقام وتاريخه ومصدره ورخصته والاستبعادات.
- قوانين الزمن والحالات الخاصة والاختصاصات المتوازية.
- مصادر البيانات وقواعد parsing وentity-resolution والـmutants الدلالية.
- المحتوى الثقافي واللهجي ونطاقه وقرار الامتناع.
- Definition of Done القطري فوق الحد الأدنى المشترك.

## 4. قرار استقرار Schema

المرجع التفصيلي هو `reports/SCHEMA_STABILITY_REVIEW.md`. توصيته الرسمية:

# `RELEASE 2.0.0`

نُفذ الإصدار المستقل 2.0.0 بعد إثبات أن التغييرات breaking. سبب الإصدار هو الفرق المتراكم بين عقد أساس v1.0.0 والعقد التنفيذي الحالي، بما فيه حقول مطلوبة جديدة وإعادة تسمية `coverage_percent` إلى `coverage_percentage`، لا الرغبة في إضافة بلد أو نموذج جديد. يجب أن يكون الإصدار مهمة مستقلة تسبق البحرين ولا تحمل بيانات البحرين.

## 5. تصنيف البلدان الثمانية عشر

التصنيف يصف **المخاطر البنيوية والدليلية الأساسية**، لا الحجم أو الشهرة. قد يحمل بلد من A مشكلة محلية عميقة، وقد يكون بلد صغير في C أو D بسبب تعدد البنى أو النزاع.

- **A — Stable / straightforward:** بنية قانونية مستقرة نسبيًا، مصدر مركزي متوقع، ومخاطر قابلة للإغلاق مباشرة.
- **B — Large / deep hierarchy:** عمق أو حجم أو تفرع يجعل التقسيم المرحلي والمراجعة الطبقية ضروريين.
- **C — Multi-structure:** مسارات اختصاص متوازية أو بنية داخلية غير قابلة لشجرة واحدة حتى بلا نزاع واسع.
- **D — Time / conflict / disputed:** القانوني والفعلي والزمني والمتنازع/المدمر/المهجر يجب أن تكون طبقات دلالية مستقلة.

**التوزيع:** A = `BH KW OM QA`؛ B = `DZ EG MA MR`؛ C = `DJ KM LB`؛ D = `IQ LY PS SD SO SY YE`.

## 8. أبعاد التغطية — ممنوع إنشاء نسبة كلية

لا يوجد حقل `overall_completion_percentage`. يعرض dashboard خمسة أبعاد منفصلة، وكل بعد ينقسم إلى طبقاته ومقاماته:

| البعد | ما يقيسه | متى تُحسب نسبة | ماذا يعرض عند غياب المقام |
|---|---|---|---|
| Administrative coverage | كل طبقة قانونية/مؤسسية معلنة على حدة | مقام مؤرخ ومصدر ورخصة، و`matched + excluded = denominator` | `denominator_unavailable/conflicted` والسبب؛ بلا نسبة |
| Populated-place coverage | city/town/village/settlement وغيرها، منفصلة عن الإدارة | سجل وطني أو استخراج bounded معرّف بوضوح؛ لا يختلطان | العدد الموثق ونطاق العينة فقط |
| Neighborhood coverage | neighborhood/quarter/block/fareej والشبيه حسب البلد | سجل رسمي قابل للعد لطبقة محددة | `unavailable`؛ لا يُستنتج من خرائط أو ملفات منتقاة |
| Cultural coverage | المجالات المبحوثة، وحالات `documented/not_found/not_documented/N/A`، وعدد Claims المتحقق حسب domain/scope | فقط إذا وُجد corpus/registry معرف ومؤرخ؛ وهذا نادر | counts وحالة البحث، لا نسبة مصطنعة |
| Claim-verification coverage | Claims المنشورة التي اكتمل مصدرها ومحددها والتحقق منها | مقامها هو كل Claims المنشورة في اللقطة نفسها | تعرض pending/ambiguous/disputed منفصلة؛ لا تُسقط من المقام |

حتى لو كانت جميع الأبعاد ذات مقامات معروفة، لا تُجمع ولا تُوزن إلى «اكتمال البلد». الإكمال وصف طبقة في تاريخ، لا صفة أبدية للدولة.

## 9. مستويات النضج 0–6 وشروط الانتقال

| المستوى | الاسم | الحالة المطلوبة | شرط الانتقال الصريح |
|---:|---|---|---|
| 0 | Registered / Manifest only | manifest موجودة، البلد `not_started` أو `baseline_only`، ولا import إنتاجي | schema-valid manifest، nomenclature أولي، صاحب قرار، ونطاق مستبعدات؛ لا يكفي وجود ملفات |
| 1 | Evidence mapped | خريطة السلطات والمصادر والتراخيص والزمن والطوبولوجيا | فتح مصدر أولي لكل طبقة، تحديد atomic locators، وتسجيل المقامات المتاحة/المتعارضة/غير المتاحة |
| 2 | First layer closed | أول طبقة إدارية مغلقة أو مصرح بتعذر مقامها بلا ادعاء نسبة | IDs ثابتة، source-backed entities/aliases/parents، صفر duplicate/orphan/cycle، ومعادلة التغطية صحيحة |
| 3 | Declared administrative scope closed | كل الطبقات الإدارية الداخلة في نطاق الدورة مغلقة أو مستبعدة/غير متاحة بوضوح | مدقق دلالي قطري، حالات زمنية واختصاصات موازية صحيحة، وكل unmatched/excluded مفسر |
| 4 | Evidence-shaped local content | طبقة أماكن محدودة بالمقام وحزمة ثقافة/لهجة لا تملأ الفراغ | entity resolution قبل الإدخال؛ لا طبقة أعمق دون مقام أو unavailable رسمي؛ كل Claim ذري ومحدد ومؤهل النطاق |
| 5 | Independently accepted candidate | البيانات قابلة للمراجعة وليست صحيحة ذاتيًا بالمدقق نفسه | مراجعة مستقلة ≥10% لكل عائلة مهمة، mutants القطرية كلها مكتشفة، P0=0 وcritical P1=0، A/B ≥95% |
| 6 | Production | commit منشور، build حتمي، dashboard مؤرخ، وموافقة قبول | idempotence، حفظ غير البلد، generated freshness، CI remote أخضر، شجرة نظيفة، وسجل release/rollback |

أي فشل يبقي البلد في مستواه ولا يخفض متطلبات الطبقة التالية. `Full Pilot`, `Micro Pilot`, و`Direct Structured Expansion` تختلف في اتساع الإثبات، لا في شروط Level 5–6.

## 10. سير العمل القطري العام — 14 خطوة

1. **Manifest:** تثبيت ISO والاسم والحالة ونطاق الدورة والطبقات المحلية والآباء المسموحين.
2. **Authority map:** تحديد السلطة القانونية والإحصائية والمكانية لكل طبقة، وعدم افتراض سلطة واحدة.
3. **Topology and time profile:** وصف الشجرة والمسارات الموازية والتقاطع وlegal/de_facto/current/historical والحالات الخاصة.
4. **Atomic source register:** سجل مستقل لكل قانون/جدول/صفحة/corpus مع publisher وlocator وتاريخ ورخصة وtier.
5. **Snapshots:** حفظ المدخلات المسموح بها وبصماتها وتاريخها وطريقة التقاطها؛ retrieval ليس valid-from.
6. **Denominator ledger:** تعريف مقام كل طبقة أو `unavailable/conflicted` وسبب ذلك قبل الاستيراد.
7. **Staging and importer design:** parser قطري حتمي، fixtures محدودة، وقائمة الملفات التي يديرها ويحفظ ما عداها.
8. **First administrative closure:** إغلاق الطبقة الأولى واختبار IDs وAliases والأب والمصدر والمقام.
9. **Declared hierarchy closure:** إضافة الطبقات الأعمق فقط حسب manifest، مع عدم فرض مسار موحد على البنى المتوازية.
10. **Entity resolution:** مقارنة الاسم والـAliases والأب والنوع والإحداثيات والفترة قبل إنشاء مكان/موقع/سلطة جديدة.
11. **Local and cultural evidence:** تطبيق استراتيجية المستويات الخمسة أدناه، ونشر Claims فقط حيث تستوفي المصدر والنطاق.
12. **Validation:** schema + integrity + country semantics + source quality + coverage arithmetic + temporal rules.
13. **Independent review and negative tests:** عينة طبقية جديدة، فتح مصادر، ومخاطر/ mutants خاصة بالبلد وإصلاح المصدر المنظم.
14. **Production gate:** توليد، freshness، idempotence، preservation، dashboard، commit/CI أخضر، قرار PASS ثم Level 6.

## 11. استراتيجية التوسع المحلي ذات المستويات الخمسة

| المستوى المحلي | النطاق | بوابة البدء والإغلاق |
|---:|---|---|
| P1 | anchors الإدارية الوطنية والطبقة الأولى | مقام مؤرخ أو تصريح رسمي بعدم توافره؛ لا عمق قبله |
| P2 | الطبقات الإدارية الأدنى والاختصاصات الموازية | مقام مستقل لكل طبقة ومسار؛ لا يُورث مقام P1 |
| P3 | المدن/البلدات/القرى/التجمعات | سجل قابل للعد أو bounded extraction معرف؛ لا تحويل المقعد الإداري تلقائيًا إلى مدينة |
| P4 | الأحياء/الحارات/القطع/الفريج/المجتمعات التخطيطية | مقام رسمي للنوع المحدد أو `denominator_unavailable` موثق؛ لا نسبة من عينة |
| P5 | المواقع التاريخية والثقافية والطبيعية والأسواق والأشخاص والادعاءات المحلية | دليل entity-resolution ومصدر ذري واتصال مكاني ودلالة؛ لا قالب يفرض عنصرًا على كل مكان |

**قاعدة المنع:** لا يبدأ مستوى أعمق إلا إذا كان مقامه متاحًا ومؤرخًا، أو أُعلن رسميًا/منهجيًا أنه غير متاح مع سبب. الحالة الثانية تسمح بعينة bounded موصوفة، ولا تسمح بـ`100%` أو «اكتمال وطني».

## 12. سياسة الثقافة والدليل

### 12.1 النطاق الموحد

كل Claim ثقافي يبين موضوعه ومكانه وزمنه ومصدره ومحدده، ويستخدم النطاق المناسب:

- `national`: دليل وطني على كيان الدولة؛ لا ينسخ إلى المناطق.
- `regional`: منطقة يذكرها المصدر صراحة.
- `local`: مكان محدد بدليل محلي.
- `shared`: ممارسة/عنصر مشترك عابر للحدود أو المناطق؛ ليس حصرية.
- `historical`: نطاق أو فترة تاريخية، لا وصفًا تلقائيًا للحاضر.
- `official`: تعيين قانوني/رسمي؛ لا يعني أنه الوحيد أو الأكثر ممارسة.
- `popular`: استعمال اجتماعي موثق؛ لا يعني الرسمي.
- `disputed`: روايات منفصلة بمصادرها؛ لا تسوية بالدمج.

`emirate_specific` يبقى نطاقًا إماراتيًا خاصًا في البيانات الحالية، ولا يعني uniqueness. يحدد subject والمكان البعد الجغرافي، بينما يشرح التصنيف طبيعة الإسناد؛ لا يجوز استعمال `official` لإخفاء غياب النطاق.

### 12.2 الكلمات المحظورة بلا دليل مناسب

لا تُنشر «فريد/unique»، «الوحيد/only»، «الأقدم/oldest»، «الأكبر/largest»، أو «وطني/national» إلا إذا سجل Claim:

1. مصدرًا ذريًا يقرر العبارة لا مجرد مصدر يذكر العنصر؛
2. comparison class ومجالًا جغرافيًا وزمنيًا واضحًا؛
3. مقام المقارنة أو منهجها ومقياس `largest` ووحدة القياس؛
4. locator دقيقًا وتاريخ صلاحية/ملاحظة freshness؛
5. مصدرين مستقلين إذا كانت حساسة، أو `status: disputed`.

«الأقدم» يحتاج chronology قابلة للمقارنة، و«الوحيد» يحتاج بحثًا/سجلًا شاملاً لا عينة، و«وطني» يحتاج سلطة أو corpus وطنيًا ولا يُستنتج من الشهرة.

## 13. نموذج اللهجة والمعجم المستقر

الوحدة القابلة للنشر ليست «عدد لهجات البلد»، بل attestation ذرية:

`language → variety/dialect → form → meaning → place → register → source+locator → study_date → speaker_or_study → IPA عند الحاجة`.

القواعد:

- تحفظ `language`, `dialect`, `variety`, `form`, `meaning`, `place_id`, `register`, `study_date`, `speaker_or_study`, و`ipa` كحقول منفصلة.
- IPA مطلوب عندما يعتمد الادعاء على فرق صوتي أو عندما يلزم لرفع الالتباس؛ ولا يُختلق من الكتابة.
- مثال واحد يثبت استعمال الصيغة في عينة الدراسة، ولا يثبت الحصرية أو كل سكان المكان.
- لا يُعلن عدد عام للهجات إلا بدراسة أكاديمية تحدد تعريف «لهجة»، corpus/السكان، المساحة، التاريخ، ومنهج العد. وإلا تكون الحالة `not_documented` ولا رقم.
- اللهجة أو التنويعة كيان مستقل عند الحاجة، والصيغة `lexical_form` وعلاقات `variety_of/form_of/attested_in`؛ النص الحر لا يستبدل السلسلة.

## 14. البلدان التي لا تكفيها شجرة بسيطة

يجب استعمال الزمن والحالة صراحةً، لا notes فقط:

- **إلزامي كامل:** العراق، ليبيا، فلسطين، السودان، الصومال، سوريا، اليمن — تحتاج بحسب الدليل `legal`, `de_facto`, `disputed`, `current`, `historical`، ومع فلسطين/السودان/سوريا/اليمن حالات `destroyed` و`displaced` عند وجود دليل ذري.
- **overlay انتقالي إلزامي:** الجزائر للوحدات التي لا تنفذ صلاحيتها الكاملة قبل 2027؛ لبنان للتغيير المؤرخ في كسروان-جبيل؛ ولا تنشر حالة مستقبلية كـcurrent.
- **اختصاصات متوازية بلا نزاع شامل:** جيبوتي، جزر القمر، المغرب، مصر، قطر، الكويت، وعُمان تحتاج أنواعًا ومسارات منفصلة، حتى إن لم تحتج `de_facto/disputed`.

لا تستخدم علاقات `administrative_parent` لتسوية مطالبتين متعارضتين. تحفظ الرواية القانونية والفعلية والمتنازع عليها بعلاقات/Claims ومصادر وفترات مستقلة، وتستبعد العلاقات غير الإدارية من فحص دورات شجرة الإدارة.

## 15. حجم الدفعة والقدرة التشغيلية

- **الدفعة الأولى:** بلد واحد نشط فقط — البحرين بعد الموافقة والحراس.
- **الدفعتان التاليتان:** بلد واحد في كل مرة حتى يحقق بلدان إنتاجيان متتاليان Level 6 بلا regression.
- **بعد إثبات القدرة:** حد أقصى بلدان نشطان، وبحد أقصى Full Pilot واحد داخل الدفعة؛ يجب أن تكون المراجعة مستقلة الموارد لكل بلد.
- **بوابة زيادة الحد:** زمن مراجعة مقاس، backlog P1=0، CI ضمن الميزانية، ومراجع قادر على فتح العينة لا مجرد تشغيلها.
- **محظور:** قبول عشرة بلدان متوازية، أو بدء بلد جديد لتجاوز فشل بلد قائم، أو استخدام ترتيب الـ18 كإذن تنفيذ.

القيم المجهولة `null` مع `missing_reason`، لا صفرًا. لا تقاس الجودة بعدد الملفات أو الأسطر أو حجم Markdown.

## 17. ما يقيس الجودة وما لا يقيسها

**ليست مقاييس جودة:** file count، line count، حجم Markdown، عدد الصفحات المولدة، أو مجموع Entities بلا مقام. يمكن لملف صغير أن يغلق سجلًا رسميًا كاملًا، ويمكن لآلاف الأسطر أن تكون تكرارًا أو ادعاءات بلا مصادر.

**الأولوية:**

1. Entities وClaims المتحققة ومحددة الهوية.
2. جودة المصدر الذري ودقة locator والرخصة/اللقطة.
3. المقام المؤرخ ومعادلة التغطية والاستبعادات المفسرة.
4. سلامة hierarchy والهوية والزمن وصفر duplicate/orphan/cycle.
5. المراجعة المستقلة والاختبارات السلبية.
6. قابلية إعادة البناء والحتمية وحفظ غير البلد وCI.

## 18. التخزين وقاعدة البيانات

**لا تُستبدل الآن بنية Markdown + JSONL + CSV بقاعدة بيانات سلطوية.** JSONL/JSON والمصادر الذرية هي مصدر الحقيقة، وMarkdown/HTML/CSV مخرجات قابلة لإعادة البناء. الحجم الحالي ومقاييس زمن الطيّار السعودي لا يظهران bottleneck قاعدة بيانات؛ bottleneck هو الدليل والمقام والمراجعة.

التوصية المرحلية:

1. الاحتفاظ بالمصدر الحالي في أول دفعات الإنتاج.
2. إضافة **SQLite مشتقة read-only** لاحقًا إذا احتاج dashboard أو QA إلى joins وبحث أسرع؛ تُعاد بناؤها حتميًا ولا تُحرر مباشرة.
3. تأجيل PostgreSQL إلى وجود كتابة متعددة المستخدمين، معاملات متزامنة، صلاحيات، أو خدمة تشغيلية لا يحلها Git workflow.
4. تأجيل API إلى وجود مستهلك معرف وSLA/versioning؛ لا يُنشأ API لمجرد عدد البلدان.

إذن: لا «قاعدة حقيقية» سلطوية الآن، ولا migration في هذه المرحلة.

## 20. المخاطر الخمسة والحراس الخمسة

### أعلى خمسة مخاطر قبل التوسع

1. **انجراف عقد Schema تحت الرقم نفسه** وما يسببه لمستهلكي الإنتاج.
2. **بوابات قطرية hard-coded** لا تتوسع بأمان إلى 18 دورة ولا تضمن قواعد موحدة.
3. **غياب/تعارض المقامات والسجلات الحالية**، خصوصًا في الطبقات المحلية.
4. **تقادم القانون والمصدر وفشل المحتوى رغم خضرة CI**؛ أثبته قبول تونس المستقل.
5. **تسوية البنى الزمنية/المتنازع عليها أو تسريب الثقافة واللهجة** لإكمال حقول أو رفع الأعداد.

### أعلى خمسة حراس يجب الاحتفاظ بها

1. **مصدر ذري + locator لكل Claim**، ومصدران مستقلان للحساس أو `disputed`.
2. **مقام مؤرخ لكل طبقة**، و`matched + excluded = denominator`، ولا نسبة عند unavailable.
3. **هوية وعلاقات وزمن صريحة** مع صفر duplicate/orphan/cycle وعدم فرض شجرة واحدة.
4. **مراجعة مستقلة ≥10% + negative mutants قطرية**، مع P0=0 وcritical P1=0.
5. **import/generation حتمي**، idempotence، حفظ غير البلد، freshness، clean tree وCI remote أخضر.
