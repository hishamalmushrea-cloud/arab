# Lessons Learned — Sudan

- Exact 18-state enumeration supersedes stale 17-state pages only with explicit source/date reconciliation.
- A currently unavailable official page can support a medium-confidence bounded release only when exact indexed entries and an independent government count are preserved, and the access limitation is prominent.
- Abyei special/claimed status must not be inserted as an ordinary state.
- Legal state identity never proves effective control, administrative operation, destruction, displacement, or access.
- Unknown locality and administrative-unit denominators require null coverage, not percentages.
