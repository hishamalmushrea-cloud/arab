# Lessons Learned — Somalia

- A denominator must name its authority: seven is the current Ministry of Planning frame, not a neutral sovereignty judgment.
- Banadir Regional Administration is a parallel unit and must not be silently promoted to Federal Member State.
- Somaliland's FGS planning/Senate classification must remain an attributed disputed narrative.
- North East State requires a dated transition from SSC-Khaatumo through 2025 formation to the 2026 full-member declaration.
- A predecessor name belongs in temporal provenance, not a duplicate current entity.
- Overlapping territorial claims and effective control cannot be derived from federal lists.
- Region and district denominators remain unavailable until competing authority structures are reconciled.

## Depth cycle 1 (2026-09-23)

- A country can be present on the ICH list and still own **no** `national` element: both Somali elements are shared files (02087 with Ethiopia and Djibouti, 02283 with six other States), and the validator fails if either is reclassified.
- A unilateral/tentative State submission is not an inscription: the three 2024–2025 tentative-list sites stay `status = القائمة المؤقتة` with **proposed** criteria, and the inscribed count stays a published, deliberate zero.
- A constitution that does not name the capital must not be made to name it: Article 9 defers the status of the capital to the constitutional review process, so no capital claim is sourced from it (a mutation injects one and must fail).
- Shared UNESCO pages need per-country source IDs: the Xeer Ciise page overwrote Djibouti's file on the first run; re-issue under an `-SO-` ID, restore the other country's file, and audit `refs(source) ⊆ source.country_scope`.
- A no-numbers rule needs an executable guard, not a promise: percentages, count words beside digits, and count-named keys are rejected inside language/dialect/food/craft/custom payloads, and a mutation must prove the guard works.
- Places stay places: four heritage places carry one `located_in` each with no administrative parent — the tentative file names states and regions, but the accepted layer keeps region/district universes unavailable, so no parent is inferred.
- A garbled coordinate string in a source is left unrecorded rather than repaired by guesswork.
