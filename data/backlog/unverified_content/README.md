# مخزن المحتوى غير الموثق — backlog

هذا المجلد يجمع المعلومات المفيدة التي **حُذفت أو اسُتبعدت سابقًا لمجرد ضعف التوثيق**، أو التي تُجمع أثناء البحث قبل تحويلها إلى سجلات `data/` منظمة.

## القواعد

1. **لا يُضاف منه شيء إلى `data/` عشوائيًا.** يعاد تقييم كل بند عند الوصول إلى دورة البلد/المنطقة المناسبة.
2. كل بند يجب أن يحمل: النص، البلد/المكان، أصل المعلومة (مصدر/رابط/كتاب/رواية)، وتصنيفًا أوليًا لدرجة الثقة (🟡 مرجحة / 🟠 معلومة محلية / 🔴 غير موثقة / ⚪ رواية شعبية).
3. **ممنوع إدخال أي بند بلا أصل خارجي معروف** — هذا المخزن لتأجيل التقييم، لا للتحايل على قاعدة عدم الاختلاق.
4. الصيغة المفضلة: ملفات JSONL باسم `{ISO2}_backlog.jsonl` بالحقول:
   `text`, `country_code`, `place_hint`, `topic`, `origin`, `origin_locator`, `initial_status`, `collected_at`, `notes`.

## العلاقة بالحجر `data/quarantine/`

- **الحجر**: صفوف قديمة رُفضت أثناء الهجرة لأسباب بنيوية، ولها سجل قرار.
- **الـbacklog**: معلومات معرفية صالحة الشكل تنتظر إعادة تقييم موضوعي بموجب سياسة `00_فلسفة_الموسوعة.md`.
