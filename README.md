# مشروع «العرب» — بيانات جغرافية وثقافية موثّقة

هذا المستودع يجمع موادًا عربية عن 22 دولة، لكنه **ليس فهرسًا مكتملًا للأماكن**.
التغطية المحلية الحالية غير مكتملة، ولا يمثّل المشروع حتى الآن جميع المدن أو القرى أو
التجمعات المأهولة أو الأحياء أو الحارات. وجود مجلد أو ملف لا يثبت اكتمال أي طبقة.

> **المصدر السلطوي هو Schema 2.0.0 تحت [`data/`](data/README.md).** ملفات Markdown وCSV
> القديمة موادّ مرجعية محفوظة، أما [`generated/`](generated/markdown/README.md) فهو عرض
> يُعاد بناؤه من البيانات المنظمة ولا يُعدّل مباشرة.

## تطبيق Android — «أطلس العرب»

يتضمن المستودع تطبيق Android عربيًا أصليًا تحت [`android/`](android/) مبنيًا بـKotlin
وJetpack Compose. يعمل التطبيق دون إنترنت ويضم قاعدة SQLite مولّدة تحتوي كل سجلات
Schema 2.0.0 المقبولة: الكيانات والأسماء البديلة والعلاقات والادعاءات والمصادر
واللقطات والمقامات والتغطية، إضافة إلى manifests ووثائق حالة المجالات الثقافية.

يوفر التطبيق بحثًا عربيًا في الأسماء الرسمية والبديلة، وصفحات للدول والكيانات
والمصادر، وتصفية حسب النوع، وعرضًا واضحًا لحدود التغطية. كما يضم مكتبة منفصلة تحفظ
النص الكامل لـ2,740 ملفًا من `الدول/` و`العواصم/` و`الحارات_والأحياء/`
و`الخريطة_الثقافية/` و`المقارنات/` و`قاعدة_بيانات_الأماكن/`
و`المصادر_والمراجع/`، مع بحث في محتواها. تظهر ملفات كل دولة كبطاقات موضوعية
وأقسام إدارية مرتبة، ويوفر القارئ فهرسًا داخليًا وأحجام خط متعددة وروابط قابلة
للفتح وبحثًا داخل الملف وعرضًا منسقًا لـMarkdown وCSV. تستخدم الواجهة Noto Kufi
Arabic للعناوين وNoto Sans Arabic للنص، وتعرض الجداول كخلايا وتفضّل الاسم العربي
الموثق للكيانات. كما تعرض شارات تفرق بين السلطوي والموسوعي والتاريخي والجزئي،
وتدعم دلالات قارئ الشاشة وتكبير خط النظام. تحفظ المفضلة وسجل القراءة وموضع المتابعة
محليًا على الجهاز، وتُفحص المكونات باختبارات Compose آلية. تبقى السجلات المحجورة وتقارير سير العمل
خارج واجهة المستخدم كي لا تختلط ببيانات منشورة.

```bash
make android-data-check        # التحقق من قاعدة التطبيق ومطابقتها للمصدر
cd android && ./gradlew :app:assembleDebug
```

دليل البنية والبناء والتحديث في [`docs/ANDROID_APP.md`](docs/ANDROID_APP.md).

### عائلات البيانات السلطوية

| النموذج | المسار |
|---|---|
| Entity | `data/entities/entities.jsonl` |
| Alias | `data/aliases/aliases.jsonl` |
| Relationship | `data/relationships/relationships.jsonl` |
| Claim | `data/claims/claims.jsonl` |
| Source | `data/sources/*.json` |
| Snapshot | `data/snapshots/snapshots.jsonl` |
| Denominator / Coverage | `data/coverage/*.jsonl` |

لا يُنشأ Entity بلا `canonical_source_id`، ولا Claim بلا `source_id`. الأسماء العربية
والإنجليزية والتاريخية والمحلية التي تشير إلى المكان نفسه تحفظ كـAlias، ولا تنشأ
كيانات منفصلة. العلاقات الحالية والتاريخية والمتنازع عليها والفعلية تبقى مستقلة.

## التحقق وإعادة التوليد

لا توجد حزم خارجية مطلوبة؛ الأدوات تستخدم مكتبة Python القياسية.

```bash
make schema-migration-test # توافق 1.0.0 وهجرة 2.0.0 والمعنى والحتمية
make malformed-json-test   # اختبار سلبي مستقل للـJSON غير الصالح
make validate              # فحص schemas والبيانات وCSV والروابط والمراجع والتغطية
make generate              # إعادة بناء Markdown وHTML وJSON وCSV
make check                 # migration + جميع بوابات البلدان المقبولة
```

أو مباشرة:

```bash
python3 scripts/validate.py
python3 scripts/generate.py --check
python3 scripts/check_phase_gate.py phase0
python3 scripts/check_phase_gate.py phase1
python3 scripts/check_phase_gate.py phase2
```

يفحص CI الأوامر نفسها عند كل push وpull request. نتائج الطيّار ومقاييسه وقيوده موثقة في
[`reports/PHASE2_TUNISIA_FINAL.md`](reports/PHASE2_TUNISIA_FINAL.md).
