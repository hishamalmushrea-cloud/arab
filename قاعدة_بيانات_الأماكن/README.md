# ملفات CSV القديمة للأماكن

هذه الملفات **ليست المصدر السلطوي** بعد اعتماد Schema v1. هي مدخلات تاريخية محفوظة
للتدقيق والهجرة، ولا يدل عدد صفوفها أو وجود ملف لدولة على اكتمال المدن أو القرى أو
الأحياء أو الحارات.

المصدر المنظم الفاعل موجود في [`../data/`](../data/README.md)، والعروض القابلة
للاستخدام في [`../generated/`](../generated/markdown/README.md).

## صيغة الملفات القديمة

تحتوي ملفات الدول وملف العواصم التجميعي على الأعمدة الـ18 الآتية:

`id`، `الدولة`، `الوحدة_الإدارية_العليا`، `المستوى_الثاني`،
`المدينة_أو_القرية`، `الحي_أو_الحارة`، `الاسم_المحلي`، `الأسماء_البديلة`،
`النوع`، `خط_العرض`، `خط_الطول`، `الارتفاع_م`، `السكان`، `سنة_السكان`،
`المصدر`، `تاريخ_المصدر`، `درجة_الثقة`، `ملاحظات`.

معرّفات هذه الملفات إحالات قديمة فقط. المعرّفات العالمية الثابتة تبدأ `ENT-{ISO2}-`
وتوجد في `data/entities/entities.jsonl`. عولجت اصطدامات المعرّفات القديمة بإبقاء أول
ظهور وإضافة لاحقة حتمية لما بعده، وسُجلت القيم قبل الإصلاح وبعده في
[`../data/quarantine/legacy_repairs.jsonl`](../data/quarantine/legacy_repairs.jsonl).

## سجل الهجرة والحجر

- `data/quarantine/migration_ledger.jsonl`: قرار لكل صف قديم.
- `data/quarantine/legacy_rows.jsonl`: نسخة كاملة من كل صف لم يُقبل أو دُمج أو كان مركبًا.
- `data/quarantine/legacy_source_candidates.jsonl`: عبارات المصادر القديمة التي لم تُرقَّ
  إلى Source ذري بسبب نقص العنوان أو الرابط أو التاريخ أو الرخصة أو المحدد.
- `data/quarantine/quarantine_summary.json`: ملخص الأعداد والأسباب.

لا يجوز استيراد صف واحد مباشرة ككيان عندما يخلط مدينة بوحدة إدارية، ولا يجوز تحويل
اسم مؤسسة في عمود `المصدر` إلى استشهاد ذري من دون بيانات نشر كاملة.

## التحقق

```bash
python3 ../scripts/validate.py
```

يفحص الأمر عدد الحقول، الصفوف المشوهة، UTF-8/NFC، الإحداثيات، المعرّفات المكررة،
البلدان، مطابقة سجل الهجرة، وسلامة البيانات المنظمة الناتجة.
