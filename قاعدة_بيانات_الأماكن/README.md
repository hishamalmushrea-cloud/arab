# قاعدة بيانات الأماكن

سجل منظَّم لكل مكان في الموسوعة (دولة/عاصمة/محافظة/ولاية/مدينة/قرية/حي/حارة)، بصيغتين:

## 1. CSV (قابلة للاستعلام)
- `العواصم_والمدن_الكبرى.csv` — بذرة أولية بعواصم الدول الـ22 (المرحلة الأولى).
- `{الدولة}.csv` — يُنشأ لكل دولة في المرحلة الثانية ويُملأ في المراحل اللاحقة.

الأعمدة: `id | الدولة | الوحدة_الإدارية_العليا | المستوى_الثاني | المدينة_أو_القرية |
الحي_أو_الحارة | الاسم_المحلي | الأسماء_البديلة | النوع | خط_العرض | خط_الطول | الارتفاع_م |
السكان | سنة_السكان | المصدر | تاريخ_المصدر | درجة_الثقة | ملاحظات`

## 2. Markdown (بطاقة المكان داخل ملفه)
انظر القوالب في `../02_منهجية_المصادر_والتحقق.md` القسم 5.

**المفتاح الفريد:** اسم + تبعية إدارية كاملة + إحداثيات، لمنع التداخل بين الأماكن ذات الاسم نفسه.
