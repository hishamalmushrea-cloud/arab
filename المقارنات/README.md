# المقارنات بين المناطق (المرحلة السابعة)

تُبنى بعد اكتمال دراسة المناطق. تشمل:
- الفرق بين لهجات المدن والقرى.
- الفرق بين الطعام والملابس والعادات والعمارة والمناخ والتضاريس والمهن.
- الفرق بين الساحل والجبل والصحراء، والحضر والريف والبادية.
- الكلمات التي تختلف بين المناطق (جدول مقارنة موحَّد).
- التاريخ المتداخل: طرق التجارة/الحج/الهجرة، القبائل العابرة للحدود، اللهجات المتقاربة،
  الأطعمة والملابس المشتركة.
