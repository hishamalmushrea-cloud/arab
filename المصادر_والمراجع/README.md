# المصادر والمراجع

الفهرس السلطوي للمصادر الذرية موجود في [`../data/sources/`](../data/sources/). لكل
مادة منشورة ملف JSON مستقل يتضمن العنوان، الناشر، النوع، الرابط، تاريخ النشر إن كان
معلنًا، تاريخ الاسترجاع، الرخصة، اللغة، البلدان، والمحدد داخل المادة.

عبارات المصادر في ملفات Markdown وCSV القديمة ليست استشهادات فاعلة تلقائيًا. حُفظت
العبارات التي لم تستوف بيانات المصدر الذري في
[`../data/quarantine/legacy_source_candidates.jsonl`](../data/quarantine/legacy_source_candidates.jsonl)
بدل تخمين بياناتها أو نسبتها إلى مصدر غير محقق.

## قواعد ملزمة

- لا Entity بلا `canonical_source_id` ومحدد داخل المصدر.
- لا Claim أو Relationship بلا `source_id`.
- لا تستخدم GeoNames بوصفه سلطة رسمية؛ يمكن أن يكون أداة مطابقة فقط.
- لا تستخدم ويكيبيديا بدل المصدر الأصلي عند توافره.
- لا تُقبل ادعاءات التفرد أو الأقدمية أو الأكبرية بلا مجال مقارنة ومصدر مقارن.
- تاريخ الاسترجاع لا يتحول إلى تاريخ نفاذ قانوني أو لقطة إدارية بالتخمين.
- غياب تاريخ النشر أو الرخصة يصرح به في سجل المصدر ولا يُملأ بقيمة مختلقة.

توجد قائمة سهلة القراءة بالمصادر المستخدمة في كل صفحة دولة مولدة تحت
[`../generated/markdown/countries/`](../generated/markdown/countries/).
